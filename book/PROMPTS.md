Изучи это.

Нужно создать Структуру книги и сохранить в файл book/содержание.md
Это будет основной план написания книги. 

Будет всего 2 уровня для простоты навигации по книге и понимания последовательности изложения материала.

Структура должна состоять из частей книги (##). Например Основы и Настройки, Проектирование, ...

Каждая часть должна содержать подзаголовки (###). Под каждым подзаголовком должно быть краткое описание содержимого буквально один абзац, и список ссылок на файлы где эта информация может быть. Дробить часть на подзаголовки нужно как более детально.

Анализировать содержимое самих файлов с информацией не нужно, это слишком много, только опираться на их заголовки и твои общие знание об этих темах.

Все темы структуры исходных данных в book/tree.md должны быть органично вплетены в рамках ТЗ. При необходимости можно расширить ТЗ если оно не требует покрытия каких то тем.
