# EPLAN Documentation Book

## Goal
Write a comprehensive book about EPLAN based on the provided technical documentation.

Create a practical, readable book for an EPLAN user designing a pressure maintenance pump station according technical specification in ./TZ.md. Every new chapter will reveal more and more knowledge of elan as we try to complete the TZ.

## Core Methodology

- **Voice:** Teacher-to-student persona.
- **Style:** Academic, strict, formal, and precise.
- **Standards:** All project settings, databases, and drawing standards must strictly comply with **GOST and ESKD** standards.
- **Visuals:** Every step requires a screenshot. The text must be written such that the reader follows the visual flow. Placeholders like `![Description of visual element](image_placeholder)` must be inserted >
- **Strategy:** RAG (Retrieval-Augmented Generation) using retrieved docs.
