# Вкладка Размещение (размещение принадлежностей)

## Вызов диалогового окна

Вкладка **Основные данные** > группа команд **Изделия** > **Управление**. В дереве выделен объект, относящийся к уровню иерархии **Размещение принадлежностей**. Выберите вкладку **Размещение**.

На этой вкладке указывается информация о размещении принадлежностей в пространстве листа с учетом определенной исходной точки.

Определенное таким образом размещение принадлежностей может быть назначено в базе данных изделий при присвоении принадлежностей или при создании списков принадлежностей. Предварительно внесенные здесь данные облегчают вставку принадлежностей в трехмерном чертеже монтажных поверхностей.

Обзор основных элементов диалогового окна:

### Варианты установки

Укажите здесь имя определенного варианта размещения принадлежностей.

### Исходная точка

Исходные точки — это строго определенные точки монтажа в пространстве листа. При этом различают автоматически генерируемые исходные точки, которые доступны для группы продуктов "Электрошкаф", групп продуктов "Отдельная часть" и "Корпус", и пользовательские исходные точки, которые пользователь размещает в макросе вручную и которые имеют заранее определенные свойства.

### Перемещаемый

Установите этот флажок, если изделие принадлежностей, размещенное с помощью этого варианта установки, может перемещаться в электрошкафу; снимите флажок, если изделие принадлежностей должно быть стационарной частью шкафа. В зависимости от настройки устанавливается свойство **Функциональный элемент привязан к вышестоящему функциональному элементу**.

### Всплывающее меню

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).
