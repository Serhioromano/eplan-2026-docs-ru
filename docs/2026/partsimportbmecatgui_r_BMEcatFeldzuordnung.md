# Вкладка Присвоение поля BMEcat

## Вызов диалогового окна

Вкладка **Основные данные** > группа команд **Изделия** > **Управление**. Кнопка ++"Дополнительно"++ > **Импортировать**. В поле **Тип файла** выбрана запись для версии ECLASS. Щелкните кнопку ++"..."++ рядом с полем **Тип файла** и выберите вкладку **Присвоение поля BMEcat**.

Здесь свойствам изделия базы данных изделий можно присвоить несколько фиксированных полей BMEcat, не имеющих признака ECLASS или отдельно сохраненных в поле BMEcat. Определенные пользователем свойства и произвольные свойства недоступны для выбора, т. к. отсутствует (многоязычное) имя признака ECLASS. Для импорта таких данных предусмотрена специальная обработка нескольких фиксированных полей BMEcat.

Обзор основных элементов диалогового окна:

### Поле BMEcat

Содержимое этих полей импортируется из файла BMEcat и не подлежит изменениям.

### Свойство изделия

Щелкните по кнопке ++"..."++ в этих полях и в диалоговом окне **Выбор свойств** выберите свойство, которое необходимо присвоить полю BMEcat.

### Всплывающее меню

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).
