# Рассчитать общий вес электрошкафов

С помощью Eplan Pro Panel можно рассчитать общий вес каждого электрошкафа, размещенного в пространстве листа, для всего проекта. Общий вес электрошкафа включает вес электрошкафа, а также вес всех "обычных" изделий, всех функциональных элементов с переменной длиной (например, несущих шин) и соединений.

### Добавить данные о весе в изделия

Для правильного расчета общего веса электрошкафа необходимо ввести соответствующие данные о весе размещаемых изделий. Проверьте их в управлении изделиями.

1. Выберите следующие команды: (Вкладка **Основные данные** > группа команд **Изделия** > **Управление**).
2. Переместите вкладку **Свойства** на передний план.
3. Проверьте, введены ли значения в свойстве изделия **Вес (полностью)** (ID 22233) для всех размещаемых изделий, таких как электрошкафы, клеммы, контакторы и т. д., а также для функциональных элементов с переменной длиной, например несущих шин и кабельных каналов.
4. Добавьте недостающую информацию о весе для изделий в свойстве изделия **Вес** (ID 22046). (Значение, присвоенное в этом свойстве, автоматически вводится в свойство **Вес (полностью)** (ID 22233), необходимое для расчета общего веса после сохранения данных изделий.)
5. Кроме того, проверьте, введены ли в свойстве изделия **Вес/длина** (ID 22067) значения для изделий, которые необходимо разместить в соединении, и добавьте эту информацию, если она отсутствует.

6. Закройте базу данных изделий.
7. В последующем диалоговом окне на вопрос "Хотите выполнить синхронизацию данных изделий в базе данных изделий?" ответьте ++"Да"++.

### Выполнить вычисление

Условия:

* Вы открыли проект.
* Открыты навигатор пространства листа и пространство листа.

1. С помощью центра вставки разместите в пространстве листа все изделия с данными о весе.
2. Выделите пространство листа в навигаторе пространства листа и маршрутизируйте все соединения.
3. Выберите следующие команды: Вкладка **Инструменты** > группа команд **Отчеты** > раскрывающаяся кнопка ++"Генерация отчета по проекту"++ > **Рассчитать общий вес шкафа**.

!!! info "Для сведения:"

    Общий вес каждого электрошкафа в проекте рассчитывается с использованием введенных значений и выводится в свойстве **Общий вес** (ID 36108) размещения изделия электрошкафа.
