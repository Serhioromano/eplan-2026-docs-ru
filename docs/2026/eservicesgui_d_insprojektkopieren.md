# Диалоговое окно "Скопировать файлы со ссылками в проект вручную"

## Вызов диалогового окна

Вы открыли проект.

* Вкладка **Основные данные** > группа команд **Синхронизация** > **Сохранить документы**.
* Вы выделили проект в Навигаторе страниц. **Файл** > **Резервировать**. Нажмите в диалоговом окне **Резервировать проекты** на ++"Связи"++.

В этом диалоговом окне в текущий проект можно скопировать файлы (внешние документы, графические файлы и т. д.), на которые в проекте или в соответствующих основных данных имеются ссылки. Можно также изменить тип хранения с автоматического сохранения файлов на "Копируется вручную" и обновить сохраненные вручную файлы.

Обзор основных элементов диалогового окна:

### Файл

В этом столбце перечисляются все внешние документы, связанные с проектом посредством гиперссылок или как страницы типа "Внешний документ". Здесь же перечисляются графические файлы, на которые в проекте или в основных данных (символах, формах, рамках) к проекту имеются ссылки.

### Тип ссылки

Тип ссылки показывает, как соответствующий файл связан со ссылкой в проекте. Это позволит вам узнать, в какие подкаталоги копируются файлы (тип ссылки "Документ" в `...\<Имя проекта>\DOC\\`, тип ссылки "Графический файл" в `...\<Имя проекта>\Images\\`).

### Дата изменения (ссылка) / Дата изменения (сохранена)

Сравнивая эти столбцы, вы можете проверить, имеет ли сохраненный файл или файл со ссылкой более позднюю дату изменения. Значение в столбце **Дата изменения (сохранена)** остается пустым, если файл еще не был сохранен.

### Тип хранения

Этот столбец показывает, был ли соответствующий файл со ссылкой скопирован в проект. Вы не можете напрямую изменить возможные записи "Не сохранено", "Копируется вручную" или "Копируется автоматически".

### Копировать

Включите флажок для тех файлов, который должны быть скопированы в текущий проект.

* Если это сделано для файлов с типом хранения "Копируется автоматически" или "Не сохранено", то эти файлы будут скопированы в проект вручную. Это изменит тип хранения на "Копируется вручную".
* Если это делается для файлов с типом хранения "Копируется вручную", вам будет предложено перезаписать эти файлы. Это позволяет по мере необходимости обновлять сохраненные вручную файлы.

Если флажок для файла снят, файл не будет скопирован в проект.

### Всплывающее меню

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).

Дополнительно здесь представлены следующие пункты всплывающего меню, специфические для данного диалогового окна:

Пункт меню |  Значение
---|---
Выбрать все |  Включает флажки для всех документов в списке.
Отменить выбор |  выключает все флажки.
