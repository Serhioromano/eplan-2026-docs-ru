# Диалоговое окно Настройки: Нумерация кабелей

## Вызов диалогового окна:

Вы открыли проект.

* **Файл** > **Настройки** > **Проекты** > "Имя проекта" > **Устройства** > **Кабель (автоматически)**. Щелкните рядом с полем **Нумерация кабелей** по ++"..."++.
* Вкладка **Соединения** > группа команд **Кабель** > раскрывающаяся кнопка **Все присвоить заново** > **Автоматически генерировать кабели**. Щелкните в диалоговом окне **Автоматически генерировать кабели** в групповом поле **Нумерация кабелей** рядом с полем **Настройки** на ++"..."++.
* Вы открыли навигатор кабелей, например с помощью следующих команд: вкладка **Соединения** > группа команд **Кабель** > **Навигатор**. Выделите несколько значений, содержащих кабели, и выберите **Всплывающее меню > Нумеровать ОУ кабелей**. Щелкните в диалоговом окне **Нумеровать кабели** рядом с полем **Настройки** по кнопке ++"..."++.

В этом диалоговом окне задаются настройки для нумерации кабелей.

Обзор основных элементов диалогового окна:
