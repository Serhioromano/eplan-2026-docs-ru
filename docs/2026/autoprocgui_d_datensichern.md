# Диалоговое окно Резервировать данные

## Вызов диалогового окна

* Вы открыли проект. Вкладка **Инструменты** > группа команд **Отчеты** > **Автоматизированная обработка**. В диалоговом окне **Выполнить: Автоматизированная обработка** щелкните по кнопке ++"..."++ рядом с полем **Схема**. В диалоговом окне **Настройки: Автоматизированная обработка** в поле **Доступные операции** выделите операцию "Резервировать данные", после чего щелкните по кнопке ![](images/all_arrowright_as.png){: .ui-icon } (Переместить направо).
* Вы открыли проект. **Файл** > **Дополнительно** > группа команд **Расширения** > **Интерфейсы** > группа команд **Автоматизированная обработка** > **Автоматизированная обработка**. В диалоговом окне **Выполнить: Автоматизированная обработка** щелкните по кнопке ++"..."++ рядом с полем **Схема**. В диалоговом окне **Настройки: Автоматизированная обработка** в поле **Доступные операции** выделите операцию "Резервировать данные", после чего щелкните по кнопке ![](images/all_arrowright_as.png){: .ui-icon } (Переместить направо).
* **Файл** > **Управление проектами**. Вы считали в диалоговом окне **Управление проектами** каталоги и выделили, как минимум, один проект. **[Организовать] > Автоматизированная обработка**. В диалоговом окне **Выполнить: Автоматизированная обработка** щелкните по кнопке ++"..."++ рядом с полем **Схема**. Выберите параметр **Схема** и нажмите кнопку ++"..."++ рядом с этим полем. В диалоговом окне **Настройки: Автоматизированная обработка** в поле **Доступные операции** выделите операцию "Резервировать данные", после чего щелкните по кнопке ![](images/all_arrowright_as.png){: .ui-icon } (Переместить направо).

В этом диалоговом окне задаются настройки для автоматизированного резервирования данных.

Обзор основных элементов диалогового окна:

### Метод

В этом поле задается способ резервирования проекта:

* Дополнительно сохранить: Проект сжимается как файл `*.zw1` и хранится в каталоге, выбранном в поле **Каталог для резервирования**. Исходный проект сохраняется без изменений.

* Выгрузить для внешней обработки: проект резервируется на другом носителе данных, а на исходный проект устанавливается защита от записи. Все данные выгруженного проекта остаются на исходном жестком диске. Из проекта `*.elk` в том же каталоге получается проект `*.els`. Дополнительно в выбранном каталоге резервирования генерируется файл резервирования `*.zw1`.
* Архивировать: проект резервируется на другом носителе данных, а исходный проект, за исключением информационного файла, удаляется с жесткого диска. Из проекта `*.elk` в том же каталоге получается проект `*.ela`. Дополнительно в выбранном каталоге резервирования генерируется файл резервирования `*.zw1`.

### Имя файла резервирования

Здесь необходимо указать имя файла резервирования. По умолчанию используется имя проекта. С помощью ![](images/all_selectfile_as.png){: .ui-icon } открывается диалоговое окно выбора файла, где можно выбрать имя существующего файла резервирования.

### Каталог для резервирования

В этом поле расположен каталог для резервирования данных. С помощью кнопки ![](images/all_selectdirectory_as.png){: .ui-icon } октройте диалоговое окно выбора каталога. В этом диалоговом окне в качестве места хранения данных можно выбрать другой каталог. Вы можете использовать любой каталог на любом доступном дисководе.

С помощью пункта всплывающего меню **Вставить переменную пути** перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.
