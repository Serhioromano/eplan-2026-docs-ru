# Вкладка Функциональные элементы (Настройки: Экспорт ЧУ — DXF / Настройки: Экспорт DXF — медь)

## Вызов диалогового окна:

Экспорт ЧУ — DXF:

* **Файл** > **Настройки** > **Компания** > **Механическая обработка** > **Экспорт ЧУ — DXF**. Выберите вкладку **Функциональные элементы**.
* **Файл** > **Экспортировать** > группа команд **Данные изготовления** > **Механическая обработка** > **ЧУ — DXF**. Нажмите рядом с полем **Машина** на кнопку ++"..."++. Выберите вкладку **Функциональные элементы**.

Экспорт DXF — медь:

* **Файл** > **Настройки** > **Компания** > **Механическая обработка** > **Экспорт DXF — медь**. Выберите вкладку **Функциональные элементы**.
* **Файл** > **Экспортировать** > группа команд **Данные изготовления** > **Механическая обработка** > **DXF — медь**. Нажмите рядом с полем **Машина** на кнопку ++"..."++. Выберите вкладку **Функциональные элементы**.

На этой вкладке можно настроить область видимости, слои и цвета контуров функциональных элементов и экспортированных полей.

Обзор основных элементов диалогового окна:

Групповое поле 'Формат поля'

### Отобразить поле:

Поля на монтажных платах и других функциональных элементах изображаются в файле DXF в качестве геометрических форм и присваиваются специфическим слоям и цветам. Если установлен флажок, поле, определенное на монтажной плате или на другом функциональном элементе, отображается в файле DXF при обработке ЧУ в качестве прямоугольника.

Если флажок не установлен, поля в файле DXF не выделяются. Но содержимое этих полей все равно экспортируется.

### Слой:

Стандартное имя слоя, на котором установлено поле в файле DXF.

### Цвет:

Стандартный цвет, который присваивается полю в файле DXF.

* * *

Групповое поле 'Формат контура функц. элемента'

### Генерировать контур функц. элемента:

Контуры трехмерных функциональных элементов показывают их пространственное ограничение дополнительно к основным контурам и путям выдавливания. Если флажок установлен, генерируются контуры функциональных элементов в файле DXF. Их можно вывести в файле DXF на отдельных слоях и присвоить им цвета.

Если флажок не установлен, контуры функциональных элементов не генерируются. Это позволяет сократить количество данных.

### Слой:

Стандартное имя слоя, на котором установлены контуры функциональных элементов в файле DXF.

### Цвет:

Стандартный цвет, который присваивается контурам функциональных элементов в файле DXF.

* * *

Групповое поле Формат информации для сгибания (доступно только для Экспорт DXF — медь)

### Экспортировать линии изгиба:

Если флажок установлен, линии изгибов генерируются из развертки в файле DXF.

### Слой:

Стандартное имя слоя, на котором установлены линии изгиба в файле DXF.

### Цвет:

Стандартный цвет, который присваивается линиям изгибов в файле DXF.

### Экспортировать концы изгиба:

Если флажок установлен, концы изгибов генерируются из развертки в файле DXF.

### Слой:

Стандартное имя слоя, на котором установлены концы изгибов в файле DXF.

### Цвет:

Стандартный цвет, который присваивается концам изгибов в файле DXF.

### Экспортировать примечания для сгибания:

Если флажок установлен, примечания для сгибания генерируются из развертки как текст в файле DXF.

### Слой:

Стандартное имя слоя, на котором установлены примечания для сгибания в файле DXF.

### Цвет:

Стандартный цвет, который присваивается примечаниям для сгибания в файле DXF.
