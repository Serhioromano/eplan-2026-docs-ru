# Изменить маршрутизацию (топология)

Трассу маршрутизации, определенную при маршрутизации маршрутизируемого соединения, можно изменять.

* Маршрутизируемые соединения можно перекладывать с одного сегмента маршрутизации на другой.
* Немаршрутизированные соединения можно прокладывать по сегменту маршрутизации, в результате чего из них получаются маршрутизированные соединения.

При изменении маршрутизации вручную заполняется свойство соединения **Топология: Трасса маршрутизации - по умолчанию**. После этого фильтры соединений, настроенные для сегмента маршрутизации, при маршрутизации этого соединения больше не учитываются.

Для изменения маршрутизации воспользуйтесь центрами сегментов маршрутизации или графикой немаршрутизированных соединений маршрута (тонкая оранжевая линия). Перетаскивая такой центр / такую линию на другой сегмент маршрутизации, можно изменить трассу маршрутизации соединений. Если через сегмент маршрутизации проходят несколько соединений, на экран выводится диалоговое окно выбора, в котором вы указываете, какое из этих соединений необходимо переместить на новый сегмент маршрутизации. Тогда сегмент маршрутизации записывается на выбранных соединениях в свойство **Топология: Трасса маршрутизации - по умолчанию**.

1. Нажмите на сегмент маршрутизации.

!!! info "Для сведения:"

    На сегменте маршрутизации появятся точки захвата.

2. Перетащите центр сегмента маршрутизации на другой сегмент маршрутизации.

!!! info "Для сведения:"

    Отобразится диалоговое окно **Соединения**, в котором перечислены все соединения, проходящие через сегмент маршрутизации источника. Отображенные соединения уже выделены в диалоговом окне.

3. Установите флажок в столбце **Изменить маршрутизацию** у тех соединений, которые вы хотите заново маршрутизировать в выбранном сегменте маршрутизации цели.
4. Щелкните по кнопке ++"OK"++.

!!! info "Для сведения:"

    Выбранные соединения будут маршрутизированы заново.

!!! tip "Совет:"

    Если вы хотите снова учесть фильтры соединения при маршрутизации, вы можете вручную удалить значение свойства **Топология: Трасса маршрутизации - по умолчанию** для соответствующих соединений. Или перетащите соединение в сторону от записанного здесь сегмента маршрутизации, после чего сегмент маршрутизации будет удален из свойства.
