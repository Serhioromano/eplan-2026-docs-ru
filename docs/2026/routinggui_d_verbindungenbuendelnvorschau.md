# Диалоговое окно Объединить соединения: Предварительный просмотр результата

## Вызов диалогового окна

Вкладка **Обработать** > группа команд **Маршрутизируемые соединения** > **Объединить**. Вы установили в диалоговом окне **Объединить маршрутизируемые соединения** флажок **Предварительный просмотр результата**. Щелкните по кнопке ++"OK"++.

В этом диалоговом окне приводятся все соединения, которые будут изменены. Новые номера объединений проводов можно подтвердить, нажав клавишу ++"OK"++, или изменить вручную.

Обзор основных элементов диалогового окна:

Таблица содержит следующие столбцы:

* Строка: Показывает непрерывный номер строки.
* Источник: Источник соединения.
* Цель: Цель соединения.
* Объединенные провода: Номера объединенных проводов, которые перед автоматическим объединением были в соединении.
* Создать: новый номер объединения проводов соединения, присвоенный при автоматическом объединении. Номер здесь можно изменить вручную, чтобы присвоить соединение другому объединению проводов.
