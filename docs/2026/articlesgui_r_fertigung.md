# Вкладка Изготовление

## Вызов диалогового окна

Вкладка **Основные данные** > группа команд **Изделия** > **Управление**. В дереве или списке выделено одно изделие. Выберите вкладку **Изготовление**.

На этой вкладке можно присвоить изделию одну или несколько схем сверления для изготовления. Эти данные можно задать для каждого варианта изделия по отдельности.

!!! note "Замечание:"

* Обращайте внимание на то, чтобы схема сверления не была изделием, а только служила для изделия дополнительным источником информации относительно конструкции.
* Устройства с различными вариантами монтажа для каждого варианта должны иметь заданную подходящую схему сверления. При [размещении](cabinetgui_h_geraetplatzieren.md) такого изделия на экране отображается диалоговое окно, в котором вы можете выбрать используемую схему сверления.

Обзор основных элементов диалогового окна:

### Имя (схема сверления)

Нажмите для строки на этот столбец, а затем на кнопку ++"..."++. Выберите в диалоговом окне **Выбор схемы сверления** любую схему сверления, которая должна быть присвоена изделию. Любому варианту изделия можно присваивать любое количество схем сверления.

### Смещение в направлении X (схема сверления) / Смещение в направлении Y (схема сверления)

Задайте в этих столбцах для соответствующей схемы сверления смещение по осям X и Y. Таким образом, можно использовать идентичные схемы сверления для изделий разной величины.

### Всплывающее меню

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).

Дополнительно здесь представлены следующие пункты всплывающего меню, специфические для данного диалогового окна:

Пункт меню |  Значение
---|---
Удалить содержимое |  Удаляет содержимое текущих выделенных ячеек.
Перейти к |  Доступно только для столбца **Имя (схема сверления)**. Переход к схеме сверления, введенной в текущей выделенной строке.
