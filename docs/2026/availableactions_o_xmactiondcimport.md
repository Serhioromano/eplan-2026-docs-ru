# Операция: XMActionDCImport

**Параметр** |  **Описание**
---|---
ProjectLink |  Имя проекта с полным путем к файлу.
DataConfigurationFile |  Путь к файлу конфигурации данных ( `*.edc`).
ProgressTitle |  Задает название индикатора выполнения (дополнительно).

!!! note "Замечание:"

    Это действие позволяет изменять свойства функций, страниц и / или соединений путем импорта. Файл конфигурации данных `*.edc` можно сгенерировать, например, при помощи **Файл** > **Экспортировать** > группа команд **Данные проекта** > **Данные проекта** > группа команд **Внешняя обработка** > **Свойства**.

!!! example "Пример:"

    XMActionDCImport
/ProjectLink:C:\Projects\EPLAN\test.elk
/DataConfigurationFile:C:\EPLAN\DataCfgFile.edc
