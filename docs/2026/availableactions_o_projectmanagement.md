# Операция: projectmanagement

**Параметр** |  **Описание**
---|---
TYPE |  Вид выполняемой задачи:
READPROJECTINFO: Загрузить информацию о проекте из файла XML в проект.
PUBLISHSMARTPRODUCTION: Публикует проект для Eplan Smart Production.
CREATESNAPSHOTCOPY: Генерирует моментальную копию проекта.
EXPORTPROPERTYPLACEMENTSSCHEMAS: Экспортирует порядок свойств проекта.
IMPORTPROPERTYPLACEMENTSSCHEMAS: Импортирует порядок свойств в проект. REORGANIZE: Реорганизует проект.
CORRECTPROJECTITEMS: Корректирует проект.
LOADDIRECTORY: Сканирует каталог на наличие проектов для их считывания в управлении проектами. Этот тип может использоваться сам по себе или вместе с параметрами PROJECTSDIRECTORY и SCANSUBDIRECTORIES.
PROJECTNAME |  Имя проекта с полным путем файла (является опцией).
Если не задано, то выбранный проект используется, когда операция вызывается через интерфейс пользователя (например, через сценарий или ленту). При вызове из командной строки Windows следует определить PROJECTNAME или сначала следует использовать `ProjectAction`. В противном случае отобразится системное сообщение.
FILENAME |  Полный путь файла и имя импортируемого XML-файла или полный путь файла для публикации проекта для Eplan Smart Production, или полный путь файла для целевого проекта при создании моментальной копии проекта.
SCHEME |  Имя схемы. Действительно, только если параметр TYPE имеет следующие значения:
CREATESNAPSHOTCOPY
CORRECTPROJECTITEMS
OVERWRITE |  Если импортированная схема уже существует для размещений свойств, этот параметр указывает на то, должна ли она перезаписываться. Возможные значения: 0: Нет (значение по умолчанию); 1: Да.
Действительно, только если параметр TYPE имеет следующее значение: IMPORTPROPERTYPLACEMENTSSCHEMAS.
EXTENDEDMODE |  Задает "расширенный режим" для реорганизации проектов. Возможные значения: 0: Нет (значение по умолчанию); 1: Да.
Действительно, только если параметр TYPE имеет следующее значение: REORGANIZE.
PROJECTSDIRECTORY |  Определяет путь файла каталога, который сканируется на наличие проектов. Если этот параметр равен нулю или пуст, по умолчанию сканируется обычный каталог проекта.
SCANSUBDIRECTORIES |  Определяет, будут ли подкаталоги сканироваться на наличие проектов. Возможные значения: 0: Нет; 1: Да (значение по умолчанию).

!!! example "Пример:"

    Загрузить в проект информацию о проекте:projectmanagement
/TYPE:READPROJECTINFO
/PROJECTNAME:"C:\Projects\EPLAN projects\EPLAN_Sample_Project.elk"
/FILENAME:C:\Files\ProjectInfo.xmlРеорганизовать проект:projectmanagement
/TYPE:REORGANIZE
/PROJECTNAME:"C:\Projects\EPLAN projects\EPLAN_Sample_Project.elk"
/EXTENDEDMODE:"1"
