# Диалоговое окно Настройки: 3D

## Вызов диалогового окна:

**Файл** > **Настройки** > **Пользователь** > **Графическая обработка** > **3D**

В этом диалоговом окне задаются персональные настройки пользователя для графической обработки в трехмерном виде.

Обзор основных элементов диалогового окна:

Групповое поле "Цветовые настройки"

Все цветовые настройки задаются в диалоговом окне [Выбор цвета](mf_d_farbauswahl.md), которое открывается с помощью кнопки ++"..."++. Выберите требуемый цвет.

### Фон оттенения 1/Фон оттенения 2:

Здесь задаются цвета фона для оттенения в 3-мерном виде.

### Отображение конфликтов:

Здесь задается цвет для представления конфликтов между компонентами, возникающих при размещении и изменении в 3-мерном виде.

### Активная монтажная поверхность:

Здесь задаются цвета фона для активной монтажной поверхности в 3-мерном виде.

### Активный медный жгут:

Здесь задаются цвета фона для активного медного жгута в 3-мерном виде.

* * *

Групповое поле Стандартные размеры сетки

В полях **Размер сетки A** - **Размер сетки E** в качестве стандартных значений можно указать пять разных размеров сетки. В открытом пространстве листа выберите размеры сетки с помощью раскрывающейся кнопки ![](images/all_gridactive_as.png){: .ui-icon } ( **Сетка**) в строке состояния.

* * *

Групповое поле 'Применить упрощенное представление к'

Здесь задается, какие функциональные элементы в пространстве листа при применении функции **Упрощенное представление** отображаются с уменьшенной детализацией графики:

* Клеммники (определение блока): Если этот флажок установлен (стандартная настройка), то клеммники представляются в виде упрощенного блока.
* 3D-макросы: Если этот флажок установлен (стандартная настройка), то графические макросы, шины и кабельные каналы упрощаются до прямоугольного параллелепипеда.

Заданное здесь представление активируется для открытого пространства листа с помощью кнопки **Упрощенное представление** (вкладка **Вид** > группа команд **Пространство листа** > **Упрощенное представление**). Или выберите в навигаторе пространства листа пункт всплывающего меню **Упрощенное представление**.

* * *

Групповое поле Средняя кнопка мыши

Здесь вы указываете, хотите ли вы использовать среднюю кнопку мыши, чтобы повернуть или переместить трехмерную модель в пространстве листа.

* Повернуть и подвинуть с помощью [Shift]: если выбран этот параметр, то при нажатии на среднюю кнопку мыши во время перемещения мышью будет изменяться угол зрения трехмерной модели в пространстве листа. Представление в пространстве листа последует за указателем мыши и будет повернуто в соответствующем направлении. Эта функция соответствует команде **Повернуть угол зрения** ![](images/statusbar_viewpoint_as.png){: .ui-icon } в строке состояния графического редактора. Если при повороте дополнительно нажать и удерживать нажатой клавишу ++"Shift"++, то поворот будет прерван и трехмерная модель в пространстве листа будет перемещаться в направлении движения мыши.
* Перемещение и вращение с помощью клавиши ++Shift++: если выбрать эту опцию (настройка по умолчанию) и удерживании клавишу ++"Shift"++ во время перемещения, перемещение прерывается, а трехмерная модель в пространстве листа поворачивается в направлении движения мыши.
