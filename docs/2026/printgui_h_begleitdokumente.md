# Печать присоединенных документов

В Eplan присоединенные документы могут быть распечатаны по отдельности. Присоединенными называются внешние документы, вставленные на страницы схемы соединений при помощи гиперссылок или внесенные в используемые изделия. Чтобы присоединенные документы могли быть распечатаны, файлы должны находиться на локальном или на сетевом диске, к которому у вас есть доступ.

Условия:

* Вы выделили проект или страницы в навигаторе страниц.
* Вы вставили внешние документы при помощи гиперссылок или внесли в изделие.

1. Выберите следующие команды: **Файл** > **Печать**.
2. Выберите в виде Backstage **Печать** в групповом поле **Конфигурация печати** опцию **Только присоединенные документы** или **Проект / страница и присоединенные документы**.
3. Нажмите на ++"Выбрать присоединенные документы"++.

!!! info "Для сведения:"

    В диалоговом окне **Выбрать присоединенные документы** перечислены все присоединенные документы, связанные с проектом. По умолчанию в столбце **Печать** для вывода на печать выделены все документы.

4. В диалоговом окне **Выбрать присоединенные документы** снимите флажок в столбце **Печать** для тех документов, которые не нужно печатать.
5. Щелкните по кнопке ++"OK"++.
6. Выберите в виде Backstage **Печать** в групповом поле **Принтер** нужный принтер из раскрывающегося списка.
7. В групповом поле **Экземпляры** в поле **Число** задайте количество экземпляров, которое необходимо распечатать.
8. Нажмите на ![](images/btn_print_as.png){: .ui-icon } (печать).

!!! info "Для сведения:"

    Процесс печати запущен.
