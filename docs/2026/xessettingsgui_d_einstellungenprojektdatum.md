# Диалоговое окно "Настройки: дата / время / числа"

## Вызов диалогового окна

Вы открыли проект. **Файл** > **Настройки** > **Проекты** > "Имя проекта" > **Отображение** > **Дата / время / числа**.

Наряду с возможностью копировать формат для даты и времени из настроек операционной системы в данном диалоговом окне есть возможность настраивать формат, специфический для проекта. Например, это имеет смысл в том случае, если работа над проектом ведется в рамках страны; тогда в этом случае как раз можно использовать единый формат данных.

Обзор основных элементов диалогового окна:

### Формат операционной системы

Выберите этот параметр, если формат для даты и времени следует брать из настроек операционной системы. В расположенном ниже поле **Предв. просмотр** представлен предварительный просмотр формата.

### Специфический для проекта формат

Выберите этот параметр, если формат для даты и времени должен отличаться от формата операционной системы. В расположенных ниже полях укажите подробности, причем в поле **Предв. просмотр** представлен обновленный предварительный просмотр для формата. Доступны следующие возможности настроек:

* Формат даты: выберите нужный формат даты из раскрывающегося списка, например "ДДММГГГГ" для отображения "05.01.2007" или запись "ДМГГ" для отображения "5.1.07".
* Первый разделитель даты / Второй разделитель даты: выберите из этих раскрывающихся списков один из возможных разделителей ".", "/" или "-".
* Формат времени: выберите нужный формат времени из раскрывающегося списка, например "ЧЧММСС" для отображения "07:05:51" или запись "ЧММ" для отображения "7:05". При этом малое "h" задает время в 12-часовом формате, т.е. "1:05" для "13:05" и "1:05".
* Разделитель времени: выберите из этих раскрывающихся списков один из возможных разделителей "<пусто>" или ":".
* Символ для первой половины дня / Символ для второй половины дня: выберите из этих раскрывающихся списков один из возможных символов для первой половины дня и второй половины дня, например "AM" и "PM".

### В значениях выводить единицы измерения через пробел

Установите этот флажок, если хотите, чтобы перед числами, которые должны выводиться с единицей измерения, например "кг", стоял пробел. Если флажок снят, между числом и единицей измерения пробел не вставляется.
