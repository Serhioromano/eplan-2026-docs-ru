# Диалоговое окно Выбор изделия

## Вызов диалогового окна

Вы открыли проект.

* Вы выделили главную функцию в графическом редакторе или навигаторе. Пункт всплывающего меню **Свойства**. Выберите вкладку **Изделия** и щелкните в поле **Номер изделия** по кнопке ++"..."++.
* Вкладка **Устройства** > группа команд **Устройства** > **Навигатор.** Выделите одну запись. Всплывающее меню **Новое устройство**.
* Вкладка **Устройства** > группа команд **Устройства** > **Спецификация**. Выделите одну запись. Пункт всплывающего меню **Добавить изделие** или **Заменить изделие**.
* Вкладка **Устройства** > группа команд **Устройства** > раскрывающаяся кнопка **Навигатор** > **Список устройств**. Выделите одну запись. Пункт всплывающего меню **Добавить изделие**.

В этом диалоговом окне выбирается изделие на основе его экономических данных. При многократном выборе изделий возможно одновременное присвоение нескольких изделий. При этом функции / условному обозначению присваиваются данные первого изделия, содержащегося в выборе.

Обзор основных элементов диалогового окна:

### Панель инструментов

Вы можете настроить отображение данных с помощью следующих кнопок:

Кнопка |  Значение
---|---
![](images/all_treeview_as.png){: .ui-icon } (представление в виде дерева) |  Отображает данные в виде иерархической структуры дерева. В качестве последнего уровня иерархии для изделий отображаются индивидуальные номера изделий или (при наличии) обозначение вариантов изделий.
![](images/all_listview_as.png){: .ui-icon } (представление в виде списка) |  Отображает изделия, расположенные друг под другом, в виде списка.
![](images/all_combinationview_as.png){: .ui-icon } (Комбинация) |  Отображает изделия в комбинированном представлении дерева и списка. При этом в списке отображаются изделия выбранного в дереве узла.
![](images/articlesgui_filterview_as.png){: .ui-icon } |  Переключает в оба направления между последней выбранной схемой фильтра и нефильтрованным видом.

Вы можете настроить, какие узлы / уровни иерархии будут отображаться для определенного типа записи данных в дереве с помощью ++"Дополнительно"++ > **Настройки** в Конфигурации дерева.

Отображать Eplan Data Portal в выборе изделия

Если вы зарегистрировались в Eplan Cloud и активировали настройку **Разрешено изменение при выборе**, то в древовидной структуре и в комбинированном представлении над главным узлом для изделий будет отображаться пиктограмма ![](images/userinterface_edpIcon_as.png){: .ui-icon } "Data Portal".

Если щелкнуть по пиктограмме, в правой части выбора изделий в окне браузера в виде вкладки отобразится Eplan Data Portal. Здесь можно выбрать и скачать основные данные изделий.

Эта пиктограмма предназначена только для отображения Eplan Data Portal; ее нельзя настроить через пункт всплывающего меню **Конфигурировать представление** или через конфигурацию дерева.

Если установлена предварительная фильтрация изделий, то поиск в Eplan Data Portal невозможен и пиктограмма ![](images/userinterface_edpIcon_as.png){: .ui-icon } "Data Portal" не отображается.

Дополнительную информацию по Eplan Data Portal см. [здесь](https://www.eplan.help/ru-ru/Infoportal/Content/EDP_Cloud/Content/htm/DataPortalCS_k_home.htm).

### Фильтр

В этом раскрывающемся списке отображаются все доступные фильтры. Выбранный фильтр активируется автоматически. Запись "- Не активировано -" отключает фильтр и приводит к тому, что данные отображаются в неотфильтрованном виде. С помощью кнопки ++"..."++ откройте диалоговое окно [Фильтр](modaldialogsdb_d_filternnach.md). Здесь можно создать, обработать, удалить, скопировать, экспортировать, импортировать фильтр и управлять им.

Во всплывающем меню раскрывающегося списка **Фильтр** содержатся следующие записи:

* Выключить: Этот пункт меню доступен, если фильтр установлен: Сбрасывает настройку фильтра до записи "- Не активировано -".
* Активировать <Имя фильтра>: Этот пункт меню доступен, если для настройки фильтра установлено значение "- Не активировано -": Повторно активирует последний активный фильтр.

Таким образом можно быстро переключаться между неотфильтрованным и отфильтрованным в соответствии с требованиями пользователя представлениями.

С помощью критериев фильтра **Шаблон функции в изделии** можно фильтровать изделия в соответствии с определениями функций и другими данными шаблонов функций (например, техническими параметрами). В результате применения такого фильтра отображаются только те изделия, у которых значения свойств или определения функций сохраненных в них шаблонов функций соответствуют заданным критериям.

### Пoиск

Введите в это поле текст для поиска и подтвердите клавишей ++"Enter"++.

По умолчанию при поиске учитываются только самые важные свойства (например, **Номер изделия**, **Номер типа**, **Производитель** и т. д.). Если поиск должен осуществляться с использованием других свойств, используйте кнопку ++"..."++ для перехода к диалоговому окну **Конфигурировать поиск**. Здесь с помощью схемы вы можете указать, по каким свойствам должен осуществляться поиск и в какой последовательности.

В остальном поиск ведет себя точно так же, как и [поиск](insertergui_k_suchen.md) в центре вставки: вы можете использовать те же операторы и символы-заполнители.

Если поиск не дал результатов, то он будет продолжен – если это возможно – в Eplan Data Portal. Если изделие было там найдено, то оно будет отображаться в Eplan Data Portal. Для этого, при необходимости, открывается Eplan Data Portal.
При поиске в Eplan Data Portal не учитываются операторы, символы-заполнители и свойства, указанные в конфигурации поиска.

!!! note "Замечание:"

    Если в диалоговом окне **Настройки: Выбор изделия** (например, через **Файл** > **Настройки** > **Пользователь** > **Управление** > **Выбор изделия**) установлен флажок **Разрешено изменение при выборе**, при выборе можно изменить доступные изделия в базе данных изделий и создать новые изделия.
    Если флажок не установлен, то изделия можно только выбирать и невозможно создавать или обрабатывать.

### Всплывающее меню

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).

Дополнительно здесь представлены следующие пункты всплывающего меню, специфические для данного диалогового окна:

Пункт меню |  Значение
---|---
Создать |  Создает новое изделие / запись данных под выделенным изделием / узлом.
Создать вариант |  Доступно только для изделий. Открывает диалоговое окно **Создать вариант** для создания варианта изделия.
Вставить данные |  Открывает диалоговое окно **Вставить данные**, с помощью которого можно задать, какие данные скопированного изделия будут переданы выбранным изделиям / вариантам.
Список с предварительным выбором (только дерево) |  Уменьшает число отображаемых элементов, чтобы ускорить ориентирование в представлении в виде списка. Если этот параметр включен, представление в виде списка вызывается с автоматическим фильтром (выбор), причем этот фильтр содержит только что выбранные элементы.
Выбрать в дереве (только список) |  Показывает выделенный объект в представлении в виде дерева.
Конфигурировать представление |  Открывает диалоговое окно **Конфигурировать представление**, в котором можно задать, какие свойства должны отображаться в представлении в виде списка и в представлении структуры дерева.
Экспортировать |  Открывает для выделенных записей данных диалоговое окно **"Экспортировать записи данных"**, в котором следует указать имя и тип файла экспорта. Если текущее выделение содержит узлы в представлении в виде дерева, будут учтены все находящиеся под ними записи данных.
Присвоить шаблоны функций |  Позволяет автоматически создавать отсутствующие шаблоны функций из записанных макросов для выделенных записей данных. Обратите внимание, что для данной функциональности команда **Отменить** недоступна! Поэтому перед крупными изменениями желательно сохранить данные изделия.

### Обзор

На этой вкладке отображаются основные свойства, а также предварительный просмотр изделия при его наличии. Здесь невозможно обрабатывать свойства. На других вкладках можно получить более подробную информацию о свойствах выбранного изделия.

### [Дополнительно]

В меню ++"Дополнительно"++ имеется следующий пункт:

Пункт меню |  Значение
---|---
Настройки |  Открывает диалоговое окно **Настройки: Изделие (пользователь)**, в котором можно, например, конфигурировать представление структуры дерева без прерывания производственного процесса.
