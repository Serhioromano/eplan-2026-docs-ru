# Изменить пароль диалогового окна

## Вызов диалогового окна:

* **Файл** > **Дополнительно** > группа команд **Расширения** > **Управление правами** > **Управление правами** > папка **Пользователь**. Вы выделили в левом поле диалогового окна **Управление правами: Пользователь** папку **Пользователь**, а также имя пользователя в правой части списка. Щелкните по ++"Изменить пароль"++.
* Вы установили рабочий режим "Регистрация". Вы запускаете Eplan. В диалоговом окне **Войти в Eplan** щелкните по кнопке ++"Изменить пароль"++.

В этом диалоговом окне вы можете изменить пароль, с которым входите в Eplan. При вызове диалогового окна из управления правами администраторы могут присвоить пользователю новый пароль, если он забыл свой.

Обзор основных элементов диалогового окна:

### Имя:

В этом поле выводится имя пользователя.

### Старый пароль:

Введите здесь свой предыдущий пароль. Для защиты введенных данных пароль отображается не открытым текстом, а в виде символов *.

Если диалоговое окно было вызвано из управления правами, данное поле недоступно и не может быть обработано.

### Новый пароль:

Введите здесь новый пароль. Для защиты введенных данных пароль отображается не открытым текстом, а в виде символов *.

### Подтвердить новый пароль:

Во избежание опечаток при вводе новый пароль необходимо ввести в поле повторно. Eplan примет новый пароль только после этого.
