# Выравнивание элементов горизонтально/вертикально

С помощью команд **Выровнять по горизонтали** и **Выровнять по вертикали** можно разместить несколько выделенных элементов на горизонтальной или вертикальной линии. Это выполняется только с элементами с одним пунктом ввода. Линия получается из центра двух расположенных далее всего друг от друга элементов.

Условие:

Вы открыли проект. Вы открыли редактор, например графический редактор, редактор рамок и т. д.

1. Выберите соответствующие элементы.
2. Выберите следующие команды: Вкладка **Обработать** > группа команд **Упорядочить** > **Выровнять по горизонтали** или раскрывающаяся кнопка **Выровнять по горизонтали** > **Выровнять по вертикали**.

!!! info "Для сведения:"

    Eplan определяет средние точки двух наиболее удаленных друг от друга элементов и выравнивает все элементы по этой линии.

!!! note "Замечание:"

    Обратите внимание, что после выравнивания необходимо выполнить команду **Выровнять по сетке**, чтобы снова разместить точки вставки на сетке.
