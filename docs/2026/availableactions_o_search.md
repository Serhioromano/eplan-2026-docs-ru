# Операция: search

**Параметр** |  **Описание**
---|---
TYPE |  Описывает область поиска:
DEVICETAG: искать устройства
ALLPROPERTIES: искать во всех свойствах
TEXTS: искать текст
PAGEDATA: искать в данных страниц
PROJECTDATA: поиск в данных проектов
PROJECTNAME |  Имя проекта с полным путем файла (является опцией).
Если не задано, то выбранный проект используется, когда операция вызывается через интерфейс пользователя (например, через сценарий или ленту). При вызове из командной строки Windows следует определить PROJECTNAME или сначала следует использовать `ProjectAction`. В противном случае отобразится системное сообщение.
SEARCHITEM  |  Искомый текст.
CASESENSITIVE  |  Учитывать регистр (необязательно, 0 = нет, 1 = да).
Значение по умолчанию: последнее используемое значение, которое задано в данный момент в интерфейсе пользователя.
WHOLETEXT  |  Искать только полные тексты (необязательно, 0 = нет, 1 = да).
Значение по умолчанию: последнее используемое значение, которое задано в данный момент в интерфейсе пользователя.
LOGICPAGES  |  Искать логические страницы (необязательно, 0 = нет, 1 = да).
Значение по умолчанию: последнее используемое значение, которое задано в данный момент в интерфейсе пользователя.
GRAPHICPAGES  |  Искать графические страницы (необязательно, 0 = нет, 1 = да).
Значение по умолчанию: последнее используемое значение, которое задано в данный момент в интерфейсе пользователя.
EVALUATIONPAGES  |  Искать страницы отчетов (необязательно, 0 = нет, 1 = да).
Значение по умолчанию: последнее используемое значение, которое задано в данный момент в интерфейсе пользователя.
NOTPLACEDFUNCTIONS  |  Искать неразмещенные функции (необязательно, 0 = нет, 1 = да).
Значение по умолчанию: последнее используемое значение, которое задано в данный момент в интерфейсе пользователя.
FILTERSCHEME |  Схема фильтра для функций (необязательно). Если задан этот параметр, поиск будет осуществляться только по тем данным, которые соответствуют критериям указанной схемы фильтра для функций.
Значение по умолчанию: схема фильтра для функций не используется.

!!! note "Замечание:"

    Результат поиска появится в списке диалогового окна **Результаты поиска** только в том случае, если проект, для которого был выполнен поиск, открыт в Eplan.

!!! example "Пример:"

    Поиск текста:search
/TYPE:TEXTS
/PROJECTNAME:C:\Projects\EPLAN\EPLAN_Sample_Project.elk
/SEARCHITEM:Hallo
/CASESENSITIVE:1
/WHOLETEXT:0
/LOGICPAGES:1Поиск свойства страницы:search
/TYPE:PAGEDATA
/PROJECTNAME:C:\Projects\EPLAN\EPLAN_Sample_Project.elk
/SEARCHITEM:Drive
/CASESENSITIVE:0
/WHOLETEXT:0
/LOGICPAGES:1
/EVALUATIONPAGES:1
/NOTPLACEDFUNCTIONS:1
