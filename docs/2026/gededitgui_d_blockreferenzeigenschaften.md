# Диалоговое окно Изменить свойства ссылки блока

## Вызов диалогового окна

Вы открыли проект. В Графическом редакторе открыта страница проекта. Вы объединили несколько элементов в один блок и выделили этот блок. Пункт всплывающего меню **Свойства**.

В этом диалоговом окне отображаются свойства ссылки блока.

Обзор основных элементов диалогового окна:

### Число объектов

В этом поле отображается количество содержащихся в блоке объектов.

### Число ссылок

В этом поле отображается, сколько ссылок на этот блок размещено в проекте. (В данный момент доступна всего одна ссылка).

### Имя блока, на который идет ссылка

Здесь указывается имя блока. При экспорте DXF / DWG это имя сохраняется в экспортированном файле.

### [Разбить блок]

Разбивает блок на свои элементы. После этого отдельные объекты можно снова обрабатывать индивидуально.
