# База данных изделий: Импорт данных изделий по стандарту ECLASS

ECLASS — это стандартизированная межотраслевая система классификации для товарных групп и товарных признаков, а также услуг, которая имеет целью облегчить электронную торговлю классифицированными изделиями.

При импорте данных изделия в базу данных изделия по стандарту ECLASS используется XML-формат "BMEcat". В поддерживаемой версии BMEcat 2005.1 среди прочего возможен импорт многоязычных данных.

Чтобы иметь возможность импортировать данные по классификации ECLASS, в диалоговом окне **Импортировать записи данных** в поле **Тип файла** есть записи для разных поддерживаемых версий ECLASS.

Импорт осуществляется с помощью схемы, которую вы выбираете в выведенном диалоговом окне. В этой схеме происходит конфигурация присвоения групп и признаков ECLASS группам продуктов и свойствам изделий базы данных изделий Eplan.
