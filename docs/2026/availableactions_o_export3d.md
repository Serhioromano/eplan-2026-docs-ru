# Операция: export3D

**Параметр** |  **Описание**
---|---
TYPE  |  Вид задачи, которую должна выполнить операция:
STEP: Экспортировать пространство листа в формате STEP. JT: Экспортировать пространство листа в формате JT.
PROJECTNAME  |  Имя проекта с полным путем файла (является опцией).
Если не задано, то выбранный проект используется, когда операция вызывается через интерфейс пользователя (например, через сценарий или ленту). При вызове из командной строки Windows следует определить PROJECTNAME, или сначала следует использовать `ProjectAction`. В противном случае отобразится системное сообщение.
INSTALLATIONSPACENAME  |  Имя экспортируемого пространства листа.
INSTALLATIONSPACENAMEn  |  Имена экспортируемых пространств листа (является опцией). При этом `n` — это номер, например /INSTALLATIONSPACENAME1:LS1 /INSTALLATIONSPACENAME1:LS4 /INSTALLATIONSPACENAME1:LS7, и т. д.
STRUCTURE  |  Структурный идентификатор экспортируемого пространства листа (является опцией).
STRUCTUREn  |  Структурный идентификатор экспортируемых пространств листа (является опцией). При этом `n` — это номер, например /INSTALLATIONSPACENAME1:LS1 /STRUCTURE1:=EB3+ET1 /INSTALLATIONSPACENAME2:LS2 /STRUCTURE2:=EB3+ET2, и т. д.
DESTINATIONPATH  |  Целевой каталог. Если этого каталога еще нет, то он создается.
EXPORTSCHEME  |  Схема для экспорта STEP пространств листа (является опцией). Если данный параметр отсутствует или пуст (""), то используется последняя использованная схема экспорта STEP.
SEPARATEFILES  |  Если значение равно 1, несколько пространств листа экспортируются в отдельные файлы. Если значение равно 0, генерируются отдельные файлы, имена которых генерируются на основе свойства **Имя пространства листа**. Этот параметр оказывает влияние, только когда параметр TYPE имеет следующее значение: STEP.
FILENAME |  Имя файла (является опцией). Этот параметр оказывает влияние, только когда параметр TYPE имеет следующее значение: JT.

!!! note "Замечание:"

    Если указанное имя пространства листа в проекте неоднозначно, а параметр STRUCTURE не задан, выводятся все пространства листа с одинаковым именем.

!!! example "Пример:"

    Экспорт двух пространств листа BR1 и BR2 в формате STEP:export3d
/TYPE:STEP
/PROJECTNAME:C:\Projects\EPLAN\EPLAN_Sample_Project.elk
/INSTALLATIONSPACENAME1:BR1
/INSTALLATIONSPACENAME2:BR2
/DESTINATIONPATH:C:\temp\step_export
