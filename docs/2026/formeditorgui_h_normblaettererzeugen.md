# Создать рамку

При создании рамки открывается диалоговое окно **Свойства рамки — <Имя рамки>**, в котором устанавливаются важнейшие свойства новой рамки. (Это диалоговое окно может быть вызвано также в последствии для открытой рамки, это позволит Вам в любое время дорабатывать свойства.)

Условие:

Вы открыли проект.

1. Выберите следующие команды: Вкладка **Основные данные** > группа команд **Рамки / формы** > раскрывающаяся кнопка **Рамка** > **Создать**.
2. В диалоговом окне **Создать рамку** выберите дисковод и каталог, в котором должна быть сохранена новая рамка.
3. Введите в поле **Имя файла** информативное имя для рамки.
4. Нажмите в левой области навигации на пиктограмму Eplan и расположенный под ней каталог, если хотите вернуться к настройкам дисковода и каталога по умолчанию. (Каталогом по умолчанию является либо предварительная программная настройка `<Дисковод программы>:\<Каталог программы>\< Рамки\<Идентификатор фирмы>`, либо каталог, заданный в настройках рамок: **Файл** > **Настройки** > **Пользователь** > **Управление** > **Каталоги**).
5. Щелкните по кнопке ++"Сохранить"++.
6. В диалоговом окне **Свойства рамки — <Имя рамки>** из раскрывающегося списка **Категория** выберите свойства, которые должны быть выведены в списке ниже.
7. Определите значения для свойств, либо введя или перезаписав запись или же выбрав значение по умолчанию из раскрывающегося списка.
8. Щелкните по кнопке ++"OK"++.

!!! info "Для сведения:"

    Новая рамка копируется согласно вашим данным и выводится в редакторе рамок.

!!! info "Для сведения:"

    Нулевая точка рамки обозначается красным кругом, как в редакторе контура и редакторе символов. Позиция нулевой точки учитывается при масштабировании, но ее нельзя перемещать вручную.
