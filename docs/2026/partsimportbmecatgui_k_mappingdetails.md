# База данных изделий: Присвоение признаков ECLASS свойствам изделия Eplan

Характеристики стандарта ECLASS могут иметь кардинальность, например число выводов устройства функционального элемента. Таким образом определяется, как часто повторно встречается блок признаков ECLASS. На момент определения присвоения данных ECLASS известно только то, что блок может встречаться многократно, но неизвестно, насколько часто он встречается непосредственно при импорте. Результаты могут отличаться для каждого импортированного объекта.

В некоторых случаях необходимо, чтобы характеристики стандарта ECLASS с кардинальностью можно было присвоить нескольким свойствам изделия Eplan. Это реализуется следующим образом:

* Для каждого признака ECLASS, который может многократно встречаться в связи с кардинальностью, пользователь также может выбрать несколько свойств Eplan.
* При импорте эти характеристики стандарта ECLASS поочередно присваиваются этим свойствам Eplan.
* Вы также можете выбрать определенные пользователем свойства и индексированные свойства Eplan, например атрибуты и произвольные свойства.
* При этом пользователь точно выбирает все используемые индексы, например "Атрибуты с 10 по 20".
* Для присвоения нескольких свойств предусмотрено диалоговое окно со списком для доступных и выбранных свойств, в котором с помощью кнопок можно изменять последовательность выбранных свойств.
* Если импортируемый объект содержит больше характеристик стандарта ECLASS, чем было определено при присвоении кардинальности, лишние характеристики стандарта ECLASS не учитываются.
