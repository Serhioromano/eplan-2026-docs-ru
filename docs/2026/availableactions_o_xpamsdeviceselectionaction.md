# Операция: XPamsDeviceSelectionAction

**Параметр** |  **Описание**
---|---
PROJECTNAME |  Имя проекта с полным путем файла (является опцией). Если заданный проект не открыт, при операции он автоматически открывается и снова закрывается.
Если не задано, то выбранный проект используется, когда операция вызывается через интерфейс пользователя (например, через сценарий или ленту). При вызове из командной строки Windows следует определить PROJECTNAME или сначала следует использовать `ProjectAction`. В противном случае отобразится системное сообщение.
MODE |  Дополнительно: Режим. Поддерживаемые режимы:

* selectDevice (значение по умолчанию): Выбирает новое устройство для имеющихся объектов. При этом все данные устройств, включая данные ссылок изделий, удаляются и заново предоставляются в соответствии с выбором устройства.
* updateDevice: Обновляет только данные устройства изделий имеющихся объектов. Номера изделий и данные ссылок изделий сохраняются. Эта функция соответствует пункту всплывающего меню **Обновить данные устройства** в навигаторе спецификаций.

KeepSwappedConnPointInformation |  Если при обновлении данных устройства обозначения выводов устройства для функций или цвета соединения для кабельных соединений заменяются по сравнению с последовательностью в шаблонах функций изделия, то с помощью этого параметра можно указать, будут ли сохраняться замененные данные (необязательно, 0 = нет, 1 = да). Значение по умолчанию: 0
Это действует только в том случае, если все обозначения выводов устройства на функции или все цвета соединения на кабельном соединении совпадают с теми, которые указаны в шаблонах функций изделия.

!!! example "Пример:"

    XPamsDeviceSelectionAction
/ProjectName:"C:\MyFolder\MyProject.elk"
