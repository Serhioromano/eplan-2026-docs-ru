# Операция: selectionset

**Параметр** |  **Описание**
---|---
TYPE |  Вид выполняемой задачи:
PROJECT: Возвращает текущий проект PROJECTS: Возвращает выбранные проекты
PAGES: Возвращает выбранные страницы LAYOUTSPACES: Возвращает выбранные пространства листа

!!! note "Замечание:"

    Результат выбора возвращается в вызываемом контексте:

* Если выбран проект:
    Имя параметра в вызываемом контексте = PROJECT. Значение из вызываемого контекста = имя проекта с полным путем файла и расширением имени файла (например, `C:\MyProjects\EPLAN_Sample_Project.elk`).
* Если выбраны проекты:
    Имя параметра в вызываемом контексте = PROJECTS. Значение из вызываемого контекста = имя проекта с полным путем файла и расширением имени файла (например, `C:\MyProjects\EPLAN_Sample_Project.elk;C:\Projects\EPLAN\EPLAN_Sample_Project2.elk`).
* Если выбраны страницы:
    Имя параметра в вызываемом контексте = PAGES. Значение из вызываемого контекста = все имена страниц разделены точкой с запятой (например, `Page1;Page2;Page3`).
* Если выбраны пространства листа:
    Имя параметра в вызываемом контексте = LAYOUTSPACES. Значение из вызываемого контекста = все пространства листа разделены точкой с запятой (например, `LayoutSpace1; LayoutSpace2; LayoutSpace3`).
