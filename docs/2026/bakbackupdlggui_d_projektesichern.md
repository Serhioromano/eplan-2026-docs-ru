# Диалоговое окно "Резервировать проекты" / диалоговое окно "Создать базовый проект"

## Вызов диалогового окна "Резервировать проекты":

* Вы открыли проект. Вы выделили проект в Навигаторе страниц. **Файл** > **Резервировать**.
* Вы настроили Управление проектами и выделили в дереве управления проектами, как минимум, один проект. Выберите пункт всплывающего меню **Резервировать**.

В этом диалоговом окне задается способ и место резервирования выбранных проектов.

## Вызов диалогового окна "Создать базовый проект":

* Вы открыли проект. Вы выделили проект в навигаторе страниц. **Файл** > **Дополнительно** > группа команд **Организовать** > **Проект** > группа команд **Резервировать** > **Создать базовый проект**.
* Вы настроили управление проектами и выделили проект в структуре дерева управления проектами. Выберите под кнопкой ++"Дополнительно"++ пункт всплывающего меню **Создать базовый проект**.

В этом диалоговом окне вы указываете, под каким именем и где выбранный проект будет сохранен в качестве базового проекта.

Обзор основных элементов диалогового окна:

### Выбранные проекты:

В этом списке отображаются выбранные для резервирования проекты. При создании базового проекта здесь отображается только выбранный проект.

### Описание:

В этом поле можно ввести информативный текст (напр., указание места хранения), который сохраняется вместе с проектом или базовым проектом и отображается в Eplan при резервировании и восстановлении.

### Метод:

В этом поле задается способ резервирования проекта. Настройки влияют на возможность дальнейшей обработки исходного проекта и на формат файлов резервирования.

* Дополнительно сохранить: доступно только при резервировании проектов. Проект резервируется на другой носитель данных. Могут быть выделены несколько проектов, которые будут резервированы последовательно. Выбрать одновременно несколько проектов можно в структуре управления проектами, представленного в виде дерева. Проект `*.elk` сохраняется в том же каталоге. Дополнительно в выбранном каталоге резервирования генерируется файл резервирования `*.zw1`.
* Выгрузить для внешней обработки: доступно только при резервировании проектов. Проект сохраняется на другой носитель данных, а на исходный проект устанавливается защита от записи. Все данные выгруженного проекта остаются на исходном жестком диске. Из проекта `*.elk` в том же каталоге получается проект `*.els`. Дополнительно в выбранном каталоге резервирования генерируется файл резервирования `*.zw1`.
* Архивировать: доступно только при резервировании проектов. Проект сохраняется на другой носитель данных, а исходный проект, за исключением информационного файла, с жесткого диска удаляется. Из проекта `*.elk` в том же каталоге получается проект `*.ela`. Дополнительно в выбранном каталоге резервирования генерируется файл резервирования `*.zw1`.
* Генерировать базовый проект: доступно только при создании базовых проектов. Проект `*.elk` сохраняется в том же каталоге. Дополнительно в выбранном каталоге для резервирования генерируется базовый проект `*.zw9`.

### Имя файла резервирования:

Здесь необходимо указать имя файла резервирования. По умолчанию используется имя проекта. Нажав ++"..."++, откройте диалоговое окно **Выбор файла резервирования** и перейдите к требуемому каталогу или создайте новый.
В зависимости от того, находится ли проект непосредственно в каталоге проекта или в каталоге за пределами каталога проекта, будет автоматически предложено имя проекта. Если проект находится в подкаталоге каталога проекта, то первым в раскрывающемся списке предлагается имя проекта, а вторым — путь файла ниже каталога проекта (разделенный на пункты) и имя проекта.
Если резервируются несколько проектов, то это поле недоступно, и в качестве имени файла резервирования используется соответствующее имя проекта.
Имя файла, включая путь файла, должно содержать не более 260 символов.

### Каталог для резервирования:

Укажите здесь место хранения. В качестве цели можно указать любой дисковод и подкаталог. Если в поле **Имя файла резервирования** выбран каталог, то этот каталог отображается здесь. Нажав ![](images/all_selectdirectory_as.png){: .ui-icon }, откройте диалоговое окно для выбора каталога и перейдите к требуемому каталогу или создайте новый.

С помощью пункта всплывающего меню **Вставить переменную пути** перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

### Автоматически скопировать файлы со ссылками:

Если этот флажок установлен, ссылки на внешние документы и графические файлы, которые не были сохранены, будут храниться в проекте или в базовом проекте. Соответствующие файлы копируются автоматически в подкаталоги `...\<Имя проекта>\DOC\\*.*` и `...\<Имя проекта>\Images\\*.*`. Каждый сохраненный файл хранится в отдельном подкаталоге, имя каталога которого вычисляется из имени исходного каталога. Файлы, сохраненные вручную, обозначаются буквой "M" перед именем каталога.

### [Связи]:

Откройте диалоговое окно **Скопировать файлы со ссылками в проект вручную**. Здесь вы можете вручную скопировать файлы со ссылками (внешние документы, графические файлы и т. д.) в текущий или создаваемый базовый проект.
