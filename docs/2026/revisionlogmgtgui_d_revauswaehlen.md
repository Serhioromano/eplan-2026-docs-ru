# Диалоговое окно Выбрать ревизию

## Вызов диалогового окна

Вы открыли проект. **Файл** > **Управление ревизиями** > группа команд **Изменения** > **Отслеживание изменений** > **Генерировать ревизию**. В диалоговом окне **Генерировать ревизию** нажмите рядом с полем **Имя ревизии** на ++"..."++.

В этом диалоговом выберите имеющееся имя ревизии.

Обзор основных элементов диалогового окна:

В **таблице** выводятся для выбора уже имеющиеся в проекте имена ревизий.

Выберите имя ревизии и закройте диалоговое окно нажатием на ++"OK"++. Имя ревизии вместе с соответствующим комментарием будет передано в диалоговое окно **Генерировать ревизию**, в котором вы сможете изменить эти данные.
