# Диалоговое окно Выбрать подклассы буквенных обозначений

## Вызов диалогового окна:

Вы открыли проект.

* Вы вставили символ в Графическом редакторе или генерировали новую функцию в Навигаторе. Выберите в диалоговом окне **Свойства** ++"..."++ вкладку **<Категория функции>**. Выберите в поле **Видимое ОУ** пункт всплывающего меню **Подклассы буквенных обозначений**.
* Выделите условное обозначение в графическом редакторе или функцию в навигаторе. Пункт всплывающего меню **Свойства**. Выберите вкладку **<Категория функции>**. Выберите в поле **Видимое ОУ** пункт всплывающего меню **Подклассы буквенных обозначений**.
* Вы выделили один объект планирования в графическом редакторе или навигаторе предварительного планирования. Пункт всплывающего меню **Свойства**. Выберите в диалоговом окне **Свойства** ++"..."++ вкладку **<Отображаемое имя объекта планирования>**. В поле **Маркировка продукции** выберите пункт всплывающего меню **Подклассы буквенных обозначений**.

В этом диалоговом окне выберите из списка выбора подклассы буквенных обозначений, которые используются для генерации нового ОУ. На объектах планирования используется подкласс, выбранный для генерации новой маркировки продукции. Подклассы буквенных обозначений сохраняются в настройках проекта (командный путь: **Файл** > **Настройки** > **Проекты** > "Имя проекта" > **Устройства** > **Нумерация (online)**).

Обзор основных элементов диалогового окна:

### Фильтр:

Введите в этом поле символьную строку. Курсор немедленно после ввода первого знака перемещается к записи в столбце **Подкласс**, которая начинается с этого знака, и выделяет ее. Если этот знак / этот ввод в столбце **Подкласс** не найден, тогда выполняется поиск в столбцах **Задача подкласса**, **Цель или задание объекта**, **Примеры продуктов** и **Комментарии**. При обнаружении искомого будет выделен соответствующий подкласс буквенных обозначений, в котором эта символьная строка встречается первый раз.

### Таблица:

Выделите в столбце **Подкласс** нужное обозначение подкласса буквенных обозначений и щелкните ++"OK"++. Строка символов затем копируется в поле **Видимое ОУ** диалогового окна свойств условных обозначений. При этом генерируется новое ОУ, и при необходимости имеющееся буквенное обозначение не сохраняется.

### Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).

### Скопировать задачу подкласса в функциональный текст:

Недоступно для объектов планирования! Если этот флажок установлен, текст из столбца **Задача подкласса** переносится в функциональный текст, если речь идет о главной функции. Уже имеющие функциональные тексты при этом переписываются. Многоязычные тексты переводятся на различные языки. Для вспомогательных функций текст не переносится.
