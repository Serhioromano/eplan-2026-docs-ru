# Диалоговое окно Присвоение VDMA 66413

## Вызов диалогового окна

Вкладка **Основные данные** > группа команд **Изделия** > **Управление**. Через меню ++"Дополнительно"++ > **Настройки** была открыта база данных изделий. ++"Дополнительно"++ > **Импортировать**. В поле **Тип файла** выберите запись "VDMA 66413" и нажмите на находящуюся рядом кнопку ++"..."++.

В этом диалоговом окне указывается для импорта VDMA в базе данных изделий, какое идентифицирующее свойство в XML-файле соответствуют определенным свойствам изделий в вашей базе данных изделий.

Доступны следующие элементы диалогового окна:

### СвойствоVDMA

Выберите из раскрывающегося списка нужное идентифицирующие свойство:

* Identifier: специфический для производителя, уникальный идентификатор для устройства
* PartNumber: специфический для производителя номер изделия и номер для заказа.

### Свойство изделия

Выберите из раскрывающегося списка свойство Eplan ( **Номер изделия**, **Номер ERP / PDM 1**, **Номер для заказа** и т. д.), соответствующее этому свойству VDMA. Если присвоение является уникальным, данные передаются вместе с параметрами, важными с точки зрения безопасности.

!!! note "Замечание:"

    Если при импорте данных изделия с типом файла "VDMA 66413" происходит присвоение к свойству Eplan **Номер изделия**, то при таком импорте можно также создать новые изделия. В качестве предварительного условия для этого импорта необходимо выбрать опцию **Обновить имеющиеся записи данных и добавить новые**. С другой стороны, если необходимо дополнить существующие изделия, выберите в диалоговом окне импорта опцию **Обновить только имеющиеся записи данных**.
