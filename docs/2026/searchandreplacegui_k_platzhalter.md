# Использование символов-заполнителей

Внутри искомых понятий можно использовать символы заполнители. Это позволяет искать значения, начинающиеся с определенной буквы, или отвечающие определенной образцовой последовательности символов.

Символ |  Использование |  Пример
---|---|---
* |  Этот символ соответствует любому количеству символов. Его можно использовать как первый или последний символ в последовательности. |  Поиск по та* найдет так, там и тара
? |  Этот символ соответствует только одному символу. |  Поиск по т?к найдет так, тюк и т2к

Символы-заполнители предназначены для использования с полями типа данных "Текст", но зачастую могут использоваться и с другими типами данных, например с типом данных "Дата", если вы не измените для этих типов данных настройки для стран.

### Специальный символ

Если вы выполняете поиск по звездочке (*), вопросительному знаку (?), символу номера (#), открывающей квадратной скобке ([) или дефису (-), искомый символ необходимо заключить в квадратные скобки.

!!! example "Пример:"

    Для выполнения поиска по вопросительному знаку введите в диалоговое окно **Поиск** значение `[?]`.

Если вы выполняете поиск по восклицательному знаку (!), или закрывающей квадратной скобке (]), их не нужно заключать в скобки.

Если вы выполняете поиск одновременно по дефису с другими символами, размещайте дефис либо перед всеми остальными символами, либо после них внутри скобок. (Если же после открывающей скобки следует восклицательный знак (!), разместите дефис после восклицательного знака.)

Невозможно выполнять поиск одновременно по открывающей и закрывающей квадратной скобке ([ ]), так как эта комбинация интерпретируется как пустая последовательность символов. Необходимо заключить эту комбинацию еще раз в квадратные скобки ([[ ]]).
