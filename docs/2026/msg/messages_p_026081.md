## P026081: Ошибка при размещении арматуры: \<x\>

### Причина

При маршрутизации шлангопровода не удалось разместить арматуру.

Возможно несколько причин. Причина, по которой появилось сообщение, выводится в заполнителе \<x\> сообщения.

### Решение

1. Установите местоположение источника маршрутизируемого соединения в пространстве листа с помощью функции Перейти к (графика) во всплывающем меню диалогового окна Управление сообщениями.
2. С помощью пункта всплывающего меню Перейти к (обратный эквивалент) перейдите к источнику на схеме соединений.
3. На схеме соединений определите подключенный к источнику шлангопровод.
4. Откройте диалоговое окно Свойства шлангопровода и переместите вкладку Изделие на передний план.
5. В зависимости от информации, отображенной в заполнителе, выполните одно из следующих корректировочных действий:

Заполнитель |  Решение
---|---
* Номер изделия не определен
* Не удалось определить данные изделия
|  Присвойте подходящее изделие или проверьте имеющиеся данные изделия на полноту и при необходимости дополните их.
* Вывод устройства не определен
* Не удалось определить вывод устройства
|  Для изделия не сохранена схема соединений или на схеме соединений не определены выводы устройства.
1. Выберите следующие команды: Вкладка Основные данные > группа команд Изделия > Управление, и в управлении изделиями выведите для этого изделия на передний план вкладку Свойства.
2. На уровне иерархии Монтажные данные нажмите в поле значений Схема соединений на кнопку ++"..."++, чтобы вызвать диалоговое окно Выбор схемы соединений.
3. Выберите подходящую схему соединений или для имеющейся схемы соединений выведите на передний план вкладку Выводы устройства, чтобы определить выводы устройства.
4. Щелкните по кнопке ++OK++.
5. Щелкните по кнопке ++Применить++.
6. Закройте управление изделиями и выполните синхронизацию данных изделий.

!!! note "Замечание:"

    При отсутствии подходящейсхемысоединений необходимо сначаласоздатьсхему соединений. Для этого в представлении в виде дерева Управления изделиямивыделите уровень иерархии Схема соединенийи выберите пункт всплывающего меню Создать.

* Невозможно сгенерировать арматуру
* Макрос не определен
|
1. Убедитесь, что для обоих арматур шлангопровода сохранен соответствующий правильный графический макрос.
2. Если это не так, вызовите управление изделиями: вкладка Основные данные > группа команд Изделия > Управление. На вкладке Свойства (уровень иерархии Монтажные данные) в поле Графический макрос выберите правильный графический макрос для соответствующего изделия.

!!! note "Замечание:"

    Если в каталоге макросов нет графического макроса для этого изделия, необходимо сначала поместить графический макрос в каталог макросов.

6. Выполните контрольный прогон (по произвольной схеме), чтобы удалить относящееся к модулю сообщение из диалогового окна управления сообщениями.
7. Повторно выполните маршрутизацию шлангопровода.
