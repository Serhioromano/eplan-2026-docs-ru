## P003014: N-жила указана многократно

### Причина

Кабель имеет более одной N-жилы.

### Решение

Измените тип потенциала на выводах устройства функций, которые привели к многократно возникающим N-жилам в кабеле.

1. Вызовите диалоговое окно свойств тех функций, которые являются источником и / или целью кабеля.
2. Переместите для каждой функции вкладку Данные символа / функции на передний план и щелкните по кнопке ++Логика++.
3. В диалоговом окне Логическая схема выводов устройства проверьте на выводах устройства функций значение в поле Тип потенциала.
4. Выберите на выводах устройства функций с многократно присвоенным значением "N" другой тип потенциала, например "Не определено".
5. Подтвердите ввод.
6. Обновите соединения.
7. При необходимости запустите новый контрольный прогон.
