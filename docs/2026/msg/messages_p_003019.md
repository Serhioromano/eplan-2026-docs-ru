## P003019: Подкабель сгенерирован

### Описание

Автоматически сгенерирован кабель с подкабелями. Это тот случай, когда вы выбираете изделие кабеля с меньшим количеством кабельных соединений, чем требуется.

При необходимости выберите другое изделие кабеля с соответствующим количеством кабельных соединений, если вы не хотите использовать подкабель.

!!! note "Замечание:"

    Это сообщение, относящееся к модулю, выводится при автоматическом генерировании кабелей. При выполнении нового контрольного прогона (любой настроеннойсхемы) его можно удалить из диалогового окна управления сообщениями.
