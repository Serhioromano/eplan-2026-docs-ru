## P005012: Несколько точек определения соединения на одном соединении

### Причина

На одном соединении находится несколько точек определения соединения.

### Решение

1. Удалите лишние точки определения соединения, чтобы для соответствующего соединения осталась только одна точка определения соединения.
2. При необходимости запустите новый контрольный прогон.
