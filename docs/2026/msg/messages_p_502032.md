## P502032: Неверное обозначение канала, указанного в шаблонах функций изделия

### Причина

В проверяемой базе данных изделий обнаружено изделие ПЛК, на котором сохранено неправильное обозначение канала.

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Выведите на передний план вкладку Шаблоны функции.
3. В таблице Выбор устройства (шаблоны функций) измените в столбце Обозначение канала одно или несколько значений в определениях функций, отображающих выводы устройства для сигнальных, сетевых кабелей / коммуникационных шин и/или точек подвода питания. Используйте только числовые значения. Следите, чтобы перед значением и после него не было пробела. Пробела также не должно быть между двумя числовыми значениями.
4. Щелкните по кнопке ++OK++.
5. Щелкните по кнопке ++Применить++.
6. При необходимости запустите новый контрольный прогон.
7. Закройте управление изделиями и выполните синхронизацию данных изделий.
