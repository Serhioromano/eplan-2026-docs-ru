## P004091: Обозначение штекера указано неверно

### Причина

Выводу шины не присвоено обозначение штекера.

### Решение

1. Установите местоположение вывода шины на схеме соединений с помощью функции Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Откройте диалоговое окно "Свойства" вывода шины.
3. Переместите первую вкладку на передний план.
4. Введите в поле Обозначение штекера недостающее значение.
5. Щелкните по кнопке ++OK++.
6. При необходимости запустите новый контрольный прогон.
