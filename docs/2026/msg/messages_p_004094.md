## P004094: Многократно заданное имя ЦПУ '\<x\>'

### Причина

В одном проекте Eplan несколько раз используется одно и то же полное имя ЦПУ. Это полное имя ЦПУ состоит из значений свойств Проект конфигураций, Рабочая станция ПЛК: имя и Идентификатор ЦПУ, разделенных точкой в качестве разделителя.

### Решение

1. Установите местоположение блока ПЛК ЦПУ на схеме соединений с помощью функции Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Откройте диалоговое окно свойств блока ПЛК.
3. Переместите вкладку Данные структуры ПЛК на передний план.
4. Измените в таблице свойств значение в поле ЦПУ: Имя [1].
5. Щелкните по кнопке ++OK++.
6. При необходимости запустите новый контрольный прогон.
