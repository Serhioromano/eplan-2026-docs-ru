## P502021: Свойство изделия 'Номер ERP / PDM \<x\>' неоднозначно

### Причина

В проверяемой базе данных изделий обнаружено изделие, для которого введено значение свойства Номер ERP / PDM \<x\>, которое уже существует в таком же свойстве у другого изделия. Это могло быть вызвано обработкой через Eplan API.

(Переменная \<x\> может принимать значения от 1 до 10. Для изделия в свойствах от Номер ERP / PDM 1 до Номер ERP / PDM 10 можно указывать до десяти номеров ERP / PDM.)

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Переместите вкладку Свойства на передний план.
3. В таблице свойств разверните уровень иерархии Общие.
4. Отметьте значение, введенное для свойства Номер ERP / PDM \<x\>.
5. Повторите это для остальных изделий, которых касается сообщение.
6. Во всех изделиях введите разные значения для свойства Номер ERP / PDM \<x\>.
7. Щелкните по кнопке ++Применить++.
8. При необходимости запустите новый контрольный прогон.
9. Закройте управление изделиями и выполните синхронизацию данных изделий.
