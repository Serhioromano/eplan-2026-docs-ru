## P020039: Изменен формат ОУ для '\<x\>'

### Описание

Выполнено сравнение проектов, при котором Структура проверяемого проекта (проекта с замечаниями) была сравнена со свойствами проекта для сравнения и были определены различия.

Это сообщение указывает, когда в проверяемом проекте изменился формат ОУ для определенного типа устройства. (Выделите проект в навигаторе страниц, выберите пункт всплывающего меню Свойства, выберите в виде Backstage Сведения команду Структура). С помощью \<x\> выводится тип устройства, у которого был изменен формат ОУ.

!!! note "Замечание:"

    Это относящееся к модулю сообщение можно удалить при выполнении нового контрольного прогона (любой настроеннойсхемы) из диалогового окна управления сообщениями.
