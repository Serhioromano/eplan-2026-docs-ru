## P007024: Изделие \<x\> больше нельзя использовать

### Причина

В вашем проекте для устройства выбрано изделие, которое в базе данных изделий отмечено как деталь, снятая с производства.

### Решение

1. Выберите для данного устройства изделие, которое не отмечено как деталь, снятая с производства.
2. При необходимости запустите новый контрольный прогон.
