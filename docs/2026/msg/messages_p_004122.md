## P004122: Логическая сеть '\<x\>' подключена через различные системы шин

### Причина

В проекте конфигураций существуют выводы шины, для которых в свойствах Физическая сеть: Имя и Логическая сеть: Имя введены идентичные значения. Однако эти выводы шины назначены разным системам шин.

### Решение

1. Установите местоположение выводов шины на схеме соединений с помощью функций Перейти к (графика) и Перейти к (2-я координата) во всплывающем меню диалогового окна Управление сообщениями.
2. Откройте диалоговое окно "Свойства" выводов шины.
3. Переместите вкладку Данные шины на передний план.
4. В поле Логическая сеть: Имя присвойте всем зарегистрированным выводам шины разные имена.
5. Подтвердите ввод.
6. При необходимости запустите новый контрольный прогон.

!!! note "Замечание:"

    Этот контрольный прогон является специфическим для проекта. Это означает, что данный контрольный прогон выполняется только в том случае, если имя проекта выбрано в навигаторе страниц или в диалоговом окне Выполнить контр. прогонустановлен флажок Применить ко всему проекту.
