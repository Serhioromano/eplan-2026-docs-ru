## P004022: Многократно заданное описание вывода устройства в одном канале (адресе) карты ПЛК

### Причина

На выводах устройств ПЛК канала карты ПЛК многократно заданы одинаковые описания выводов устройств.

### Решение

1. В диалоговом окне Свойства ++"..."++ каждого вывода устройства ПЛК канала введите разные данные в поле Описание вывода устройства.
2. При необходимости запустите новый контрольный прогон.
