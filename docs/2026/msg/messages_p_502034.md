## P502034: Идентификация устройств ПЛК неоднозначна

### Причина

В проверяемой базе данных изделий обнаружено изделие ПЛК, которому присвоена неоднозначная идентификация устройства.

Идентификация устройств в Eplan выполняется либо с помощью обозначения типа ПЛК, либо путем указания файла описания устройства. В этом конкретном случае одному и тому же обозначению типа ПЛК или одним и тем же данным описания устройства были присвоены несколько изделий ПЛК.

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Переместите вкладку Свойства на передний план.
3. В таблице свойств разверните уровень иерархии Данные ПЛК.
4. Исправьте запись в поле значений свойства Обозначение типа ПЛК или свойства Описание устройства: имя файла.
5. Щелкните по кнопке ++OK++.
6. Щелкните по кнопке ++Применить++.
7. При необходимости запустите новый контрольный прогон.
8. Закройте управление изделиями и выполните синхронизацию данных изделий.
