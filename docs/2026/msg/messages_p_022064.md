## P022064: Свойство '\<x\>' (значение с единицей измерения '\<z\>') содержит недействительную единицу измерения: '\<y\>'

### Причина

Проект содержит объект (страницу, макрос, функцию и т. д.) со свойством типа поля "Значение с единицей измерения", для которого определена группа единиц измерения. При этом для значения свойства данного объекта указана неверная единица измерения.

### Решение

1. Установите местоположение объекта в проекте с помощью функции Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Вызовите диалоговое окно Свойства объекта.
3. Укажите верную единицу измерения для значения соответствующего свойства.
4. Щелкните по кнопке ++OK++.
5. При необходимости запустите новый контрольный прогон.

!!! note "Замечание:"

    Этот контрольный прогон не активирован по умолчанию и может быть выполнен только в автономном режиме.
