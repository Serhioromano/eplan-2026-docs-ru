## P004112: Неправильный тип данных '\<x\>' или длина данных канала

### Причина

Тип данных символического адреса вывода устройства ПЛК отличается от длины массива данных канала.

### Решение

1. Проверьте данные в программе конфигурации ПЛК, с помощью которой был создан файл AML.
2. Еще раз выполните импорт данных ПЛК.

!!! note "Замечание:"

    Это относящееся к модулю сообщение можно удалить при выполнении нового контрольного прогона (любой настроеннойсхемы) из диалогового окна управления сообщениями.
