## P003007: Несколько целей кабеля

### Причина

Выполнена нумерация кабеля, у которого более, чем одна цель. При этом выбран формат нумерации, который выводит обозначение устройства цели как счетчик в обозначение устройства кабеля, например -W(=ANL+EBO-X5/=ANL+EBO-H3). Так как имеется более, чем одна цель кабеля, однако можно вывести только обозначение цели, произошел конфликт.

!!! note "Замечание:"

    Вы сможете попасть внастройкинумерации кабелей, выделив сначала кабель на схеме соединений, а затем выбрав следующие команды: вкладка Соединения> группа команд Кабели>Нумеровать. В диалоговом окне Нумеровать кабелирядом с полем Настройкищелкните затем по кнопке ++"..."++. Затем откройте в диалоговом окне Настройки: Нумерация кабелейна первой вкладке раскрывающийся список Формат.

### Решение

1. Присвойте кабелю только одну цель кабеля.
2. Обновите соединения.
3. Затем повторно пронумеруйте кабель, воспользовавшись одним из следующих форматов:

* По источнику
* По цели
* По источнику и цели
* По цели и источнику

!!! note "Замечание:"

    Это относящееся к модулю сообщение можно удалить при выполнении нового контрольного прогона (любой настроеннойсхемы) из диалогового окна управления сообщениями.
