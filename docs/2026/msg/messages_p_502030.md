## P502030: Внесенная на изделии схема сверления '\<x\>' является неполной. Контур '\<y\>' отсутствует

### Причина

В проверяемой базе данных изделий обнаружено изделие со схемой сверления, для который указан контур, не найденный Eplan.

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Выведите на передний план вкладку Изготовление.
3. В столбце Имя (схема сверления) таблицы свойств щелкните по записи в таблице, а затем нажмите ++"..."++.
4. В последующем диалоговом окне раскройте список доступных схем сверления и отметьте нужную схему сверления.
5. В диалоговом окне справа выведите на передний план вкладку Монтажные отверстия.
6. В столбце Название контура таблицы введите существующий контур или нажмите кнопку ++"..."++ и выберите контур в диалоговом окне.
7. Щелкните по кнопке ++OK++.
8. Щелкните по кнопке ++Применить++.
9. При необходимости запустите новый контрольный прогон.
10. Закройте управление изделиями и выполните синхронизацию данных изделий.
