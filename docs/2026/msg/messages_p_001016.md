## P001016: Клемма без целей

### Причина

В схеме соединений размещена клемма, не соединенная с условным обозначением.

### Решение

1. Соедините с условным обозначением минимум один из двух выводов устройства символов размещенной клеммы.
2. Обновите соединения.
3. При необходимости запустите новый контрольный прогон.

!!! note "Замечание:"

    Учтите, чтонеразмещенные клеммыне учитываются при данном контрольном прогоне!
