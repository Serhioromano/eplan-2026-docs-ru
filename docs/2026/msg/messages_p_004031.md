## P004031: Многократно заданный символический адрес в одном ЦПУ

### Причина

Внутри карты ЦПУ существует вывод устройства ПЛК, за которым закреплен символический адрес со значением, которое уже существует на другом выводе устройства ПЛК.

При использовании определенных пользователем типов данных (UDT) символический адрес состоит из объединенных значений свойств Символический адрес: UDT (имя) и Символический адрес вывода устройства ПЛК, а именно "<Символический адрес: UDT (имя)><Символический адрес>". Эта комбинация значений обоих символических адресов не является уникальной в конкретном случае.

!!! note "Замечание:"

### Решение

1. Установите местоположение выводов устройства ПЛК на схеме соединений с помощью функции Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Откройте диалоговое окно "Свойства" заявленных выводов устройств ПЛК.
3. В поле свойства Символический адрес введите значение, которое является уникальным, т. е. не присваивается другому выводу устройства ПЛК. Если вы дополнительно используете свойство Символический адрес: UDT (имя) таблицы свойств, значения этого свойства также могут не совпадать из-за комбинации обоих символических адресов. Комбинация значений обоих свойств должна быть уникальной в пределах ЦПУ.
4. Подтвердите ввод.
5. При необходимости запустите новый контрольный прогон.
