## P004055: При импорте было найдено более одного каркаса. Убедитесь, что для соединения используется надлежащее аппаратное обеспечение

### Причина

Используется интерфейс импорта ПЛК Schneider Unity Pro: На линии продукции M340 в файле импорта отсутствуют блоки ПЛК для соединения каркасов между собой.

### Решение

1. Убедитесь, что имеющиеся расширения каркасов спроектированы с использованием надлежащего аппаратного обеспечения.
2. Еще раз выполните импорт данных ПЛК.

!!! note "Замечание:"

    Это относящееся к модулю сообщение можно удалить при выполнении нового контрольного прогона (любой настроеннойсхемы) из диалогового окна управления сообщениями.
