## P005051: Символ соединения с несвязанным выводом устройства

### Причина

На схеме соединений был обнаружен символ соединения по крайней мере с одним несвязанным выводом. Под символами соединения в этом сообщении имеются в виду следующие:

* Угол
* Тройник
* Перемычка
* Перекрестное соединение
* Диагональное соединение
* Пересечение, угловое соединение (технология производственных процессов)
* Перекрестное соединение с отверстием (технология производственных процессов)
* Отверстие для перекрестного соединения
* Полукруг для перекрестного соединения
* Прерывание трубопровода

!!! example "Пример:"

    У тройника на схеме соединений имеется несвязанный вывод (см. кружок на следующем рисунке).

### Решение

1. Установите местоположение данного символа соединения на схеме соединений, пользуясь функциональностью Перейти к (графика), которую вы можете найти во всплывающем меню диалогового окна Управление сообщениями.
2. Соедините свободный вывод (выводы) символа соединения с условным обозначением так, чтобы образовались линии автоматического соединения.
3. Если символ соединения больше не нужен, удалите его.
4. При необходимости запустите новый контрольный прогон.
