## P007034: Назначение обозначений выводов устройств выводам устройств не соответствует шаблону функции

### Причина

На схеме соединений размещено устройство, в котором имеются несколько функций. Впоследствии обозначения выводов устройства в функции устройства были изменены или перевернуты, например, для замыкающего контакта с "13¶14" на "14¶13". В результате обозначения выводов устройства в этой функции больше не совпадают с обозначениями выводов устройства на соответствующем шаблоне функции выбранного изделия.

### Решение

1. Установите местоположение этой функции на схеме соединений с помощью функции Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Вызовите диалоговое окно свойств функции.
3. Переместите вкладку Изделие на передний план.
4. Изучите обозначения выводов устройства на соответствующем шаблоне функции и запишите введенные значения.
5. Перейдите на вкладку диалогового окна "Свойства".
6. В поле Обозначение вывода устройства измените значения в соответствии со значениями на соответствующем шаблоне функции изделия.
7. Щелкните по кнопке ++OK++.
8. При необходимости запустите новый контрольный прогон.
