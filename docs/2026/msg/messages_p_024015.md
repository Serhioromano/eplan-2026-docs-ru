## P024015: Группа соединений использует не все соединения изделия

### Причина

Вы разместили группу соединений в схеме соединений, которой присвоено изделие с установленными шаблонами функции (устройство). При размещении группы соединений использовано меньше функций (соединений группы), чем предоставлено в соответствующем изделии. Например, для размещенной группы соединений вы выбрали изделие, содержащее 4 соединения группы, из которых только 3 использованы в схеме соединений.

### Решение

#### Возможность 1

Выберите изделие группы с соответствующим числом шаблонов функций (количеством соединений группы).

#### Возможность 2

Уменьшите в базе данных изделий число шаблонов функций для выбранного изделия (количество соединений группы).

1. Выберите следующие команды: Вкладка Основные данные > группа команд Изделия > Управление.
2. Выберите в диалоговом окне База данных изделий вкладку Шаблоны функций.
3. Выделите в таблице убираемые шаблоны функций и щелкните по кнопке  (Удалить).
4. Примените измененную настройку в базе данных изделий.
5. Затем еще раз разместите группу соединений как устройство в схеме соединений.
6. Обновите соединения.
7. При необходимости запустите новый контрольный прогон.

!!! note "Замечание:"

    Вывод этого сообщения зависит от настроек Свернуть свободные функциии Число свободных функций. Перейти к настройкам можно, сначала открыв диалоговое окно Свойстваустройства, переместив на передний план вкладку Изделиеи нажав кнопку ++Выбор устройства++. В диалоговом окне Выбор устройстванажмите ++Настройки++ и откройте диалоговое окно Настройки: Выбор устройствас перечисленными ранее возможностяминастройки. С помощью настройки Число свободных функцийопределите число неиспользуемых в устройстве функций (резервных функций), которое должно иметь изделие. Количество можно указать, только если установлен флажок в настройке Свернуть свободные функции.Если в настройке Число свободных функцийустановлено значение "0", то любой свободный шаблон воспринимается как ошибка.
