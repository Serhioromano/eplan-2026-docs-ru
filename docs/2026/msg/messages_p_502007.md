## P502007: На изделии не указана высота, ширина и / или глубина: Высота = \<x\>, Ширина = \<y\>, Глубина = \<z\>

### Причина

В проверяемой базе данных изделий было найдено изделие, на котором отсутствует монтажная информация о высоте, ширине и / или Глубине.

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Переместите вкладку Свойства на передний план.
3. В таблице свойств разверните такие уровни иерархии: Данные монтажа > Размеры.
4. Занесите в свойства Ширина, Высота и / или Глубина недостающие значения.
5. Щелкните по кнопке ++Применить++.
6. При необходимости запустите новый контрольный прогон.
7. Закройте управление изделиями и выполните синхронизацию данных изделий.

!!! note "Замечание:"

    Чтобы сообщение больше не выводилось, не менее двух из приведенных выше параметров монтажных данных на изделии должны иметь значения. Исключения составляютизделия, на которых сохранен 3D-макрос. В этом случае должны присутствовать значения всех трех параметров монтажных данных.
