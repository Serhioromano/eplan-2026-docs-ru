## P013051: Устройству можно присвоить не более 50 изделий

### Причина

При импорте спецификации выполнена попытка присвоения обозначению устройства более 50 изделий.

!!! note "Замечание:"

    В Eplan устройству может быть присвоено максимум50изделий. Индексизделиязадает последовательность внесения изделий в диалоговом окне Свойства ++"..."++ на вкладке Изделие.

### Решение

1. Откройте файл импорта с помощью текстового или XML-редактора и удалите лишние изделия.
2. Сохраните файл и заново импортируйте спецификацию.

!!! note "Замечание:"

    Это относящееся к модулю сообщение можно удалить при выполнении нового контрольного прогона (любой настроеннойсхемы) из диалогового окна управления сообщениями.
