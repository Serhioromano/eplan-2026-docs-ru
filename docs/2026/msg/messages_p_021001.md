## P021001: Объект-заполнитель не содержит переменные

### Причина

В ходе присвоения значений не были определены переменные для объекта-заполнителя.

### Решение

1. Дважды щелкните по объекту-заполнителю. Перейдите в диалоговом окне Объект-заполнитель на вкладку Значения.
2. Определите здесь как минимум одну переменную. Выберите для этого пункт всплывающего меню  Создать переменную.
3. Введите в диалоговом окне Назвать новую переменную требуемое имя и подтвердите ввод, нажав ++OK++.

Новая переменная вставляется в виде новой строки под заголовком столбца Переменная.
4. Выберите пункт всплывающего меню Новый набор значений.

К таблице добавляется пустой столбец.
5. Введите в верхнюю строку столбца обозначение для набора значений. Введите во второй ячейке значение для переменной.
6. Перейдите на вкладку Присвоение.
7. Выделите в таблице присвоений в столбце Переменная ячейку с требуемым свойством объекта.
8. Выберите пункт всплывающего меню Выбрать переменную.
9. Присвойте в следующем диалоговом окне новую переменную требуемому свойству объекта.
10. При необходимости запустите новый контрольный прогон.
