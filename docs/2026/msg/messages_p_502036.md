## P502036: Свойство изделия 'Номер ERP / PDM \<x\>' отличается в разных вариантах изделия

### Причина

В проверяемой базе данных изделий было найдено изделие, имеющие разные варианты. В свойстве изделия Номер ERP / PDM \<x\> для каждого из вариантов изделия введено разное значение. Это могло быть вызвано обработкой через Eplan API.

(Переменная \<x\> может принимать значения от 1 до 10. Для варианта изделия в свойствах от Номер ERP / PDM 1 до Номер ERP / PDM 10 можно указать до десяти номеров ERP / PDM.)

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Для всех вариантов изделия выведите на передний план вкладку Свойства.
3. В таблице свойств разверните каждый уровень иерархии Общие.
4. Во всех вариантах введите одинаковые значения для свойства Номер ERP / PDM \<x\>.
5. Щелкните по кнопке ++Применить++.
6. При необходимости запустите новый контрольный прогон.
7. Закройте управление изделиями и выполните синхронизацию данных изделий.
