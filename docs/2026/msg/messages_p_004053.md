## P004053: Между структурой сети в файле импорта и в проекте найдено слишком много различий! Пожалуйста, проверьте все структуры сети

### Причина

При последнем импорте данных ПЛК было найдено соединение, противоречащее существующему сейчас в проекте соединению. Неверное соединение не могло быть создано по причине сложного противоречия. Возможно, импортированный файл был определен для другого проекта.

### Решение

1. Проверьте, все ли выводы шины соединены с правильной физической сетью.
2. Еще раз выполните импорт данных ПЛК.

!!! note "Замечание:"

    Это относящееся к модулю сообщение можно удалить при выполнении нового контрольного прогона (любой настроеннойсхемы) из диалогового окна управления сообщениями.
