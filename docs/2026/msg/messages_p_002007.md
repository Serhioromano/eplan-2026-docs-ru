## P002007: Имеются несколько определений штекеров, не связанных между собой

### Причина

Вы осуществляете проектирование со штекерами и работаете с гнездами и штырями раздельно. Теперь определения функций двух связанных друг с другом определений штекеров с одинаковым ОУ не сходятся. Вследствие этого образование пары между стороной штыря и гнезда отсутствует.

### Решение

1. Проверьте на определении штекера для стороны гнезд и штырей правильность установки определения функции.
2. Для этого откройте диалоговое окно Свойства ++"..."++ и просмотрите на вкладке Определение штекера настройки в поле Определение функции. Для определения штекера со стороны гнезд определение функции должно стоять на "Определение штекера для гнезд". Для определения штекера стороны штырей определение функции должно стоять на "Определение штекера для штырей".
3. Измените отличающиеся настройки с учетом этих значений.
4. При необходимости запустите новый контрольный прогон..
