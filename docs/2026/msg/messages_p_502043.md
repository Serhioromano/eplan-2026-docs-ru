## P502043: Регистр указанного имени файла для свойства '\<x\>' не соответствует регистру в файловой системе

### Причина

В проверяемой базе данных изделий обнаружено изделие, в свойстве которого указан файл, где верхний/нижний регистр в написании пути или имени файла не совпадает с регистром в написании пути или имени файла, физически хранящегося в файловой системе.

Расхождение в написании (из-за разного регистра) может привести к тому, что при обмене данными в формате EDZ идентичные файлы (изображения, документы и т. д.) будут несколько раз сохранены в одном файле EDZ.

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Переместите вкладку Свойства на передний план.
3. Щелкните по кнопке  в поле значений соответствующего свойства, чтобы открыть проводник Windows.
4. Дважды щелкните по соответствующему файлу в проводнике Windows.
В поле значений соответствующего свойства будут добавлены путь и имя файла в правильном написании.
5. Щелкните по кнопке ++Применить++.
6. При необходимости запустите новый контрольный прогон.
7. Закройте управление изделиями и выполните синхронизацию данных изделий.

!!! note "Замечание:"

    Этот контрольный прогон не активирован по умолчанию и может быть выполнен только в автономном режиме.
