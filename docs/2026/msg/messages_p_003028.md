## P003028: Кабель использует не все кабельные соединения изделия

### Причина

Вы разместили кабель в схеме соединений, которой присвоено изделие с установленными шаблонами функции (устройство). При размещении кабеля использовано меньше функций (кабельных соединений), чем предоставлено в соответствующем изделии. Например, для размещенного кабеля вы выбрали изделие, содержащее 4 кабельных соединения, из которых только 3 использованы в схеме соединений.

### Решение

#### Возможность 1

Выберите кабельное изделие с соответствующим числом шаблонов функций (количеством кабельных соединений).

#### Возможность 2

Уменьшите в базе данных изделий число шаблонов функций для выбранного изделия (количество кабельных соединений).

1. Выберите следующие команды: Вкладка Основные данные > группа команд Изделия > Управление.
2. В диалоговом окне База данных изделий переместите вкладку Шаблоны функций на передний план.
3. Выделите в таблице убираемые шаблоны функций и щелкните по кнопке  (Удалить).
4. Примените измененную настройку в базе данных изделий.
5. Затем еще раз разместите кабель как устройство в схеме соединений.
6. Обновите соединения.
7. При необходимости запустите новый контрольный прогон.
