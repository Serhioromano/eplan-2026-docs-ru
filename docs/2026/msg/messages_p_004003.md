## P004003: Относящееся к указанному значению конфигурации '\<x\>' свойство '\<y\>' не содержит число

### Причина

При адресации выводов устройства ПЛК используется схема адресации, для которой было указано определенное значение конфигурации в элементе формата "Счетчик". Например, вы выбрали настройку "На позиции / разъем". Однако в диалоговом окне "Свойства" соответствующего блока ПЛК на вкладке Данные структуры ПЛК в поле На позиции / разъем введено нечисловое значение.

Или же, например, в качестве значения конфигурации на счетчике установлена настройка "Обозначение канала (автоматич.)", однако в диалоговом окне "Свойства" соответствующего вывода устройства ПЛК в поле Обозначение канала введено нечисловое значение.

### Решение

1. Введите для блока ПЛК или для вывода устройства ПЛК только числовое значение в поле, которое было указано при адресации как требуемое значение конфигурации для элемента формата "Счетчик".
2. Еще раз выполните адресацию выводов устройства ПЛК.

!!! note "Замечание:"

    Это относящееся к модулю сообщение можно удалить при выполнении нового контрольного прогона (любой настроеннойсхемы) из диалогового окна управления сообщениями.
