## P502002: Записанный на изделии графический файл '\<x\>' отсутствует

### Причина

В проверяемой базе данных изделий было найдено изделие, на котором сохранен графический файл, который Eplan не может найти.

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Переместите вкладку Свойства на передний план.
3. В таблице свойств на уровне иерархии Монтажные данные в поле значений свойства Графический файл нажмите ++"..."++ и выберите в открывшемся диалоговом окне выбора графический файл из одного из предлагаемых каталогов картинок.

Или в качестве альтернативы удалите введенный графический файл в поле значений свойства.

Или создайте новую картинку, сохраните ее в нужном каталоге картинок и выберите ее снова в свойстве.
4. Щелкните по кнопке ++Применить++.
5. При необходимости запустите новый контрольный прогон.
6. Закройте управление изделиями и выполните синхронизацию данных изделий.
