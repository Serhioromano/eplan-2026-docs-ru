## P001012: Неверное образование мостов. перемычки

### Причина

В проекте обнаружена ошибочно созданная мостовая перемычка. Это сообщение выдается по ряду причин, которые разъясняются в следующих примерах:

#### Возможность 1

В схеме соединений в качестве мостовой перемычки определено соединение между разными уровнями многоуровневой клеммы.

!!! example "Пример:"

    Между обеими клеммами-X1:1и-X1:2существует соединение, определенное как мостовая перемычка. Обе клеммы расположены наразныхуровняхмногоуровневой клеммы. Создание мостовой перемычки в данном случае невозможно.

#### Возможность 2

Вы определили в схеме соединений или диалоговом окне Обработать клеммник соединение между клеммами как мостовую перемычку, однако не внесли значение количества мостовых перемычек на одной или обеих клеммах.

!!! example "Пример:"

    Между обеими клеммами-X1:1и-X1:2существует соединение, определенное как мостовая перемычка. Обе клеммы являются "стандартными" проходными клеммами с двумя возможностями вывода устройств. В диалоговом окне Логическая схема выводов устройствадля первого выводаустройствафункциина обеих клеммахневведено значения или введен0длясвойства Число мостовых перемычек.

#### Возможность 3

Вы создали вручную в диалоговом окне Обработать клеммник мостовую перемычку между уровнями многоуровневой клеммы.

### Решение

#### Для возможности 1

1. В схеме соединений дважды нажмите на точку определения соединения между клеммами.
2. Выберите в диалоговом окне Свойства ++"..."++ вкладку Точка определения соединения.
3. Щелкните рядом с полем Определение функции по кнопке ++"..."++ и выберите в диалоговом окне Определения функций вместо записи "Мостовая перемычка" запись "Проволочная перемычка".

#### Для возможности 2

1. Для клемм вызывайте диалоговое окно Свойства.
2. Перейдите на вкладку Данные символа/функции и, нажав кнопку ++Логика++, откройте диалоговое окно Логическая схема выводов устройства.
3. В поле Число мостовых перемычек для соответствующих выводов устройства функции введите значение, которое больше "0" (например, в разделе "Возможность 2" на первом выводе устройства функции указана 1).

#### Для возможности 3

Удалите в диалоговом окне Обработать клеммник многоуровневую клемму, созданную вручную между уровнями мостовой перемычки.

* * *

При необходимости запустите новый контрольный прогон.
