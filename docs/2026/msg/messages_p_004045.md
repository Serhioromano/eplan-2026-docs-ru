## P004045: Связующее устройство на блоке ПЛК: '\<x\>'

...Жгут / сеть = '\<x\>', Главный шины / шинный интерфейс = '\<y\>', Подключен к главному шины / шинному интерфейсу = '\<z\>', Система шин = '\<u\>', На позиции / адрес шины = '\<v\>', Скорость передачи данных = '\<w\>', Подразъем = '\<r\>', Имя устройства в DNS/PROFINET = '\<s\>'

### Причина

Возможно несколько причин:

* В проекте содержатся блоки ПЛК со связующими устройствами.
* Или вы импортировали старый проект с блоками ПЛК, которые содержат связующие устройства.
* Или вы импортировали старые макросы, которые содержат блоки ПЛК со связующими устройствами.

### Решение

Вам предоставляется право выбора по обращению с данными:

1. Например, создать новый вывод шины или использовать имеющийся вывод и внести туда соответствующие данные, отображенные в заполнителях сообщения.
2. Затем удалите имеющиеся связующие устройства с блоков ПЛК с помощью следующих команд: Файл > Дополнительно > группа команд Организовать > Проект > группа команд Оптимизировать > Сжать проект.
3. Еще раз выполните импорт данных ПЛК.

!!! note "Замечание:"

    Это относящееся к модулю сообщение можно удалить при выполнении нового контрольного прогона (любой настроеннойсхемы) из диалогового окна управления сообщениями.
