## P502042: Файл '\<x\>' не находится в каталоге основных данных '\<z\>', предназначенном для свойства '\<y\>'

### Причина

В проверяемой базе данных изделий обнаружено изделие, в свойстве которого указан файл, отсутствующий в настроенном каталоге для соответствующих основных данных (например, графический файл, хранящийся вне настроенного каталога для изображений). Файлы, отсутствующие в настроенных каталогах, невозможно вывести при экспорте данных изделия в формате EDZ.

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Переместите вкладку Свойства на передний план.
3. Щелкните по кнопке  в поле значений соответствующего свойства, чтобы открыть проводник Windows.
4. Переместите соответствующий файл в правильный каталог основных данных.
5. Дважды щелкните по перемещенному файлу в проводнике Windows.
Файл с указанием правильного пути будет добавлен в поле значений соответствующего свойства.
6. Щелкните по кнопке ++Применить++.
7. При необходимости запустите новый контрольный прогон.
8. Закройте управление изделиями и выполните синхронизацию данных изделий.

!!! note "Замечание:"

    Этот контрольный прогон не активирован по умолчанию и может быть выполнен только в автономном режиме.
