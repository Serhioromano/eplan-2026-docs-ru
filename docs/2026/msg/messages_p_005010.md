## P005010: Соединение без указания потенциала

### Причина

Не определен потенциал для соединения.

### Решение

#### Возможность 1

1. Выберите следующие команды: вкладка Соединения > группа команд Соединения > Навигатор.
2. Нажмите на сообщение в диалоговом окне управления сообщениями и выберите пункт всплывающего меню Синхронизировать выбор, чтобы определить недостающее соединение.

Соединение будет выделено в навигаторе соединений.
3. Перейдите из выделенного соединения через пункты всплывающего меню Перейти к (графика, источник) и / или Перейти к (графика, цель) к целевым функциям на схеме соединений, между которыми проходит графическое соединение в качестве линии автоматического соединения.
4. Разместите точку определения потенциала на этой линии.
5. Укажите имя потенциала в диалоговом окне "Свойства".
6. Щелкните по кнопке ++OK++.

#### Возможность 2

Если вы создали неразмещенное соединение, выполните следующие действия:

1. Чтобы убрать из проекта ненужные данные, выберите следующие команды: Файл > Дополнительно > группа команд Организовать > Проект > группа команд Оптимизировать > Сжать проект.
2. Установите флажок Убрать неразмещенные соединения в настройках сжатия.

* * *

При необходимости запустите новый контрольный прогон.
