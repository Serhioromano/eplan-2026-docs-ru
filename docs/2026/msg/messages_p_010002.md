## P010002: Многократное главное размещение одноименных обозначений местоположений

### Причина

Два или более, так как два обозначения местоположения с одинаковым ОУ обладают свойством Главное размещение.

### Решение

1. Выделите в диалоговом окне Управление сообщениями присвоенное сообщению обозначение устройства.
2. С помощью пунктов меню Перейти к (графика) и Перейти к (2-я координата) всплывающего меню последовательно переходите к соответствующим обозначениям местоположения на схеме соединений.
3. Для этого двойным щелчком мыши по точке вставки вызовите свойства соответствующего обозначения местоположения.
4. Снимите на всех, кроме одного, обозначениях местоположения флажок Главное размещение, чтобы только одно обозначение местоположения обладало этим свойством.
5. Подтвердите ввод.
6. При необходимости повторите этот процесс для других обозначений местоположения.
7. При необходимости запустите новый контрольный прогон.
