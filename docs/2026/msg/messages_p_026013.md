## P026013: Размещение изделия накладывается на заблокированную для монтажных отверстий область

### Причина

Находящееся на монтажной поверхности размещение изделия накладывается на заблокированную для монтажных отверстий область или наоборот.

Возможные случаи наложения:

* Размещение изделия заходит на заблокированную для монтажных отверстий область.
* Заблокированная для монтажных отверстий область заходит на размещение изделия.
* Размещение изделия было расположено на заблокированной для монтажных отверстий области.
* Заблокированная для монтажных отверстий область была расположена на размещении изделия.

### Решение

1. Установите местоположение размещения изделия или заблокированной для монтажных отверстий области в пространстве листа с помощью функциональности Перейти к, которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Переместите размещение изделия или заблокированную для монтажных отверстий область на монтажной поверхности таким образом, чтобы оба объекта не накладывались друг на друга.
3. При необходимости запустите новый контрольный прогон.
