## P004009: Многократно заданный разъем '\<x\>' каркаса '\<y\>'

### Причина

В нескольких блоках ПЛК, содержащих данные структуры ПЛК, при одинаковых введенных данных каркаса и проекта конфигураций дополнительно указаны одинаковые позиции / разъемы.

### Решение

1. Откройте диалоговое окно Свойства ++"..."++ для соответствующих блоков ПЛК.
2. Переместите вкладку Данные структуры ПЛК блоков на передний план.
3. Введите в соответствующих полях На позиции / разъем разные данные.
4. При необходимости запустите новый контрольный прогон.
