## P013050: Невозможно добавить покупное изделие

### Причина

При импорте спецификации невозможно было добавить покупное изделие, так как максимально возможное число было перезаписано.

!!! note "Замечание:"

    В Eplan число импортируемых покупных изделий составляет максимум 1 000.

### Решение

1. Откройте файл импорта с помощью текстового или XML-редактора и удалите лишние покупные изделия.
2. Сохраните файл и заново импортируйте спецификацию.

!!! note "Замечание:"

    Это относящееся к модулю сообщение можно удалить при выполнении нового контрольного прогона (любой настроеннойсхемы) из диалогового окна управления сообщениями.
