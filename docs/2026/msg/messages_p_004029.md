## P004029: Объект отмечен для удаления

### Описание

При импорте файлов конфигурации ПЛК объекты ПЛК (блоки ПЛК, выводы устройства ПЛК или адреса) выделяются программно, если в проекте Eplan они содержатся в соответствующем проекте конфигураций, а не в файле импорта.

После импорта данных ПЛК выделение соответствующих объектов в диалоговом окне Адреса / списки присвоений (вкладка Устройство > группа команд ПЛК > Список присвоений) в столбце таблицы Выделено для удаления отображается в виде установленного флажка.

При импорте в формате AutomationML AR APC выводы устройства ПЛК дополнительно выделяются для удаления, если символический адрес в файле импорта пуст, а свойство Символический адрес (автоматич.) на соответствующем выводе устройства ПЛК в Eplan заполнено. Имеющийся символический адрес остается.

Во время этого контрольного прогона выполняется поиск всех объектов, выделенных таким образом. Для каждого найденного объекта выводится сообщение в управлении сообщениями.

!!! note "Замечание:"

    Выделение сохраняется после вывода сообщения.
