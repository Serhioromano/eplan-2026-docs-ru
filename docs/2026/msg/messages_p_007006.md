## P007006: Функция без обозначения вывода устройства

### Причина

Отсутствует как минимум одно обозначение вывода устройства для устройства, размещенного в схеме соединений. Или не введено имя на экранировании.

### Решение

1. Дважды щелкните по соответствующему условному обозначению и введите в диалоговом окне Свойства ++"..."++ недостающее обозначение(я) вывода устройства. Или введите недостающее имя экранирования.
2. Щелкните по кнопке ++OK++.
3. При необходимости запустите новый контрольный прогон.

!!! note "Замечание:"

    Оповещения о выводах устройства безобозначенияне отображаются, если им присвоен тип вывода устройства "Внутренний", "Прямой вывод устройства" или "Мостовая перемычка".
