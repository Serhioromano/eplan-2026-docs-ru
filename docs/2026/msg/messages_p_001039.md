## P001039: Мостовая перемычка на клемме без паза мостовых перемычек

### Причина

В проекте обнаружена ошибочно созданная мостовая перемычка. Вы определили в схеме соединений или диалоговом окне Обработать клеммник соединение между клеммами как мостовую перемычку, однако не внесли значение количества мостовых перемычек на одной или обеих клеммах.

!!! example "Пример:"

    Между обеими клеммами-X1:1и-X1:2существует соединение, определенное как мостовая перемычка. Обе клеммы являются "стандартными" проходными клеммами с двумя возможностями вывода устройств. В диалоговом окне Логическая схема выводов устройствадля первого выводаустройствафункциина обеих клеммахневведено значения или введен0длясвойства Число мостовых перемычек.

### Решение

1. Для клемм вызывайте диалоговое окно Свойства.
2. Перейдите на вкладку Данные символа/функции и, нажав кнопку ++Логика++, откройте диалоговое окно Логическая схема выводов устройства.
3. В поле Число мостовых перемычек для соответствующих выводов устройства функции введите значение больше "0" (например, в данном примере на первом выводе устройства функции указано 1).

* * *

При необходимости запустите новый контрольный прогон.
