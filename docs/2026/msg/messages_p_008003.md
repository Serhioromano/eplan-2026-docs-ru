## P008003: Язык '\<x\>' отсутствует в словаре

### Причина

Исходный язык '\<x\>' для текстов проекта, выбранный в специфических для проекта настройках, доступен в качестве языка перевода, но не в качестве языка словаря.

### Решение

Добавьте отсутствующий словарь в язык, который вы назначили в настройках языком перевода и выбрали исходным языков.

1. Выберите следующие команды: Вкладка Инструменты > группа команд Перевод > Словарь.
2. Щелкните в диалоговом окне Словарь на вкладке Управление по кнопке  (Создать).
3. Выберите требуемый язык в открывшемся списке.
4. Закройте диалоговое окно.
5. Переведите текст.

!!! note "Замечание:"

    Это сообщение, относящееся к модулю, выводится при автоматическом переводе текстов. При выполнении нового контрольного прогона (любой настроеннойсхемы) его можно удалить из диалогового окна управления сообщениями.
