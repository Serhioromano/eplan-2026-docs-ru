## P001038: Несколько главных клемм с одинаковым положением устройства

### Причина

Для одной группы клемм определено несколько главных клемм с одинаковым положением устройства (свойство Клемма: Положение устройства).

Относительно применения главных клемм:

* На одну группу клемм должна приходиться только одна главная клемма.
* Две группы клемм не могут иметь одинаковое положение устройства.

Из чего следует: на каждое положение устройства должна приходиться только одна главная клемма.

### Решение

1. Установите местоположение соответствующих главных клемм на схеме соединений, пользуясь функцией Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Снимите флажок Главная клемма для всех главных клемм кроме одной в диалоговом окне 'Свойства'.
Или введите для всех главных клемм кроме одной в диалоговом окне 'Свойства' различные значения свойства Клемма: Положение устройства.
3. Подтвердите ввод.
4. При необходимости запустите новый контрольный прогон.
