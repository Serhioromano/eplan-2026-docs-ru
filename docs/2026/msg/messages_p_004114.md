## P004114: Адрес ПЛК '\<x\>' не находится в диапазоне адресов принадлежащего карте ПЛК подустройства '\<y\>'

### Причина

На выводе устройства ПЛК был определен адрес, который не входит в диапазон адресов подустройства, относящегося к карте ПЛК.

Выводы устройства ПЛК с определением функции "Вывод устройства ПЛК, внутр., общ." не проверяются, поскольку они служат только для отображения свободных символических адресов.

### Решение

1. Установите местоположение вывода устройства ПЛК на схеме соединений с помощью функции Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Вызовите диалоговое окно "Свойства" вывода устройства ПЛК.
3. На выводе устройства ПЛК определите значения, введенные в первой вкладке для свойств Адрес и Подустройство ПЛК: Индекс (список свойств).
4. С помощью пункта всплывающего меню Перейти к (обратный эквивалент) вывода устройства ПЛК перейдите к соответствующему блоку ПЛК на карте ПЛК.
5. Вызовите диалоговое окно "Свойства" блока ПЛК.
6. Определите значения, введенные в таблице свойств первой вкладки, в поле Подустройство ПЛК (x): Начальный адрес (...) и Подустройство ПЛК (x): Длина данных (...).
7. Измените адрес ПЛК так, чтобы он находился в диапазоне адресов карты ПЛК, либо соответствующим образом скорректируйте начальный адрес или длину данных для подустройства на блоке ПЛК.
8. Подтвердите ввод.
9. При необходимости запустите новый контрольный прогон.
