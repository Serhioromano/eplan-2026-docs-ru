## P502014: Свойство изделия 'Главная группа продуктов' не определено

### Причина

В проверяемой базе данных изделий было найдено изделие, на котором в свойстве Главная группа по продукту указано значение "Не определено".

!!! note "Замечание:"

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Переместите вкладку Свойства на передний план и раскройте уровень иерархии Группировка продуктов.
3. В поле значений свойства Группировка продуктов нажмите кнопку ++"..."++.
4. В открывшемся дереве изделий выберите группировку продуктов, в которой конкретное значение определено для всех трех свойств изделия.
5. Щелкните по кнопке ++Применить++.
6. При необходимости запустите новый контрольный прогон.
7. Закройте управление изделиями и выполните синхронизацию данных изделий.
