## P502025: Свойства изделия 'Обозначение типа ПЛК' и 'Описание устройства: Имя файла' не заполнены

### Причина

В проверяемой базе данных изделий обнаружено изделие ПЛК, у которого для свойства Обозначение типа ПЛК или свойства Описание устройства: Имя файла не задано значение. При импорте файлов конфигурации ПЛК присвоение изделия осуществляется на основании свойства Обозначение типа ПЛК или свойства Описание устройства: Имя файла. Для успешного присвоения изделия одно из двух свойств должно содержать значение.

Сообщение контрольного прогона также выводится, если изделие не является устройством ПЛК и имеет шаблон функции с определением функции "Кабельный вывод сети / шины".

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Переместите вкладку Свойства на передний план.
3. В таблице свойств разверните уровень иерархии Данные ПЛК.
4. Введите значение в поле значений свойства Обозначение типа ПЛК или свойства Описание устройства: имя файла.
5. Щелкните по кнопке ++Применить++.
6. При необходимости запустите новый контрольный прогон.
7. Закройте управление изделиями и выполните синхронизацию данных изделий.
