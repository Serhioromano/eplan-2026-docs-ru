## P004107: Диапазон адресов карты ПЛК '\<x\>' пересекается с диапазоном адресов карты ПЛК '\<y\>'

### Причина

Для обоих блоков ПЛК диапазоны адресов были определены таким образом, что они пересекаются.

### Решение

1. Установите местоположение блоков ПЛК на картах ПЛК в схеме соединений во всплывающем меню диалогового окна Управление сообщениями. С помощью функции Перейти к (графика) перейдите к карте ПЛК '\<x\>', а с помощью функции Перейти к (2-я координата) — к карте ПЛК '\<y\>'.
2. Вызовите диалоговое окно "Свойства" обоих блоков ПЛК и переместите первую вкладку на передний план.
3. Скорректируйте значения в полях Начальный адрес карты ПЛК и Устройство ПЛК: Длина данных (...) таблицы свойств так, чтобы пересечение диапазонов адресов обеих карт ПЛК исключалось.
4. Подтвердите ввод.
5. При необходимости запустите новый контрольный прогон.

!!! note "Замечание:"

    Этот контрольный прогон проверяет, не пересекаются ли диапазоны адресов карт ПЛК.
