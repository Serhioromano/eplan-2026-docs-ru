# Диалоговое окно "Частичные проекты"

## Вызов диалогового окна

Вы открыли проект и выделили его в Навигаторе страниц. В проекте установлены области обработки. **Файл** > **Взаимодействие** > группа команд **Частичные проекты** > **Сохранить / выгрузить** > **Сохранить / выгрузить частичные проекты**

!!! note "Замечание:"

    Чтобы иметь возможность работать с частичными проектами, нужно открыть проект в режиме обработки "Эксклюзивный". Поэтому при выборе команды **Сохранить / выгрузить частичные проекты** осуществляется внутренняя проверка того, открыт ли проект в эксклюзивном режиме. Если это не так, проект закрывается и открывается автоматически в эксклюзивном режиме. Если это невозможно, появится сообщение о том, что эксклюзивный доступ невозможен, и действие прерывается.

В этом диалоговом окне отображаются определенные областями обработки возможные частичные проекты выбранного открытого в эксклюзивном режиме проекта.

Обзор основных элементов диалогового окна:

### Проект

В этом поле указано имя проекта, для которого вы хотите определить частичные проекты. Запись нельзя обработать, и поле неактивно.

### Частичные проекты

В этой таблице показана информация о частичных проектах, а именно: статус, номер частичного проекта, имя и описание схемы соответствующей области обработки.

В столбце **Каталог** с помощью кнопки ++"..."++ можно выбрать другой целевой каталог, при этом данная информация будет сохранена в исходном проекте. В качестве предварительной настройки здесь указан заданный каталог проектов.

Перед выгрузкой установите флажок **Только расширить**, тогда объекты (страницы, пространства листа, сегменты предварительного планирования и т. д.) сгенерированного частичного проекта получат защиту от изменений. Для эти объектов автоматически активируется свойство **Защита от изменений** (ид. 3014). Благодаря этому частичный проект можно только расширить. Это означает, что, хотя в данный частичный проект возможна вставка новых страниц, пространства листа, сегментов предварительного планирования и т. д., нельзя удалить или изменить уже имеющиеся объекты.

Частичные проекты пронумерованы в соответствии с очередностью областей обработки и дополнены впереди нулями (например `EPLAN_Sample_Project#003`). Если область обработки была добавлена позже, соответствующий частичный проект получает следующий по порядку свободный номер.

### Всплывающее меню

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).

### [Выгрузить]

С помощью этой кнопки можно сгенерировать частичные проекты, т. е. выгрузить из проекта. Накладывающиеся области обработки могут быть выгружены, только если область обработки с накладывающейся частичной областью еще не было выгружено. Если вы выделили такую область обработки, клавиша ++"Выгрузить"++ становится недоступной.

### [Сохранить]

С помощью этой кнопки можно снова вставить в проект выгруженные частичные проекты. Возможен многократный выбор выгруженных частичных проектов.

### [Обновить]

С помощью этой кнопки можно обновить главный проект, т. е. "сохранить" новые состояния частичных проектов без их повторной выгрузки.
