# Дублировать объекты в пространстве листа

Команда **Дублировать** позволяет очень просто вставить несколько копий трехмерных объектов и 3D-макросов в пространство листа. Функция дублирования работает только в пределах пространства листа, она не может быть использована для всех пространств листа сразу. Условие: Вы открыли проект. Вы открыли пространство листа.

1. Выделите дублируемый объект, 3D-макрос или группу объектов, заключив эти объекты в рамку.
2. Выберите следующие команды: Вкладка **Обработать** > группа команд **Графика** > **Дублировать**.

!!! info "Для сведения:"

    Объекты появятся рядом с точкой захвата слева над курсором. Точку захвата можно переключать при помощи клавиши ++"A"++.

3. Выберите пункт всплывающего меню **Опции размещения**, чтобы вызвать диалоговое окно **Опции размещения** и задать угол поворота, точку захвата и значения смещения. Щелкните по кнопке ++"OK"++.
4. Разместите первую копию.
5. Укажите в диалоговом окне **Дублировать** общее число генерируемых элементов.
6. В следующем диалоговом окне **Режим вставки** укажите способ обработки структурных идентификаторов дублированных объектов. Щелкните по кнопке ++"OK"++.

!!! info "Для сведения:"

    Eplan автоматически генерирует указанное число копий и размещает их, используя интервал, выбранный для первой копии. В навигаторе пространства листа копии отображаются параллельно исходным объектам.

!!! tip "Совет:"

* Чтобы сгенерировать простую копию, можно также щелкнуть по объекту, удерживая нажатой клавишу ++"Ctrl"++, а затем перетащить копию на новое место.
* Если в пространстве листа требуется совместно обработать несколько 3D-объектов (дублировать, копировать, переместить, вырезать, удалить), выделите эти объекты и с помощью команды **Группировать** объедините их в [группу](gededitgui_h_elementegruppieren.md). Затем можно снова отменить группирование при помощи команды **Отменить** (вкладка **Обработать** > группа команд **Группировать**).
