# Диалоговое окно Дополнить данные изделия

## Вызов диалогового окна:

* Вы открыли базу данных изделий. Вкладка **Основные данные** > группа команд **Изделия** > раскрывающаяся кнопка **Управление** > **Настройки**. В диалоговом окне **Настройки: Изделие (пользователь)** нажмите на кнопку ++"..."++ в поле **Дополнить данные изделия через**.
* Вы открыли проект. Вы выделили главную функцию в графическом редакторе или навигаторе. Пункт всплывающего меню **Свойства**. Выберите вкладку **Изделия** и щелкните рядом с полем **Источн. данных** по ++"..."++. В диалоговом окне **Настройки: Изделие (пользователь)** нажмите на кнопку ++"..."++ в поле **Дополнить данные изделия через**.

В этом диалоговом окне задается, какие технические данные изделия, специфические для Eplan, должны быть дополнены коммерческими данными из подсоединенных систем, таких как PMS,

Обзор основных элементов диалогового окна:

### Дополнить данные изделия через:

Если специфические для Eplan технические данные изделий необходимо дополнить коммерческими данными из подключенных систем, например PMS, этого можно добиться с помощью этой таблицы. При выборе схемы выбора изделия можно определить не только источник данных (поле **Схема** диалогового окна **Настройки: Изделие (пользователь)**), но и выбрать другие источники данных, которые также должны быть определены как схема. Соответствующее присвоение выполняется в следующем поле:

Сначала щелкните по ![](images/all_new_as.png){: .ui-icon } (Создать), чтобы сгенерировать строку в списке привязок. Эта кнопка активна только в том случае, если вы определили хотя бы одну схему выбора изделия в специфических для пользователя настройках. После этого выберите из раскрывающегося списка схему, для которой будет действительна настройка, и установите флажок в столбце **Генерировать изделия, если отсутствуют** для каждой схемы. Вместе с номером изделия и вариантом, которые при создании новых записей данных получают значение `Создать_<порядковый_номер>`, свойство **Группа функций** (на уровне иерархии **Данные** вкладки **Свойства**) также заполняется значением "Новое", что позволяет легко находить изделия, сгенерированные путем выбора изделий.

!!! example "Пример:"

    В поле **Схема** диалогового окна **Настройки: Изделие (пользователь)** выбрана настройка "Стандарт", анастройки, определенные в этой схеме, учитываются при выборе изделия. В раскрывающемся списке **Имя схемы** поля **Дополнить данные изделия через** вы выбрали обе схемы: "KundeA_SQL" и "KundeA_API"; если флажок **Генерировать изделия, если отсутствуют** установлен, то соответствующие изделия генерируются в базе данных изделий.
