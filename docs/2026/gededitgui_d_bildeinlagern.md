# Диалоговое окно Сохранить графический файл

## Вызов диалогового окна:

Вы открыли проект. Вы открыли символ. Вкладка **Вставить** > группа команд **Рисунок** > **Графический файл**. Выберите в диалоговом окне **Выбрать графический файл** нужный графический файл и нажмите на кнопку ++"Открыть"++.

В Eplan можно вставить графические файлы форматов GIF, JPG, BMP, ICO, PNG или TIFF. В этом диалоговом окне вы указываете, сохраняется ли графический файл в библиотеке символов или на него предоставляется ссылка из исходного каталога.

Обзор основных элементов диалогового окна:

### Исходный каталог не изменять:

В символ вставляется ссылка на графический файл. Изменения в графическом файле будут автоматически обновляться, как только вы откроете символ. При резервном копировании данных можно учитывать файлы со ссылками с помощью соответствующей настройки.

### Сохранить:

Графический файл сохраняется как копия в символе, являясь тем самым частью библиотеки символов. Вставленный таким образом графический файл сохраняется после синхронизации основных данных, передачи библиотек символов или импорта / экспорта символов. Однако, если графический файл изменяется, он не обновляется автоматически.
