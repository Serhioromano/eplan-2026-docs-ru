# Вкладка "Номинальный диаметр"

## Вызов диалогового окна

* **Файл** > **Настройки** > **Пользователь** > **Add-ons** > **Конфигуратор шлангопроводов**. Нажмите на вкладку **Номинальный диаметр**.
* Вы открыли проект. Вы открыли диалоговое окно **Конфигурировать шлангопроводы**. Выберите пункты меню **Дополнительно** > **Настройки**. В последующем диалоговом окне нажмите на вкладку **Номинальный диаметр**.

На этой вкладке определите значения по умолчанию для номинального диаметра используемых шлангов. Сохраненные в таблице значения предлагаются вам на выбор при конфигурировании шлангопроводов в диалоговом окне **Обработать** ++"..."++. Обзор основных элементов диалогового окна:

### Список

Значения номинальных диаметров всегда указываются в "мм". Поэтому их можно вводить без указания единицы измерения. Используйте кнопки панели инструментов над списком для создания новых записей, удаления ненужных и/или обработки имеющихся.

!!! note "Замечание:"

    Если выбрана стандартная схема `DIN 20066_2012-01`, список заполняется значениями по умолчанию из стандарта DIN 20066, которые присвоены стандартному номинальному диаметру шланга "d1".
