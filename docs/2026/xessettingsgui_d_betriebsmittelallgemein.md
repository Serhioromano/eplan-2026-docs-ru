# Диалоговое окно Настройки: Общие (Проекты, Устройства)

## Вызов диалогового окна:

Вы открыли проект. **Файл** > **Настройки** > **Проекты** > "Имя проекта" > **Устройства** > **Общее**.

В данном диалоговом окне задайте общие относящиеся к проекту настройки для устройств, например как должна выполняться синхронизация устройств.

Обзор основных элементов диалогового окна:

Групповое поле синхронизация

### Пустые свойства перезаписывают заполненные:

При синхронизации взаимосвязанных функций свойства одной функции копируются для других функций. Вообщем, значения свойств исходной функции копируются в свойства целевой функции. Этот флажок предназначен для свойств исходных функций, которые не имеют записей. если он активирован, целевая функция принимает пустые записи. Существующие записи целевой функции удаляются. если флажок деактивирован, целевая функция не принимает пустые записи. Существующие записи сохраняются.

### Заполненные свойства перезаписывают пустые:

Этот флажок предназначен для свойств исходных функций, которые имеют записи. если он активирован, целевая функция без записей принимает запись исходной функции. если он деактивирован, целевая функция без записей не принимает запись исходной функции. Целевая функция остается без записи.

### Учитывать макрос при генерировании устройств:

Эта настройка определяет, следует ли при генерировании нового устройства в навигаторах (через пункты всплывающего меню **Новое устройство** и **Новые клеммы (устройства)**) или в графическом редакторе (через центр вставки) из указанного для изделия макроса генерировать функции, которые не размещаются сразу, как неразмещенные функции. По умолчанию флажок снят.

В навигаторах эта настройка действует следующим образом:

Флажки |  Результат
---|---
активировано |  Все функции из макроса генерируются как неразмещенные функции, если они относятся к этому устройству. Если в одном из вариантов макроса функция дублируется, то другие функции из варианта макроса и из всех следующих вариантов не учитываются. Действие не зависит от того, содержит ли изделие шаблоны функций или нет.
деактивировано |  Из первой главной функции, которая записана в шаблонах функции, создается одна неразмещенная функциия. Остальные шаблоны остаются свободными.
Если изделие не содержит шаблоны функций, то в качестве неразмещенной функции генерируется только первая главная функция из макроса.

В Графическом редакторе эта настройка действует в следующем случае:

Изделие содержит шаблоны функции, и задан файл макроса. При этом функции, подходящие к шаблонам, распределяются по нескольким вариантам макроса. При вставке устройств из центра вставки, однако, вставляется только первый (подходящий к типу страниц) вариант макроса.

Флажки |  Результат
---|---
активировано |  Функции из других вариантов макроса, относящиеся к устройству, создаются как неразмещенные функции. Если в одном из вариантов макроса функция дублируется, то другие функции из варианта макроса и из всех следующих вариантов не учитываются.
деактивировано |  Остальные шаблоны, для которых не найдена подходящая функция в первом варианте макроса, остаются свободными.

### Автоматически добавить необходимые принадлежности:

Если этот флажок установлен, то при вставке или генерировании устройств будут одновременно автоматически добавляться необходимые принадлежности. Необходимыми принадлежностями являются (отдельные) изделия принадлежностей, для которых в управлении изделиями на вкладке **Принадлежности** установлен флажок **Необходимый**. Принадлежности из обязательных списков принадлежностей учитываются только в том случае, если для этого списка принадлежностей активировано свойство **Вставить полностью список принадлежностей**.

* Если устройство вставляется, например, через центр вставки в графическом редакторе, то тогда для размещения предлагаются не только функции этого устройства, но и функции необходимых изделий принадлежностей.
* Если неразмещенное устройство генерируется, например, в навигаторе устройств через пункт всплывающего меню **Новое устройство**, то к неразмещенной главной функции этого устройства также добавляются шаблоны функций для необходимых принадлежностей.

После вставки или генерирования устройства в диалоговом окне "Свойства" главной функции на вкладке **Изделие** дополнительно к номеру изделия главной функции также вносятся номера изделий принадлежностей.

Если этот флажок снят, то устройство вставляется или генерируется без принадлежностей. В этом случае принадлежности необходимо сначала добавить через выбор устройства, а затем разместить из навигатора устройств.

### Запустить выбор устройства для выбираемых принадлежностей:

Если установлен флажок **Автоматически добавить необходимые принадлежности**, то при этом можно указать, следует ли автоматически запускать выбор устройства для выбираемых принадлежностей.

Выбираемые принадлежности означают, что у изделия есть как минимум одно изделие принадлежностей, для которого снят флажок **Необходимый**, или для какой-либо принадлежности речь идет о списке принадлежностей. Списки принадлежностей обычно позволяют выбрать изделие принадлежностей из списка возможных альтернативных вариантов. Обязательные списки принадлежностей, для которых активировано свойство **Вставить полностью список принадлежностей**, непосредственно добавляются полностью без выбора устройства.

Если этот флажок установлен, то при вставке или генерировании устройств открывается диалоговое окно **Выбор устройства**. Там уже выбрано подходящее главное изделие. Соответствующее изделие принадлежностей или соответствующие изделия принадлежностей можно выбрать в списке **Принадлежности**, щелкнув в столбце **Выбор** и на ++"..."++.

Если этот флажок снят, то устройство добавляется только с необходимыми принадлежностями, но без выбираемых принадлежностей.

### Выводить изделия в соответствии с их позицией:

Если этот флажок установлен, то данные изделий и ссылок изделий выводятся в соответствии с их позицией, независимо от того, имеются между записями изделий пустые строки или нет. Однако эта настройка не влияет на изделия типа 'Присвоение: источник / цель' и на принадлежности клеммы.

Если этот флажок снят, изделия выводятся независимо от их позиции.
