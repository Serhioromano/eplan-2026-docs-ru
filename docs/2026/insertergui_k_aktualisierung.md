# Обновление центра вставки

Центр вставки автоматически обновляется после следующих событий:

* Добавление или удаление библиотек символов
* Генерирование, обновление и удаление [набора макросов](insertergui_k_makrosammlung.md)
* Изменение данных изделия в базе данных изделий
* Импорт избранного или тегов

!!! note "Замечание:"

    Если набор макросов подлежит обновлению, это отобразится в строке состояния с помощью пиктограммы ![](images/warningicon_systemmessages.png){: .ui-icon }. Одновременно будет выдано соответствующее предупреждение. При нажатии на пиктограмму появится диалоговое окно системных сообщений со списком сообщений. Нажмите на кнопку ++"Закрыть"++, чтобы закрыть диалоговое окно и удалить пиктограмму с предупреждением в строке состояния.
