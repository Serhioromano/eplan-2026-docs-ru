# Шаблоны Excel для внешней обработки

Вы можете создавать шаблоны Excel для экспорта в формат файла Excel. С помощью данных шаблонов можно задавать определенные значения по умолчанию касательно внешнего вида и форматирования таблиц Excel. Выведенные файлы Excel можно редактировать в Microsoft Excel, а также других офисных приложениях, которые читают данный формат. Пример шаблона Excel:

При этом обязательны оба заполнителя на этой таблице ("###" и "#H#").Свойстваво второй таблице "Формат" указывают порядок форматирования различных данных первой таблицы, при этом каждое из них является опцией. При этом действительны следующие присвоения:#H# означает заголовки### означает данные#ID# означает ид. объекта#HD# обозначает автоматически добавленные к выводу данные заголовка (например,определения функцийдля соединений)#F# означает нижние колонтитулы#RO# означает свойства, которые невозможно обработать и перезаписать#RW# означает свойства, которые можно обработать и перезаписать.Если эта информация отсутствует во второй таблице, все свойства форматируются таким же, как ячейка со значением "###".

Заполненные ячейки в таблице Excel указывают формат для соответствующих данных. Порядок отображения данных в Excel определяется настройкой в схеме.

После успешного завершения экспорта все столбцы форматируются по ширине.

В шаблоне можно также сохранять макросы Excel. Они потом копируются также в целевой файл.
