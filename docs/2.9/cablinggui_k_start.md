# Сети соединенных сегментов (топология)

Под топологией в EPLAN понимается область внутри двухмерной обработки [схемы соединений](Glossary_o_anschlussbilder.md), в которой планируются [сети соединенных сегментов](Glossary_o_streckennetze.md) и маршрутизируются [соединения](Glossary_o_verbindungen.md). При этом можно [маршрутизировать](Glossary_o_verlegen.md) любые соединения, [кабели](Glossary_o_kabel.md), шланги и трубы. Укажите для этих соединений [трассы маршрутизации](Glossary_o_verlegewege.md) внутри топологии, по которым должны проходить соединения.

Доступны следующие [действия](Glossary_o_aktionen.md):

* Сеть соединенных сегментов можно создавать независимо от других представлений в проекте. Структуризация сети соединенных сегментов осуществляется через структуру идентификаторов (для страниц, устройств и т. д.).
* Сеть соединенных сегментов можно проектировать как размещенную или неразмещенную, по вашему усмотрению. Для размещения служит тип страницы "Топология".
* У функций и соединений есть дополнительный вид представления "Топология". Соединения с таким видом представления учитываются при синхронизации.
* Через [фильтр](Glossary_o_filter.md) соединений можно управлять тем, какие соединения допускается [прокладывать](Glossary_o_auflegen.md) по трассе маршрутизации.
* При маршрутизации определяется длина проложенного кабеля или соединения.
* На основе сети соединенных сегментов и сгенерированных маршрутизируемых соединений можно [генерировать](Glossary_o_erzeugen.md) ответы, отображающие, например, трассы маршрутизации, [сегменты маршрутизации](Glossary_o_strecken.md) или проходящие через [сегменты](Glossary_o_segmente.md) маршрутизации кабели и соединения.
