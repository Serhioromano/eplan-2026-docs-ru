# Операция: XPamSelectPart

**Параметр** |  **Описание**
---|---
DatabaseId |  Идентификатор базы данных.
SelectedPartsCount |  Выводит количество выбранных изделий.
PartNr(nr) |  Выводит номер выбранных изделий, при этом nr = 1, 2, ...
Variant(nr) |  Выводит [варианты](Glossary_o_varianten.md) выбранных изделий, при этом nr = 1, 2, ...
PartType(nr) |  Выводит тип выбранных изделий, при этом nr = 1, 2, ...

С вашей помощью мы можем улучшить работу системы. Мы документируем ваши действия в Google Analytics, чтобы постоянно совершенствовать справочную систему ([Дополнительная информация и возможности подачи возражений](helpsystem_hinweise_optout.md)).
