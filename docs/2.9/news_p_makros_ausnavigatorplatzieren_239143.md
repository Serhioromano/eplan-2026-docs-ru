# Вставить макросы из навигатора макросов путем перетаскивания мышью

Макросы окон и символов одного проекта макросов теперь можно вставлять из навигатора макросов в открытые страницы другого проекта макросов или [схемы соединений](Glossary_o_anschlussbilder.md) либо того же проекта макросов путем перетаскивания мышью.

![](images/benefit.png)Эффект:

Путем перетаскивания из навигатора макросов можно быстрее и проще вставлять готовые стандартизированные [макросы](Glossary_o_makros.md) в другие [проекты](Glossary_o_projekte.md). Больше нет необходимости в затруднительном выборе макросов из каталога макросов — теперь можно с легкостью использовать макрос из навигатора.

Это действие возможно как для макросов с методом использования "Определяющий", так и для макросов с методом использования "Не задан". Аналогично можно перетаскивать мышью 3D-макросы в открытое [пространство листа](Glossary_o_bauraum.md) проекта. Выбор другого варианта макроса при вставке с помощью перетаскивания мышью ***невозможен***. Многократный выбор макросов при этом также ***невозможен***.

В качестве альтернативы эту операцию в навигаторе макросов можно также выполнить с помощью нового пункта всплывающего меню Вставить макрос.

!!! note "Замечание:"

    Обратите внимание, что при вставке путем перетаскивания мышью или с помощью пункта всплывающего меню Вставить макрос используется состояние макроса в проекте макросов, а не сохраненное состояние макроса в файле макроса. Если обновить вставленный таким образом макрос, будет выполнен [возврат](Glossary_o_zurueckbuchen.md) к состоянию, сохраненному в файле макроса.
