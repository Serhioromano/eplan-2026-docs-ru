# Диалоговое окно Настройки: Сравнение настроек проектов

Вы выбрали базу данных управления проектами. Вы считали каталоги и [проекты](Glossary_o_projekte.md). Проект > Управление. Выделите проект ввода, содержащий прогрессивное состояние проекта. [Дополнительно] > Проверить проект. Щелкните рядом с полем Сравнить настройки по ++...++.

В этом диалоговом окне можно управлять схемами сравнения настроек и обрабатывать их. В такой схеме сохраняются данные о том, какие [настройки](Glossary_o_einstellungen.md) сравнивались между собой в процессе нормоконтроля при проверке проекта с замечаниями и проекта для сравнения.

Обзор основных элементов диалогового окна:

### Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать или обработать. Для этого также воспользуйтесь соседней [панелью инструментов](schemeconfig_m_schemaschaltflaechen.md).

### Сравниваемые настройки:

Отображает все специфические для проекта настройки, которые EPLAN может сравнить при сравнении и проверке проектов в процессе нормоконтроля. Эти настройки соответствуют настройкам, доступным через меню Параметры > Настройки > Проекты > "Имя проекта". Если перед записью флажок установлен, производится проверка того, идентичны ли настройка и все подчиненные настройки [Проекта для сравнения и проекта с замечаниями](processreceiptcontrol_k_projekte.md).
