# Диалоговое окно Настройки: Rittal — Athex

* Параметры > Настройки > Фирма > Автоматическое оснащение > Rittal — Athex
* Сервисные программы > Данные изготовления > Автоматическое оснащение Rittal — Athex. Рядом с полем Машина нажмите ++...++.

В этом диалоговом окне задаются [настройки](Glossary_o_einstellungen.md) экспорта данных для управления системой автоматического оснащения Rittal — Athex для клеммников и последовательных принадлежностей клеммы.

Обзор основных элементов диалогового окна:

### Машина:

В комплекте поставки содержится определение машины с названием "Стандарт". Если в качестве [схемы](Glossary_o_schemata.md) сгенерирована другая машина, можно выбрать из раскрывающегося списка другие определения машины и работать с ними.

Через расположенную рядом [панель инструментов](schemeconfig_m_schemaschaltflaechen.md) можно создавать новые схемы, сохранять изменения в схеме, копировать или удалить схему. Кроме того, схемы можно импортировать и экспортировать.

### Описание:

В этом поле дается описание, которое было введено в диалоговом окне Новая схема в поле Описание для машины.

### Вкладки:

Для [конфигурации](Glossary_o_konfigurationen.md) экспорта для системы автоматического оснащения Rittal — Athex имеются следующие вкладки:

* [Вкладка Общее (Автоматическое оснащение Rittal — Athex)](ncgui_r_allgemeinathas.md)
* [Вкладка Машина (Автоматическое оснащение Rittal — Athex)](ncgui_r_maschineathas.md)
