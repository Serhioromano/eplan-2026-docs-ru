# P017008: ОУ не соответствует настройкам в поле 'Формат нумерации' под проектом > 'Имя проекта' > Устройство > Нумеровать (online), групповое поле 'При вставке символов'

### Причина

Задано обозначение устройства, не соответствующее формату нумерации в режиме подключения.

!!! example "Пример:"

    В проекте для устройств общего назначения настроен формат нумерации в режиме подключения "Буквенное обозначение + счетчики". В отличие от данного формата нумерации обозначение устройства-FAприсвоено размещенному на схемесоединенияпредохранителю. Так как за "F" следует "A", не являющееся числом, то оно внутри программы присваивается буквенному обозначению. Неверный счетчик приводит к выводу сообщения.

### Решение

1. Определите местоположение соответствующего ОУ в проекте с помощью функции Перейти к (...), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Вызовите диалоговое окно свойств функции и щелкните на первой вкладке рядом с полем Полное ОУ [...].
3. В диалоговом окне Полное ОУ просмотрите состав значений в групповом поле ОУ (поля Предш. цифра, Буквенное обозначение, Счетчик и Подсчетчик) и при необходимости отметьте их.
4. Закройте диалоговое окно "Свойства".
5. Выберите пункты меню Параметры > Настройки > Проекты > "Имя проекта" > Устройствo > Нумерация (онлайн).
6. В диалоговом окне Настройки: Нумерация (online) в групповом поле При вставке символов нажмите кнопку ++...++ рядом с раскрывающимся списком Формат нумерации.
7. Отобразите в диалоговом окне Форматы нумерации для используемых схем формат ОУ устройства, который привел к выводу сообщения.
8. Для этого нажмите кнопку ++...++ соответствующего типа устройств, например в поле Устройства общего назначения.
9. В диалоговом окне Формат ОУ просмотрите выбор элементов формата и их позиции.
10. Сравните формат ОУ с составом ОУ устройства, которое было ранее отмечено.
11. Закройте все диалоговые окна в настройках и измените обозначение устройства функции относительно настроенных элементов формата для нумерации в режиме подключения.
12. Затем запустите новый контрольный прогон.

!!! note "Замечание:"

    Следующее проверяется в ОУ относительно формата нумерации в режиме подключения при вставке символов.

* Наличие числа в ОУ, если соответствующий элемент формата относится к типу "Счетчик".
* Наличие правильного имени страницы в ОУ после размещения функции в схеме соединений, если формат нумерации "Страница + буквенное обозначение + счетчик" настроен.
