# Корректировка проекта

В ходе проектирования часто генерируются [данные проекта](Glossary_o_projektdaten.md), которые в конце проектирования требуют корректировки. Поэтому для определенных данных (клемм, штекеров и т. д.) можно запустить корректировочные прогоны, в ходе которых автоматически корректируются обнаруженные ошибки. При этом учитываются только многополюсные [функции](Glossary_o_funktionen.md).

* Вы можете задать, какие данные проекта должны быть откорректированы.
* Данные проекта корректируются для всего проекта. Вы можете определить [фильтр](Glossary_o_filter.md) для исключения корректировки данных проекта или для корректировки только выбранных уровней иерархии.
* Настройки объема корректировки сохраняются в схеме. Благодаря этому [настройки](Glossary_o_einstellungen.md) могут использоваться повторно.
