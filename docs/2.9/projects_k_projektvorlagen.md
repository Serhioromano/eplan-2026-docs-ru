# Шаблоны проектов

Шаблоны проектов — шаблоны, из которых можно создавать новые [проекты](Glossary_o_projekte.md). При этом все данные шаблона проекта копируются в новый проект.

Тип файла |  Значение
---|---
Шаблон проекта EPLAN (*.ept) |  ***Шаблон проекта / файл *.ept:*** Из файла *.ept можно создавать новые проекты; также можно сохранять проекты EPLAN как файлы *.ept.
Шаблон проекта EPLAN (*.epb) |  ***Шаблон проекта / файл *.epb:*** Далее из файла *.epb можно [создать](Glossary_o_erstellen.md) новый проект. Но создать из проекта EPLAN файл *.epb невозможно. Для этого используйте файл *.ept или *.zw9.

Шаблон проекта может содержать следующие [настройки](Glossary_o_einstellungen.md) проекта и [данные проекта](Glossary_o_projektdaten.md).

* ***Все настройки проекта:*** Настройки проекта — это настройки в диалоговом окне Параметры > Настройки > Проекты > "Имя проекта". Сюда относятся также и [схемы](Glossary_o_schemata.md) структуры страниц и устройств.
* ***Все данные проекта:*** Данные проекта, например неразмещенные и размещенные на страницах [устройства](Glossary_o_betriebsmittel.md).
* ***Все страницы:*** Копируются все страницы базового проекта, находящиеся в шаблоне проекта.

!!! tip "Совет:"

    Если необходимо из проекта, содержащего страницы, создать шаблон проекта, не содержащий страницы, скопируйте проект. Удалите страницы из копии проекта и создайте шаблон проекта.
