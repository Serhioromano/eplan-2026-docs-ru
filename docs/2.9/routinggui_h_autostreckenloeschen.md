# Удалить автоматические сегменты маршрутизации

При создании [сети соединенных сегментов](Glossary_o_streckennetze.md) автоматические [сегменты маршрутизации](Glossary_o_strecken.md) генерируются внутри кабельных каналов, на концах и в качестве перемычек в зазорах между кабельными каналами. Эти автоматические [сегменты](Glossary_o_segmente.md) маршрутизации нельзя выделить для обработки. Если вы хотите, чтобы трасса маршрутизации определялась исключительно сегментами маршрутизации, размещенными вручную, автоматические сегменты маршрутизации можно удалить из сети соединенных сегментов перед началом маршрутизации.

Условие:

Вы открыли проект. Открыто одно [пространство листа](Glossary_o_bauraum.md). Вы рассчитали [сеть](Glossary_o_netze.md) соединенных сегментов в открытом пространстве листа.

1. Выберите пункты меню Данные проекта > Соединения > Удалить автоматические сегменты маршрутизации.

!!! info "Для сведения:"

    Все автоматические сегменты маршрутизации кабельных каналов будут удалены из открытого пространства листа.
