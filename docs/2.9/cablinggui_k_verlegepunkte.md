# Точки маршрутизации топологии

Точки маршрутизации — это особые места в [сети соединенных сегментов](Glossary_o_streckennetze.md), такие как повороты, проломы в стенах, [смещение](Glossary_o_offset.md), выпуск в пути, [отверстия](Glossary_o_bohrungen.md) электрошкафа и т. д. Точки маршрутизации не обязательно состоят из какого-либо материала.

Точка маршрутизации служит для входа [соединения](Glossary_o_verbindungen.md) к цели, для разветвления на несколько сегментов или для соединения сегментов маршрутизации. Сегменты маршрутизации всегда заканчиваются на точке маршрутизации, т.е. точка маршрутизации прерывает [сегменты маршрутизации](Glossary_o_strecken.md).

Точка маршрутизации может иметь не более одного вывода [устройства](Glossary_o_betriebsmittel.md) топологии, по умолчанию используется точка вставки как вывод устройства.

!!! example "Пример:"

    На следующем рисунки показаныфункциитопологии,сегментымаршрутизации иточки маршрутизации:Цифры означают следующее: (1) функция топологии, (2) точка маршрутизации, (3) автоматически генерированный сегмент маршрутизации, (4) сегмент маршрутизации, вставленный вручную.

### Точки маршрутизации структурного идентификатора

Точки маршрутизации структурного идентификатора — это точки маршрутизации с определением функции "Точка маршрутизации структурного идентификатора топологии". Точка маршрутизации структурного идентификатора объединяет в себе определенную структуру обозначений и подключенные функции топологии. В одной точке маршрутизации структурного идентификатора можно [генерировать](Glossary_o_erzeugen.md) функции топологии вручную и автоматически.

С помощью точек маршрутизации структурного идентификатора можно [прокладывать](Glossary_o_auflegen.md) соединения между различными структурами обозначений, не размещая подключенные функции топологии. Таким образом можно, например, прокладывать кабель между различными электрошкафами, не распознавая все подключенные устройства или не размещая их по отдельности.
