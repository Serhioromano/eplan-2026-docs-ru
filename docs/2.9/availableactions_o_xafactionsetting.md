# Операция: XAfActionSetting

**Параметр** |  **Описание**
---|---
set |  Имя [настройки](Glossary_o_einstellungen.md), которую необходимо установить.
index |  Индекс настройки (не обязательно). Если индекс не указан, используется 0.
value |  Новое значение настройки.

!!! example "Пример:"

    XAfActionSetting
/set:USER.SYSTEM.GUI.SHOW_PROPERTY_NR
/value:1В этом примере устанавливается специфическая для пользователя настройка интерфейса Отображать идентифицирующие номера.

С вашей помощью мы можем улучшить работу системы. Мы документируем ваши действия в Google Analytics, чтобы постоянно совершенствовать справочную систему ([Дополнительная информация и возможности подачи возражений](helpsystem_hinweise_optout.md)).
