# Проводной монтаж

EPLAN оказывает поддержку при проектировании проводного монтажа и его компонентов, а также при управлении ими. С помощью [функции](Glossary_o_funktionen.md) импорта в EPLAN Harness proD можно импортировать созданный [проводной монтаж](Glossary_o_kabelbaeume.md) и его компоненты в [проекты](Glossary_o_projekte.md) EPLAN и там обрабатывать и анализировать их. Проводной монтаж и его компоненты можно снова экспортировать для повторной обработки в EPLAN Harness proD.

Возможно следующее:

* Созданный с помощью EPLAN Harness proD проводной монтаж можно импортировать в проект на платформе EPLAN.
* Проводной монтаж можно [генерировать](Glossary_o_erzeugen.md) с предварительно заданными свойствами или вставить в качестве символа на схему соединений.
* Проводному монтажу можно присваивать другие функции, [соединения](Glossary_o_verbindungen.md) или изделия, а также убирать из него имеющиеся присвоения.
* Изделия, внесенные на определения проводного монтажа и его компоненты, можно выводить в отчетах или использовать для экспорта данных изготовления / маркировки.
* Проводной монтаж можно экспортировать для последующей обработки в EPLAN Harness proD.
