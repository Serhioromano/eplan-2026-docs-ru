# Операция: XEGActionInsertSymRef

**Параметр** |  **Описание**
---|---
SymbolLibName  |  Имя [библиотеки символов](Glossary_o_symbolbibliotheken.md), в которой содержится символ
SymbolId |  Номер символа, который следует вставить
VariantId  |  Номер варианта, если у символа есть [варианты](Glossary_o_varianten.md)
FctDefTag  |  Идентификатор определения [функции](Glossary_o_funktionen.md) для поиска вставляемого символа
Placementmode  |  Идентификатор вида представления для поиска вставляемого символа. Строка, которая определяет вид представление символа. Возможные значения:

* all: Многополюсный
* single: Однополюсный
* paircrossreference: Парная перекрестная ссылка
* overview: Обзор
* graphics: Графика
* processandinstdiagram: Функциональная схема автоматизации
* cabling: Топология
* functional: Функциональный.

SymbolType  |  Идентификатор типа символа для поиска вставляемого символа
CustomSymbols  |  Имя специфической для проекта [настройки](Glossary_o_einstellungen.md) для загрузки вставляемого символа клиента.

!!! note "Замечание:"

    Данная операция использует [главное окно](Glossary_o_hauptfenster.md). Если указанный символ не найден, откроется диалоговое окно Выбор символа.

!!! example "Пример:"

    XEGActionInsertSymRef
/SymbolLibName:IEC_symbol
/SymbolId:55
/VariantId:0
