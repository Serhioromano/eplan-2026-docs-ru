# Операция: MfImportToolbarAction

**Параметр** |  **Описание**
---|---
File  |  Импортируемый XML-файл, включая путь файла.
Replace  |  Имеющиеся одноименные [панели инструментов](Glossary_o_symbolleisten.md) заменяются.

!!! note "Замечание:"

    Данная операция использует [главное окно](Glossary_o_hauptfenster.md).

!!! example "Пример:"

    MfImportToolbarAction
/File:"?"
/Replace:Yes

С вашей помощью мы можем улучшить работу системы. Мы документируем ваши действия в Google Analytics, чтобы постоянно совершенствовать справочную систему ([Дополнительная информация и возможности подачи возражений](helpsystem_hinweise_optout.md)).
