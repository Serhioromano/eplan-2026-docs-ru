# Диалоговое окно <Блок идентификаторов> (<Имя проекта>) / Диалоговое окно Идентификатор объекта

Вы открыли проект.

* Вы открыли диалоговое окно "Свойства" для [функции](Glossary_o_funktionen.md). Вы щелкнули мышкой на вкладке <Категория функции> в поле Полное ОУ по кнопке ++...++. В диалоговом окне Полное ОУ в таблице Структурный идентификатор вы щелкнули в поле столбца Видимое по кнопке ++...++.
* Вы открыли диалоговое окно Свойства страницы для страницы. В поле Полное имя страницы вы щелкнули по кнопке ++...++, а в следующем диалоговом окне — в поле Значение структурного идентификатора — по кнопке ++...++.

Вы открыли проект, для которого выбран идентификатор объекта для структурирования страниц (диалоговое окно Структура страниц в свойствах проекта). Вы открыли диалоговое окно Свойства страницы для страницы. В поле Полное имя страницы вы щелкнули мышкой по кнопке ++...++, а в следующем диалоговом окне в поле Значение структурного идентификатора "Идентификатор объекта" — по кнопке ++...++.

В этом диалоговом окне выберите [структурный идентификатор](Glossary_o_strukturkennzeichen.md), который уже был определен в проекте для соответствующего блока идентификаторов, или выберите структурный идентификатор, который следует использоваться как идентификатор объекта.

Обзор основных элементов диалогового окна:

В представлении структуры дерева или в представлении в виде списка отображаются структурные идентификаторы с описанием их структуры, которые уже были определены в проекте для соответствующего блока идентификаторов. Кроме того, в диалоговом окне Идентификатор объекта, в левой части диалогового окна отображаются уже имеющиеся в проекте [блоки идентификаторов](Glossary_o_kennzeichnungsbloecke.md).

### Фильтр:

В этом раскрывающемся списке отображаются все доступные фильтры. Выбранный [фильтр](Glossary_o_filter.md) активируется автоматически и применяется как к дереву, так и к списку. Запись "- Не активировано -" отключает фильтр и приводит к тому, что данные отображаются в неотфильтрованном виде. С помощью кнопки ++...++ откройте диалоговое окно [Фильтр](modaldialogsdb_d_filternnach.md). Здесь можно [создать](Glossary_o_erstellen.md), обработать, удалить, скопировать, экспортировать, импортировать фильтр и управлять им.

Во всплывающем меню раскрывающегося списка Фильтр содержатся следующие записи:

* Выключить: Этот пункт меню доступен, если фильтр установлен: Сбрасывает настройку фильтра до записи "- Не активировано -".
* Активировать <Имя фильтра>: Этот пункт меню доступен, если для [настройки](Glossary_o_einstellungen.md) фильтра установлено значение "- Не активировано -": Повторно активирует последний активный фильтр.

Таким образом можно быстро переключаться между неотфильтрованным и отфильтрованным в соответствии с требованиями пользователя представлениями.
