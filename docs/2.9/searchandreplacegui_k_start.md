# Найти и заменить

Во время проектирования и при сравнении ревизий часто требуется целевой поиск информации в проекте, чтобы дополнительно обработать их. Возможно следующее:

* Можно искать тексты, [обозначения](Glossary_o_bezeichnungen.md) устройств, [символы](Glossary_o_symbole.md), [кабели](Glossary_o_kabel.md), [кабельные соединения](Glossary_o_kabelverbindungen.md), [потенциалы](Glossary_o_potenziale.md), [макросы](Glossary_o_makros.md), [основные данные](Glossary_o_stammdaten.md), данные заголовка страницы, данные заголовка проекта, [свойства](Glossary_o_eigenschaften.md) (данные форматирования) и т. д. по всему проекту или на определенных страницах.
* При поиске можно использовать заполнители.
* Структурные идентификаторы можно учитывать при поиске.
* При поиске также учитываются невидимые [объекты](Glossary_o_objekte.md) и [уровни](Glossary_o_etagen.md).
* Результаты поиска записываются в списки результатов. С помощью этих списков возможны следующие [действия](Glossary_o_aktionen.md): Так, например, вы можете открывать диалоговое окно свойств для одного выделенного объекта и обрабатывать его свойства.
* Можно синхронизировать отображения между открытыми навигаторами.
