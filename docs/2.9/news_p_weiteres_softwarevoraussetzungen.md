# Общие условия

Для работы платформы EPLAN необходима платформа .NET Framework 4.7.2 корпорации Microsoft. Более подробную информацию по этим компонентам Microsoft и их текущую версию для скачивания можно найти на веб-страницах Microsoft.

Дополнительные сведения о поддерживаемых операционных системах и выпусках программного обеспечения см. по адресу:
<https://www.eplan.help/ru-RU/Infoportal/Content/htm/portal_software_approvals.htm>

С вашей помощью мы можем улучшить работу системы. Мы документируем ваши действия в Google Analytics, чтобы постоянно совершенствовать справочную систему ([Дополнительная информация и возможности подачи возражений](helpsystem_hinweise_optout.md)).
