# Диалоговое окно Настройки: Кабель (автоматически)

Вы открыли проект. Параметры > Настройки > Проекты > "Имя проекта" > Устройство > Кабель (автоматически).

В этом диалоговом окне задаются предварительные [настройки](Glossary_o_einstellungen.md), используемые для автоматически генерированных кабелей.

Обзор основных элементов диалогового окна:

### Генерация кабеля:

Выбранная здесь схема определяет, где должны быть размещены [свойства](Glossary_o_eigenschaften.md) кабелей и какие [кабельные соединения](Glossary_o_kabelverbindungen.md) должны учитываться при генерации кабелей. С помощью кнопки ++...++ откройте диалоговое окно [Настройки: Генерация кабеля](cablegui_d_einstellungenkabelerzeugen.md), в котором можно обработать [схемы](Glossary_o_schemata.md) и управлять ими.

### Нумерация кабелей:

Выбранная здесь схема определяет, в какой последовательности выполняется нумерация кабелей, какие свойства будут отображаться в ОУ кабеля и каким образом будет осуществляться их форматирование. С помощью кнопки ++...++ откройте диалоговое окно [Настройки: Нумерация кабелей](cablegui_d_einstellungenkabelnummerierung.md), в котором можно обработать схемы и управлять ими.

### Автоматический выбор кабеля:

Выбранная здесь схема определяет критерии для автоматического выбора кабеля. С помощью кнопки ++...++ откройте диалоговое окно [Настройки: Автоматический выбор кабеля](cablegui_d_einstellungenautomatischekabelauswahl.md), в котором можно обработать схемы и управлять ими.
