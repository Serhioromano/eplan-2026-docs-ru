# Внешние отчеты

При помощи [функции](Glossary_o_funktionen.md) "Экспорт / маркировка" возможно [генерировать](Glossary_o_erzeugen.md) внешние [отчеты](Glossary_o_auswertungen.md). При этом [данные проекта](Glossary_o_projektdaten.md) анализируются, как при экспорте / маркировке, и выводятся в файле отчетов.

!!! warning "Предупреждение:"

    Обязательным условием для создания в EPLAN файлов в формате Microsoft Office является наличие установленных на компьютере следующих разрешенных EPLAN программных продуктов.

* [Экспорт данных изготовления / маркировка](labelgui_k_start.md)
* [Файл экспорта / маркировки / Внешний файл отчетов](labelgui_k_aufbaubeschriftung.md)
* [Экспорт данных изготовления / маркировка: Способ действий](labelgui_k_vorgehensweise.md)
* [Создать схему экспорта / маркировки](labelgui_h_beschriftungsschema.md)
С вашей помощью мы можем улучшить работу системы. Мы документируем ваши действия в Google Analytics, чтобы постоянно совершенствовать справочную систему ([Дополнительная информация и возможности подачи возражений](helpsystem_hinweise_optout.md)).
