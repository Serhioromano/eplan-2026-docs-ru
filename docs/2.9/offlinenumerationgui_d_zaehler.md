# Диалоговое окно <Элемент формата>

Вы открыли проект. Параметры > Настройки > Проекты > "Имя проекта" > Устройства > Нумеровать (автономно). В диалоговом окне Настройки: Нумеровать (автономно) выбрана пользовательская схема. Щелкните два раза в поле Доступные элементы формата или Выбранные элементы формата по элементу формата для просмотра [свойства](Glossary_o_eigenschaften.md).

В этом диалоговом обрабатываются выбранные [элементы формата](Glossary_o_formatelemente.md).

Обзор основных элементов диалогового окна:

### Минимальное число разрядов:

Значение в этом поле указывает на минимальное используемое число разрядов.

### Заполнитель:

Отсутствующие места заполняются этим символом. То, сколько разрядов заполняется, зависит от значения, введенного в поле Мин. число разрядов.

!!! example "Пример:"

    Если в поле Мин. число разрядоввведено значение '4', а в поле Заполнитель— значение '0', нумерация выглядит следующим образом: '0001'.

### Счетчик явл. подсчетчиком:

Это поле присутствует только у элементов формата типа 'Счетчик'.

Если этот флажок установлен, при изменении остальной нумерации счетчик каждый раз будет начинать отсчет с начального значения.
Если флажок не установлен, счетчик независимо от других символов будет продолжать нумерацию.

### Использовать алфавитно-числов. счетчик:

Это поле присутствует только у элементов формата типа 'Счетчик'.

Если установлен этот флажок, применяется алфавитно-числовой счетчик. Если флажок снят, применяется числовой счетчик.

### Алфавитно-числовой счетчик:

Это поле присутствует только у элементов формата типа 'Счетчик'.

При использовании алфавитно-числового счетчика здесь необходимо определить [символы](Glossary_o_symbole.md), которые будут использоваться для счетчика. Разрешается использовать только буквы и цифры.

Алфавитно-числовые счетчики сортируются по символам слева направа (как в столбцах в Excel). Например, если предварительно заданы символы "Тех. марк.", то счет осуществляется следующим образом: A, K, S, AA, AK, AS, KA, ..., AAA, AAK, AAS, AKA ..., AAAA, AAAK, ...
