# Обзор свойств изделий EPLAN

В файле [конфигурации](Glossary_o_konfigurationen.md) festo.cfg можно задать присвоение свойств изделий Festo свойствам изделий EPLAN. На вкладках [базы данных изделий](Glossary_o_artikeldatenbanken.md) EPLAN можно ввести эти [свойства](Glossary_o_eigenschaften.md).

В справке [База данных изделий: Импорт и экспорт CSV для изделий](partsmanagementgui_k_konfigurationcsvartikel.md) найдите отсортированные по обозначениям вкладок свойства изделий. А в справке "Свойства EPLAN" (под обзорами) можно отобразить внутренние свойства EPLAN для класса объекта "Изделие (вложенное)" отсортированными в алфавитном порядке.

**См. также:**

* [Свойства EPLAN](properties_k_prinzip.md)
* [Файл конфигурации для импорта изделий Festo](festocatalog_k_zuordnungsdatei.md)
