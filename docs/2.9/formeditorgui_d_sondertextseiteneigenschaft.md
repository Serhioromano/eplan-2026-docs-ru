# Диалоговое окно Свойства (спец. текст): Свойства страницы

Вы открыли проект. Сервисные программы > Основные данные > Рамка / Форма > Открыть > [Открыть].

* Вставить > Спец. текст > Свойства страницы.
* Вы дважды щелкнули по свойству страницы (или выбрали Всплывающее меню > Свойства; в этом случае могут быть выделены также несколько свойств страницы).

В этом диалоговом окне выберите свойство страницы, которое должно быть добавлено в форму или рамку, и установите его [свойства](Glossary_o_eigenschaften.md) для [формы](Glossary_o_formulare.md), языка и [рамки](Glossary_o_normblaetter.md). Эти [специальные тексты](Glossary_o_sondertexte.md) заполняются в соответствии с введенными данными программы.
