#  Компоновка электрошкафа 2D

Наряду с созданием схем соединений с соответствующими схемами и списками, программа также позволяет проектировать [устройства](Glossary_o_betriebsmittel.md) электрошкафов и [монтажные платы](Glossary_o_montageplatten.md). При этом монтажные платы можно создавать только на страницах проекта типа "Компоновка электрошкафа".

Для [обозначения](Glossary_o_bezeichnungen.md) функциональных элементов монтажной платы используются графические [объекты](Glossary_o_objekte.md) или так называемые "объединенные [макросы](Glossary_o_makros.md)". которые надо [создать](Glossary_o_erstellen.md) и [сохранить](Glossary_o_einlagern.md) в основных данных [базы данных изделий](Glossary_o_artikeldatenbanken.md).

В дополнение к монтажной плате возможно создание легенд функциональных элементов, которые различным образом встраиваются в проект.
