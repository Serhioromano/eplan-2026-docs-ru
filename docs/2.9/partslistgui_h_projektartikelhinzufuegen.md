# Добавить покупные изделия

Изделиями проекта являются изделия, которые ***не*** присвоены специальному устройству, как, напр., комплектующие детали.

Условие:

Вы открыли проект.

1. Выберите следующие пункты меню: Данные проекта > Устройство / изделие > Навигатор спецификаций
2. В диалоговом окне Спецификация — <Имя проекта> выберите пункт всплывающего меню Добавить покупные изделия.
3. В диалоговом окне Выбор изделия выберите добавляемое [изделие](Glossary_o_artikel.md)(я). Возможен многократный выбор.
4. Щелкните по кнопке ++OK++.

!!! info "Для сведения:"

    Новые [покупные изделия](Glossary_o_projektartikel.md) вводятся в дереве с сортировкой по алфавиту.

!!! note "Замечание:"

    Могут быть использованы все [функции](Glossary_o_funktionen.md) диалогового окна Выбор изделия, при этом учитываются предварительные [настройки](Glossary_o_einstellungen.md), специфические для [базы данных изделий](Glossary_o_artikeldatenbanken.md).

С вашей помощью мы можем улучшить работу системы. Мы документируем ваши действия в Google Analytics, чтобы постоянно совершенствовать справочную систему ([Дополнительная информация и возможности подачи возражений](helpsystem_hinweise_optout.md)).
