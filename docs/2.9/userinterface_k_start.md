# Интерфейс пользователя

Интерфейс пользователя EPLAN позволяет выполнять следующие [действия](Glossary_o_aktionen.md):

* Вызывать все [функции](Glossary_o_funktionen.md) программы, используя клавиатуру и мышь.
* По своему усмотрению изменять сочетания клавиш.
* Настраивать [панели инструментов](Glossary_o_symbolleisten.md).
* Фильтровать записи данных.
* Определять, создавать и изменять [схемы](Glossary_o_schemata.md) для фильтров и других настроек.
* Настраивать EPLAN для работы на нескольких мониторах.
* Определять последовательность отображения и сортировки данных.
