# Вкладка Определение функции

Сервисные программы > Изделие > Управление. Вы отметили в дереве или в списке [изделие](Glossary_o_artikel.md) из главной группы продуктов Механика. Выберите вкладку Определение функции.

Изделия из главной группы продуктов Механика вместо вкладки Шаблоны функций имеют вкладку Определение функции. На этой вкладке настроено присвоение определения [функции](Glossary_o_funktionen.md) механических функциональных элементов группе продуктов в базе данных изделий.

Обзор основных элементов диалогового окна:

### Определение функции:

Настроенное здесь определение функции отображается также в диалоговом окне Свойства (условное обозначение): Размещение изделия (3D).

### Функциональный элемент:

Группа продуктов внутри главной группы продуктов Механика, присвоенная определению функции изделия.

Настроенная здесь [группа продуктов](Glossary_o_produktgruppen.md) отображается также в диалоговом окне Свойства (условное обозначение): Размещение изделия (3D).
