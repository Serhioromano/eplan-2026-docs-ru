# Автоматически оптимизировать сети

Во время автоматической оптимизации [соединения](Glossary_o_verbindungen.md) сети / [шлейфы](Glossary_o_verbindungsketten.md) преобразуются так, чтобы следующие условия были выполнены:

* Все остальные [выводы устройства](Glossary_o_anschluesse.md) подключены.
* Минимально возможная сумма прокладываемых проводов.
* Максимум два соединения оканчиваются у одного вывода [устройства](Glossary_o_betriebsmittel.md).
* Всегда генерируется один шлейф.

При автоматической оптимизации все соединения сети получают [свойства](Glossary_o_eigenschaften.md) (в том числе определение [функции](Glossary_o_funktionen.md)) первого соединения. Фиксированные соединения (перемычки, [прямые соединения](Glossary_o_direktverbindungen.md), внутренние соединения) остаются; их нельзя оптимизировать.

Условие:

Сгенерированы [маршрутизируемые соединения](Glossary_o_verlegeverbindungen.md). В навигаторе пространства листа или в навигаторе соединений выделен компонент, содержащий маршрутизируемые соединения (пространства листа, электрошкафы, [монтажные поверхности](Glossary_o_montageflaechen.md), трехмерные [размещения изделий](Glossary_o_artikelplatzierungen.md), соединения).

1. Выберите пункты меню Данные проекта > Соединения > Автоматически оптимизировать сети.

!!! info "Для сведения:"

    Если не выбрана ни одна [сеть](Glossary_o_netze.md) или выбрана неполная сеть, появится сообщение об ошибке. В этом случае повторите и измените выбор.

2. В диалоговом окне Автоматически оптимизировать сети выберите [настройки](Glossary_o_einstellungen.md) для оптимизации сетей.
3. Щелкните по кнопке ++OK++.

!!! info "Для сведения:"

    Проводится анализ сетей.

!!! info "Для сведения:"

    Отобразится диалоговое окно Автоматически оптимизировать сети: Предв. просмотр результата. В диалоговом окне отображаются результаты анализа. Соединения, найденные с помощью оптимизации, автоматически маршрутизируются заново с помощью клавиши ++OK++.

4. В диалоговом окне Автоматически оптимизировать сети: Предв. просмотр результата щелкните по ++OK++.

!!! info "Для сведения:"

    Соединения со статусом 'новые' будут проложены по новым трассам маршрутизации.
