# Диалоговое окно Настройки: Глубина предварительного планирования

Вы открыли проект. Параметры > Настройки > Проекты > "Имя проекта" > Предварительное планирование > Глубина предварительного планирования.

В этом диалоговом окне определите [контрольные прогоны](Glossary_o_prueflaeufe.md) для различных видов сегментов. Для этого задайте обязательные [свойства](Glossary_o_eigenschaften.md), т. е. свойства, которые обязательно должны быть заполнены для данных сегментов. Обязательными могут быть как свойства EPLAN, так и свойства, определенные пользователем.

Для обязательных свойств проверяется, внесено ли значение, активировано ли свойство и не выбрана ли в раскрывающемся списке запись "Неопред.".

Для выполнения контрольных прогонов, в схеме контрольных прогонов необходимо задать для нужных контрольных прогонов вид проверки.

Доступны следующие элементы диалогового окна:

В таблице имеются следующие столбцы:

* Строка: непрерывный номер строки.
* Имя: Укажите здесь имя контрольного прогона, например нужную ступень предварительного планирования. Это имя отображается в управлении сообщениями как текст соответствующего [сообщения контрольного прогона](Glossary_o_prueflaufmeldungen.md).
* Определение сегмента: Выберите в раскрывающемся списке, для какого вида сегментов вы хотите задать обязательные свойства. При этом при выборе отдельного определения сегмента проверяются только [сегменты](Glossary_o_segmente.md) одного вида (например, только [измерительные контуры](Glossary_o_messstellen.md)), при выборе определения базового сегмента — сегменты определенной категории (например, все [технологические контуры](Glossary_o_plt_stellen.md), к которым относятся как измерительные [контуры](Glossary_o_konturen.md), так и [исполнительные механизмы](Glossary_o_verbraucherstellen.md)), а при выборе записи "Все" — все сегменты.
* Обязательное свойство 1... 10: Для каждого контрольного прогона можно задать до десяти обязательных свойств. Если щелкнуть в ячейке по клавише ++...++, откроется диалоговое окно Выбор свойств и в нем можно будет выбрать нужное свойство.
