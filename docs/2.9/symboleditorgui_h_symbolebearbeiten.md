# Обработать символы

Условие:

Вы открыли проект и как минимум одну библиотеку символов.

1. Выберите следующие пункты меню: Сервисные программы > Основные данные > Символ > Открыть
2. В диалоговом окне Выбор символа выберите [символы](Glossary_o_symbole.md), которые следует обработать.
3. Щелкните для более быстрого выбора при необходимости по ++...++ в поле Фильтр, и выберите критерии фильтра, или определите новые.
4. Или введите в поле Прямой ввод***Представления в виде списка*** символьную строку.

!!! info "Для сведения:"

    Курсор немедленно после ввода первого знака перемещается к символу, который начинается с этого знака, и выделяет его.

5. Выберите в ***Представлении в виде дерева*** пункт всплывающего меню С ориентацией на функцию, если иерархическое представление символов должно производиться не по библиотеке символов, а по функциональной категории (например "Катушки и контакты", "Сигнальные [устройства](Glossary_o_betriebsmittel.md)" и т. д.).
6. Выберите в ***Представлении в виде списка*** пункт всплывающего меню Конфигурировать представление, если требуется изменить отображение и / или последовательность свойств символов в списке.
7. Щелкните по кнопке ++OK++.
8. Обработайте графику символа, т. е. добавьте [выводы устройства](Glossary_o_anschluesse.md) и дополните графической и функциональной информацией.

!!! info "Для сведения:"

    Каждый открытый символ отображается в отдельном графическом редакторе, причем всегда учитывается первый имеющийся вариант символа. Обмен данными между несколькими открытыми символами может при этом выполняться через буфер обмена.

!!! info "Для сведения:"

    Предварительные [настройки](Glossary_o_einstellungen.md) для свойств линий (тип, толщина, цвет...), а также специфичные для отображения [свойства](Glossary_o_eigenschaften.md) [обозначения](Glossary_o_bezeichnungen.md) вывода устройства и описания вывода устройства берутся из соответствующих слоев (Данные проекта > Управление слоями > Графика символа / Данные проекта > Управление слоями > Размещение свойства).

!!! note "Замечание:"

* Используемая [сетка](Glossary_o_raster.md) запоминается в свойствах [библиотеки символов](Glossary_o_symbolbibliotheken.md) и, следовательно, действительна для всех символов данной библиотеки символов.
* Точка вставки символа может быть только сдвинута, но не удалена, так как она обозначает место, на котором символ будет прикреплен к курсору при размещении. Кроме того, точка вставки является определяющей для позиции символа и, тем самым, также для перекрестной ссылки.

С вашей помощью мы можем улучшить работу системы. Мы документируем ваши действия в Google Analytics, чтобы постоянно совершенствовать справочную систему ([Дополнительная информация и возможности подачи возражений](helpsystem_hinweise_optout.md)).
