# Схемы

Схема — это группа настроек, которые сохраняются под определенным именем. Для большинства настроек существуют стандартные [схемы](Glossary_o_schemata.md) EPLAN, которые нельзя обрабатывать. Они создаются во время установки в собственном каталоге (по умолчанию в меню \Схемы\<Идентификатор фирмы> на дисководе и в каталоге, в котором произведена [установка](Glossary_o_anlage.md) EPLAN). Так, например, существуют схемы для экспорта данных изготовления, настроек нумерации для [устройства](Glossary_o_betriebsmittel.md), кабелей и т. д., рабочих областей и т. п.

Чтобы задать собственные [настройки](Glossary_o_einstellungen.md), можно [создать](Glossary_o_erstellen.md) определенные пользователем схемы: С помощью [панели инструментов](schemeconfig_m_schemaschaltflaechen.md), расположенной рядом с полем Схема, можно создавать новые схемы, сохранять изменения в них, копировать или удалять. Кроме того, схемы можно импортировать и экспортировать. При импорте возможен многократный выбор схем, а при экспорте — нет.
