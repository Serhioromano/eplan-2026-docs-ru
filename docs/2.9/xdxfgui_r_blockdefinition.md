# Вкладка Определение блока

* Параметры > Настройки > Пользователь > Интерфейсы > Экспорт и импорт DXF / DWG. Выберите вкладку Определ. блока.
* Страница > Экспортировать > DXF/DWG. Щелкните рядом с полем Схема по кнопке ++...++. Выберите вкладку Определ. блока.

Определите на этой вкладке, как [блоки](Glossary_o_bloecke.md) должны учитываться при экспорте.

Обзор основных элементов диалогового окна:

Групповое поле 'Динамические отчеты'

При экспорте в формате [DXF](Glossary_o_dxf.md)/[DWG](Glossary_o_dwg.md) динамические и подчиненные области форм объединяются и копируются как блоки. Задайте здесь префиксы обозначений на область, например "ВЕРХ" для верхнего колонтитула.

* * *

Групповое поле 'Свойства блока'

В этом групповом поле можно выполнить следующие [настройки](Glossary_o_einstellungen.md):

* Экспортировать невидимые атрибуты: установите этот флажок, если необходимо экспортировать ***все*** специфические для AutoCAD атрибуты функционального элемента, в том числе невидимые.
* Генерировать один блок для символа: установите этот флажок, если для каждого размещенного символа EPLAN необходимо [генерировать](Glossary_o_erzeugen.md) блок AutoCAD. если флажок снят, блоки создаваться не будут, а страницы будут экспортироваться как графика.
* Генерировать один блок для рамки: установите этот флажок, если необходимо генерировать [блоки AutoCAD](Glossary_o_autocad_bloecke.md) для всех рамок EPLAN. если флажок снят, блоки создаваться не будут, а [рамки](Glossary_o_normblaetter.md) будут экспортироваться как графика.
* Генерировать один блок для станд. формы: установите этот флажок, если необходимо генерировать блоки AutoCAD для всех стандартных форм EPLAN. если флажок снят, блоки создаваться не будут, а [формы](Glossary_o_formulare.md) будут экспортироваться как графика.
