# Вкладка Медный жгут

Вы открыли проект. Проект содержит как минимум одно [пространство листа](Glossary_o_bauraum.md). Пространство листа содержит один [медный жгут](Glossary_o_kupferstrang.md). Открыт навигатор пространства листа. Выделите в навигаторе пространства листа или в трехмерной области отображения медный жгут. Выберите пункт всплывающего меню Свойства.

На этой вкладке указываются [свойства](Glossary_o_eigenschaften.md) выделенного медного жгута.

Обзор основных элементов диалогового окна:

### Имя:

Указанное здесь имя отображается в навигаторе пространства листа.

### Структурный идентификатор:

В данном поле отображается полное ОУ медного жгута (т. е. [структурный идентификатор](Glossary_o_strukturkennzeichen.md) текущего окружения + видимое ОУ); щелкните по кнопке ++...++, чтобы открыть диалоговое окно Структурный идентификатор медного жгута и выбрать, например, другое [место установки](Glossary_o_einbauort.md).

### Описание:

В этом поле медному жгуту может быть подчинен описательный текст, который, например, выводится в отчете.
