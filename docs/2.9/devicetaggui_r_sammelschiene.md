# Вкладка Сборная шина

Вы открыли проект.

* Проект содержит как минимум одно [пространство листа](Glossary_o_bauraum.md). Пространство листа содержит [сборные шины (изогнутые)](Glossary_o_sammelschienegebogen.md). Открыт навигатор пространства листа. Выделите сборную шину в навигаторе. Выберите пункт всплывающего меню Свойства. В диалоговом окне Свойства (условное обозначение): Размещение изделия (3D) выберите вкладку Сборная шина.
* Вы выделили сборную шину в трехмерной области отображения при нажатой клавише ++Shift++. Обработать > Свойства. В диалоговом окне Свойства ++...++ выберите вкладку Сборная шина.

На этой вкладке указываются [свойства](Glossary_o_eigenschaften.md) выделенной сборной шины.

Обзор основных элементов диалогового окна:

### Видимое ОУ:

Видимое ОУ будет показано в графическом редакторе рядом с условным обозначением. Если вы определили в настройках проекта, что устройство должно автоматически нумероваться при вставке символов, здесь вам будет автоматически предложено ОУ. Вы можете [сохранить](Glossary_o_einlagern.md) или переписать вручную это ОУ.

Кроме того, можно использовать [всплывающее меню или кнопку ++...++](devicetaggui_r_feldsichtbaresbmk.md), чтобы cгенерировать или выбрать ОУ.

### Полное ОУ:

В этом поле отображается полное ОУ (т. е. [структурный идентификатор](Glossary_o_strukturkennzeichen.md) текущего окружения + видимое ОУ) видимого ОУ / функционального элемента. С помощью кнопки ++...++ откройте диалоговое окно Полное ОУ. Здесь можно обработать структурный идентификатор и, например, выбрать другое [место установки](Glossary_o_einbauort.md).

### Функциональный элемент:

В этом поле отображается определение функционального элемента, оно считывается из выбранного определения [функции](Glossary_o_funktionen.md) и используется для отображения в навигаторе пространства листа.

### Определение функции:

Указанное здесь определение функции для сборной шины присваивается автоматически в зависимости от определения функции соответствующего функционального элемента. Щелкните по ++...++, чтобы открыть диалоговое окно Определения функций и, если нужно, выберите другое определение функции.

### Медный жгут:

В данном поле определяется принадлежность медного функц. элемента медному жгуту. Эту принадлежность можно изменить. При нажатии клавиши ++...++ отображается диалоговое окно Выбор 3D-объекта. Здесь перечисляются все входящие в пространство листа медные [жгуты](Glossary_o_straenge.md). При перемещении выделения на другой [медный жгут](Glossary_o_kupferstrang.md) медный функциональный элемент присваивается этому жгуту. Нажатием клавиши ++OK++ выбор переносится в поле свойств.
