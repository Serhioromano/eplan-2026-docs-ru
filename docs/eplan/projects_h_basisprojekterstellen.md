## Создать базовые проекты

[Базовые проекты](projects_k_basisprojekteerweitert.md) можно создавать с помощью вида Backstage или управления проектами. Можно использовать базовый проект для создания проекта. При создании базового проекта из имеющегося проекта, весь проект сохраняется в базовом проекте.

Условие:

Вы выделили проект.

Вид Backstage: Файл > Дополнительно > группа команд Организовать > Проект > группа команд Резервировать > Создать базовый проект.

Управление проектами: [Дополнительно] > Создать базовый проект.

1. Определите настройки в диалоговом окне Создать базовый проект. Метод "Генерировать базовый проект" является предварительно установленным и не может быть изменен вами.
2. Введите в поле Имя файла резервирования имя базового проекта.
3. В поле Каталог для резервирования укажите каталог, в котором будет сохранен базовый файл.  
  
В качестве места хранения Eplan предлагает каталог шаблонов, указанный в настройках пользователя в диалоговом окне Настройки: Каталоги.
4. Щелкните по кнопке [OK].  
  
Создается базовый проект *.zw9.
