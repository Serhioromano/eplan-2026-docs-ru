# Диалоговое окно Экспорт Eplan Smart Production

## Вызов диалогового окна:

Вы открыли проект. **Файл** > **Экспортировать** > группа команд **Данные изготовления** > **Данные изготовления** > **Smart Production**.

В этом диалоговом окне устанавливаются настройки экспорта проекта в формат "EPDZ" для считывания в приложении Eplan Smart Production.

Обзор основных элементов диалогового окна:

### Источник:

В данном поле выводится имя экспортируемого проекта. Обработка записи в данном поле невозможна.

### Файл EPDZ:

Введите имя файла в это поле или нажмите ![](images/all_selectfile_as.png), чтобы выбрать имя файла в интерактивном режиме и при необходимости перезаписать его.

### Каталог вывода:

Введите в этом поле место хранения. Кнопка ![](images/all_selectdirectory_as.png) открывает диалоговое окно **Выбрать папку** для выбора любого каталога для места хранения.
