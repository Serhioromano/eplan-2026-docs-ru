## Диалоговое окно Формат: Присвоение данных изделия

Вы открыли проект.

* Вы выделили нужные элементы, которые необходимо сохранить в виде макроса. Вкладка Основные данные > группа команд Макросы > Создать. В диалоговом окне Сохранить как выберите [Дополнительно] > Присвоить данные изделия. В столбце Присвоение диалогового окна Присвоение данных изделия нажмите кнопку [...], в диалоговом окне Формат в списке Доступные элементы формата выберите один элемент формата из раздела "Данные изделия" и нажмите кнопку  (Переместить вправо). Или в списке Выбранные элементы формата выделите один элемент формата и щелкните  (Обработать).
* Вы вставили в проект макросов рамку макроса (вкладка Вставить > группа команд Макросы > раскрывающаяся кнопка Навигатор > Вставить рамку макроса), либо вы дважды щелкнули по уже имеющейся рамке макроса. Выберите вкладку Присвоение данных изделия. В столбце Присвоение диалогового окна Присвоение данных изделия нажмите кнопку [...], в диалоговом окне Формат в списке Доступные элементы формата выберите один элемент формата из раздела "Данные изделия" и нажмите кнопку  (Переместить вправо). Или в списке Выбранные элементы формата выделите один элемент формата и щелкните  (Обработать).

В этом диалоговом окне выберите из группы свойств определенное свойство и установите для него форматирование.

Обзор основных элементов диалогового окна:

Категория:

Выберите из раскрывающегося списка, какие свойства должны быть выведены в списке ниже. В списке выводятся все свойства выбранного типа, которым еще не было присвоено форматирование.

Мин. число разрядов:

Здесь указывается минимальное число разрядов для значения свойства. К значениям с меньшим числом разрядов добавляются знаки, определенные в поле Заполнитель. Более длинные значения выводятся полностью. Разрешено использовать только положительные числовые значения. При вводе нуля число разрядов является переменным.

Заполнитель:

Значение заполняется с помощью этого символа, если запись в поле Мин. число разрядов больше, чем ширина значения.
