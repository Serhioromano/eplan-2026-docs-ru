# Вставить функции

Вставить в проект функции можно следующим образом:

* Вы используете принцип работы, ориентированный на символы. В графическом редакторе вставьте символ при помощи центра вставки. На символе указано определение функции, которое вставляется одновременно с символом. (Символ и функция объединяются в одно условное обозначение.)
* Вы вводите в проект через центр вставки макрос, содержащий функции (т. е. условное обозначение). Условному обозначению присвоено определение функции или в нем сохранено специальное определение логики.
* Вы используете принцип работы по применению инжиниринга, ориентированный на устройства, и хотите работать с предварительно определенными устройствами. Вы выбираете устройство (и, соответственно, изделие); это устройство имеет данные по своим функциям. Теперь выберите одну из этих функций. Предлагаются все символы, пригодные для представления этой функции. Теперь выберите символ и разместите его. Одновременно с этим создается устройство со всеми его функциями. Сведения по функциям обусловлены изделием.
* Вы выбираете (в навигаторах) непосредственно функцию(sdefinition) и вставляете ее (как размещенную или неразмещенную) в проект.

### Вставить функции через символы

Функции могут быть вставлены простым способом — размещением символа на странице схемы соединений.

Условие:

В графическом редакторе открыта страница схемы соединений.

1. Выберите следующие команды: Центр вставки > строка навигации Главная > Символы.
2. Перейдите через структуру папок к нужному символу и выберите его, щелкнув на плитку предварительного просмотра.
3. Разместите символ, перетянув его на схему соединений.

!!! info "Для сведения:"

    На символе указано определение функции, оно вместе с символом в качестве функции.

4. Обработайте свойства функции в диалоговом окне Свойства ++...++.
5. Щелкните по кнопке ++OK++.

!!! info "Для сведения:"

    На условном обозначении отображаются новые и измененные свойства (если они выбраны для отображения).
