## Вкладка Статус

[Вызов диалогового окна:](javascript:void\(0\);)

  * Вы открыли проект. Вкладка Главная > группа команд Страница > Навигатор. Выделите проект. Выберите следующие команды: Файл > Сведения > группа команд Свойства проекта > Статус.
  * Вы открыли проект. Вкладка Главная > группа команд Страница > Навигатор. Выделите проект. Выберите пункт всплывающего меню Свойства. Выберите в виде Backstage Сведения команду Статус.
  * Вы выбрали базу данных управления проектами. Вы считали каталоги и проекты. Файл > Управление проектами. Выделите проект. Выберите вкладку Статус.



В этом диалоговом окне отображаются последние контр. прогоны со статусом и количеством сгенерированных сообщений.



!!! note "Замечание:"

    Если вы выполнили контрольный прогон, а сведения в управлении проектаминеотображаются илинеобновляются, нажмите кнопку[Дополнительно]>Обновить данные.


 

Обзор основных элементов диалогового окна:

Контрольные прогоны:

В этом столбце указываются все доступные классы сообщений контрольных прогонов.

Дата контр.прогона:

В этом столбце для каждого контр.прогона указывается, когда он проводился в последний раз.

Версия:

В этом столбце указывается программная версия Eplan. Версия программы отображается в виде Backstage Справка (Файл > Справка > группа команд Сведения > Продукт).

№ сборки:

В этом столбце выводится номер сборки Eplan. Номер сборки отображается в виде Backstage Справка (Файл > Справка > группа команд Сведения > Продукт).

Схема проверки:

В этом столбце отображается схема, использующаяся для контрольного прогона, например "Автономно" или "Точки разрыва".

Ошибки / предупреждения / замечания:

В этих столбцах выводятся статус и количество сообщений для каждого класса сообщений, формируемых при каждом контрольном прогоне. Сообщения генерируются при выполнении контрольных прогонов и идентичны сообщениям, отображаемым в управлении сообщениями (вкладка Инструменты > группа команд Проверка > Сообщения).

Продолжительность:

В каждом столбце для каждого класса сообщения отображается общее время в миллисекундах, необходимое для выполнения соответствующих контрольных прогонов.

При нажатии на [...] откроется последующее диалоговое окно со списком, в котором будет указано время по каждому выполненному контрольному прогону. Будут показаны только значения для фактически выполненных контрольных прогонов.
