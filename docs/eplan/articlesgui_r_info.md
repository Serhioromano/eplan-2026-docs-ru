## Вкладка Информация

Вкладка Основные данные > группа команд Изделия > Управление. Через меню [Дополнительно] > Настройки была открыта база данных изделий. В дереве выделен главный узел (изделие, список принадлежностей).

На этой вкладке отображается такая информация, как имя и версия используемой в данный момент базы данных изделий, количество содержащихся изделий, количество вариантов изделий, количество списков принадлежностей, схемы сверления и т. д. С помощью нескольких свойств, таких как свойство Имя конфигурируемого узла дерева [1-n], можно получить статистическую информацию о главном узле (имя, тип, количество).

Содержимое вкладки автоматически обновляется при открытии, при этом в любой момент также можно выполнить обновление вручную с помощью клавиши [F5].

Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).
