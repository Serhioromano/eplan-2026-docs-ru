## Вкладка Статистика

[Вызов диалогового окна:](javascript:void\(0\);)

  * Вы открыли проект. Вкладка Главная > группа команд Страница > Навигатор. Выделите проект. Выберите следующие команды: Файл > Сведения > группа команд Свойства проекта > Статистика.
  * Вы открыли проект. Вкладка Главная > группа команд Страница > Навигатор. Выделите проект. Выберите пункт всплывающего меню Свойства. Выберите в виде Backstage Сведения команду Статистика.
  * Вы выбрали базу данных управления проектами. Вы считали каталоги и проекты. Файл > Управление проектами. Выделите проект. Выберите вкладку Статистика.



На этой вкладке показывается, сколько страниц разных типов содержится в проекте.

Обзор основных элементов диалогового окна:

Таблица

Тип страницы:

Показывает все [типы страниц](pagebrowsergui_k_seitentypen.htm), доступные в Eplan.

Число:

Показывает количество страниц всех типов, содержащихся в проекте.

Последнее изменение:

Здеь указывается дата изменения количества страниц определенного типа.

Необновляемые страницы:

Показывает для каждого типа страниц количество [замороженных страниц отчета](formgeneratorgui_k_eingefrorseiten.htm). В навигаторе страниц вы можете фильтровать замороженные страницы отчета.

* * *

Индивидуально созданные страницы:

Показывает количесиво страниц, которые вы создали в проекте.

Сгенерированные страницы отчета:

Показывает количество страниц, сгенерированных при составлении отчетов и находящихся в проекте.

Общее число страниц:

Показаны все данные, которые содержатся в проекте.

Количество пространств листа:

Показывает количество пространств листа, которые имеются в проекте.
