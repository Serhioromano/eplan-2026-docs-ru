# Создать / выбрать базу данных управления проектами

Запускайте управление проектами всегда в соединении с базой данных управления проектами. Вся информация, которая выводится на просмотр в управлении проектами, находится в этой базе данных. Управление проектами может основываться на внутренней базе данных Eplan или базе данных сервера SQL. Имя этой базы данных можно свободно выбирать. По умолчанию здесь для базы данных Eplan задано имя `Projects.db`.

###

## Создать базу данных управления проектами

Условие:

Вы еще не создали базу данных управления проектами.

1. Выберите следующие команды: **Файл** > **Настройки** > **Пользователь** > **Управление** > **База данных управления проектами**.
2. В диалоговом окне **Настройки: База данных управления проектами** нажмите кнопку ![](images/all_new_as.png) (Создать), чтобы создать базу данных Eplan или базу данных сервера SQL.

![](images/arrow.png) В случае выбора параметра **Сервер SQL** для этого открывается диалоговое окно **Сгенерировать базу данных сервера SQL**.
3. Подтвердите ввод.

![](images/arrow.png) После этого вновь созданная база данных заносится в настройки в качестве базы данных управления проектами и автоматически выбирается как таковая.

!!! note "Замечание:"

    Если вы открываете управление проектами, не создав и не выбрав базу данных управления проектами, отображается сообщение. После того как вы его подтвердите, откроется диалоговое окно **База данных управления проектами**, в котором можно создать или выбрать базу данных управления проектами.

###

## Выбрать базу данных Eplan

Условие:

Вы создали базу данных управления проектами Eplan или имеете доступ к базе данных управления проектами Eplan.

1. Выберите следующие команды: **Файл** > **Настройки** > **Пользователь** > **Управление** > **База данных управления проектами**.
2. Нажмите в диалоговом окне **Настройки: База данных управления проектами** рядом с полем **Eplan** кнопку ++"..."++.
3. Перейдите в диалоговом окне выбора файла к каталогу, в котором находится база данных управления проектами. Выберите требуемый файл.
4. Подтвердите ввод.

![](images/arrow.png) База данных записывается в настройках в качестве базы данных управления проектами.

###

## Выбрать базу данных сервера SQL

Условие:

Вы создали базу данных сервера SQL или имеете доступ к базе данных сервера SQL.

1. Выберите следующие команды: **Файл** > **Настройки** > **Пользователь** > **Управление** > **База данных управления проектами**.
2. Выберите в диалоговом окне **Настройки: База данных управления проектами** в раскрывающемся списке **Сервер SQL** одну из 15 последних использованных баз данных SLQ, при этом последние использованные базы данных находятся в верхней позиции.

![](images/arrow.png) При открытии / генерации новой базы данных, которая отсутствует в списке, при необходимости из списка удаляется база данных, находящаяся на самой нижней позиции.

![](images/arrow.png) С помощью пункта всплывающего меню **Удалить записи** можно полностью очистить список, в том числе базу данных, использующуюся в настоящий момент.
3. Щелкните по кнопке ++"OK"++.

![](images/arrow.png) База данных записывается в настройках в качестве базы данных управления проектами.
