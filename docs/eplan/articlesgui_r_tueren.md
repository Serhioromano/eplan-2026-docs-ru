# Вкладка Двери

## Вызов диалогового окна:

Вкладка **Основные данные** > группа команд **Изделия** > **Управление**. В дереве или списке выделено одно изделие **главной группы продуктов** "Механика", **группа продуктов** "Электрошкаф". Выберите вкладку **Двери**.

В этой вкладке установите общие специфические для двери данные для изделий **главн. группы продукт.** "Механика", **Группа продуктов** "Электрошкаф". При этом данные для каждого изделия могут указываться многократно, а именно один раз для каждого варианта.

Обзор основных элементов диалогового окна:

### Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).
