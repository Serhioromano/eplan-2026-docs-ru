# Автоматически генерировать страницы с обзорами

В проектах с механическими компонентами в пространствах листа можно автоматически генерировать страницы с обзорами модели, 2D-отображениями отверстий и развертками шины.

Условие:

Вы открыли проект. В Графическом редакторе открыта страница проекта.

1. Создайте обзор модели, 2D-отображение отверстий или развертку шины.
2. Сохраните вид как макрос с помощью следующих команд: вкладка **Главная** > группа команд **Страница** > раскрывающаяся кнопка **Макрос страницы** > **Создать**.
3. Выберите следующие команды: Вкладка **Инструменты** > группа команд **Отчеты** > **Обзоры модели**.
4. Во вкладке **Шаблоны** щелкните по кнопке ![](images/all_new_as.png) (Создать), чтобы создать новый шаблон.
5. Внесите в свойства шаблона подходящие значения, как описано в разделе [Вкладка Шаблоны (диалоговое окно Обзоры модели, Развертки шины, Отображения отверстий)](gededit3dgui_r_vorlagen.md).
6. С помощью настроек фильтра определите, из каких основных функциональных элементов генерируются обзоры, и какие функциональные элементы с иерархической структурой представляются в обзоре.
7. Внесите в свойство **Макрос** обзор, сохраненный как макрос.
8. Щелкните по кнопке ![](images/all_generate_as.png) (Генерировать отчет) или выберите пункт всплывающего меню **Генерация отчета**, чтобы сгенерировать автоматические отчеты.

![](images/arrow.png) Страницы с отчетами генерируются на основе настроек, заданных в шаблоне, и с учетом выбранного макроса.

!!! note "Замечание:"

    При [составлении отчетов проектов](formgeneratorgui_h_projektauswerten.md) с помощью команды **Генерация отчета по проекту** обзоры модели, 2D-отображения отверстий и развертки шины также генерируются автоматически, если в диалоговых окнах для видов доступны соответствующие шаблоны (командный путь: вкладка **Инструменты** > группа команд **Отчеты** > **Генерация отчета по проекту**). Если эти обзоры уже включены в проект, они обновляются.
