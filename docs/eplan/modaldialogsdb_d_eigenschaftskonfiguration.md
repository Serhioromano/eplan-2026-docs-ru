## Диалоговое окно "Конфигурировать свойства" / диалоговое окно "Конфигурировать представление"

[Вызов диалогового окна "Конфигурировать свойства":](javascript:void\(0\);)

Вы открыли проект.

* Вы выделили один или несколько объектов (тексты, условные обозначения, сегменты, графические элементы) в графическом редакторе, пространстве листа или навигаторе. Вкладка Главная > группа команд Обработать > Обзор свойств. В обзоре свойств в раскрывающемся списке нажмите [...].

Открыто управление изделиями. Через меню [Дополнительно] > Настройки была открыта база данных изделий.

* В дереве или списке выделено одно изделие. Выбрана вкладка Обзор. Нажмите для поля Вид рядом с раскрывающимся списком на кнопку [...].
* В дереве или списке выделено одно изделие. Выбрана вкладка Свойства. Рядом с раскрывающимся списком нажмите на кнопку [...].

[Вызов диалогового окна "Конфигурировать представление":](javascript:void\(0\);)

Вы открыли проект. В Графическом редакторе открыта страница проекта. Вы находитесь в информационной области диалогового окна Центр вставки. Выберите пункт всплывающего меню Конфигурировать представление.

В этом диалоговом окне можно управлять схемами для конфигураций свойств и редактировать их. В такой схеме, как правило, сохраняются несколько конфигураций. С помощью присвоения нужному объекту (изделию, функции и т. п.) и определения фильтров появляется возможность всегда отображать соответствующие свойства для выбранного объекта.

Такие конфигурации свойств используются для отображения на вкладках Обзор и Свойства в разделе управления изделиями, для отображения в обзоре свойств и для конфигурации столбцов в информационной области центра вставки. Для каждой из этих областей применения используются разные схемы.

Обзор основных элементов диалогового окна:

Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать или обработать. Для этого также воспользуйтесь соседней [панелью инструментов](eplan/schemeconfig_m_schemaschaltflaechen.md).

Конфигурации:

Эта таблица содержит конфигурации свойств для выбранной схемы. Здесь отображаются присвоенный объект, имя и — при наличии — фильтр, определенный для конфигурации свойств.

Чтобы добавить новую конфигурацию, нажмите кнопку  (Создать). Для редактирования конфигурации выделите соответствующую строку в списке и нажмите кнопку  (Обработать). Затем в [следующем диалоговом окне](eplan/modaldialogsdb_d_eigenschaftskonfigurationhauptknoten.md) вы сможете, например, добавить или удалить свойства соответствующей конфигурации.

Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](eplan/userinterface_m_kontextmenu.md).
