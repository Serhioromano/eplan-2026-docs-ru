## Диалоговое окно Настройки: Экспорт PDF

[Вызов диалогового окна:](javascript:void\(0\);)

  * Файл > Экспортировать > группа команд Данные проекта > Данные проекта > группа команд Страница > PDF. Щелкните в поле Схема диалогового окна Экспорт PDF[...].
  * Файл > Настройки > Пользователь > Интерфейсы > Экспорт PDF.



В этом диалоговом окне устанавливаются настройки для экспорта. При экспорте отдельных страниц или всего проекта в формат PDF всегда создается только один файл независимо от выполненного выделения.

Обзор основных элементов диалогового окна:

Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать или обработать. Для этого также воспользуйтесь соседней [панелью инструментов](schemeconfig_m_schemaschaltflaechen.htm).
