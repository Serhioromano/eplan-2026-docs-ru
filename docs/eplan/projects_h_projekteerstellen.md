# Создать проекты

Проекты можно создавать с помощью вида Backstage или управления проектами. В обоих случаях проект создается на основе базового проекта. Ниже описывается, как создать проект с помощью вида Backstage. Если вы сами еще не создали базовый проект, можно использовать [Примерные шаблоны](projects_k_basisprojekteerweitert.md) Eplan.

Условие:

Вы имеете доступ к [Базовые проекты](projects_k_basisprojekteerweitert.md).

1. Выберите следующие команды: **Файл** > **Создать**.
2. В поле **Имя проекта** диалогового окна **Создать проект** введите имя проекта без расширения файла.
3. Нажмите в поле **Место хранения** на ![](images/all_selectdirectory_as.png){ .ui-icon }, и укажите в следующем диалоговом окне каталог, в котором должен быть сохранен проект.
4. Нажмите в поле **Базовый проект** на кнопку ![](images/all_selectfile_as.png){ .ui-icon } и замените в диалоговом окне **Выбрать базовый проект** каталог, в котором находится базовый проект.
5. Выделите нужный базовый проект и нажмите на ++"Открыть"++.
6. Щелкните по кнопке ++"OK"++.

!!! info "Для сведения:"

    В целевом каталоге создается новый проект `*.elk`.

!!! info "Для сведения:"

    Если вы работаете с управлением проектами, новый проект будет автоматически добавлен в управление проектами.

!!! tip "Совет:"

    Можно отобразить в свойствах проекта информацию о том, из какого базового проекта создан проект:
    Выделите проект в навигаторе страниц и выберите пункт всплывающего меню **Свойства**. Добавьте в виде Backstage **Сведения** на вкладке **Свойства** свойство проекта **Проект: Шаблон**. Это свойство указывает, на основе какого шаблона (базовый проект или, если он скопирован, исходный проект) создан проект. Для дифференциации помимо имени файла отображается также расширение имени файла.
