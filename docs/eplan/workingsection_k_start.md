## Области обработки

Проекты можно разделить на области обработки. Это повышает наглядность обработки проектов и облегчает одновременное редактирование проектов несколькими пользователями. Критерии разделения хранятся в схемах фильтрации.

Для проектов, структурированных по блокам идентификаторов, разбивка основана на структурных идентификаторах, доступных для блоков идентификаторов в проекте. Вы можете фильтровать по любой комбинации этих структурных идентификаторов. Вы также можете отфильтровать страницы, пространства листа, функции и соединения в соответствии с конкретными разделами.

Для проектов с общей нумерацией возможно только разделение по разделам.

Возможно следующее:

  * Выбрав схему, вы можете указать область обработки, в которой хотите работать.
  * При использовании управления правами Eplan области обработки может централизованно распределять администратор проекта. Без использования управления правами каждый отдельный пользователь может сам решать, в какой области обработки он хочет работать.
  * В навигаторах данных проекта будут отображаться только страницы, устройства и т. д., соответствующие критериям, заданным в схеме. Это позволяет увеличить наглядность проекта и повышает скорость работы.
  * Область обработки изделия может быть временно распространена на весь проект.
