## Генерировать ручные перекрестные ссылки

Ручные перекрестные ссылки представляют собой многострочные тексты, которые отображаются на условном обозначении вместе с "нормальной" перекрестной ссылкой. Eplan размещает ручную перекрестную ссылку перед автоматически созданной.

Условие:

Вы открыли проект.

1. Выберите страницу схемы соединений для обработки.
2. Дважды щелкните по условному обозначению, на котором хотите отобразить перекрестную ссылку.
3. Щелкните на вкладке <Категория функции> диалогового окна Свойства <...> в групповом поле Свойства на  (Создать).
4. Выберите в диалоговом окне Выбор свойств свойство Перекрестная ссылка вручную.
5. Щелкните по кнопке ++OK++.
6. В поле Значение свойства Перекрестная ссылка вручную введите требуемый текст.
7. Выберите пункт всплывающего меню Новая строка, чтобы применить новую строку, или пункт контекстного меню Многострочный ввод, чтобы ввести многострочный текст в диалоговом окне Многострочный ввод. Новая строка в таком случае добавляется с помощью комбинации клавиш [Ctrl] \+ [Ввод].
8. Щелкните по кнопке ++OK++.  
  
Текст копируется в поле Значение.
9. Щелкните по кнопке ++OK++.  
  
Ручная перекрестная ссылка записывается на символ.
