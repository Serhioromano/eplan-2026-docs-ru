## Расчет общего веса электрошкафов

В Eplan Pro Panel доступна функция, с помощью которой можно определить фактический общий вес каждого электрошкафа, размещенного в пространстве листа, для всего проекта. Эта информация доступна для отчета и / или экспорта. Фактический общий вес электрошкафа рассчитывается на основании веса электрошкафа и суммы значений веса всех размещенных в электрошкафу изделий и маршрутизированных соединений.

### Принцип

Основанием для расчета служат следующие данные изделий:

* Все изделия, независимо от раздела (например, электрошкафы, контакторы, клеммы, клапаны и т. д.): используется свойство Вес (полностью) (ID 22233).
* Функциональные элементы с переменной длиной (например, несущие шины, кабельные каналы и т. д.): используется свойство Вес (полностью) (ID 22233). Вес рассчитывается исходя из фактической длины функционального элемента.
* Маршрутизируемые соединения: используется свойство Вес/длина (ID 22067). Вес рассчитывается исходя из фактической длины соединения.

Для этого в управлении изделиями необходимо сохранить соответствующую информацию о весе для всех размещаемых изделий, включая изделия соединения.

Для расчета вам доступна команда Рассчитать общий вес шкафа в ленте (командный путь: вкладка Инструменты > группа команд Отчеты > раскрывающаяся кнопка [Генерация отчета по проекту]).

Результат расчета отображается в диалоговом окне "Свойства" электрошкафа на вкладке Размещение изделия в свойстве Общий вес (ID 36108).

### Контрольные прогоны

Для правильного расчета общего веса всех электрошкафов в проекте имеются контрольные прогоны 026106 и 026107:

* Во время расчета общего веса контрольный прогон 026106 выявляет изделия, которые были размещены или маршрутизированы в электрошкафу без данных о весе.
* При выполнении контрольного прогона 026107 определяется, что расчет общего веса еще не был выполнен для всех электрошкафов в проекте или что значение общего веса электрошкафа изменилось с момента выполнения последнего расчета.
