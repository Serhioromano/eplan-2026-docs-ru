## Дополнения для автоматизированной обработки

Для автоматизированной обработки проектов в данной версии реализованы следующие возможности:   
\- Архивация проектов с использованием автоматизированной обработки   
\- Автоматизированная обработка дополнена экспортом данных изготовления в формате "Komax — Zeta"   
\- Новая операция "Обновить отчеты" для автоматизированной обработки

### Архивация проектов с использованием автоматизированной обработки

Раньше с помощью автоматизированной обработки можно было только резервировать проекты. Архивация была невозможной. Теперь при запуске автоматизированной обработки из управления проектами у вас также есть возможность архивировать несколько проектов. Для этого диалоговое окно Резервировать данные в раскрывающемся списке Метод дополнено пунктом "Архивировать". Теперь в раскрывающемся списке доступны те же методы резервного копирования, что и в диалоговом окне Резервировать проекты. Это означает, что теперь можно также выбрать пункт "Выгрузить для внешней обработки".

### Автоматизированная обработка дополнена несколькими операциями для экспорта данных изготовления

Теперь автоматизированная обработка дополнена несколькими операциями для экспорта данных изготовления. Для этого при создании схемы для автоматизированной обработки в диалоговом окне Настройки: Автоматизированная обработка доступны следующие новые операции:

  * Komax — Zeta: Экспортировать данные изготовления
  * Rittal — Perforex BC: Экспортировать данные изготовления
  * Rittal — Perforex LC: Экспортировать данные изготовления



Чтобы перейти в это диалоговое окно, используйте следующий командный путь: Вкладка Инструменты > группа команд Отчеты > Автоматизированная обработка. Затем в диалоговом окне Выполнить: Автоматизированная обработка рядом с полем Схема щелкните по [...].

### Новая операция "Обновить отчеты" для автоматизированной обработки

Раньше при автоматизированной обработке при выполнении операции "Обновить / генерировать отчеты" можно было при абсолютно конкретных условиях только обновлять страницы отчетов, но не генерировать новые отчеты. Поэтому теперь в диалоговом окне Настройки: Автоматизированная обработка доступна новая операция "Обновить отчеты". Если в схеме для автоматизированной обработки присутствует эта операция, а не операция "Обновить / генерировать отчеты", то будут только обновляться существующие страницы отчетов.
