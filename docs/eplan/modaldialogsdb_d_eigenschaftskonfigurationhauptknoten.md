## Диалоговое окно "Конфигурировать свойства — Конфигурация" / диалоговое окно "Конфигурировать представление — Конфигурация"

[Вызов диалогового окна "Конфигурировать свойства":](javascript:void\(0\);)

Вы открыли проект.

  * Вы выделили один или несколько объектов (тексты, условные обозначения, сегменты, графические элементы) в графическом редакторе, пространстве листа или навигаторе. Вкладка Главная > группа команд Обработать > Обзор свойств. В обзоре свойств в раскрывающемся списке нажмите [...]. В диалоговом окне Конфигурировать свойства нажмите кнопку  (Создать) на панели инструментов над таблицей с конфигурациями или выделите строку ранее определенной конфигурации и нажмите кнопку  (Обработать).



Открыто управление изделиями. Через меню [Дополнительно] > Настройки была открыта база данных изделий.

  * В дереве или списке выделено одно изделие. Выбрана вкладка Обзор. Нажмите для поля Вид рядом с раскрывающимся списком на кнопку [...]. В диалоговом окне Конфигурировать свойства нажмите кнопку  (Создать) на панели инструментов над таблицей с конфигурациями или выделите строку ранее определенной конфигурации и нажмите кнопку  (Обработать).
  * В дереве или списке выделено одно изделие. Выбрана вкладка Свойства. Рядом с раскрывающимся списком нажмите на кнопку [...]. В диалоговом окне Конфигурировать свойства нажмите кнопку  (Создать) на панели инструментов над таблицей с конфигурациями или выделите строку ранее определенной конфигурации и нажмите кнопку  (Обработать).



[Вызов диалогового окна "Конфигурировать представление":](javascript:void\(0\);)

Вы открыли проект. В Графическом редакторе открыта страница проекта. Вы находитесь в информационной области диалогового окна Центр вставки. Выберите пункт всплывающего меню Конфигурировать представление. В диалоговом окне Конфигурировать представление нажмите кнопку  (Создать) на панели инструментов над таблицей с конфигурациями или выделите строку ранее определенной конфигурации и нажмите кнопку  (Обработать).

В этом диалоговом окне вы задаете свойства, которые должны отображаться для конфигурации с указанным здесь именем. С помощью определенного фильтра вы можете задать, чтобы эти сконфигурированные свойства отображались, например, в разделе управления изделиями в изделиях только для очень конкретной группы продуктов или в обзоре свойств в функциях только для очень конкретного определения функции.

Обзор основных элементов диалогового окна:

Присвоение:

В этом раскрывающемся списке выберите, какой объект (например, изделие, символ, графический элемент и т. д.) следует использовать для конфигурации свойств. То, какой объект здесь доступен, зависит от того, где именно вызывается конфигурация. Так, конфигурацию свойств в управлении изделиями можно присвоить только объекту "Изделие".

Присвоенный здесь объект отображается в столбце Присвоение в предыдущем диалоговом окне конфигурации для соответствующей конфигурации свойств.

Имя:

Введите здесь имя конфигурации свойств, как оно должно отображаться в диалоговом окне конфигурации.

Фильтр:

Это поле показывает фильтр, который задается с помощью кнопки [...] в диалоговом окне Фильтр.

Свойства:

Этот список содержит свойства, которые были присвоены текущей конфигурации свойств. Свойства зависят от объекта, выбранного в поле Присвоение.
