## Вкладка Шаблоны (диалоговое окно Обзоры модели, Развертки шины, Отображения отверстий)

[Вызов диалогового окна (обзоров модели):](javascript:void\(0\);)

Вы открыли проект. Вкладка Инструменты > группа команд Отчеты > Обзоры модели. Выберите вкладку Шаблоны.

[Вызов диалогового окна (развертки шины):](javascript:void\(0\);)

Вы открыли проект. Вкладка Инструменты > группа команд Отчеты > раскрывающаяся кнопка Обзоры модели > Развертки шины. Выберите вкладку Шаблоны.

[Вызов диалогового окна (2D-отображения отверстий):](javascript:void\(0\);)

Вы открыли проект. Вкладка Инструменты > группа команд Отчеты > раскрывающаяся кнопка Обзоры модели > 2D-отображения отверстий. Выберите вкладку Шаблоны.

На этой вкладке можно генерировать и обрабатывать шаблоны для автоматической генерации обзоров модели, разверток шины или 2D-отображений отверстий. Шаблоны содержат только данные о форматировании генерируемого обзора модели и о том, для каких основных функциональных элементов должны генерироваться отдельные обзоры. Геометрические данные отсутствуют. Автоматическая генерация страниц происходит на основе шаблонов в диалоговом окне Обзоры модели – <Имя проекта> на вкладке Шаблоны либо после нажатия кнопки  (Генерировать отчет), либо в дереве с помощью пункта всплывающего меню Генерировать отчет.

Обзор основных элементов диалогового окна:

Имя проекта:

В этой структуре дерева отображаются содержащиеся в проекте шаблоны отчетов для обзоров модели, разверток шины или 2D-отображений отверстий.

Панель инструментов:

В панели инструментов, расположенной над структурой дерева, имеются следующие кнопки:

Кнопка |  Значение  
---|---  
(Генерировать отчет) |  Генерирует обзоры модели, двухмерные отображения отверстий и развертки шины на основе принятых во вкладке Шаблоны настроек.  
(Создать) |  Создает новый шаблон, имя которого нумеруется по нарастающей, начиная с 1. Это имя впоследствии можно изменить в таблице свойств.  
(Удалить) |  Удаляет выделенные шаблоны из списка.  
(Импортировать) |  Открывает диалоговое окно Импортировать шаблон отчета. Позволяет импортировать шаблон отчета.  
(Экспортировать) |  Открывает диалоговое окно Экспортировать шаблон отчета. Позволяет экспортировать шаблон отчета.  
  
Всплывающее меню:

Всплывающее меню дерева на вкладке Шаблоны содержит те же пункты меню, что и кнопки на панели инструментов.

Таблица Имя свойства / Значение:

В столбцах этой таблицы отображаются свойства и значения выделенных отчетов, которые можно задать для генерации шаблонов.

Свойство |  Значение  
---|---  
Имя |  Имя шаблона  
Начальная страница блока отчетов |  Начальная страница для всех страниц, автоматически генерируемых с помощью этого шаблона. С помощью кнопки [...] можно открыть диалоговое окно [Начальная страница](eplan/formgeneratorgui_d_struktur.md).  
Настройка фильтра |  Фильтрует основные функциональные элементы, для которых должна автоматически генерироваться страница с обзором модели. С помощью кнопки [...] можно открыть диалоговое окно [Фильтр](eplan/modaldialogsdb_d_filternnach.md). Если выбранный основной функциональный элемент не содержится в проекте, то для него не будет генерироваться обзор модели. Если ни один основной функциональный элемент не установлен, для каждого пространства листа проекта генерируется обзор модели.  
Настройка сортировки |  Здесь задается вид сортировки основных функциональных элементов при генерации обзоров модели. С помощью кнопки [...] можно открыть диалоговое окно [Сортировка](eplan/formgeneratorgui_d_sortierung.md).  
Функции: Настройка фильтра |  Только для обзоров модели! Этим задается, какие функции основного функционального элемента или какие функциональные элементы с иерархической структурой будут представлены в обзоре модели. С помощью кнопки [...] можно открыть диалоговое окно [Фильтр](eplan/modaldialogsdb_d_filternnach.md).  
Раздел |  Заданный раздел присваивается сгенерированной странице.  
Ручное описание обзора |  Если флажок Автоматическое описание вида снят, то здесь можно ввести описание обзора.  
Автоматическое описание вида |  Если этот флажок установлен, описание обзора автоматически генерируется из свойства Формат для автоматического описания.  
Формат для автоматического описания |  Этим можно задать формат для автоматического описания обзоров и страниц. С помощью кнопки [...] можно открыть диалоговое окно [Формат: Свойство](eplan/eservicesgui_d_formateigenschaft.md).  
Описание страниц вручную |  Если флажок Автоматическое описание страницы снят, то здесь можно ввести описание страниц.  
Автоматическое описание страницы |  Если этот флажок установлен, описание страниц автоматически генерируется из свойства Формат для автоматического описания.  
Сортировка страниц |  С помощью кнопки [...] можно открыть диалоговое окно [Сортировка страниц](eplan/formgeneratorgui_d_seitensortierung.md). Значение настройки Сортировка страниц полностью соответствует одноименной специфической для проекта настройке Отчеты > Вывод в страницах.  
Макрос |  Заданный здесь макрос используется для вывода обзора в страницах. Кнопка [...] открывает диалоговое окно Выбрать макрос. На выбор предлагаются макросы окон, символов и страниц. 

!!! note "Замечание:"

    После вставкимакросыне сохраняются в проект. В тех случаях, когда проект копируется с шаблонами отчетов или передается другим пользователям, необходимо убедиться, что заданный в шаблоне макрос находится в списке макросов соответствующего пользователя.
