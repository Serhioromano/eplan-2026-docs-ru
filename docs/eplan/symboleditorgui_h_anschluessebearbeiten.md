## Обработать выводы устройств

Условие:

Вы открыли проект.

1. Выберите следующие команды: Вкладка Основные данные > группа команд Символы > раскрывающаяся кнопка Символ > Открыть.
2. Если библиотека символов еще не открыта, выберите в последующем диалоговом окне нужную библиотеку символов, в которой находится символ с обрабатываемыми выводами устройства.
3. В диалоговом окне Выбор символа выберите символ. Чтобы быстро найти символ, используйте фильтр или прямой ввод.  

4. Щелкните по кнопке [OK].  

Символ откроется в редакторе символов.
5. Щелкните двойным щелчком на каждый из выводов устройства.
6. Определите в диалоговом окне Вывод устройства свойства вывода устройства, такие как Номер вывода устройства, Обозначение вывода устройства и/или Описание вывода устройства.
7. Щелкните по кнопке [OK].
8. Выберите следующие команды: Вкладка Основные данные > группа команд Символы > раскрывающаяся кнопка Выводы устройства > Нумеровать.
9. Задайте в диалоговом окне Нумеровать выводы устройства в групповом поле Последовательность, в какой последовательности будут пронумерованы выводы устройства: "сверху вниз и затем слева направо" (опция Горизонтально / вертикально) или "слева направо и затем сверху вниз" (опция Вертикально / горизонтально).
10. Щелкните по кнопке [OK].
11. Закройте редактор символов.  

Символ будет проверен, данные обновлены.

!!! warning "Предупреждение:"

    Несколько выводов устройства одного символа не должны располагаться друг над другом.

Данные выводы устройства принимаются для символа согласно своим настройкам. При этом графическое изображение вывода устройства однозначно описывает направление вывода устройства, однако оно не является составной частью готового символа.
