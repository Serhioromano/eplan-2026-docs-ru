## P001026: Несоединенные распределенные клеммы имеют одинаковые обозначения

### Причина

В схеме соединений находятся распределенные клеммы, имеющие одинаковое обозначение, но не связанные друг с другом. Возможно, не активирована специфическая для проекта настройка Автоматически связать родственные распределенные клеммы.

### Решение

1. Выберите команды Файл > Настройки и отследите в представлении в виде дерева диалогового окна Настройки структуру папок Проекты > "Имя проекта" > Устройства.
2. Нажмите на область настройки Клеммы (распределенные клеммы) и установите флажок Автоматически связать родственные распределенные клеммы.
3. В диалоговом окне нажмите кнопку [OK].
4. Обновите соединения.
5. При необходимости запустите новый контрольный прогон.
