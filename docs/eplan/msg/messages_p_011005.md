## P011005: Острия стрел перекрестных точек разрыва не подходят друг к другу

### Причина

Стрелки двух точек разрыва, связанных перекрестной ссылкой, направлены друг на друга. Точки разрыва должны быть размещены так, чтобы острие стрелки одной точки разрыва указывало на конец стрелки другой точки разрыва.

### Решение

1. Установите местоположение точек разрыва на схеме соединений с помощью функций Перейти к (графика) и Перейти к (2-я координата) во всплывающем меню диалогового окна Управление сообщениями.
2. Для этого дважды щелкните на изменяемой точке разрыва и переместите в диалоговом окне Свойства ++...++ вкладку Данные символа на передний план.
3. С помощью раскрывающегося списка Вариант поверните стрелку на 180° в зависимости от выравнивания точки разрыва. Для этого, например, если ранее был установлен вариант A, выберите вариант C.
4. При необходимости запустите новый контрольный прогон.
