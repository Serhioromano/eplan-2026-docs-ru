## P007002: Устройство использует меньше функций, чем предоставлено соответствующим изделием

### Причина

Вы вставляете устройство, которое определено как изделие с помощью фиксированных шаблонов функций (устройство). Однако при этом размещается меньше функций, чем имеется в соответствующем изделии.

### Решение

#### Возможность 1

Выберите изделие с соответствующим числом шаблонов функций.

#### Возможность 2

Уменьшите в базе данных изделий число шаблонов функций для выбранного изделия.

1. Выберите следующие команды: Вкладка Основные данные > группа команд Изделия > Управление.
2. Выберите в диалоговом окне База данных изделий вкладку Шаблоны функций.
3. Выделите в таблице убираемые шаблоны функций и щелкните по кнопке  (Удалить).
4. Примените измененную настройку в базе данных изделий.
5. Затем еще раз разместите символ устройства в схеме соединений.

* * *

При необходимости запустите новый контрольный прогон.
