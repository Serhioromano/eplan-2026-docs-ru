## P022002: Невозможно найти символ <x>, вариант <y> в библиотеке символов <z>

### Причина

В исходном проекте из символов определенной библиотеки символов <z> был создан макрос. После этого макрос был вставлен в целевой проект (текущий проект), в котором также сохранена библиотека символов, использованная при создании макроса. Однако перед сохранением символ <x> в определенном варианте <y> был удален из библиотеки символов, хотя этот символ является частью вставленного макроса.

!!! note "Замечание:"

    Отсутствующиесимволывыводятся в схеме соединений целевого проекта в виде красного символа "x".

### Решение

1. Заново создайте отсутствующий символ на основе имеющегося варианта и сохраните его в сохраненную библиотеку символов. Заново вставьте макрос.
2. При необходимости запустите новый контрольный прогон.

!!! tip "Совет:"

    Используйте функциональность синхронизации для основных данных, чтобы обновить библиотеку символов, сохраненную в целевом проекте. Для этого выберите следующие команды: вкладка Основные данные> группа команд Синхронизировать>Синхронизировать проект. Выделите соответствующую библиотеку символов в области основных данных диалогового окна Синхронизация основных данных — <Имя проекта>и щелкните по кнопке со стрелкой, указывающей влево. Выводится сообщение, чтоосновные данные проектаобновлены.
