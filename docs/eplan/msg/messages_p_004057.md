## P004057: Найдено несколько изделий с одинаковой или подходящей идентификацией устройства '<x>'. Если возможно, функции '<y>' необходимо присвоить другое изделие

### Причина

При импорте данных ПЛК поиск подходящего изделия в базе данных изделий ведется по идентификации устройства — она может состоять из указания обозначения типа ПЛК или файла описания устройства. В базе данных изделий могут быть найдены два или несколько изделий с идентичной идентификацией устройства. При этом обозначение типа ПЛК, которое всегда ищется первым, также может содержать символы-заполнители. При обнаружении нескольких изделий будет использоваться то, которое было найдено первым.

В заполнителе '<x>' сообщения отображается идентификация устройства, а в заполнителе '<y>' — ОУ соответствующего изделия.

### Решение

1. Если было найдено несколько изделий с идентичной идентификацией устройства, необходимо откорректировать изделия в базе данных изделий. Если было найдено изделие с заполнителями в обозначении типа ПЛК, необходимо проверить, указано ли правильное изделие на устройстве. При необходимости выберите другое изделие.
2. Еще раз выполните импорт данных ПЛК.

!!! note "Замечание:"

    Это относящееся к модулю сообщение можно удалить при выполнении нового контрольного прогона (любой настроеннойсхемы) из диалогового окна управления сообщениями.
