## P004030: Недостающий символический адрес (автоматич.)

### Причина

Не указан символический адрес для одного из выводов устройства ПЛК. У вывода устройства нет подсоединенной цели, которая вместе с ОУ может автоматически образовать символический адрес.

!!! note "Замечание:"

    Проверяются тольковыводы устройства ПЛК, которые являются входами или выходами.

### Решение

#### Возможность 1

Откройте диалоговое окно Свойства ++...++ для соответствующего вывода устройства ПЛК. Внесите на вкладку Вывод устройства ПЛК, в поле Символический адрес, символический адрес.

#### Возможность 2

1. Выберите следующие команды: Файл > Настройки > Проекты > "Имя проекта" > Устройства > ПЛК.
2. В диалоговом окне Настройки: ПЛК нажмите кнопку ++...++ рядом с полем Специфические для ПЛК настройки.
3. Переместите в следующем диалоговом окне вкладку Формат символического адреса на передний план и установите флажок Автоматически генерировать символические адреса, используя.
4. Подтвердите ввод.
5. Соедините вывод устройства ПЛК с датчиком или исполнительным элементом, имеющим обозначение устройства.

С помощью отслеживания цели Eplan автоматически определяет подсоединенное ОУ и генерирует символический адрес.
6. При необходимости запустите новый контрольный прогон.
