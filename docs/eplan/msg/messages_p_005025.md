## P005025: Слишком много соединений к одному выводу устройства

### Причина

Как минимум один из выводов устройства функции условного обозначения соединен с большим число условных обозначений, чем указано.

### Решение

#### Возможность 1

1. Установите местоположение точки определения соединения на схеме соединений, пользуясь функциональностью Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Дважды щелкните по условному обозначению и выберите в диалоговом окне Свойства <...> вкладку Данные символа / функции.
3. Щелкните в групповом поле Данные функции (логика) по кнопке [Логика].
4. В диалоговом окне Логическая схема выводов устройства следует просмотреть, какие значения в строке Число целей сохранены для выводов устройства функции условного обозначения.
5. Увеличьте до требуемого уровня настроенное значение для соответствующих выводов устройства функции.

#### Возможность 2

1. Выполните действия, описанные в пунктах от 1 до 4 возможности 1.
2. Удалите соответствующим образом лишние условные обозначения, соединенные с выводом устройства функции.

* * *

При необходимости запустите новый контрольный прогон.
