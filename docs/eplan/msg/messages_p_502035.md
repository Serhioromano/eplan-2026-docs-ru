## P502035: Определенное пользователем свойство '<x>' со значением '<y>' не определено в диалоговом окне 'Конфигурировать свойства'

### Причина

В проверяемой базе данных изделий найдено изделие с определенными пользователем свойством '<x>' и значением '<y>'. Определенное пользователем свойство не определено в диалоговом окне Конфигурировать свойства. Это может произойти, если вы импортируете изделия из Eplan версии 2.9 с определенными пользователем свойствами изделий или схемами для определенных пользователем свойств.

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Переместите вкладку Определенные пользователем свойства на передний план.
3. Выберите пункт всплывающего меню Конфигурировать свойства.
4. Внесите нужную конфигурацию в диалоговое окно Конфигурировать свойства, затем закройте его.
5. Обработайте определенное пользователем свойство во все еще открытой вкладке.
6. Щелкните по кнопке [Применить].
7. При необходимости запустите новый контрольный прогон.
8. Закройте управление изделиями и выполните синхронизацию данных изделий.
