## P001035: Несколько выводов распределенных клемм с одинаковым обозначением: \<x\>

### Причина

Несколько выводов одной распределенной клеммы в проекте получили одно и то же обозначение вывода устройства.

### Решение

1. Установите местоположение соответствующей распределенной клеммы в проекте при помощи функции Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Вызовите через всплывающее меню диалоговое окно "Свойства" распределенной клеммы и задайте на первой вкладке в поле Обозначение вывода устройства однозначные обозначения выводов устройств для всех выводов устройств.
3. При необходимости запустите новый контрольный прогон.
