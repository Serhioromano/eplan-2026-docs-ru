## P007005: Устройство без главной функции

### Причина

Вы вставили устройство с распределенными функциями в схему соединений. При этом ни одна из функций не обозначена как главная функция.

!!! note "Замечание:"

    Это сообщение также выводится для отдельно размещеннойфункции, которая не обозначена как главная функция.

### Решение

Сделайте одну из размещенных функций устройства главной функцией.

1. Дважды щелкните по соответствующему условному обозначению и выберите в диалоговом окне Свойства ++...++ вкладку Данные символа / функции.
2. В групповом поле Данные функции (логика) установите флажок Главная функция.
3. Щелкните по кнопке ++OK++.
4. При необходимости запустите новый контрольный прогон.
