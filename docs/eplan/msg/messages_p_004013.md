## P004013: Каркас '<x>': кольцевое соединение

### Причина

Обозначение каркаса и указанные данные обозначения каркаса для разъема карты ПЛК ссылаются на два различных блока ПЛК.

!!! example "Пример:"

    На первом блоке ПЛК в полеКаркасвведено обозначениеBGT1, а в полеКарта ПЛК вставлена в каркас— обозначениеBGT2. На втором блоке ПЛК в полеКаркасвведено обозначениеBGT2, а в полеКарта ПЛК вставлена в каркас— обозначениеBGT1.

### Решение

1. Измените данные структуры ПЛК в диалоговом окне Свойства <...> для обоих блоков ПЛК, чтобы обозначения каркасов больше не ссылались друг на друга.
2. Обновите соединения.
3. При необходимости запустите новый контрольный прогон.
