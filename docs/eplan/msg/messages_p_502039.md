## P502039: Ссылка '<x>' в шаблоне функции для прокладки жилы недействительна

### Причина

В проверяемой базе данных изделий был обнаружен предварительно собранный кабель, для которого сохранено такое значение свойства жилы Начальная часть жилы или Концевая часть жилы, которое не ссылается на действительный шаблон функции штекера.

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Выведите на передний план вкладку Шаблоны функции.
3. Введите допустимое значение для соответствующего свойства.
4. Щелкните по кнопке ++Применить++.
5. При необходимости запустите новый контрольный прогон.
6. Закройте управление изделиями и выполните синхронизацию данных изделий.
