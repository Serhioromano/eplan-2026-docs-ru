## P005070: Различные обозначения соединений на одном потенциале

### Причина

Внутри потенциала есть точки определения соединения с различными обозначениями соединений.

### Решение

1. Установите местоположение данной точки определения соединения на схеме соединений, пользуясь функциональностью Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Удалите обозначения соединений или переименуйте их так, чтобы все обозначения соединений внутри потенциала выглядели одинаково.
3. При необходимости запустите новый контрольный прогон.
