## P502005: Присвоенный макросу '<x>' ('<y>' / '<z>') слой '<u>' определен пользователем, сообщение касается свойства изделия '<w>'

### Причина

В проверяемой базе данных изделий было найдено изделие, на котором сохранен макрос с определенным пользователем слоем. В заполнителе '<x>' сообщения выводятся путь и имя макроса, в заполнителях '<y>' и '<z>' вид представления макроса и вариант макроса, в заполнителе '<u>' имя слоя, а в заполнителе '<w>' свойство изделия, на котором вы ввели макрос.

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Переместите вкладку Свойства на передний план.
3. Разверните в представлении в виде дерева таблицы свойств уровень иерархии Данные или Монтажные данные, в зависимости от того, что было указано в сообщении — макрос схемы соединений или графический макрос.
4. Щелкните в поле значений указанного в сообщении контрольного прогона свойства изделия для макроса на [...].
5. Выберите в открывшемся диалоговом окне выбора файл макроса, который содержит макрос с присвоенным специфическим для Eplan слоем.

Или в качестве альтернативы удалите внесенный макрос схемы соединений в поле значений свойства.

Или создайте новый макрос со специфическим для Eplan слоем, сохраните его в нужном каталоге макросов и заново выберите его в свойстве.
6. Щелкните по кнопке [Применить].
7. При необходимости запустите новый контрольный прогон.
8. Закройте управление изделиями и выполните синхронизацию данных изделий.
