## P004121: 'Символический адрес: UDT (тип данных)' не однозначный

### Причина

Внутри карты ЦПУ существует несколько выводов устройства ПЛК, для которых в свойстве Символический адрес: UDT (имя) введено то же значение. Однако на одном или нескольких из этих выводов устройства ПЛК имеются противоречивые значения в отношении свойства Символический адрес: UDT (тип данных).

### Решение

1. Установите местоположение вывода устройства ПЛК на схеме соединений с помощью функции Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Откройте диалоговое окно "Свойства" вывода устройства ПЛК.
3. В таблице свойств введите уникальное значение в поле Символический адрес: UDT (тип данных). Это значение должно совпадать на всех выводах устройства ПЛК внутри карты ЦПУ, для которых свойство Символический адрес: UDT (имя) имеет идентичное значение.
4. Щелкните по кнопке [OK].
5. При необходимости запустите новый контрольный прогон.
