## P011004: Соединение через точки разрыва на той же странице

### Причина

Две или более точки разрыва с одинаковым ОУ, связанные друг с другом перекрестной ссылкой, находятся на одной и той же странице схемы соединений. На одной странице схемы соединений может находиться только одна точка разрыва с одинаковым ОУ.

### Решение

1. Поочередно установите местоположение точек разрыва на схеме соединений, воспользовавшись функцией Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Разместите все лишние точки разрыва с одинаковым ОУ на разных страницах схемы соединений.
3. Обновите соединения.
4. При необходимости запустите новый контрольный прогон.
