## P026107: Необходим новый расчет общего веса для электрошкафа '<x>'

### Причина

Значение общего веса электрошкафа '<x>' изменилось, поэтому необходимо рассчитать его заново.

!!! note "Замечание:"

### Решение

1. Выберите следующие команды: Вкладка Инструменты > группа команд Отчеты > раскрывающаяся кнопка [Генерация отчета по проекту] > Рассчитать общий вес шкафа.
2. Затем снова запустите контрольный прогон.
