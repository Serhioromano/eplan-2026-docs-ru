## P033005: Недействительное имя кабельной сборки соединения

### Причина

На схеме соединений обнаружено соединение, которому было присвоено имя кабельной сборки, но для которого отсутствует определение кабельной сборки с идентичным именем кабельной сборки. Вероятно, соединение было скопировано из схемы соединений другого проекта и вставлено в открытый на данный момент проект, или имена кабельных сборок в определениях кабельных сборок в дальнейшем были переименованы.

### Решение

Если соединение не присвоено определению кабельной сборки, удалите имя кабельной сборки из соединения. Или же присвойте соединению существующее имя кабельной сборки, которое сохранено на определении кабельной сборки.

1. Установите местоположение точки определения группы соединений соединения на схеме соединений при помощи функции Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Откройте диалоговое окно свойств точки определения соединения.
3. В таблице свойств на первой вкладке удалите значение свойства Имя кабельной сборки. Или же с помощью кнопки ++...++ в поле значения свойства выберите существующее имя кабельной сборки в определении кабельной сборки.
4. Щелкните по кнопке ++OK++.
5. Обновите соединения.
6. При необходимости запустите новый контрольный прогон.
