## P020018: <x> различается в <y> Настройки

### Описание

Выполнено сравнение проектов, при котором Настройки проверяемого проекта (проект с замечаниями) сравнивались с настройками проекта для сравнения, а также была установлена разница. Это сообщение <x> для структуры папки области настройки в проверяемом проекте выводится на просмотр так же, как и отображается в представлении в виде дерева диалогового окна Настройки (командный путь: Файл > Настройки). <y> указывает число настроек внутри области настройки, которые в проверяемом проекте выявляются на этапе сравнения проектов.

!!! example "Пример:"

    В области настройкиНумерация (автономно)проверяемого проекта схема нумерации изменилась. При этом были добавлены дополнительныеэлементы формата. При сравнении проектов сообщение могло бы выглядеть следующим образом:"Устройство+нумерация (автономно)+элементыформыразличаются в 5 настройках".
