## P005024: Точка определения соединения без свойств

### Причина

На соединении определена точка определения соединения без свойств.

### Решение

1. Установите местоположение точки определения соединения на схеме соединений, воспользовавшись функцией Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Вызовите диалоговое окно Свойства ++"..."++ точки определения соединения и заполните поля свойств значениями, например, для обозначения соединения, поперечного сечения или диаметра и / или цвета.
3. При необходимости запустите новый контрольный прогон.
