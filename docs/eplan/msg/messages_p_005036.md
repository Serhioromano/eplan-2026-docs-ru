## P005036: Превышено минимальное число разрядов для формата (<x>)

### Причина

Минимальное число разрядов для элемента формата нумерации соединений больше, чем указано в настройках.

### Решение

Чтобы это сообщение не выводилось, увеличьте минимальное число разрядов для соответствующего элемента формата.

Настройка выполняется следующим образом:

1. Выберите следующие команды: Вкладка Соединения > группа команд Соединения > Обозначить.
2. Нажмите в диалоговом окне Обозначить соединения рядом с полем Настройки на кнопку ++...++.
3. В диалоговом окне Настройки: Нумерация соединений — <Имя проекта> переместите вкладку Обозначение на передний план.
4. Выделите в списке Группы форматов необходимую группу соединений и щелкните  (Обработать).
5. Выделите в диалоговом окне Нумерация соединений: Форматы необходимый элемент формата в списке Выбранные элементы формата и щелкните  (Обработать).

Откроется диалоговое окно Формат: <Элемент формата, содержащий поле настройки Мин. число разрядов.

!!! note "Замечание:"

    Это сообщение, относящееся к модулю, выводится при нумерации соединений. При выполнении нового контрольного прогона (любой настроеннойсхемы) его можно удалить из диалогового окна управления сообщениями.
