## P502026: Вывод шины '<x>', внесенный в шаблоны функций изделия, не найден в однополюсном представлении в макросе '<y>', сообщение касается свойства изделия '<z>'

### Причина

В проверяемой базе данных изделий было найдено изделие, для которого определен шаблон функции вывода шины '<x>'. В соответствующем макросе '<y>', расположенном на уровне иерархии Данные в управлении изделиями в свойстве изделия '<z>', отсутствует вывод шины в однополюсном представлении.

### Решение

1. Дополните вывод шины в макросе в однополюсном представлении.
2. Сохраните изменение в макросе.
3. Снова создайте в управлении изделиями макрос для соответствующего свойства изделия.
4. Щелкните по кнопке [Применить].
5. При необходимости запустите новый контрольный прогон.
6. Закройте управление изделиями и выполните синхронизацию данных изделий.
