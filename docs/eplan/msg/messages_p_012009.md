## P012009: Изделие размещения изделия присутствует на главной функции в недостаточном количестве

### Причина

#### Возможность 1

Размещение изделия на странице типа "Компоновка электрошкафа" имеет определенный номер изделия и вариант. Соответствующей соединяемой с размещением изделия главной функции на странице схемы соединений не присвоен никакой номер изделия, присвоен другой номер изделия или другой вариант изделия.

#### Возможность 2

Размещение изделия с определенным номером изделия и вариантом было несколько раз вставлено на странице типа "Компоновка электрошкафа". Соответствующая соединяемая с размещением изделия главная функция на странице схемы соединений имеет тот же номер изделия и вариант, но на изделии в свойстве Число штук / количество указано значение, которое меньше вставленного на странице типа "Компоновка электрошкафа" числа размещений изделия.

### Решение

#### Для возможности 1

Введите для размещения изделия на странице типа "Компоновка электрошкафа" и главной функции на схеме соединений одинаковый номер изделия и вариант.

#### Для возможности 2

Приведите введенное значение для свойства Число штук / количество в свойствах изделия главной функции на схеме соединений в соответствие с числом вставленных на странице типа "Компоновка электрошкафа" размещений изделия. Т. е. либо увеличьте значение числа для свойства Число штук / количество для главной функции, либо удалите избыточное число размещений изделия.

* * *

При необходимости запустите новый контрольный прогон.
