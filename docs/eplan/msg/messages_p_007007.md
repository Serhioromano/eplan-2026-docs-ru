## P007007: Отсутствует место монтажа (описывающее)

### Причина

Не указано описывающее место монтажа для функции.

### Решение

1. Дважды щелкните по соответствующему условному обозначению и введите в диалоговом окне Свойства ++...++ отсутствующую информацию в поле Место монтажа (описывающее).
2. Щелкните по кнопке ++OK++.
3. При необходимости запустите новый контрольный прогон.
