## P004098: Неверный формат ОУ

### Причина

При импорте данных шины ПЛК обнаружен узел ПЛК с неверным форматом ОУ или без ОУ. Это происходит, если, например, предшествующие знаки "=", "+", "-" забыты в программе конфигурации ПЛК и из-за этого невозможно выполнить однозначное присвоение к свойствам структуры (функциональное назначение, место установки, ОУ).

### Решение

#### Возможность 1

1. Установите местоположение объекта на схеме соединений с помощью функции Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Выберите следующие команды: Файл > Настройки > Проекты > "Имя проекта" > Устройства > Синтаксическая проверка ОУ.
3. Установите в групповом поле Обозначение устройства на вкладке Электротехника флажок Допустимые спец. символы, чтобы использовать символы "+", "-", "_", "*" и "?".
4. Кроме того, если необходимо использовать в обозначении устройства специальные текстовые символы, например, умлауты, установите флаг Текстовые специальные символы.
5. Введите без разделителей символы, определенные как допустимые, в находящее рядом поле.
6. После изменения запустите любой контрольный прогон, чтобы удалить сообщение.
7. Еще раз выполните импорт данных ПЛК.

#### Возможность 2

Измените ОУ в используемой программе конфигурации ПЛК и повторно запустите импорт ПЛК.

!!! note "Замечание:"

    Это относящееся к модулю сообщение можно удалить при выполнении нового контрольного прогона (любой настроеннойсхемы) из диалогового окна управления сообщениями.
