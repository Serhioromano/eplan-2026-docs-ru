## P004051: Соединение отсутствует! '\<x\>' не соединено с физической сетью '\<y\>'

### Причина

Согласно файлу импорта устройство '\<x\>' соединено с физической сетью '\<y\>'. Однако, в проекте соединение с ней не было обнаружено.

### Решение

1. Установите соединение устройства с физической сетью посредством вывода шины.
2. Еще раз выполните импорт данных ПЛК.

!!! note "Замечание:"

    Это относящееся к модулю сообщение можно удалить при выполнении нового контрольного прогона (любой настроеннойсхемы) из диалогового окна управления сообщениями.
