## P502029: Внесенное на модуль '<x>', вариант '<y>', изделие '<z>', вариант '<u>', не имеет ни ОУ, ни идентификатора ОУ

### Причина

В проверяемой базе данных изделий определен модуль, на котором указано подизделие (т. н. позиция модуля) без ОУ и идентификатора ОУ. В заполнителе <x> выводится номер изделия модуля, в заполнителе <y> — вариант модуля, в заполнителе <z> — номер изделия, а в заполнителе <u> — вариант указанного подизделия.

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.

Соответствующий вариант внесенного в модуль подизделия, будет выделен в дереве управления изделиями.
2. Переместите вкладку Модуль на передний план.
3. Присвойте соответствующее значение в таблице свойств в столбце ОУ и / или в столбце Идентификатор ОУ.
4. Щелкните по кнопке ++Применить++.
5. При необходимости запустите новый контрольный прогон.
6. Закройте управление изделиями и выполните синхронизацию данных изделий.
