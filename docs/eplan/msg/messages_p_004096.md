## P004096: Многократно заданный адрес (отказоуст.): цель '<x>'

### Причина

Как минимум в двух релевантных для безопасности блоках ПЛК в проекте введено одинаковое значение свойства Адрес (отказоуст.): цель.

### Решение

1. Определите местоположение блоков ПЛК на схеме соединений с помощью функций Перейти к (графика) и Перейти к (2-я координата) во всплывающем меню диалогового окна Управление сообщениями.
2. Поочередно откройте диалоговое окно 'Свойства' каждого блока ПЛК.
3. Переместите первую вкладку на передний план.
4. Введите в таблице свойств в поле Адрес (отказоуст.): цель уникальное значение.
5. Щелкните по кнопке ++OK++.
6. При необходимости запустите новый контрольный прогон.
