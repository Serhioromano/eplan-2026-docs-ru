## P002001: Вывод контакта штекера имеет слишком много целей: <x>. Макс. число целей: <y>

### Причина

Как минимум одно из двух выводов устройства функции контакта штекера соединено с большим числом условных обозначений, чем указано.

### Решение

#### Возможность 1

1. Щелкните дважды в схеме соединений на контакт штекера и выберите в диалоговом окне Свойства ++...++ вкладку Данные символа / функции.
2. Щелкните в групповом поле Данные функции (логика) по кнопке ++Логика++.
3. В диалоговом окне Логическая схема выводов устройства следует проверить, какие значения введены в строке Число целей для обоих выводов устройства функции контакта штекера
4. Увеличьте до требуемого уровня настроенное значение для одного или обоих выводов устройства функции.

#### Возможность 2

1. Щелкните дважды в схеме соединений на контакт штекера и выберите в диалоговом окне Свойства ++...++ вкладку Данные символа / функции.
2. Щелкните в групповом поле Данные функции (логика) по кнопке ++Логика++.
3. В диалоговом окне Логическая схема выводов устройства следует проверить, какие значения введены в строке Число целей для обоих выводов устройства функции контакта штекера
4. Удалите соответствующие условные обозначения, которых размещено слишком много, на соответствующем выводе устройства функции контакта штекера в схеме соединений.

* * *

Обновите соединения.

При необходимости запустите новый контрольный прогон.
