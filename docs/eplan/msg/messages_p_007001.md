## P007001: Устройство использует больше функций, чем предоставлено соответствующим изделием

### Причина

К устройству, которое размещено как изделие с шаблонами функций (устройство) добавлена еще одна функция, и ей присвоено ОУ устройства. Изделие не предоставляет возможность такого дополнения функции.

### Решение

#### Возможность 1

Выберите изделие с соответствующими шаблонами функций.

#### Возможность 2

Расширьте в базе данных изделий число шаблонов функций для выбранного изделия.

1. Выберите следующие команды: Вкладка Основные данные > группа команд Изделия > Управление.
2. Выберите в диалоговом окне База данных изделий вкладку Шаблоны функций.
3. Щелкните по кнопке  (Создать), расположенной над таблицей. После этого вставляется новая строка.
4. Щелкните по ячейке в первом столбце, а затем нажмите [...].
5. Выберите требуемую функцию в диалоговом окне Определения функций, на которую требуется расширить изделие.
6. Подтвердите выбор, нажав кнопку [OK], и примените измененную настройку в базе данных изделий.
7. Затем еще раз разместите символ устройства в схеме соединений.

* * *

При необходимости запустите новый контрольный прогон.

!!! note "Замечание:"

    Сообщение выводится также в следующей ситуации: Одна из функций в одном из устройств была обозначена какЗащитная функция. Однако в выбранном изделии соответствующий шаблон функциинеопределен как защитная функция.
