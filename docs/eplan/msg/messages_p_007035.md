## P007035: Нет действительного обратного эквивалента или количество целей не равно 1: Вывод устройства '<x>' (Механический канал)

### Причина

Вы разместили на схеме соединений втулочный или стержневой трансформатор тока и при этом используете один из символов "LSW1A", "LSW2A" или "LSW3A" с определением функции "Трансформатор тока, индукционный". Выводы устройства "1" и "2" для этих функций имеют сквозное соединение с точки зрения логической схемы выводов устройства, которое определено как тип вывода устройства "Механический канал".

В каждом конкретном случае свойство Тип вывода устройства отличается от значения "Механический канал" как минимум на одном из функциональных выводов устройства, поэтому действительного обратного эквивалента не существует. Или же настройка Передать потенциал в на одном из функциональных выводов устройства имеет такое значение, которое делает передачу потенциала невозможной. Это сообщение также выводится, если для свойства Число целей было выбрано значение, не соответствующее "1".

### Решение

1. Установите местоположение этой функции на схеме соединений с помощью функции Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Вызовите диалоговое окно свойств функции.
3. Выведите на передний план вкладку Данные символа / функции.
4. Щелкните кнопку [Логика].
5. В диалоговом окне Логическая схема выводов устройства проверьте и измените значения следующих свойств на функциональных выводах устройства "1" и "2":
– Тип вывода устройства: для обоих функциональных выводов устройства выберите запись "Механический канал".
– Передать потенциал в: на выводе устройства функции "1" введите "2", а на выводе устройства функции "2" введите "1".
– Число целей: установите значение "1" на обоих функциональных выводах устройства.
6. Щелкните по кнопке [OK].
7. При необходимости запустите новый контрольный прогон.
