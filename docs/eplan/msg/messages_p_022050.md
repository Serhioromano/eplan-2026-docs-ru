## P022050: GUID (AutomationML) '\<x\>' неоднозначен

### Причина

В проекте несколько функций имеют идентификатор GUID с одинаковым значением '\<x\>'. Для экспорта в AutomationML каждая функция должна иметь уникальный GUID.

### Решение

#### Возможность 1

1. Установите местоположение главных функций с многократно заданным в проекте идентификатором GUID с помощью функции Перейти к (графика) или Синхронизировать выбор во всплывающем меню диалогового окна Управление сообщениями.
2. Вызовите диалоговое окно Свойства для каждой главной функции.
3. В таблице свойств в поле GUID (AutomationML) задайте однозначное значение.
4. Щелкните по кнопке ++OK++.

#### Возможность 2

1. Выберите следующие команды: Файл > Организовать > Оптимизировать > Сжать проект
2. Щелкните в диалоговом окне Сжать проект рядом с полем Настройки по ++"..."++.
3. Перейдите в следующем диалоговом окне через Убрать данные проекта к настройке AutomationML GUIDs и установите этот флажок.
4. Щелкните по кнопке ++OK++.

Идентификаторы AutomationML GUIDs будут удалены для всех функций.
5. Повторно экспортируйте данные в формате AutomationML.

Идентификаторы AutomationML GUIDs будут заново присвоены для каждой функции.

* * *

При необходимости запустите новый контрольный прогон.
