## P013056: Изделие с номером изделия '<x>' и вариантом '<y>' не существует в базе данных

### Причина

В проекте обнаружено сохраненное изделие, номер или сохраненный в проекте вариант которого отсутствует в базе данных изделий. Возможно, изделие или вариант изделия были удалены из базы данных изделий, или номер изделия был изменен в базе данных изделий.

### Решение

#### Возможность 1

Для размещенных изделий или вариантов изделий:

1. Установите местоположение объекта с сохраненным изделием или вариантом изделия, пользуясь функциональностью Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Откройте диалоговое окно Свойства объекта и выведите вкладку Изделия на передний план.
3. Замените данное изделие или вариант изделия на подходящее изделие или подходящий вариант изделия из базы данных изделий.
4. При необходимости запустите новый контрольный прогон.

#### Возможность 2

Для неразмещенных изделий или вариантов изделий:

1. Очистите проект. Выберите следующие команды: Файл > Дополнительно > группа команд Организовать > Проект > группа команд Оптимизировать > Сжать проект.
2. Выберите в поле Настройки диалогового окна Сжать проект схему "Убрать избыточные данные проекта" и перейдите с помощью кнопки ++...++ к настройкам для сжимаемых данных.
3. Установите флажок Убрать данные проекта и в нижестоящей ветке дополнительно установите флажки Неиспользованные изделия и Неиспользованные варианты изделий.
4. Подтвердите ввод.
5. При необходимости запустите новый контрольный прогон.

!!! note "Замечание:"

    Этот контрольный прогон не активирован по умолчанию и может быть выполнен только в автономном режиме.
