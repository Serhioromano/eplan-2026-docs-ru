## P004120: 'Символический адрес: UDT (тип данных)' пуст, хотя 'Символический адрес: UDT (имя)' существует

### Причина

Внутри карты ЦПУ найден вывод устройства ПЛК с неполными данными UDT. В конкретном случае на выводе устройства ПЛК в свойстве Символический адрес: UDT (имя) вводится значение, но значение типа данных отсутствует для свойства Символический адрес: UDT (тип данных).

### Решение

1. Установите местоположение вывода устройства ПЛК на схеме соединений с помощью функции Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Откройте диалоговое окно "Свойства" вывода устройства ПЛК.
3. В таблице свойств введите тип данных в поле Символический адрес: UDT (тип данных). Это значение должно совпадать на всех выводах устройства ПЛК внутри карты ЦПУ, для которых свойство Символический адрес: UDT (имя) имеет идентичное значение.
4. Щелкните по кнопке ++OK++.
5. При необходимости запустите новый контрольный прогон.
