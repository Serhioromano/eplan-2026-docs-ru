## P004052: Соединение с неверной физической сетью! '<x>' должно быть соединено с физической сетью '<y>'

### Причина

Во время последнего импорта данных ПЛК было обнаружено устройство, соединенное с неверной физической сетью.

### Решение

1. Проверьте свойство Физическая сеть: Имя на указанном выводе устройства.
2. Еще раз выполните импорт данных ПЛК.

!!! note "Замечание:"

    Это относящееся к модулю сообщение можно удалить при выполнении нового контрольного прогона (любой настроеннойсхемы) из диалогового окна управления сообщениями.
