## P502010: Внесенное на узле / модуле изделие '<x>', вариант '<y>', отсутствует

### Причина

В проверяемой базе данных изделий было найдено внесенное на узле или модуле изделие, которое не существует как запись данных в базе данных изделий. Eplan отображает имя изделия в заполнителе <x> и вариант изделия в заполнителе <y>.

### Решение

1. Откройте базу данных изделий и создайте сначала требуемое изделие в базе данных изделий. Или импортируйте изделие.
2. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.

Соответствующий узел / соответствующий модуль будет выделен в дереве управления изделиями.
3. Переместите вкладку Узел или Модуль на передний план.
4. Выберите в поле Номер изделия новое созданное изделие.
5. Щелкните по кнопке ++Применить++.
6. При необходимости запустите новый контрольный прогон.
7. Закройте управление изделиями и выполните синхронизацию данных изделий.
