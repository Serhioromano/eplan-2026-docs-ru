## P022014: Свойство '<x>' для определения 'Число / имена страниц на свойство' на странице '<y>' является пустым

### Причина

Свойству, выбранному в настройке Число / имена страниц на свойство, не присваивается на странице проекта никакого значения.

### Решение

1. Дважды щелкните "Cообщение" в диалоговом окне Управление сообщениями и определите место соответствующей страницы в древовидной структуре навигатора страниц.
2. Откройте для страницы с помощью всплывающего меню диалоговое окно Свойства страницы и задайте значение для указанного в тексте сообщения свойства, которое выбрано в настройках для страниц (командный путь: Файл > Настройки > Проекты > "Имя проекта" > Управление > Страницы > Число / имена страниц на свойство).
3. Выберите команду Число / имена страниц на свойство. (Для этого вам нужно сначала [Настроить ленту](userinterface_h_menuebandanpassen.md) и присвоить нужную команду определенной пользователем группе команд.)

Результат записывается в свойства страницы Количество страниц в свойстве, Имена страниц в свойстве и Счетчик страниц в свойстве.
4. При необходимости запустите новый контрольный прогон.
