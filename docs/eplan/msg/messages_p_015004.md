## P015004: Форма '<x>' используется в форме '<y>', но не сохранена в проекте

### Причина

Для отчетов используется форма <y>, для которой отображена следующая форма <x>. При этом следующая форма в текущем проекте не загружена.

### Решение

1. Загрузите в проект следующую форму <x>.
2. При необходимости запустите новый контрольный прогон.
