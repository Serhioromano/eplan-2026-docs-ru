## P004118: Отсутствующее имя ЦПУ на карте ПЛК в проекте конфигураций '<x>' с несколькими ЦПУ

### Причина

В проекте конфигураций, содержащем несколько ЦПУ, есть карта ПЛК с начальным адресом, который не может быть присвоен ни одному из ЦПУ, поскольку имя ЦПУ не было указано.

### Решение

1. Установите местоположение блока ПЛК карты ПЛК на схеме соединений с помощью функции Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Вызовите диалоговое окно "Свойства" блока ПЛК и переместите вкладку Данные структуры на передний план.
3. В таблице свойств для свойства ЦПУ:Имя [1] в проекте конфигураций выберите имя ЦПУ, которому нужно присвоить карту ПЛК.
4. Щелкните по кнопке [OK].
5. При необходимости запустите новый контрольный прогон.
