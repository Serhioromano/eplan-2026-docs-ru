## P021002: Объект-заполнитель не содержит ссылки объектов

### Причина

При расширении объекта-заполнителя были случайно удалены прежние ссылки объекта. Из-за этого объект-заполнитель содержит переменные и наборы значений, но не имеет ссылки объекта в таблице на вкладке Присвоение.

### Решение

Чтобы расширить объекты-заполнители, выполните приведенные ниже действия.

1. Нажмите клавишу ++Ctrl++ и удерживайте ее нажатой.
2. Щелкните друг за другом по тем объектам в схеме соединений, которые должны стать частями объекта-заполнителя.
3. Отпустите клавишу ++Ctrl++ и щелкните по объекту-заполнителю правой клавишей мыши.
4. Выберите пункт всплывающего меню Присвоить объекты объекту-заполнителю и дважды щелкните по объекту-заполнителю.

На вкладке Присвоение диалогового окна Объект-заполнитель в таблице теперь выведены свойства всех выделенных объектов.
5. Присвойте требуемому свойству объекта переменную с соответствующим значением.
6. При необходимости запустите новый контрольный прогон.
