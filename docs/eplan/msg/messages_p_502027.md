## P502027: Данные вывода устройства на выводе шины заполнены

### Причина

В проверяемой базе данных изделий было найдено изделие, на котором определен шаблон функции с определением функции "Кабельный вывод сети / шины". На шаблоне функции данные выводов устройства (обозначения выводов устройства, описания выводов устройства, сечение вывода устройства и / или размер присоединения) заполнены значениями.

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Выведите на передний план вкладку Шаблоны функций с таблицей Выбор устройства (шаблоны функций).
3. Удалите значения на шаблоне функции вывода шины в столбцах Обозначения выводов устройства, Описания выводов устройства, Сечение вывода устройства и Размер присоединения.
4. Щелкните по кнопке [Применить].
5. При необходимости запустите новый контрольный прогон.
6. Закройте управление изделиями и выполните синхронизацию данных изделий.
