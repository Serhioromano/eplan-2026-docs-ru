## P003026: Не задана длина кабеля

### Причина

На главной функции кабеля не указана длина кабеля.

### Решение

1. Определите из диалогового окна Управление сообщениями главную функцию кабеля в схеме соединений с помощью функциональности Перейти к (графика).
2. Щелкните там двойным щелчком по выделенной линии определения кабеля и вызовите диалоговое окно Свойства <...> кабеля.
3. Перейдите — если не установлено по умолчанию — на вкладку Кабель и укажите в поле Длина количество жил.
4. Щелкните по кнопке [OK].
5. При необходимости запустите новый контрольный прогон.
