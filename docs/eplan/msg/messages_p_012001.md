## P012001: Размещению изделия не присвоено изделие

### Причина

Отсутствует номер изделия у размещения изделия на монтажной плате.

### Решение

1. Дважды щелкните по соответствующему размещению изделия на монтажной плате.
2. Выберите в диалоговом окне Свойства ++"..."++ размещения изделия отсутствующий номер в поле Изделие.
3. При необходимости запустите новый контрольный прогон.
