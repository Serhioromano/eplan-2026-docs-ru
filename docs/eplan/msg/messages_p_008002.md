## P008002: Пустое текстовое поле

### Причина

Вы пытались перевести текст в текстовом поле для графического текста или для функционального текста зоны, в которое не введена символьная строка.

### Решение

1. Вызовите на экран из диалогового окна Управление сообщениями соответствующий текст, воспользовавшись функцией Перейти к (...).
2. Откройте диалоговое окно "Свойства" текстового поля.
3. Заполните соответствующее текстовое поле текстом и переведите его.

!!! note "Замечание:"

    Это сообщение, относящееся к модулю, выводится при автоматическом переводе текстов. При выполнении нового контрольного прогона (любой настроеннойсхемы) его можно удалить из диалогового окна управления сообщениями.
