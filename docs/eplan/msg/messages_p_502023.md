## P502023: Шаблоны функций узла / модуля '<x>', вариант '<y>', неактуальны

### Причина

В проверяемой базе данных изделий в варианте '<y> был 'определен узел / модуль '<x>', шаблоны функций которого уже неактуальны.

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Выберите пункт меню ++Дополнительно++ > Объединить шаблоны функций.

Находящиеся на подизделиях узлов / модулей шаблоны функций будут объединены и обновлены.
3. При необходимости запустите новый контрольный прогон.
