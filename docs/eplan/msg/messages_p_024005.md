## P024005: Связать неопределенный вывод устройства (напорная линия / блок управления) с определенным выводом устройства (напорная гидролиния / блок управления)

### Причина

Функции, имеющиеся на соединении, противоречат друг другу на выводах устройства функций с точки зрения настроенного свойства Рабочая линия/блок управления. Например, для источника соединения установлена "Рабочая линия", а для цели — "Не определено".

### Решение

1. Присвойте источнику и цели соединения на выводах устройства функций совпадающие данные с точки зрения свойства Рабочая линия/блок управления. Это свойство настраивается в диалоговом окне Логическая схема выводов устройства соответствующей функции (запустите диалоговое окно Свойства ++"..."++, выберите вкладку Данные символа / функции и нажмите ++Логическая схема++).
2. Обновите соединения.
3. При необходимости запустите новый контрольный прогон.
