## P004099: Карта ПЛК с идентификацией устройства '<x>' не вставлена в первичную станцию

### Причина

На карте ПЛК с идентификацией устройства '<x>', которая вставлена в определенный каркас, с помощью активированного свойства Карта ПЛК вставлена в первичную станцию документируется, что каркас является первичной станцией. Карта ПЛК, которая представляет каркас, не является первичной станцией. Первичная станция характеризуется тем, что сама является каркасом и в данных структуры ПЛК установлен либо флажок Шинный интерфейс / первичная станция, либо флажок ЦПУ.

### Решение

1. Установите местоположение вставленной в каркас карты ПЛК на схеме соединений с помощью функции Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Выберите пункт Перейти к (2-я координата) из всплывающего меню, чтобы сразу перейти к блоку ПЛК, который представляет каркас.
3. Откройте диалоговое окно свойств блока ПЛК.
4. Переместите вкладку Данные структуры ПЛК на передний план.
5. Установите в таблице свойств флажок для свойства Шинный интерфейс / первичная станция и / или ЦПУ.
6. Щелкните по кнопке [OK].
7. При необходимости запустите новый контрольный прогон.

!!! note "Замечание:"

    Если перейти к каркасу невозможно, значит, он не определен. В таком случае выберите или создайте сначала карту ПЛК, которая будет служить в качестве каркаса. Присвойте этому каркасу (вторая вкладка, полеКаркас) значение, которое вы задали в карте ПЛК, которая должна быть вставлена в каркас (вторая вкладка, полеКарта ПЛК вставлена в каркас). Не забудьте задекларировать определенный таким образом каркас в качествешинного интерфейса / первичной станциии / илиЦПУ.
