## P008001: Текст '<x>' не может быть переведен на язык <y>

### Причина

Отсутствуют необходимые записи (ключевые слова) в соответствующем языке словаря.

### Решение

1. Выберите следующие команды: Вкладка Инструменты > группа команд Перевод > Словарь.
2. Проверьте в диалоговом окне Словарь используемые языки словаря. Если требуемый язык словаря отсутствует в списке на вкладке Управление, добавьте его с помощью кнопки  (Создать).
3. Затем перейдите на вкладку Обработать слова и выберите из раскрывающегося списка Исходный язык нужный язык.
4. Введите в поле Поиск соответствующие ключевые слова и проверьте, имеются ли необходимые тексты перевода на данном языке словаря.
5. Если нет, создайте отсутствующие ключевые слова на исходном языке и соответствующие тексты перевода на нужном языке словаря или добавьте их, использовав кнопку  (Создать).
6. Закройте диалоговое окно Словарь и переведите необходимые тексты.

!!! note "Замечание:"

    Это сообщение, относящееся к модулю, выводится при автоматическом переводе текстов. При выполнении нового контрольного прогона (любой настроеннойсхемы) его можно удалить из диалогового окна управления сообщениями.
