## P001008: Вывод клеммы имеет слишком много целей: <x>. Макс. число целей: <y>

### Причина

Как минимум один из выводов устройства функции клеммы соединен с большим числом условных обозначений, чем указано.

### Решение

#### Возможность 1

1. Щелкните дважды в схеме соединений по клемме и выберите в диалоговом окне Свойства ++"..."++ вкладку Данные символа / функции.
2. Щелкните в групповом поле Данные функции по кнопке ++Логика++.
3. В диалоговом окне Логическая схема выводов устройства следует просмотреть, какие значения в строке Число целей настроены для выводов устройства функции клеммы.
4. Увеличьте до требуемого уровня настроенное значение для выводов устройства функции.

#### Возможность 2

1. Щелкните дважды в схеме соединений по клемме и выберите в диалоговом окне Свойства ++"..."++ вкладку Данные символа / функции.
2. Щелкните в групповом поле Данные функции по кнопке ++Логика++.
3. В диалоговом окне Логическая схема выводов устройства следует просмотреть, какие значения в строке Число целей настроены для выводов устройства функции клеммы.
4. Удалите соответствующие условные обозначения, которых размещено слишком много, на соответствующем выводе устройства функции клеммы в схеме соединений.

* * *

Обновите соединения.

При необходимости запустите новый контрольный прогон.
