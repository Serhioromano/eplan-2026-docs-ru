## P502003: Записанный на изделии документ '<x>' отсутствует

### Причина

В проверяемой базе данных изделий было найдено изделие, на котором сохранен документ, который Eplan не может найти.

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Переместите вкладку Свойства на передний план.
3. В таблице свойств разверните уровни иерархии Документы > Внешний документ: файл / гиперссылка, чтобы отобразились индексированные свойства.
4. В поле значений индексированного свойства, которое содержит документ из управления сообщениями, нажмите ++"..."++.
5. Выберите документ в открывшемся диалоговом окне выбора.

Или в качестве альтернативы удалите внесенный документ в поле значений свойства.

Или сохраните новый документ в нужном каталоге документов и заново выберите его в индексированном свойстве.
6. Щелкните по кнопке ++Применить++.
7. При необходимости запустите новый контрольный прогон.
8. Закройте управление изделиями и выполните синхронизацию данных изделий.
