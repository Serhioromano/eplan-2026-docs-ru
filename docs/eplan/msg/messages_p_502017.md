## P502017: В изделии не выбран раздел

### Причина

В проверяемой базе данных изделий было найдено изделие, на котором не указан раздел.

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Переместите вкладку Свойства на передний план.
3. В таблице свойств разверните уровень иерархии Разделы.
4. В поле значений активируйте флажок хотя бы на одном из перечисленных свойств разделов.
5. Если изделие имеет подразделы, разверните уровни иерархии соответствующих подразделов с индексированными свойствами и введите обозначение в нужном свойстве.
6. Щелкните по кнопке ++OK++.
7. Щелкните по кнопке ++Применить++.
8. При необходимости запустите новый контрольный прогон.
9. Закройте управление изделиями и выполните синхронизацию данных изделий.
