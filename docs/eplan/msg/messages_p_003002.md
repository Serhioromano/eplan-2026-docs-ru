## P003002: Невозможно выполнить автоматический выбор кабеля для этого кабеля, так как соответствующий критерий фильтра не найден

### Причина

Вы создали кабель при помощи автоматического выбора кабеля. Однако у кабеля уже есть созданное вручную определение кабеля, которое включает определенные значения, например, для свойств Число соединений, Напряжение, Поперечное сечение и т. д. И одно или несколько из этих значений не подходит для кабелей, которые вы сохранили в таблице Предв. выбор кабеля для автоматического выбора кабеля. То есть отсутствует подходящее изделие кабеля для определенного вручную кабеля.

!!! example "Пример:"

    Вы определили кабель со значением напряжения 1000 В. Однако в таблице для предв. выбора кабеля имеются толькоизделиякабеля с напряжением 230 В и 400 В.

### Решение

Приведите предварительный выбор кабеля в соответствие с определенными вручную значениями свойств.

1. Выберите следующие команды: Файл > Настройки > Проекты > "Имя проекта" > Устройство > Кабель (автоматически).
2. Нажмите на ++...++ рядом с полем Автоматический выбор кабеля.
3. Нажмите в диалоговом окне Настройки: Автоматический выбор кабеля на панели инструментов таблицы Предв. выбор кабеля на кнопку  (создать).
4. Перейдите в представлении в виде дерева открывшегося окна выбора изделия через уровни иерархии Изделие > Электротехника > Отдельная часть к группе продуктов Кабели и выберите изделие кабеля с соответствующими значениями свойств.
5. Подтвердите ввод.
6. Затем повторно автоматически сгенерируйте кабель.

!!! note "Замечание:"

    Это относящееся к модулю сообщение выводится при автоматическом выборе кабеля. При выполнении нового контрольного прогона (любой настроеннойсхемы) его можно удалить из диалогового окна управления сообщениями.
