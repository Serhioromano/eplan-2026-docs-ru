## P001010: Отсутствует определение клеммника

### Причина

Вы создали клемму без определения клеммника в навигаторе клеммников или разместили ее в схеме соединений.

### Решение

#### Возможность 1

1. Выделите клемму в навигаторе клеммников.
2. Выберите пункт всплывающего меню Создать.
3. Перейдите в представлении в виде дерева открывшегося диалогового окна (через узлы Электротехника > Клеммы и штекеры > Определение клеммника > Определение клеммника) к определению функции Определение клеммника.
4. Щелкните по кнопке ++OK++.
5. Присвойте в диалоговом окне Свойства ++...++, в поле Видимое ОУ, ОУ клеммы определению клеммника.

#### Возможность 2

1. Разместите с помощью типа объекта Символы центра вставки определение клеммника на схеме соединений.
2. Присвойте в диалоговом окне Свойства ++...++, в поле Видимое ОУ, ОУ клеммы определению клеммника.
3. Щелкните по кнопке ++OK++.

#### Возможность 3

1. Выделите клемму в навигаторе клеммников.
2. Выберите пункт всплывающего меню Генерировать определение клеммника.
3. В открывающемся диалоговом окне "Свойства" щелкните по кнопке ++OK++.

#### Возможность 4

Воспользуйтесь очисткой проектов.

1. Выберите следующие команды: Файл > Дополнительно > группа команд Организовать > Проект > группа команд Оптимизировать > Очистить проект
2. В диалоговом окне Очистить проект нажмите на кнопку ++...++ рядом с полем Настройки.
3. Нажмите в следующем диалоговом окне в списке корректируемых данных на узел Клеммы и установите флажок Добавить отсутствующие определения клеммников.
4. Подтвердите ввод.

* * *

При необходимости запустите новый контрольный прогон.
