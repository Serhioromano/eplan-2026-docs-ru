## P026044: Схема соединений не определена.

### Причина

На размещении изделия в пространстве листа не определена схема соединений.

### Решение

Укажите на размещении изделия схему соединений.

#### Возможность 1

1. Установите местоположение размещения изделия в пространстве листа с помощью функции Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Вызовите диалоговое окно Свойства <...> размещения изделия.
3. Выведите на передний план вкладку Изделие, запомните указанный на ней номер изделия и закройте диалоговое окно 'Cвойства'.
4. Выберите следующие команды: Вкладка Основные данные > группа команд Изделия > Управление.
5. Перейдите в представлении диалогового окна База данных изделий в виде дерева к тому изделию, которое вы запомнили.
6. Переместите вкладку Свойства на передний план.
7. Нажмите в таблице свойств на уровне иерархии Данные в поле значений свойства Схема соединений на [...].
8. В открывающемся диалоговом окне Выбор схемы соединений — <Имя проекта> выделите имя необходимой схемы соединений и щелкните кнопку [OK].

Имя скопируется в поле Схема соединений на вкладке Свойства, а схема соединений будет присвоена размещению изделия в пространстве листа.

9. Закройте базу данных изделий, сохраните измененные данные и обновите базу данных изделий.

    Если схема соединений в базе данных изделий отсутствует, ее нужно будетсоздатьпозднее. Выполните для этого следующиедействия:

#### Возможность 2

1. Вызовите диалоговое окно Свойства <...> размещения изделия.
2. Выведите на передний план вкладку Схема соединений.
3. Установите флажок Локальная схема соединений.
4. Внесите в таблицу необходимые обозначения выводов устройства вместе с другими данными выводов.
5. Закройте диалоговое окно Свойства <...>, для чего нажмите на кнопку [OK].

* * *

При необходимости запустите новый контрольный прогон.
