## P502040: Свойство '<x>' (значение с единицей измерения '<z>') не содержит единицы измерения: '<y>'

### Причина

В проверяемой базе данных изделий обнаружено изделие, у которого в свойстве типа поля "Значение с единицей измерения" определена группа единиц измерения. При этом для значения свойства данного изделия не указана единица измерения.

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Переместите вкладку Свойства или Определенные пользователем свойства на передний план.
3. Укажите единицу измерения для значения соответствующего свойства.
4. Щелкните по кнопке ++Применить++.
5. При необходимости запустите новый контрольный прогон.
6. Закройте управление изделиями и выполните синхронизацию данных изделий.

!!! note "Замечание:"

    Этот контрольный прогон не активирован по умолчанию и может быть выполнен только в автономном режиме.
