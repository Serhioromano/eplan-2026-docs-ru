## P011003: Точка разрыва без цели

### Причина

Точка разрыва не имеет цель.

### Решение

1. Установите местоположение точки разрыва на схеме соединений с помощью функции Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Соедините как минимум один вывод устройства точки разрыва с другим условным обозначением, чтобы образовалась линия автоматического соединения.
3. Обновите соединения.
4. При необходимости запустите новый контрольный прогон.
