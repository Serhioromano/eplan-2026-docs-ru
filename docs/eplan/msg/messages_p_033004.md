## P033004: Недействительное имя кабельной сборки функции

### Причина

На схеме соединений определена функция, которой было присвоено имя кабельной сборки, но для которой отсутствует определение кабельной сборки с идентичным именем кабельной сборки. Вероятно, функция была скопирована из схемы соединений другого проекта и вставлена в открытый на данный момент проект, или имена кабельных сборок в определениях кабельных сборок в дальнейшем были переименованы.

### Решение

Если функция не присвоена никакому определению кабельной сборки, то удалите имя кабельной сборки из функции. Или же присвойте функции существующее имя кабельной сборки, которое сохранено на определении кабельной сборки.

1. Установите местоположение этой функции на схеме соединений с помощью функции Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Откройте диалоговое окно свойств функции.
3. В таблице свойств на первой вкладке удалите значение свойства Имя кабельной сборки. Или же с помощью кнопки ++...++ в поле значения свойства выберите существующее имя кабельной сборки в определении кабельной сборки.
4. Щелкните по кнопке ++OK++.
5. При необходимости запустите новый контрольный прогон.
