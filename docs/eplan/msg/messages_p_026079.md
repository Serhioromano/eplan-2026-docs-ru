## P026079: Экспорт Rittal - Athex: <x>

### Причина

При экспорте данных несущих шин для машины по оснащению клеммников "Rittal - Athex" была установлена недопустимая настройка и / или недопустимое состояние.

На то, о какой настройке и / или каком состоянии шла речь, указывает заполнитель <x> в сообщении. Выводится следующий заполнитель:

* Несущая шина не экспортирована из-за избыточной длины.

В этом случае была предпринята попытка экспортировать несущую шину, длина которой больше, чем максимальная длина шины, определенная в фирменных настройках для машины по оснащению клеммников Rittal - Athex.

### Решение

Укоротите несущую шину.

1. Выберите следующие команды: Файл > Настройки > Фирма > Автоматическое оснащение > Rittal – Athex.
2. Сначала определите, какая максимальная длина несущей шины задана для машины по оснащению клеммников.
3. Переместите для этого в диалоговом окне Настройки: Rittal - Athex вкладку Машина на передний план и запомните значение, сохраненное в поле Максимальная длина шины.
4. Перейдите в область настроек Пользователь > Графическая обработка > Область ввода данных и в диалоговом окне Настройки: Область ввода данных установите флажок Всегда отображать область ввода данных (3D), чтобы иметь возможность изменять длину несущей шины с помощью области ввода данных.
5. Закройте диалоговое окно Настройки: Область ввода данных нажатием кнопки ++OK++.
6. Установите местоположение несущей шины в пространстве листа, пользуясь функцией Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
7. Вызовите двойным щелчком диалоговое окно Настройки ++"..."++ несущей шины, переместите вкладку Изделие на передний план и запомните значение, записанное в поле Подмножество / длина данных ссылки изделия.
8. Закройте диалоговое окно Свойства ++"..."++ несущей шины, нажав на кнопку ++Отменить++.
9. Выберите следующие команды: Вкладка Обработать > Шина / кабельный канал > Изменить длину.
10. Нажмите на нужный конец несущей шины в пространстве листа, который хотите укоротить.

Рядом с курсором на выделенном конце несущей шины появится точка захвата красного цвета.

Под точкой захвата отображается активированная прежде область ввода данных.
11. Укоротите несущую шину, передвинув точку захвата при помощи мышки в направлении другого конца несущей шины. Проследите при этом за значением, отображаемым в области ввода данных.
12. Щелкните левой кнопкой мыши, если значение в области ввода данных совпадает со значением фирменной настройки для машины по оснащению клеммников Athex (или меньше него).
13. Завершите изменение длины несущей шины с помощью пункта всплывающего меню Прервать операцию.
14. Еще раз выполните экспорт данных.

!!! note "Замечание:"

    Это относящееся к модулю сообщение можно удалить при выполнении нового контрольного прогона (любой настроеннойсхемы) из диалогового окна управления сообщениями.
