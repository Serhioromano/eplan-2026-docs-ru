## P004202: Siemens: Неверный вывод шины: \<x\>

### Причина

Eplan обнаружил неверный вывод шины. В заполнителе '\<x\>' сообщения отображается неверно присвоенная карта ПЛК и свойства вывода шины, которые следует откорректировать. Заполнитель может включать приведенную ниже информацию.

* Вывод шины карты ПЛК с идентификацией устройства '\<y\>' не может содержать обозначение штекера.
* Вывод шины карты ПЛК с идентификацией устройства '\<y\>' содержит неправильное значение как минимум в одном из свойств: 'Система шин', 'Имя интерфейса шины', 'Обозначение штекера'.

### Решение

#### Возможность 1

В первую очередь в заполнителе выводится приведенная ниже информация.

1. Установите местоположение вывода шины на схеме соединений с помощью функции Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Откройте диалоговое окно "Свойства" вывода шины.
3. Переместите вкладку Вывод устройства ПЛК на передний план.
4. Проверьте значение свойства Обозначение штекера и откорректируйте его.
5. Щелкните по кнопке ++OK++.

#### Возможность 2

Следующей в заполнителе выводится приведенная ниже информация.

1. Выполните действия, описанные в пунктах от 1 до 2 возможности 1.
2. Переместите вкладку Данные шины на передний план, если возникли ошибки относительно свойств Система шин, Имя интерфейса шины и / или Обозначение штекера, и откорректируйте их.
3. Щелкните по кнопке ++OK++.

!!! note "Замечание:"

    При проверке обозначений штекера ожидаются значения в формате "P1 R", "P2 R" и т. д. Такиеобозначенияштекера необходимы для обмена данными с порталом SIEMENS STEP 7 TIA Portal. Начиная с версии 19 TIA Portal, по умолчанию используются обозначения штекера в формате "P1R", "P2R" и т. д. (т. е. без пробелов). Начиная с версии 17 TIA Portal, разрешены оба варианта написания, а при импорте обозначения штекера исправляются согласно используемому по умолчанию варианту написания. Поэтому в зависимости от используемой вами версии TIA Portal вы можете игнорировать соответствующие сообщения.
