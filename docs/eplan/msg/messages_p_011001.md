## P011001: Точка разрыва без обозначения устройства

### Причина

На точке разрыва отсутствует указание обозначения устройства.

### Решение

1. Установите местоположение точки разрыва на схеме соединений, воспользовавшись функцией Перейти к (графика), которую можно найти во всплывающем меню диалогового окна Управление сообщениями.
2. Откройте диалоговое окно Свойства <...> точки разрыва и заполните поле Видимое ОУ значением.
3. Щелкните по кнопке [OK].
4. При необходимости запустите новый контрольный прогон.
