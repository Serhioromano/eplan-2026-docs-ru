## P013047: Изделие с индексом '\<x\>' уже импортировано

### Причина

При импорте спецификации был обнаружен индекс изделия, использующийся два или более раз. Возможно, в импортируемом файле для нескольких изделий были вручную изменены значения в имени поля "REFERENCE_POS" , и при этом произошло присвоение нескольких идентичных индексов.

!!! note "Замечание:"

    В Eplan устройству может быть присвоено максимум50изделий. Индекс изделия задает последовательность внесения изделий в диалоговом окне Свойства ++"..."++ на вкладке Изделие.

### Решение

1. Откройте импортируемый файл при помощи текстового или XML-редактора и найдите индекс, указанный в диалоговом окне управления сообщениями в качестве сообщения "013047", например, организуя поиск по слову REFERENCE_POS="<Индекс>".
2. Обнаружив повторно присвоенный индекс, скорректируйте его.
3. Сохраните файл и заново импортируйте спецификацию.
