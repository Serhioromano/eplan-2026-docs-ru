## P004020: Больше одного вывода устройства В/В с одинаковым видом представления на один канал

### Причина

Определено больше одного вывода устройства В/В в канале с таким же адресом и таким же видом представления.

### Решение

1. Выделите сообщение в диалоговом окне Управление сообщениями и определите местонахождение вывода устройства В/В на схеме соединений с помощью функции Перейти к (перекрестная ссылка).
2. Для этого дважды щелкните в диалоговом окне Результаты поиска – <Имя проекта> по функции вывода устройства В/В, которая многократно присутствует в одном виде представления.
3. В открывающемся диалоговом окне свойств переместите вкладку Данные символа / функции на передний план и измените в раскрывающемся списке Вид представления настроенное значение так, чтобы оно встречалось всего один раз на каждый канал.
4. Повторите корректировку для других выводов устройства В/В, которые были объявлены неверными.
5. Обновите соединения.
6. При необходимости запустите новый контрольный прогон.
