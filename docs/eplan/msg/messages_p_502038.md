## P502038: Значение свойства изделия '\<x\>' не входит в диапазон значений, определенный в Eplan Data Standard

### Причина

В базе данных изделий, подлежащих проверке, обнаружено изделие кабельного канала или несущей шины, для которого сохранено значение свойства Высота, Ширина или Глубина (отображаемое в заполнителе '\<x\>'), не соответствующее Eplan Data Standard. Например, несанкционированное негативное значение было импортировано в базу данных изделий для одного из этих свойств изделия при импорте данных изделия с Eplan Data Portal.

### Решение

1. Обратитесь к сайту службы поддержки Eplan для [Eplan Data Standard](https://www.eplan.com/en/support/data-standard.html), чтобы узнать, какой диапазон значений допустим для заявленного свойства изделия.
2. Настройте значение свойства изделия в управлении изделиями таким образом, чтобы оно находилось в допустимом диапазоне значений.
3. При необходимости запустите новый контрольный прогон.
