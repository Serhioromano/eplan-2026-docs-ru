## P005035: Точка определения соединения (<x>), которая находится на нескольких соединениях, заново выровнена и отформатирована

### Описание

Это сообщение выводится в том случае, если при выравнивании и форматировании точек определения соединений одна из этих точек находится на нескольких соединениях.

!!! example "Пример:"

    Точка определениясоединения001размещена на линии автоматического соединения, которая ведет от тройника к клемме-XD1и обратно. Поэтому выводустройствафункции1 клеммы подключен к нескольким соединениям. Это приводит к противоречию при нумерации соединения.Узнать, находится ли обозначенная точка определения соединения на нескольких соединениях, можно из текста всплывающей подсказки, наведя курсор на линию автоматического соединения с точкой определения соединения.

!!! note "Замечание:"

    Это относящееся к модулю сообщение можно удалить при выполнении нового контрольного прогона (любой настроеннойсхемы) из диалогового окна управления сообщениями.
