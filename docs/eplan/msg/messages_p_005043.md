## P005043: Поперечное сечение / диаметр не содержится в разделе 'Поперечные сечения / диаметры' в настройках проекта!

### Причина

Вы используете поперечное сечение/диаметр, которого нет в настройках проекта. В диалоговом окне Настройки: Поперечные сечения / диаметры (командный путь: Файл > Настройки > Проекты > "Имя проекта" > Соединения > Поперечные сечения / диаметры) могут быть указаны поперечные сечения или диаметры, которые присваиваются любому соединению проекта.

Выбранное вами значение отсутствует в таблице допустимых значений.

### Решение

#### Возможность 1

Выберите значение из имеющихся в таблице Поперечные сечения / диаметры.

1. Для этого откройте диалоговое окно Свойства ++"..."++ для соответствующего соединения или соответствующей точки определения соединения.
2. Щелкните рядом с полем Поперечное сечение/диаметр по кнопке ++"..."++.
3. Выделите в открывшемся диалоговом окне Поперечные сечения / диаметры одно из возможных значений и нажмите ++OK++.

#### Возможность 2

Добавьте в таблицу допустимых значений Поперечные сечения / диаметры то значение, которое вы хотели бы использовать.

1. Выберите следующие команды: Файл > Настройки > Проекты > "Имя проекта" > Соединения > Поперечные сечения / диаметры.
2. Щелкните в диалоговом окне Настройки: Поперечные сечения / диаметры по кнопке  (Создать) и занесите в новую строку таблицы нужное значение.
3. Затем щелкните по кнопке ++ОК++.

* * *

При необходимости запустите новый контрольный прогон.
