## P005060: Вывод устройства уже имеет одно многополюсное соединение в одно- и многополюсном представлении

### Причина

Вывод устройства, подключенный на вкладке Подключить устройства диалогового окна "Свойства" точки определения соединения, которая представлена однополюсной, уже имеет одно многополюсное соединение.

### Решение

1. Удалите одно из двух соединений.
2. При необходимости запустите новый контрольный прогон.

* [Диалоговое окно / вкладка "Подключить устройства"](xesconnectdevicegui_d_geraeteverschalten.md)
