## P502022: Размеры присоединений шаблонов функций не совпадают с размерами присоединений на схеме соединений

### Причина

В проверяемой базе данных изделий были определены шаблоны функций с размерами присоединения на изделии, которые не совпадали с размерами присоединения выбранной на изделии схемы соединений.

### Решение

1. В управлении изделиями на вкладке Сообщения выделите строку с сообщением и выберите для этой строки пункт всплывающего меню Перейти к.
Соответствующее изделие будет выделено в дереве в управлении изделиями.
2. Выведите на передний план вкладку Шаблоны функции.
3. Запишите размеры присоединения, внесенные в таблицу свойств для выводов устройства.
4. Перейдите на вкладку Свойства.
5. В таблице свойств разверните уровень иерархии Данные.
6. Запомните имя, указанное в поле значений свойства Схема соединений.
7. Закройте базу данных изделий.
8. Откройте повторно базу данных изделий, на этот раз по следующему командному пути: вкладка Основные данные > группа команд Изделия > Управление.
9. В виде дерева выделите схему соединений, имя которой вы запомнили.
10. В таблице свойств перейдите на вкладку Выводы устройства.
11. Скопируйте в таблицу предварительно записанные размеры присоединения выводов устройства из шаблонов функций, чтобы значения на схеме соединений и на шаблонах функций полностью совпадали.
12. Щелкните по кнопке [Применить].
13. При необходимости запустите новый контрольный прогон.
14. Закройте управление изделиями и выполните синхронизацию данных изделий.
