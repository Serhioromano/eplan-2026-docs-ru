# Изменить последовательность целей сетевых соединений

Последовательность целей сетевых соединений можно изменить позже в диалоговом окне "Свойства" соответствующей точки определения сети.

Условия:

* Вы открыли проект. В Графическом редакторе открыта страница проекта.
* Вставлена точка определения сети.

1. Выделите в графическом редакторе точку определения сети и выберите пункт всплывающего меню **Свойства**.
2. В диалоговом окне **Свойства** ++"..."++ выберите вкладку **Соединения сети**.
3. Выделите вывод устройства в таблице **Выводы устройства**.
4. Выберите пункт всплывающего меню **Изменить последовательность целей**.

![](images/arrow.png) В диалоговом окне **Последовательность целей** отображаются все цели вывода устройства, соединенные через сетевые соединения.
5. Переместите цели с помощью кнопок с изображением стрелки в нужные положения.
6. Щелкните по кнопке ++"OK"++.

![](images/arrow.png) Измененная последовательность целей сохраняется.
