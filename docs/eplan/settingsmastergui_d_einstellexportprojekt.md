## Диалоговое окно Экспортировать настройки <...>: <Путь иерархии>

[Вызов диалогового окна:](javascript:void\(0\);)

Файл > Настройки. Выделите одну из областей настроек "Проект" или "Фирма" и нажмите кнопку  (Экспортировать).

В этом диалоговом окне определяется, в какой целевой файл будут экспортированы настройки выбранной области настройки.

Обзор основных элементов диалогового окна:

Целевой файл:

В этом поле выводится предложение пути и имени файла экспорта. По умолчанию файл экспорта получает имя, которое соответствует выделенной области в дереве диалогового окна Настройки. Имя файла состоит из следующих элементов: <Основная категория>+<Подкатегория>+<Область настройки>.xml. С помощью  можно указать другой путь или имя файла экспорта.

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.htm), из которого можно будет скопировать одну из доступных переменных пути.
