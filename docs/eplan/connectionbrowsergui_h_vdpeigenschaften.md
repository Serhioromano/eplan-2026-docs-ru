## Определить свойства соединения посредством точек определения соединения

Точки определения соединений определяют свойства для сквозных соединений, проходящих под ними.

Условие:

Вы открыли проект. В Графическом редакторе открыта страница проекта. Вставлена точка определения соединения.

1. Дважды щелкните по точке определения соединения.
2. В диалоговом окне Свойства <...> на вкладке [Точка определения соединения](eplan/devicetaggui_r_vdp.md) измените значения предварительно установленных свойств соединения или укажите новые.
3. На вкладке [Отображение](eplan/devicetaggui_r_anzeige.md) можно изменить представление свойств на схеме соединений, а на вкладке [Графика соединения](eplan/devicetaggui_r_verbindungsgrafik.md) — графические свойства линий соединения. 
4. На вкладке [Изделие](eplan/partselectiongui_r_artikel.md) можно присвоить соединению данные изделия.
5. Щелкните по кнопке [OK].  
  
Свойства, которые определены, присваиваются только тому соединению, которое пересекает точку определения соединения. (При многократном выборе точек определения соединений можно одновременно изменять свойства нескольких соединений).

!!! tip "Совет:"

    Во вкладкеТочка определения соединенияв полеОбозначение соединенияможно автоматически определить следующее свободное обозначение соединения. Для этого воспользуйтесь пунктом всплывающего менюОпределить новое обозначениеили комбинацией клавиш[Ctrl]+[N].

 

!!! note "Замечание:"

    Комплексная обработка свойств соединений возможна только в навигаторе соединений (например, для нескольких видов представления соединения). Комплексная обработка точек определения соединения невозможна — ни для различных видов представления соединения, ни для нескольких точек определения соединения на соединении.
