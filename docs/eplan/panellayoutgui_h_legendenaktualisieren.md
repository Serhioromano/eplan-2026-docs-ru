## Обработать позиции легенды

В случае изменения оснащения монтажной платы может потребоваться заново пронумеровать позиции легенды.

Условия:

  * Вы открыли проект.
  * Вы открыли диалоговое окно Компоновка электрошкафа 2D - <Имя проекта>.
  * Вы выделили на вкладке Дерево монтажную плату, позицию легенды которой требуется обновить. (Многократный выбор здесь невозможен.)


  1. В диалоговом окне Компоновка электрошкафа 2D — <Имя проекта> выберите пункт всплывающего меню Обработать позицию легенды.
  2. Нажимайте в диалоговом окне Обработать позицию легенды кнопки , ,  и  для перемещения позиций легенды вверх / вниз или в начало / в конец списка.
  3. Нажмите на кнопку [Нумеровать].
  4. Установите в диалоговом окне Нумеровать настройки нумерации.
  5. Щелкните по кнопке [OK].  
  
Записи в столбце Позиция легенды приводятся в соответствие.
  6. Щелкните по кнопке [OK].  
  
Выполняется обновление позиций легенды.



Обновленные записи могут отображаться на вкладке Список. Для этого вам может потребоваться изменить конфигурацию столбца списка при помощи пункта Конфигурировать представление во всплывающем меню и выбрать свойство Позиция легенды для конфигурации.
