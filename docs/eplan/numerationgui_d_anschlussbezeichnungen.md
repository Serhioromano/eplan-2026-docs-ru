## Диалоговое окно Обозначения и описания выводов устройства

Вы открыли проект.Файл > Настройки > Проекты > "Имя проекта" > Устройства > Нумерация (online). Нажмите на кнопку [Обозначения / описания выводов устройства].

В этом диалоговом окне у вас есть возможность для каждого определения функции сохранять десять наборов обозначений и описаний выводов устройства. Затем эти наборы можно использовать из функции. Выполненные здесь настройки сохраняются как специфические для проекта.

Обзор основных элементов диалогового окна:

Пoиск:

Введите в это поле текст, по которому должны фильтроваться определения функций. При этом поиск этого текста будет выполняться в столбцах Раздел, Категория, Группа и Определение функции.

Если необходимо вернуться к прежнему виду определения функций, удалите текст из поля ввода. Для этого нажмите кнопку  (Удалить).

Таблица:

В двух вкладках Обозначения выводов устройства и Описания выводов устройства перечисляются выводы устройства определений функций в таблице (под указанием типа потенциала). Редактировать можно только данные в столбцах 1 \- 10 для обозначений и описаний выводов устройства.

* Раздел: Здесь выводится раздел определения функции.
* Категория: Здесь выводится категория определения функции.
* Группа: Здесь выводится группа определения функции.
* Определение функции: Здесь выводится определение функции.
* Вывод устройства: Выводы устройства определения функции выводятся соответственно в отдельной строке. Или указан номер вывода устройства, или "n" (для переменного числа выводов устройства), или "z" (для последнего вывода устройства при переменном числе выводов устройства).
* Тип потенциала: Здесь показывается тип потенциала вывода устройства.
* 1 -10: На вкладке Обозначения выводов устройства вы можете для каждого вывода устройства вводить десять различных предложений для обозначения вывода устройства. Обозначение вывода устройства является идентифицирующим признаком вывода устройства.  
На вкладке Описания выводов устройства вы можете для каждого вывода устройства вводить десять различных предложений для описания выводов устройства. Описание вывода устройства содержит дополнительные, неидентифицирующие данные.

Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](eplan/userinterface_m_kontextmenu.md).
