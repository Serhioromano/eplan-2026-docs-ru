# Настроить панель быстрого доступа

Чтобы иметь возможность быстро воспользоваться часто используемыми командами, над или под лентой находится панель быстрого доступа. Здесь можно хранить часто используемые команды в виде кнопок независимо от их расположения в ленте.

Определенные команды, многократно встречающиеся в ленте (на разных вкладках и / или группах команд в зависимости от контекста), невозможно вставить в панель быстрого доступа. Это касается, например, команд Графический файл, DXF / DWG, Гиперссылка, QR-код из вкладки Вставить, которые в зависимости от контекста (открытого редактора) присвоены различным группам команд. Команды продуктов Eplan Cloud также невозможно вставить в панель быстрого доступа.

1. Нажмите в строке заголовка главного окна Eplan на пиктограмму ![](images/all_quickaccess_as.png) (настроить панель быстрого доступа).
2. Выберите команду Другие команды.
3. Перейдите в диалоговом окне Настроить на вкладку Добавить быстрый доступ.
4. Выберите в раскрывающемся списке Вкладки ту вкладку, из которой вы хотите выбирать команды для быстрого доступа.
5. Выделите в поле Команды нужную команду и нажмите на кнопку ![](images/all_arrowright_as.png){ .ui-icon }, чтобы добавить эту команду на панель быстрого доступа.
6. Нажмите на кнопки ![](images/all_arrowup_as.png){ .ui-icon } и ![](images/all_arrowdown_as.png){ .ui-icon }, чтобы изменить последовательность команд на панели.
7. Щелкните по кнопке ++OK++.

!!! info "Для сведения:"

    Выбранные команды отображаются в строке заголовка в виде пиктограммы на панели быстрого доступа и остаются на этой панели даже после завершения программы.

Вы также можете настроить свою панель инструментов с помощью ленты.

1. Нажмите правой кнопкой мыши на команду в ленте.
2. Выберите всплывающее меню Добавить в панель быстрого доступа.

!!! info "Для сведения:"

    Выбранная команда отображается в виде кнопки на панели быстрого доступа. Для команд с главных вкладок или команд из категории "Другие команды" всегда отображается соответствующее стандартное изображение.

!!! info "Для сведения:"

    Если для выбранной команды в программе пиктограмма не сохранена, вместо этого на панели инструментов будет отображена цветная точка.

1. Нажмите правой кнопкой мыши на команду в панели быстрого доступа.
2. Выберите всплывающее меню Удалить из панели быстрого доступа.

!!! info "Для сведения:"

    Кнопка выбранной команды удаляется из панели быстрого доступа.

1. Нажмите правой кнопкой мыши на панели быстрого доступа.
2. Выберите всплывающее меню Настроить панель быстрого доступа.
3. Перейдите в диалоговом окне Настроить на вкладку Добавить быстрый доступ.
4. Нажмите на кнопку ++Сбросить++.

!!! info "Для сведения:"

    После подтверждения запроса панель быстрого доступа будет снова сброшена на состояние по умолчанию.
