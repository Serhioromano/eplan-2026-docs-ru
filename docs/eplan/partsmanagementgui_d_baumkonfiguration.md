## Диалоговое окно Конфигурация дерева

[Вызов диалогового окна:](javascript:void\(0\);)

  * Вкладка Основные данные > группа команд Изделия > Управление. Кнопка [Дополнительно] > Настройки.
  * Файл > Настройки > Пользователь > Управление > Изделия.



Щелкните в поле Конфигурация дерева по [...].

В этом диалоговом окне укажите, как конфигурируется представление в виде дерева базы данных изделий.

Обзор основных элементов диалогового окна:

Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать или обработать. Для этого также воспользуйтесь соседней [панелью инструментов](schemeconfig_m_schemaschaltflaechen.htm).

Главные узлы:

Этот список содержит возможные главные узлы для конфигурации. Нажмите на кнопку  (Обработать) для выделенной строки главного узла, чтобы задать подробные настройки для соответствующей конфигурации в диалоговом окне Конфигурация дерева — Главные узлы.

Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.htm).
