# Дополнительная оптимизация для платформы Eplan и ее продуктов

Продукт | Область | Функциональность
---|---|---
Платформа Eplan | Интерфейс пользователя |  Уменьшено количество объектов, отображаемых в обзоре свойств Раньше обзор свойств содержал данные всех объектов, которые были выбраны в графическом редакторе, навигаторе и т. д. и соответствовали схеме, используемой для обзора свойств. Если в обзоре свойств не использовалась схема, то отображение ограничивалось 1000 объектов. В обоих случаях могло пройти некоторое время, прежде чем все объекты отображались в обзоре свойств. Теперь отображение в обзоре свойств ограничено данными 100 объектов. Это позволяет быстрее отображать данные выбранных объектов в обзоре свойств. Если в выборе содержится более 100 объектов, то в информационной области диалогового окна появляется текст "Отображаются не все выбранные объекты.". Если вы хотите, чтобы в обзоре свойств отображалось больше объектов, можно нажать расположенную ниже кнопку ++Загрузить все объекты++. В зависимости от количества объектов эта операция может продлиться некоторое время.
Платформа Eplan | Интерфейс пользователя |  Новое уведомление для обновлений Если для установленной вами версии Eplan имеется обновление, то об этом будет свидетельствовать пиктограмма загрузки в строке состояния. Эти системные сообщения часто не распознаются пользователями, особенно если пиктограмма уже была видна. По этой причине теперь – при наличии нового обновления – в правом нижнем углу экрана на несколько секунд отображается уведомление. Помимо информации о наличии нового обновления здесь отображается гиперссылка, с помощью которой можно открыть Eplan Download Manager.
Платформа Eplan | Интерфейс пользователя |  Клавиша [F10] для помощи при вводе с клавиатуры с японской раскладкой В операционной системе Windows на клавиатурах с японской раскладкой для преобразования символов в качестве помощи при вводе используется клавиша [F10]. Однако в Eplan, начиная с версии 2022, клавиша [F10] используется для перехода курсора к первому полю на вкладке. Это означало, что на клавиатурах с японской раскладкой помощь при вводе не работала. Эта проблема устранена. Чтобы обеспечить возможность использования этой стандартной функции Windows для японских пользователей, прежнее назначение клавиши ++F10++ в Eplan было убрано.
Платформа Eplan | Интерфейс пользователя |  Убраны горячие клавиши в диалоговых окнах и всплывающем меню Раньше при нажатии клавиши ++Alt++ в диалоговых окнах и всплывающих меню отображались подчеркнутые буквы, так называемые "горячие клавиши". Теперь в рамках стандартизации разных продуктов эти элементы убраны в диалоговых окнах и всплывающих меню. В ленте горячие клавиши будут по-прежнему отображаться.
Платформа Eplan | Интерфейс пользователя |  Настройка ленты дополнена командой eStock Теперь при настройке ленты в диалоговом окне Настроить в разделе Другие команды (основные данные) доступны следующие команды для Eplan eStock:

* Загрузить в eStock все изделия
* Проверить на наличие изменений в eStock
* Удалить локальные данные eStock
* Обновить данными из eStock

Платформа Eplan | Интерфейс пользователя |  Улучшена поддержка при настройке высокой контрастности в Windows В операционной системе Windows есть настройка "Высокая контрастность". Эта настройка уже поддерживалась платформой Eplan, но в некоторых местах некорректно учитывалась при отображении цветов в интерфейсе пользователя (например, окраска пиктограмм по сравнению с фоном, цвет выбранных элементов и т. д.). Эта проблема устранена. Теперь Eplan обеспечивает улучшенную поддержку этой настройки.
Платформа Eplan | Интерфейс пользователя |  Копировать имя и место хранения проекта из свойств проекта В свойствах проекта отображается имя текущего проекта и под ним соответствующее место хранения (командный путь: Файл > Сведения > группа команд Свойства проекта > Свойства). Теперь здесь у вас есть возможность скопировать имя проекта или путь к месту хранения файла в буфер обмена. Для этого рядом с именем проекта и местом хранения доступна новая кнопка ![](images/all_copy_as.png) (Копировать). С помощью новой кнопки ![](images/all_fileopen_as.png) (Открыть) рядом с местом хранения можно также открыть путь к месту хранения файла в проводнике Windows.
Платформа Eplan | Интерфейс пользователя |  Одинаковый порядок для проектов в навигаторах и настройках Ранее при открытии нескольких проектов на платформе Eplan в древовидной структуре и в представлении в виде списка в навигаторах, а также в дереве диалогового окна "Настройки" проекты могли отображаться в разном порядке. Это было связано с тем, что в навигаторах проекты сортировались по внутреннему идентификатору базы данных, а в древовидной структуре диалогового окна "Настройки" — по имени. Эта проблема устранена. Теперь проекты сортируются по имени как в древовидной структуре и в списке в навигаторах, так и в диалоговом окне "Настройки". В результате этого последний открытый проект в древовидной структуре навигатора больше не отображается внизу списка проектов, а сортируется по имени.
Платформа Eplan | Интерфейс пользователя |  Вкладка "Изделия" дополнена полем поиска Чтобы можно было ограничить количество отображаемых свойств изделия и свойств ссылок изделий в диалоговом окне "Свойства" устройств на вкладке Изделия, теперь над таблицей свойств расположено привычное поле поиска. Это поле поиска работает аналогично поиску свойств в управлении изделиями. Поиск выполняется как по имени отображаемых свойств, так и по значениям свойств.
Платформа Eplan | Интерфейс пользователя |  Переименованы специфические для пользователя настройки перевода для независимых от проекта данных В специфических для пользователя настройках перевода диалоговое окно Настройки: Управление изделиями / вне зависимости от проекта переименовано в Настройки / вне зависимости от проекта. В этом новом диалоговом окне можно устанавливать настройки для перевода данных независимо от проекта. В соответствии с этим связанный узел "Управление изделиями / вне зависимости от проекта" в диалоговом окне "Настройки" переименован в "Вне зависимости от проекта" (командный путь: Файл > Настройки > Пользователь > Перевод).
Платформа Eplan | Интерфейс пользователя |  Из вида Backstage убрана устаревшая ссылка на курсы eLearning В виде Backstage Справка убрана лишняя, устаревшая ссылка на курсы eLearning. Актуальная ссылка на курсы eLearning по-прежнему доступна на ленте на вкладке "Облачные продукты Eplan Cloud".
Платформа Eplan | Интерфейс пользователя |  Улучшения в присвоении тегов в центре вставки При присвоении тега символу, устройству или макросу в центре вставки открывается диалоговое окно Управление тегами: <название объекта>. В это диалоговое окно были внесены улучшения, делающие создание тегов более простым и удобным. Теперь, если после открытия диалогового окна щелкнуть по полю Новый тег, то список существующих тегов отображается сразу, а не при вводе буквы, как раньше. (Этот список содержит все имеющиеся теги, за исключением тегом, уже присвоенных этому объекту.)
Кроме того, теперь после создания тега диалоговое окно остается открытым. Теперь можно поочередно создать несколько тегов или удалить ненужные теги из списка, не закрывая диалоговое окно между этими действиями.
Платформа Eplan | Интерфейс пользователя |  Настраиваемая высота строки в диалоговом окне "Многоязычный ввод" Раньше в диалоговом окне Многоязычный ввод высота строки была фиксированной и составляла три строки. Теперь у вас есть возможность индивидуально настраивать высоту строки с помощью пункта всплывающего меню Настроить строку. Это соответствует поведению, уже знакомому вам по другим диалоговым окнам, в которых есть таблица. Теперь в соответствии с этой стандартизацией высота строки по умолчанию установлена на "1". Как и в диалоговых окнах Обработать клеммник и Обработать штекер, настройка высоты строки влияет на все строки таблицы.

Платформа Eplan | Графический редактор |  Настраиваемая кодировка для QR-кода Раньше для кодировки текстов в QR-кодах использовалась только кодировка "UTF-8". Однако для японских символов требуется кодировка "Shift JIS". Теперь для настройки кодировки добавляемых в проект QR-кодов доступна новая настройка проекта Кодировка QR-кода (командный путь: Файл > Настройки > Проекты > "Имя проекта" > Графическая обработка > Общее). Используя раскрывающийся список этой настройки, можно переключаться между кодировками "UTF-8" и "Shift JIS".
Платформа Eplan | Поиск |  Перечислить обзоры модели с помощью "Перекрестная функция -> Список" из схемы соединений Теперь, если для какой-либо функции на странице схемы соединений выполняются пункты всплывающего меню Перекрестная функция > Список, то в диалоговом окне Результаты поиска также перечисляются обзоры модели с перекрестными ссылками, при их наличии. Если затем из списка Перейти к с помощью пункта всплывающего меню Перейти к (графика) переключиться на обзор модели, то в обзоре модели будет выделено представление функции с перекрестной ссылкой. Если сама функция в обзоре модели не видна (например, в отображении отверстий) или если для обзора модели выбран стиль с "оттенением", то это будет невозможно и тогда выделяется весь обзор модели. Благодаря этому нововведению больше нет необходимости переходить к обзору модели через пространство листа. Теперь также есть доступ к обзорам модели сразу из схемы соединений с помощью списка "Перейти к".
Платформа Eplan | Поиск |  Вывод комментариев в списке результатов поиска как объект "Комментарий" Теперь, чтобы при поиске лучше отличать комментарии от других текстов в списке результатов поиска, тексты комментариев отображаются в диалоговом окне Результаты поиска не как "Произвольный текст", а как объект "Комментарий".
Платформа Eplan | Навигаторы |  Доступ к свойствам проекта через пространство листа и навигатор предварительного планирования Если открыто два или более проектов, то имя проекта в дереве навигатора отображается как верхний уровень иерархии. Используя это имя проекта, можно было перейти к свойствам проекта практически во всех навигаторах, а затем обработать их. Раньше исключение составляли навигатор пространства листа и навигатор предварительного планирования. Раньше в навигаторе пространства листа пункт всплывающего меню Свойства был неактивен и не выполнялся в навигаторе предварительного планирования. Теперь в этих навигаторах также можно перейти на вкладку Свойства соответствующего проекта с помощью пункта всплывающего меню Свойства.
Платформа Eplan | Выбор устройства |  Улучшения для выбора устройства Раньше в списке Выбранные изделия: Функции / шаблоны выбора устройства взаимосвязанные шаблоны функций нескольких изделий выделялись разным цветом. Поскольку желтый цвет используется в других местах программы для обозначения измененных свойств, то сюда были внесены изменения. Теперь вместо списка функции / шаблоны отображаются в таблице. Взаимосвязанные шаблоны функций теперь идентифицируются по одинаковому номеру изделия и группировке номера изделия в одном поле. Сгруппированные строки образуют блок, представляющий изделие. Таким образом легче различать отдельные изделия. Кроме того, теперь номер изделия по умолчанию отображается как первый столбец.
Платформа Eplan | Выбор устройства |  Выбор устройства дополнен полем поиска Чтобы сократить число изделий, отображаемых в выборе устройства для списка Главное изделие, теперь над списком главных изделий интегрировано привычное поле поиска. Поиск значений будет осуществляться по всем отображаемым столбцам.
Платформа Eplan | Соединения |  Определенная пользователем сортировка по цветам соединений и диаметрам / поперечным сечениям Теперь в настройках проекта для соединений можно задать определенную пользователем сортировку по цветам соединений и поперечным сечениям / диаметрам. Для этого диалоговые окна настройки Настройки: Цвета соединений и Настройки: Поперечные сечения / диаметры дополнены привычными кнопками со стрелками для перемещения записей в списках.
Затем указанная здесь сортировка будет использоваться во время проектирования для отображения в соответствующих диалоговых окнах выбора.
Платформа Eplan | Отчеты |  Непосредственный вывод данных изделий из источника и цели соединений в таблице соединений Если ранее вам требовалось вывести данные изделий подсоединенных функциональных элементов (источника и цели) непосредственно в таблице соединений, то это было возможно только косвенно, через определение свойств блока. Теперь эти данные можно выводить непосредственно в таблице соединений, так же как можно выводить данные изделий источника и цели кабелей в спецификации кабеля. Для этой цели были добавлены тексты-заполнители для форм таблицы соединений (*.f27). Теперь для размещения соответствующих текстов-заполнителей в формах в диалоговом окне Тексты-заполнители — таблица соединений дополнительно доступны элементы Изделие (источник), Изделие (цель), Ссылка изделия (источник) и Ссылка изделия (цель).
Платформа Eplan | Отчеты |  Отображение источника данных для текста-заполнителя В форме для связанного с функцией отчета (например, спецификации клеммника), могут выводиться как данные для анализируемого объекта верхнего колонтитула (например, устройство, такое как клеммник в спецификации клеммника), так и данные для связанных объектов данных (например, функции, такие как клеммы клеммника в спецификации клеммника). Раньше при вставке текстов-заполнителей в такую форму было непонятно, было ли свойство выбрано и вставлено в форму для анализируемого объекта верхнего колонтитула или для связанных объектов данных. Теперь источник текста-заполнителя отображается в диалоговом окне "Свойства" текстов-заполнителей и при выборе в диалоговом окне Тексты-заполнители — <Тип формы>. Для этой цели вкладка Размещение в диалоговом окне "Свойства" текстов-заполнителей под полем с выбранным текстом-заполнителем была дополнена новым полем Источник данных. В этом поле отображается, откуда берутся данные: из объекта верхнего колонтитула или из объекта данных. Кроме того, теперь в диалоговом окне выбора Тексты-заполнители — <Тип формы> доступные элементы в поле Элемент разделены на два списка: "Объект верхнего колонтитула" и "Объект данных". Однако оба этих списка доступны только в формах для связанных с функцией отчетов. Тексты-заполнители для объекта верхнего колонтитула можно рационально размещать в области верхнего или нижнего колонтитула формы, а тексты-заполнители для объекта данных — в области данных формы.
Платформа Eplan | Редактор форм |  Представление свойств текстов-заполнителей в виде изображений Теперь для отчетов платформа Eplan дает возможность представлять свойства с помощью текстов-заполнителей в виде изображений. Для реализации этой возможности знакомая вам технология отображения изображений или QR-кодов на устройстве была расширена для использования текстов-заполнителей. Теперь в редакторе форм в диалоговом окне Свойство (текст-заполнитель) на вкладке Формат под уровнем иерархии "Блок выравнивания" доступен раскрывающийся список Представление с тремя параметрами: "Текст", "QR-код" и "Графический файл". Если нужное представление (например "Графический файл") невозможно для какого-либо текста-заполнителя, то ничего не отображается. Поскольку теперь настройка для вывода QR-кода перенесена на вкладку Формат, то флажок Отобразить как QR-код на вкладке Размещение был удален. Платформа Eplan | Сообщения |  Новый контрольный прогон для сохраненных изделий, которых нет в базе данных изделий Теперь в классе сообщения 013 "Данные изделий" доступен новый контрольный прогон 013056 "Изделие с номером изделия '<x>' и вариантом '<y>' не существует в базе данных". Этот контрольный прогон позволяет выявлять изделия или варианты изделия, которые хранятся в проекте, но для которых в базе данных изделий не существует изделие или вариант изделия с таким же номером.
