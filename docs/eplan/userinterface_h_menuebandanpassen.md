## Настроить ленту

Вы можете настроить ленту в соответствии со своими потребностями, присвоив команды определенной пользователем группе команд. При этом речь может идти и о командах из главных вкладок, и о редко используемых командах вкладки ("Другие команды"), и об операциях. Кроме этого, вы можете создать собственные вкладки, переименовать существующие вкладки, а также изменить последовательность в ленте.

!!! note "Замечание:"

    Вкладку для доступа к облачным продуктам Eplan нельзя настроить, поскольку она генерируется динамически.

 

### [Свернуть ленту](javascript:void\(0\);)

1. Нажмите правой кнопкой мыши на ленте.
2. Выберите пункт всплывающего меню Свернуть ленту.  
  
Будут отображены только вкладки ленты.
3. Повторно выберите пункт всплывающего меню Свернуть ленту, чтобы снова развернуть ленту.

### [Создание новых групп команд](javascript:void\(0\);)

Вы можете присвоить команды только определенной пользователем группе команд.

1. Нажмите правой кнопкой мыши на ленте.
2. Выберите пункт всплывающего меню Настроить ленту.
3. Перейдите в диалоговом окне Настроить на вкладку Настроить ленту.
4. Выберите в поле Главная вкладка то место, на которое хотите добавить определенную пользователем группу команд.
5. Нажмите на кнопку [Новая группа команд].  
  
Под текущей выбранной вкладкой / группой команд создается новая определенная пользователем группа команд с именем "Новая группа команд (определено пользователем)".
6. Нажмите на кнопку [Правка].
7. Введите в следующем диалоговом окне нужное имя для группы команд.  
  
Определенные пользователем группы команд характеризуются тем, что к имени присоединяется дополнение "(определено пользователем)".

При помощи кнопок  и  можно изменить последовательность групп команд и вкладок в ленте. С помощью кнопки [Новая вкладка] можно создать новую вкладку под выбранной вкладкой. Под этой вкладкой одновременно создается новая определенная пользователем группа команд.

### [Присваивание команд определенной пользователем группе команд](javascript:void\(0\);)

1. Нажмите правой кнопкой мыши на ленте.
2. Выберите пункт всплывающего меню Настроить ленту.
3. Перейдите в диалоговом окне Настроить на вкладку Настроить ленту.
4. Выберите в раскрывающемся списке Выбрать команды ту категорию, из которой вы хотите выбрать команду для ленты.
5. Выделите нужную команду в приведенном ниже списке.
6. В поле Главная вкладка выберите определенную пользователем группу команд, которую хотите расширить.
7. Нажмите на кнопку , чтобы присвоить выбранную команду определенной пользователем группе команд.
8. Повторите этот процесс, чтобы присвоить другие команды.
9. Щелкните по кнопке [OK].  
  
Выбранные команды отображаются на соответствующей вкладке в ленте.

### [Назначение операций как команд в группе команд, определенной пользователем](javascript:void\(0\);)

В Eplan многочисленные функциональные возможности программы реализуются через так называемые "операции". Вы можете без проблем выбрать некоторые из этих операций при настройке ленты и сохранить часто используемые символы, макросы или другие важные операции программы на ленте. Это позволит быстро получить доступ к указанным выше компонентам. Управление этими операциями осуществляется через командную строку.

1. Нажмите правой кнопкой мыши на ленте.
2. Выберите пункт всплывающего меню Настроить ленту.
3. Перейдите в диалоговом окне Настроить на вкладку Настроить ленту.
4. В раскрывающемся списке Выбрать команды выберите категорию "Операции".
5. Выделите нужную операцию в приведенном ниже списке.
6. В поле Главная вкладка выберите определенную пользователем группу команд, которую хотите расширить.
7. Нажмите кнопку , чтобы присвоить операцию определенной пользователем группе команд.
8. В последующем диалоговом окне [Правка](eplan/modaldialogs_d_befehleumbenennen.md) в поле Рисунок выберите изображение, которое будет отображаться для команды на ленте.
9. Для выбранной операции в поле Отображаемое имя введите текст, который будет отображаться для команды на ленте.
10. В качестве примера в поле Командная строка настройте запись для выбранной операции в соответствии с вашими пожеланиями.
11. Введите в полях Всплывающая подсказка и Описание текст, который будет отображаться как заголовок и вторая строка во всплывающей подсказке.
12. Щелкните по кнопке [OK].  
  
Выбранная операция отображается как команда на соответствующей вкладке в ленте. Если вы не выбрали рисунок в диалоговом окне Правка, для команды будет отображаться стандартное изображение.

!!! note "Замечание:"

    

 

!!! example "Пример:"

    При помощи операции "Выполнить внешнюю программу" (XCMUserToolAction) можно, например, интегрировать в Eplan текстовый редактор. Для этого в командной строке нужно указать путь к файлу и имя файла:XCMUserToolAction /command:"c:\Windows\notepad.exe"

 

### [Сброс ленты](javascript:void\(0\);)

1. Нажмите правой кнопкой мыши на ленте.
2. Выберите пункт всплывающего меню Настроить ленту.
3. Перейдите в диалоговом окне Настроить на вкладку Настроить ленту.
4. Нажмите на кнопку [Сбросить].  
  
После подтверждения запроса лента будет снова сброшена на состояние по умолчанию.

### [Экспортировать ленту](javascript:void\(0\);)

1. Нажмите правой кнопкой мыши на ленте.
2. Выберите пункт всплывающего меню Экспортировать ленту.
3. В последующем диалоговом окне задайте каталог и имя для файла экспорта.
4. Щелкните по кнопке [Сохранить].  
  
Файл экспорта сохранится в формате XML. Будет выполнен экспорт всей ленты.

### [Импортировать ленту](javascript:void\(0\);)

1. Нажмите правой кнопкой мыши на ленте.
2. Выберите пункт всплывающего меню Импортировать ленту.
3. В последующем диалоговом окне выберите нужный файл в формате XML.
4. Щелкните по кнопке [Открыть].  
  
Откроется диалоговое окно Настроить. В списке под полем Выбрать команды отображаются содержащиеся в файле импорта команды в представлении структуры дерева.
5. Выделите команды, которые вы будете импортировать. Вы можете выбрать как отдельные команды, так и группы команд и вкладки.
6. Выберите в поле Главная вкладка то место, на которое хотите добавить определенные пользователем команды. Отдельные команды вставляются только в определенную пользователем группу команд.
7. Нажмите кнопку , чтобы присвоить выбранные команды.
8. Повторите этот процесс, чтобы присвоить другие команды.
9. Щелкните по кнопке [OK].  
  
Выбранные команды импортируются и затем отображаются на соответствующей вкладке в ленте.


!!! tip "Совет:"

    С помощью операцииMfImportRibbonBarActionвы можете импортировать всю ленту полностью. Одновременно будут перезаписаны текущие настройки ленты.

 

!!! note "Замечание:"

    Невозможно импортировать ленты, которые были экспортированы с помощью болееновойверсии Eplan, чем текущая. Для лент, экспортированных с помощью болеестаройверсии Eplan, импортируются только вкладки, определенные пользователем.
