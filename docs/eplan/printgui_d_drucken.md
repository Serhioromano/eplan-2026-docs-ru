## Диалоговое окно Печать

Файл > Печать.

В этом диалоговом окне выберите принтер и задайте страницы, которые должны распечатываться.

Обзор основных элементов диалогового окна:

Групповое поле Принтеры

В раскрывающемся списке Имя отображаются все принтеры, установленные для вашего компьютера; выберите нужный принтер. В полях Статус, Тип, Местопол. и Комментарий отображается информация для этого принтера, сохраненная в настройках печати Windows.

[Свойства]:

При нажатии этой кнопки открывается диалоговое окно Windows для настроек печати. В этом окне вы можете выбрать настройки печати. Дополнительные сведения вы можете получить из справки для соответствующего принтера.

* * *

Групповое поле Страницы

В этом групповом поле укажите, какие страницы вы хотите распечатать. Если вы вызвали диалоговое окно Печать из графического редактора, вы можете распечатать либо страницу, находящуюся в данный момент на переднем плане, либо все страницы проекта. При вызове из навигатора страниц можно распечатать либо выделенные страницы, либо все страницы проекта.

* Текущая страница: будет распечатана находящаяся на переднем плане страница в графическом редакторе.
* Выделение: будут распечатаны страницы, выделенные в навигаторе страниц. Если в навигаторе страниц выделен проект и одновременно активирован фильтр страниц, будут распечатаны только отфильтрованные страницы проекта.
* Весь проект: будут распечатаны все страницы проекта. Активированный фильтр страниц при этом не учитывается.
* Только измененные страницы: установите этот флажок, чтобы распечатать все страницы, которые были отмечены как "измененные" с момента последней печати, т. е. все страницы, для которых свойство "Дата изменения (автоматич.)" является более актуальным, чем последняя дата печати.

[Настройки]:

С помощью этой кнопки открывается диалоговое окно [Настройки: Печать](eplan/printgui_d_druckoptionen.md). Там вы можете установить масштабирование, границы печати и положение на странице, а также настройку для цветной или черно-белой печати.

* * *

Групповое поле Экземпляры

В этом групповом поле установите количество распечаток и способ их сортировки.

* Количество: здесь указывается, сколько экземпляров выбранных страниц будет распечатано.
* Сортировать: этот флажок устанавливается только в том случае, если вы распечатываете несколько экземпляров. Если этот флажок установлен, наборы выбранных страниц будут распечатаны друг за другом. Если флажок не установлен, друг за другом печатаются все одноименные страницы. Небольшое изображение в диалоговом окне показывает, как нужно действовать.
* Обратный порядок печати: если этот флажок установлен, страницы будут распечатаны в обратном порядке. Если флажок снят, страницы будут распечатаны в той последовательности, в котором они встречаются в проекте. Небольшое изображение в диалоговом окне показывает, как нужно действовать.
* Изменить вывод для печати в файл: установите этот флажок, если хотите распечатать выбранные страницы в файл. Eplan создаст файл *.PRN, который, например, можно распечатать позже или использовать для создания PDF-файла.

* * *

Групповое поле Конфигурация печати

В этом групповом поле указывается, будут ли распечатаны только страницы проекта или также присоединенные документы.

* Только проект / страница: будут распечатаны страницы проекта, выбранные в групповом поле Страницы.
* Только присоединенные документы: будут распечатаны только присоединенные документы, связанные с выбранными для печати страницами.
* Проект / страница и присоединенные документы: будут распечатаны страницы проекта, выбранные в групповом поле Страницы, а также присоединенные документы, связанные с этими страницами.

[Выбрать присоединенные документы]:

С помощью этой кнопки открывается диалоговое окно [Печать присоединенных документов](eplan/printgui_d_begleitdokumente.md). Там среди всех присоединенных документов, связанных в проекте, выбираются те, которые должны быть распечатаны.

* * *

Предв. просмотр

В правой области диалогового окна отображается предварительный просмотр выбранных страниц. Отображение соответствует выводу на принтере, включая позицию на бумаге. Для цветной печати все элементы отображаются с цветовой схемой "Цветное на белом"; для черно-белой печати все элементы (кроме графических файлов) отображаются черным цветом на белом фоне.

Под окном предварительного просмотра отображается общее количество печатаемых страниц, а также имя страницы, отображаемой в режиме предварительного просмотра. С помощью поля ввода можно пролистывать страницы или переходить на нужную страницу.

В предварительном просмотре отображаются только те страницы, которые будут печататься. Если в групповом поле Печать выбрана опция Только измененные страницы, среди выбранных могут содержаться страницы, которые не изменились с момента последней печати и поэтому не будут распечатаны. Эти страницы не отображаются в предварительном просмотре.
