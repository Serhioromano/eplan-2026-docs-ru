## Управление маршрутизируемыми соединениями

Для управления маршрутизируемыми соединениями доступно диалоговое окно Диспетчер разводки. Это диалоговое окно является центральным местом для получения обзора соединений в пространстве листа, а также для маршрутизации этих соединений и их экспорта для сборки проводов. Для наглядности нарочно скрываются мостовые перемычки и другие виды соединений, не актуальные для маршрутизации в пространстве листа. Кроме того, для лучшей наглядности также не показываются различия между видами представления соединений. Таким образом, в этом диалоговом окне отображаются только те соединения, которые актуальны для маршрутизации и разводки.

Возможно следующее:

Отображение в диалоговом окне

  * Диалоговое окно реагирует на выбор, сделанный в навигаторе пространства листа, трехмерном навигаторе монтажных поверхностей, навигаторе соединений и т. д. Например, если выделить пространство листа и запустить диалоговое окно Диспетчер разводки, то отображаются все соединения, проходящие в этом пространстве листа.
  * Отображаются все соединения, определения функций которых учитываются при маршрутизации, а источник и цель как размещение изделия находятся в одном том же пространстве листа.
  * Соединения между разными пространствами листа не отображаются.
  * По каждому соединению отображается актуальный для маршрутизации и разводки статус. Возможные значения: "Не маршрутизировано", "Маршрутизировано", "Немаршрутизируемое", "Защищено", "Экспортировано" и "Неэкспортируемое". Список соединений можно отфильтровать по статусу.
  * Диалоговое окно также можно использовать для отображения свойств соединений и текущего статуса соединений. Любое изменение соединения вне этого диалогового окна отображается непосредственно в диалоговом окне.



Обработка соединений

  * Для всех выделенных соединений можно изменять свойства соединений в режиме Свойства (общие).
  * Для выбранных соединений можно выделять различные виды представления в навигаторах с помощью команды Синхронизировать выбор в ленте (вкладка Главная > группа команд Поиск).
  * Для выбранных соединений можно выполнять переход к двухмерным и трехмерным видам представления соединения или источника и цели.



Маршрутизация соединений

  * Выделенные в диалоговом окне соединения можно маршрутизировать непосредственно из этого диалогового окна.
  * Если соединение невозможно маршрутизировать, то будет показан текст первого сообщения, выведенного для этого соединения.
  * Выделенные в диалоговом окне маршрутизируемые соединения (3D-соединения ) можно удалить непосредственно из этого диалогового окна.
  * Вы можете работать с отфильтрованным списком маршрутизируемых (но еще не маршрутизированных) соединений до тех пор, пока все соответствующие соединения не будут маршрутизированы и список не опустеет.



Экспорт для сборки проводов

  * Выделенные в диалоговом окне соединения можно экспортировать для сборки проводов (командный путь: Файл > Экспортировать > группа команд Данные изготовления > Сборка проводов). После экспорта статус соединений обновляется и отображается в диалоговом окне.
  * Список соединений можно отфильтровать по пространству листа и электрошкафу посредством выбора в навигаторе пространства листа. Это позволяет обрабатывать каждый электрошкаф по отдельности и уже передавать данные разводки в производство, пока обрабатываются следующие электрошкафы. Эту процедуру можно выполнять последовательно для всех пространств листа, имеющихся в проекте.
  * Если во время экспорта выводились сообщения, то будет показан текст первого сообщения, выведенного для этого соединения. Чтобы необходимые настройки данных о сборке проводов проверялись во время экспорта и соответствующие сообщения отображались в диспетчере разводки, необходимо активировать контрольный прогон P026072.
