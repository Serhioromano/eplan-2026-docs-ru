## Создать схему сравнения настроек

В схеме сравнения настроек вы определяете, какие настройки сравниваются друг с другом при сравнении проектов нормоконтроля. Eplan может использовать эту схему для сравнения между собой всех настроек, заданных в настройках проекта (командный путь: Файл > Настройки > Проекты > "Имя проекта") для соответствующего проекта.

Условия:

  * Вы выбрали базу данных управления проектами.
  * Вы сосчитали каталоги и проекты в управление проектами.


  1. Выберите следующие команды: Файл > Управление проектами.
  2. Выделите проект.
  3. Выберите [Дополнительно] > Проверить проект.
  4. Рядом с флажком Сравнить настройки щелкните по [...].
  5. Щелкните рядом с полем Схема по кнопке  (Создать).
  6. В диалоговом окне Новая схема в поле Имя введите информативное имя для новой схемы и щелкните по [OK].
  7. Чтобы выбрать настройку для сравнения, установите флажок перед настройкой в поле Сравниваемые настройки.
  8. Чтобы исключить настройку из сравнения, снимите флажок перед настройкой в поле Сравниваемые настройки.
  9. Щелкните по кнопкам [Сохранить] и [OK].
