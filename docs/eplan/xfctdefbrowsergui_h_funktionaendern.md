## Изменить функции

Если функция используется в проекте, присвоенное определение функции уже несет с собой определенные свойства. Данные из определения функции представляют собой только предварительное назначение и могут быть переписаны на каждом отдельном условном обозначении. Кроме того, можно добавить дополнительные свойства.

### Изменить свойства

Условие:

Вы разместили функцию (то есть условное обозначение) на странице схемы соединений. Или вы сгенерировали функцию в одном из навигаторов.

1. Выделите функцию.
2. Выберите пункт всплывающего меню Свойства.
3. Измените свойства функции в диалоговом окне Свойства<...>. Используйте для этого различные вкладки и поля ввода.
4. Назначьте — если требуется — другие свойства, которые не были предварительно заданы в определении функции.
5. Щелкните по кнопке [OK].  
  
Новые и измененные свойства сохраняются на функции.   
  
На условном обозначении отображаются текущие свойства (если они выбраны для отображения).

### Выбрать обозначения выводов устройства и описания

Для каждого определения функции можно сохранить десять наборов обозначений и описаний выводов устройства. При создании функции в качестве предварительно установленного используется первый набор обозначений вывода устройства.

Условие:

Вы разместили функцию (то есть условное обозначение) на странице схемы соединений. Или вы сгенерировали функцию в одном из навигаторов.

1. Выделите функцию.
2. Выберите пункт всплывающего меню Свойства.
3. Выберите в диалоговом окне Свойства <...> вкладку <Категория функции>.
4. Выберите в поле Обозначение вывода устройства запись из раскрывающегося списка или введите обозначения выводов устройства в ручном режиме.
5. Выберите в поле Описание вывода устройства запись из раскрывающегося списка или введите описания выводов устройства в ручном режиме.
6. Щелкните по кнопке [OK].  
  
Данные вывода устройства присваиваются функции.
