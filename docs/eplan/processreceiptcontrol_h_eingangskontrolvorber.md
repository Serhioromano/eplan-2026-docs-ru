## Проверить проект

В ходе нормоконтроля сравниваются настройки и свойства проекта для сравнения и проекта с замечаниями. Кроме того, выполняются целенаправленные контрольные прогоны по проекту с замечаниями.

Условия:

* Вы выбрали базу данных управления проектами.
* Вы сосчитали каталоги и проекты в управление проектами.
* В импортированном каталоге содержится возвращенный проект с замечаниями.
* Имеется доступ к исходному проекту, который нужно использовать в качестве проекта для сравнения.

1. Выберите следующие команды: Файл > Управление проектами.
2. В управлении проектами выделите проект, содержащий прогрессивное состояние.
3. Выберите [Дополнительно] > Проверить проект.
4. Щелкните рядом с полем Выбрать проект для сравнения по кнопке  (создать).
5. В последующем диалоговом окне выберите исходный проект, который является проектом для сравнения, и щелкните по кнопке [Открыть].
6. Чтобы в ходе нормоконтроля выполнить специфическое для проекта сравнение настроек, установите флажок Сравнить настройки и выберите из раскрывающегося списка Схема ниже существующую схему сравнения.  
  
С помощью [...] можно [создать схему сравнения настроек](processreceiptcontrol_h_vergleichsschema.md).
7. Чтобы в ходе нормоконтроля выполнить сравнение свойств, установите флажок Сравнить свойства и выберите из раскрывающегося списка Схема ниже существующую схему сравнения.  
  
С помощью [...] можно [создать схему сравнения свойств](processreceiptcontrol_h_eigenschaftenvergleich.md).
8. Чтобы в ходе нормоконтроля выполнить контрольные прогоны, установите флажок Выполнить контрольные прогоны и выберите из раскрывающегося списка Схема существующую схему контрольного прогона.  
  
С помощью [...] можно [создать схему контрольного прогона для нормоконтроля](processreceiptcontrol_h_pruefschema.md).
9. Чтобы сравнить структуры обоих проектов, установите флажок Сравнить структуры проектов.
10. Чтобы приостановить сравнение проектов при первом различии, установите флажок Остановить сравнение при обнаружении первого различия.
11. Щелкните по кнопке [OK].  
  
Проекты сравниваются друг с другом, выполняются заданные контрольные прогоны.  
  
В диалоговом окне Проверка проекта: Результаты Eplan автоматически отображает общий результат нормоконтроля.  
  
В управлении сообщениями перечисляются подробные результаты (командный путь: вкладка Инструменты > группа команд Проверка > Сообщения).
