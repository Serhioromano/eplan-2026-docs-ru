# Импортировать / экспортировать библиотеки символов

Условие:

Вы открыли проект.

1. Выберите следующие команды: Вкладка Основные данные > группа команд Символы > раскрывающаяся кнопка Библиотека символов > Импортировать.
2. В диалоговом окне Импортировать библиотеку символов выберите из списка требуемую библиотеку символов (*.esl). Многократный выбор невозможен.
3. Щелкните по кнопке ++Открыть++.
4. Выберите в диалоговом окне Создать библиотеку символов дисковод и каталог, в котором будет сохранена импортируемая библиотека символов. (Чтобы вернуться к стандартно настроенному каталогу, щелкните на пиктограмму Eplan в левой части области навигации и выведенному под ней каталогу.)
5. Перезапишите имя файла, если это необходимо.
6. Щелкните по кнопке ++Сохранить++.

!!! info "Для сведения:"

    Библиотека символов импортируется и доступна для дальнейшей обработки в текущем проекте.

!!! tip "Совет:"

    Вы можете импортировать библиотеки символов с помощью перетаскивания мышью, перетащив выделенную библиотеку символов из Windows Explorer в диалог навигатора Страницы — <Имя проекта> вашего проекта.

1. Выберите следующие команды: Вкладка Основные данные > группа команд Символы > раскрывающаяся кнопка Библиотека символов > Экспортировать.
2. В диалоговом окне Экспортировать библиотеку символов выберите из списка экспортируемую библиотеку символов (*.slk). Многократный выбор невозможен.
3. Щелкните по кнопке ++Открыть++.
4. Выберите в диалоговом окне Создать файл экспорта дисковод и каталог, в котором будет сохранена экспортируемая библиотека символов. (Чтобы вернуться к стандартно настроенному каталогу, щелкните на пиктограмму Eplan в левой части области навигации и выведенному под ней каталогу.)
5. Перезапишите имя файла, если это необходимо.
6. Щелкните по кнопке ++Сохранить++.

!!! info "Для сведения:"

    Файл экспорта создается под указанным именем на указанном дисководе и в указанном каталоге.
