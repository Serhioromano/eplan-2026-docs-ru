## Диалоговое окно Выполнить: Автоматизированная обработка

Вы открыли проект. В навигаторе страниц выделен проект или страницы проекта.

* Вкладка Инструменты > группа команд Отчеты > Автоматизированная обработка.
* Файл > Дополнительно > группа команд Расширения > Интерфейсы > группа команд Автоматизированная обработка > Автоматизированная обработка.

В этом диалоговом окне выберите с помощью схемы последовательность действий для автоматического выполнения.

Обзор основных элементов диалогового окна:

Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать. При нажатии кнопки [...] открывается диалоговое окно Настройки: Автоматизированная обработка.

Таблица:

Таблица содержит следующие столбцы:

* Операции в выбранном сценарии: отображает действия, сохраненные в выбранной схеме.
* Описание: отображает описательный текст, введенный в диалоговом окне Настройки: Автоматизированная обработка для выбранного действия в поле Описание.
