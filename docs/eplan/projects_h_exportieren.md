## Экспорт проектов

Проекты можно экспортировать с помощью вида Backstage или управления проектами. Экспортируемые проекты имеют формат, совместимый с XML, и затем (во внешнем приложении, например редакторе) их можно обрабатывать и снова импортировать обратно в Eplan.

Условие:

Вы выделили проект. При экспорте с помощью вида Backstage достаточно выделить страницу проекта в диалоговом окне Страницы — <имя проекта> или открыть страницу проекта в графическом редакторе.

Вид Backstage: Файл > Экспортировать > группа команд Данные проекта > Данные проекта > группа команд Проект > Проект.

Управление проектами: [Организовать] > Экспортировать.

1. Введите в диалоговом окне Экспортировать проект в место хранения экспортируемого проекта. Через пункт всплывающего меню Создать > Папка можно при необходимости создать новый каталог.
2. Щелкните по кнопке [OK].  
  
Выполняется экспорт проекта, указатель процесса показывает ход экспорта. В целевом каталоге сохраняется экспортированный проект *.epj в формате XML.
