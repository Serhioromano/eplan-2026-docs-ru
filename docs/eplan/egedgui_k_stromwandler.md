# Трансформатор тока с механическим каналом

Втулочный или стержневой трансформатор тока — это специальное устройство, которое используется для измерения первичного тока в проводнике без его отключения. С помощью такого устройства соединение осуществляется без подключения вывода устройства к этому соединению.

### Логическая схема выводов устройства

Чтобы такие устройства можно было сконфигурировать в Eplan, в диалоговом окне **Логическая схема выводов устройства** для свойства **Тип вывода устройства** доступна опция "Механический канал". При наличии двух выводов устройства этого типа вывода в логической схеме выводов устройства соединение проходит через устройство. Для этого необходимо указать для вывода устройства с этим типом вывода в свойстве **Передать потенциал в** вывод устройства с тем же типом вывода. Свойство **Число целей** должно быть равно "1".

Чтобы вам не приходилось вручную настраивать приведенные условия на каждом задействованном устройстве, вам доступно определение функции "Трансформатор тока, индукционный" именно с такой логической схемой выводов устройства.

Стандартные библиотеки символов содержат ряд символов ( `LSW1C`, `LSW2C`, `LSW3C`) для представления трансформаторов тока с механическим каналом, для которых это определение функции уже задано.

Чтобы проверить настройки в логической схеме выводов устройства для механических каналов, можно использовать контрольный прогон 007035 из класса сообщений 007 "Устройства". Этот контрольный прогон сообщает о выводах устройства с типом вывода "Механический канал", которые не имеют действительного обратного эквивалента или количество целей которых не равно "1".

### Свойства соединения

Следующие два свойства используются для идентификации соединений, проходящих через механический канал:

* **Проходные механические каналы** (ид. 31164)
* **Имеются механические каналы** (ид. 31165)

Эти свойства можно использовать в качестве столбцов в навигаторе соединений, для вывода в отчетах, для фильтрации и т. д. Приведенная информация предназначена для пользователей, которые выполняют разводку электрошкафа на основе списка разводок и не используют Eplan Smart Wiring.

### Маршрутизация маршрутизируемых соединений

При маршрутизации маршрутизируемых соединений в пространстве листа особое внимание уделяется соединениям, проходящим через функциональные элементы с механическим каналом. Для этих функциональных элементов генерируются сегменты маршрутизации, которым присваивается то же обозначение, что и функциональному элементу, через который направляется соединение. В этом случае ОУ функционального элемента с каналом указывается в свойстве **Пространство листа: Трасса маршрутизации** в дополнение к другим сегментам маршрутизации (например, для кабельных каналов). Эта информация требуется Eplan Smart Wiring.

Оба свойства **Проходные механические каналы** (ид. 31164) и **Имеются механические каналы** (ид. 31165) также доступны для трехмерных соединений и содержат значения.

При маршрутизации соединений для компонентов с механическим каналом могут возникнуть различные проблемы, которые приводят к невозможности маршрутизации соединений. Для устранения этих проблем в классе сообщений 026 "Трехмерный чертеж монтажных поверхностей" вам доступны следующие контрольные прогоны:

* Контрольный прогон 026108 проверяет наличие подходящей схемы соединений для функционального элемента с механическим каналом.
* Контрольный прогон 026109 проверяет, есть ли соответствующее трехмерное размещение изделия в пространстве листа для многополюсного функционального элемента с механическим каналом на схеме соединений.
* Контрольный прогон 026110 обнаруживает, что для конкретного вывода устройства механического канала не найдена точка входа в сеть соединенных сегментов.

В этом случае, когда соединения не маршрутизируются, в дополнение к перечисленным выше сообщениям выдается сообщение 026043 ("Не найдена трасса маршрутизации между источником и целью"). Для функциональных элементов с механическими каналами это сообщение сопровождается дополнением для механических каналов.
