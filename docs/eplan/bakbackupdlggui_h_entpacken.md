## Распаковка проектов

Проекты, запакованные, например, в предыдущих версиях Eplan, можно открыть как любой другой проект либо распаковать в управлении проектами.

### Открытие запакованных проектов

1. Выберите следующие команды: Файл > Открыть > группа команд Открыть > Поиск
2. В диалоговом окне Открыть проект в поле с типами файла выберите запись "Запакованный проект Eplan (*.elp)".
3. Откройте каталог, в котором хранится проект, и выберите нужный проект.
4. Щелкните по кнопке [Открыть].  
  
Проект будет распакован и открыт; при этом вы увидите указатель процесса и сможете, при необходимости, прервать процесс. Если открыт навигатор страниц, проект отображается в Навигаторе страниц.
