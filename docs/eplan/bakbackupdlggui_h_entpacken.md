# Распаковка проектов

Проекты, запакованные, например, в предыдущих версиях Eplan, можно открыть как любой другой проект либо распаковать в управлении проектами.

### Открытие запакованных проектов

1. Выберите следующие команды: **Файл** > **Открыть** > группа команд **Открыть** > **Поиск**
2. В диалоговом окне **Открыть проект** в поле с типами файла выберите запись "Запакованный проект Eplan (*.elp)".
3. Откройте каталог, в котором хранится проект, и выберите нужный проект.
4. Щелкните по кнопке ++"Открыть"++.

![](images/arrow.png) Проект будет распакован и открыт; при этом вы увидите указатель процесса и сможете, при необходимости, прервать процесс. Если открыт навигатор страниц, проект отображается в Навигаторе страниц.

!!! tip "Совет:"

* Запакованный проект можно также открыть, дважды щелкнув в каталоге проекта по проекту с расширением имени файла `*.elp`. Проект будет распакован и открыт автоматически.
* В управлении проектами распакуйте выбранный запакованный проект через меню **[Организовать] > Распаковать**.
