## Заменить настройки

Можно передавать проектные настройки в другие проекты. Для этого необходимо сохранить настройки исходного проекта вместе с проектом в качестве базового проекта и затем создать из этого базового проекта новый проект.

### Сохранение проекта в качестве базового проекта

Условия:

* Вы открыли меню управления проектами: Файл > Управление проектами
* В структуре дерева управления проектами находится считанный каталог с проектом.

1. Выделите в диалоговом окне Управление проектом исходный проект.
2. Выберите [Дополнительно] > Создать базовый проект.
3. Выберите место хранения и имя для базового проекта.
4. Щелкните по кнопке [Сохранить].  
  
Создается базовый проект.

### Создание проекта из базового проекта

1. Выберите следующие команды: Файл > Создать.
2. В диалоговом окне Создать проект задайте имя для нового проекта.
3. Нажмите на кнопку [...] рядом с полем Базовый проект.
4. Выберите в диалоговом окне Выбрать базовый проект нужный базовый проект и нажмите на кнопку [Открыть].
5. Выберите место хранения для проекта.
6. Щелкните по кнопке [OK].  
  
Создается проект на основе базового проекта.
