## Операция: SetProjectLanguage

  
**Параметр** |  **Описание**  
---|---  
PROJECTNAME |  Полное имя проекта. Проект должен быть открыт.   
При вызове из командной строки Windows сначала необходимо использовать ProjectAction.  
DISPLAY |  Язык отображения (например, "en_US"). Если указано несколько языков, отдельные идентификаторы языков разделяются точкой с запятой (";").  
VARIABLE |  Одноязычный (изменяемый) язык отображения. Можно настроить через идентификатор языка (например, "de_DE" для немецкого языка) или через индекс для языка отображения (например, "03_03" для языка отображения 3).  
Последний описанный метод работает только для первых пяти языков отображения (т. е. "05_05" — максимальное значение).  
SOURCE |  Исходный язык.  


!!! note "Замечание:"

    


 

!!! example "Пример:"

    SetProjectLanguage 
/DISPLAY:en_US;de_DE 
/VARIABLE:en_USУстанавливает для языка отображения значение "Язык отображения 4" (здесь для него установлен французский язык):SetProjectLanguage 
/DISPLAY:en_US;de_DE;pl_PL;fr_FR 
/VARIABLE:04_04
