# Определить многополюсные соединения в однополюсной точке определения соединений

В диалоговом окне "Свойства" однополюсной точки определения соединений определите, между какими выводами устройств должны быть многополюсные соединения. При этом можно генерировать перемычки (соединения между выводами устройств того же устройства) и добавить изоляцию. Кроме того, для определенных многополюсных соединений можно задать данные соединений.

Условия:

* Многополюсные функции устройства (например, контакты штекеров) должны создаваться в проекте как неразмещенные функции.
* Однополюсная функция устройства (например, штекера) является главной функцией. В этой функции должно быть активировано свойство **Неразмещенные вспомогательные функции управляются в главной функции**.
* В однополюсном представлении сгенерированы однополюсные соединения.
* Вставлена точка определения соединений и присвоена виду представления "Однополюсн".

1. Выберите точку определения соединения и выберите пункт всплывающего меню **Свойства** (или дважды щелкните по точке определения соединения).
2. Выберите в диалоговом окне **Свойства** ++"..."++ вкладку **Подключить устройства**.

![](images/arrow.png) В поле **Источник устройства** автоматически отобразится устройство, являющееся источником однополюсного соединения. Выводы выбранного устройства отобразятся в столбце **Вывод устройства**. При этом отображаются только выводы неразмещенных многополюсных функций.

![](images/arrow.png) В поле **Цель устройства** автоматически отобразится устройство, являющееся целью однополюсного соединения. Выводы выбранного устройства отобразятся в столбце **Вывод устройства**. При этом отображаются только выводы неразмещенных многополюсных функций.
3. Выделите в левой и правой областях диалогового окна равное количество выводов устройства.

![](images/arrow.png) Если выделено неравное число выводов устройства, тогда все соединения создаются для меньшего количества. Если было выделено больше выводов устройства, чем имеется кабельных соединений, соединяются те выводы устройства, для которых доступны кабельные соединения.
4. Нажмите на ++"Генерировать соединения"++.

![](images/arrow.png) Генерируются многополюсные соединения. Если кабель присвоен однополюсному соединению, генерируются соединения кабелей, в противном случае генерируется жильное / проволочное соединение.
5. Обработайте при необходимости соединения. Выделите для этого нужное соединение и выберите пункт всплывающего меню **Свойства**.
6. Введите в диалоговом окне **Свойства (усл. обозначение): Соединение** нужные данные соединения (например, цвет соединения и обозначение соединения).
7. Подтвердите ввод.

![](images/arrow.png) Многополюсные соединения и данные соединений сохраняются в точке определения соединений.
