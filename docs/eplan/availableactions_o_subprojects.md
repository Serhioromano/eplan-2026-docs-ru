## Операция: subprojects

  
**Параметр** |  **описание**  
---|---  
TYPE |  Вид выполняемой задачи:  
FILEOFF: Выгрузка частичного проекта  
STORE: Сохранение частичного проекта.  
PROJECTNAME |  Имя проекта с полным путем файла (является опцией).  
Если не задано, то выбранный проект используется, когда операция вызывается через интерфейс пользователя (например, через сценарий или ленту). При вызове в командной строке Windows необходимо указать PROJECTNAME.   
Проект должен быть открыт в эксклюзивном режиме обработки для выгрузки или сохранения частичных проектов.  
DESTINATIONPATH |  Целевой каталог (является опцией). Стандартное значение: $(MD_PROJECTS)  
SPNR |  Номер частичного проекта.  
EXPANDONLY |  Только расширить частичный проект (является опцией). Стандартное значение: "Нет".  


!!! example "Пример:"

    Выгрузить частичный проектsubprojects 
/TYPE:FILEOFF 
/PROJECTNAME:C:\Projects\EPLAN\EPLAN_Sample_Project.elk 
/SPNR:1
