# Диалоговое окно Выбор класса применения

Вкладка Основные данные > группа команд Изделия > Управление. Кнопка ++Дополнительно++ > Импортировать. В поле Тип файла выбрана запись для версии ECLASS. Щелкните кнопку ++...++ рядом с полем Тип файла, выберите вкладку Присвоение класса и щелкните ![](images/all_new_as.png) (Создать).

В этом диалоговом окне представляется полный проводной монтаж ECLASS для сегментов ECLASS 19 ("Информационная, коммуникационная и мультимедийная техники"), 23 ("Деталь установки, средство крепления, покрытие"), 27 ("Электротехника, автоматизированная техника и технологический контур") и 37 ("Трубопроводная техника").

Обзор основных элементов диалогового окна:

### Список:

Список содержит все классы для соответствующих сегментов ECLASS в структурированном дереве. Здесь можно произвольно выбрать сегменты, главные группы и т. д. для присвоения свойствам Eplan.

!!! note "Замечание:"

    Характеристики стандарта ECLASS, обозначенные как "Deprecated", для присвоения не предлагаются.
