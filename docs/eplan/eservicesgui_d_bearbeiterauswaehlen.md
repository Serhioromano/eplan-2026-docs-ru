## Диалоговое окно Выбрать обработчик

Вы используете управление правами Eplan и имеете право распределять области обработки в качестве администратора проекта. Вы открыли проект. Файл > Взаимодействие > группа команд Области обработки > Определить > Определить как администратора проекта. Для этого щелкните мышкой в строке необходимой области обработки по ячейке таблицы Все обработчики, а затем по кнопке ++...++.

В этом диалоговом окне можно присвоить одной области обработки несколько обработчиков.

Обзор основных элементов диалогового окна:

Группа пользователей:

В этом раскрывающемся списке отображаются все группы пользователей, которым в управлении присвоено право пользователя. В зависимости от выбранной записи в таблице Обработчик отображаются только те пользователи, которые входят в соответствующую группу пользователей.

Таблица 'Обработчики':

В таблице отображаются свойства Имя и Описание пользователей, определенных в управлении правами. Дополнительно отображаются пользователи, которые были введены вручную, но не определены в управлении правами.

Установите в столбце Присвоить флажок для обработчиков, которым разрешено обрабатывать текущую область обработки. Или снимите флажок напротив тех обработчиков, которым хотите запретить вносить изменения в текущую область обработки.
