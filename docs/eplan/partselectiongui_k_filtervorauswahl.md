## Фильтры и предварительный выбор изделия

Для рационального использования фильтра и поиска необходимо вначале соответствующим образом подготовить данные в базе данных изделий. Эти функции действуют только на те данные, которые внесены в свойствах базы данных изделий, но все же не на данные из определений функции.

При выборе изделий эти два варианта также можно комбинировать между собой:

* Фильтр: С помощью фильтра можно выполнить поиск только в определенных полях записей данных (например, для свойства Номер типа). При этом проверяется, совпадает ли все содержимое поле с искомым текстом.
* Поиск: через поиск можно ввести любой искомый текст. Поиск в управлении изделиями работает так же, как и [поиск](insertergui_k_suchen.md) в центре вставки: вы можете использовать те же операторы и символы-заполнители. По умолчанию при поиске учитываются только самые важные свойства изделия (например, Номер изделия, Номер типа, Производитель и т. д.). Чтобы выполнить поиск по всем свойствам, введите перед поисковым запросом букву "p" (например, p:Двигатель).

Настройки фильтра сохраняются относительно к пользователю.

### Предварительный выбор изделий

Дополнительно к фильтру можно создать и применить предварительный выбор изделий, также список изделий. При выборе изделий затем предлагаются только изделия из этого списка. Можно создавать различные списки и соответственно сохранять под каким-либо именем, так что их всегда можно применить.

Списки предварительного выбора изделия сохраняются для конкретного проекта. При помощи функции экспорта и импорта можно все же их также использовать в других проектах.

#### Выбор кабеля

При выборе кабеля имеется дополнительный фильтр для свойств жилы кабеля. Кроме того, можно определить специальный предварительный список изделий для изделия кабеля.
