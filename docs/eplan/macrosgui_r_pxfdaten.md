# Вкладка Данные (Настройки: Внешняя обработка)

## Вызов диалогового окна (для данных проекта):

* Вы открыли проект. **Файл** > **Экспортировать** > группа команд **Данные проекта** > **Данные проекта** > группа команд **Внешняя обработка** > **Свойства**. Нажмите в диалоговом окне **Внешняя обработка** рядом с полем **Настройки** кнопку ++"..."++. Выберите вкладку **Данные**.
* **Файл** > **Настройки** > **Пользователь** > **Интерфейсы** > **Внешняя обработка**. Выберите вкладку **Данные**.

## Вызов диалогового окна (для данных изделия):

Вкладка **Основные данные** > группа команд **Изделия** > **Управление**. В диалогом окне **База данных изделий** через меню ++"Дополнительно"++ > **Настройки** была открыта база данных изделий. Кнопка ++"Дополнительно"++ > **Внешняя обработка свойств** > **Экспортировать данные**. Нажмите в диалоговом окне **Внешняя обработка** рядом с полем **Настройки** кнопку ++"..."++. Выберите вкладку **Данные**.

На этой вкладке указываются данные, которые необходимо учитывать при внешней обработке.

Обзор основных элементов диалогового окна:

### Категория:

Доступно только для экспорта данных проекта. Выберите из этого раскрывающегося списка, какой вид свойств должен быть отображен в списке.

### Пoиск:

Доступно только для экспорта данных проекта. Введите в это поле текст, по которому должна выполняться фильтрация свойств.

Если необходимо вернуться к прежнему виду свойств, удалите текст из поля ввода. Для этого нажмите кнопку ![](images/all_delete_input_as.png) (Удалить).

### Доступные элементы формата:

Доступно только для экспорта данных проекта. В зависимости от выбранной категории в списке выводятся возможные элементы формата.

Чтобы экспортировать элемент формата, необходимо переместить его вправо в список выбранных элементов формата с помощью кнопки ![](images/all_arrowright_as.png). Многократный выбор невозможен.

### Объект источника:

Доступно только для экспорта данных изделия. В зависимости от выбранного типа объекта в списке отображаются возможные исходные объекты для свойства из базы данных изделий. Для определенного типа объекта (например, изделия) могут быть выведены не только собственные данные, но и данные других объектов, связанных с ним (например, шаблонов функций, схем сверлений, принадлежностей и т. д.). Чтобы иметь возможность выводить данные для такого связанного объекта (например, для 4-го шаблона функции), нажмите на соответствующий узел и выберите в списке исходный объект более низкого уровня с соответствующим индексом (например, "Шаблон функции [4]").

Чтобы экспортировать свойство, необходимо выделить связанный с ним исходный объект и переместить его вправо с помощью кнопки ![](images/all_arrowright_as.png). В открывшемся диалоговом окне **Выбор свойств** отображаются доступные свойства этого исходного объекта, и вы можете выбрать нужное свойство. Возможен многократный выбор.

### Выбранные элементы формата:

В этом списке в табличной форме представлены все выбранные элементы форма и указанием их обозначения и информации "Возможно изменение" = "Да" / "Нет". С помощью кнопок, расположенных над списком, можно удалять элементы формата или изменять их последовательность.

Кнопка |  Значение
---|---
![](images/all_delete_as.png) (Удалить) |  Удаляет выбранный элемент формата.
![](images/all_arrowtop_as.png) (Переместить в начало) / ![](images/all_arrowbottom_as.png) (Переместить в конец) |  Перемещает выделенную запись на первую или последнюю позицию в списке.
![](images/all_arrowup_as.png) (Переместить вверх) / ![](images/all_arrowdown_as.png) (Переместить вниз) |  Перемещает запись в списке вверх / вниз.
![](images/all_arrowswap_as.png) (Заменить) |  Меняет местами позиции двух выделенных записей.
