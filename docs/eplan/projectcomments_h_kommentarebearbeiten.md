## Редактировать комментарии

Вы можете редактировать комментарии, импортированные или созданные в Eplan.

Условия:

* Вы открыли проект. Этот проект содержит комментарии.
* В Графическом редакторе открыта страница проекта.
* Открыт навигатор комментариев.

1. Выделите комментарий на странице проекта или в навигаторе комментариев.
2. Выберите пункт всплывающего меню Свойства.  

Отображается вкладка Комментарий.
3. Измените текст комментария, добавьте ответ или присвойте комментарию другой статус.
4. При необходимости переключитесь на вкладку Формат, чтобы отформатировать комментарий, размещенный на странице проекта.
5. Щелкните по кнопке ++OK++.  

!!! tip "Совет:"

    Комментарии с замкнутой графикой (прямоугольник, ломаная линия), а также графики с сегментами линий могут быть очерчены в форме облака. Для этого в диалоговом окне "Свойства" комментариев на вкладке Форматпод уровнем иерархии "Формат" выберите свойство Тип линиии установите тип линии в виде облака с идентификационным номером "56".
