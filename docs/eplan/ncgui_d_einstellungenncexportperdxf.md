## Диалоговое окно "Настройки: Экспорт ЧУ — DXF" / диалоговое окно "Настройки: Экспорт DXF — медь"

[Вызов диалогового окна:](javascript:void\(0\);)

Экспорт ЧУ — DXF:

  * Файл > Настройки > Компания > Механическая обработка > Экспорт ЧУ — DXF
  * Файл > Экспортировать > группа команд Данные изготовления > Механическая обработка > ЧУ — DXF. Нажмите рядом с полем Машина на кнопку [...].



Экспорт DXF — медь:

  * Файл > Настройки > Компания > Механическая обработка > Экспорт DXF — медь
  * Файл > Экспортировать > группа команд Данные изготовления > Механическая обработка > DXF — медь. Нажмите рядом с полем Машина на кнопку [...].



В этом диалоговом окне установите настройки для экспорта ЧУ и меди в формате DXF.

Обзор основных элементов диалогового окна:

Машина:

В комплекте поставки содержится соответствующее определение машины с названием "Стандарт". Если в качестве схемы сгенерирована другая машина, можно выбрать из раскрывающегося списка другие определения машины и работать с ними.

Через расположенную рядом [панель инструментов](schemeconfig_m_schemaschaltflaechen.htm) можно создавать новые схемы, сохранять изменения в схеме, копировать или удалить схему. Кроме того, схемы можно импортировать и экспортировать.

Описание:

В этом поле дается описание, которое было введено в диалоговом окне Новая схема в поле Описание для машины.

Вкладки:
