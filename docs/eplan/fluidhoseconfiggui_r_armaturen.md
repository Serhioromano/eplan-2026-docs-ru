## Вкладка "Арматура"

[Вызов диалогового окна:](javascript:void\(0\);)

  * Файл > Настройки > Пользователь > Add-ons > Конфигуратор шлангопроводов. Нажмите на вкладку Арматура.
  * Вы открыли проект. Вы открыли диалоговое окно [Конфигурировать шлангопроводы](fluidhoseconfiggui_d_schlauchleitungen.htm). Выберите пункты меню Дополнительно > Настройки. В последующем диалоговом окне нажмите на вкладку Арматура.



В этой вкладке можно управлять данными арматуры для шлангопроводов. При конфигурировании шлангопроводов записанные значения предлагаются на выбор в диалоговом окне Обработать <...>.

Обзор основных элементов диалогового окна:

Таблица:

В этой таблице можно определять типы конструкций, серии, номера изделий и графические файлы арматур.

С помощью кнопки [...] в ячейках таблицы столбца Номер изделия можно получить доступ к базе данных изделий и выбрать в ней нужное изделие.

В столбце Графический файл для каждой арматуры можно сохранить путь к графическому файлу. Графический файл отображается в окне предварительного просмотра при выборе арматуры.   
С помощью доступной в ячейках таблицы кнопки [...] можно задать графический файл через окно выбора. Возможные типы графических файлов — *. gif и *.jpg.

Используйте кнопки панели инструментов над таблицей для создания новых записей и/или удаления ненужных записей.

Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.htm).
