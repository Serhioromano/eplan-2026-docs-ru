# Диалоговое окно Настройки: Экспорт текстового файла

## Вызов диалогового окна (для данных проекта):

* Вы открыли проект. **Файл** > **Экспортировать** > группа команд **Данные проекта** > **Данные проекта** > группа команд **Внешняя обработка** > **Свойства**. Нажмите в диалоговом окне **Внешняя обработка** рядом с полем **Настройки** кнопку ++"..."++. Выберите в следующем диалоговом окне вкладку **Общее**. Выберите из этого раскрывающегося списка **Тип файла** одну из записей "Текст, разделенный табуляторами", "Файл в формате Юникод с разделением табуляцией (*.txt)" или "XML-файл (*.edc)" и щелкните ++"Параметры"++.
* **Файл** > **Настройки** > **Пользователь** > **Интерфейсы** > **Внешняя обработка**. Выберите вкладку **Общее**. Выберите из этого раскрывающегося списка **Тип файла** одну из записей "Текст, разделенный табуляторами", "Файл в формате Юникод с разделением табуляцией (*.txt)" или "XML-файл (*.edc)" и щелкните ++"Параметры"++.

## Вызов диалогового окна (для данных изделия):

Вкладка **Основные данные** > группа команд **Изделия** > **Управление**. В диалогом окне **База данных изделий** через меню ++"Дополнительно"++ > **Настройки** была открыта база данных изделий. Кнопка ++"Дополнительно"++ > **Внешняя обработка свойств** > **Экспортировать данные**. Нажмите в диалоговом окне **Внешняя обработка** рядом с полем **Настройки** кнопку ++"..."++. Выберите вкладку **Общее**. Выберите из этого раскрывающегося списка **Тип файла** одну из записей "Текст, разделенный табуляторами", "Файл в формате Юникод с разделением табуляцией (*.txt)" или "XML-файл (*.edc)" и щелкните ++"Параметры"++.

В этом диалоговом окне указываются настройки для внешней обработки страниц, функций или соединений с помощью текстового редактора.

Обзор основных элементов диалогового окна:

### Прикладная программа:

Укажите здесь имя (с указанием дисковода и каталога) прикладной программы, которую требуется использовать для соответствующего формата, или же нажмите кнопку ![](images/all_selectfile_as.png){: .ui-icon } для интерактивного выбора программы.

С помощью пункта всплывающего меню **Вставить переменную пути** перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.
