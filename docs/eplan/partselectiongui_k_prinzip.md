## Поведение изделий при выборе устройств

Для выбора устройства большое значение имеет нижеописанное поведение изделий.

### Сохранение изделий

Изделия сохраняются в проекте в следующих местах:

  * Изделия для комплектующих диталей, общих установочных материалов и т. д. можно присваивать непосредственно проекту. Возможно применение до 1000 покупных изделий.
  * Главной функции устройства можно присваивать до 50 номеров изделия.
  * Через точку определения изделия (как у каждой главной функции) можно сохранить в одном месте схемы соединений до 50 изделий.



### Сохраненные в проекте изделия

Некоторые свойства изделия (напр., закупочная цена) необходимы для расчета в списках вывода, но не всегда они должны попадать заказчикам. Через диалоговое окно конфигурации можно установить, какие свойства сохраняются в проект. Затем эти свойства также применяются при дальнейшей передаче проекта. Несохраненные свойства изделий доступны только через обращение к базе данных изделий.

В диалоговом окне Удалить сохраненные свойства изделия можно быстро просмотреть, какие свойства изделий сохранены в проекте. Кроме того, можно удалить отдельные свойства сохраненных в проекте изделий.

В диалоговом окне Синхронизация изделий - <Имя проекта> можно выполнять синхронизацию сохраненных в проекте изделий с изделиями системы.

### Обновление данных изделия и устройства

Изделия и другие основные данные постоянно обновляются и становятся доступными, например, через Eplan Data Portal. Это может привести к изменению данных изделий, хранящихся в проекте, в базе данных изделий.   
Для переноса таких измененных данных в проект доступны различные функции синхронизации данных изделия:

  * Синхронизировать текущий проект (команда Синхронизировать)
  * Обновить текущий проект (команда Обновить)
  * Дополнить текущий проект (команда Дополнить)
  * Обновить сохраненные изделия при открытии проекта
  * Синхронизация данных после изменения изделия



Если изделия в проекте старее, чем в базе данных изделий, то новые изделия сохраняются в проекте при синхронизации данных изделий. Чтобы перенести для этих функций данные устройства в проект, необходимо активировать настройку [Обновлять данные устройства после сохранения изделий](partselectiongui_d_datenauswahlbenutzer.htm#GeraetedatenAktualisieren). В этом случае из шаблонов функций в главные функции, которые используют эти изделия, будут перенесены еще и более новые данные устройства.

При обновлении или пополнении проекта данные устройства обновляются для всех затронутых изделий, а при синхронизации данных изделий обновляются только данные устройства для выбранного изделия. При этом соответствующие номера изделий и данные ссылки изделий остаются неизменными.

При выполнении всех этих действий переносятся только данные шаблонов функций.



!!! note "Замечание:"

    При присвоении данных шаблонов изделия функциям на схеме соединений используютсянастройкив диалоговом окнеНастройки: Выбор устройства.


 

#### Выбор изделия и устройства — обновленное изделие

При выборе изделия и устройства для изделия, состояние которого в проекте более старое, чем в базе данных изделий, обновление данных устройства происходит на соответствующей главной функции. При выборе устройства это означает, что в дополнение к данным шаблона переносятся еще и данные других свойств изделия (например, длина кабеля, введенная на изделии). Настройка Обновлять данные устройства после сохранения изделий не влияет на это обновление данных устройства.

Однако, поскольку данные устройства не могут быть перенесены на все варианты использования изделия в проекте (например, если данные шаблона были изменены), в этом случае отображается запрос. Вы можете решить, нужно ли выбрать это обновленное изделие или другое изделие.

Чтобы в таком случае иметь возможность обновлять данные устройства на функциях в проекте, в навигаторе спецификаций доступен пункт всплывающего меню Обновить данные устройства. При этом так же, как и при выборе устройства, в дополнение к данным шаблона переносятся еще и свойства изделия.

### Изделия, сгенерированные из данных схемы соединений

Через команду Генерировать изделие можно сгенерировать изделие из данных схемы соединений. Это изделие сохраняется в проекте как сохраненное в проекте изделие. При этом в базе данных изделий сохраняется устройство, т. е. изделия и типовые для устройства данные сохраняются в базе данных изделий. Если устройству назначены подустройства, то типичные для подустройств данные переносятся в изделие.

Это действие может выполняться только при условном обозначении главной функции. Оно доступно только в том случае, если внесена хотя бы одна ссылка изделия (с числом изделий 1) в ОУ.

Таким образом сгенерированное изделие содержит шаблоны функции для всех функций устройства.

По умолчанию с помощью команды изделие генерируется как отдельная часть. Если нужно сгенерировать изделие как модуль или узел, перед генерированием необходимо установить в свойстве ссылки изделия Тип записи данных запись "Модуль" или "Узел".

### Спецификация

Через сохраненное изделие можно генерировать спецификацию, которая содержит такие дополнительные данные, как "Описание", " Поставщик" и т. д. Такая спецификация может, например, затем передаваться заказчикам (с дополнительной информацией) без необходимости передачи всей базы данных изделий.

Спецификация изделий может выдаваться в различных отсортированных / сгруппированных списках вывода. При этом иерархически построенные группы изделий могут дополнительно разворачиваться или выдаваться до установленной глубины.



!!! note "Замечание:"

    Следует обратить внимание на то, что изделия с количеством = "0" выводятся всегда! Чтобы не выводить такие изделия, необходимо установить соответствующийфильтр.


 

### Компоновка электрошкафа

Элементы, сохраненные в схеме соединений на устройствах, определяют на монтажной плате механическую занимаемую площадь. В базе данных изделий можно управлять присвоением данных заказов к механическим символам с определением размеров (уровень иерархии Монтажные данные на вкладке Свойства).

### Узлы

При присвоении изделий устройствам могут разворачиваться вложенные узлы. Отдельный элемент содержит при этом свою информацию, к какому узлу он относится.

В настройках пользователя Развернуть узел задается, разворачиваются ли узлы при вставке и до какой степени (Файл > Настройки > Пользователь > Управление > Выбор изделия). Дополнительно существует настройка проекта Развернуть узел, с помощью которой задается, разворачиваются ли узлы в отчетах и каким образом (Файл > Настройки > Проекты > "Имя проекта" > Отчеты > Изделия). Если узлы были развернуты при вводе, их нельзя снова обрабатывать в отчете в качестве узла.

### Варианты изделий

Для поддержки многофункциональных реле в базе данных изделий могут создаваться так называемые варианты изделий.

Если к устройству добавляется новое изделие и в этом изделии находится шаблон функции, то этот шаблон функции добавляется в устройство. Если изделие удаляется из устройства, то также удаляются все шаблоны функции, которые относятся к этому изделию.
