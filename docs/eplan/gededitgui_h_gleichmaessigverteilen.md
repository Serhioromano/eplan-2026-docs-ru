## Равномерно распределить элементы

С помощью команд Распределить по горизонтали и Распределить по вертикали можно присвоить нескольким выделенным элементам одинаковый интервал по отношению друг к другу в горизонтальном или вертикальном направлении. Эту операцию можно использовать только для элементов с точками вставки (тексты, символы, размещенные устройства и т. д.), причем простые графические элементы, например прямоугольники и линии, учитываются не так, как ожидается.

Условие:

Вы открыли редактор, например графический редактор, редактор рамок и т. д.

1. Выберите соответствующие элементы.
2. Выберите следующие команды: Вкладка Обработать > группа команд Упорядочить > Распределить по горизонтали или раскрывающаяся кнопка Распределить по горизонтали > Распределить по вертикали.  
  
Eplan определяет расстояние между первым и последним элементом и равномерно распределяет все остальные элементы между ними.

!!! note "Замечание:"

    Обратите внимание, что при распределении элементовсеткане учитывается; при необходимости воспользуйтесь командойВыровнять по сетке, чтобы снова разместить элементы на сетке.
