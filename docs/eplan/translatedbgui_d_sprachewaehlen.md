## Вкладка / диалоговое окно "Выбрать языки"

Вы открыли проект.

* Вкладка Инструменты > группа команд Перевод > Убрать перевод
* Вкладка Инструменты > группа команд Перевод > Импортировать тексты проекта
* Вы выделили проект или страницы. Вкладка Инструменты > группа команд Перевод > Экспортир. список отсутствующих слов

В этом диалоговом окне вы можете выбрать из приведенных языков один или несколько языков.

Доступны следующие элементы диалогового окна

Язык:

Выделите язык, который необходимо выбрать. Чтобы выбрать несколько языков, выделите нужные языки, удерживая клавишу ++Ctrl++.
