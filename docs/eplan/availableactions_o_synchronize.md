## Операция: synchronize

**Параметр** |  **Описание**  
---|---  
TYPE |  Вид выполняемой задачи:  
MULTILINE: 'Многополюсная' синхронизация данных.  
SINGLELINE: 'Однополюсная' синхронизация данных.  
OVERVIEW: 'Обзорная' синхронизация данных.  
SYSTEMPARTSTOPROJECT: Добавление изделий системы в проект. PARTSTOSYSTEM: Добавление изделий из проекта в основные данные системы.  
  
PROJECTNAME |  Имя проекта с полным путем файла (является опцией).  
Если не задано, то выбранный проект используется, когда операция вызывается через интерфейс пользователя (например, через сценарий или ленту). При вызове из командной строки Windows следует определить PROJECTNAME или сначала следует использовать ProjectAction. В противном случае отобразится системное сообщение.  
STOREMODE |  Указывает, будут ли перезаписаны существующие изделия или добавлены только новые (необязательно):

* 0: добавление только новых изделий (значение по умолчанию)
* 1: перезапись только существующих изделий
* 2: перезапись существующих изделий и добавление новых

Этот параметр оказывает влияние, только когда параметр TYPE имеет следующее значение: SYSTEMPARTSTOPROJECT.
