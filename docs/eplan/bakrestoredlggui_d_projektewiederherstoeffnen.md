# Диалоговое окно Восстановить проект

## Вызов диалогового окна:

**Файл** > **Открыть** > группа команд **Открыть** > **Поиск**. Выберите в следующем диалоговом окне резервированный проект Eplan (*.zw1). Кнопка ++"Открыть"++.

В этом диалоговом окне отображаются выбранные для открытия резервированные проекты, где можно задать, в каком каталоге они будут восстановлены.

Обзор основных элементов диалогового окна:

### Проекты:

В этом списке отображаются проекты, которые были ранее выбраны для открытия.

### Целевой каталог:

Укажите каталог, в который будет сохранен восстановленный проект. При помощи ![](images/all_selectdirectory_as.png){ .ui-icon } можно открыть диалоговое окно для выбора каталога и перейти в нем к нужному каталогу.

С помощью пункта всплывающего меню **Вставить переменную пути** перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

### Подкаталог:

В этом поле отображается подкаталог, расположенный под стандартным каталогом, в котором находился проект на момент резервирования. Если подкаталог отсутствовал, ничего не отображается.

### Восстановить в подкаталоге:

Установите этот флажок, если проект должен быть восстановлен в исходном подкаталоге. Если при резервировании данных сохраненных каталогов нет, флажок недоступен.
При необходимости использования подкаталога, который не существует, появится запрос о его создании.

### Имя проекта:

Если выбран всего один проект для открытия, здесь отобразится его имя. Чтобы не перезаписывать уже существующий проект, следует задать другое имя.
Если выбрано несколько проектов для открытия, это поле будет пустым, и вы не сможете изменить имена проектов.
