# Диалоговое окно "Диспетчер разводки"

Вы открыли проект. Вы открыли пространство листа. Вкладка Обработать > группа команд Маршрутизируемые соединения > Диспетчер.

В этом диалоговом окне вы можете управлять маршрутизируемыми соединениями, которые включены в выбор (например, в навигаторе пространства листа, в трехмерном навигаторе монтажных поверхностей, в навигаторе соединений). Отображаются только те соединения, определения функций которых учитываются при маршрутизации, а источник и цель как размещение изделия находятся в одном и том же пространстве листа.
При выборе в навигаторе пространства листа или трехмерном навигаторе монтажных поверхностей в строке заголовка диалогового окна отображается имя первого объекта, включенного в выбор. Если в выбор не включены соединения, которые можно отобразить в диалоговом окне, будет показан текст "Недействительный выбор".

Обзор основных элементов диалогового окна:

### Панель инструментов:

На панели инструментов над таблицей отображается количество соединений, перечисленных в таблице. Здесь также имеется несколько кнопок, с помощью которых можно фильтровать отображаемые соединения по статусу, актуальному для маршрутизации или разводки. Рядом с каждой кнопкой указывается количество соответствующих соединений.

Вы можете настроить отображение данных с помощью следующих кнопок:

Кнопка |  Значение
---|---
![](images/wiringmanager_notrouted_as.png){ .ui-icon } (Немаршрутизированные соединения) |  Отображаются только немаршрутизированные соединения.
![](images/wiringmanager_routed_as.png){ .ui-icon } (Маршрутизированные соединения) |  Отображаются только маршрутизированные соединения.
![](images/wiringmanager_exported_as.png){ .ui-icon } (Экспортированные соединения) | Отображаются только экспортированные соединения.
![](images/wiringmanager_notroutable_as.png){ .ui-icon } (Немаршрутизируемые соединения) | Отображаются только немаршрутизируемые соединения.
![](images/wiringmanager_protected_as.png){ .ui-icon } (Защищенные соединения) | Отображаются только защищенные соединения.
![](images/wiringmanager_notexportable_as_15x15.png){ .ui-icon } (Неэкспортируемые соединения) | Отображаются только неэкспортируемые соединения.
![](images/all_update_as.png){ .ui-icon } (Обновить) | Обновляется отображение соединений в таблице. При этом заново анализируется выбор (например, в навигаторе пространства листа).
При обновлении с помощью клавиши ++F5++ обновляются только данные уже отображенных в диалоговом окне соединений.
Обновление необходимо, например, если изменились исходные данные соединений или если соединения были маршрутизированы или удалены.

Таблица:

В таблице в одной строке отображаются свойства соединения, такие как определение функции, источник и цель соединения, а также некоторые свойства соединения. При необходимости можно показать дополнительные столбцы, например, с информацией о трассе маршрутизации или типе потенциала, выбрав пункт всплывающего меню Конфигурировать представление. Данные соединения отображаются в соответствии с режимом обработки Свойства (общие), т. е. свойства соответствующего 2D-соединения и 3D-соединения объединяются в одной строке. Свойства в таблице нельзя изменить. Если вы выделили строку или ячейку в таблице, можно здесь дважды щелкнуть, чтобы открыть диалоговое окно "Свойства" соединения в режиме обработки Свойства (общие).

В таблице могут отображаться, в частности, следующие столбцы:

* Определение функции: Отображается определение функции соединения.
* Пространство листа: Отображается пространство листа, в котором находится соединение.
* Источник: Отображается ОУ устройства, являющегося источником соединения.
* Цель: Отображается ОУ устройства, являющегося целью соединения.
* Цвет / номер соединения: Отображается цветовой код, имя или номер цвета соединения.
* Обозначение соединения: Отображается обозначение соединения.
* Поперечное сечение соединения / диаметр с единицей измерения: Отображается поперечное сечение или диаметр соединения с указанием единицы измерения.
* Соединение: Длина с единицей измерения: Отображается длина соединения с указанием единицы измерения.
* Контрольный прогон: Статус: Если во время маршрутизации или экспорта выводились сообщения, то здесь будет показан статус первого сообщения, выведенного для этого соединения.
* Контрольный прогон: Номер: Если во время маршрутизации или экспорта выводились сообщения, то здесь будет показан номер контрольного прогона первого сообщения, выведенного для этого соединения.
* Контрольный прогон: Текст сообщения: Если во время маршрутизации или экспорта выводились сообщения, то здесь будет показан текст первого сообщения, выведенного для этого соединения.
* Статус: Отображается статус соединения. Возможные значения: "Не маршрутизировано", "Маршрутизировано", "Немаршрутизируемое", "Защищено", "Экспортировано" и "Неэкспортируемое".

!!! note "Замечание:"

    Столбцы Источник и Цель позволяют обрабатывать устройства, подключенные к соединению, и поэтому их поведение отличается. Если выбрать какую-либо ячейку в одном из этих столбцов, то во всплывающем меню появятся пункты, позволяющие переходить к источнику или цели соединения. Кроме того, можно дважды щелкнуть здесь, чтобы открыть диалоговое окно "Свойства" соответствующего устройства в режиме обработки Свойства (общие).

### Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).

Дополнительно здесь представлены следующие пункты всплывающего меню, специфические для данного диалогового окна:

Пункт меню |  Значение
---|---
Перейти к (2D, соединение) |  Выделенное 2D-соединение отображается в графическом редакторе.
Перейти к (3D, соединение) |  Выделенное 3D-соединение отображается в пространстве листа.
Перейти к (2D, источник) | Доступно, только когда выделена ячейка в столбце Источник. Устройство, являющееся источником выделенного соединения, отображается в графическом редакторе.
Перейти к (3D, источник) | Доступно, только когда выделена ячейка в столбце Источник. Размещение изделия, являющееся источником выделенного соединения, отображается в пространстве листа.
Перейти к (2D, цель) | Доступно, только когда выделена ячейка в столбце Цель. Устройство, являющееся целью выделенного соединения, отображается в графическом редакторе.
Перейти к (3D, цель) | Доступно, только когда выделена ячейка в столбце Цель. Размещение изделия, являющееся целью выделенного соединения, отображается в пространстве листа.
Маршрутизировать | Маршрутизируются выделенные соединения, при этом генерируются маршрутизируемые соединения между 3D-размещениями изделий.
Свободная маршрутизация | Выделенные соединения свободно маршрутизируются в пространстве вне сети соединенных сегментов.
Удалить маршрутизацию | Удаляются выделенные 3D-соединения. При этом обновляется статус соединения в диалоговом окне и может принимать значения "Не маршрутизировано" или "Немаршрутизируемое". Если соединений больше нет, то строка удаляется.
