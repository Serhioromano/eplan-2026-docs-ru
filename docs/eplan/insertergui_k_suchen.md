## Поиск в центре вставки и управлении изделиями

### Отличия поиска в зависимости от настроенной базы данных изделий

Поиск в центре вставки и управлении изделиями, производимый в базах данных Eplan (напр., базах данных изделий Eplan в формате alk) выполняется не так, как в базах данных изделий SQL. Это, среди прочего, связано с тем, что при использовании баз данных изделий SQL поиск выполняется не локально, а на сервере SQL.

Имеются такие отличия:

* При поиске в базах данных Eplan искомое понятие ищется в настроенном языке диалогового окна, а при поиске на сервере SQL — на всех языках.
* При поиске в базах данных Eplan искомое понятие может быть найдено также внутри или в конце слова. При поиске в базах данных изделий SQL искомое понятие может быть найдено только в начале слова. Поиск в базе данных изделий Eplan по слову "Bus" выдаст как "Bus", так и "Interbus". Поиск в базе данных изделий SQL по тому же запросу выдаст только результаты "Bus".
* Сервер SQL поддерживает по выбору полнотекстовый поиск или прямой поиск по данным. При этом скорость прямого поиска непосредственно зависит от количества ядер ЦПУ на сервере SQL.

### Операторы и символы-заполнители

При поиске поддерживаются логические операторы (связь И/ИЛИ) и символы-заполнители (например, * или ?).

При полнотекстовом поиске на сервере SQL не следует использовать символы-заполнители (например, * или ?), так как при таком поиске они не анализируются. Эти ограничения зависят от поисковых механизмов используемых баз данных.

Символ |  Использование  
---|---  
Пробел |  Соединение И  
| |  Соединение ИЛИ  
- |  Соединение НЕ (поиск с отрицанием)  
* |  Любое количество символов. При полнотекстовом поиске на сервере SQL не поддерживается.  
? |  Один символ. При полнотекстовом поиске на сервере SQL не поддерживается.  
  
Кроме того, вводя поисковый термин в кавычках ("искомое понятие"), можно выполнить поиск в точности с последовательностью символов. Поиск не учитывает написание искомого понятия в верхнем или нижнем регистрах.

### Поиск в центре вставки

С помощью поля Поиск центр вставки дает возможность поиска по всем типам объектов. Если нужно ограничить поиск определенным типом объекта, можно воспользоваться фильтром поиска. Этот фильтр активируется нажатием кнопки  перед полем поиска. После нажатия кнопки откроется меню с соответствующими параметрами Поиск в <...> для всех типов объектов.

#### Учитываемые свойства и объекты

При поиске внутри символов учитываются следующие свойства:

* Имя символа (ид. 16000)
* Описание символа (ид. 16011)
* Определение функции (ид. 20026)
* Определение функции: Описание (ид. 20117)

При поиске внутри устройств учитываются свойства изделия, указанные ниже.

* Номер изделия (ид. 22001)
* Номер типа (ид. 22002)
* Номер для заказа (ид. 22003)
* Изделие: Обозначение 1 (ид. 22004)
* Изделие: Обозначение 2 (ид. 22005)
* Изделие: Обозначение 3 (ид. 22006)
* Производитель (ид. 22007)
* Поставщик (ид. 22008)
* Описание (ид. 22009)
* Технические параметры (ид. 22017)
* Атрибуты (ид. 22051)
* Номер ERP / PDM 1 (ид. 22056)
* Имя производителя (ид. 22222)
* Имя поставщика (ид. 22223)

При поиске внутри макросов окон / символов учитываются указанные ниже свойства.

* Макрос: Имя файла (ид. 23001)
* Макрос: Описание (ид. 23004)

Если вы хотите выполнить поиск по свойствам, отличным от перечисленных, нажмите кнопку […] и в следующем диалоговом окне с помощью схемы укажите, какие свойства следует учитывать при поиске.

Если определены теги, в центре вставки можно выполнять поиск по объектам, для которых назначен тег. Для этой цели можно использовать искомое понятие t:<Имя тега>, например t:Двигатель.

#### Результаты поиска

После выполнения поиска в строке навигации отобразится запись Главная > Результаты поиска. Результат поиска (разделенный по типам объектов) появится под строкой навигации в форме раскрывающихся папок. Количество найденных совпадений по каждому типу объекта можно узнать, посмотрев на число рядом с папками. После раскрытия соответствующей папки найденные объекты будут предложены для предварительного просмотра в виде плиток. Из режима предварительного просмотра результата поиска путем перетаскивания мышью можно вставить нужные объекты непосредственно на схему соединений или в пространство листа.

Результат поиска остается даже при переходе на главный экран центра вставки, откуда его можно вызвать через папку Результаты поиска. После удаления искомого понятия эта папка больше не будет отображаться.

!!! note "Замечание:"

    Определяемый результат поиска зависит от того, открыта ли страница проекта или пространство листа.

 

#### Целевой поиск в центре вставки через клавиатуру

При нажатии определенных клавиш можно отобразить всплывающее окно центра вставки, причем курсор сразу же помещается в поле Поиск. По завершении поиска папка с типом объекта, который соответствует комбинации клавиш, автоматически расширяется, а найденные объекты отображаются в виде плиток в окне предварительного просмотра.

Комбинация клавиш |  Тип объекта  
---|---  
[Insert] |  Символы  
[Alt] \+ [Insert] |  Устройства  
[M], [Ctrl] \+ [Insert] |  Макросы окна / символа  
  
### Дополнительный поиск в Eplan Data Portal

Если вы зарегистрировались в Eplan Cloud, то для управления изделиями и центра вставки можно с помощью пиктограммы "Data Portal" открыть специальное окно для Eplan Data Portal. Если поиск в управлении изделиями не дал результатов, то он будет продолжен в Eplan Data Portal. Если при поиске в центре вставки активирован один из фильтров поиска для Eplan Data Portal, то поиск также будет выполняться в Eplan Data Portal. При этом поиске в Eplan Data Portal не учитываются операторы, символы-заполнители и свойства, указанные в конфигурации поиска.

Также при поиске в Eplan Data Portal количество найденных совпадений отображается в результатах поиска под строкой навигации. Чтобы отобразить результаты в Eplan Data Portal, можно нажать на пиктограмму  "Data Portal" в результатах поиска.
