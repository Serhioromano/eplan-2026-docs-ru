# Диалоговое окно Настроить

* Нажмите в строке заголовка главного окна Eplan на пиктограмму ![](images/all_quickaccess_as.png) (настроить панель быстрого доступа) и выберите команду Другие команды.
* Нажмите правой кнопкой мыши на ленте и выберите команду Настроить ленту.

В этом диалоговом окне можно настроить панель быстрого доступа и ленту в соответствии с вашими потребностями.

!!! note "Замечание:"

    * После настройки панели быстрого доступа и / или ленты необходимо задать текущую конфигурацию интерфейса пользователя как новую рабочую область или пересохранить выбранную вами рабочую область (с помощью команды Обработать раб. область), чтобы изменения были доступны Вам постоянно (в текущей рабочей области).
    * Вкладка Лента всегда содержит отображаемое имя для каждой команды, которое также появляется под сконфигурированной кнопкой. В результате в раскрывающемся списке Выбрать команды для некоторых команд отображаются одинаковые тексты. Чтобы их различать, вызовите всплывающую подсказку, наведя курсор на соответствующую запись.

    * Во всплывающей подсказке для каждой команды также отображается категория, для которой назначена данная команда. Это также касается команд, которые по умолчанию не отображаются на ленте.

    * * *

### Вкладка "Быстрый доступ"

На этой вкладке Вы выбираете нужные команды, которые должны быть доступны в виде пиктограмм на панели быстрого доступа.

Обзор основных элементов диалогового окна:

### Вкладки:

В этом списке отображаются все вкладки ленты. Также здесь доступна запись "Все команды". При выборе данной записи в расположенном ниже поле будут отображены все команды на ленте, которые можно настроить для быстрого доступа.

### Команды:

После выбора записи в поле Вкладки в этом списке будут отобразятся соответствующие команды. С помощью кнопки ![](images/all_arrowright_as.png){ .ui-icon } можно добавить выделенную команду панели быстрого доступа. В быстром доступе отображается соответствующая пиктограмма команды.

(Выбранные команды:)

В поле справа отображаются выбранные команды. При помощи кнопок ![](images/all_arrowup_as.png){ .ui-icon } и ![](images/all_arrowdown_as.png){ .ui-icon } можно изменить последовательность команд на панели быстрого доступа.

### Отображать под лентой:

Если этот флажок установлен, панель быстрого доступа отобразится под лентой.

### [Сбросить]:

Нажмите на эту кнопку, если хотите сбросить панель быстрого доступа на состояние по умолчанию.

* * *

### Вкладка "Лента"

На этой вкладке можно настроить ленту в соответствии с вашими требованиями. Выбранные команды могут быть присвоены определенной пользователем группе команд.

Обзор основных элементов диалогового окна:

### Выбрать команды:

Выберите в раскрывающемся списке нужную категорию, из которой вы хотите выбрать команду. В поле ниже отображаются все команды данной категории.

При помощи кнопки ![](images/all_arrowright_as.png){ .ui-icon } можно присвоить выделенную команду определенной пользователем группе команд.

### Настроить ленту:

Выберите в раскрывающемся списке нужную категорию вкладок, которую хотите настроить для ленты.

### Главные вкладки:

Отображает существующие главные вкладки ленты на высшем уровне иерархии (например, Пуск). Снимите флажок впереди, если хотите скрыть соответствующую вкладку в ленте.

Под вкладками отображаются группы команд , а на низшем слое — команды. Как предварительно определенные, так и определенные пользователем вкладки и группы команд можно переименовать с помощью всплывающего меню или кнопки ++Правка++. Удаление групп команд и определенных пользователем вкладок возможно только с помощью команды Удалить во всплывающем меню.

### [Новая вкладка]:

Нажмите на эту кнопку, чтобы создать новую определенную пользователем вкладку под выбранной в данный момент вкладкой.

### [Обработать]:

Открывает одноименное диалоговое окно, с помощью которого можно переименовать вкладки, группы команд и команды, присвоенные определенным пользователем группам команд. Команды, перечисленные на стандартных вкладках, невозможно переименовать.

### [Новая группа команд]:

Нажмите на эту кнопку, чтобы создать новую определенную пользователем группу команд под выбранной в данный момент вкладкой.

### [Сбросить]:

Нажмите на эту кнопку, если хотите сбросить все настройки для ленты на состояние по умолчанию.

### Комбинации клавиш:

При помощи кнопки ++Настроить++ перейдите в диалоговое окно Настроить комбинации клавиш, в котором можно настроить комбинации клавиш для отдельных команд.
