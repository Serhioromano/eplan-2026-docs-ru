## Вкладка Настройки: Пространство конструкции — Определения функций (импорт)

Файл > Настройки > Пользователь > Интерфейсы > Импорт и экспорт пространства конструкции. Выберите вкладку Определения функций (Импорт).

На этой вкладке вы указываете, какие определения функций и функциональные элементы должны автоматически назначаться импортированным трехмерным телам в Eplan при импорте файлов STEP с пространствами конструкции.

!!! note "Замечание:"

    Eplan поддерживает исключительно импорт файлов STEP, сгенерированных с помощью прикладного протокола AP 203 или AP 214.

Обзор основных элементов диалогового окна:

Укажите схему присвоения в следующий полях:

* Обозначение в CAD: Укажите внутризаводское обозначение функционального элемента, используемое для данного трехмерного тела в CAD-системе, из которой выполнялся экспорт.
* Определение функции в Eplan: Выберите определение функции, которое должно автоматически назначаться трехмерному телу, экспортированному из CAD-системы при импорте в Eplan, например: "Стенка". С помощью кнопки [...] можно открыть диалоговое окно Определения функций.
* Функциональный элемент в Eplan: Выберите для определения функции подходящий функциональный элемент, который должен автоматически назначаться трехмерному телу, экспортированному из CAD-системы при импорте в Eplan, например: "Боковая стенка справа".

!!! note "Замечание:"

    Геометрической модели, содержащейся в файле STEP, при импорте автоматически назначается определение функции "Электрошкаф".
