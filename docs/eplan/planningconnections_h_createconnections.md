# Сгенерировать неразмещенные соединения

Неразмещенные соединения – соединения между выводами устройства, еще не размещенные на странице. Есть возможность сгенерировать неразмещенные соединения между выводами устройства. При генерировании соединения можно сгенерировать жильное / проволочное соединение, использовать имеющиеся кабели или создать новые кабели.

### Сгенерировать неразмещенное жильное / проволочное соединение

Условие:

Создано минимум 2 устройства с выводами устройств.

1. Выберите следующие команды: Вкладка **Устройства** > группа команд **Устройства** > **Навигатор**.
2. Выделите устройство, которое имеет выводы и должно быть источником соединения.
3. Выберите следующие команды: Вкладка **Устройства** > группа команд **Устройства** > раскрывающаяся кнопка **Дополнительно** > **Подключить устройства**.

![](images/arrow.png) Откроется диалоговое окно **Подключить устройства**.

![](images/arrow.png) Выделенное устройство автоматически отображается в поле **Источник устройства**. Выводы выделенного устройства отобразятся в столбце **Вывод устройства**.
4. Щелкните рядом с полем **Цель устройства** по ++"..."++, выберите в выведенном диалоговом окне устройство, которое должно быть целью соединения, и щелкните на ++"OK"++.

![](images/arrow.png) Выбранное устройство автоматически отображается в поле **Цель устройства**. Выводы выбранного устройства отобразятся в столбце **Вывод устройства**.
5. Выделите в левой и правой областях диалогового окна равное количество выводов устройства.

![](images/arrow.png) Если выделено неравное число выводов устройства, тогда все соединения создаются для меньшего количества. Если было выделено больше выводов устройства, чем имеется кабельных соединений, соединяются те выводы устройства, для которых доступны кабельные соединения.
6. Чтобы сгенерировать жильные / проволочные соединения, щелкните по ++"Генерировать соединения"++.

![](images/arrow.png) Выполняется генерация соединений.

### Сгенерировать неразмещенное кабельное соединение

Условие:

Создано минимум 2 устройства с выводами устройств.

1. Выберите следующие команды: Вкладка **Устройства** > группа команд **Устройства** > **Навигатор.**
2. Выделите устройство, которое имеет выводы и должно быть источником соединения.
3. Выберите следующие команды: Вкладка **Устройства** > группа команд **Устройства** > раскрывающаяся кнопка **Дополнительно** > **Подключить устройства**.

![](images/arrow.png) Откроется диалоговое окно **Подключить устройства**.

![](images/arrow.png) Выделенное устройство автоматически отображается в поле **Источник устройства**. Выводы выделенного устройства отобразятся в столбце **Вывод устройства**.
4. Щелкните рядом с полем **Цель устройства** по ++"..."++, выберите в выведенном диалоговом окне устройство, которое должно быть целью соединения, и щелкните на ++"OK"++.

![](images/arrow.png) Выбранное устройство автоматически отображается в поле **Цель устройства**. Выводы выбранного устройства отобразятся в столбце **Вывод устройства**.
5. Выделите в левой и правой областях диалогового окна равное количество выводов устройства.

![](images/arrow.png) Если выделено неравное число выводов устройства, тогда все соединения создаются для меньшего количества. Если было выделено больше выводов устройства, чем имеется кабельных соединений, соединяются те выводы устройства, для которых доступны кабельные соединения.
6. Чтобы использовать для соединения имеющийся кабель, щелкните рядом с полем **ОУ кабеля** на ++"..."++, выберите в выведенном диалоговом окне кабель и щелкните по кнопке ++"OK"++.
7. Чтобы сгенерировать новый кабель для соединения, щелкните рядом с полем **Тип кабеля** на ++"..."++, выберите в выведенном диалоговом окне подходящее изделие для типа кабеля и щелкните по кнопке ++"OK"++.
8. Введите в поле **Тип кабеля** ОУ для кабеля.
9. Чтобы после генерации соединения открыть кабель непосредственно в диалоговом окне **Обработать кабель**, установите флажок **Обработать кабель**.
10. Нажмите на ++"Генерировать соединения"++.

![](images/arrow.png) Выполняется генерация соединений.

![](images/arrow.png) Кабель автоматически отобразится в диалоговом окне **Обработать кабель**.

![](images/arrow.png) После того как вы создали кабель, новый кабель отобразится в навигаторе кабелей (вкладка **Соединения** > группа команд **Кабели** > **Навигатор**).
