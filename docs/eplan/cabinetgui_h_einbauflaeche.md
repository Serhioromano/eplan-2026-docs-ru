# Определить и изменить поверхность установки

Для корректного размещения на других трехмерных объектах 3D-макросам требуются сведения о том, с использованием какой поверхности они размещаются и в каком направлении они должны быть при необходимости повернуты. Эти сведения сохраняются в 3D-макросах через определение поверхности установки. Расположение поверхности установки определяет и глубину установки, с которой трехмерный объект будет расположен на монтажной поверхности. На поверхности установки автоматически генерируется девять точек захвата, которые могут быть использованы при размещении. Также с помощью команды **Точка захвата** можно определить другую точку захвата (командный путь: вкладка **Вставить** > группа команд **Инструмент для монтажных работ** > **Точка захвата**). Указанная точка захвата при размещении всегда проецируется на поверхность установки.

!!! note "Замечание:"

    Используйте функции для создания и изменения поверхностей установки только для электрошкафов собственного производства, которые вы импортировали в качестве пространства конструкции, или для макросов одного проекта макросов. Электрошкафы, которые вы скачиваете через Data Portal, уже имеют поверхности установки, изменять которые вы не имеете права. В противном случае электрошкафы перестанут быть совместимыми с предусмотренными принадлежностями, а также затруднится конфигурирование электрошкафов.

Условия:

* Вы открыли проект схемы соединений или проект макросов.
* Открыты навигатор пространства листа и пространство листа.
* Пространство листа содержит импортированные трехмерные тела, которые необходимо сохранить в виде макроса.

###

## Определить поверхность установки

1. Выберите следующие команды: Вкладка **Вставить** > группа команд **Поверхность установки** > **Определить**.
2. Переместите курсор в область трехмерного тела.

![](images/arrow.png) Расположенная под курсором поверхность будет автоматически выделена цветом.
3. После выявления требуемой поверхности щелкните по ней мышью.

![](images/arrow.png) Выбранная поверхность будет определена как поверхность установки. Это приведет к отображению прозрачной поверхности, выходящей за пределы выделенной области. В угловых и средних точках граничных ребер генерируются точки захвата.

!!! note "Замечание:"

    Поверхность, которую необходимо определить как поверхность установки, должна быть ограничена точками, лежащими геометрически в одном слое. В зависимости от качества импортированных трехмерных данных могут появляться поверхности, которые не соответствуют данному условию. Такие поверхности нельзя определить как поверхности установки.

!!! example "Пример:"

    На рисунке изображен 3D-макрос с поверхностью установки под цокольной плитой. Точки захвата расположены в углах и в средних точках ребер.

###

## Перевернуть поверхность установки

Команда **Перевернуть** переворачивает поверхность установки в горизонтальном направлении на 180°.

1. Выберите следующие команды: Вкладка **Вставить** > группа команд **Поверхность установки** > ![](images/ribbon_placementarea_turnaround_as.png) **Перевернуть**.

![](images/arrow.png) Поверхность установки и трехмерное тело вращаются на 180°.

!!! example "Пример:"

    3D-макрос с перевернутой поверхностью установки

###

## Переместить поверхность установки

Команда **Переместить** изменяет положение поверхности установки параллельно оси Z. Таким образом можно изменить глубину установки 3D-макроса.

1. Выберите следующие команды: Вкладка **Вставить** > группа команд **Поверхность установки** > ![](images/ribbon_placementarea_move_as.png) **Переместить**.
2. Введите значение перемещения.

![](images/arrow.png) При вводе положительного числа или числа без предшествующего знака поверхность установки перемещается вверх.

![](images/arrow.png) При вводе отрицательного числа с предшествующим знаком ' `–`' поверхность установки перемещается вниз.

!!! example "Пример:"

    На рисунке изображен 3D-макрос с поверхностью установки, передвинутой на 100 мм.

###

## Поворот поверхности установки

Команда **Поворачивать** поворачивает поверхность установки вокруг центра в вертикальном направлении. Таким образом можно добиться повернутого размещения 3D-макроса.

1. Выберите следующие команды: Вкладка **Вставить** > группа команд **Поверхность установки** > ![](images/ribbon_placementarea_rotate_as.png) **Поворачивать**.
2. Введите угол отверстия.

![](images/arrow.png) При вводе положительного числа или числа без предшествующего знака трехмерное тело на поверхности установки будет повернуто в направлении против часовой стрелки.

![](images/arrow.png) При вводе отрицательного числа с предшествующим знаком ' `-`' трехмерное тело на поверхности установки будет повернуто в направлении по часовой стрелке.

!!! example "Пример:"

    На рисунке изображен 3D-макрос с поверхностью установки, повернутой на -15°. Точки захвата на нижней поверхности остаются без изменений.
