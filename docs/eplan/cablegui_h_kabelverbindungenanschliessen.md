## Подключить кабельные соединения

Если один кабель соединяет два клеммника друг с другом и спроектированы не все кабельные соединения, у вас есть возможность автоматически сгенерировать и подключить отсутствующие кабельные соединения. Резервные клеммы, необходимые для прокладывания этих соединений, также генерируются автоматически. Для этого служит команда Подключить кабельные соединения. Для выполнения команды должно быть выделено одно или несколько определений кабеля или экранирований (как главных функций).

Условия:

  * Кабели уже подключены к двум клеммам, т. е. полностью подключено как минимум одно кабельное соединение.
  * Кабелям присвоено одно изделие.


  1. В навигаторе кабелей выберите нужные определения кабеля и / или экранирования или вышестоящий уровень иерархии. Или выделите нужные определения кабеля и/или экранирования в графическом редакторе. Вы также можете выделить страницы проекта в навигаторе страниц.
  2. Выберите следующие команды: Вкладка Соединения > группа команд Кабели > раскрывающаяся кнопка Обработать > Подключить кабельные соединения.  
  
Для каждого непроложенного кабельного соединения определенного кабеля в клеммниках генерируются резервные клеммы (т. е. неразмещенные клеммы).  
  
Неразмещенные соединения между клеммами автоматически генерируются из шаблонов функций изделия кабеля. ОУ сгенерированных клемм вводятся в свойствах Источник и Цель этих соединений.  
  
После успешного выполнения операции отобразится соответствующее сообщение. Здесь будет информация об общем количестве сгенерированных кабельных соединений и клемм.



При генерировании запасных клемм учитывается потенциал кабельных соединений. По умолчанию клеммы генерируются с определением функции "Клемма с мостовой перемычкой, 2 вывода устройства". Клеммы PE генерируются для кабельных соединений с типом потенциала "PE", а клеммы SH — для кабельных соединений с типом потенциала "SH" и т. д. Клеммы сортируются и нумеруются в конце клеммника (как при генерировании отдельных новых клемм в навигаторе клеммников).

Снаружи ли или внутри подключаются автоматически сгенерированные клеммы определенного клеммника, зависит от логической схемы выводов устройства первой графически размещенной клеммы данного клеммника. Если для подключения клемм задано значение "Внешнее", все новые клеммы подключаются снаружи; если задано значение "Внутреннее", все новые клеммы подключаются изнутри.
