# Операция: XCCreateGravingtextAction

**Параметр** |  **Описание**
---|---
Complete |  Сохранять одноименные места установки (необязательно, 0 = нет, 1 = да). Операция XCCreateGravingtextAction генерирует текст гравировки на основе ОУ источника и цели кабеля. Без указания параметра или при указании параметра /Complete:0 обозначение сокращается согласно стандарту VASS (Volkswagen Audi Seat Skoda), т. е. одноименные структурные идентификаторы источника и цели удаляются, начиная слева. При указании параметра /Complete:1 одноименные места установки сохраняются для источника и цели.

!!! example "Пример:"

    XCCreateGravingtextAction
/Complete:1
