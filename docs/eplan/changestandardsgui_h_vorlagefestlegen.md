## Задать базовый проект и поворот / инверсию (изменение стандарта)

Используя базовый проект, обозначения и названия, можно настроить под целевой стандарт. Настройка поворота / инверсии в сочетании с выбранными библиотеками символов задает расположение элементов схемы соединений на схеме.

Условия:

* Вы открыли проект.
* При нескольких открытых проектах: В навигаторе страниц выделен проект.
* У вас есть базовый проект, содержащий специфические для страны или стандарта настройки.
* Вы настроили целевой проект.

1. Выберите следующие команды: Вкладка Инструменты > группа команд Стандарты > Заменить.
2. Откройте на вкладке Поворот / инверсия в поле Базовый проект при помощи  диалоговое окно выбора файла, и выберите там нужный базовый проект *.zw9 или нужный сохраненный проект Eplan *.zw1.
3. Из раскрывающегося списка Поворот / инверсия выберите способ вращения и инверсии.
4. Щелкните по [Далее].
