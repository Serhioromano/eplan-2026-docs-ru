## Диалоговое окно Настройки: Конфигуратор шлангопроводов

* Файл > Настройки > Пользователь > Add-ons > Конфигуратор шлангопроводов
* Вы открыли проект. Вы открыли диалоговое окно [Конфигурировать шлангопроводы](eplan/fluidhoseconfiggui_d_schlauchleitungen.md). Выберите пункты меню Дополнительно > Настройки.

В этом диалоговом окне задаются свойства и значения для конфигурации шлангопроводов, которые затем сохраняются как схема. Сохраненная здесь информация предлагается вам на выбор при конфигурировании шлангопроводов в диалоговом окне Обработать <...>.

!!! note "Замечание:"

    

 

Обзор основных элементов диалогового окна:

Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать или обработать. Для этого также воспользуйтесь соседней [панелью инструментов](eplan/schemeconfig_m_schemaschaltflaechen.md).

Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](eplan/userinterface_m_kontextmenu.md).
