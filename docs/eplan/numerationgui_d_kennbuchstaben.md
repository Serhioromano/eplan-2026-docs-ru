# Диалоговое окно Буквенные обозначения

## Вызов диалогового окна:

Вы открыли проект. **Файл** > **Настройки** > **Проекты** > "Имя проекта" > **Устройства** > **Нумерация (online)**. Нажмите рядом с полем **Буквенные обозначения** на кнопку ++"..."++.

В этом диалоговом окне вы можете определять собственные наборы буквенных обозначений. Набор буквенных обозначений представляет собой присвоение буквенных обозначений и функций. Каждый набор буквенных обозначений сохраняется в отдельной схеме как специфический для проекта. Прилагаются схемы для некоторых наиболее часто используемых стандартов.

Обзор основных элементов диалогового окна:

### Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать или обработать. Для этого также воспользуйтесь соседней [панелью инструментов](schemeconfig_m_schemaschaltflaechen.md).

### Пoиск:

Введите в это поле текст, по которому должны фильтроваться определения функций. При этом поиск этого текста будет выполняться в столбцах **Раздел**, **Категория**, **Группа** и **Определение функции**.

Если необходимо вернуться к прежнему виду определения функций, удалите текст из поля ввода. Для этого нажмите кнопку ![](images/all_delete_input_as.png){ .ui-icon } (Удалить).

### Таблица:

В таблице приводятся определения функций и присвоенные им буквенные обозначения. Редактировать можно только данные в столбце **Буквенное обозначение**. Набор устаревших буквенных обозначений "IEC" невозможно изменить.

* Раздел: Здесь выводится раздел определения функции.
* Категория: Здесь выводится категория определения функции.
* Группа: Здесь выводится группа определения функции.
* Определение функции: Здесь выводится определение функции.
* Буквенное обозначение: В отдельных ячейках укажите буквенные обозначения отдельных функций, разделяя буквенные обозначения посредством точки с запятой. При вставке функционального элемента в качестве настройки по умолчанию используется первое введенное буквенное обозначение.

### Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).
