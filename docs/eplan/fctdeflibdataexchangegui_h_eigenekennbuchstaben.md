# Создать собственные наборы буквенных обозначений

В Eplan вы можете создавать собственные наборы буквенных обозначений и, тем самым, учитывать разные стандарты, страны и клиентов. Рекомендуем создавать и поддерживать наборы буквенных обозначений в базовом проекте.

Условие:

Вы открыли проект.

1. Выберите следующие команды: Файл > Настройки > Проекты > "Имя проекта" > Устройства > Нумерация (online). Нажмите рядом с полем Буквенные обозначения на кнопку ++...++.
2. В диалоговом окне Буквенные обозначения рядом с полем Схема щелкните по ![](images/all_new_as.png) (Создать).
3. В диалоговом окне Новая схема в поле Имя введите информативное имя для новой схемы и щелкните по ++OK++.

4. В столбце Буквенное обозначение в отдельных ячейках введите буквенные обозначения для отдельных функций. Буквенные обозначения могут также состоять из нескольких символов.
5. Щелкните по кнопке ++OK++.

!!! info "Для сведения:"

    Выполняется сохранение введенных буквенных обозначений.

### Выбрать наборы буквенных обозначений

Условие:

Вы открыли проект.

1. Выберите следующие команды: Файл > Настройки > Проекты > "Имя проекта" > Устройства > Нумерация (online).
2. Выберите в поле Буквенные обозначения нужный набор буквенных обозначений из раскрывающегося списка.
3. В поле Подклассы буквенных обозначений выберите необходимый подкласс из раскрывающегося списка.
4. Либо щелкните по кнопке ++...++ в поле Подклассы буквенных обозначений и в диалоговом окне Подклассы буквенных обозначений создайте новый класс.
5. Щелкните по кнопке ++OK++.

!!! info "Для сведения:"

    При создании функции используется соответствующее буквенное обозначение/соответствующий подкласс.
