## Диалоговое окно Копировать гиперссылку

[Вызов диалогового окна:](javascript:void\(0\);)

Вы открыли проект. В Графическом редакторе открыта страница проекта.. Вкладка Вставить > группа команд Внешн. > раскрывающаяся кнопка QR-код > Гиперссылка. В диалоговом окне Свойства на вкладке Гиперссылка укажите документ, который нужно связать, и нажмите [OK].

В этом диалоговом окне вы указываете, копируется ли документ в каталог проекта или на него предоставляется ссылка из исходного каталога.

Обзор основных элементов диалогового окна:

Исходный каталог не изменять:

В проект вставляется ссылка на документ, и документ отображается из исходного каталога. Изменения в документе будут автоматически обновляться, как только вы откроете страницу. При резервном копировании данных документы, находящиеся во внешних каталогах и на которые имеются ссылки, могут быть учтены с помощью настройки.

Копировать:

Документ копируется в каталог проекта (то есть в подкаталог DOC проекта), а копируемый документ отображается из каталога проекта. Документ хранится не непосредственно в подкаталоге DOC, а в другом отдельном подкаталоге. Имя этого подкаталога вычисляется на основе имен исходных каталогов.   
Все файлы в подкаталогах проекта также учитываются при резервировании данных.

Перезаписать с запросом:

Установите этот флажок, чтобы параметр Копировать отображал запрос, если документ уже существует в каталоге проекта. Затем вы можете решить, будет ли он перезаписан или нет.
