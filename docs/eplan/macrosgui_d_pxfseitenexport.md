## Диалоговое окно Внешняя обработка

Вызов диалогового окна (для данных проекта):

Вы открыли проект. Вы выделили экспортируемые данные в проекте. Файл > Экспортировать > группа команд Данные проекта > Данные проекта > группа команд Внешняя обработка > Свойства.

Вызов диалогового окна (для данных изделия):

Вкладка Основные данные > группа команд Изделия > Управление. В диалогом окне База данных изделий через меню [Дополнительно] > Настройки была открыта база данных изделий.

* Кнопка [Дополнительно] > Внешняя обработка свойств > Экспортировать данные.
* В дереве или списке выделены экспортируемые данные. Выберите пункт всплывающего меню Экспортировать данные.

В этом диалоговом окне можно указать, как и куда должны быть экспортированы выбранные данные. Вывод зависит от типа объекта, который был задан при создании схемы и после этого уже не подлежит изменению.

В зависимости от того, откуда вызывается экспорт, возможны различные типы объектов. В базе данных изделий доступны такие типы объектов, как изделия, адреса, схемы сверления и т. д.; в виде Backstage при экспорте данных проекта доступны такие типы объектов, как устройства, кабели, функциональные тексты зоны и т. д. Соответственно, во время экспорта вам будут предложены на выбор только схемы с релевантными типами объектов.

Обзор основных элементов диалогового окна:

Настройки:

В этом раскрывающемся списке отображаются все пользовательские и предварительно определенные схемы для внешней обработки. Для обработки или создания схемы нажмите кнопку [...].

Тип объекта:

Схема для внешней обработки всегда создается для определенного типа объекта. В этом поле отображается тип объекта, выбранный при создании текущей схемы. Тип объекта затем уже нельзя изменить!

Язык:

Выберите из раскрывающегося списка, на каком языке должен выполняться экспорт:

* Все языки проекта / Все языки: При этой настройке многоязычные данные выводятся в зависимости от количества языков, настроенных для проекта / для базы данных изделий. При импорте заменяются только импортированные языки, другие имеющиеся языки не изменяются. В этом случае затем требуется запустить соответствующий прогон перевода.
* Один язык (например, "en_US (английский (США))").

Целевой файл:

Введите в это поле имя целевого файла, включая путь к нему, или нажмите на кнопку , чтобы выбрать каталог и имя файла в интерактивном режиме.

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

!!! note "Замечание:"

    Обратите внимание на то, что при экспортестраницпеременные путидля "Полный каталог проекта" и "Имя проекта" пусты, поэтому их можно постоянно изменять в зависимости от выбранного целевого файла.

Вид вывода:

Выберите в этом групповом поле одну из доступных опций вывода:

* Экспортировать: Выберите эту опцию, если соответствующие данные требуется только экспортировать, например, чтобы обработать их на другом рабочем месте.
* Экспортировать и запустить приложение: Выберите эту опцию, если после экспорта следует сразу запустить соответствующее приложение для внешней обработки, например, если данные необходимо обработать на другом рабочем месте. Однако перед этим требуется просмотреть их и при необходимости переработать.
* Обработать во внешнем приложении и считать обратно: Выберите этот параметр, чтобы обработать данные во внешнем приложении и после закрытия этого приложения иметь их сразу в своем проекте / своей базе данных изделий.

Применить ко всей базе данных изделий:

Доступно только при вызове из базы данных изделий через пункт всплывающего меню Экспортировать данные. Установите этот флажок, если текущий выбор нужно распространить на все записи данных текущего типа объекта. При выделении одного или нескольких изделий экспортируются все изделия базы данных изделий. При выделении одного или нескольких списков принадлежностей при подходящем типе объекта экспортируются все списки принадлежностей базы данных изделий.
