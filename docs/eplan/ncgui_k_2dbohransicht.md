## 2D-отображение отверстий: принцип

Двухмерные отображения отверстий показывают данные, релевантные для ЧУ и отверстий, схемы сверления, а также геометрические контуры базисных функциональных элементов и изделий в виде модели. Двухмерные отображения отверстий являются документами, ориентированными на проект, которые постоянно находятся в распоряжении в ходе обработке проекта в Eplan. Вы можете воспользоваться отображениями отверстий, чтобы перед началом производства синхронизировать выданные данные изготовления (например, сгенерированные с помощью следующих команд: Файл > Экспортировать > группа команд Данные изготовления > Механическая обработка > Шаблон сверления) с фактическим состоянием обработки в проекте Eplan.

Функциональные элементы и отверстия в отображениях отверстий можно снабдить указаниями размеров.

Если размещения изделия были изменены в проекте, 2D-отображения отверстий можно в любое время отобразить с помощью следующих команд: вкладка Инструменты > группа команд Отчеты > Обновить.



!!! example "Пример:"

    Изображенное двухмерное отображение отверстия показывает монтажную плату с несущими шинами и кабельными каналами, отверстия этих функциональных элементов и масштабирование.
