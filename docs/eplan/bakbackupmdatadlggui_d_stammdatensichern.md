## Диалоговое окно "Резервировать основные данные"

Файл > Дополнительно > группа команд Организовать > Основные данные > группа команд Резервировать > Резервировать основные данные

В этом диалоговом окне задается способ и место резервирования выбранных основных данных.

Посредством диалогового окна можно резервировать следующие основные данные:

* Данные изделий
* Базовые проекты
* Формы
* Контуры
* Рамки
* Макросы
* Настройки вне зависимости от проекта.
* Библиотеки символов
* Словари

!!! note "Замечание:"

    Графика рамок или форм резервируется только в том случае, если она загружена в рамке или форме. Графика со ссылками не может быть резервирована и восстановлена.

Обзор основных элементов диалогового окна:

Тип основных данных:

Выберите здесь тип основных данных, который вы хотите резервировать.

Каталог:

Выберите каталог, в котором находятся основные данные для резервирования. Каталог основных данных по умолчанию предварительно установлен (как задано по командному пути Файл > Настройки > Пользователь > Управление > Каталоги). При помощи  можно открыть диалоговое окно для выбора каталога и перейти в нем к нужному каталогу.

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

Основные данные: <Тип основных данных>:

В этой таблице перечислены основные данные, расположенные в выбранном каталоге. Для сортировки основных данных по возрастанию, по убыванию или в первоначальной последовательности щелкните по заголовку столбца. Выделите основные данные для резервирования.

Резервировать подкаталоги:

Если этот флажок установлен, в процесс резервирования будут включаться и основные данные подкаталогов.

Имя файла:

Укажите имя файла, в который будут резервироваться выбранные основные данные. Нажав , откройте диалоговое окно Выбор файла резервирования и перейдите к требуемому каталогу или создайте новый.

Описание:

В этом поле можно ввести информативный текст (напр., указание места хранения), который сохраняется вместе с основными данными и отображается в Eplan при резервировании и восстановлении.

Целевой каталог:

Укажите здесь место хранения. В качестве целевых для резервирования данных можно указать любой дисковод и подкаталог. Нажав , откройте диалоговое окно для выбора каталога и перейдите к требуемому каталогу или создайте новый.

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.
