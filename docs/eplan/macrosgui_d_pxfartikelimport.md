# Диалоговое окно Внешняя обработка: импортировать данные изделий

## Вызов диалогового окна:

Вкладка **Основные данные** > группа команд **Изделия** > **Управление**. В диалогом окне **Управление изделиями** через меню ++"Дополнительно"++ > **Настройки** была открыта база данных изделий. Кнопка ++"Дополнительно"++ > **Внешняя обработка свойств** > **Импортировать данные**.

В этом диалоговом окне задаются настройки импорта для данных базы данных изделий, которые после экспорта были подвергнуты внешней обработке. Диалоговое окно не открывается, если при экспорте был выбран параметр **Обработать во внешнем приложении и считать обратно**.

Обзор основных элементов диалогового окна:

### Имя файла:

Введите в это поле имя файла импорта или нажмите на ![](images/all_selectfile_as.png){: .ui-icon }, чтобы выполнить интерактивный выбор.

### Идентификация записей данных:

* Идентификация с помощью ид. объекта: При выборе этого параметра данные идентифицируются по идентификатору объекта базы данных изделий (как обычно при импорте).
* Идентификация с помощью имени: При выборе этого параметра данные идентифицируются по их имени. Изделия идентифицируются, например, по номеру изделия и обозначению варианта, а записи данных для адресов (клиента, производителя / поставщика) — по их краткому имени.
С помощью такой идентификации вы можете импортировать в собственную базу данных изделий данные изделий, созданные в сторонних системах.

### Импорт:

С помощью параметров в этом групповом поле задаются следующие настройки обработки при импорте:

* Добавлять только новые записи данных: Существующие записи данных не изменяются, а добавляются только новые.
* Заменить только имеющиеся записи данных: Существующие записи данных будут полностью заменены записями данных из файла импорта. Новые записи данных будут игнорироваться.
* Заменить имеющиеся записи данных и добавить новые: Существующие записи данных будут полностью заменены записями данных из файла импорта. Новые записи данных будут добавляться.
