# Диалоговое окно Настройки: Символьная схема (Изменение стандарта)

## Вызов диалогового окна:

**Файл** > **Настройки** > **Пользователь** > **Изменение стандарта** > **Символьная схема**.

В этом диалоговом окне перечислены все относящиеся к пользователю установленные ранее схемы присвоения исходных символов библиотеки символов целевым символам библиотеки символов. Не нужные больше схемы присвоения можно удалить. Если при изменении стандарта используется схема присвоения, символы исходной библиотеки символов заменяются на символы целевой библиотеки символов.

Обзор основных элементов диалогового окна:

### Панель инструментов:

Кнопка |  Значение
---|---
![](images/all_delete_as.png){ .ui-icon } (Удалить) |  Удаляет выделенные строки. Удаленное присвоение более недоступно ни в одном из проектов.

### Присвоить символы:

Каждая строка содержит присвоение символов исходной библиотеки символов символам целевой библиотеки символов.

* Библиотека символов, источник: отображает имя файла библиотеки символов исходного проекта без расширения имени файла.
* Библиотека символов, цель: отображает имя файла библиотеки символов целевого проекта без расширения имени файла.
* Схема: в этом раскрывающемся списке отображаются все заданные на данный момент схемы присвоения символов. Выбранные здесь схемы сохраняются в проекте.
* Статус: если в столбце **Схема** выбрана какая-либо схема, проверяется присвоение символов. В данном столбце отображается статус проверки. Статус "OK", когда определения функций символов соответствуют друг другу, а число выводов устройств исходных символов меньше или равно числу выводов устройства целевых символов.

### Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).
