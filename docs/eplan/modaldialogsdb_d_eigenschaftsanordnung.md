# Диалоговое окно Конфигурировать свойства

Вы открыли проект. Вы открыли диалоговое окно, в котором можно назначить свойства объекту (например, проекту, странице, форме и т. д.) с помощью таблицы. Выберите пункт всплывающего меню Конфигурировать.

Выберите в этом диалоговом окне те свойства и их последовательность, которые стандартно выводятся в таблице для каждого объекта соответствующей категории функции.

Открыто управление изделиями. Через меню ++Дополнительно++ > Настройки была открыта база данных изделий. В дереве вы выделили список принадлежностей, размещение принадлежностей и т. п. Выбрана вкладка Свойства. Рядом с раскрывающимся списком нажмите на кнопку ++...++.

В этом диалоговом окне вы выбираете свойства и их последовательность, которые должны отображаться на вкладке Свойства в разделе управления изделиями для таких типов записи данных, как список принадлежностей, схема сверления и т. п.

При этом свойства сохраняются в виде схем, поэтому их можно повторно использовать в любое время.

Обзор основных элементов диалогового окна:

!!! note "Замечание:"

    Поля Схема и Описание доступны только в разделе управления изделиями при конфигурации вкладки Свойства для таких типов записи данных, как список принадлежностей, схема сверления и т. п.

### Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать или обработать. Для этого также воспользуйтесь соседней [панелью инструментов](schemeconfig_m_schemaschaltflaechen.md).

### Список / конфигурация:

В этом поле укажите, какие свойства следует отображать. С помощью кнопки ![](images/all_new_as.png) (Создать) можно выбирать другие свойства и вставить их в список. С помощью кнопок со стрелками можно изменять последовательность свойств.

### Всплывающее меню:

Пункт меню |  Значение
---|---
Выделить все |  Выделяет все записи в списке.
