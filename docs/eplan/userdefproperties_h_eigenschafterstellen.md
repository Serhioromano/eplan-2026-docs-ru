## Создать определенные пользователем свойства

Условия:

Определенные пользователем свойства для проекта:

* Вы открыли проект.
* Вы выбрали следующие команды: вкладка Инструменты > группа команд Управление > Свойства.

Определенные пользователем свойства в базе данных изделий:

* Вы открыли базу данных изделий. Вкладка Основные данные > группа команд Изделия > Управление.
* Вы выбрали пункты меню [Дополнительно] > Конфигурировать свойства.

1. Щелкните в диалоговом окне Конфигурировать свойства по кнопке  (Создать).
2. В диалоговом окне [Новое свойство](eplan/eservicesgui_d_konfigeigenschaften.md#Name) введите уникальное идентифицирующее имя.   
  
Идентифицирующее имя затем уже нельзя изменить.
3. На вкладке Общее в поле Отображаемое имя введите имя, под которым свойство должно отображаться в проекте / управлении изделиями. Возможен многоязычный ввод.
4. В поле Описание при необходимости введите описательный текст, который затем будет отображаться в диалоговых окнах выбора свойств для данного свойства.
5. В поле Присвоение установите, для каких объектов должно быть доступно свойство.  
  
Для конфигурации в базе данных изделий в качестве присвоения доступна только запись "Изделие". Эта запись отсутствует при конфигурации для проекта.
6. Установите флажок Также активировать для ссылок изделий, если определенное пользователем свойство для изделия также должно быть доступно как свойство для ссылок изделий.
7. С помощью раскрывающегося списка Тип поля задайте символы и формат, разрешенные для определенного пользователем свойства. Выберите запись "Многоязычный текст", если значения свойств впоследствии нужно перевести.
8. Если вы указали тип поля "Значение с единицей измерения", выберите нужную группу единиц измерения из раскрывающегося списка Группа единиц измерения.  
  
Если ввести значение без единицы измерения, то для него будет использоваться соответствующая стандартная единица СИ, например, при пересчете.
9. Установите флажок Перевести значение свойства, если значение определенного пользователем многоязычного свойства необходимо учитывать при автоматическом переводе проекта или при автоматическом переводе в базе данных изделий.
10. На вкладке Представление в поле Тип отображения укажите, возможен ли свободный ввод для свойства или необходимо выбирать значения из списка выбора.
11. В поле Категория выберите категорию, в которой должно отображаться данное свойство.
12. Если в поле Отображаемый тип вы выбрали один из параметров "Список выбора", "Свободный ввод со списком вариантов выбора" или "Саморасширяющийся список выбора", определите в поле Список выбора значений по умолчанию возможные записи в раскрывающемся списке.
13. Щелкните по кнопке [OK].  
  
Новое определенное пользователем свойство для проекта сохраняется как специфическое для проекта и доступно в нем на существующем объекте в соответствии с заданным присвоением.  
  
Новое определенное пользователем свойство для изделия сохраняется в базе данных изделий и может присваиваться изделию с помощью вкладки Определенные пользователем свойства.
