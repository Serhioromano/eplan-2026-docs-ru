# Атрибуты сценария

Атрибутами в сценарии обозначаются выполняемые функции. В сценариях могут использоваться следующие атрибуты:

Атрибут |  Описание
---|---
Пуск |  Используется для обозначения выполняемой функции в сценарии. Когда выполняется сценарий, вызывается именно эта функция. Функция может также иметь параметры.
DeclareAction |  Используется для обозначения выполняемой функции в сценарии, если функция данного сценария в системе должна подключаться как операция.
DeclareEventHandler |  Если функция в сценарии должна реагировать на события в системе, ее необходимо обозначить данным атрибутом.
DeclareMenu |  Используется для обозначения выполняемой функции в сценарии, если какую-либо функцию данного сценария в системе необходимо добавить в качестве пункта всплывающего меню.
DeclareRegister |  Данная функция вызывается при добавлении в Eplan нового файла сценария.
DeclareUnregister |  Данная функция вызывается перед удалением из Eplan нового файла сценария.
