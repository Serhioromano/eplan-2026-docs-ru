# Диалоговое окно Обзор свойств — <Имя проекта>

## Вызов диалогового окна:

Вы открыли проект. Вкладка **Главная** > группа команд **Обработать** > **Обзор свойств**.

В этом диалоговом окне можно обрабатывать свойства одного или нескольких выделенных объектов (тексты, графические элементы, функции, сегменты).

Чтобы отобразить требуемые свойства для выделенных объектов, необходимо выбрать или создать подходящую схему для конфигурации свойств. В комплектной схеме "Стандарт" мы предоставляем вам схему с конфигурациями свойств для всех важных объектов.

Обзор основных элементов диалогового окна:

### Панель инструментов:

Вы можете настроить отображение свойств с помощью следующих кнопок:

Кнопка |  Значение
---|---
![](images/all_treeview_as.png){ .ui-icon } (представление в виде дерева) |  Отображает свойства в виде дерева.
![](images/all_listview_as.png){ .ui-icon } (представление в виде списка) |  Отображает свойства, расположенные друг под другом, в виде списка.
![](images/all_allproperties_as.png){ .ui-icon } (Все свойства) |  Отображает все свойства.
![](images/all_filledproperties_as.png){ .ui-icon } (Заполненные свойства) |  Отображает только те свойства, для которых существует значение.
![](images/all_fromscheme_as.png){ .ui-icon } (Из схемы) |  Отображает настроенные свойства из схемы.

Если активирована кнопка ![](images/all_fromscheme_as.png){ .ui-icon } (Из схемы), вы можете выбрать из раскрывающегося списка схему для отображения и обработки свойств. Откройте с помощью кнопки ++"..."++ диалоговое окно **Конфигурировать свойства**. Здесь с помощью схемы с несколькими конфигурациями свойств вы можете указать, какие свойства должны отображаться в обзоре свойств и в какой последовательности.

Если активирована кнопка ![](images/all_allproperties_as.png){ .ui-icon } (Все свойства), ![](images/all_filledproperties_as.png){ .ui-icon } (Заполненные свойства) или ![](images/all_fromscheme_as.png){ .ui-icon } (Из схемы), вы можете перейти в представление в виде дерева или списка с помощью кнопок ![](images/all_treeview_as.png){ .ui-icon } (Представление в виде дерева) и ![](images/all_listview_as.png){ .ui-icon } (Представление в виде списка).

В соответствующем представлении в виде дерева выбранные исходные объекты (функция, текст, условное обозначение и т. д.) отображаются в виде уровня иерархии.

### Пoиск:

Введите в это поле текст, по которому должна выполняться фильтрация свойств. При этом выполняется поиск имен отображаемых свойств и их значений.

Если необходимо вернуться к прежнему виду свойств, удалите текст из поля ввода. Для этого нажмите кнопку ![](images/all_delete_input_as.png){ .ui-icon } (Удалить).

### Свойство / Значение:

Отображает для выделенного или выделенных объектов значения определенных свойств. От выбранной схемы зависит, какие значения здесь можно обработать.

Значения некоторых свойств, которые содержат значение, отличающееся от указанного в изделии, в логической модели или в шаблоне сегмента, отображаются с желтым фоном ячеек. Это относится к свойствам ссылки изделия, свойствам логической схемы выводов устройства или свойствам предварительного планирования.

В Информационной области под таблицей свойств отображается дополнительная информация. Для свойства, выбранного в таблице **Свойство / Значение**, это, например, идентификатор, обозначение и описание свойства.

### [Загрузить все объекты]:

Если в графическом редакторе, навигаторе и т. п. выбрано более 100 объектов, то в информационной области выводится текст, сообщающий о том, что отображаются не все объекты. Нажмите эту кнопку, чтобы загрузить все объекты и отобразить их в обзоре свойств. Эта операция может продлиться некоторое время.

### Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).
