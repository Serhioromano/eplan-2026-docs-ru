# Произвести настройки для внешней обработки

При экспорте для внешней обработки подготовленные схемы имеются не для каждого типа объекта. Если нужно экспортировать данные такого объекта, рекомендуется сперва установить схему с соответствующими настройками.

Условия:

Экспорт данных проекта для внешней обработки:

* Вы выбрали следующие команды: **Файл** > **Настройки** > **Пользователь** > **Интерфейсы** > **Внешняя обработка**.

Экспорт данных изделий для внешней обработки:

* Вы открыли диалоговое окно **База данных изделий** (вкладка **Основные данные** > группа команд **Изделия** > **Управление**).
* Вы выбрали в диалоговом окне **База данных изделий** под кнопкой ++"Дополнительно"++ пункты меню **Внешняя обработка свойств** > **Экспортировать данные**.
* Вы нажали в диалоговом окне **Внешняя обработка** рядом с полем **Настройки** кнопку ++"..."++.

1. Выберите в диалоговом окне **Настройки: Внешняя обработка** из раскрывающегося списка **Схема** ту схему, настройки которой нужно отредактировать, или нажмите кнопку ![](images/all_new_as.png) (Новая), чтобы выбрать в последующем диалоговом окне тип объекта для новой определенной пользователем схемы.
2. Из раскрывающегося списка **Тип файла** выберите тип файла, который будет сгенерирован при экспорте.
3. Нажмите кнопку ++"Параметры"++, чтобы задать настройки экспорта для выбранного типа файла, и щелкните ++"OK"++.
4. В поле **Целевой файл** укажите дисковод, каталог и имя генерируемого целевого файла или нажмите кнопку ![](images/all_selectfile_as.png), чтобы выбрать дисковод и каталог в интерактивном режиме.
5. Если вы выбрали для типа файла запись для файла Excel, введите в поле **Шаблон** путь и имя файла шаблона или выберите шаблон с помощью кнопки ![](images/all_selectfile_as.png). Этот шаблон затем будет определять формат данных при экспорте.
6. Выберите вкладку **Данные**.
7. Выберите из списка **Доступные элементы формата** / **Исходный объект** объект, который необходимо учитывать при экспорте. Многократный выбор невозможен.
8. С помощью кнопки ![](images/all_arrowright_as.png) (Переместить направо) переместите объект в список **Выбранные элементы формата**. После выбора исходного объекта в базе данных изделий откроется диалоговое окно **Выбор свойств**, позволяющее выбрать экспортируемые свойства для выбранного исходного объекта. Возможен многократный выбор.
9. Выполните аналогичные действия для всех остальных элементов формата, которые необходимо учитывать при экспорте.
10. Определите последовательность выбранных элементов формата / исходных объектов, используя кнопки панели инструментов.
11. Щелкните по кнопке ++"OK"++.

![](images/arrow.png) Выполненные настройки будут сохранены в выбранной схеме.
