# Настройка навигационного куба

Для навигационного куба, отображаемого в пространстве листа, имеются различные специфические для пользователя настройки. С помощью этих настроек можно отобразить и скрыть навигационный куб, выбрать основное представление точки наблюдения, задать размеры навигационного куба, а также включить и отключить анимацию поворота вида при изменении точки наблюдения в пространстве листа:

1. Выберите следующие команды: **Файл** > **Настройки** > **Пользователь** > **Графическая обработка** > **3D-навигационный куб**.
2. В диалоговом окне **Настройки: 3D-навигационный куб** установите или снимите флажок **Навигационный куб виден**, чтобы показать или скрыть навигационный куб в пространстве листа.
3. В раскрывающемся списке **Основное представление навигационного куба** задайте точку наблюдения для 3D-объекта в пространстве листа, которая должна использоваться при нажатии на кнопку ![](images/cabinetgui_navigationcubehome_as.png){ .ui-icon }. У вас есть возможность в качестве основного представления выбрать предпочтительную точку наблюдения из шести точек наблюдения в ортогональном и четырех в изометрическом виде.

!!! note "Замечание:"

    Основное представление также можно определить с помощью комбинации клавиш ++"Ctrl"++ + ++"Alt"++ + ++"5"++. Для этой цели также можно использовать на ленте вкладки **Вид** в группе команд **Точка наблюдения 3D** кнопку ![](images/ribbon_setstartview_as.png){ .ui-icon } (Установить в качестве основного представления).

4. В раскрывающемся списке **Размер навигационного куба** выберите размер, с которым навигационный куб должен отображаться в пространстве листа. Вы можете настроить пять разных размеров: от "Очень маленький" до "Очень большой". Вместе с размером навигационного куба изменяются и все кнопки, используемые для управления навигационным кубом.
5. Если вы хотите включить или выключить анимацию вращения при изменении точек наблюдения в пространстве листа, установите или снимите флажок **Поворот при смене точки наблюдения**. В зависимости от выбранной настройки также будет выполняться или не выполняться анимация вращения навигационного куба при смене точки наблюдения.
