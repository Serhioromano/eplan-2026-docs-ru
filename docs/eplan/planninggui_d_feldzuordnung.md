## Диалоговое окно Присвоение полей (предварительное планирование)

Вы открыли проект и навигатор предварительного планирования. Вкладка Предварительное планирование > группа команд Общее > Импортировать. В диалоговом окне Импортировать данные предварительного планирования — <Имя проекта> выберите в поле Тип источника данных одну из записей — "Excel" или "Текст", а затем щелкните в поле Присвоения полей на [...].

В этом диалоговом окне вы создаете и обрабатываете схемы, задающие присвоение внешних полей данных свойствам Eplan.

Строки без назначенного свойства игнорируются при импорте. Если для внешних полей ступени назначены свойства, одно свойство должно быть обозначено как идентифицирующее.

Обзор основных элементов диалогового окна:

Схема:

Выберите из раскрывающегося списка схему, которую вы хотите обработать. Вы можете обрабатывать только пользовательские схемы.

Через расположенную рядом [панель инструментов](eplan/schemeconfig_m_schemaschaltflaechen.md) можно создавать новые схемы, сохранять изменения в схеме, копировать или удалить схему. Кроме того, схемы можно импортировать и экспортировать.

Описание:

Данное поле отображает текст описания, который вы ввели при создании схемы в диалоговом окне Новая схема в поле Описание.

* * *

Таблица

В таблице имеются следующие столбцы:

Статус:

Зеленая пиктограмма  показывает, что поле данных имеется в источнике данных и его удалось идентифицировать. Желтая пиктограмма  сигнализирует о том, что соответствующие поля данных отсутствуют. Эти строки не учитываются при импорте, при необходимости их можно выделить и удалить.

Внешнее поле:

В этом столбце отображаются поля данных / свойства выбранной таблицы внешнего источника данных.

Ступень:

Здесь вы указываете уровень иерархии в представлении в виде дерева, на котором находится генерируемый или обновляемый сегмент. Все строки с одинаковой ступенью принадлежат одному сегменту.

Определение сегмента:

Укажите здесь, какой вид сегмента должен быть создан из записи данных, например, объект планирования или сегмент структуры.

Свойство:

В этом столбце отображается присвоенное свойство Eplan. Чтобы присвоить свойство, щелкните по столбцу, а затем на [...], и выберите в выведенном диалоговом окне свойство.

Идентифицирующ.:

Установите данный флажок, если соответствующее свойство является идентифицирующим при присвоении. На основании свойств, обозначенных как идентифицирующие, выполняется идентификация и синхронизация объектов при импорте. Для каждого типа объекта как минимум одно внешнее поле должно быть идентифицирующим!

Фильтр:

Здесь можно задать фильтр для соответствующего свойства. При внесении значения выполняется фильтрация по совпадению. Но вы можете ввести, например, "> 100".

Панель инструментов:

На панели инструментов сверху от таблицы доступны следующие кнопки:

Кнопка |  Значение  
---|---  
(Создать) |  Создает новую строку в таблице. При этом новая строка добавляется в конце таблицы.  
(Удалить) |  Удаляет со всем содержимым ту строку, в одной из ячеек которой находится курсор. Возможен многократный выбор.  

!!! tip "Совет:"

    Объектытакже можно идентифицировать, используя свойствоИдентификация объектавместо таких свойств, какОбозначение,Измеряемая величинаиНомер. Такая идентификация по идентификатору объекта подходит для обновления существующих сегментов.
