## Диалоговое окно Настройки: Драйвер для сервера SQL

[Вызов диалогового окна:](javascript:void\(0\);)

Файл > Настройки > Рабочая станция > Интерфейсы > Драйвер для сервера SQL

При использовании баз данных SQL для управления изделиями, управления проектами и словаря для платформы Eplan требуется драйвер Microsoft ODBC для подключения к серверу SQL. В этом диалоговом окне можно выбрать нужный драйвер, если установлено несколько версий драйвера ODBC.

Обзор основных элементов диалогового окна:

Драйвер для сервера SQL:

Если установлен один драйвер ODBC, он будет отображаться здесь. Если установлено несколько драйверов, то можно выбрать нужный драйвер для сервера SQL из раскрывающегося списка.



!!! note "Замечание:"

    Выбор в раскрывающемся списке доступен, только если на компьютере установлены соответствующие драйверы. При возникновении вопросов о возможных драйверах обратитесь к системному администратору SQL.
