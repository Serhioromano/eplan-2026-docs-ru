## Вкладка Узел

Вкладка Основные данные > группа команд Изделия > Управление. В дереве или списке выделен одно изделие узла. Выберите вкладку Узлы.

В этой вкладке выбранному узлу присваиваются позиции, т. е., изделия, которые должны содержаться в нем (т. н. позиции узлов).

Обзор основных элементов диалогового окна:

Номер позиции:  
Дополнительный текст:

В этих полях можно вводить дополнительную информацию об изделиях узла, например номера позиций и исполнения принадлежностей для монтажа из монтажных чертежей. Свойства могут отображаться, например, в отчетах типа "Обзор групп изделий" или использоваться там для фильтрации.

Идентификатор ОУ:

Введите буквенно-цифровое значение для идентификатора ОУ. Можно использовать этот идентификатор ОУ для присвоения подизделий узла отдельным составным частям макроса. Обязательное условие: для этого узла должен быть снят флажок Распределенное размещение узла.

Таким макросом может быть 3D-макрос (графический макрос) или макрос схемы соединений, присвоенный данному узлу. Если затем узел вставляется как устройство в пространство листа или на страницу схемы соединений (например, из центра вставки), то тогда посредством соответствующего идентификатора ОУ подизделия узла присваиваются отдельным составным частям в макросе (устройство в макросе схемы соединений, 3D-размещение изделия в 3D-макросе). Идентификатор ОУ можно присваивать в макросе несколько раз в, но в узле каждый идентификатор ОУ должен быть уникальным.

Присвоение подизделий с использованием идентификатора ОУ обеспечивает гибкое использование макросов. Таким образом можно использовать макросы без присвоенных изделий для различных узлов с разными подизделиями.

Длина:

Ввод значений в этот столбец возможен только для изделий с указаниями длины (таких как кабели, соединения, провода / группы соединений, шланги), но невозможен для изделий из главной группы продуктов "Механика".

Для такого изделия, например кабеля, здесь можно ввести часть длины, указанную на самом изделии. Если узел разворачивается при вставке в схему соединений в качестве устройства или при выборе изделия, введенная здесь длина для отдельного изделия переносится в свойство ссылки изделия Подмножество / длина и может выводиться в отчетах. Однако передача работает только для тех функций, которые из-за определения функции имеют собственное поле длины в дополнение к свойствам ссылки изделия. К ним относятся, например, линии определения кабеля и точки определения соединения.

Содержит дополнительные части:  
Содержит узлы:  
Содержит модули:  

Включить показ этих столбцов можно через пункт всплывающего меню Конфигурировать представление, чтобы отображать информацию о вложенных узлах. Если узел содержит другие узлы и / или модули, здесь будет указано, содержат ли эти элементы дополнительные части, узлы или модули.

!!! note "Замечание:"

    

 

Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](eplan/userinterface_m_kontextmenu.md).

Дополнительно здесь представлены следующие пункты всплывающего меню, специфические для данного диалогового окна:

Пункт меню |  Значение  
---|---  
Удалить содержимое |  Удаляет содержимое текущих выделенных ячеек.  
Перейти к |  Доступно только для столбца Номер изделия. Переход к изделию, введенному в текущей выделенной строке.

Групповое поле Значение изделия

Разбить на групповую спецификацию изделий:  
Учитывать дополнительные части (групповая спецификация изделий):  
Разбить в спецификации изделий:  
Учитывать дополнительные части (спецификация изделий):

С помощью раскрывающихся списков Разбить на групповую спецификацию изделий и Разбить в спецификации изделий в столбцах Отчеты и Данные изготовления (экспорт) укажите индивидуально для узла, следует ли развертывать узел при генерации отчета и / или при экспорте данных изготовления. Дополнительно можно указать, следует ли учитывать при развертывании дополнительные части, содержащиеся в узле.

Значение по умолчанию — параметр "Из настроек". В этом случае используются настройки, заданные в диалоговом окне "Настройки" для отчетов или для экспорта данных изготовления.

* Отчеты В этом случае настройка берется из диалогового окна [Настройки: Изделие](eplan/partslistgui_d_paramartikelauswertung.md#Artikelauswertung). Если в соответствующем отчете используются шаблоны, то сначала берутся настройки из шаблонов и только потом из диалогового окна "Настройки".
* Данные изготовления (экспорт) В этом случае настройка берется из диалогового окна [Настройки: Экспорт данных изготовления / маркировка](eplan/labelgui_d_paramartikelauswertung.md#Artikelauswertung).

Если вы выберете другой параметр, то он заменит настройку, заданную в соответствующем диалоговом окне "Настройки" для значений изделий.

Общую информацию по развертыванию / разъединению см. в разделе "[Разъединение модулей и развертывание узлов](eplan/articlesgui_k_module.md#ModuleAufloesen)".

* * *

Групповое поле Выбор изделия

Развернуть узел:

При установке этого флажка узел разъединяется при выборе изделия, и устройству присваиваются номера изделия отдельных составных частей этого узла. Это также относится к вставке узла из центра вставки.  
Если этот флажок не установлен, то узел не разъединяется при выборе изделия, и устройству присваивается номер изделия этого узла.

Вместо того чтобы разъединить узел при выборе изделия, вы также можете решить при генерации отчета, следует ли разъединять этот узел. Мы рекомендуем не разъединять узлы при выборе изделия, так как в противном случае будет утрачена взаимосвязь между изделием узла и отдельными составными частями.

До степени:

Если установлен флажок Развернуть узел, укажите до какой глубины вложения должен разъединяться узел.

* * *

Распределенное размещение узла:

С помощью этого флажка можно указать, как должен вести себя узел: Установите флажок, если узел следует разместить отдельно на трехмерном чертеже монтажных поверхностей (например, главный выключатель распределяется на пластине и двери). Для других узлов (например, контакторы со вспомогательными контактами), размещенных вместе и определяющихся в спецификации как узлы, снимите флажок.

Обратите внимание, что распределенное размещение никак не сказывается на отчетах и на компоновке электрошкафа 2D.
