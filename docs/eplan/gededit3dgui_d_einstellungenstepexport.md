## Диалоговое окно "Настройки: Экспорт STEP" / диалоговое окно "Настройки: Экспорт VRML" / диалоговое окно "Настройки: Экспорт IFC" / диалоговое окно "Настройки: Экспорт JT"

* Файл > Настройки > Пользователь > Интерфейсы > Экспорт STEP, Экспорт VRML, Экспорт IFC или Экспорт JT
* Файл > Экспортировать > группа команд Данные проекта > Пространство листа > STEP, VRML, IFC или JT. Нажмите рядом с полем Схема на кнопку [...].

В этом диалоговом окне указываются настройки для экспорта файлов STEP, VRML, IFC или JT, после чего настройки сохраняются в виде схемы. Схемы для экспорта в файлы STEP, VRML, IFC или JT сохраняются специфически для пользователя. В этом диалоговом окне можно скопировать и обработать существующую схему или создать новую.

Обзор основных элементов диалогового окна:

Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать или обработать. Для этого также воспользуйтесь соседней [панелью инструментов](schemeconfig_m_schemaschaltflaechen.md).

Каталог вывода:

Укажите здесь место хранения. В качестве целевых для экспорта данных можно указать любой дисковод и подкаталог. Нажав , откройте диалоговое окно Выбрать папку и перейдите к требуемому каталогу или создайте новый.

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

Генерировать имена файлов:

При настройках имени файла существуют следующие возможности:

* Из непрерывного номера
* Из имени пространства листа
* Из свойств

В свойствах доступны свойства пространства листа, свойства проекта и разделитель.

Генерировать подкаталоги: (IFC)

В этом раскрывающемся списке определяется стандартный порядок создания подкаталогов при экспорте файлов IFC:

* Нет: Если выбран данный параметр, при экспорте подкаталоги не генерируются.

* Из свойств: Если выбран этот параметр, имя подкаталога составляется из свойств пространства листа и проекта, а также свободно определяемого разделителя. При нажатии кнопки [...] открывается диалоговое окно Формат: Свойство для конфигурации имени каталога. Воспользуйтесь, например, элементом формата "Разделитель каталога", чтобы создать структуру каталога с несколькими подкаталогами, расположенными друг под другом.

Версия IFC: (IFC)

В этом раскрывающемся списке перечислены все версии спецификации IFC, поддерживаемые Eplan Pro Panel. При необходимости измените предварительные настройки.

Степень детализации: (IFC)

Используйте этот ползунок, чтобы задать степень детализации трехмерной модели для экспорта IFC. Вам доступны три уровня (от 1 до 3), с помощью которых вы можете влиять на уровень детализации трехмерной модели в зависимости от фазы планирования.

Экспортируются следующие данные:

* 1: для всего, что видно снаружи, экспортируется единственный охватывающий параллелепипед.
* 2: все представленные отдельные части, видимые снаружи, экспортируются вместе с охватывающим параллелепипедом.
* 3: все представленные отдельные части, видимые снаружи, экспортируются в детализированном виде.

!!! note "Замечание:"

Следующие данные, как правило, не экспортируются:

* Маршрутизируемые соединения (одиночная жила, кабель, шлангопровод, трубопровод)
* Монтажные отверстия (просверленное отверстие, отверстие с резьбой, прямоугольник, продольное отверстие, шестиугольник, восьмиугольник, определенный пользователем контур)
* Инструменты для монтажных работ (монтажная поверхность, точка монтажа, монтажная сетка, монтажная линия, исходная точка)
* Заблокированные области (заблокированные для монтажных отверстий области, запретные зоны для размещения)
* Инструменты для маршрутизации (сегмент маршрутизации, кривая, область маршрутизации, соединительное отверстие для проводов)
* Вспомогательные линии
* Текстуры

Версия формата: (STEP)

Для версий формата имеются следующие возможности:

* STEP AP 203
* STEP AP 214, версия CD
* STEP AP 214, версия DIS
* STEP AP 214, версия IS

Только внешн. представление электрошкафа: (STEP и JT)

Если установлен данный флажок (стандартная настройка), то электрошкаф экспортируется со всеми функциональными элементами, которые видны снаружи при закрытом электрошкафе. Это правило также действует для произвольно размещенной монтажной платы, которая не является составной частью электрошкафа.

Экспортируются все размещенные изделия с ниже расположенными функциональными элементами, которые в иерархии находятся под электрошкафом или монтажной платой.

Отдельный экспорт для каждого электрошкафа: (STEP и JT)

Если установлен этот флажок (стандартная настройка), то для электрошкафа или свободно стоящей монтажной платы генерируется отдельный файл STEP или JT. Если для генерирования имени файла используется настройка Из имени пространства листа, то имя электрошкафа зависит от имени файла.

Экспортировать вспомогательные элементы: (STEP и JT)

Если данный флажок снят (стандартная настройка), то следующие вспомогательные элементы не экспортируются:

* Сегменты маршрутизации
* Области маршрутизации
* Соединительные отверстия для проводов
* Заблокированные для монтажных отверстий области
* Запретные зоны для размещения
* Монтажные отверстия

Экспортировать маршрутизируемые соединения: (STEP)

Если активирован этот флажок, в ходе экспорта STEP выполняется экспорт маршрутизируемых соединений, имеющихся в пространстве листа. После импорта образованного файла STEP во внешнюю программу CAD в ней могут отображаться маршрутизируемые соединения.

Групповое поле Упрощенное представление (STEP)

В данном групповом поле можно настроить упрощенный экспорт функциональных элементов, как при представлении в пространстве листа.

* Клеммники (Определение блока): Если этот флажок установлен (стандартная настройка), то клеммники экспортируются как упрощенный блок.
* 3D-макросы: Если этот флажок установлен (стандартная настройка), то графические макросы, шины и кабельные каналы упрощаются до прямоугольного параллелепипеда.
