# Диалоговое окно Настройки: Изделие (пользователь)

* Вкладка Основные данные > группа команд Изделия > раскрывающаяся кнопка Управление > Настройки.
* Вы открыли проект. Вы выделили главную функцию в графическом редакторе или навигаторе. Пункт всплывающего меню Свойства. Выберите вкладку Изделия и нажмите рядом с полем Источн. данных на ++...++.
* Файл > Настройки > Пользователь > Управление > Изделия.

В этом диалоговом окне устанавливаются определенные настройки пользователя для работы с выбором изделия и базой данных изделий.

Обзор основных элементов диалогового окна:

### Выбор изделия с выбором схемы:

Если этот флажок установлен, то при каждом выборе изделия открывается новое диалоговое окно выбора, в котором из раскрывающегося списка выбирается схема и посредством [...] можно просматривать / обрабатывать настройки. Это позволяет, например, заполнять список устройств данными из разных источников данных.
Если флажок не установлен (настройка по умолчанию), выбора не происходит.

### Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать или обработать. Для этого также воспользуйтесь соседней [панелью инструментов](schemeconfig_m_schemaschaltflaechen.md).

### Eplan:

Выберите этот параметр, чтобы выбрать файл базы данных в формате Eplan (*.alk) с помощью кнопки ![](images/all_selectfile_as.png) в интерактивном режиме. С помощью следующего диалогового окна можно также выбрать старую базу данных изделий в формате Access (*.mdb) для переноса.

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

Или щелкните по кнопке ![](images/all_new_as.png) (Создать), чтобы в следующем диалоговом окне сгенерировать новую базу данных.

Текущая база данных затем показывается в строке заголовка диалогового окна Управление изделиями.

### Сервер SQL:

Выберите этот параметр и щелкните мышкой по кнопке ++...++, чтобы в диалоговом окне [Сервер SQL — Настройка](modaldialogsdb_d_sqlserver.md) определить настройки для использования сервера SQL.
Или щелкните по кнопке ![](images/all_new_as.png) (Создать), чтобы в следующем диалоговом окне сгенерировать новую базу данных.
Или выберите требуемую базу данных из раскрывающегося списка 15 последних использованных баз данных SLQ, при этом последние использованные базы находятся в верхней позиции. При открытии / генерации новой базы данных, которая отсутствует в списке, при необходимости из списка удаляется база данных, находящаяся на самой нижней позиции. С помощью пункта всплывающего меню Удалить записи можно полностью очистить список, в том числе базу данных, использующуюся в настоящий момент.

Текущий выбранный сервер затем отображается в строке заголовка диалогового окна Управление изделиями.

### Сервер SQL — использовать полнотекстовой поиск:

Доступно только для параметра Сервер SQL. Если этот флажок установлен, для поля Поиск в управлении изделиями используется полнотекстовый поиск, интегрированный на сервере SQL. Это ускоряет поиск, но дает другие результаты по сравнению с "обычным" поиском в базах данных SQL. Это также относится к поиску в выборе изделий, в навигаторе основных данных изделий и к поиску свойств изделий в центре вставки.

!!! note "Замечание:"

    * При использовании SQL Server Express необходимо установить и сконфигурировать на сервере SQL модуль "Advanced Services", чтобы полнотекстовый поиск мог выполняться в фоновом режиме.
    * В отличие от "нормального" полнотекстового поиска, здесь находятся только поисковые понятия, стоящие в начале слова. Так, например, через параметр поиска INTER вы найдете изделия с обозначением INTERBUS, а введя BUS — нет.
    * Чтобы искать числа, заканчивающиеся цифрой "0", необходимо заключить число в кавычки, иначе SQL идентифицирует символы не как символьную строку, а как диапазон значений. (Например, при полнотекстовом поиске значение "21.022000" будет идентифицировано как число, а не как символьная строка, поэтому будет выполняться поиск "21.022*", а не "21.022000*".)

Если флажок деактивирован, полнотекстовой поиск в базах данных SQL не используется.

### API:

С помощью кнопки ++...++ откройте диалоговое окно Настройки: Выбор API изделия. Укажите, какие свойства изделий из внешней базы данных используются, а какие сохраняются в проект.

### Коллекция eStock:

Выберите эту опцию, если вы хотите использовать изделие из центральной базы данных Eplan eStock в Eplan Cloud. Выберите из раскрывающегося списка требуемую коллекцию eStock.

!!! note "Замечание:"

    * Если вы установили коллекцию eStock в качестве источника базы данных, эта база данных защищена от записи на платформе Eplan. Изменения можно вносить только в eStock.
    * При подключении к коллекции eStock загружаются также данные (макросы, рисунки, документы), используемые в изделиях коллекции eStock. Эти данные хранятся в заданных каталогах макросов, рисунков и т. д. При этом вы можете непреднамеренно перезаписать свои основные данные в этих каталогах. Чтобы этого не случилось, рекомендуем перед использованием коллекции eStock в качестве источника базы данных изменить каталоги этих данных в диалоговом окне [Настройки: Каталоги](modaldialogs_d_einstellungenverzeichnisse.md).

Изделия из eStock невозможно изменить в управлении изделиями на платформе Eplan.

Текущая выбранная коллекция eStock затем отображается в строке заголовка диалогового окна Управление изделиями.

Чтобы загрузить изделие из других баз данных в eStock, открыть и обработать изделие коллекции eStock в eStock или обновить данные в управлении изделиями, заменив их измененными данными из eStock, в диалоговом окне Управление изделиями всплывающего меню или под кнопкой [Дополнительно] вам доступны несколько пунктов меню.

Дополнительную информацию касательно Eplan eStock можно найти в [справке eStock](https://www.eplan.help/ru-ru/Infoportal/Content/eStock/Content/htm/eSTOCK_k_home.htm).

### Дополнить данные изделия через:

Если технические данные изделий, специфические для Eplan, необходимо дополнить коммерческими данными из подключенных систем, например PMS, это можно сделать с помощью таблицы в диалоговом окне [Дополнить данные изделия](partselectiongui_d_artikeldatenergaenzen.md), которое открывается нажатием кнопки ++...++. При выборе схемы выбора изделия вы можете определить не только источник данных (поле Схема данного диалогового окна), но и выбрать дополнительные источники данных, которые также необходимо определить как схему.

### Конфигурация дерева:

Выберите из этого раскрывающегося списка схему, которая должна использоваться для представления в виде дерева в базе данных изделий и в выборе изделия. Или щелкните по кнопке ++...++, чтобы в диалоговом окне Конфигурация дерева обработать схему или создать новую.
Если необходимы различные представления структуры дерева в выборе изделия и в базе данных изделий (например, одно для проектирования и одно для обработки основных данных), вы можете создать для этого в настройках изделия несколько схем с различной конфигурацией дерева и через выбор схемы быстро переходить из одного представления структуры дерева в другое.

### Разрешено изменение при выборе:

Если этот флажок установлен, то при выборе изделия на вкладке Изделие диалогового окна свойств условных обозначений можно изменять изделия, имеющиеся в базе данных изделий, и создавать новые изделия. В случае с устаревшей базой данных также поступит запрос на обновление при выборе изделий.

Если вы зарегистрировались в Eplan Cloud, то, помимо прочего, в древовидной структуре и в комбинированном представлении выбора изделий будет отображаться пиктограмма "Data Portal". Это позволяет открывать Eplan Data Portal в окне браузера, а также выбрать и скачать основные данные изделий.

Если флажок не установлен, то изделия можно только выбирать и невозможно создавать или обрабатывать.

### Объект-заполнитель / Рамка макроса: Копировать номер изделия без синхронизации данных изделия:

Если этот флажок установлен, то при присвоении набора значений с помощью объекта-заполнителя / рамки макроса диалоговое окно Конфликт не отображается и данные из базы данных изделий не копируются.

Если флажок снят, то диалоговое окно Конфликт отображается и можно задать, какие данные необходимо оставить без изменений, а какие данные необходимо перезаписать новыми.

### Обновлять данные устройства после сохранения изделий:

Если изделия в проекте старее, чем в базе данных изделий, то новые изделия сохраняются в проекте при синхронизации данных изделий.

Если этот флажок установлен, то в дополнение к синхронизации данных изделия в главные функции, которые используют эти изделия, переносятся еще и более новые данные устройства. При этом в главные функции переносятся только данные из шаблонов функций. Другие данные изделий не переносятся, так как это могло бы целенаправленно изменить данные ссылки изделия в главных функциях.

Если флажок снят, данные устройства в проекте не обновляются.

Дополнительную информацию на эту тему см. в разделе "[Обновление данных изделия и устройства](partselectiongui_k_prinzip.md)".

### Автоматически объединить шаблоны функций:

Если этот флажок установлен, то в диалоговом окне Управление изделиями для узлов и модулей после каждого изменения будут автоматически объединяться шаблоны функций, находящиеся в подизделиях. Это также будет выполняться после импорта данных изделия или при внесении изменений через Eplan API.

Если этот флажок не установлен, то шаблоны функций узлов и модулей не будут автоматически объединяться. В этом случае нужно вручную объединить шаблоны функций в управлении изделиями, чтобы шаблоны функций узла или модуля были актуальными после изменений.
