## Диалоговое окно Экспортировать записи данных

Вкладка Основные данные > группа команд Изделия > Управление. В диалогом окне База данных изделий через меню [Дополнительно] > Настройки была открыта база данных изделий.

* Кнопка [Дополнительно] > Экспортировать.
* В дереве или списке выделены экспортируемые записи данных. Выберите пункт всплывающего меню Экспортировать.

В этом диалоговом окне устанавливаются настройки экспорта.

Обзор основных элементов диалогового окна:

Тип файла:

Выберите требуемый тип файла из раскрывающегося списка. Возможные настройки — "Формат обмена данными Eplan Data Portal (EDZ)" и "XML".

Нажмите на кнопку [...], чтобы задать тип экспорта данных для формата обмена данными Eplan Data Portal (EDZ): установите флажок Полностью экспортировать справочные данные, если в случае с узлами, модулями и т. д. при экспорте также должны учитываться подузлы, подмодули и т. д.

Общий файл:

Выберите этот параметр, если вы хотите экспортировать выбранные данные в один файл. В этом случае будет активировано поле Имя файла, укажите в нем имя файла экспорта или щелкните по  для выбора в интерактивном режиме. При этом расширение имени файла добавляется автоматически в зависимости от выбранного в поле Тип файла типа файла (например, .xml для типа файла "XML").

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](eplan/modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

Отдельные файлы:

Выберите этот параметр, если вы хотите экспортировать выбранные данные в виде отдельных файлов. В этом случае активируется поле Каталог, и в нем указывается каталог, в котором должны выводиться экспортируемые данные в виде отдельных файлов. Имя каждого файла экспорта соответствует номеру изделия, имени схемы сверления, имени производителя и т. д.

Тип записи данных:

Эта настройка доступна только в том случае, если экспортируется вся база данных изделий или ее подмножество, т. е. диалоговое окно открыто через [Дополнительно] > Экспортировать. Выберите с помощью флажков в этой части, какие данные требуется экспортировать.

С помощью типа записи данных "Свойство" вы можете экспортировать определенные пользователем свойства, созданные для изделий, в диалоговом окне [Конфигурировать свойства](eplan/eservicesgui_d_konfigeigenschaften.md).

Раздел:

Эта настройка доступна только в том случае, если экспортируется вся база данных изделий или ее подмножество, т. е. диалоговое окно открыто через [Дополнительно] > Экспортировать. Выберите с помощью флажков в этой части, какие разделы требуется экспортировать; если раздел выбран, экспортируются все относящиеся к этому разделу типы изделий. Для раздела Fluid-Техника здесь можно далее ограничить или расширить объем экспорта.
