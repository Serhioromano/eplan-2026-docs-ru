## Обновить базу данных изделий

Если вы работаете с несколькими версиями Eplan (например, при переходе к версии 2026) и в версии 2026 настроена "старая" база данных изделий, при открытии управления изделиями поступит запрос на ее обновление. Если ответить [Да], база данных изделий будет обновлена.

Если нажать [Нет], база данных изделий не будет обновляться. База данных изделий откроется, но она будет доступна только для чтения. При этом изделия и устройства доступны для выбора.
