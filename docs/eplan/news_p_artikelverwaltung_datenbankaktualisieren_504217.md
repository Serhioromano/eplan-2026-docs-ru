# Обновить базу данных изделий

Если вы работаете с несколькими версиями Eplan (например, при переходе к версии 2026) и в версии 2026 настроена "старая" база данных изделий, при открытии управления изделиями поступит запрос на ее обновление. Если ответить [Да], база данных изделий будет обновлена.

Если нажать [Нет], база данных изделий не будет обновляться. База данных изделий откроется, но она будет доступна только для чтения. При этом изделия и устройства доступны для выбора.

!!! note "Замечание:"

    * При работе с несколькими версиями Eplan для редактирования и обслуживания базы данных изделий необходимо всегда использовать последнюю версию Eplan.
    * Новые и обновленные старые базы данных изделий можно открывать в версиях Eplan 2022 (начиная с обновления 3), 2023, 2024 и 2025, но нельзя редактировать. Это позволяет выполнить выбор изделия или устройства. В версиях Eplan 2022 (до обновления 3) для новой или обновленной старой базы данных изделий будет отображаться пустое диалоговое окно в управлении изделиями.
    * В версии 2022 управление изделиями было переведено на другую технологию баз данных. Поэтому базы данных изделий версии 2.9 (или старше) больше нельзя обновлять в более новых версиях Eplan (2022, 2023 и т. д.). Существует возможность переносить такие базы данных изделий в новые.
