## Удалить свойства сохраненных изделий

Вы можете удалить свойства сохраненных в проекте изделий, при этом также учитываются все специфические для пользователя свойства. Таким образом, напр., можно удалить информацию о цене перед передачей проекта заказчикам.

Условие:

Вы выделили проект или отдельные страницы в навигаторе страниц или вы выделили условное обозначение в графическом редакторе.

  1. Выберите следующие команды: Вкладка Основные данные > группа команд Изделия > раскрывающаяся кнопка Синхронизировать > Удалить сохраненные свойства изделия.
  2. В диалоговом окне Удалить сохраненные свойства изделия из раскрывающегося списка выберите схему Настройки или нажмите кнопку [...], чтобы открыть одноименное диалоговое окно, в котором можно обработать схемы и управлять ими.
  3. Нажмите кнопку  (Создать) и выберите в диалоговом окне Выбор свойств свойства изделия для удаления. Возможен многократный выбор.
  4. Щелкните по кнопке [OK].  
  
Выбранные свойства изделия удаляются из проекта.



!!! note "Замечание:"

    Если вы удаляете сохраненные свойства изделий, то из проекта удаляются только те данные, которые сохранены в этих изделиях. Данныессылки изделияостаются.
