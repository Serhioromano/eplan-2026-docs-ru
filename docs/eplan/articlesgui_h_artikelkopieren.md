## Копировать изделие и вставить данные

### Вставка изделия

Копируя и вставляя изделия, можно быстро создавать новые изделия с помощью существующих данных.

Условия:

* Вы открыли диалоговое окно Управление изделиями (вкладка Основные данные > группа команд Изделия > Управление).
* Вы выделили и скопировали в дереве изделие или один или несколько вариантов.

1. Выделите место в дереве, в которое нужно вставить изделие.
2. Выберите пункт всплывающего меню Вставить.  
  
Eplan генерирует новое изделие с номером <исходный_номер_изделия>(1) на текущем уровне иерархии.  
  
Если перед копированием выделен уровень иерархии изделия, в новом изделии будут отображаться все варианты скопированного изделия. Если выделен один или несколько вариантов изделия, новое изделие будет сгенерировано именно с этими вариантами.  
  
Номера ERP / PDM изделия не копируются при копировании во избежание дублирования номеров ERP / PDM.
3. Отредактируйте скопированные данные в правой части базы данных изделий на вкладках или введите новые данные.  
  
Если группа продуктов выбранной целевого изделия не совпадает с группой продуктов исходного изделия, можно также перенести данные свойств, которые обычно не отображаются для группы продуктов целевого изделия.  

4. Нажмите на ++Применить++, чтобы сохранить введенные данные и изменения, не выходя из базы данных изделий.

### Вставить данные

После копирования изделия или варианта можно перенести его данные (технические данные, шаблоны функций, определенные пользователем свойства и т. д.) в другие изделия или варианты.

Условие:

* Вы открыли диалоговое окно Управление изделиями (вкладка Основные данные > группа команд Изделия > Управление).
* В дереве или в списке вы скопировали изделие или вариант в буфер обмена с помощью пункта всплывающего меню Копировать.

1. Выберите в дереве или в списке изделие или вариант, в который необходимо скопировать данные исходного изделия. Возможен многократный выбор.
2. Выберите пункт всплывающего меню Вставить данные.  
  
Если группа продуктов выбранного целевого изделия не совпадает с группой продуктов исходного изделия, отобразится запрос. Если подтвердить этот запрос нажатием ++Да++, скопированные данные будут вставлены в любом случае. В этом случае могут быть скопированы и данные свойств, которые обычно не отображаются для группы продуктов. Нажмите ++Нет++, тогда данные не будут скопированы и действие будет завершено.
3. Установите в следующем диалоговом окне Вставить данные флажки для данных, которые необходимо вставить.  
  
Если данные для определенной области (например, параметры, важные с точки зрения безопасности, модули и т. д.) отсутствуют, соответствующий им флажок будет недоступен.
4. При необходимости активируйте флажок Не изменять существующие шаблоны функции, если хотите вставить скопированные шаблоны функций и оставить существующие шаблоны функций.
5. Щелкните по кнопке ++OK++.  
  
Эти данные записываются в соответствующие свойства изделий / вариантов, причем уже существующие данные перед этим удаляются.
6. Закройте базу данных изделий и сохраните измененные данные.
7. Нажмите ++Да++ в следующем диалоговом окне, чтобы выполнить синхронизацию данных изделий.
