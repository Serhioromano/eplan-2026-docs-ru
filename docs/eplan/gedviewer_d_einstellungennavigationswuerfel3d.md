## Диалоговое окно Настройки: 3D-навигационный куб

Файл > Настройки > Пользователь > Графическая обработка > 3D-навигационный куб

В этом диалоговом окне вы указываете настройки пользователя для навигационного куба в пространстве листа.

Обзор основных элементов диалогового окна:

Навигационный куб виден:

Здесь вы указываете, следует ли отображать или скрыть навигационный куб в пространстве листа. По умолчанию этот флажок установлен.

Основное представление навигационного куба:

С помощью этого раскрывающегося списка можно задать определенную точку наблюдения в пространстве листа при нажатии кнопки  под навигационным кубом. У вас есть возможность выбрать для основного представления один из шести ортогональных или один из четырех изометрических видов.

Размер навигационного куба:

С помощью этого раскрывающегося списка можно выбрать размер навигационного куба в пространстве листа. Вы можете настроить пять разных размеров: от "Очень маленький" до "Очень большой". Вместе с размером навигационного куба изменяются и все кнопки, используемые для управления навигационным кубом.

Поворачивать при изменении точек наблюдения:

С помощью этого флажка можно включать и выключать анимацию поворота при смене точки наблюдения в пространстве листа. В зависимости от выбранной настройки также будет выполняться или не выполняться анимация вращения навигационного куба при смене точки наблюдения. По умолчанию анимация включена. Эта настройка также относится к командам поворота угла зрения в строке состояния, а также к возможности смены точки наблюдения с помощью предусмотренных для этого комбинаций клавиш.
