## Копировать, вырезать и вставить элементы

Eplan поддерживает типичные команды Windows для копирования, вырезания и вставки элементов.

Условие:

Вы открыли проект. Вы открыли редактор, например графический редактор, редактор рамок и т. д.

1. Выделите нужные элементы и выберите либо пункт всплывающего меню Копировать, либо Вырезать.
2. Если работа выполняется с несколькими буферами обмена (это настраивается в пользовательских настройках), введите в диалоговом окне [Буфер обмена](eplan/macrosgui_d_zwischenablage.md) описание содержимого соответствующего буфера обмена и щелкните по кнопке [OK].
3. При необходимости откройте другую страницу, в которую требуется вставить скопированные / вырезанные элементы.
4. Выберите пункт всплывающего меню Вставить.  
  
При работе с несколькими буферами обмена Eplan открывает диалоговое окно [Вставить](eplan/macrosgui_d_einfuegen.md). Выберите в нем требуемый элемент и щелкните по кнопке [OK].
5. Переместите курсор к тому месту, где требуется вставить эти элементы, и нажмите клавишу [Ввод].  
  
Содержимое буфера обмена будет вставлено на текущей открытой странице.

!!! note "Замечание:"

    


### Копирование элементов с помощью "перетаскивания"

Копирование элементов можно выполнить с помощью стандартной функции Windows "перетаскивание мышью".

1. Выделите те элементы, которые требуется скопировать.
2. Удерживая нажатой клавишу [Ctrl] и левую кнопку мыши, перетащите элементы на новую позицию и отпустите клавиши.  
  
В соответствующее место вставляется копия элементов.
