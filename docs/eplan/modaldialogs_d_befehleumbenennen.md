## Диалоговое окно "Правка"

Вы нажали правой кнопкой мыши на ленте и выбрали команду Настроить ленту.

* Вы выбрали операцию для категории "Операции" в диалоговом окне Настроить в раскрывающемся списке Выбрать команды и с помощью кнопки  хотите назначить его определенной пользователем группе команд в поле Главные вкладки.
* В диалоговом окне Настроить в поле Главные вкладки вы выбрали команду в определенной пользователем группе команд, группе команд или вкладке и нажали кнопку [Правка].

В этом диалоговом окне можно изменить имя группы команд или вкладки, под которым соответствующий элемент будет отображаться в ленте. Для команды или действия можно также задать дополнительные настройки, например, рисунок, отображаемый в ленте.

Обзор основных элементов диалогового окна:

Рисунок:

Доступно только для действия или команды. В этом поле выберите рисунок, который будет назначен действию или команде в ленте.

Здесь у вас есть возможность использовать собственные графические файлы. Для этого с помощью кнопки  откройте окно выбора, в котором можно выбрать и импортировать нужный графический файл. Могут использоваться только графические файлы формата svg.

* Рекомендуемый размер изображения 64x64 пиксела.
* Файл svg должен содержать векторный рисунок. Встроенный графический файл не отображается.
* Для лучшей производительности файл svg должен быть как можно меньшим. Поэтому для конвертированных файлов мы рекомендуем удалять встроенную часть рисунка.

Отображаемое имя:

Введите здесь имя, под которым действие, команда, группа команд или вкладка будет отображаться в ленте. Многоязычный ввод невозможен.

Отображаемое имя операции или команды также может быть пустым. Однако в таком случае необходимо обязательно присвоить изображение.

Командная строка:

Доступно только для одного действия. Операции управляются с помощью командной строки. В этом поле выводится пример записи для выбранной операции. Настройте его в соответствии с собственными желаниями. Знак вопроса "?" в командной строке является заполнителем, который можно заменить.

!!! example "Пример:"

    Текст в командной строке для операции "Вставить символ":XEGActionInsertSymRef /SymbolLibName:? /SymbolId:? /VariantId:0Вы открыли страницу проекта. При нажатии на соответствующую команду вызывается диалоговое окноВыбор символа.Заполнитель "?" в командной строке заменяется конкретными значениями:XEGActionInsertSymRef /SymbolLibName:IEC_Symbol /SymbolId:30 /VariantId:0При нажатии на соответствующую команду символ "клемма" избиблиотеки символовIEC_Symbolдобавляется к курсору и его можно разместить на странице.

Всплывающая подсказка:  

Доступно только для одного действия. Здесь вы вводите текст, который будет отображаться как заголовок во всплывающей подсказке.

Описание:

Доступно только для одного действия. Здесь вы вводите дополнительный текст, который будет отображаться как вторая строка во всплывающей подсказке.
