## Управление изделиями: Перенос старых баз данных изделий

Базы данных изделий из старых версий Eplan (версия 2.9 и старше) не могут использоваться в текущей версии из-за изменения технологии баз данных. Впрочем, в базе данных изделий существует возможность переносить старые базы данных изделий в новые.

Для этого при выборе источника базы данных в диалоговом окне Настройки: изделие (пользователь) можно выбрать старые базы данных. Если такая база изделий установлена или выбрана в диалоговом окне настроек для одного из параметров Eplan или Сервер SQL, открывается следующее диалоговое окно [Переместить базу данных изделий](articlesgui_d_datenbankmigrieren.htm), с помощью которого можно перенести старые базы данных изделий в новые. Затем эти новые базы данных изделий можно использовать в текущей версии Eplan.
