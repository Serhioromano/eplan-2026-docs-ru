## Обработать объекты в табличном виде

Условия:

  * Вы открыли проект.
  * Вы открыли навигатор (навигатор страниц, навигатор устройств и т. д.) в графическом редакторе.


  1. Выделите нужные объекты на странице проекта или в навигаторе.
  2. Выберите следующие команды: Вкладка Главная > группа команд Обработать > В табличном виде.  
  
В диалоговом окне Табличная обработка — <Имя проекта> данные выбранных объектов отображаются в форме таблицы. Если выбор содержит несколько типов объекта, для каждого типа объекта отображаются отдельные вкладки, например Функции, Соединения и т. д.
  3. При необходимости выберите для функций и соединений другую схему, чтобы изменить отображение столбцов.
  4. Измените требуемые свойства в соответствующих полях.
  5. Закройте диалоговое окно с помощью кнопки  или щелкните мышью в другом (открытом) диалоговом окне.  
  
Измененные данные будут приняты.
