## Диалоговое окно Настройки: Выбор функциональных элементов

Вы открыли проект. В Графическом редакторе открыта страница проекта. Вы вставили обзор модели (вкладка Вставить > группа команд Вид > Обзор модели) и разместили его. Выберите в диалоговом окне Обзор модели вкладку Вид и нажмите для свойства Обзор модели: Схема выбора в столбце Значение на кнопку ++...++.

В данном диалоговом окне можно создавать и использовать схемы для представления типов функциональных элементов в обзоре модели.
