## Диалоговое окно Настройки: Синтаксическая проверка ОУ

[Вызов диалогового окна:](javascript:void\(0\);)

Вы открыли проект.

  * Файл > Настройки > Проекты > "Имя проекта" > Устройства > Синтаксическая проверка ОУ.
  * В настройках синтаксической проверки ОУ активирована проверка. В диалоговом окне Свойства <...> в качестве элемента идентификатора вводится недопустимый символ. Нажмите в диалоговом окне Синтаксическая проверка ОУ на кнопку [Настройки].



В этом диалоговом окне можно указать для конкретного проекта, какие именно символы допускаются для блоков идентификаторов ОУ, обозначений устройства и счетных номеров. Эти настройки можно выполнять отдельно для структурных идентификаторов (например, страниц) и для ОУ электротехники и Fluid-техники.

Обзор основных элементов диалогового окна:

Вкладка Структурные идентификаторы

Активировать проверку:

Установите этот флажок, если необходимо проверить блоки идентификаторов. После ввода свойств страницы или свойств устройства Eplan автоматически проверит правильность синтаксиса введенного структурного идентификатора. Если синтаксис неправильный, то появляется окно сообщения, в котором отображаются и выделяются неверные элементы.



!!! note "Замечание:"

    Блокиидентификаторов ОУ электротехники или Fluid-техникинепроверяются, если на вкладкеЭлектротехникаилиFluid-техникаснят флажокАктивировать проверку.


 

Блоки идентификаторов:

В этом групповом поле задается объем проверки блоков идентификаторов (например, функциональное назначение и место установки со структурой идентификаторов по стандартам DIN), причем указываются следующие данные:

  * Числа: выберите эту опцию, если при проверке должны учитываться только числа.
  * Все прописные буквы и числа: выберите эту опцию, если при проверке должны учитываться все прописные буквы и числа.
  * Все прописные и строчные буквы и числа: выберите эту опцию, если при проверке в дополнение к прописным буквам и числам должны также учитываться и строчные буквы.
  * Допустимые спец. символы: установите этот флажок, если при вводе для ОУ должны быть разрешены специальные символы, перечисленные рядом с полем.
  * Текст. спец. символы: установите этот флажок, если должны быть разрешены дополнительные специальные символы (например, умляуты); затем введите соответствующие специальные символы в находящееся рядом поле ввода.
  * Для номеров установок только числа: установите этот флажок, если при проверке номеров установок должны быть разрешены только числа.

Вкладки Электротехника / Fluid-Техника

Выполненные здесь настройки применяются только к элементам обозначения устройств полного ОУ (например, Буквенное обозначение и Счетчик), а не к блокам идентификаторов.

Активировать проверку:

Установите этот флажок, если обозначения устройств должны проверяться. Затем Eplan после ввода свойств устройства автоматически проверяет правильность синтаксиса введенного обозначения устройства. Если синтаксис неправильный, то появляется окно сообщения, в котором отображаются и выделяются неверные элементы.

Если флажок снят, ОУ электротехники / Fluid-техники не проверяются.



!!! note "Замечание:"

    Если на вкладкеЭлектротехникаилиFluid-техникаустановлен флажокАктивировать проверку, то проверяется вся символьная строка обозначения устройства, то естьполное ОУвместе с блоками идентификаторов. Для блоков идентификаторов используются настройки вкладкиСтруктурный идентификатор, даже если снят флажок в этом поле.


 

Обозначение устройства:

В данном групповом поле укажите объем проверки обозначений устройств:

  * Все прописные буквы и числа: выберите эту опцию, если при проверке должны учитываться все прописные буквы и числа.
  * Все прописные и строчные буквы и числа: выберите эту опцию, если при проверке в дополнение к прописным буквам и числам должны также учитываться и строчные буквы.
  * Допустимые спец. символы: установите этот флажок, если при вводе для ОУ должны быть разрешены специальные символы, перечисленные рядом с полем.
  * Текст. спец. символы: установите этот флажок, если должны быть разрешены дополнительные специальные символы (например, умляуты); затем введите соответствующие специальные символы в находящееся рядом поле ввода.
  * Предш. цифра: выберите из раскрывающегося списка, должны ли быть предшествующие цифры разрешенными, запрещенными или обязательными.



Счетн. номер:

В этом групповом поле задается объем проверки счетных номеров; за исключением флажка Текст. спец. символы, который недоступен для счетных номеров, возможные данные соответствуют данным в групповом поле Блоки идентификаторов (на вкладке Структурный идентификатор).
