## Многопользовательский монитор: Порядок действий

На основе сведений многопользовательского монитора можно управлять своей работой так, чтобы сократить препятствия в многопользовательском режиме. При этом у вас есть возможность получить информацию до начала или во время выполнения действия в диалоговом окне.

Чтобы открыть многопользовательский монитор, выберите следующие команды: Файл > Взаимодействие > группа команд Многопользовательский монитор > Многопользовательский монитор. Прогресс запущенных в данный момент операций отображается в столбце Ход выполнения с помощью индикатора выполнения и указания процентов.

### Информирование перед операцией в многопользовательском мониторе

Вы хотите запустить в многопользовательском режиме масштабную операцию для открытого проекта (например, контрольный прогон для всего проекта, отчет для всего проекта и т. д.). Для этого сначала узнайте с помощью монитора, не запустил ли другой пользователь длительную операцию для текущего проекта.

Если не запустил, запустите нужную операцию.

Если для текущего проекта уже выполняется масштабная операция, у вас есть следующие возможности:

* Вы соглашаетесь на длительное время выполнения и все равно запускаете свою операцию.
* Вы можете отложить свою операцию на поздний срок.
* Вы можете связаться с другим пользователем для согласования своих действий. Для этого можно нажать, например, на идентификатор другого пользователя в столбце Пользователя и отправить электронную почту.

### Информирование во время операции в многопользовательском мониторе

Вы запускаете операцию. Поскольку выполнение операции занимает больше времени, чем обычно, вы открываете многопользовательский монитор. Здесь вы узнаете, обусловлена ли задержка параллельно выполняемыми операциями в многопользовательском режиме.

Если это так, то у вас есть следующие возможности:

* Вы соглашаетесь на длительное время выполнения и ждете, пока ваша операция завершится.
* Вы завершаете свою операцию, нажав на ++Отменить++. Затем (как уже было упомянуто выше) можно связаться другим пользователем для согласования своих действий.
