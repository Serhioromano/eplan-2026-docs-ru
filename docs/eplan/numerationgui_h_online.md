# Автоматическая нумерация новых устройств

Новые устройства / функции, которые вы вставляете в страницы схемы соединений с помощью центра вставки или которые вы создаете в навигаторе без размещения, могут быть автоматически пронумерованы непосредственно во время вставки или создания. При этом для каждого нового устройства / каждой функции в зависимости от выбранного online-формата нумерации определяется ОУ в режиме online, которое присваивается автоматически. Если online-формат нумерации содержит счетчик, то счетчик ОУ будет нумеровать по возрастанию.

!!! note "Замечание:"

    Нумеруются группы устройств, которые вы выбрали в формате нумерации в режиме подключения.

Условия:

* Вы открыли проект.
* Вы открыли страницу схемы соединений.

1. Выберите следующие команды: **Файл** > **Настройки** > **Проекты** > "Имя проекта" > **Устройства** > **Нумерация (online)**.
2. Выберите в групповом поле **При вставке символов** опцию **Нумеровать**.
3. Если вы хотите создать или обработать формат нумерации в режиме подключения, щелкните в поле **Формат нумерации** ++"..."++.

![](images/arrow.png) Открывается диалоговое окно **Форматы нумерации**. Здесь вы можете создать [формат нумерации в режиме подключения](numerationgui_h_onlineformat.md). Щелкните по кнопке ++"OK"++.
4. Если вы хотите использовать уже существующий формат нумерации в режиме подключения, выберите в групповом поле **При вставке символов** из раскрывающегося списка **Формат нумерации** формат нумерации в режиме подключения.
5. Щелкните по кнопке ++"OK"++.

### Вставить и пронумеровать устройство / функцию через символ

1. Выберите следующие команды: **Центр вставки** > строка навигации **Главная** > **Символы**. Перейдите через структуру папок к нужному символу и выберите его, щелкнув на плитку предварительного просмотра.

![](images/arrow.png) Символ появится рядом с курсором.
2. Переместите курсор в нужное место на странице схемы.
3. Для размещения символа щелкните по странице.

![](images/arrow.png) Откроется диалоговое окно **Свойства (усл. обозначение):** ++"..."++.

![](images/arrow.png) В поле **Видимое ОУ** в зависимости от выбранного online-формата нумерации будет предложено видимое обозначение устройства для нового устройства / новой функции.
4. Щелкните по кнопке ++"OK"++.

![](images/arrow.png) Символ будет размещен, а ОУ отобразится на схеме соединений.

### Создать и пронумеровать устройство / функцию без размещения

1. Выберите следующие команды: Вкладка **Устройства** > группа команд **Устройства** > **Навигатор.**
2. Выберите вкладку **Дерево**.
3. Выделите уровень проекта или структурный идентификатор.
4. Выберите пункт всплывающего меню **Создать**.
5. Выделите в диалоговом окне **Определения функций** в поле **Выбор** определение функции и нажмите на кнопку ++"ОК"++.

![](images/arrow.png) Откроется диалоговое окно **Свойства (усл. обозначение):** ++"..."++.

![](images/arrow.png) Если перед этим вы выделили уровень проекта, в поле **Видимое ОУ** в зависимости от выбранного online-формата нумерации будет предложено видимое обозначение устройства для нового устройства / новой функции без структурных идентификаторов.

![](images/arrow.png) Если перед этим вы выделили структурный идентификатор, в поле **Видимое ОУ** в зависимости от выбранного online-формата нумерации будет предложено видимое обозначение устройства для нового устройства / новой функции со структурным идентификатором.
6. Щелкните по кнопке ++"OK"++.

![](images/arrow.png) Устройство / функция создается в навигаторе устройств.
