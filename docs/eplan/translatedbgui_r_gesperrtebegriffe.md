## Вкладка Автокоррекция

Вкладка Инструменты > группа команд Перевод > Словарь. Выберите вкладку Автокоррекция.

На этой вкладке вы можете вести список слов, которые не должны использоваться на страницах проекта и будут автоматически заменяться на другие. Для каждого слова, которое не должно использоваться, необходимо ввести текст замены. Таким образом обеспечивается терминологическое единобразие в рамках проекта.

Если на вкладке Пользователи настроек перевода установлен флажок Автокоррекция, то при вводе нежелательных слов на исходном языке они заменяются текстами замены. Нежелательные слова на других языках отображения заменяться не будут.

Обзор основных элементов диалогового окна:

Пoиск:

Используя это поле, можно выполнять поиск всех ключевых слов, которые уже включены в список ключевых слов для автокоррекции. Чтобы найти нужное ключевое слово, введите его в поле ввода. Чтобы отобразить текстзамены для ключевого слова, выделите соответствующее ключевое слово в списке ключевых слов. Ключевое слово выводится в поле Заменить. Текст замены выводится в поле На.

Заменить:

В этом поле изменяется ключевое слово, которое будет заменяться другим. Используя панель инструментов, можно создать, сохранить, скопировать или удалить ключевое слово для автокоррекции.
