## Генерировать изделия из данных схемы соединений

Из данных, сохраненных в условном обозначении, в Eplan можно сгенерировать изделие. При этом изделие и типичные для устройства данные (определение функции, обозначение вывода устройства и т. д.) переносятся в базу данных изделий. Одно такое сгенерированное изделие содержит шаблоны функций для всех функций устройства и хранится в проекте как сохраненное изделие. Если устройству назначены подустройства, то типичные для подустройств данные переносятся в изделие.

Условия:

* Вы открыли проект. В Графическом редакторе открыта страница проекта.
* Вы выделили условное обозначение, которое представляет главную функцию.
* На ОУ записана точно ссылка изделия.

1. Выберите пункт всплывающего меню Генерировать изделие.  
  
Открывается диалоговое окно Управление изделиями. На основе определения функции на условном обозначении новое изделие определяется в структуру группы продуктов базы данных изделий и предварительно выбирается.  
  
Если изделие уже содержится в проекте, отобразится запрос для подтверждения перезаписи. Если изделия еще нет в базе данных изделий, откроется база данных изделий и предварительно будет выбрано новое изделие.  
  
Если изделие уже содержится в базе данных изделий, отобразится запрос. Подтвердите запрос, щелкнув [Да], и типовые для устройства данные (напр., шаблонов функций) будут обновлены для изделия, уже содержащегося в базе данных изделий. В таком случае откроется база данных изделий и это изделие будет предварительно выбрано. Щелкните [Нет], и содержащееся в проекте изделие будет перезаписано, при этом изделие в базе данных изделий не будет обновлено.  

2. При необходимости измените данные нового изделия на вкладках с правой стороны.
3. Щелкните по кнопке [Закрыть].  
  
Закрывается база данных изделий.   
  
Если измененные данные не сохранены с помощью кнопки [Применить], последует еще один запрос. Дополнительно выводится сообщение, с помощью которого можно решить, должна ли автоматически проводиться синхронизация данных изделий "База данных изделий -> Проект".

!!! note "Замечание:"

    Изделия, сгенерированные таким образом, содержат на вкладкеСвойствазначение "NEW" как запись в полеГруппа функций. Это позволяет целенаправленно выполнять фильтрацию по таким изделиям.


### Генерирование предварительно собранных кабелей в качестве модулей

Если вы запроектировали в схеме соединений предварительно собранный кабель (кабель с определением кабеля в качестве главной функции, одно или два определения штекера со штекерами в качестве нижестоящих устройств), с помощью команды Генерировать изделие в управлении изделиями вы можете также генерировать из нового номера изделия кабеля новый модуль для предварительно собранного кабеля.

Чтобы можно было сгенерировать модуль, необходимо внести на кабеле во вкладку Изделие новое изделие, также для свойства ссылки изделия Тип записи данных должен быть установлен тип записи данных "Модуль". Для нижестоящих определений штекера можно использовать новое или уже имеющееся изделие. Выберите здесь во вкладке Изделие запись "Отдельная часть" для типа записи данных и установите флажок свойства ссылки изделия Изделие является составной частью модуля.

При таком способе данные кабеля и штекеров переносятся на модуль. Один сгенерированный таким способом модуль содержит шаблоны функций для всех функций предварительно определенного кабеля и хранится в проекте как сохраненное изделие. Один или несколько нижестоящих штекеров кабеля заносятся для модуля во вкладку Модуль как подизделия. Если какое-либо не внесенное в определение штекера изделие еще отсутствует в управлении изделиями, это изделие тоже будет сгенерировано (как отдельная часть).
