# Панель инструментов схемы

На панели инструментов справа рядом с полем Схема могут быть доступны следующие кнопки:

Кнопка |  Значение
---|---
![](images/all_edit_as.png) (Обработать) |  Открывает диалоговое окно, в котором можно обработать выбранную схему.
![](images/all_new_as.png) (Создать) |  Открывает диалоговое окно "Новая схема". Позволяет создать схему.
![](images/all_save_as.png) (Сохранить) |  Сохраняет схему.
![](images/all_copy_as.png) (Копировать) |  Открывает диалоговое окно "Копировать схему". Позволяет копировать имеющуюся схему.
![](images/all_delete_as.png) (Удалить) |  Удаляет схему.
![](images/all_export_as.png) (Экспортировать) |  Открывает диалоговое окно "Выбрать файл экспорта". Позволяет экспортировать схему. Многократный выбор невозможен.
![](images/all_import_as.png) (Импортировать) |  Открывает диалоговое окно "Выбрать файл импорта". Позволяет импортировать схему (схемы). Возможен многократный выбор.

!!! note "Замечание:"

    * Чтобы старые схемы были доступны, их необходимо сначала экспортировать в одной из предыдущих версий программы. Это можно сделать либо для всех схем одной области настройки при помощи кнопки ![](images/all_export_as.png) (Экспортировать) в левой части диалогового окна настроек (панель инструментов над структурой дерева областей настроек), либо для отдельной схемы с помощью кнопки ![](images/all_export_as.png) (Экспортировать) в правой части диалогового окна настроек (панель инструментов рядом с полем Схема).

    Затем после импорта с помощью соответствующей кнопки ![](images/all_import_as.png) (Импортировать) эти схемы конвертируются в новый формат.
* Как при импорте, так и при экспорте предлагаются однозначные имена файлов по образцу "Операция.Имя схемы.xml", например "CBcr.Стандарт.xml" для экспорта схем "Стандарт" для генерации кабелей ("CBcr" = CABLE create). Это облегчает обзор уже имеющихся схем.
