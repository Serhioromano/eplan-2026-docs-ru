## Панель инструментов схемы

На панели инструментов справа рядом с полем Схема могут быть доступны следующие кнопки:

Кнопка |  Значение  
---|---  
(Обработать) |  Открывает диалоговое окно, в котором можно обработать выбранную схему.  
(Создать) |  Открывает диалоговое окно "Новая схема". Позволяет создать схему.  
(Сохранить) |  Сохраняет схему.  
(Копировать) |  Открывает диалоговое окно "Копировать схему". Позволяет копировать имеющуюся схему.  
(Удалить) |  Удаляет схему.  
(Экспортировать) |  Открывает диалоговое окно "Выбрать файл экспорта". Позволяет экспортировать схему. Многократный выбор невозможен.  
(Импортировать) |  Открывает диалоговое окно "Выбрать файл импорта". Позволяет импортировать схему (схемы). Возможен многократный выбор.
