# Вкладка Модуль

## Вызов диалогового окна:

Вкладка **Основные данные** > группа команд **Изделия** > **Управление**. В дереве или списке выделено одно изделие модуля. Выберите вкладку **Модуль**.

В этой вкладке выбранному модулю присваиваются позиции, т. е. изделия, которые должны содержаться в нем (т. н. позиции модулей).

Обзор основных элементов диалогового окна:

### ОУ:

Введите здесь нижестоящее обозначение устройства, которое относится к этому модулю.

### Идентификатор ОУ:

Введите здесь идентификатор ОУ для шаблона функции устройства, который относится к этому модулю. Допускаются буквенно-цифровые значения.

Чтобы модули также учитывались при выборе устройства, необходимо определить идентификатор ОУ как на главных, так и на вспомогательных функциях.

!!! note "Замечание:"

* Устройство должно быть частью макроса, присвоенного модулю. Указанное в строке изделие присваивается этому устройству при вставке модуля.
* Для идентификации устройства, находящегося в присвоенном макросе, используется либо нижестоящее ОУ устройства, либо указанный на устройстве идентификатор ОУ. Соответственно, на строку (т. е. для каждой позиции модуля) возможен ввод либо в столбец **ОУ**, либо в столбец **Идентификатор ОУ**. При сохранении выполняется соответствующая проверка. Если оба поля не заполнены, выводится сообщение.

### Длина:

Ввод значений в этот столбец возможен только для изделий с указаниями длины (таких как кабели, соединения, провода / группы соединений, шланги), но невозможен для изделий из главной группы продуктов "Механика".

Для такого изделия, например кабеля, здесь можно ввести часть длины, указанную на самом изделии. Модуль разворачивается при вставке в качестве устройства в схему соединений или при выборе изделия. При этом введенная здесь длина для индивидуального изделия переносится в свойство ссылки изделия **Подмножество / длина**. Это свойство можно вывести также в отчетах. Однако передача работает только для тех функций, которые из-за определения функции имеют собственное поле длины в дополнение к свойствам ссылки изделия. К ним относятся, например, линии определения кабеля и точки определения соединения.

!!! note "Замечание:"

    Если в отчетах по изделиям (например, в спецификации изделий) необходимо вывести длину отдельных изделий модулей, используемых в схеме соединений, следует развернуть модули для этих отчетов. Для этого в [настройках конкретного проекта для значения изделия](partslistgui_d_paramartikelauswertung.md) необходимо установить флажок **Развернуть модули** (например, **Файл** > **Настройки** > **Проект** > "Имя проекта" > **Отчеты** > **Изделия**).

### Содержит дополнительные части:Содержит узлы:Содержит модули:

Включить показ этих столбцов можно через пункт всплывающего меню **Конфигурировать представление**, чтобы отображать информацию о вложенных модулях. Если узел модуль содержит другие узлы и / или модули, здесь будет указано, содержат ли эти элементы дополнительные части, узлы или модули.

### Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).

Дополнительно здесь представлены следующие пункты всплывающего меню, специфические для данного диалогового окна:

Пункт меню |  Значение
---|---
Удалить содержимое |  Удаляет содержимое текущих выделенных ячеек.
Перейти к |  Доступно только для столбца **Номер изделия**. Переход к изделию, введенному в текущей выделенной строке.

Групповое поле Значение изделия

### Разбить на групповую спецификацию изделий:Учитывать дополнительные части (групповая спецификация изделий):Разбить в спецификации изделий:Учитывать дополнительные части (спецификация изделий):

С помощью раскрывающихся списков **Разбить на групповую спецификацию изделий** и **Разбить в спецификации изделий** в столбцах **Отчеты** и **Данные изготовления (экспорт)** укажите индивидуально для модуля, следует ли разъединять модуль при генерации отчета и / или при экспорте данных изготовления. Дополнительно можно указать, следует ли учитывать при разъединении дополнительные части, содержащиеся в модуле.

Значение по умолчанию — параметр "Из настроек". В этом случае используются настройки, заданные в диалоговом окне "Настройки" для отчетов или для экспорта данных изготовления.

* Отчеты: В этом случае настройка берется из диалогового окна **Настройки: Изделие**. Если в соответствующем отчете используются шаблоны, то сначала берутся настройки из шаблонов и только потом из диалогового окна "Настройки".
* Данные изготовления (экспорт) В этом случае настройка берется из диалогового окна **Настройки: Экспорт данных изготовления / маркировка**.

Если вы выберете другой параметр, то он заменит настройку, заданную в соответствующем диалоговом окне "Настройки" для значений изделий.

Общую информацию по развертыванию / разъединению см. в разделе "[Разъединение модулей и развертывание узлов](articlesgui_k_module.md)".

### Распределенное размещение модуля:

С помощью этого раскрывающегося списка задайте размещение модуля в трехмерном чертеже монтажных поверхностей. В соответствии с выбранным здесь параметром соответствующее изделие модуля и / или его элементы (т. е. изделия, которые содержатся в модуле) отображаются в трехмерном навигаторе монтажных поверхностей, если они присвоены устройству, и могут быть размещены в пространстве листа.

Обратите внимание, что эта настройка никак не сказывается на отчетах и на действиях в двумерной компоновке электрошкафа.

!!! note "Замечание:"

    Механические модули можно разместить только как единое целое. Соответственно, для модулей из главной группы продуктов "Механика" в настройке **Распределенное размещение модуля** предустановлен параметр "Разместить модульные изделия и элементы", и эту настройку нельзя изменить.
