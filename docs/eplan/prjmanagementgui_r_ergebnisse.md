# Вкладка Результат (проверка проекта)

Вы выбрали базу данных управления проектами. Вы считали каталоги и проекты. Файл > Управление проектами. Выделите проект ввода, содержащий прогрессивное состояние проекта. Выберите ++Дополнительно++ > Проверить проект. Выберите проект для сравнения. Установите флажок Сравнить настройки. Нажмите на кнопку ++ОК++. Выберите вкладку Результат.

В этой вкладке отображается краткий обзор результатов проверки проекта.

Обзор основных элементов диалогового окна:

### Описание:

В этом столбце отображается, какие сравнения и контрольные прогоны были проведены во время проверки проекта, а какие нет. Отображается также общий результат нормоконтроля. При выделении строки в поле Описание сообщения (под таблицей) отображается пояснительный текст. Подробные результаты нормоконтроля можно просмотреть в управлении сообщениями (вкладка Инструменты > группа команд Проверка > Сообщения).

* Сравнение настроек: в этой строке отображается результат сравнения настроек.
* Сравнение свойств: в этой строке отображается результат сравнения свойств.
* Сравнение структур проектов: в этой строке отображается результат сравнения структуры проекта.
* Сравнение слоев: в этой строке отображается результат сравнения слоев.
* Контрольные прогоны: отображает результат контрольных прогонов. На [Вкладка Статус](prjmanagementgui_r_status.md) также отображаются статистические значения контрольных прогонов, такие как количество ошибок и используемая схема контрольных прогонов.

### Статус:

Отображает общий результат нормоконтроля.

* ![](images/all_statusok_as.png){ .ui-icon }: Все в порядке! Нет различий в настройках или свойствах между проектом для сравнения и проектом с замечаниями. Контрольный прогон не генерировал сообщений контрольных прогонов.
* ![](images/erroricon_error_systemmessages.png){ .ui-icon }: Внимание! Нормоконтроль выявил различия в настройках или свойствах между проектом для сравнения и проектом с замечаниями. Контрольный прогон сгенерировал сообщения.
* ![](images/all_statusnotok_as.png){ .ui-icon }: Внимание! Сравнение / контрольный прогон не были проведены. Возможные причины: для проверки проекта вы не выбрали сравнение / контрольный прогон. Вы активировали настройку Остановить сравнение при обнаружении первого различия, Eplan обнаружил отличие и поэтому не провел сравнение / контрольный прогон.

### Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).
