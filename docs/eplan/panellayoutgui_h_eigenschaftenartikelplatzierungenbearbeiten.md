## Обработать и отобразить свойства размещений изделий

При отображении свойств размещений изделий необходимо учитывать следующее: такие отдельные размещенные свойства могут быть присоединены друг к другу и образовывать, таким образом, общий блок; это позволяет перемещать все (требуемые) тексты одновременно и предотвращает перекрытие многострочных текстов другими текстами.

Условия:

* Вы открыли проект.
* Вы находитесь в графическом редакторе на странице типа "компоновка электрошкафа".
* Вы вставили размещение изделия или дважды щелкнули по размещению изделия (или выбрали пункт Свойства во всплывающем меню; в этом случае можно выделить несколько монтажных плат).

1. На вкладке Размещение изделия в диалоговом окне Свойства <...> щелкните по [...] в поле Видимое ОУ.
2. Введите в диалоговом окне Выбор ОУ ОУ, которое должно отображаться в графическом редакторе на размещении изделия.
3. Щелкните по кнопке [OK].  
  
ОУ копируется в поле Видимое ОУ.
4. Щелкните на [...] в поле Изделия, чтобы присвоить изделие размещению изделия.
5. Выберите необходимое изделие в диалоговом окне Выбор изделия.
6. Щелкните по кнопке [OK].  
  
Номер изделия копируется в поле Изделия.
7. Обработайте свойства размещения изделия, введя в поле Значение символьную строку, выбрав значение из раскрывающегося списка и т. п.
8. Щелкните по  (Нов.) в панели инструментов сверху списка свойств.
9. Выберите в диалоговом окне Выбор свойств другие свойства, которым хотите присвоить значение. (Возможен многократный выбор.)
10. Щелкните по кнопке [OK].  
  
Свойства добавляются в столбец Имя свойства в конец списка.
11. Присвойте требуемые значения новым свойствам.
12. Выделите свойства, которые Вам (более) не нужны. (Возможен многократный выбор.)
13. Щелкните по  (Удалить) в панели инструментов сверху списка свойств.  
  
Свойства будут удалены из списка, т. е. скопированы в диалоговое окно Выбор свойств без присвоенных им ранее значений, таким образом значения можно присваивать заново.
14. Перейдите на вкладку Отображение.
15. Выберите из раскрывающегося списка Порядок свойств запись "Определено пользователем" и установите свой вид представления.
16. Выделите в списке свойств то свойство, для которого требуется указать настройки отображения.  
  
Значение по умолчанию в отдельных полях копируется из стандартного указания.
17. Укажите настройки для отображения в полях.
18. Перейдите на вкладку Формат.
19. Укажите настройки формата размещения изделия, выбрав записи из раскрывающихся списков, установив / сняв флаги и т.д.
20. Щелкните по кнопке [OK].  
  
Выполняется обновление отображения свойств.

!!! note "Замечание:"

    Каждое устройство может содержать несколько ссылок изделий в разном количестве. Однако одно размещение изделия может быть размещено только с количеством "1". Поэтому может случиться так, что несколько размещений изделий с одним и тем же обозначениемустройствабудут установлены на одну монтажную плату.
