## Диалоговое окно "Сервер SQL - Настройка" / диалоговое окно "Генерировать базу данных сервера SQL"

[Вызов диалогового окна Настройка сервера SQL:](javascript:void\(0\);)

* Файл > Настройки > Пользователь > Перевод > Словарь. Выберите параметр Сервер SQL и щелкните по кнопке [...].
* Вкладка Инструменты > группа команд Перевод > Словарь. Выберите вкладку Управление. Выберите параметр Сервер SQL и щелкните по кнопке [...].
* Файл > Настройки > Пользователь > Управление > База данных управления проектами. Выберите параметр Сервер SQL и щелкните по кнопке [...].

В этом диалоговом окне задаются предварительные настройки для сервера SQL, который должен использоваться для работы со словарем или с управлением проектами.

[Диалоговое окно Настройка сервера SQL (Управление изделиями):](javascript:void\(0\);)

* Вкладка Основные данные > группа команд Изделия > Управление. Кнопка [Дополнительно] > Настройки. Выберите параметр Сервер SQL и щелкните по кнопке [...].
* Файл > Настройки > Пользователь > Управление > Изделия. Выберите параметр Сервер SQL и щелкните по кнопке [...].
* Вы открыли проект и выделили главную функцию в графическом редакторе или навигаторе. Пункт всплывающего меню Свойства. Вы щелкнули на вкладке Изделие рядом с полем Источн. данных по кнопке [...]. В диалоговом окне Настройки: Изделие (пользователь) выберите опцию Сервер SQL и щелкните по кнопке [...].

В этом диалоговом окне задайте предварительные настройки для сервера SQL, который должен использоваться для работы с базой данных изделий и / или выбором изделия. При этом настройки эксклюзивны, т. е. настройки, заданные для базы данных изделий, не действительны автоматически для выбора изделия.

[Вызов диалогового окна Сгенерировать базу данных сервера SQL:](javascript:void\(0\);)

* Вкладка Инструменты > группа команд Перевод > Словарь. Выберите вкладку Управление. Выберите параметр Сервер SQL. [Дополнительно] > Создать.
* Файл > Настройки > Пользователь > Управление > База данных управления проектами. Выберите параметр Сервер SQL. Щелкните по кнопке  (Создать).
* Вкладка Основные данные > группа команд Изделия > Управление. Кнопка [Дополнительно] > Настройки. Выберите параметр Сервер SQL. Щелкните по кнопке  (Создать).

В этом диалоговом окне можно сгенерировать новую пустую базу данных сервера SQL.

!!! note "Замечание:"

    Для переключения словаря насервер SQLплатформа Eplan поддерживает перечисленные в описании характеристик версииMicrosoft SQL Server. Это относится как к перенастройке базы данных изделий, так и к настройке внутреннего выбора изделия на сервере SQL.

 

Обзор основных элементов диалогового окна:

Сервер:

Укажите здесь имя сервера, на котором осуществляется управление базами данных.

Регистрация:

Выберите из раскрывающегося списка вид регистрации для сервера SQL:

* Проверка подлинности Windows: С помощью этой настройки можно ссылаться на сервер SQL сразу после регистрации в Windows в качестве пользователя; отдельный пароль для идентификации не требуется.
* Сервер SQL: С помощью этой настройки можно ссылаться на сервер SQL, только если вы указаны как авторизованный пользователь в обоих нижних полях. Для этого на сервере SQL необходимо создать базу данных прав и заполнить ее данными.

Пользователь/ пароль:

Эти поля активны только тогда, когда в окне Регистрация выбран параметр Сервер SQL!  
Укажите здесь ваше имя и пароль, если необходимо защитить доступ на сервер SQL с помощью пароля. Чтобы гарантировать конфиденциальность, введенная строка символов представлена точками.

База данных:

Укажите имя базы данных, которая должна использоваться для словаря или для базы данных управления проектами. Или выберите из раскрывающегося списка имя существующей на указанном сервере базы данных.

Тест соединения:

Нажмите на эту кнопку, чтобы проверить соединение с указанным в настройках сервером SQL. При этом выполняется проверка соединения, например, с сервером и главной базой данных SQL. Это позволяет быстрее выявить возможную причину в случае проблем при использовании баз данных SQL. В последующем диалоговом окне Тест соединения с SQL в столбцах Статус и Сообщение о состоянии будет показано, был ли тест успешным или удалось ли установить соединение. В случае успешной проверки будут отображаться соответствующие версии драйвера SQL и сервера SQL.

!!! tip "Совет:"

    Чтобы перенести данные словаря или базы данных изделий из существующей внутренней базы данных Eplan в базу данных сервера SQL, экспортируйте сначала данные из словаря или базы данных изделий в файл формата XML, сгенерируйте новую базу данных сервера SQL, а затем импортируйте данные в новую базу данных.
