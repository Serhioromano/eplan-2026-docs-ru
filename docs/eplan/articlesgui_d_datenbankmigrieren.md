## Диалоговое окно перемещения базы данных изделий

* Вкладка Основные данные > группа команд Изделия > раскрывающаяся кнопка Управление > Настройки. В диалоговом окне Настройки: Изделие (пользователь) в групповом поле Источник базы данных настроена или выбрана база данных изделий из устаревшей версии Eplan.
* Вы открыли проект. Вы выделили главную функцию в графическом редакторе или навигаторе. Пункт всплывающего меню Свойства. Выберите вкладку Изделия и нажмите рядом с полем Источн. данных на ++...++. В диалоговом окне Настройки: Изделие (пользователь) в групповом поле Источник базы данных настроена или выбрана база данных изделий из устаревшей версии Eplan.
* Файл > Настройки > Пользователь > Управление > Изделия. В диалоговом окне Настройки: Изделие (пользователь) в групповом поле Источник базы данных настроена или выбрана база данных изделий из устаревшей версии Eplan.

В этом диалоговом окне можно задать настройки для переноса (перемещения) существующей базы данных изделий из устаревших версий Eplan в новую базу данных изделий.

После переноса новая база данных изделий устанавливается в групповом поле Источник базы данных диалогового окна настроек, и эта база данных используется для управления изделиями и их выбора. В прежних версиях Eplan (версии 2.9 или старше) невозможно использовать такие базы данных изделий.

Обзор основных элементов диалогового окна:

Существующие базы данных изделий:

Здесь отображается, какой тип базы данных (Access или SQL) переносится (перемещается). При выборе параметра Access можно выбрать существующую базу данных изделий с помощью , а при выборе параметра Сервер SQL — с помощью […].

Новые базы данных изделий:

Здесь отображаются новые базы данных изделий, которые появятся после переноса (перемещения).

* При выборе параметра Access для новой базы данных изделий по умолчанию используется старое имя. С помощью  можно выбрать другой каталог.
* При выборе параметра Сервер SQL для новой базы данных изделий по умолчанию используется старое имя с расширением _<порядковый_номер>. С помощью  (Создать) можно перейти в следующее диалоговое окно и создать там новую базу данных с другим именем.   
Выберите из раскрывающегося списка имя старой, существующей базы данных SQL, затем можно выполнить перенос (перемещение) в ту же базу данных изделий.

Дополнительно здесь представлены следующие пункты всплывающего меню, специфические для данного диалогового окна:

Пункт меню |  Значение  
---|---  
Вставить переменную пути |  Доступно только для параметров Access и Eplan. Открывает диалоговое окно Выбрать переменную пути, из которого можно применить одну из доступных переменных пути.  
Удалить записи |  Доступно только для параметра Сервер SQL. Полностью удаляет список баз данных, за исключением текущей используемой базы данных.  

!!! note "Замечание:"

    Во время перемещения не только переносятся данные в новую базу данных изделий, но и обновляется старая база данных изделий Access или SQL. Это означает, что данную базу данных изделий можно открыть в старых версиях Eplan, например, для выбора изделий или устройств. При этом ее невозможно обработать. Во время переноса (перемещения) создается резервная копия базы данных Access (например,ESS_part001 backup 1.mdb). Рекомендуем перед переносом баз данных изделий SQL также создать резервную копию.
