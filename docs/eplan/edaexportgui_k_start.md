## Данные изготовления для Eplan Smart Production

С помощью Eplan Pro Panel выполняется экспорт данных изготовления для Eplan Smart Production. Eplan Smart Production — это веб-приложение, которое поможет вам в изготовлении электрошкафов при монтаже несущих шин, кабельных каналов и установке соединений. Файл экспорта из Eplan Pro Panel выводится в формате "EPDZ". Этот файл содержит свойства всех пространств листа и страниц схем соединений проекта, а также содержащуюся в нем информацию обо всех маршрутизированных соединениях. Кроме того, в файл EPDZ для каждого пространства листа вложены файл AML с данными всех размещений изделий и файл E3D с трехмерными графическими данными.
