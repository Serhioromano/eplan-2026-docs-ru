## Свойства блока

Свойства блока предназначены для совместного форматирования и отображения нескольких прямых и/или косвенных свойств. Использование свойств блока дает следующие возможности:

* Через свойства блока можно получать доступ к косвенным свойствам объекта.
* Можно указывать свойства блока для любого условного обозначения и отображать значения свойств на схеме соединений.
* Свойства блока можно указывать в отчетах.
* Свойства блока можно определять как определяемые пользователем свойства.
* Вам также доступны индексированные свойства блока.
* Индексированные свойства блока можно предварительно определять для символов и проектов.
* Формулы расчета можно вводить в свойствах блока для определения свойств расчета.
