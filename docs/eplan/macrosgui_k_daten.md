# Данные сгенерированного макроса

Макросы, созданные в Eplan вручную или автоматически, содержат следующие данные:

* Имя макроса
* Версия
* Исходный проект
* Описание
* Источник / ссылка.

В свойство Исходный проект Eplan вносит проект, в котором макрос был создан изначально. Свойства Версия и Источник / ссылка можно обрабатывать только в проекте макросов. При наличии макросов, созданных обычным способом в проекте схемы соединений, эти поля остаются пустыми. При вставке макросов эти данные отображаются в поле комментария.

Все макросы также содержат данные страницы. Таким образом, у вас есть возможность вставить макрос окна или символа в качестве макроса страницы. Если эти макросы вставляются как фрагмент на существующую страницу, "страница" в макросе игнорируется.

Определения функций, символы, изделия, формы и рамки в макрос не включаются. В макросе сохраняются лишь источники и номера / названия.

Если вы вставите макрос, а некоторые из данных, на которые он ссылается (например, библиотека символов), отсутствуют в текущем проекте, макрос может не отображаться. В таком случае у вас есть возможность синхронизировать и / или дополнить на вкладке Основные данные в группе команд Изделия основные данные проекта. Кроме того, с помощью следующих команд можно выполнить синхронизацию данных покупного изделия изделиями основных данных: вкладка Основные данные > группа команд Изделия > Синхронизировать.
