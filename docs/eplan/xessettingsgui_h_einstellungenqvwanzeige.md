# Произвести настройки для отображения перекрестных ссылок

Перекрестная ссылка важна для надежного поиска условного обозначения на большом количестве страниц. По этой причине перекрестная ссылка должна обозначать как минимум искомую страницу. Кроме того, требуется ориентация внутри страницы — столбец. Поскольку столбец также может быть относительно большим, внутри страницы есть другая ориентация — строка.

Условие:

Вы открыли проект.

1. Выберите следующие команды: **Файл** > **Настройки** > **Проекты** > "Имя проекта" > **Перекр. ссылки / образы контактов**.
2. Выберите область настройки **Точки разрыва**.
3. В групповом поле **Представление** укажите, как должны отображаться перекрестные ссылки в точках разрыва.
4. Выберите область настройки **Общее**.
5. В групповом поле **Представление** укажите, как должны отображаться перекрестные ссылки на функциональном элементе.
6. В групповом поле **Разделитель** укажите, какие символы должны использоваться в качестве разделителей перед страницей, а также между страницей и столбцом и строкой и столбцом.
7. Выберите область настройки **Отображение**.
8. Укажите здесь для разных типов страниц, для каких типов страниц должны отображаться перекрестные ссылки и в какой последовательности.
9. В групповом поле **Отображать перекрестные ссылки обзора** задайте обработку перекрестных ссылок обзора.
10. Щелкните по кнопке ++"OK"++.

!!! info "Для сведения:"

    Настройки будут скопированы.
