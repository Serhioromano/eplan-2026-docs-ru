# Диалоговое окно Многопользовательский монитор

Вы открыли проект. Условия многопользовательского режима выполнены. Eplan связан с сервером монитора. Файл > Взаимодействие > группа команд Многопользовательский монитор > Многопользовательский монитор.

В данном диалоговом окне в двух таблицах приведены проекты, относящиеся к многопользовательскому режиму.

Обзор основных элементов диалогового окна:

### Мои проекты, открытые в многопользовательском режиме:

В левой таблице содержится подробная информация по использованию многопользовательского режима. Здесь представлены проекты, которые открыты одновременно вами и другим пользователем. Для данных проектов приведены следующие данные:

* Проект
* Пользователь
* Область
* Версия продукта
* Операция проекта
* Ход выполнения.

Если какой-нибудь пользователь запустил операцию с соответствующим временем выполнения для проекта, который открыт и у вас (контрольные прогоны, отчеты и т. д.), это отображается индикатором выполнения в столбце Ход выполнения.

Нажмите в столбце Пользователь идентификатор пользователя в виде гиперссылки, который запустит программу для электронной почты на вашем компьютере, и вы сможете отправить электронную почту этому пользователю.

При нажатии на пиктограмму ![](images/all_expand_hierarchy_as.png){ .ui-icon } перед именем соответствующего проекта в обеих таблицах отображается дополнительная информация о пользователе (имя, телефон, компьютер). В качестве условия для этого пользователи, участвующие в многопользовательском режиме, должны сохранить соответствующие данные пользователя в настройках (Файл > Настройки > Пользователь > Отображение > Ид. пользователя / адрес).

!!! note "Замечание:"

    * Проекты, которые открыты исключительно вами, не включаются в многопользовательский монитор.
    * Для отправки электронных сообщений на компьютере должна быть установлена программа электронной почты, а в настройках Windows ее нужно указать как приложение электронной почты по умолчанию.

### Другие открытые проекты:

В правой таблице диалогового окна перечислены все проекты, которые открыты только другими пользователями. Для данных проектов приведены следующие данные:

* Проект
* Пользователь.

Если проект открыт несколькими другими пользователями, для соответствующего проекта в столбце Пользователь отобразятся несколько идентификаторов пользователей.

Если вы хотите послать электронное сообщение одному из пользователей, перечисленных в данной таблице, необходимо сначала развернуть следующую информационную строку. Нажмите на имя пользователя, представленное в виде гиперссылки.
