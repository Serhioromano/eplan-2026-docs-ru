# Вставить графические файлы

В Eplan можно вставить графические файлы форматов JPG, BMP, ICO, PNG или TIFF.

Условие:

Вы открыли проект. Вы открыли редактор, например графический редактор, редактор рамок и т. д.

1. Выберите следующие команды: Вкладка **Вставить** > группа команд **Внешн.** > **Графический файл**.
2. В диалоговом окне **Выбрать графический файл** выберите файл через меню выбора файлов.
3. В диалоговом окне [Копировать графический файл](gededitgui_d_bildkopieren.md) определите, будет ли сохранен исходный каталог для файла или файл будет скопирован в каталог проекта.
4. Щелкните по кнопке ++"OK"++.
5. Начертите рамку, в которой должен быть масштабирован рисунок.

!!! info "Для сведения:"

    Оригинальные соотношения страниц при размещении сохраняются.

6. Измените свойства отображения графического файла в диалоговом окне **Свойства (графический файл)**.
7. Щелкните по кнопке ++"OK"++.

!!! info "Для сведения:"

    Если вы выбрали опцию **Копировать** в диалоговом окне **Копировать графический файл**, то он будет скопирован в подкаталог  `Images` проекта. Графический файл хранится не непосредственно там, а в другом отдельном подкаталоге. Имя этого подкаталога вычисляется на основе имен исходных каталогов.

!!! note "Замечание:"

* При резервировании проекта резервируются все графические файлы, которые находятся в каталоге проекта. Чтобы включить графические файлы со ссылками, необходимо при резервировании активировать настройку **Автоматически скопировать файлы со ссылками**.
* Во всплывающей подсказке для соответствующего графического файла указывается, скопирован ли графический файл, добавленный в графическом редакторе, в каталог проекта или размещена только ссылка на исходный каталог этого графического файла. Для ссылочного графического файла во всплывающей подсказке отображается только имя файла с исходным каталогом. Для графического файла, сохраненного в проекте, дополнительно отображаются тип хранения ("Копируется вручную" или "Копируется автоматически") и место хранения.
* При удалении страницы графические файлы, скопированные в каталог проекта, не удаляются. Графические файлы и внешние документы, которые хранятся в проекте и больше не используются, можно удалить, сжав проект.
* Для вывода графических файлов на страницах отчета для текстов-заполнителей в диалоговом окне **Свойства (текст-заполнитель)** на вкладке **Формат** под уровнем иерархии "Блок выравнивания" можно использовать раскрывающийся список **Представление**. Параметр "Графический файл" можно использовать, например, для свойства изделия **Графический файл**, чтобы отобразить на странице отчета графический файл присвоенного изделия.

!!! tip "Совет:"

    Графические файлы, которые не были добавлены в каталог проекта, можно скопировать в каталог проекта с помощью диалогового окна [ **Скопировать файлы со ссылками в проект вручную** ](eservicesgui_d_insprojektkopieren.md) при резервировании проекта. При этом также меняется связь (тип хранения). Это диалоговое окно также можно открыть, используя следующий командный путь: вкладка **Основные данные** > группа команд **Синхронизация** > **Сохранить документы**.

Если графический файл удален из его каталога и поэтому больше не выводится, вместо него выводится прямоугольник с путем файла.

!!! tip "Совет:"

    Графический файл можно вставить с помощью перетаскивания, выделив графический файл в Windows Explorer и перетащив его в графический редактор проекта с помощью мыши.
