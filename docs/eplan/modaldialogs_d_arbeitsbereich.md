## Диалоговое окно "Рабочая область" / диалоговое окно "Настройки: Рабочая область"

* Нажмите справа вверху в ленте на кнопку  (рабочая область) и выберите в раскрывшемся списке команду Обработать раб. область.
* Файл > Настройки > Пользователь > Отображение > Рабочая область

В этом диалоговом окне можно управлять схемами для рабочих областей и обрабатывать их. В такой схеме сохраняется конфигурация интерфейса пользователя, которая была настроена в соответствии с личными предпочтениями или рабочими задачами.

Обзор основных элементов диалогового окна:

Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать или обработать. Для этого также воспользуйтесь соседней [панелью инструментов](schemeconfig_m_schemaschaltflaechen.md).

Помимо этого здесь находится кнопка  (Обработать). С помощью этой кнопки перейдите в диалоговое окно Обработать раб. область, в котором вы сможете выбрать другую рабочую область в качестве шаблона для текущей рабочей области. В таком случае все настройки текущей рабочей области перезаписываются.
