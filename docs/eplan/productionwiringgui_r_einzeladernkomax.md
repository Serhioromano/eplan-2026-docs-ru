## Вкладка "Одиночные жилы" (Komax — Zeta)

* Файл > Настройки > Компания > Сборка проводов > Komax — Zeta > вкладка Одиночные жилы
* Файл > Экспортировать > группа команд Данные изготовления > Сборка проводов > Komax - Zeta. Нажмите рядом с полем Схема на кнопку [...]. Выберите вкладку Одиночные жилы.

В этой вкладке определяются основные данные по проводам для обработки одиночных жил машины Komax — Zeta.

Обзор основных элементов диалогового окна:

Панель инструментов:

Кнопка |  Значение  
---|---  
(Создать) | Создает новую строку. При этом новая строка добавляется в конце списка.  
(Переместить вверх) /  
(Переместить вниз) | Перемещает выделенные строки на, соответственно, одну позицию вверх или вниз, если это возможно.  
(Обновить) |  Заново считывает из проекта номера изделий, цвета соединений и поперечные сечения соединений, маршрутизированные в пространстве листа.  
(Удалить) |  Удаляет выделенные строки.  
  
Таблица:

Номер изделия:

В полях этого столбца отображаются номера изделий одиночных жил, подлежащих обработке. Вы можете изменить номера изделий вручную или использовать кнопку [...] для перехода к выбору изделий, чтобы в интерактивном режиме выбрать нужное изделие с одним номером. Если вы выбрали однопроводное изделие, следующие поля Цвет соединения и Поперечное сечение соединения автоматически заполняются соответствующими значениями.

Цвет соединения:

Введите здесь идентификатор цвета каждой одиночной жилы, например, SW = черный. Поля автоматически заполняются значением, когда вы выбираете одиночные изделия с помощью выбора изделий.

Поперечное сечение соединения:

Укажите здесь поперечное сечение каждой одиночной жилы, например, 2,5 = 2,5 мм. Поля автоматически заполняются значением, когда вы выбираете одиночные изделия с помощью выбора изделий.

!!! note "Замечание:"

    Если вы не вводите единицу измерения, предполагается, что это "мм²". Если вы хотите указать поперечное сечениесоединенияв AWG, введите соответствующую единицу измерения непосредственно.

 

Одиночная жила: WireKey:

Введите здесь "WireKey" для каждой одиночной жилы, например, H07V-K-BK-1.50. Это текст, который определяется как параметр, заданный в настройках программного обеспечения машины Komax, и должен быть взят оттуда. "WireKey" содержит информацию об изделии, цвете соединения и поперечном сечении соединения одиночной жилы. Максимальная длина текста этого набора параметров составляет 25 символов.

Маркировка: FontKey:

Введите здесь "FontKey" для каждой одиночной жилы. "FontKey" необходим для прямой маркировки одиночных жил. Это текст, который определяется как набор параметров, заданный в программных настройках машины Komax, и должен быть взят оттуда. "FontKey" содержит информацию о форматировании текста, такую как шрифт, размер шрифта и цвет шрифта. Максимальная длина текста этого набора параметров составляет 25 символов.

Маркировочный шланг: TubeKey:

Введите здесь "TubeKey". Это текст, который определяется как набор параметров, заданный в программных настройках машины Komax, и должен быть взят оттуда. Если для маркировки одиночных жил используется маркировочный шланг, в "TubeKey" содержится информация об используемом изделии, диаметре и цвете маркировочного шланга. Максимальная длина текста этого набора параметров составляет 25 символов.

Маркировочный шланг: Размер текста:

Укажите здесь размер шрифта для печати маркировочного шланга, если он предназначен для маркировки одиночных жил. Вы можете выбрать один из 10 различных размеров шрифта. (Значение по умолчанию: 2.)

Маркировочный шланг: Оформление:

Введите здесь "Макет" для каждой одиночной жилы. "Макет" необходим для маркировки маркировочных шлангов. Это текст, который определяется как набор параметров, заданный в программных настройках машины Komax, и должен быть взят оттуда. "Макет" содержит информацию о форматировании текста, такую как шрифт, размер шрифта и цвет шрифта. Максимальная длина текста этого набора параметров составляет 25 символов.
