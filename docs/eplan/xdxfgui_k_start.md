## Интерфейс DXF/DWG

Eplan поддерживает импорт и экспорт данных в формате обмена чертежными данными DXF (Drawing eXchange Format) и чертежном формате DWG (DWG = DraWinG) компании Autodesk. Эти распространенные форматы позволяют обмениваться данными между различными программами CAD. Оба формата были предложены вместе с выпуском программы AutoCAD и в настоящее время являются отраслевыми стандартами.

С помощью экспорта данных в формате DXF / DWG проектную документацию можно направлять заказчикам, которые не используют Eplan. Логика Eplan при этом не переносится. Eplan позволяет экспортировать страницы проекта или проекты целиком.

Реализованные в Eplan функции импорта данных в формате DXF / DWG позволяют извлекать конструкторские данные из внешних систем и переносить их в проекты Eplan. Эту операцию можно выполнить тремя способами:

  * Импорт файлов DXF / DWG на уровне проекта в виде графической страницы
  * Вставка чертежей DXF / DWG на страницах проекта
  * Создание макроса окна Eplan из файлов DXF / DWG.



!!! note "Замечание:"

    Eplan поддерживает формат DXF / DWG различных версий формата AutoCAD, которые можно просмотреть или задать черезФайл>Настройки>Пользователь>Интерфейсы>Экспорт и импорт DXF / DWGна вкладкеЭкспорт; если вы используете файлы DXF / DWG с элементами, которые не являются частью версии формата AutoCAD, Eplan не будет воспринимать эти элементы.
