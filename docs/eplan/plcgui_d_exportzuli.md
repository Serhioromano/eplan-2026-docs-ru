## Диалоговое окно Экспортировать список присвоений (весь ЦПУ)

Вы открыли проект.

* Вкладка Устройства > группа команд ПЛК > Список присвоений > кнопка [Дополнительно] > Экспортировать список присвоений (весь ЦПУ)
* Файл > Экспортировать > группа команд Данные проекта > Данные проекта > группа команд ПЛК > Список присвоений > Кнопка [Дополнительно] > Экспортировать список присвоений (весь ЦПУ)

В этом диалоговом окне экспортируются списки присвоений, которые были вновь созданы или обработаны.

!!! note "Замечание:"

Обзор основных элементов диалогового окна:

Специфические для ПЛК настройки:

В этом поле отображается схема, задающая формат адресов ПЛК. Схема находится на основе ЦПУ, содержащихся в выборе, и здесь ее нельзя изменить. Если ЦПУ не присвоена схема, используется схема, заданная в настройках проекта. Над полем дополнительно отображаются проект конфигураций и имя станции, которым присвоено ЦПУ.

Язык:

В этом раскрывающемся списке представлены все языки, определенные в настройках перевода проекта. Выберите язык, на котором экспортируется список присвоений. С помощью записи "Все языки отображения" список присвоений экспортируются на всех языках отображения, выбранных в настройках перевода. Подробную информацию см. в разделе "[Экспорт и импорт многоязычных функциональных текстов в списке присвоений](plcgui_k_zuordnungslisten.md)".

!!! note "Замечание:"

    Чтобы экспортировать список присвоений в языки Юникод (например, китайский и русский), в диалоговом окнеНастройки: Специфические для ПЛКна вкладкеФормат списка присвоенийнеобходимо выбрать запись "UNICODE" из раскрывающегося спискаНабор символов.

Имя файла:

В этом поле введите имя, под которым сохраняется список присвоений. С помощью  откройте диалоговое окно выбора файла, где можно выбрать список присвоений, который необходимо переписать или переименовать.

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

!!! note "Замечание:"

    Предложенные в диалоговом окне выбора файла типы файла зависят отсхемы, выбранной в диалоговом окнеНастройки: ПЛК.
