# Диалоговое окно Соединения

## Вызов диалогового окна:

Вы открыли проект. Вкладка **Основные данные** > группа команд **Рамки / формы** > раскрывающаяся кнопка **Форма** > **Открыть** > кнопка ++"Открыть"++ для формы типа "Схема кабельных соединений". Вы выделили форму в навигаторе страниц и открыли с помощью пункта всплывающего меню **Свойства** диалоговое окно **Свойства формы — <Имя формы>**. Вы нажали для свойства **Соединения** в поле **Значение** на кнопку ++"..."++.

В этом диалоговом окне Вы управляете присвоением соединений к выводам устройств в формах для отображения спецификации кабеля.

Обзор основных элементов диалогового окна:

### Источник (обозначение) / Цель (обозначение)

В этой таблице сохраняются обозначения источников и целей соединения.

### Соединение (цвет / номер):

Здесь Вы можете сохранить цвет или номер соединения.

Таким образом, присвоение соединения двум выводам устройства будет представлено в виде трех "записей"; несколько присвоений соединений разделяются с помощью "обратного" слеша.
("Запись" — математическое понятие, обозначающее упорядоченный набор объектов, элементы которых расположены в заданной последовательности.)

!!! example "Пример:"

    Запись`1;2:красный|2;3;|;3;4;синий`означает для кабеля:Красная жила типа кабеля соединяет вывод устройства`1`с выводом устройства`2`. Вторая жила типа кабеля соединяет вывод устройства`2`с выводом устройства`3`, а голубая жила типа кабеля соединяет вывод устройства`3`с выводом устройства`4`.

### Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).
