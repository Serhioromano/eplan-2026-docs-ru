# Использование справочной системы

## Вызов диалогового окна:

**Файл** > **Справка** > группа команд **Поддержка** > **Содержимое** > **Справочная система**

Если вы открыли диалоговое окно, можно, кроме того, активировать контекстную справку ( ++"F1"++).

Тему справки можно выбрать непосредственно через содержание. Однако в справочной системе доступен также удобный полнотекстовый поиск, который автоматически заполняет искомые понятия во время их ввода и таким образом отображает предложения. Кроме того, есть возможность целенаправленного ограничения поиска конкретными категориями с помощью фильтра поиска. Синтаксис, используемый для поиска, ориентируется на синтаксис широко используемых поисковых систем в интернете.

Для определения понятий доступны записи в глоссарии. Записи в глоссарии представлены в тексте подчеркиванием и выделяются цветом при наведении на них курсора. Если щелкнуть мышью по такой записи, запись в глоссарии отобразится в отдельном окне.

!!! note "Замечание:"

    Текстовый поиск обеспечивает поиск по синонимам: Например, при вводе схожих, более не используемых или неправильных искомых понятий в большинстве случаев будет отображаться подходящий результат поиска.

###

## Использовать фильтр поиска

Поиск текста в справке можно ограничить специфическими категориями с помощью фильтра поиска. Возможные категории: варианты продукта Eplan (напр., "Eplan Electric P8") и типы страниц справочной системы (напр., "Указания по действиям", "Сообщения контрольного прогона"). Фильтр поиска можно настроить перед началом поиска или изменить в результате поиска.

1. Щелкните кнопку ++Поиск в++ справа от поля ввода для поиска текста.
2. Из раскрывающегося списка выберите категорию.
3. Введите искомое понятие и запустите поиск с помощью кнопки ![](images/helpsystem_startsearch_as.png).

![](images/arrow.png) В результате поиска будут отображаться только записи из выбранной категории.
4. Из раскрывающегося списка выберите другую категорию.

![](images/arrow.png) В результате поиска будут отображаться только записи из новой категории.

###

## Автозаполнение для искомых понятий

Искомые понятия будут автоматически дополняться при вводе в поле для поиска текста. Предлагаемые понятия содержатся в индексе справочной системы.

Кроме того, автозаполнение можно комбинировать с фильтрами поиска.

###

## Переключить язык справки

В справочной системе можно переключаться между всеми доступными языками.

1. На панели инструментов справки щелкните кнопку, на которой отображается текущий язык.
2. Из раскрывающегося списка выберите язык, на который нужно переключиться.

![](images/arrow.png) Текущая страница справочной системы отобразится на выбранном языке.

###

## Копировать URL страницы справки в буфер обмена

Нажмите кнопку ![](images/helpsystem_copylink_as.png) (Копировать URL в буфер обмена) на панели инструментов справочной системы, чтобы скопировать URL открытой страницы справки в буфер обмена, а затем, при необходимости, вставить адрес в другие приложения. Это может пригодиться, например, при отправке запросов в службу поддержки.
