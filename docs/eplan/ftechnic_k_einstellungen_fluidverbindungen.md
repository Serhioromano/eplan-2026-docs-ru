# Eplan Fluid: Предварительное назначение свойств для соединений Fluid-техники

На соединения Fluid-техники можно предварительно накладывать свойства соединения со значениями. В настройках проекта можно предварительно задать значения для разделов "Гидравлика", "Пневматика", "Охлаждение", "Смазка", "Смазочно-охлаждающая жидкость" и "Газовая техника" (командный путь: Файл > Настройки > Проекты > "Имя проекта" > Соединения > Свойства).

Значения данных свойств по умолчанию присваиваются всем соединениям проекта. Если вы устанавливаете точку определения соединения для какого-нибудь соединения, значения его свойств перезаписывают стандартно заданные для этого соединения.
