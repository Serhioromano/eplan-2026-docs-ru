## Вкладка "История"

Вы открыли проект. Этот проект содержит либо комментарии из импортированного PDF-файла, либо комментарии, вставленные непосредственно в Eplan.

* Вы выделили комментарий на странице проекта. Выберите пункт всплывающего меню Свойства. Перейдите в диалоговом окне Свойства на вкладку История.
* Вкладка Инструменты > группа команд Комментарии > Навигатор. Выделите один комментарий и выберите пункт всплывающего меню Свойства. Перейдите в диалоговом окне Свойства на вкладку История.

На этой вкладке вы можете просмотреть историю редактирования комментария. Самые последние изменения приведены вверху вкладки, а самые старые — внизу.

Обзор основных элементов диалогового окна:

Статус:

Пиктограммы в этом столбце показывают, были ли удалены, отредактированы или добавлены значения свойств для комментария.

Статус |  Значение  
---|---  
|  Новое: для свойства было добавлено новое значение (например, текст ответа).  
|  Удалено: значение свойства было удалено.  
|  Изменено: значение свойства было изменено (например, текст комментария).  
  
Имя пользователя:

Показывает имя пользователя в Windows, который отредактировал комментарий.

Дата изменения:

Показывает, когда комментарий был отредактирован.

Изменение: Свойство:

Отображает свойство комментария, который был отредактирован.

Изменение: Старое значение:

Отображает старое значение свойства перед редактированием.

Изменение: Новое значение:

Отображает новое значение свойства после редактирования.
