## Заменить определения функций

На функции вы можете заменить присвоенное определение функции. При этом предлагаются только такие определения функции, которые подходят по числу выводов устройства. Число выводов устройства нового определения функции должно быть таким же или больше, чем у использованного символа. Так, например, для символа замыкающего контакта можно использовать определение функции "Переключающий контакт".

Если функция должна иметь меньше выводов устройства чем использованный символ, необходимо заменить символ. Новый символ будет иметь при себе новую функцию.

Замена определений функции также возможна методом "найти и заменить".

Условие:

Вы разместили функцию (то есть условное обозначение) на странице схемы соединений. Или вы сгенерировали функцию в одном из навигаторов.

  1. Выделите функцию.
  2. Выберите пункт всплывающего меню Свойства.
  3. Выберите в диалоговом окне Свойства <...> вкладку Данные символа / функции и щелкните рядом с полем Определение на [...].
  4. Перемещайтесь по древовидной структуре в диалоговом окне Определения функции и выделите нужное определение функции.  
  
На вкладках с правой стороны в диалоговом окне отображаются свойства и данные вывода устройства выбранного определения функции.
  5. Щелкните по кнопке [OK].
  6. При необходимости дополнительно обработайте данные вывода устройства в диалоговом окне Логическая схема выводов устройства или замените символ.
  7. Щелкните по кнопке [OK].
