# Импортировать свойства с внешней обработкой

!!! note "Замечание:"

* Если в экспортируемый файл перед импортом добавляется новый объект (новая функция, новая страница, новое изделие, новый подобъект для изделия и т. д.), эту новую строку в файле Excel также необходимо указать в определении имени "EPL_VALUES". Для этого в Excel откройте диалоговое окно **Определить имя**, например комбинацией клавиш ++"Ctrl"++ + ++"F3"++. Здесь необходимо настроить соответствующим образом область данных переменной "EPL_VALUES" в поле **Относится к**, чтобы при импорте учитывать новый объект.
* Подобъектами для изделий являются, например, шаблоны функций, схемы сверления, принадлежности и т. п. Данные по ним указываются во втором столбце таблицы Excel. Для создания новых подобъектов они должны следовать в файле Excel под основным объектом. Более подробную информацию по идентификации данных при импорте и возможных значений для объектов и подобъектов см. в разделе "[Операция: XMImportDCArticleDataAction](availableactions_o_xmimportdcarticledataaction.md)".

###

## Импортировать данные проекта с внешней обработкой

Условия:

* Вы экспортировали данные проекта для внешней обработки, не выбрав при этом опцию **Обработать во внешнем приложении и считать обратно**.
* Вы обработали данные в выбранном внешнем приложении и сохранили файл.
* Вы открыли проект, в который следует импортировать данные.

1. Выберите следующие команды: **Файл** > **Импортировать** > группа команд **Данные проекта** > **Данные проекта** > группа команд **Внешняя обработка** > **Свойства**.
2. В диалоговом окне **Открыть** выберите каталог, в котором находится импортируемый файл, выделите его и нажмите ++"Открыть"++.

!!! info "Для сведения:"

    Данные импортируются. При больших объемах данных ход выполнения отображается при помощи индикатора выполнения.

###

## Импортировать внешне обработанные данные изделий

Условия:

* Вы экспортировали данные изделия для внешней обработки, не выбрав при этом опцию **Обработать во внешнем приложении и считать обратно**.
* Вы обработали данные в выбранном внешнем приложении и сохранили файл.
* Вы открыли диалоговое окно **Управление изделиями** (вкладка **Основные данные** > группа команд **Изделия** > **Управление**). В диалогом окне **Управление изделиями** через меню ++"Дополнительно"++ > **Настройки** была открыта база данных изделий, в которую следует импортировать данные.

1. Выберите в диалоговом окне **Управление изделиями** под кнопкой ++"Дополнительно"++ пункты меню **Внешняя обработка свойств** > **Импортировать данные**.
2. Введите в диалоговом окне **Внешняя обработка: импортировать данные изделий** в поле **Имя файла** имя файла импорта, или нажмите на кнопку ![](images/all_selectfile_as.png), чтобы выбрать файл в интерактивном режиме. Возможен многократный выбор.
3. Укажите в групповом поле **Идентификация записей данных** способ идентификации — с помощью идентификатора объекта базы данных изделий или по имени. Идентификация с помощью имени применяется, если вы импортируете данные изделий, созданные в сторонних системах, в собственную базу данных изделий.
4. В групповом поле **Импорт** с помощью опций определите действия, которые следует выполнить при импорте с новыми или имеющимися записями данных.
5. Щелкните по кнопке ++"OK"++.

!!! info "Для сведения:"

    Данные импортируются. При больших объемах данных ход выполнения отображается при помощи индикатора выполнения.

!!! info "Для сведения:"

    Если при импорте генерируются новые изделия, адреса и т. д., вы получите соответствующее сообщение об этом. Если изделия, адреса и т. д. уже существуют, а также в случае отсутствия данных в файле импорта, вы также получите соответствующее сообщение.

## Создать новые объекты при импорте из Excel

Условия:

Импортировать данные проекта:

* Вы открыли проект.
* Вы открыли навигатор и выделили в структуре дерева или списке проект, одну или несколько страниц или одну или несколько записей данных.
* Вы выбрали следующие команды: **Файл** > **Экспортировать** > группа команд **Данные проекта** > **Данные проекта** > группа команд **Внешняя обработка** > **Свойства**.

Импортировать данные изделий:

* Вы открыли диалоговое окно **Управление изделиями** (вкладка **Основные данные** > группа команд **Изделия** > **Управление**).
* Вы выделили в структуре дерева одно или несколько изделий или другие записи данных.
* Вы выбрали в диалоговом окне **Управление изделиями** под кнопкой ++"Дополнительно"++ пункты меню **Внешняя обработка свойств** > **Экспортировать данные**.

1. Выберите в диалоговом окне **Внешняя обработка** из раскрывающегося списка **Настройки** схему. Если нужно создать новые функции, выберите схему, для которой тип объекта настроен на **Все функции**. По умолчанию вам для этого доступна схема "Устройства". Если нужно создать новые изделия, выберите схему с типом объекта **Изделие**. По умолчанию вам для этого доступна схема "Стандарт". Для обработки и создания изделий с шаблонами функций вам доступна схема "Изделия (вкл. шаблоны функций)".
2. В диалоговом окне **Внешняя обработка** выберите опцию **Обработать во внешнем приложении и считать обратно**.
3. Щелкните по кнопке ++"OK"++.

!!! info "Для сведения:"

    Данные экспортируются в Excel.

!!! info "Для сведения:"

    Excel открывается вместе с экспортированными свойствами.

!!! example "Пример:"

    Определение функции Группа функций Категория функции ОУ (полное)ОУ (видимое)317/6558111200=GAA+A1-K4-K4417/6558111200=GAA+A1-K4-K4517/6558111200=GAA+A1-K4-K4617/6558111200=GAA+A1-K4-K4717/6558111200=GAA+A1-K4-K48

4. Чтобы создать новые изделия, скопируйте, например, строки уже имеющихся объектов. Для функций измените в скопированных строках записи в столбцах ОУ (полное) и ОУ (видимое). Для изделий измените в скопированных строках записи в столбцах Номер изделия и Вариант.
5. В заключение измените запись в каждом первом столбце таблицы Excel, обнулив число после косой черты ("/"). Для новой функции укажите в нем, например, значение "17/0", а для нового изделия значение "117/0".

!!! example "Пример:"

    Определение функции Группа функций Категория функции ОУ (полное)ОУ (видимое)317/6558111200=GAA+A1-K4-K4417/011200=GAA+A1-K5-K5517/011200=GAA+A1-K6-K6617/011200=GAA+A1-K7-K7717/011200=GAA+A1-K8-K88

6. Чтобы создать новые подобъекты для изделия, скопируйте, например, строки уже имеющихся подобъектов. Подчиненные объекты (например, шаблоны функций) не имеют записей в первом столбце, но имеют записи во втором столбце таблицы Excel, напр. "99/117/65/1 (117/65:99/1)". При этом первое число означает идентификатор объекта (подчиненного объекта), в данном случае шаблон функции. Для шаблонов функций измените в скопированных строках записи в столбце Номер шаблона функции / Определение функции: Категория/Группа/Определение.
7. В заключение измените запись в каждом второго столбце таблицы Excel, установив идентификатор объекта для основных объектов и подобъектов на ноль. Для нового шаблона функции укажите в ней, например, значение "99/117/0/0 (117/0:99/0)".

8. Чтобы сделать новые объекты (а также, при наличии, подобъекты) доступными для Eplan, необходимо расширить область значений Eplan в Excel. Нажмите ++"Ctrl"++ + ++"F3"++.

!!! info "Для сведения:"

    Откроется диалоговое окно **Диспетчер имен**.

9. Щелкните "EPL_VALUES" и измените запись в поле **Относится к** таким образом, чтобы она включала вновь добавленные ячейки.
10. Щелкните по кнопке ++"Закрыть"++.
11. Сохраните таблицу и закройте Excel.

!!! info "Для сведения:"

    Выполняется экспорт данных.

12. Подтвердите запрос о том, следует ли импортировать данные, нажав кнопку ++"Да"++.

!!! info "Для сведения:"

    Созданные в Excel объекты будут импортированы. Новые изделия непосредственно доступны в базе данных изделий. Новые функции добавляются в навигатор устройств как неразмещенные функции.
