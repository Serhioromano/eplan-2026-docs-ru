## Создать изделие

Условия:

* Вы открыли диалоговое окно База данных изделий (вкладка Основные данные > группа команд Изделия > Управление).
* В дереве под уровнем иерархи "Изделие" выделена одна запись.

1. Выберите в дереве пункт всплывающего меню Создать.  
  
При выделении уровня иерархии "Отдельная часть" или находящейся под ней группы продуктов Eplan генерирует новое изделие с номером Создать(<текущий_номер>).  
  
Когда выделено изделие, Eplan генерирует новое изделие с номером исходный_номер_изделия(<порядковый_номер>).
2. Перейдите справа в диалоговом окне на вкладку Свойства.
3. Измените автоматически назначенную запись для свойства Номер изделия на уровне иерархии Общее.
4. Измените группировку продуктов для изделия, если появились уровни иерархии с обозначением "Не определено". Это происходит, например, когда выделен уровень иерархии "Отдельная часть".
5. Для этого нажмите для свойства Группировка продуктов в столбец Значение и на кнопку [...]. Из раскрывающегося списка группировок продуктов выберите нужную подгруппу продуктов (например, "Общие"), дважды щелкнув по ней.  
  
Выбранная группировка продуктов отображается в свойстве Группировка продуктов. После применения изменений группировка продуктов также отображается для уровней иерархии в дереве.
6. Введите дополнительные данные изделия на вкладке Свойства (например, производитель).
7. Нажмите на [Применить], чтобы сохранить введенные данные и изменения, не выходя из базы данных изделий.

!!! note "Замечание:"

    Если для главной группы продуктов (например, Fluid) в деревеотсутствуетуровень иерархии "Отдельная часть", создайте отдельную часть с помощью пунктов всплывающего менюСоздать>Отдельная часть.

 

### [Создать варианты](javascript:void\(0\);)

Условия:

* Вы открыли диалоговое окно База данных изделий (вкладка Основные данные > группа команд Изделия > Управление).
* Вы создали изделие.

1. Выделите в дереве или списке нужное изделие.
2. Выберите пункт всплывающего меню Создать вариант.
3. Введите в следующем диалоговом окне обозначение для нового варианта текущего изделия. Доступно не более 3 символов.


!!! note "Замечание:"

    Номер изделия и обозначение варианта должны быть уникальными. Если случайно введено обозначение, которое уже существует, Eplan укажет на это при нажатии кнопок[Применить]или[Закрыть]. Запись данных будет сохранена только после того, как будет указан новый номер изделия.
