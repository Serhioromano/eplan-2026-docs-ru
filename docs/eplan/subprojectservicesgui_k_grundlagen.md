## Частичные проекты: Принцип работы

Для разделения проектов на частичные проекты используется функция областей обработки. Поэтому, прежде чем вы сможете генерировать для проекта частичные проекты, вам или администратору сначала необходимо задать нужные области обработки с помощью диалогового окна Области обработки определить как администратора проекта. Определенные здесь области представляют собой возможные частичные проекты. Затем необходимо активировать выбранную область обработки с помощью следующих команд: Файл > Взаимодействие > группа команд Области обработки > Активировать > флажок Активировать выбранную область обработки.

Для генерирования частичных проектов области обработки не должны накладываться друг на друга. "Наложение" означает, что определенные объекты (например, страницы, пространства листа или сегменты предварительного планирования) имеются в нескольких областях обработки. Иначе объекты, встречающиеся в нескольких областях обработки, могут привести к проблемам при сохранении проектов.  
Разделены ли области обработки или накладываются друг на друга, отображается при помощи пиктограммы в диалоговом окне [Определить области обработки как администратор проекта](eplan/eservicesgui_d_bearbeitungsbereichdefinieren.md) в столбце Статус.

!!! note "Замечание:"

    


### Дальнейшее разделение частичных проектов

Возможно разделение частичных проектов на новые частичные проекты. Для этого также необходимо задать области обработки для частичного проекта и активировать область обработки.

В частичном проекте области обработки возвращаются в предыдущее состояние. Это означает, что вы должны определить новые области обработки для дальнейшего разделения частичного проекта. Номер такого "частичного подпроекта" (например 002) разделяется символом подчеркивания и дополняется нулями (например EPLAN_Sample_Project#003#002).

### Перекрестные ссылки на оригинальный проект

В частичном проекте сохраняются перекрестные ссылки на содержащиеся в оригинальном проекте элементы в свойстве Перекрестная ссылка (внешн.). После выгрузки частичного проекта у соответствующих объектов с перекрестными ссылками (напр., точки разрыва, выводы устройства ПЛК, катушки и т. д.) это свойство отображается автоматически на вкладке таблицы свойств.  
В отношении отображенных значений этого свойства необходимо учитывать следующее:

* "@" в значении этого свойства означает позицию соответствующей перекрестной ссылки в списке перекрестных ссылок.
* При наличии нескольких перекрестных ссылок на разные объекты внешние перекрестные ссылки перечисляются на нескольких строках.
* Внешняя перекрестная ссылка на образ контакта содержит в дополнение к перекрестной ссылке сведения о символе образа контакта, включая обозначения вывода устройства.

Чтобы отличать перекрестные ссылки на оригинальный проект от других перекрестных ссылок, можно установить для таких перекрестных ссылок префикс в виде любого знака или последовательности знаков. Для этого в специфических настройках проекта для перекрестных ссылок имеется поле для ввода Префикс для перекрестной ссылки (внешн.). (Командный путь для диалогового окна настроек выглядит следующим образом: Файл > Настройки > Проекты > "Имя проекта" > Перекр. ссылки / образы контактов > Общее.)
