## Диалоговое окно Выполнить контр. прогон

[Вызов диалогового окна:](javascript:void\(0\);)

  * Вы открыли проект. В навигаторе страниц выделена одна или несколько страниц или проект, или же в графическом редакторе открыта страница. Вкладка Инструменты > группа команд Проверка > Проверить.
  * Вкладка Основные данные > группа команд Изделия > Управление. Через меню [Дополнительно] > Настройки была открыта база данных изделий. Вы выделили в дереве управления изделиями одно или несколько изделий. Вы выбрали пункт всплывающего меню Выполнить контр. прогон.



В этом диалоговом окне выберите схему для проверки данных проекта в проекте или основных данных изделий в управлении изделиями. Схема указывает, какие виды проверок проводились и как классифицированы сообщения.

Обзор основных элементов диалогового окна:

Настройки:

Выберите схему из раскрывающегося списка. С помощью кнопки [...] откройте диалоговое окно [Настройки: сообщения и контр. прогоны](xesinspectiongui_d_einstellungenmeldungen.htm), в котором можно устанавливать собственную схему для отображения сообщений контрольного прогона.

Применить ко всему проекту:

Этот флажок доступен только при проверке данных проекта. Установите этот флажок, чтобы распространить проверку на все кабели проекта.  
Если один из проектов уже был отмечен, данный параметр является предварительно установленным, убрать его нельзя.

Проверять только выполненные сообщения:

Если этот флажок установлен, то в выполняемом после этого автономном контрольном прогоне будут проверены только те сообщения, для которых в управлении сообщениями был установлен флажок Выполнено. (При вызове в управлении изделиями проверяются только те сообщения, для которых на вкладке Сообщения установлен флажок Выполнено.) Все невыполненные сообщения останутся в базе данных сообщений без изменения.

В этом случае все другие настройки контрольного прогона или выбор, сделанный в навигаторах, не учитываются. Поэтому поле Настройки и флажок Применить ко всему проекту будут недоступны.
