# Вкладка Присвоение признака

Вкладка Основные данные > группа команд Изделия > Управление. Кнопка ++Дополнительно++ > Импортировать. В поле Тип файла выбрана запись для версии ECLASS. Щелкните кнопку ++...++ рядом с полем Тип файла и выберите вкладку Присвоение признака.

На этой вкладке можно присваивать характеристики стандарта ECLASS свойствам изделий базы данных изделий.

!!! note "Замечание:"

    Предварительно на вкладке Присвоение класса необходимо выбрать классы ECLASS.

Обзор основных элементов диалогового окна:

### Панель инструментов:

Кнопка |  Значение
---|---
![](images/all_new_as.png) (Создать) |  Открывает диалоговое окно Выбор признака. Позволяет выбрать одну или несколько характеристик стандарта ECLASS. При этом из раскрывающегося списка Характеристики стандарта ECLASS можно выбрать, должны ли использоваться характеристики стандарта ECLASS типа "Advanced" (предварительно установлен) или "Basic". При этом "Advanced" обозначает структурированное дерево признаков, в то время как "Basic" — плоский список признаков. Фильтр позволяет ограничить количество отображаемых признаков. Для этого в поле Фильтр введите текст для поиска и щелкните по кнопке ![](images/all_search_as.png) (Поиск). При этом выполняется поиск имен признаков и их описания.
![](images/all_delete_as.png) (Удалить) |  Позволяет удалить одно или несколько присвоений признаков из схемы.

Таблица

Чтобы присвоить свойство изделия или определенное пользователем свойство выбранному признаку ECLASS, в столбце Свойство изделия или Определенное пользователем свойство нажмите на кнопку ++...++; откроется диалоговое окно Выбор свойств, где вы сможете выбрать нужные свойства из списка доступных. Если свойство изделия уже назначено, определенное пользователем свойство не может быть назначено, и наоборот.

Количество присваиваемых свойств изделий или определенных пользователем свойств (одно или несколько) зависит от кардинальности признака ECLASS; для этого см. тему [База данных изделий: Присвоение признаков ECLASS свойствам изделий Eplan](partsimportbmecatgui_k_mappingdetails.md).

В столбце Условие можно задать критерии фильтра, щелкнув кнопку ++...++ в поле и выбрав критерии в открывшемся диалоговом окне Фильтр. При этом с помощью кнопки ![](images/all_new_as.png) (Создать) в нем откроется диалоговое окно Выбор признака. Выберите здесь признак ECLASS, для которого необходимо определить фильтр, и задайте условие (т. е. оператор и значение) в диалоговом окне Фильтр.

!!! example "Пример:"

    Представим, что вам необходимо импортировать пути к документам типа "Графика 2D" неизменно в одном и том же месте, например в свойстве изделия Внешний документ: Файл / гиперссылка 1, независимо от последовательности признаков в файле импорта. Затем для признака "Источник в качестве указания пути" задается свойство изделия Внешний документ: Файл / гиперссылка 1и создается условие "Тип документа = Графика 2D". (Оба признака "Источник в качестве указания пути" и "Тип документа" доступны в диалоговом окне Выбор признакав папке Дополнительная документация>Дополнительная документация.)

!!! note "Замечание:"

    * Характеристики стандарта ECLASS могут присваиваться различным свойствам Eplan, независимо от класса. Это объясняется тем, что характеристики стандарта ECLASS имеют однозначное описание благодаря идентификатору и определению.
    * Одному свойству изделия Eplan можно присвоить несколько характеристик стандарта ECLASS. Это может приводить к конфликтам при импорте (если изделие имеет обе характеристики стандарта ECLASS) и появлению системного сообщения. При этом приоритет будет у первого импортированного свойства.
    * Значения и характеристики стандарта ECLASS, импортируемые во многоязычные поля, импортируются на языках каталога BMEcat (при наличии).
    * Единица измерения значений не добавляется только при импорте в произвольные свойства. В этом случае она переносится в поле Единица измерения диалогового окна Произвольн. свойства. Для полей базы данных изделий с фиксированной единицей измерения в некоторых случаях необходимо проводить перерасчет.
    * Чтобы импортировать изделие, свойство Номер изделия должно быть всегда заполнено.
