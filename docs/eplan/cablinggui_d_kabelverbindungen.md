# Диалоговое окно Кабели / соединения

## Вызов диалогового окна:

Вы открыли проект и находитесь на странице топологии. Вы выделили сегмент маршрутизации. Выберите пункт всплывающего меню **Кабели / соединения**.

В этом диалоговом окне перечисляются проходящие через выделенный сегмент маршрутизации соединения. Если через сегмент маршрутизации проходит полный кабель (т.е. все маршрутизируемые соединения кабеля), отдельные соединения не будут перечисляться. Вместо этого отображается ОУ кабеля.

Обзор основных элементов диалогового окна:

В таблице приведен список проходящих через сегмент маршрутизации кабелей / соединений со своими свойствами, такими как **ОУ**, **Источник**, **Цель** и сведения о трассе маршрутизации.

### Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).

Дополнительно здесь представлены следующие пункты всплывающего меню, специфические для данного диалогового окна:

Пункт меню |  Значение
---|---
Обработать |  Открывает диалоговое окно **Обработать кабель**, в котором можно просмотреть и обработать для кабеля присвоение кабельных соединений соединениям изделия. Эта команда доступна, только если выделен кабель.
Свойства |  Открывает диалоговое окно **Свойства (усл. обозначение):** ++"..."++. Обеспечивает обработку функции.
Свойства (общие) |  Открывает диалоговое окно **Свойства (общие):** ++"..."++. Позволяет обрабатывать свойства устройства.
