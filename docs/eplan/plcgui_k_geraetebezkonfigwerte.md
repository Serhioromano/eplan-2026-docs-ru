## Значения конфигурации, связанные с устройствами

Значения конфигурации, связанные с устройствами, — это параметры, которые могут быть индивидуально настроены на устройстве. Это могут быть, например, коммутационные уровни реле давления или базовые состояния релевантных для безопасности устройств после включения. При обмене данными ПЛК в формате AutomationML AR APC (начиная с версии AutomationML AR APC 1.2.0) возможен обмен значениями конфигурации, связанными с устройством. С помощью обмена значениями конфигурации, связанными с устройствами, можно также обмениваться свойствами, которые по умолчанию отсутствуют в Eplan.

В Eplan есть два варианта использования таких значений конфигурации, связанных с устройством: в свойствах Устройство ПЛК: TemplateIdentifier и / или Рабочая станция ПЛК: TemplateIdentifier можно сделать ссылку на шаблон в программе конфигурации ПЛК (подробную информацию может предоставить производитель ПЛК) или создать свойства ссылки изделия в Eplan, определенные пользователем.

* Некоторые программы конфигурации ПЛК поддерживают технику шаблонов, при котором происходит обмен только ссылками на шаблон. В этом случае отдельные параметры устройств не конфигурируются, а только сохраняется спецификация шаблона в свойстве Устройство ПЛК: TemplateIdentifier (идентификатор 20580) на главной функции. Это свойство также может быть присвоено изделию по умолчанию. Для этого в базе данных изделий на вкладке Свойства под узлом Данные ПЛК используется свойство Устройство ПЛК: TemplateIdentifier (идентификатор 22338).  
В дополнение или в качестве альтернативы устройств ПЛК свойству Устройство ПЛК: TemplateIdentifier можно использовать свойство Рабочая станция ПЛК: TemplateIdentifier (ID 20614) и ввести здесь имя шаблона, связанного со станцией. Свойство должно быть заполнено в пределах соответствующей рабочей станции на каждом блоке ПЛК, представляющем ЦПУ или первичную станцию.
* В качестве альтернативы или в дополнение к технике шаблонов вы можете создать в базе данных изделий значения конфигурации, связанные с устройством, в виде определенных пользователем свойств ссылок изделий и при необходимости присвоить их изделию или группе изделий.  
При выборе устройства значения конфигурации, связанные с устройством, которые были присвоены изделию как определенные пользователем свойства ссылок изделий, переносятся на устройство в проекте и могут быть изменены там на вкладке Изделия диалогового окна "Свойства".

### Создание определенных пользователем свойств ссылок изделий

В следующих случаях необходимо создать определенные пользователем свойства ссылок изделий:

* Вы работаете без шаблона (свойство Устройство ПЛК: TemplateIdentifier).
* Вы хотите обмениваться значениями конфигурации в дополнение к тем, которые определены в шаблоне.
* Вы хотите перезаписать определенные значения конфигурации из шаблона.

Значения конфигурации, связанные с устройствами, определяются в базе данных изделий как определенные пользователем свойства через диалоговое окно [Конфигурировать свойства](eservicesgui_d_konfigeigenschaften.md). Следующие настройки необходимы для того, чтобы эти свойства были учтены при обмене данными ПЛК в формате AutomationML AR APC:

Поле | Значение  
---|---  
Категория | Данные ПЛК  
Присвоение | Изделие  
Также активировать для ссылок изделий |   
  
Созданные таким образом определенные пользователем свойства ссылок изделий сохраняются в базе данных изделий и могут быть присвоены изделию или группе изделий с помощью вкладки Определенные пользователем свойства.

### Обмен значениями конфигурации, связанными с устройством

Чтобы значения конфигурации, связанные с устройствами, также выводились в файле экспорта, в диалоговом окне Настройки: Экспорт AutomationML AR APC должен быть установлен флажок Экспортировать значения конфигурации, связанные с устройствами.

Значения конфигурации, связанные с устройством, выводятся в файле экспорта с идентифицирующим их именем. Имя при этом укорачивается на первый префикс.

При импорте значений конфигурации, связанных с устройством, присваивается первое подходящее определенное пользователем свойство импортируемого изделия.
