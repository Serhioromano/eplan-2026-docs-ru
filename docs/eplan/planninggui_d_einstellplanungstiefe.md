## Диалоговое окно Настройки: Глубина предварительного планирования

Вы открыли проект. Файл > Настройки > Проекты > "Имя проекта" > Предварительное планирование > Глубина предварительного планирования.

В этом диалоговом окне определяются контрольные прогоны для разных видов сегментов. Для этого задаются обязательные свойства, т. е. свойства, которые должны быть заполнены для этих сегментов. Обязательными свойствами могут быть как свойства Eplan, так и определенные пользователем свойства.

Обязательные свойства проверяются на предмет того, внесено ли значение, активировано ли свойство или, в случае раскрывающийся списка, не выбрана ли запись "Не определено".

Чтобы контрольные прогоны были выполнены, вы должны определить вид проверки в схеме контрольных прогонов для нужных контрольных прогонов.

Обзор основных элементов диалогового окна:

В таблице имеются следующие столбцы:

* Строка: Непрерывный номер строки.
* Имя: здесь задается имя контрольного прогона, например, нужная глубина предварительного планирования. Это имя отображается в управлении сообщениями в виде текста соответствующего сообщения контрольного прогона.
* Определение сегмента: в раскрывающемся списке выберите вид сегментов, для которых необходимо задать обязательные свойства. При этом, выбрав определение отдельного сегмента, можно проверить только однотипные сегменты (например, только измерительные контуры), выбрав определение базового сегмента, можно проверить сегменты определенной категории (например, все технологические контуры, включая как измерительные контуры, так и исполнительные механизмы), или выбрав "Все", можно проверить все сегменты.
* Обязательное свойство 1 ... 10: для каждого контрольного прогона можно задать до десяти обязательных свойств. Нажав в ячейке на кнопку [...], откроется диалоговое окно Выбор свойств, где можно выбрать нужное свойство.
