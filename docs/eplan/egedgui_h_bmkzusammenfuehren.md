# Объединить ОУ

В Eplan усл. обозначения с различными обозначениями устройства сводятся к одному новому устройству путем присвоения условным обозначениям единого ОУ.

Условие:

Вы открыли проект. В Графическом редакторе открыта страница проекта.

1. Выделите условные обозначения (как минимум два), которые должны быть объеденены.
2. Выберите следующие команды: Вкладка **Главная** > группа команд **Обработать** > **Обзор свойств**.
3. Щелкните в диалоговом окне **Обзор свойств** в таблице свойств для свойства **Имя (полное)** в столбец **Значение**, затем нажмите на кнопку ++"..."++.
Если свойство **Имя (полное)** не отображается в таблице свойств, в раскрывающемся списке схем необходимо выбрать схему с подходящей конфигурацией свойств.
4. В диалоговом окне **Полное ОУ** введите ОУ, которое должно быть одновременно присвоено всем выделенным условным обозначениям.
5. Щелкните по кнопке ++"OK"++.

!!! info "Для сведения:"

    ОУ присваивается всем выделенным условным обозначениям. На условных обозначениях автоматически отображаются перекрестные ссылки оборудования.
