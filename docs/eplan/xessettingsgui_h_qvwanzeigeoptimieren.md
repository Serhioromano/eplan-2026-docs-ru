# Оптимизировать отображение перекрестных ссылок

Перекрестная ссылка, представленная в проекте, состоит в основном из полных обозначений устройств, страницы (включая определенный разделитель до страницы) и позиции в используемой рамке, которая выводится как обозначения столбцов и строк. Перекрестные ссылки помогают Вам быстро находить функции устройства, распределено представленного в проекте. Посредством информации о странице, столбце и / или строке можно быстро определить соответствующую функцию. Страница, столбец и строка отображаются только в том случае, если какой-либо идентификатор (например, для блока идентификаторов "Функциональное назначение") устройства не совпадает с вышестоящим слоем (страница). Для этой оптимизации отображения действуют следующие правила:

* Вышестоящим слоем считается исключительно текущая страница, поэтому здесь не учитываются обозначения местоположения.
* [Разделитель]Страница[Разделитель]Столбец[Разделитель]Строка отображается в том случае, если какой-либо идентификатор (например, для блока идентификаторов "Функциональное назначение") устройства не совпадает с вышестоящим слоем (страница).
* Если блоки идентификаторов идентичны вышестоящим слоям, их можно подавить.
* если все идентифицирующие свойства идентичны, номер страницы тоже может быть подавлен.
* [Разделитель]Страница[Разделитель]Строка никогда не скрываются.
Если перекрестная ссылка отображает только столбец (строку), то элемент перекрестной ссылки находится на той же странице.

Для автоматической оптимизации дополнительно можно произвести следующие настройки:

Условие:

Вы открыли проект.

1. Выберите следующие команды: Файл > Настройки > Проекты > "Имя проекта" > Перекр. ссылки / образы контактов > Общее.
2. Установите флажок Отнести правила сокр. перекр. ссылок на ОУ, если вышеприведенные правила сокращения должны применяться к полному ОУ, а не к информации страницы.
3. Установите флажок Подавить одинаковые страницы, если хотите подавить также номер страницы; это можно выполнить только для перекрестных ссылок, для которых все идентифицирующие свойства идентичны.
4. Щелкните по кнопке ++OK++.
