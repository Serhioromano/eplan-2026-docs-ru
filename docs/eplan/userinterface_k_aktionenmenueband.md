## Обзор операций для ленты

Указанные ниже операции можно вставить в качестве команд, выполнив настройку ленты:

Операция |  Значение  
---|---  
Установить настройку |  Устанавливает определенное значение для настроек пользователя, станции и фирмы.  
Импортировать настройки |  Импортирует настройки порядка свойств, диалоговой памяти, конфигурации дерева и списка.  
Выполнить внешнюю программу |  Позволяет выполнить внешнюю программу, открываемую из Eplan.  
Экспортировать данные изготовления / вывести маркировку |  Выводит данные изготовления / маркировку для проекта.  
Установить формат графич. элементов |  Устанавливает на определенные значения одну или несколько настроек форматирования выбранных графических элементов. Если вы еще не выбрали графический элемент, то при нажатии на кнопку курсор изменяется и вы можете выделить нужную область с графическими элементами. Дополнительную информацию о настройках форматирования можно получить [здесь](availableactions_o_xgedstartinteractionaction.md).  
Экспортировать функции |  Экспортирует свойства функций текущего проекта для внешней обработки.  
Вставить устройство |  Позволяет разместить заданное устройство без вызова диалогового окна.  
Вставить макрос |  Позволяет вставлять определенный вариант заданного макроса без вызова диалогового окна. Если вариант в макросе отсутствует, то выводится замечание.  
Экспортировать в Rittal - Athex |  Экспортирует данные изготовления клеммников и последовательных принадлежностей для управления автоматизированными системами монтажа, например Rittal - Athex.  
Управлять проектом |  Выполняет операцию для управления проектами или для проектов. Одним из вариантов является реорганизация проекта. Дополнительную информацию о возможных настройках можно получить [здесь](availableactions_o_projectmanagement.md).  
Установить свойство проекта |  Устанавливает свойство выбранного проекта на определенное значение.  
Установить проектную настройку |  Устанавливает определенное значение для настройки проекта.  
Установить свойство усл. обозначения |  Устанавливает свойство выбранного условного обозначения на определенное значение.  
Установить формат усл. обознач |  Устанавливает на определенные значения одно или несколько свойств форматирования у всех текстов свойств выбранных условных обозначений. Если вы еще не выбрали условное обозначение, то при нажатии на кнопку курсор изменяется и вы можете выделить нужную область с условными обозначениями. Дополнительную информацию о настройках форматирования можно получить [здесь](availableactions_o_xgedstartinteractionaction.md).  
Экспортировать страницы |  Экспортирует свойства страниц текущего проекта для внешней обработки.  
Установить свойство страницы |  Устанавливает свойство выбранной страницы на определенное значение.  
Вставить символ |  Позволяет вставить заданный символ без вызова диалогового окна. Если заполнители "?" в командной строке не заменяются имеющими смысл значениями, то открывается диалоговое окно Выбор символа.  
Вставить символ с определением функции |  Позволяет вставлять символы с одинаковым определением функции.  
Установ. формат текста |  Устанавливает на определенные значения одну или несколько настроек форматирования выбранных текстовых элементов. Если вы еще не выбрали текстовый элемент, то при нажатии на кнопку курсор изменяется и вы можете выделить нужную область с текстовыми элементами. Дополнительную информацию о настройках форматирования можно получить [здесь](availableactions_o_xgedstartinteractionaction.md).  
Экспортировать соединения |  Экспортирует свойства соединений текущего проекта для внешней обработки.  
Установить формат графики соединений (точки определения соединения, точки определения потенциала) |  Устанавливает на определенные значения одну или несколько настроек форматирования выбранных точек определения соединений и / или потенциалов. Если вы еще не выбрали точку определения, то при нажатии на кнопку курсор изменяется и вы можете выделить нужную область с точками определений. Дополнительную информацию о настройках форматирования можно получить [здесь](availableactions_o_xgedstartinteractionaction.md).
