# Импортировать данные изделий

Условие:

В диалогом окне База данных изделий через меню ++Дополнительно++ > Настройки была открыта база данных изделий.

1. Выберите следующие команды: Вкладка Основные данные > группа команд Изделия > Управление.
2. Выберите в диалоговом окне База данных изделий под кнопкой [Дополнительно] пункт меню Импортировать.
3. Выберите требуемый тип файла из раскрывающегося списка Тип файла диалогового окна Импортировать записи данных.

!!! info "Для сведения:"

    В зависимости от заданного здесь формата импорта активируется кнопка ++...++, а в следующем диалоговом окне можно задать настройки для импорта.

4. Введите в поле Имя файла имена для файлов импорта или нажмите на кнопку ![](images/all_selectfile_as.png), чтобы выбрать файлы в интерактивном режиме. Возможен многократный выбор.

!!! info "Для сведения:"

    Расширение имени файла автоматически добавляется в зависимости от типа файла, выбранного в поле Тип файла.

5. Выберите из этого раскрывающегося списка Присвоения полей схему, которая должна использоваться для присвоения полей. Или щелкните по ++...++, чтобы в диалоговом окне Присвоение полей обработать имеющуюся схему или создать новую.
6. С помощью опций определите действия, которые следует выполнить при импорте с новыми и имеющимися записями данных.
7. Щелкните по кнопке ++OK++.
