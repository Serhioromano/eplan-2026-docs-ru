# Вкладка Формат (Размещение изделия 3D)

## Вызов диалогового окна:

Вы открыли проект.

* Открыты навигатор пространства листа и пространство листа. В пространстве листа находятся трехмерные размещения изделия. Выделите размещение изделия в навигаторе. Выберите пункт всплывающего меню **Свойства**. Выберите в диалоговом окне **Свойства** ++"..."++ вкладку **Формат**.
* Выделено устройство в трехмерной области отображения. Пункт всплывающего меню **Свойства**. Выберите в диалоговом окне **Свойства** ++"..."++ вкладку **Формат**.

На этой вкладке обрабатываются свойства отображения графического представления трехмерных компонентов, таких как электрошкафы, монтажные платы, несущие шины и т. д.

Обзор основных элементов диалогового окна:

### Свойство/Присвоение:

В таблице доступен уровень иерархии **Формат**, который можно открыть щелчком по знаку ![](images/all_expand_hierarchy_as.png){: .ui-icon }.

### Прозрачность:

Выберите степень прозрачности из раскрывающегося списка или введите значение вручную. Значение 100% делает объект полностью прозрачным.

!!! note "Замечание:"

* Цвет трехмерного объекта нельзя изменить, если уже задан цвет площади или цвет элементов. Цвет отдельной площади нельзя изменить в том случае, если имеется соответствующий слой для всего объекта. Примером может служить трехмерный электрошкаф.
* Цвет площади или цвет объекта возникает после импортирования файла STEP с заранее заданными цветами. Если цвета площади или объектов не заданы, их можно настроить при помощи следующего элемента диалогового окна.
* Эти ограничения распространяются также на принцип работы функций **Копировать формат** и **Присвоить формат** применительно к трехмерным объектам (вкладка **Главная** > группа команд **Буфер обмена** > **Копировать формат** или **Присвоить формат**).
