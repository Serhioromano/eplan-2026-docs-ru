## Диалоговое окно Генерировать клеммы (устройства)

Вы открыли проект.

* Вкладка Устройства > группа команд Клеммы > Навигатор. Выделите ОУ. Выберите пункт всплывающего меню Новые клеммы (устройства).
* Вы открыли диалоговое окно [Обработать клеммник](eplan/stripmanagementgui_d_klemmenleistebearbeiten.md), например, для выделенного определения клеммника или клеммы через командный путь вкладки Устройства > группа команд Клеммы > Клеммник. Выберите пункт всплывающего меню Новые клеммы (устройства).

В данном диалоговом окне для нового или уже имеющегося ОУ можно сгенерировать несколько клемм по определенному образцу нумерации. Клеммы генерируются из шаблонов функций выбранного изделия, при этом образец нумерации определяет обозначения клемм. Каждое устройство имеет по одной главной клемме: этой главной клеммой становится первая сгенерированная клемма, которой присваивается выбранное изделие.

!!! note "Замечание:"

    Если вы установили флажокУчитывать макрос при генерировании устройствв общих настройках проекта для устройств и для выбранного изделия создан макрос, то используемый макрос должен содержать клеммы. В противном случае клеммы не будут сгенерированы. Если у вас нет подходящего макроса, то при необходимости отключите эту опцию в настройках проекта.

 

Обзор основных элементов диалогового окна:

Полное ОУ:

Это поле доступно только в том случае, если это диалоговое окно было вызвано в навигаторе клеммников. В этом поле показывается полное ОУ, которому присвоены новые функции. Показывается ОУ устройства, которое вы выделили в навигаторе. Вы можете изменить ОУ или ввести новое.

Если это диалоговое окно было вызвано в диалоговом окне Обработать клеммник, то ОУ изменить невозможно. Новые устройства будут добавляться только к текущему клеммнику.

Образец нумерации:

Введите в это поле образец нумерации. Образец нумерации определяет обозначения клеммы.

Номер изделия:

В этом поле выводится номер изделия. Кнопка [...] открывает диалоговое окно Выбор изделия и обеспечивает выбор изделия клеммы. Изделие должно обладать минимум одним шаблоном функций клеммы, в обратном случае генерировать клеммы невозможно.

Вариант изделия:

В этом поле отображается вариант изделия выбранного изделия.

Число новых функций:

Значение в этом поле указывает, сколько новых функций будет сгенерировано. Число новых функций зависит от образца нумерации.

Нумеровать с ориентацией на уровни:

Если флажок установлен, тогда клеммы нумеруются по уровням. Если флажок не установлен, тогда клеммы нумеруются по клеммам.
