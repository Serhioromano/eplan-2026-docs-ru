# Экспорт данных изготовления для механической обработки электрошкафов в Rittal - RiPanel Processing Center

Eplan Pro Panel позволяет предоставлять данные изготовления для механической обработки электрошкафов в форме AML-файла для Rittal — RiPanel Processing Center. Для этого в виде Backstage доступен интерфейс для экспорта данных.

Условие:

* Вы открыли проект.
* Проект содержит не менее одного пространства листа с трехмерным чертежом монтажных поверхностей.

1. Пометьте проект в навигаторе страниц.
2. Выберите следующие команды: **Файл** > **Экспортировать** > группа команд **Данные изготовления** > **Механическая обработка** > **Rittal - RiPanel Processing Center**.
3. В поле **Схема** диалогового окна **Экспорт: Rittal - RiPanel Processing Center** выберите из раскрывающегося списка подходящую схему. Или щелкните по ++"..."++, чтобы задать в следующем окне настройки новой определенной пользователем схемы.
4. Выберите в поле **Каталог вывода** место хранения экспортируемых данных.
5. Введите в поле **Целевой файл** имя, под которым будет сохранен файл экспорта. Или выберите имя в интерактивном режиме через ![](images/all_selectfile_as.png){ .ui-icon }.

!!! info "Для сведения:"

    Если вы выбираете уже имеющийся файл, отображается запрос. Выберите, нужно ли перезаписать файл.

6. Щелкните по кнопке ++"OK"++.

!!! info "Для сведения:"

    Данные будут записан в файл экспорта.
