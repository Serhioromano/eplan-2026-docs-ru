## Диалоговое окно Настройки: Многопользовательский монитор

[Вызов диалогового окна:](javascript:void\(0\);)

Файл > Настройки > Пользователь > Управление > Многопользовательский монитор

В этом диалоговом окне вы указываете, на каком компьютере настроен сервер мониторинга в качестве службы.



!!! note "Замечание:"

    При возникновении вопросов по настройкам обратитесь к своему системному администратору.


 

Обзор основных элементов диалогового окна:

Имя сервера:

Введите в этом поле имя компьютера, на котором установлено серверное приложение для многопользовательского монитора.

Порт:

Введите в этом поле номер порта серверного приложения.

Активно:

Установите этот флажок для соединения с сервером.

Статус:

В этом поле отображается статус соединения.

[Проверить]:

Нажмите на эту кнопку для проверки настроек. При наличии соединения с серверным компьютером вы увидите соответствующее сообщение в поле Статус.
