# Диалоговое окно Отверстие

## Вызов диалогового окна:

Вы открыли проект. В редакторе контура открыт контур типа "Генерирование записи данных контура ЧУ" (например, с помощью следующих команд: вкладка **Основные данные** > группа команд **Контур / профиль** > раскрывающаяся кнопка **Контур (данные ЧУ)** > **Открыть**), и для данного контура сгенерирована запись данных ЧУ. Вкладка **Обработать** > группа команд **Запись данных ЧУ** > раскрывающаяся кнопка **Обработать** > **Генерировать отверстие**.

В этом диалоговом окне указываются свойства отверстия.

Обзор основных элементов диалогового окна:

### Диаметр:

Из раскрывающегося списка выберите определенный для машины диаметр отверстия. Ручной ввод здесь невозможен.
