## Диалоговое окно Тексты заполнителей — <Тип формы>

[Вызов диалогового окна:](javascript:void\(0\);)

Вы открыли проект. Вкладка Основные данные > группа команд Рамки / формы > раскрывающаяся кнопка Форма > Открыть > кнопка [Открыть].

  * Вкладка Вставить > группа команд Текст > раскрывающаяся кнопка Формы > Текст-заполнитель. В поле Свойство вкладки Размещение нажмите [...].
  * Вы дважды щелкнули по тексту-заполнителю (или выбрали пункт всплывающего меню Свойства; в этом случае можно выделить даже несколько текстов заполнителей), а в диалоговом окне Свойства (текст заполнитель) во вкладке Размещение в поле Свойства щелкнули кнопку [...].



В этом диалоговом окне выберите специфический для формы текст-заполнитель, в который должна быть вставлена форма. При оценке формы программа автоматически заменяет эти заполнители на соответствующие значения конкретных объектов проекта, для которого выполняется отчет, например, на значения функциональных элементов, страниц, символов и т.д.

Обзор основных элементов диалогового окна:

Элемент:

В зависимости от текущего типа формы здесь показываются все элементы, для которых может быть определен заполнитель. В формах для связанных с функцией отчетов доступные элементы разделены на два списка: "Объект верхнего колонтитула" и "Объект данных". Выделите запись, чтобы в правой области вывести соответствующий список свойств.



!!! example "Пример:"

    Выделите к примеру элементСвойства страницы(тип формы "Содержание"), таким образом в правом списке выводятся подчиненныесвойстваФункциональное назначение,Номер страницы,Доп. поле страницыи др.


 

!!! note "Замечание:"

    Для некоторых элементов, напримерИзделие (источник)возможен индекс, в этом случае рядом с элементом отображается символ. Щелкните по этому символу, тогда раскроется иерархический список возможных индексированных свойств, и вы сможете выбрать необходимое. Обратите внимание на то, что данный индекс не обязательно соответствует индексу на вкладкеИзделиедиалогового окна свойств. Если, например, в строке1и строке20введено изделие, в отчете получаются данные второгоизделиячерез индекс2(а не через индекс20).


 

Категория:

Ограничьте отображение подчиненных свойств, выбрав запись из этого раскрывающегося списка.



!!! example "Пример:"

    Выделите, к примеру, элементСвойства страницы(Тип формы 'Содержание') и выберите категорию 'Ревизия', таким образом в правом списке выводятся только специфические для обработки подчиненные свойстваАвтор,Дата создания,Последний обработчики др.


 

Пoиск:

Введите в это поле текст, по которому должна выполняться фильтрация свойств. При фильтрации свойств можно найти как имена свойств, так и установленные значения. Логические операторы (операции И / ИЛИ) и символы-заполнители (например, * или ?) при фильтрации не поддерживаются.

Если необходимо вернуться к прежнему виду свойств, удалите текст из поля ввода. Для этого нажмите кнопку  (Удалить).
