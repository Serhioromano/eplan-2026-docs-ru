## Заменить символы

Условие:

Вы разместили функцию (то есть условное обозначение) на странице схемы соединений. Или вы сгенерировали функцию в одном из навигаторов.

1. Выделите функцию.
2. Выберите пункт всплывающего меню Свойства.
3. Выберите в диалоговом окне Свойства <...> вкладку Данные символа / функции и щелкните рядом с полем Номер / имя по ++...++.
4. В диалоговом окне Выбор символа выберите подходящий символ и щелкните по кнопке ++ОК++.
5. Щелкните в диалоговом окне Свойства <...> по ++OK++.
