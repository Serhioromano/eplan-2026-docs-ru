## Определить формат и объем нумерации

Условие:

Вы открыли проект.

  1. Выберите следующие команды: Файл > Настройки > Проекты > "Имя проекта" > Устройства > Нумерация с данными ПЛК.
  2. Выберите в диалоговом окне Настройки: Нумерация с данными ПЛК определенную пользователем схему из раскрывающегося списка или создайте с помощью команды  (Создать) новую схему.
  3. Нажмите в диалоговом окне Настройки: Нумерация с данными ПЛК над полем Группы форматов кнопку  (Создать).
  4. В диалоговом окне Нумерация с данными ПЛК: Формат выберите из раскрывающегося списка Группа ту группу устройств, для которой требуется настроить формат. Возможен выбор клемм, контактов штекера и устройств.
  5. Выберите объем нумерации для выбранной группы из раскрывающегося списка Объем.

!!! note "Замечание:"

    Если вы выбрали запись "Сеть", через расширение сети можно увеличить зону воздействия для нумерации, указавсетевое расширения.



  6. Выделите элемент формата в поле Доступные элементы формата и перенесите его с помощью  вправо в список выбранных элементов формата.  
  
В зависимости от элемента формата открывается следующее диалоговое окно. В зависимости от выбранного элемента формата это может быть одно из следующих диалоговых окон: [Формат: Данные ПЛК](offlinenumerationplcgui_d_formateigenschaften.htm), [Формат: Буквенное обозначение](offlinenumerationplcgui_d_formatkennbuchstabe.htm), [Формат: Страница / столбец / строка](offlinenumerationplcgui_d_formatseite.htm) или [Формат: Разделитель](offlinenumerationplcgui_d_formattrennzeichen.htm).
  7. Определите форматирование в следующем диалоговом окне.  
  
В поле Предв. просмотр отображается предварительный просмотр формата нумерации. Отдельные элементы формата выводятся в обозначении соединения в той последовательности, в которой они стоят в списке.
  8. При необходимости измените последовательность элементов формата с помощью кнопок со стрелками.
  9. Щелкните по кнопке [OK].  
  
Введенные значения сохраняются в выбранной схеме.
