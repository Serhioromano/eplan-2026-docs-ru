## Экспортировать данные проводного монтажа

При экспорте данных проводного монтажа также учитываются выбранные в проекте кабельные сборки, и для этих объектов выводятся соответствующие данные.

Условия:

* Вы открыли проект.
* Открыт навигатор проводного монтажа.

1. Выделите одно или несколько определений проводного монтажа и/или определений кабельных сборок в графическом редакторе или в навигаторе проводного монтажа.
2. Выберите следующие команды: Файл > Экспортировать > группа команд Данные проекта > Данные проекта > группа команд Устройства > Данные проводного монтажа.  
  
Открывается диалоговое окно Экспортировать данные проводного монтажа. Выбранный проводной монтаж и/или выбранные кабельные сборки отображаются в поле Источник.
3. Введите в поле Имя файла имя, под которым будет сохранен файл экспорта, или выберите его в интерактивном режиме с помощью кнопки .  
  
При экспорте в уже имеющийся документ отображается запрос. Потребуется дополнить или перезаписать файл.
4. Щелкните по кнопке [OK].  
  
Генерируется файл с данными проводного монтажа (*.hpdex). Если были выбраны кабельные сборки, то в файл экспорта также включаются данные этих объектов.

!!! note "Замечание:"

    Если при экспорте данных проводного монтажа активировать флажокПрименить ко всему проекту, то будут экспортированы не только весь предопределенный проводной монтаж и/или все предопределенные кабельные сборки и связанные с ними компоненты, но и совокупный проект со всеми его данными. В таком случае в полеИсточникне будут перечисляться имена проводного монтажа и кабельных сборок всего проекта, вместо этого поле останется пустым.
