## Диалоговое окно Настроить комбинации клавиш

* Нажмите в строке заголовка главного окна Eplan на пиктограмму  (настроить панель быстрого доступа) и выберите команду Другие команды. Нажмите в диалоговом окне Настроить на вкладке Настроить ленту для поля Комбинации клавиш на кнопку ++Настроить++.
* Нажмите правой кнопкой мыши на ленте и выберите команду Настроить ленту. Нажмите в диалоговом окне Настроить на вкладке Настроить ленту для поля Комбинации клавиш на кнопку ++Настроить++.

В этом диалоговом окне можно назначить новые комбинации клавиш для команд (например, из ленты) или удалить существующие.

Обзор основных элементов диалогового окна:

Вкладки:

Здесь можно выбрать нужную вкладку ленты. В соответствии с вашим выбором в поле Команды отображаются соответствующие команды.

!!! tip "Совет:"

Команды:

Здесь вы выбираете команду, комбинацию клавиш которой вы хотите обработать.

Текущие кнопки:

Здесь отображается комбинация клавиш, назначенная выделенной команде (при наличии). Одной команде можно назначить несколько комбинаций клавиш.

Описание:

Здесь отображается краткое описание выделенной команды.

Новая комбинация клавиш:

Введите в этом поле нужную комбинацию клавиш. Клавиши ++Alt++, [Ctrl] и т. д. вводятся простым нажатием соответствующей клавиши и отображаются непосредственно здесь.

После ввода под этим полем отображается текст "Присвоена", а также имя команды, если комбинация клавиш уже назначена какой-либо команде.

[Назначить]:

Назначает выбранной команде комбинацию клавиш, введенную в поле Новая комбинация клавиш.

[Убрать]:

Удаляет комбинацию клавиш, выделенную в поле Текущие кнопки.

[Сбросить все]:

Удаляет после запроса все назначенные пользователем комбинации клавиш. После этого будут присвоены стандартные сочетания.
