## Последовательность видов представлений при общей обработке и анализе

Если у функции есть несколько видов представлений, общие свойства которых содержат различные данные, на основе вида представления решается, какие свойства должны учитываться при общей обработке и составлении отчетов. Для этого в Eplan существует заданная последовательность. Для [Последовательности обработки сгруппированных объектов](eplan/gededitgui_k_gruppierung.md) также существует заданная последовательность.

### Последовательность функций

Это последовательность видов представлений, в Eplan учитываются общие свойства всех видов представлений функции в [Режим-Свойства (общие)](eplan/reverseengineering_k_modus.md):

* Многополюсный
* Обзор
* Парная перекрестная ссылка
* Однополюсный
* Функциональная схема автоматизации
* Топология
* Компоновка электрошкафа
* Компоновка электрошкафа подробно
* Трехмерный чертеж монтажных поверхностей
* Функциональный
* Обзор функций (Fluid-Техника).

Eplan сначала учитывает свойства многополюсного вида представлений. Если функция не имеет многополюсного вида представления или в многополюсном виде представления соответствующее поле свойства пусто, Eplan учитывает свойство функции обзора и т. д.

При генерации отчета и синхронизации функций, обладающих несколькими видами представлений, а также общие свойства которых содержат различные данные, свойства учитываются в той же последовательности что и при общей обработке.

### Последовательность соединений

Виды представления соединений учитываются при общей обработке, при генерации отчета и при синхронизации в следующей последовательности:

* Многополюсный
* Трехмерный чертеж монтажных поверхностей
* Однополюсный
* Функциональная схема автоматизации
* Топология.
