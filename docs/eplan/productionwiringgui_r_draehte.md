# Вкладка "Провода" / вкладка "Одиночные жилы"

* Файл > Настройки > Компания > Сборка проводов > "Машина" > вкладка Провода / вкладка Одиночные жилы
* Файл > Экспортировать > группа команд Данные изготовления > Сборка проводов > "Машина". Нажмите рядом с полем Схема на кнопку ++...++. Выберите вкладку Провода или вкладку Одиночные жилы (только для Komax — Zeta).

Возможности настройки на вкладке Провода или вкладка Одиночные жилы различаются в зависимости от используемой машины:
