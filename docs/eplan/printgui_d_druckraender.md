## Диалоговое окно Настройки: Границы печати

Вы открыли проект. Файл > Экспортировать > группа команд Данные проекта > Данные проекта > Групповое поле Страница > PDF > Кнопка [Настройки] > Поля для печати.

В этом диалоговом окне отображаются и могут быть изменены настройки печати, связанные с экспортом PDF. Выполненные здесь изменения также передаются непосредственно в настройки печати (Файл > Печать > Групповое поле Страницы > [Настройки]).

Обзор основных элементов диалогового окна:

Слева/ справа / вверху / внизу:

Здесь для всех четырех границ страницы устанавливается область, в которой печать не производится. Соответствующие отображаемые здесь единицы берутся из настроек проекта. Ввод может быть в мм и в дюймах.

Позиция печати:

Здесь задается положение PDF-страницы на листе при печати. При этом учитываются указанные границы печати. Выберите из раскрывающегося списка нужное положение.
