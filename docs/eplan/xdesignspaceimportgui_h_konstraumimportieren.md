## Импортировать пространство конструкции

Eplan Design Space Exchange используется в 3 следующих рабочих этапа.

* Импорт пространств конструкции в качестве файлов STEP из программ 3D-CAD.
* Создание чертежа монтажных поверхностей в Eplan Pro Panel.
* Экспорт расширенного за счет чертежа монтажных поверхностей и данных ЧУ пространства конструкции в программу 3D-CAD.

Далее описывается первый рабочий этап — импорт файлов STEP.

Настройки для импорта STEP выполняются в специфических для пользователя настройках (Файл > Настройки > Пользователь > Интерфейсы > Импорт и экспорт пространства конструкции).

Условие:

Вы открыли проект. Открыт навигатор пространства листа.

1. Выберите следующие команды: Файл > Импортировать > группа команд Данные проекта > Пространство листа > Пространство конструкции.
2. Выберите в диалоговом окне Открыть файл STEP, генерированный программой 3D-CAD.
3. Выберите в диалоговом окне Импорт пространства конструкции схему с настройками для импорта выбранного исходного файла или откройте с помощью кнопки [...] диалоговое окно настроек, чтобы изменить настройки.
4. Щелкните по кнопке [OK].  

Откроется диалоговое окно Импорт пространства конструкции — определить функциональные элементы.
5. При необходимости перезапишите настройки из схемы импорта и укажите поверхность установки.

!!! warning "Предупреждение:"

6. Щелкните по кнопке [OK].  

Данные 3D-графики импортируются из файла STEP в отдельное пространство листа. В навигаторе пространства листа появляется узел электрошкафа, в котором все функциональные элементы расположены без вложенности.

!!! note "Замечание:"

    Импортированная геометрия частично защищена от изменений. Можно изменятьсвойствафункциональных элементов, но нельзя удалять или перемещать функциональный элементы.

7. Создайте в импортированном пространстве конструкции чертеж монтажных поверхностей с функциональностью Eplan Pro Panel. В зависимости от настроек в схеме импорта вам, возможно, потребуется внести всего лишь некоторые коррективы.
