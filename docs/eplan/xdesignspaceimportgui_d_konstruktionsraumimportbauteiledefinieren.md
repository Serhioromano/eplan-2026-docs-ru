## Диалоговое окно "Импорт пространства конструкции — определить функциональные элементы"

Файл > Импортировать > группа команд Данные проекта > Пространство листа > Пространство конструкции

Вы выбрали файл STEP для импорта. В диалоговом окне Импорт пространства конструкции вы выбрали схему и нажали кнопку ++OK++.

В этом диалоговом окне вы указываете, какие определения функций и функциональные элементы должны назначаться импортированным трехмерным телам в Eplan при импорте файлов STEP с пространствами конструкции.

!!! note "Замечание:"

Обзор основных элементов диалогового окна:

В следующий полях выполните настройки присвоения:

* Предв. просмотр: Отображается предварительный просмотр импортированного трехмерного тела с выполненными настройками.
* Описание функционального элемента: Отображается внутризаводское обозначение функционального элемента, используемое для данного трехмерного тела в CAD-системе, из которой выполнялся экспорт.
* Определение функции: Выберите определение функции, которое должно присваиваться трехмерному телу, экспортированному из CAD-системы при импорте в Eplan, например: "Стенка". С помощью кнопки ++...++ можно открыть диалоговое окно Определения функций.
* Функциональный элемент: Выберите для определения функции подходящий функциональный элемент, который должен присваиваться трехмерному телу, экспортированному из CAD-системы при импорте в Eplan, например: "Боковая стенка справа".

!!! note "Замечание:"

    Геометрической модели, содержащейся в файле STEP, при импорте автоматически назначается определение функции "Электрошкаф".

* Выбрать поверхность установки для электрошкафа: Щелкните по пиктограмме, чтобы указать поверхность установки для электрошкафа. Предварительный просмотр электрошкафа и изображения функциональных элементов для предварительного просмотра будут автоматически скорректированы с учетом этой настройки.
