# Выделить потенциалы, сигналы или сеть

Потенциалы и сигналы можно временно выделять цветом, что позволяет быстро просматривать их расширение. Текущий выбранный потенциал / сигнал / сеть выделяются заданным в настройках пользователя цветом.

Ниже описан процесс выделения потенциалов; сигналы и сети можно выделять аналогичным образом: вкладка **Вид** > группа команд **Общее** > **Отслеживание сигнала** или **Отслеживание сети**.

Условие:

В настройках пользователя ( **Файл** > **Настройки** > **Пользователь** > **Графическая обработка** > **2D** в раскрывающемся списке **Отслеживание потенциала**) задан цвет для выделения потенциала / сигнала / сети.

1. На вкладке **Вид** в группе команд **Общее** нажмите кнопку **Отслеживание потенциалов**.
2. Щелкните по символу соединения или по линии соединения.

![](images/arrow.png) Eplan найдет соответствующий потенциал и полностью выделит его цветом (т.е. также и за пределами страницы).
3. Щелкните по другому соединению.

![](images/arrow.png) Выделение цветом будет снято с предыдущего потенциала, будет выделен потенциал, связанный с этим соединением.
4. Отожмите кнопку **Отслеживание потенциалов**.

![](images/arrow.png) Выделение потенциала цветом снимается.

!!! note "Замечание:"

* Потенциалы, сигналы и сети выделяются цветом тогда, когда соединения являются актуальными. Следите за тем, чтобы данные потенциала записывались на соединения только при обновлении соединений для всего проекта. При смене страницы обновляются только данные соединений.
* После завершения отслеживания потенциала, сигнала или сети посредством кнопки ++"Esc"++ или пункта всплывающего меню **Прервать операцию** для повторного выделения цветом потенциала / сигнала / сети необходимо отключить и вновь включить отслеживание (например, посредством следующих команд: вкладка **Вид** > группа команд **Общее** > **Отслеживание потенциалов**).
