# Диалоговое окно XML-проект

Существует (по меньшей мере) один проект с расширением имени файла *.epj, который был экспортирован ранее.

* Файл > Импортировать > группа команд Данные проекта > Данные проекта > группа команд Проект > Проект. Выберите в диалоговом окне Импортировать проект файл и нажмите на кнопку ++Открыть++.
* Файл > Управление проектами > кнопка ++Организовать++ > Импортировать. Выберите в диалоговом окне Импортировать проект файл и нажмите на кнопку ++Открыть++.

В этом новом диалоговом окне установите настройки для импорта XML проекта.

Обзор основных элементов диалогового окна:

### XML-файл:

Введите здесь дисковод, каталог и имя импортируемого XML-файла или нажмите на кнопку ++...++, чтобы выбрать файл в интерактивном режиме.

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути, специфических для Eplan.

### Выполнить синхронизацию изделий:

Установите этот флажок, если при импорте необходимо автоматически выполнить синхронизацию изделий. В этом случае индикатор выполнения отобразит ход синхронизации.

### Целевой проект:

Введите здесь дисковод, каталог и имя проекта, в который необходимо импортировать данные, или нажмите на кнопку ++...++, чтобы выбрать файл в интерактивном режиме.

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути, специфических для Eplan.
