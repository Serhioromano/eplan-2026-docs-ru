## Вкладка Обзор

Вкладка Основные данные > группа команд Изделия > Управление. Через меню ++Дополнительно++ > Настройки была открыта база данных изделий. В дереве или списке выделено одно изделие. Выберите вкладку Обзор.

На этой вкладке отображаются наиболее важные свойства и — при наличии — изображения для предварительного просмотра изделия. Здесь невозможно обрабатывать свойства.

Если здесь не отображаются нужные вам свойства, необходимо выбрать или создать схему с соответствующими конфигурациями свойств в поле Вид.

Обзор основных элементов диалогового окна:

Вид:

Выберите для отображения свойств схему из раскрывающегося списка. Откройте с помощью кнопки ++...++ диалоговое окно [Конфигурировать свойства](modaldialogsdb_d_eigenschaftskonfiguration.md). Здесь с помощью схемы с несколькими конфигурациями свойств вы можете указать, какие свойства должны отображаться на вкладке Обзор и в какой последовательности.

!!! note "Замечание:"

    Схемы, созданные на этой вкладке, недоступны на вкладке Свойства.

Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).

Предв. просмотр:

В предварительном просмотре для одного или нескольких выбранных изделий отображаются все изображения и макросы, связанные с этими изделиями. Например, графический файл для изделия хранится в свойстве Графический файл, а 3D-макрос для трехмерного чертежа монтажных поверхностей — в свойстве Графический макрос.

Если проект не открыт, в предварительном просмотре отображаются только графический файл изделия и графический макрос (3D-макрос). Если проект открыт, то для изделия с присвоенным макросом отображаются три плитки с рисунками (например, графический файл, многополюсный макрос схемы соединений и графический макрос).

Если для одного или нескольких выделенных изделий имеется больше трех рисунков, рисунки можно выбирать с помощью полосы прокрутки. К отображению рисунков (при их наличии) применяется указанная ниже последовательность:

* Графический файл
* 2D-макрос схемы соединений во всех видах представления и во всех вариантах
* Графический макрос (3D-макрос)

Если в представлении в виде дерева или списка выбрано несколько изделий, то все виды представления и варианты для каждого изделия всегда отображаются в плитках один за другим. Сразу за ними без перерыва отображаются рисунки последующих изделий.
