# Выравнивание элементов по горизонтали / вертикали в пространстве листа

При помощи команд Выровнять по горизонтали и Выровнять по вертикали разместите несколько выделенных 3D-размещений изделий на горизонтальной или вертикальной линии. Для этого выравниваемые 3D-объекты должны лежать на одной общей монтажной поверхности или одной несущей шине. Линия получается из центра двух расположенных далее всего друг от друга элементов. Выравнивание объектов, расположенных на различных монтажных поверхностях, не имеет смысла. Поэтому функция выравнивания недоступна, если были выделены объекты, не лежащие на одной общей монтажной поверхности или несущей шине.

!!! note "Замечание:"

    Обратите внимание, что после этого действия необходимо выполнить команду Выровнять по сетке, чтобы снова разместить точки вставки на сетке.

Условие:

Вы открыли пространство листа. Вы выбрали трехмерную точку наблюдения "Впереди".

1. Выберите соответствующие 3D-объекты.
2. Выберите следующие команды: Вкладка Обработать > группа команд Упорядочить > Выровнять по горизонтали.
Или выберите: вкладка Обработать > группа команд Упорядочить > раскрывающаяся кнопка Выровнять по горизонтали > Выровнять по вертикали.

!!! info "Для сведения:"

    Eplan определяет средние точки двух наиболее удаленных друг от друга трехмерных объектов и выравнивает все элементы по этой линии.
