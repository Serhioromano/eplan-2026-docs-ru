# Очистить проект

Условие:

Вы открыли проект и выделили его в Навигаторе страниц.

1. Выберите следующие команды: Файл > Дополнительно > группа команд Организовать > Проект > группа команд Оптимизировать > Очистить проект.
2. Нажмите в диалоговом окне Очистить проект рядом с полем Настройки на кнопку ++...++.
3. Если вы уже сохранили объем корректировки как схему, выберите в диалоговом окне Настройки: Очистить существующую схему из раскрывающегося списка. Либо нажмите на ![](images/all_new_as.png){ .ui-icon } (создать).
4. В диалоговом окне Новая схема в поле Имя введите информативное имя, а в поле Описание – краткий текст описания схемы, после чего нажмите кнопку ++OK++.
5. Чтобы выбрать данные проекта для [корректировочных настроек](ProjectCorrectionGui_k_korrekturdaten.md), установите в диалоговом окне Настройки: Очистить в поле Объем соответствующий флажок.

!!! info "Для сведения:"

    Если флажок установлен для узла, все нижестоящие флажки активируются автоматически.

6. Щелкните по кнопке ![](images/all_save_as.png){ .ui-icon } (Сохранить).
7. Щелкните по кнопке ++OK++.
