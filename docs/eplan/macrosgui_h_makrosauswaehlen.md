## Вставить макросы

Макросы могут быть вставлены на странице проекта как макрос окна или символа. При вставке макросов страниц появляются новые страницы проекта.

При вставке макросы всегда разворачиваются, однако с помощью объектов-заполнителей можно изменить записи данных.

### Вставить макросы окон и макросы символов

Условия:

  * В Графическом редакторе открыта страница проекта.
  * С помощью команд Файл > Настройки > Пользователь > Графическая обработка > Макросы в групповом поле Открыть окно выбора набора значений объектов-заполнителей вы установили флажок При вставке макросов окна.


  1. Выберите следующие команды: Центр вставки > строка навигации Главная > Макросы окна / символа.
  2. Перейдите через структуру папок к нужному макросу окна / символа.  

  3. Если выбранный макрос имеет варианты, нажмите на пиктограмму количества вариантов в правом верхнем углу плитки предварительного просмотра макроса.  
  
В предварительном просмотре все варианты макросов отображаются в виде плиток.
  4. Нажмите на плитку нужного варианта макроса.  
  
Макрос прикрепляется к курсору и может быть размещен в любом месте (один щелчок мышью).  
  
При наличии наборов значений выберите в диалоговом окне Выбрать набор значений — <имя заполнителя> соответствующий набор значений для объекта-заполнителя. Вставленные условные обозначения содержат соответствующие данные из набора значений.  
  
Если в макросе присутствуют ОУ и с помощью команд Файл > Настройки > Проекты > "Имя проекта" > Устройства > Нумерация (online) в групповом поле При вставке макросов и копий активирован параметр С запросом, Eplan откроет диалоговое окно [Режим вставки](numerationgui_d_einfuegemodus.htm). В нем можно указать, каким образом должна быть выполнена нумерация ОУ во вставленном макросе.
  5. Макрос все еще прикреплен к курсору. При необходимости вставьте макрос еще раз.
  6. Завершите операцию, выбрав пункт всплывающего меню Прервать операцию или нажав клавишу [Esc].



!!! note "Замечание:"

    




### Вставить макросы страниц

  1. Выберите следующие команды: Вкладка Главная > группа команд Страница > раскрывающаяся кнопка Макрос страницы > Вставить или в порядке альтернативы воспользуйтесь для этого в навигаторе страниц пунктом всплывающего меню Вставить макрос символа.
  2. В диалоговом окне выбора выберите требуемый макрос / требуемые макросы. (Для макросов страницы возможен многократный выбор!) При этом в поле Тип файла в качестве критерия выбора можно настроить не только макросы страниц (*.emp), но и макросы окон (*.ema) или макросы символов (*.ems).
  3. Щелкните по кнопке [Открыть].
  4. В диалоговом окне Адаптировать структуру укажите порядок новых страниц в структуре страниц проекта.   
  
В зависимости от количества вставляемых макросов страницы это диалоговое окно отображается многократно (для каждого отдельного макроса).
  5. Щелкните по кнопке [OK]. Далее выполняются те же действия, что и при копировании страниц (см. [Адаптировать структуру](pagebrowsergui_h_seitenstrukturanpassen.htm)).   
  
Страницы генерируются или перезаписываются.



!!! note "Замечание:"

    


 

!!! tip "Совет:"

    Макросы можно вставить с помощью перетаскивания мышью, переместив выделенный файл из Windows Explorer в графический редактор или в навигатор страниц проекта. Здесь также возможен многократный выбор длямакросов страницы.
