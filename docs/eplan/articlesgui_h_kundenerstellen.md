# Создать основные персональные данные

!!! warning "Предупреждение:"

    Персональные основные данные можно просматривать и обрабатывать только в структуре дерева, список показывает только данные изделий, но не производителей, поставщиков и клиентов.

Условия:

* Вы открыли диалоговое окно **База данных изделий** (вкладка **Основные данные** > группа команд **Изделия** > **Управление**).
* В структуре дерева выделен уровень иерархии "Клиент" или "Производитель / поставщик", или запись данных под этими уровнями иерархии.

1. Выберите пункт всплывающего меню **Создать**.

!!! info "Для сведения:"

    Eplan автоматически генерирует новую запись данных с кратким именем `Создать_<порядковый_номер>`.

2. Перейдите справа в диалоговом окне на вкладку **Свойства**.
3. Измените автоматически назначенную запись для свойства **Краткое имя** на уровне иерархии **Данные**.
4. Введите дополнительные данные клиента или производителя / поставщика на вкладке **Свойства** (например, полное имя).
5. Нажмите на ++"Применить"++, чтобы сохранить введенные данные и изменения, не выходя из базы данных изделий.

!!! note "Замечание:"

    Краткие имена клиентов и производителей / поставщиков должны быть однозначными. Если случайно введено имя, которое уже существует, Eplan укажет на это при нажатии кнопок ++"Применить"++, ++"Закрыть"++ или другое поле. Запись данных будет сохранена только после того, как будет указано новое имя.
