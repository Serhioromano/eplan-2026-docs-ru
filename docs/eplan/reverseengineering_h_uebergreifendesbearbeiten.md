# Общая обработка свойств на страницах отчетов

Функцию Общая обработка можно использовать для внесения на страницах отчетов изменений, которые сразу же применяются ко всем логическим страницам во всех представлениях.

!!! note "Замечание:"

* При изменении данных объекта на самой странице отчета обновляется строка или столбец, в котором находится объект. Обратите внимание, что другие страницы отчета, которые тоже могут содержать данные объекта, не изменяются. Возможно вам придется обновить эти отчеты.
* На страницах отчетов типа **Перечень форм**, **Перечень рамок**, **Обзор ревизий** и **Перечень символов** общая обработка недоступна.
* Отчеты, сгенерированные в другом проекте, утрачивают ссылку на первоначальные исходные объекты. Поэтому общая обработка на таких страницах недоступна.
* Некоторые записи на страницах отчетов не содержат ссылку на объект. На таких записях невозможно открыть диалоговое окно для обработки — тогда двойной щелчок всегда откроет диалоговое окно **Свойства — текст-заполнитель**.

Условие:

Вы открыли страницу отчета.

1. Выделите нужный текст-заполнитель на странице отчета.
2. Выберите пункт всплывающего меню **Свойства (общие)**.

!!! info "Для сведения:"

    Откроется диалоговое окно для обработки, связанное с исходным объектом.

3. Внесите нужные изменения в диалоговом окне.
4. Щелкните по кнопке ++"OK"++.

!!! info "Для сведения:"

    На странице отчета изменение применяется сразу. На всех логических страницах данные исходного объекта также автоматически обновляются во всех представлениях.

!!! example "Пример:"

    При просмотре открытого списка обозначений устройств вы обнаружите, что плавкий предохранитель имеет неправильное ОУ`-F25`. Разместите курсор наобозначение устройстваэтойфункциии выберите пункт всплывающего меню**Свойства (общие)**.Откроется диалоговое окно**Свойства (общие): Устройство общего назначения**. Нажмите на вкладке**Плавкий предохранитель (устройство)**в поле**Полное ОУ**и настройте, например, счетчикобозначенияустройствана`3`. После закрытия диалогового окна свойств нажатием кнопки ++"ОК"++ новое ОУ сразу же отобразится в списке обозначений устройств. Обозначение устройства также обновляется на всех других логических страницах, связанных с функцией (например, многополюсная схема соединений).Вспецификацииизделий проекта для плавкого предохранителя все еще указано неправильное ОУ. Обновите эту страницу, например, вручную. Для этого выделите спецификацию изделий в навигаторе страниц и выберите следующие команды: вкладка**Инструменты**> группа команд**Отчеты**>**Обновить**. Спецификация изделий теперь также имеет правильное ОУ.

Если вы активировали режим Свойства (общие) (командный путь: вкладка **Обработать** > группа команд **Параметры** > **Общие**), вы сможете открыть соответствующее диалоговое окно для обработки исходного объекта, дважды щелкнув по тексту заполнителю. Если этот режим не активирован, то двойным щелчком запустится диалоговое окно **Свойства — текст-заполнитель**.

!!! example "Пример:"

    Вы открыли страницу содержания проекта и хотите изменить описание страницысхемы соединений`Электропитание`. Для этого нажмите на вкладке**Обработать**в группе команд**Параметры**кнопку**Общие**. Затем дважды щелкните на странице отчета по изменяемому тексту. Открывается диалоговое окно**Свойства страницы**. После изменения текста в поле**Описание страниц**на`Электропитание рабочей станции 1`нажмите на кнопку ++"ОК"++. Новый текст для страницы отображается в содержании, в навигаторе страниц и в рамке страницысхемысоединений изменение сразу же обновляется.

!!! tip "Совет:"

    Можно настроить Eplan так, чтобы существующие страницы отчетов автоматически обновлялись при открытии. Активируйте для этого настройку пользователя **Обновить отчеты при открытии страниц** (командный путь: **Файл** > **Настройки** > **Пользователь** > **Отображение** > **Общее**).
