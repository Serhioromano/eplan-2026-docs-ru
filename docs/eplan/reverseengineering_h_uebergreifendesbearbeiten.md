## Общая обработка свойств на страницах отчетов

Функцию Общая обработка можно использовать для внесения на страницах отчетов изменений, которые сразу же применяются ко всем логическим страницам во всех представлениях.

!!! note "Замечание:"

    

 

Условие:

Вы открыли страницу отчета.

1. Выделите нужный текст-заполнитель на странице отчета.
2. Выберите пункт всплывающего меню Свойства (общие).  
  
Откроется диалоговое окно для обработки, связанное с исходным объектом.
3. Внесите нужные изменения в диалоговом окне.
4. Щелкните по кнопке [OK].  
  
На странице отчета изменение применяется сразу. На всех логических страницах данные исходного объекта также автоматически обновляются во всех представлениях.

!!! example "Пример:"

    При просмотре открытого списка обозначений устройств вы обнаружите, что плавкий предохранитель имеет неправильное ОУ-F25. Разместите курсор наобозначение устройстваэтойфункциии выберите пункт всплывающего менюСвойства (общие).Откроется диалоговое окноСвойства (общие): Устройство общего назначения. Нажмите на вкладкеПлавкий предохранитель (устройство)в полеПолное ОУи настройте, например, счетчикобозначенияустройствана3. После закрытия диалогового окна свойств нажатием кнопки[ОК]новое ОУ сразу же отобразится в списке обозначений устройств. Обозначение устройства также обновляется на всех других логических страницах, связанных с функцией (например, многополюсная схема соединений).Вспецификацииизделий проекта для плавкого предохранителя все еще указано неправильное ОУ. Обновите эту страницу, например, вручную. Для этого выделите спецификацию изделий в навигаторе страниц и выберите следующие команды: вкладкаИнструменты> группа командОтчеты>Обновить. Спецификация изделий теперь также имеет правильное ОУ.

 

Если вы активировали режим Свойства (общие) (командный путь: вкладка Обработать > группа команд Параметры > Общие), вы сможете открыть соответствующее диалоговое окно для обработки исходного объекта, дважды щелкнув по тексту заполнителю. Если этот режим не активирован, то двойным щелчком запустится диалоговое окно Свойства — текст-заполнитель.

!!! example "Пример:"

    Вы открыли страницу содержания проекта и хотите изменить описание страницысхемы соединенийЭлектропитание. Для этого нажмите на вкладкеОбработатьв группе командПараметрыкнопкуОбщие. Затем дважды щелкните на странице отчета по изменяемому тексту. Открывается диалоговое окноСвойства страницы. После изменения текста в полеОписание страницнаЭлектропитание рабочей станции 1нажмите на кнопку[ОК]. Новый текст для страницы отображается в содержании, в навигаторе страниц и в рамке страницысхемысоединений изменение сразу же обновляется.

 

!!! tip "Совет:"

    Можно настроить Eplan так, чтобы существующиестраницы отчетовавтоматически обновлялись при открытии. Активируйте для этого настройку пользователяОбновить отчеты при открытии страниц(командный путь:Файл>Настройки>Пользователь>Отображение>Общее).
