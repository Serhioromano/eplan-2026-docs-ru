## Диалоговое окно Экспорт ЧУ Steinhauer

[Вызов диалогового окна:](javascript:void\(0\);)

Вы открыли проект. В пространстве листа или навигаторе пространства листа выделены объекты, для которых необходим экспорт ЧУ. Файл > Экспортировать > группа команд Данные изготовления > Механическая обработка > Steinhauer - ModCenter.

В этом диалоговом окне устанавливаются настройки для экспорта данных ЧУ в формате 'Steinhauer'.

Обзор основных элементов диалогового окна:

Машина:

В комплекте поставки содержится определение машины с названием "Стандарт". Если в настройках фирмы определены другие схемы, можно выбрать из раскрывающегося списка другие определения машины.

Кнопка [...] открывает диалоговое окно Настройки: Экспорт ЧУ Steinhauer, в котором можно изменить настройки схемы или определить новую схему.

Каталог вывода:

В этом поле выводится место хранения. Здесь по умолчанию выбран каталог, который указан в фирменных настройках для экспорта ЧУ Steinhauer.

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.htm), из которого можно будет скопировать одну из доступных переменных пути.

Целевой файл:

Данное поле доступно только в том случае, если выбраны объекты, которые могут быть экспортированы (например, монтажная плата). Здесь можно ввести или выбрать с помощью кнопки  в диалоговом окне Сохранить как имя генерируемого файла CNC. При наличии нескольких файлов поле деактивируется и действуют условия создания названий файлов и подкаталогов, определенные в схеме.
