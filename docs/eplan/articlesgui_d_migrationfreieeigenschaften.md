## Диалоговое окно Перенести произвольные свойства

Вкладка Основные данные > группа команд Изделия > Управление. Через меню [Дополнительно] > Настройки была открыта база данных изделий. Кнопка [Дополнительно] > Перенести произвольные свойства.

В этом диалоговом окне отображаются устаревшие произвольные свойства, имеющиеся в настроенной базе данных изделий. Вы можете решить, нужно ли перенести произвольное свойство в определенное пользователем свойство, удалить произвольное свойство или оставить его в базе данных изделий.

При переносе вам будет оказана поддержка, например, в виде возможности выбора уже существующих определенных пользователем свойств. Это удобно в том случае, если вы подготовили определенные пользователем свойства с нужными отображаемыми именами и конфигурациями и всего лишь хотите изменить присвоение к изделию. Тогда при переносе изделию присваивается определенное пользователем свойство и туда вводится значение произвольного свойства.

Обзор основных элементов диалогового окна:

В таблице выше показаны все имеющиеся произвольные свойства. В левой области таблицы Произвольн. свойства отображается информация о соответствующем произвольн. свойстве, такая как отображаемое имя. В правой области таблицы Определенные пользователем свойства отображаются идентифицирующее имя и прочая информация о соответствующем генерируемом или уже имеющемся определенном пользователем свойстве.

Область таблицы Произвольные свойства:

* Отображаемое имя: Показывает отображаемые имена произвольных свойств.
* Положение свойства: Показывает положения произвольных свойств в диалоговом окне Произвольн. свойства.
* Значения: Показывает значения произвольных свойств.
* Единица: Показывает единицы измерения для значений произвольных свойств.

Операция:

В этом столбце вы указываете, какая операция должна быть выполнена для соответствующего произвольного свойства:

* Нет: Произвольное свойство остается в базе данных изделия в неизменном виде. Выберите этот параметр, если пока не хотите переносить или удалять произвольное свойство.
* Удалить: Произвольное свойство будет удалено в соответствующем изделии. При следующем запуске диалогового окна удаленные произвольные свойства больше не будут доступны.
* Перенести: Произвольное свойство переносится в определенное пользователем свойство. Вы можете либо создать новое определенное пользователем свойство, либо выбрать уже имеющееся. Для этого будет разблокировано поле в столбце Идентифицирующее имя, и вы можете ввести новое идентифицирующее имя или с помощью диалогового окна выбора выбрать имя уже имеющегося свойства.  
Произвольное свойство не удаляется в результате операции "Перенести" и остается по-прежнему доступным.

Область таблицы Определенные пользователем свойства:

Если выбраны операции "Нет" или "Удалить", то поля в следующих столбцах для соответствующего произвольного свойства будут неактивными и не могут быть изменены.

* Идентифицирующее имя: Показывает идентифицирующее имя определенного пользователем свойства. Если выбрана операция "Перенести", то здесь можно ввести новое имя в соответствии с форматом идентифицирующих имен ("Область имени.Имя").   
Или вы можете нажать на кнопку […] в ячейке для идентифицирующего имени, чтобы перейти в диалоговое окно Выбрать свойства и выбрать имя уже существующего определенного пользователем свойства.
* Тип поля: Показывает тип поля определенного пользователем свойства. Доступно только в том случае, если в столбце Идентифицирующее имя введено новое идентифицирующее имя.
* Группа единиц измерения: Показывает группу единиц измерения для определенного пользователем свойства. Доступно только в том случае, если в столбце Идентифицирующее имя введено новое идентифицирующее имя или если в качестве типа поля выбран пункт "Значение с единицей измерения".
* Тип отображения: Показывает тип отображения определенного пользователем свойства. Доступно только в том случае, если в столбце Идентифицирующее имя введено новое идентифицирующее имя.

Использование таблицы:

При выборе произвольного свойства в верхней таблице здесь отображаются изделия, которые используют данное произвольное свойство (т.е. которым было назначено это произвольное свойство). Это позволяет более наглядно оценить результаты переноса.

* Номер изделия: Показывает номер изделия, которому было назначено выбранное произвольное свойство.
* Вариант: Показывает вариант изделия.
* Положение свойства: Показывает положения произвольных свойств в диалоговом окне Произвольн. свойства.
* Значения: Показывает значения произвольных свойств.
* Единица: Показывает единицы измерения для значений произвольных свойств.

Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](eplan/userinterface_m_kontextmenu.md).

Выполнение переноса

Когда диалоговое окно переноса закрывается кнопкой [OK], выполняется перенос для произвольных свойств с выбранной операцией "Перенести". При создании нового определенного пользователем свойства отображаемое имя произвольного свойства становится отображаемым именем нового определенного пользователем свойства.

Независимо от того, создано ли при переносе новое определенное пользователем свойство или использовано существующее, данные переносятся в изделия, использующие это произвольное свойство. Этим изделиям присваивается соответствующее определенное пользователем свойство, и значение произвольного свойства вводится в это определенное пользователем свойство.

Произвольное свойство при переносе не удаляется и продолжает отображаться в диалоговом окне Перенести произвольные свойства. Чтобы удалить произвольное свойство, выберите операцию "Удалить" в диалоговом окне переноса или удалите его вручную во всех соответствующих изделиях в диалоговом окне Произвольн. свойства.
