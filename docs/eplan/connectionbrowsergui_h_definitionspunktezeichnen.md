## Чертить точки обозначения соединения

Соединения получают дополнительные свойства посредством точек определения соединений.

  1. Выберите следующие команды: Вкладка Вставить > группа команд Кабели / соединения > Соединение.
  2. Разместите точку определения соединения на линии автоматического соединения.
  3. В диалоговом окне Свойства <...> во вкладке [Точка определения соединения](devicetaggui_r_vdp.htm) введите свойства соединения (а при необходимости и другие свойства в других вкладках).
  4. Щелкните по кнопке [OK].  
  
Свойства присваиваются соединению, проходящему через точку определения соединения.
