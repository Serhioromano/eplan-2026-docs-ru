## Отображать внешние цели

Кнопка Внешние цели на вкладке Вид упрощает нахождение внешних целей: если она активирована, внешние выводы функций обозначаются стрелкой. Это упрощает, например, отслеживание цели в случае с клеммами. Благодаря этому можно узнать, на какой странице спецификации клеммника выведена цель.

Свойство Внутр. / внешн. настройте в диалоговом окне [Логическая схема выводов устройства](eplan/xfctdefbrowsergui_d_anschlusslogik.md), которое вызывается в диалоговом окне свойств на вкладке Данные символа / функции с помощью кнопки [Логика].

Условие:

Вы открыли проект. В Графическом редакторе открыта страница проекта.

1. Активируйте на вкладке Вид в группе команд Общее кнопку Внешние цели.  
  
Внешние выводы функций обозначаются маленькой стрелкой.
2. Деактивируйте кнопку Внешние цели.  
  
Стрелки для отображения внешних выводов снова скрыты.
