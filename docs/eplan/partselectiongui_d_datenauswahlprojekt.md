# Диалоговое окно Настройки: Выбор изделия (проект)

Вы открыли проект.

* Файл > Настройки > Проекты > "Имя проекта" > Управление > Изделия.
* Вы выделили главную функцию в графическом редакторе или навигаторе. Пункт всплывающего меню Свойства. Выберите вкладку Изделия Кнопка ++Настройки++ > Выбор изделия (проект).

В этом диалоговом окне для всего проекта устанавливается, какой источник данных используется для выбора изделия.

Обзор основных элементов диалогового окна:

### Выбор изделия:

Выберите одну из следующих опций:

* Определ. пользователем: для выбора изделия используются специфические для пользователя настройки, заданные через Файл > Настройки > Пользователь > Управление > Выбор изделия.
* Проект: При выборе изделий предлагаются только такие изделия, которые сохранены в проекте. Этот выбор изделий заполняется данными с помощью синхронизации изделий между базой данных изделий и проектом.

### Предварительный выбор изделий:

Выберите имеющуюся схему (т. е. список изделий) из раскрывающегося списка. Затем при выборе изделий предлагаются только те изделия, которые имеются в выбранном списке.

С помощью [...] откройте диалоговое окно Предварительный выбор изделий, где можно создать новый список изделий и сохранить его как схему или изменить имеющийся список.

!!! note "Замечание:"

    Предварительный выбор изделий влияет на [центр вставки](insertergui_k_start.md). С его помощью можно, например, ограничить предлагаемые для вставки устройства определенными изделиями с помощью соответствующей схемы.
