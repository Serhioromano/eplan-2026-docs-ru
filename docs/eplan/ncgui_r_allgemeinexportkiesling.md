## Вкладка Общее (экспорт Rittal - Perforex BC / Secarex)

* Файл > Настройки > Фирма > Механическая обработка > Экспорт Rittal - Perforex BC / Secarex. Выберите вкладку Общее.
* Файл > Экспортировать > группа команд Данные изготовления > Механическая обработка > Rittal - Perforex BC. Нажмите рядом с полем Машина на кнопку ++...++. Выберите вкладку Общее

На этой вкладке задайте общие настройки для экспорта ЧУ во фрезерный обрабатывающий станок Rittal — Perforex BC / листорезный станок Secarex AC 18.

Обзор основных элементов диалогового окна:

Формат:

Управление машинами Perforex BC может осуществляться в следующих форматах:

* DOS,
* Windows до 1.9x
* Windows от 1.9x

Содержащийся в обоих форматах Windows номер версии указывается на программном обеспечении машины Perforex. Таким образом не указывается версия операционной системы Windows.

Префикс:

Здесь вы можете указать символ или строку символов, которые в экспортируемом файле ЧУ ставятся перед записями для генерирования имени контура Perforex. По умолчанию используется настройка "BC_".

Префикс для контуров действует также для идентификатора поля Функциональный элемент / Изменяемый функциональный элемент - Имя на вкладке [Идентификатор поля](ncgui_r_feldbezeichner.md), если соответствующая настройка для генерирования установлена на "Автоматически".

Объем:

Для листорезного станка Secarex AC 18 используется интерфейс экспорта для фрезерного обрабатывающего станка Rittal — Perforex BC. Для функциональных элементов с переменной длиной, например, кабельных каналов или несущих шин, которые, например, наклеиваются на монтажную поверхность или размещаются на держателях, отверстия не предусмотрены. Поэтому экспорт координат отверстий в листорезный станок Secarex AC 18 не требуется.

С помощью раскрывающегося списка можно задать, следует ли учитывать следующую информацию о конкретном станке при экспорте данных изготовления:

* Только Perforex: Экспортируются все данные для механической обработки корпусов и плоских деталей.
* Только Secarex: Экспортируются все данные для резки кабельных каналов, несущих шин и профильных C-шин.
* Perforex и Secarex: Экспортируются все данные для механической обработки корпусов и плоских деталей, а также для резки кабельных каналов, несущих шин и профильных C-шин.

Каталог вывода:

Выберите каталог, в котором следует разместить экспортируемые файлы. Рабочее место в мастерской возле машины должно иметь доступ к этому каталогу.

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

Генерировать имена файлов:

С помощью записи "Из свойств" при экспорте ЧУ имя файла составляется из свойств пространства листа и проекта, а также свободно определяемого разделителя. Используя кнопку ++...++, откройте диалоговое окно Формат: Свойство для конфигурации имени файла.

Генерировать подкаталоги:

В этом раскрывающемся списке можно задать стандартный порядок создания подкаталогов при экспорте ЧУ:

* Нет: Если выбран данный параметр, при экспорте подкаталоги не генерируются.
* Из свойств: Если выбран этот параметр, имя подкаталога составляется из свойств пространства листа и проекта, а также свободно определяемого разделителя. При нажатии кнопки ++...++ открывается диалоговое окно Формат: Свойство для конфигурации имени каталога. Воспользуйтесь, например, элементом формата "Разделитель каталога", чтобы создать структуру каталога с несколькими подкаталогами, расположенными друг под другом.

Таблица номеров материала

При использовании формата экспорта "Windows от 1.9x" доступны до 10 различных номеров материала, которые можно присвоить обрабатываемым материалам. Все присвоенные материалы на вкладке Инструменты можно также назначить для отдельных инструментов. Это назначение относится только к фрезе. Вводится соответствующий номер материала.

При использовании форматов экспорта "DOS" и "Windows до 1.9x" определимы три номера материала. Назначение данных номеров материала для отдельных инструментов в этих форматах экспорта невозможно.

При экспорте этот номер будет выбран и перенесен в машину. Эти настройки необходимо синхронизировать с настройками на машине. По умолчанию первые три номера материала заданы следующим образом:

* Номер материала 1: таль
* Номер материала 2: высококач. сталь
* Номер материала 3: алюминий.
