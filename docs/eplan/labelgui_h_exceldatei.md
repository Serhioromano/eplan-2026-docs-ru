# Определить настройки вывода Excel

Условия:

* Вы открыли проект.
* Задан шаблон Excel.

1. Выберите следующие команды: **Файл** > **Экспортировать** > группа команд **Данные изготовления** > **Данные изготовления** > **Маркировки**.
2. В диалоговом окне **Экспортировать данные изготовления / Вывести маркировку** рядом с полем **Настройки** щелкните по кнопке ++"..."++.
3. В диалоговом окне **Настройки: Экспорт данных изготовления / маркировка** в поле **Схема**, определенную пользователем.

![](images/arrow.png) При помощи ![](images/all_new_as.png) (Создать) можно [создать новую схему экспорта / маркировки](labelgui_h_beschriftungsschema.md).
4. Выберите на вкладке **Файл** в поле **Тип файла** тип файла "Файл Excel (*.xlsx, *.xlsm").
5. Нажмите рядом с полем **Целевой файл** на кнопку ![](images/all_selectfile_as.png) и выберите в открывшемся диалоговом окне каталог и файл или задайте в поле **Имя файла** имя для нового файла.
6. Нажмите рядом с полем **Шаблон** на кнопку ![](images/all_selectfile_as.png) и выберите через следующее диалоговое окно [шаблон Excel](labelgui_k_excelexportvorlagen.md).
