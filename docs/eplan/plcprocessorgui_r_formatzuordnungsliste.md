## Вкладка Формат списка присвоений

[Вызов диалогового окна:](javascript:void\(0\);)

Вы открыли проект. Файл > Настройки > Проекты > "Имя проекта" > Устройства > ПЛК. В диалоговом окне Настройки: ПЛК нажмите рядом с полем Специфические для ПЛК настройки на [...]. В диалоговом окне Настройки: Специфич. для ПЛК выберите вкладку Формат списка присвоений.

В этой вкладке вы определяете формат списка присвоений.

Обзор основных элементов диалогового окна:

Набор символов:

Выберите набор символов, в котором Вы хотите сохранить списки присовений. Доступные форматы — ANSI, ASCII (набор символов OEM 852) и UNICODE.

Разрешить умлауты:

Включите этот флажок, если хотите использовать умлауты в списках присвоений.

Если флажок выключен, умлауты заменяются при написании в списках присвоений.

Вывести элементы формата в виде заголовка:

Данный флажок доступен, только если вы экспортируете список присвоений в формат Excel.

Если флажок установлен, в первой строке файла экспорта в виде заголовка столбцов выводятся имена элементов формата.

Если флажок снят, файл экспорта не содержит заголовков столбцов.

Имя файла:

Укажите путь и имя файла списка присвоений вручную либо нажмите на , чтобы открыть диалоговое окно для выбора файла.

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.htm), из которого можно будет скопировать одну из доступных переменных пути.

Строка верхн. колонт.:

Здесь вы можете ввести текст, который появится в верхнем колонтитуле списка присвоений. При экспорте в формате Excel верхние колонтитулы не выводятся.

Строка нижн. колонт.:

Здесь вы можете ввести текст, который появится в нижнем колонтитуле списка присвоений. При экспорте в формате Excel нижние колонтитулы не выводятся.

Формат строки списка присвоений:

С помощью [...] откройте диалоговое окно Формат строки списка присвоений. Здесь можно изменить формат цифровых и аналоговых адресов ПЛК в строках списков присвоений.

Формат адреса списка присвоений:

С помощью [...] откройте диалоговое окно Формат адреса списка присвоений. Здесь можно изменить формат цифровых и аналоговых адресов ПЛК в адресах списков присвоений.
