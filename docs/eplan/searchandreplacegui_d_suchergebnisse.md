## Диалоговое окно Результаты поиска — <Имя проекта>

Вы открыли проект. Вкладка Главная > группа команд Поиск > Отобразить результаты.

В этом диалоговом окне отображается результат поиска.

Обзор основных элементов диалогового окна:

В строке заголовка диалогового окна указывается, к какому проекту относятся результаты поиска.

Вкладки "Список результатов" / "Перейти к"

С помощью этих вкладок в нижней части диалогового окна можно переходить из Список результатов в список Перейти к и наоборот.

Список Перейти к заполняется с помощью следующих команд: вкладка Главная > группа команд Поиск > раскрывающаяся кнопка Синхронизировать выбор > Перекрестная функция --> Список и Все представления.

Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).

Дополнительно здесь представлены следующие пункты всплывающего меню, специфические для данного диалогового окна:

Пункт меню |  Значение  
---|---  
Удалить |  Удаляет выделенную(ые) запись(и) из активного списка.  
Удалить все записи |  Удаляет все записи из активного списка.  
Поиск |  Открывает диалоговое окно Поиск. Там можно ввести новые критерии поиска и начать новый поиск.  
Заменить |  Открывает диалоговое окно Заменить. Там можно заменить значения найденных записей новыми.  
Перейти к (перекрестная ссылка) |  Заносит перекрестные функции в список Перейти к и открывает его.  
Перейти к (все виды представлений) |  Заносит все виды представлений функции (например, на странице схем соединений, странице обзора и странице отчета) в список Перейти к и открывает его.  
Перейти к (графика) |  Переход к выделенной записи. При размещенных объектах производится переход в графический редактор. При неразмещенных объектах переход не производится. При переходе к соединениям он производится к первой точке определения соединения. Если точка определения соединения отсутствует, переход производится к исходной функции.  
Табличная обработка |  Открывает табличную обработку и обеспечивает обработку свойств страниц и размещенных на них устройств.  
Свойства |  Открывает диалоговое окно свойств для выделенных элементов списка.  
Свойства (общие) |  Открывает выделенные элементы списка соответствующего диалогового окна для использования "Общей обработки". Если выбран объект, например, функция, открывается диалоговое окно Свойства (общие). В нем можно обработать свойства устройства.
