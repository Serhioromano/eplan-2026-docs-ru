# База данных изделий: Основные положения

### Принцип работы программы

Аналогично к другим исходным данным также для изделий в проекте сохраняется вся информация, необходимая для независимого использования проекта. Таким образом, всегда имеются две базы данных изделий (резервное хранение данных): центральная база данных изделий для всех проектов и внутренняя база данных покупных изделий, сохраненная в проект, которая содержит только установленные в проекте изделия.

В составе проекта обрабатываются изделия из внутренней базы данных покупных изделий, т. е., изделие, использованное 10 раз, сохраняется только один раз и обрабатывается в проекте 10 раз (через номер изделия). Измененные данные изделия могут также просто вводиться или синхронизироваться с центральной базой данных изделий.

Для базы данных изделий можно использовать либо внутренний формат Eplan, либо базы данных SQL. При этом данные сохраняются в вариантах изделий. Это дает вам возможность, например, хранить разные макросы на вариантах одного изделия.

### Структура окна базы данных изделий

Главное окно базы данных изделий разделено по вертикали. В левой части диалогового окна в дереве или списке отображаются управляемые данные, причем в дереве отображаются следующие уровни иерархии:

* Изделие; конфигурация отображенной иерархии [Конфигурация дерева](partsmanagementgui_d_baumkonfiguration.md)
* Список принадлежностей
* Размещение принадлежностей
* Схема сверления
* Схема соединений
* Клиент
* Производитель/поставщик.

На уровне иерархии "Изделие" изделия структурируются в соответствии с группировкой продуктов и подразделяются на различные разделы. Самый верхний уровень иерархии представлен главными группами продуктов, такими как "Электротехника", "Fluid", "Механика" или "Технология производственных процессов". Изделия главной группы продуктов "Механика" содержат общие и механические данные (например, данные Eplan Pro Panel). В главной группе продуктов изделия подразделяются на "отдельные части", "узлы" и "модули". При этом кабели и корпуса представлены в группе в виде отдельных частей.

В качестве последнего уровня иерархии в дереве на экран выводятся отдельные номера изделий. При наличии более одного варианта изделия эти варианты изображаются под изделием.

Также, помимо дерева, данные могут отображаться в списке, причем объем просматриваемых данных можно настроить с помощью пункта всплывающего меню Конфигурировать представление. В списке отображаются все изделия, но не отображаются производители, поставщики и клиенты.

В правой части этого диалогового окна отображается соответствующая информация о записях данных (например, изделиях, списках принадлежностей, клиентах), которые выделены в левой части. При этом имеются вкладки, которые доступны для всех типов изделий (например, Обзор, Свойства и т. д.), и вкладки, в которых имеются особые возможности ввода для определенного типа изделия (например, Модуль, Узел и т. д.).

### Индивидуализация структуры дерева

Чтобы иметь возможность структурировать изделия (и другие типы записей данных) в том числе в соответствии с видением клиента, можно адаптировать представление в виде дерева в соответствии с вашими потребностями (так называемая [Конфигурация дерева](partsmanagementgui_d_baumkonfiguration.md)). При этом можно создавать собственные уровни иерархии (узлы) для представления в виде дерева. В качестве последнего уровня иерархии в дереве отображаются индивидуальные номера изделий или (при наличии более одного варианта) обозначение варианта.
