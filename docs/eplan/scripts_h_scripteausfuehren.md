# Выполнить или загрузить сценарии

Простые сценарии, функция которых должна выполняться однократно, выполняются с помощью команды Выполнить в виде Backstage Дополнительно. Для идентификации соответствующей функции используется атрибут [Start]. Сценарии, функции которых должны быть доступны системе на долговременной основе, необходимо загружать. В данном случае для идентификации используются другие атрибуты.

### Выполнить сценарии

Условие:

Вы создали простой сценарий (с атрибутом [Start]) на языке программирования C# или Visual Basic.Net.

1. Выберите следующие команды: Файл > Дополнительно > группа команд Расширения > Интерфейсы > группа команд Сценарии > Выполнить.
2. Выберите в следующем диалоговом окне сценарий с Типом файла CSharp (*.cs) или VB.NET (*.vb).
3. Щелкните по кнопке ++Открыть++.

!!! info "Для сведения:"

    Сценарий выполняется.

Если при выполнении сценария возникает ошибка, она регистрируется в Системных сообщениях.

### Загрузить сценарии

Условие:

Вы создали более сложный сценарий (например, с собственными операциями) на языке программирования C# или Visual Basic.Net. В более сложных сценариях используются атрибуты [DeclareEventHandler], [DeclareAction] и / или ++DeclareMenu++.

1. Выберите следующие команды: Файл > Дополнительно > группа команд Расширения > Интерфейсы > группа команд Сценарии > Загрузить.
2. Выберите в следующем диалоговом окне сценарий с Типом файла CSharp (*.cs) или VB.NET (*.vb).
3. Щелкните по кнопке ++Открыть++.

!!! info "Для сведения:"

    Сценарий загружается.

Если при загрузке сценария возникает ошибка, она регистрируется в Системных сообщениях. После первой загрузки сценарий автоматически загружается при следующем пуске программы.

### Выгрузить сценарии

Условие:

Вы загрузили сценарий.

1. Выберите следующие команды: Файл > Дополнительно > группа команд Расширения > Интерфейсы > группа команд Сценарии > Выгрузить.
2. В следующем диалоговом окне в списке Зарегистрированные сценарии выберите соответствующий сценарий.
3. Щелкните по кнопке ++OK++.

!!! info "Для сведения:"

    Регистрация сценария отменяется.

При следующем пуске программы выгруженный сценарий больше не будет автоматически регистрироваться в Eplan.
