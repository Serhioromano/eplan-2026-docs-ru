## Определить точку захвата для сгруппированных 3D-объектов

Если вы сгруппировали 3D-объекты в пространстве листа, вы можете определить вышестоящую точку захвата для этой группы. С помощью данной точки захвата можно перемещать всю группу. После разделения группы вышестоящая точка захвата автоматически удаляется, а точки захвата отдельных 3D-объектов снова становятся действующими.

Условия:

  * Вы открыли проект.
  * Вы открыли пространство листа.
  * Пространство листа содержит 3D-объекты, которые можно вставить в качестве устройств или макросов окна / символа.
  * Включен захват объекта.
  * Активировано группирование 3D-объектов (вкладка Обработать > группа команд Группировать > кнопка Группирование).
  * Для просмотра в пространстве листа активирована кнопка Инструмент для монтажных работ.


  1. Удерживая нажатой левую кнопку мыши, перетащите рамку вокруг 3D-объектов, которые нужно переместить как группу.  
  
3D-объекты выделены цветом.
  2. Выберите следующие команды: Вкладка Обработать > группа команд Группировать > Группировать.  
  
3D-объекты объединяются в группу.
  3. Теперь вставьте точку захвата, которую определяете как вышестоящую точку захвата группы. Для этого выберите следующие команды: вкладка Вставить > группа команд Инструмент для монтажных работ > Точка захвата.
  4. Переместите курсор на 3D-объекты.  
  
На объекте будут показаны точки захвата 3D. Это конечные или серединные точки ребер или угловые точки параллелепипеда, обрамляющего объект.
  5. Щелкните по нужной точке захвата 3D.  
  
Точка захвата будет выделена оранжевым параллелепипедом.
  6. Теперь нажмите на один из сгруппированных 3D-объектов.
  7. Нажмите клавишу [V], чтобы переместить группу с помощью точки захвата.
  8. Переместите курсор в нужное место и нажмите левую кнопку мыши.  
  
Сгруппированные 3D-объекты разместятся на новой позиции.
  9. Если вы хотите отменить группирование, снова начертите рамку вокруг группы.
  10. Выберите следующие команды: Вкладка Обработать > группа команд Группировать > Отменить группирование.  
  
Вышестоящая точка захвата будет удалена.
  11. Отключите группирование 3D-объектов. (Вкладка Обработать > группа команд Группировать > кнопка Группирование)  
  
Точки захвата всех отдельных 3D-объектов снова действуют.
