## Генерировать схемы сверления из файлов DXF / DWG

Импорт информации об отверстиях из файлов ЧУ Steinhauer с расширением имен файла *.CNC напрямую невозможен, поскольку в файле ЧПУ всегда собрана вся информация об отверстиях для всех компонентов монтажной платы. Чтобы сделать эту информацию доступной для генерирования схем сверления, файл ЧПУ в машинном ПО Steinhauer необходимо экспортировать в формат DXF / DWG. Экспортирванные файлы DXF- / DWG затем можно импортировать в Eplan и с помощью границ схемы сверления использовать для генерирования схем сверления.

Кроме файлов DXF- / DWG из машинного ПО Steinhauer, эта функция позволяет также импортировать данные сверления, которые были экспортированы из других источников DXF- / DWG, например систем CAD.

!!! note "Замечание:"

    Для идентификации объектов в качестве функциональных элементов, монтажных отверстий или контуров при импорте требуется специальная схема импорта. Выберите командыФайл>Настройки>Пользователь>Интерфейсы>Экспорт и импорт DXF / DWGи создайте новую схему.

 

Условие:

Вы открыли проект макросов.

1. Импортируйте файл DXF- / DWG. Выберите следующие команды: Файл > Импортировать > группа команд Данные проекта > Данные проекта > группа команд Страница > DXF / DWG.   
Или вставьте графику DXF / DWG в уже открытую страницу. Выберите следующие команды: Вкладка Вставить > командный путь Внешний > DXF / DWG. Используйте при этом предварительно созданную схему импорта с присвоением имен слоя CAD слоям Eplan для генерирования схем сверления.  
  
Графика DXF- / DWG будет добавлена на новую или на уже открытую страницу.
2. При необходимости удалите содержащиеся в графике DXF- / DWG блоки. Выберите следующие команды: Вкладка Обработать > группа команд Блок > Разбить.
3. Проверьте содержащиеся в графике DXF- / DWG контуры на замкнутость.
4. Вставьте границу схемы сверления, которая охватывала бы объекты, предназначенные для схемы сверления. Выберите следующие команды: Вкладка Основные данные > Группа команд Вставить > Граница схемы сверления.  

!!! tip "Совет:"

    При генерировании схемы сверления все расчеты позиций и интервалов между участвующими объектами базируются на нулевой точке границы схемы сверления. Позиция нулевой точки на границе схемы сверления определяет позицию нулевой точки на генерируемой схеме сверления. С помощью пункта всплывающего менюПереместить нулевую точкуможно изменить позицию нулевой точки и таким образом задать требуемые интервалы для первого и всех последующих отверстий на схеме сверления.

 

5. В диалоговом окне "Свойства" границы схемы сверления введите имя, описание и каталог для генерируемых определенных пользователем контуров.
6. Сгенерируйте схемы сверления. Выберите следующие команды: Вкладка Основные данные > группа команд Схема сверления / контур > раскрывающаяся кнопка Генерировать > Из проекта макросов автоматически.
7. Выберите, должен ли процесс применяться ко всему проекту или только к выделенной границе схемы сверления.  
  
Схемы сверления генерируются в базе данных изделий из импортированных объектов DXF / DWG, которые присвоены границам схем сверления, в виде сверху.
