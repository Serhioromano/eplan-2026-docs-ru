## Предварительно собранные кабели

Предварительно собранные кабели имеют определенную длину и уже оснащены подходящими штекерами. Это значит, что такие кабели сразу можно использовать без необходимости дальнейшей настройки. Чтобы правильно запроектировать предварительно собранные кабели в схеме соединений, необходимо выполнить следующие настройки:

* Активируйте для кабелей свойство [Использовать подключенные устройства как источник и цель](devicetaggui_r_kabeldaten.md) (ид. 20621). При определении и выводе источника и цели назначения кабеля подключенные штекерные контакты пропускаются, вместо них в качестве источника и цели отображаются подключенные к кабелю устройства. Это свойство влияет только на отображение в диалоговых окнах для обработки кабелей, клемм и штекеров и на отображение в отчетах; сами кабели и соединения не изменяются.
* При помощи настройки проекта [Всегда генерировать прямые соединения на прямых выводах устройства контактов штекера](connectionsettingsgui_d_einstellungenallgemein.md) вы задаете, чтобы соединения на прямых выводах устройства контактов штекера всегда становились прямыми соединениями.  
Вследствие этого соединение между выводом устройства и прямым выводом устройства контакта штекера на кабеле становится прямым соединением. Прямые соединения выделяются в схеме соединений цветом в соответствии с настройкой слоя EPLAN510, Внутренние соединения / прямые соединения, не нумеруются и не маршрутизируются.

Совместное управление штырями штекера и гнездами в качестве функции (комбинации штыря и гнезда) при использовании предварительно собранных кабелей является нецелесообразным, поэтому не поддерживается.

### Предварительно собранные кабели в управлении изделиями

Предварительно собранные кабели создаются в управлении изделиями как модули. Чтобы успешно обмениваться предварительно собранными кабелями с Eplan Cable proD, необходимо выполнить назначение жил кабеля штекерам. При этом рекомендуется действовать следующим образом.

* Создать модуль: создайте модуль и выберите для свойства Группировка продуктов данного модуля значение "Электротехника > Кабели > Предварительно собранный".   
Добавьте в этом модуль на вкладке Шаблоны функций шаблоны функций для определения кабеля и кабельных соединений (например, шаблон функции с "Определением кабеля" и три шаблона функций с "Жила / провод"). Внесите в эти шаблоны функций характерные для кабеля данные (например, Цвет / номер соединения, Поперечное сечение / диаметр соединения и т. п.).
* Добавить штекер как изделие: добавьте в предварительно собранный кабель на вкладке Модуль один или два штекера как изделие. Для единожды проложенного кабеля вам нужно одно изделие штекера, для проложенного дважды — два изделия штекера. Для этого нажмите на кнопку  (Создать), затем нажмите в столбце Номер изделия на ++…++, чтобы выбрать изделие.  
В случае изделия модуля вам необходимо, как обычно, еще ввести ОУ или идентификатор ОУ для идентификации.
* Объединить шаблоны функций: По умолчанию шаблоны функций модулей и узлов в управлении изделиями автоматически объединяются после каждого изменения. Если настройка пользователя [Автоматически объединить шаблоны функций](partselectiongui_d_datenauswahlbenutzer.md) отключена, то придется объединять шаблоны функций вручную. Для этого выделите модуль в структуре дерева управления изделиями и выберите пункт всплывающего меню Объединить шаблоны функций. В результате этого шаблоны функций штекеров объединяются в виде подизделий модуля, переносятся во вкладку Шаблоны функций модуля и распределяются по шаблонам функций кабеля.  
Если какой-то шаблон функции для определения кабеля еще отсутствует, он автоматически добавляется как группирующий элемент для модуля на первой позиции шаблонов функций.
* Присвоить штекеры кабельным соединениям: затем присвойте кабельным соединениям контакты штекеров. Для этого только для изделий кабельной подгруппы продуктов "Предварительно собранный" во вкладке Шаблоны функций доступны оба столбца Начальная часть жилы и Концевая часть жилы. Здесь вы можете выполнить присвоение шаблонов функций "Жила / провод" кабеля штекерам. Для единожды проложенного кабеля необходимо присвоение только в столбце Начальная часть жилы, для дважды проложенного кабеля необходимо выполнить присвоение в обоих столбцах.

#### Присвоение контактов штекера жилам

Есть разные варианты указать присвоение контактов штекера жилам:

* Позиция шаблона функции контакта штекера (напр., "6")
* Нижестоящее ОУ и обозначение контакта штекера (напр., "X1:2")
* Идентификатор ОУ и обозначение контакта штекера, (напр. "ID.:X1:2")

Чтобы проверить правильность присвоения, можно использовать контрольный прогон 502039 из класса сообщения 502 "Основные данные изделий". Этот контрольный прогон определяет предварительно собранные кабели, для которых в управлении изделиями сохранено недействительное присвоение контактов штекера для кабельных соединений.

Чтобы выявлять при проектировании все неправильные кабельные соединения предварительно собранных кабелей, в классе сообщения 005 "Соединения" доступен контрольный прогон 005094. Этот контрольный прогон сообщает обо всех кабельных соединениях, которые не подключены к правильным контактам штекера.

Штекеры в предварительно собранных кабелях могут крепиться на резьбовых соединениях или привариваться. Для приваренных штекеров целесообразно активировать свойство изделия Подавлять в спецификации. Изделие, обозначенное таким образом, не отображается ни в навигаторе спецификаций, ни в соответствующих значениях изделий и не выводится через интерфейсы для данных изготовления. В этом случае в спецификации и отчетах выдается только модуль.
