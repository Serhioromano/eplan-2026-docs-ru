## Создать символы

Условие:

Вы открыли проект и как минимум одну библиотеку символов.

1. Выберите следующие команды: Вкладка Основные данные > группа команд Символы > раскрывающаяся кнопка Символ > Создать.
2. если открыто несколько библиотек символов, то в диалоговом окне Выбор библиотеки символов выберите библиотеку символов, в которой должен быть создан символ.
3. Щелкните по кнопке [OK].
4. В диалоговом окне Генерировать варианта выберите вариант, который должен быть создан для символа.
5. Щелкните по кнопке [OK].
6. В диалоговом окне Свойства символов — <Имя библиотеки> задайте данные создаваемого символа. Номер символа будет при этом заполнен первым свободным номером.
7. Щелкните в поле Определение функции по [...], чтобы задать логику символа в диалоговом окне Определения функций.
8. Подтвердите ввод.  

Откроется редактор символов.  

В редакторе символов отображается круг, который можно сдвинуть, но невозможно удалить. Этот круг отображает точку, в которой позже будет вставлен символ.
9. Оформите нужный символ: введите графические элементы — линии, прямоугольники и/или круги и разместите эту точку вставки и графические элементы так, как вам нужно.
10. Расположите в нужных местах выводы устройства, которые будут изображать выводы устройства символов. Выберите следующие команды: Вкладка Вставить > группа команд Логика > раскрывающаяся кнопка Выводы устройства символов > Вывод устройства вверху, ...внизу, ...справа или ...слева.
11. Определите в диалоговом окне Вывод устройства свойства выводов устройства, такие как Номер вывода устройства, Описание вывода устройства и/или Обозначение вывода устройства.  

12. Подтвердите ввод.
13. Выберите следующие команды: Вкладка Обработать > группа команд Символ > раскрывающаяся кнопка Другие > Размещенные свойства.
14. Задайте в диалоговом окне Размещение свойства отображаемые по умолчанию свойства символа и их порядок.
15. Щелкните по кнопке [OK].
16. Закройте редактор символов и ответьте [Да] на последующее сообщение.  

В выбранной библиотеке символов будет создан новый символ.  

!!! tip "Совет:"

    При размещении выводов устройства нажмите клавишу[Ctrl]и двигайте мышь для переключения направления вывода устройства. Или нажмите клавишу[Tab], для вращения вывода устройства через все направления против часовой стрелки.
