# Управление видами пространства листа

У вас есть различные возможности для управления ортогональными и изометрическими видами, сгенерированными вами, например, с помощью навигационного куба для какого-либо пространства листа в диалоговом окне **Виды пространства листа**.

Условия:

* Вы открыли проект.
* Открыты навигатор пространства листа и пространство листа.
* Пространство листа содержит 3D-объект (или трехмерный чертеж монтажных поверхностей).
* В специфических для пользователя настройках задано основное представление для навигационного куба, например вид "ЮВ изометрия".
* Открыто диалоговое окно **Виды пространства листа**.

###

## Сохранение вида пространства листа

1. Сгенерируйте, например, с помощью навигационного куба, какой-нибудь вид для вашего пространства листа.
2. В диалоговом окне **Виды пространства листа** выберите плитку.
3. Щелкните по пиктограмме ![](images/all_new_as.png){ .ui-icon } (Добавить текущий вид) или выберите во всплывающем меню плитки пункт **Добавить текущий вид**.

!!! info "Для сведения:"

    На плитке отображается предварительное изображение сохраненного вида.

###

## Вызов и повторное использование вида пространства листа

1. В диалоговом окне **Виды пространства листа** выберите плитку.
2. Выберите во всплывающем меню плитки пункт **Использовать вид** или дважды щелкните по плитке.

!!! info "Для сведения:"

    В пространстве листа будет использоваться вид, сохраненный на этой плитке.

!!! tip "Совет:"

* Вы можете также использовать вид без настроенного угла зрения, со скрытыми в сохраненном виде функциональными элементами и соединениями или без отображения этих функциональных элементов и соединений в сохраненном виде. Для этого перед вызовом вида выберите пункт всплывающего меню **Угол зрения вкл. / выкл.** или **Область видимости вкл. / выкл.** В этом случае пиктограмма плитки ![](images/views_viewing_angle_as.png){ .ui-icon } или ![](images/views_visibility_as.png){ .ui-icon } также будет скрыта.
* Вы можете также вызывать виды с помощью комбинаций клавиш. В диалоговом окне **Настроить комбинации клавиш** можно присвоить каждой плитке определенную комбинацию клавиш. Для этого в диалоговом окне **Настроить комбинации клавиш** доступны команды от **Активировать вид пространства листа 1** до **Активировать вид пространства листа 10**, если вы выбрали в поле **Вкладки** запись **Все команды**.

###

## Переименование вида пространства листа

По умолчанию видам пространства листа присваиваются имена от **Вид 1** до **Вид 10**. Вы можете изменить имя вида.

1. В диалоговом окне **Виды пространства листа** выберите плитку.
2. Во всплывающем меню плитки выберите пункт **Переименовать вид**.

!!! info "Для сведения:"

    Отображается диалоговое окно **Переименование вида пространства листа**.

3. Введите новое имя для этого вида.
4. Щелкните по кнопке ++"OK"++.

!!! info "Для сведения:"

    Новое имя вида отобразится на плитке.

###

## Удаление вида пространства листа

1. В диалоговом окне **Виды пространства листа** выберите плитку.
2. Щелкните по пиктограмме ![](images/all_delete_as.png){ .ui-icon } (Удалить вид) или выберите во всплывающем меню плитки пункт **Удалить вид**.
3. Подтвердите следующий запрос, нажав кнопку ++"Да"++.

!!! info "Для сведения:"

    Предварительное изображение удаленного вида больше не будет отображаться на плитке.

###

## Перезапись вида пространства листа

1. Сгенерируйте, например, с помощью навигационного куба, какой-нибудь вид для вашего пространства листа.
2. В диалоговом окне **Виды пространства листа** выберите плитку, на которой уже сохранен какой-либо вид.
3. Щелкните по пиктограмме ![](images/all_new_as.png){ .ui-icon } (Добавить текущий вид) или выберите во всплывающем меню плитки пункт **Добавить текущий вид**.
4. Подтвердите следующий запрос, нажав кнопку ++"Да"++.

!!! info "Для сведения:"

    На плитке отображается предварительное изображение сохраненного нового вида.
