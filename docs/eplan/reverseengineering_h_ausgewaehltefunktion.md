# Обработать свойства выбранного представления функции

Функция может быть многократно представлена в проекте в распределенном виде, например, как однополюсная или многополюсная функция, функция обзора, парная перекрестная ссылка и / или функция функциональной схемы автоматизации. При этом свойства представлений функции в распределенном виде можно обрабатывать независимо друг от друга.

Условия:

* Вы открыли проект.
* Открыт Навигатор устройств или Графический редактор.

1. На вкладке **Обработать** в группе команд **Параметры** отожмите кнопку **Общие**.
2. Дважды щелкните по представлению функции главной или вспомогательной функции.

!!! info "Для сведения:"

    В диалоговом окне **Свойства (усл. обозначение):** ++"..."++ отображаются свойства выбранного представления функции.

3. Измените нужные свойства и нажмите ++"OK"++.
4. Для обновления нажмите ++"F5"++.

!!! info "Для сведения:"

    Свойства будут изменены исключительно на выбранном представлении функции.
