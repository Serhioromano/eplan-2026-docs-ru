# Диалоговое окно Копировать графический файл

Вы открыли проект. Вы открыли редактор, например графический редактор, редактор рамок и т. д. Вкладка Вставить > группа команд Внешн. > Графический файл. Выберите в диалоговом окне Выбрать графический файл нужный графический файл и нажмите на кнопку ++Открыть++.

В Eplan можно вставить графические файлы форматов GIF, JPG, BMP, ICO, PNG или TIFF. В этом диалоговом окне указывается, следует ли скопировать графический файл в каталог проекта или должна быть создана ссылка на исходный каталог графического файла.

Обзор основных элементов диалогового окна:

### Исходный каталог не изменять:

В проект вставляется ссылка на графический файл. В случае изменений этот графический файл будет обновлен при открытии данной страницы. При резервном копировании данных можно учитывать файлы со ссылками с помощью соответствующей настройки.

### Копировать:

Файл копируется в каталог проекта (т. е. в подкаталог Images проекта). Графический файл хранится не непосредственно там, а в другом отдельном подкаталоге. Имя этого подкаталога вычисляется на основе имен исходных каталогов.
Все файлы в подкаталогах проекта также учитываются при резервировании данных.

### Перезаписать с запросом:

Установите этот флажок, чтобы параметр Копировать отображал запрос, если рисунок уже существует в каталоге проекта. При этом можно выбрать, перезаписывать этот рисунок или нет.
