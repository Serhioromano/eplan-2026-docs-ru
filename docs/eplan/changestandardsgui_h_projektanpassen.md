## Настроить целевой проект (изменение стандарта)

При изменении стандарта происходит преобразование исходного проекта. Преобразованный исходный проект сохраняется в целевом проекте. Исходный проект сохраняется без изменений.



!!! note "Замечание:"

    Обратите внимание, что в целевой проект копируются только теобъекты, которые находятся внутри области отчетарамки(т. е. области, установленной через строки и столбцы).


 

Условия:

  * Вы открыли проект.
  * При нескольких открытых проектах: В навигаторе страниц выделен проект.
  * У вас есть базовый проект, содержащий специфические для страны или стандарта настройки.


  1. Выберите следующие команды: Вкладка Инструменты > группа команд Стандарты > Заменить.
  2. На вкладке Проект в поле Имя проекта Целевой проект задайте информативное имя проекта без расширения имени файла.
  3. Чтобы выбрать место хранения, нажмите рядом с полем Место хранения на .
  4. Выберите в диалоговом окне Выбрать папку каталог для сохранения нового проекта и щелкните по кнопке [OK].
  5. Нажмите на кнопку [Далее].
