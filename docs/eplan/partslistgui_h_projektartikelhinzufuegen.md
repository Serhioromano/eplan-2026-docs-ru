## Добавить покупные изделия

Изделиями проекта являются изделия, которые не присвоены специальному устройству, как, напр., комплектующие детали.

Условие:

Вы открыли проект.

  1. Выберите следующие команды: Вкладка Устройства > группа команд Устройства > Спецификация.
  2. В диалоговом окне Спецификация — <Имя проекта> выберите пункт всплывающего меню Добавить покупные изделия.
  3. В диалоговом окне Выбор изделия выберите добавляемые изделия. Возможен многократный выбор.
  4. Щелкните по кнопке [OK].  
  
Новые покупные изделия вводятся в дереве с сортировкой по алфавиту.



!!! note "Замечание:"

    Могут быть использованы всефункциидиалогового окнаВыбор изделия, при этом учитываются предварительныенастройки, специфические длябазы данных изделий.
