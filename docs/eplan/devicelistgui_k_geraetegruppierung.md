# Группы устройств

Сложные устройства можно реализовать с помощью групп устройств. При этом функции и обозначения устройств из различных разделов собираются графически и логически в одно устройство. Таким образом можно, например, сгруппировать устройства Fluid-техники с электротехническими компонентами.

Объединенные в группу устройств функции, как правило, сохраняются в виде макроса. Поэтому создание и отмена групп устройств возможны только в проекте макросов.

Чтобы создать группу устройств, должны / могут удовлетворяться следующие критерии:

* Должна существовать ровно одна главная функция, которой присваивается вид представления "многополюсный" или "функциональная схема автоматизации".
* Должна иметься одна или несколько главных или вспомогательных функций, которым присвоен вид представления "парная перекрестная ссылка". (Настройка раздела главной или вспомогательной функции при этом роли не играет).
* Может присутствовать произвольное число условных обозначений вида представления "графика". (Эти условные обозначения учитываются в графике, но не в логике.)
* Может иметься произвольное число графических элементов (линий, прямоугольников и т.п.). (Эти элементы учитываются в графике, но не в логике.)

В навигаторе устройств функции группы устройств, которым присвоен вид представления "Парная перекрестная ссылка", отображаются ниже многополюсной главной функции, хотя эти функции имеют другие обозначения устройства.

### Создание группы устройств

Создание группы устройств возможно только в проекте макросов. Чтобы сгруппировать устройства, группируемые функции и графические элементы должны быть сначала выделены на схеме соединений, после чего необходимо выбрать следующие команды: вкладка **Обработать** > группа команд **Группировать** > **Устройство**. Программа сначала проверяет, выполнены ли критерии настройки группы устройств. Если это не так, будет показано соответствующее сообщение. Если критерии выполняются, произойдет группировка.

!!! note "Замечание:"

    Учтите, что функции, относящиеся к группе устройств, выступают в качестве группы, только когда активирован параметр **Учитывать группирование**. В противном случае функции при выполнении таких операций, как групповая обработка, удаление, копирование, перемещение и т. д., выступают не как группа, а как отдельные функции.

### Разгруппировка устройств

В проекте макросов группы устройств могут снова раскладываться на отдельные составляющие. Перед тем, как разгруппировать группу устройств, она должна быть отмечена на схеме соединений. Затем их можно разбить с помощью следующих команд: вкладка **Обработать** > группа команд **Группировать** > **Отменить**.

!!! note "Замечание:"

    В проектах схем соединений с помощью команды **Отменить** можно отменить только группирование групп элементов (т. е. группирование графических элементов).

### Характеристики групп устройств в проекте схемы соединений

Если в графическом редакторе при активированной кнопке **Группирование** провести курсор над группой устройств, все элементы этой группы выделятся одним цветом.

Даже при активированной кнопке **Группирование** логические элементы группы устройств всегда рассматриваются по отдельности. Это значит, что можно выбрать отдельные функции группы устройств (вспомогательные функции, парные перекрестные ссылки) и открыть соответствующее диалоговое окно "Свойства".

В проекте схемы соединений нельзя удалить из группы устройств функции и графические элементы этой группы.

### Неразмещенные группы устройств

Размещение выбранной группы устройств можно полностью удалить в проекте схемы соединений с помощью следующих команд: вкладка **Главная** > группа команд **Буфер обмена** > раскрывающаяся кнопка **Удалить** > **Размещение**. При этом не имеет значения, выполняется удаление размещения в навигаторе устройств или в графическом редакторе.

Неразмещенные группы устройств ведут себя так же, как и остальные неразмещенные функции, и, например, могут быть снова размещены из навигатора устройств в графическом редакторе как полноценная группа устройств, если эта группа устройств была введена как устройство с макросом изделия.

### Свойства блока для групп устройств

Для функций группы устройств в свойствах блока в диалоговом окне **Формат** имеется элемент формата 'Группа устройств (прочие функции)'. С помощью этого элемента формата внутри группы устройств теперь можно получить доступ из одной функции группы устройств к свойствам других функций. Таким образом можно, например, отобразить на функции группы устройств на электротехнической странице схемы соединений данные изделий или значения свойств главной функции, в то время как главная функция с группой устройств размещена на странице типа 'Схема соединений Fluid'.

Чтобы получить доступ к другим функциям группы устройств через свойства блока, выделите сначала в диалоговом окне **Формат** элемент из группы "Группа устройств (прочие функции)" и нажмите на кнопку ![](images/all_stairup_as.png){ .ui-icon } (следующая степень). Находясь на исходной функции, так можно перейти к другим функциям группы устройств и выбрать там нужные данные изделия ( напр., **Номер изделия**) или свойства функции (напр., **Функциональный текст**, **Примечание** и т. д.).

* Если выбран самый верхний элемент формата без значения индекса, будут выведены значения свойства для всех функций группы устройств, за исключением текущей выделенной функции.
* Если в подчиненной группе свойств выбран элемент "Свойства функции 1", перейдите с помощью кнопки ![](images/all_stairup_as.png){ .ui-icon } (следующая степень) к косвенным свойствам другой функции группы устройств. Если вы находитесь при этом в диалоговом окне 'Свойства' вспомогательной функции, будут выведены значения главной функции.
