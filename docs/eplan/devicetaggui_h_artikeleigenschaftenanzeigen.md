# Отображение свойств изделия в виде QR-кодов или в виде изображений на устройстве

На условном обозначении на схеме соединений у вас есть возможность отобразить данные изделия, хранящегося на устройстве, в виде размещения свойств. Для этого добавьте нужные свойства к порядку свойств. Для свойств изделия **Графический файл** и **Внешний документ: Файл / гиперссылка [1–20]** графический файл присвоенного изделия и/или гиперссылку внешнего документа на присвоенном изделии можно отобразить в виде QR-кода на условном обозначении в графическом редакторе с помощью свойства отображения **Представление**.

Если вы используете эти свойства изделия в порядке свойств, то при обмене изделия на устройстве может отображаться другое изображение или другой QR-код с другой гиперссылкой.

Условие:

Вы открыли проект. В Графическом редакторе открыта страница проекта.

1. В графическом редакторе выделите условное обозначение.
2. Выберите пункт всплывающего меню **Свойства**.
3. Выберите в диалоговом окне **Свойства <…>** вкладку **Отображение**.
4. Из списка **Порядок свойств** выберите один порядок свойств с нужным свойством изделия либо добавьте свойство изделия **Графический файл** и/или **Внешний документ: Файл / гиперссылка [1–20]** к порядку свойств с помощью кнопки ![](images/all_new_as.png) (Создать).
5. В списке **Порядок свойств** выделите одно из этих свойств изделия.
6. В правой части вкладки в таблице **Свойство / присвоение** откройте уровень иерархии **Блок выравнивания** и установите флажок для свойства **Активировать блок выравнивания**.
7. В раскрывающемся списке **Представление** выберите запись "QR-код" или "Графический файл".
8. Щелкните по кнопке ++"OK"++.

!!! info "Для сведения:"

    QR-код или графический файл отобразятся на условном обозначении. Если нужное представление (например "Графический файл") невозможно для какого-либо свойства в порядке свойств, ничего не отображается.

Размер блока выравнивания определяет размер изображения или QR-кода в графическом редакторе.

Для "обычных" текстов, функциональных текстов, специальных текстов и текстов-заполнителей значение "Текст" не может быть изменено для свойства отображения **Представление**.

!!! note "Замечание:"

* Если вы добавили одно или оба свойства изделия к порядку свойств, то для этого порядка свойств устанавливается значение "Определено пользователем". Сохраните порядок свойств с помощью кнопки ![](images/all_save_as.png) (Сохранить), если хотите, чтобы этот порядок свойств был доступен также и для других функций с тем же вариантом символа.
* Для кодировки текстов в QR-кодах по умолчанию используется кодировка "UTF-8". Однако для японских символов требуется кодировка "Shift JIS".
    Для настройки кодировки добавляемых в проект QR-кодов доступна настройка проекта **Кодировка QR-кода**. Используя раскрывающийся список этой настройки, можно переключаться между кодировками "UTF-8" и "Shift JIS".

!!! tip "Совет:"

    Для изображений или QR-кодов, отображаемых в качестве размещений свойств, могут быть реализованы различные функции:

* Например, если QR-код является ссылкой на внешний документ, вы можете превратить курсор в руку, нажав клавишу ++"Ctrl"++, и открыть гиперссылку щелчком мыши.
* Как и другие тексты свойств, изображения или QR-коды также можно перемещать в графическом редакторе, используя пункты всплывающего меню **Текст** > **Переместить текст свойства**. Чтобы изображение или QR-код можно было перемещать независимо от других мест размещения свойств, соответствующие свойства не должны стыковаться с другими свойствами в порядке свойств.
