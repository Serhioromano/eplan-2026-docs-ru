# Диалоговое окно Порядок свойств (редактор символов)

## Вызов диалогового окна:

Вы открыли проект. В редакторе символов вы либо открыли символ, либо создали символ (вкладка **Основные данные** > группа команд **Символы** > раскрывающаяся кнопка **Символ** > ++"Открыть"++ или **Создать**).

* Вкладка **Вид** > группа команд **Общее** > **Порядок свойств**.
* Выберите пункт всплывающего меню **Свойства** на имени символа в навигаторе страниц. В диалоговом окне **Свойства символа — <Имя символа>** выберите из раскрывающегося списка **Категория** пункт "Настройки". Нажмите ![](images/all_new_as.png) (Создать) и выберите из диалогового окна **Выбор свойств** одну из записей "Стандартный порядок свойств для варианта x". ++"OK"++. Нажмите ++"..."++ в ячейке **Значение** свойства "Стандартный порядок свойств для варианта x".

В данном диалоговом окне выберите запись данных порядка для свойств, отображаемую сейчас в редакторе символов. Установленная в данный момент запись данных порядка отображается в строке заголовка после информации о символе, и для варианта ее можно определять индивидуально.

Обзор основных элементов диалогового окна:

### Порядок свойств:

В данном раскрывающемся списке приводятся все созданные, а также заданные по умолчанию порядки свойств.
