# Импортировать данные проводного монтажа

Для проектирования проводного монтажа на платформе Eplan можно импортировать данные проводного монтажа из Eplan Harness proD.

Во время импорта выполняется синхронизация с уже имеющимися в проекте данными проводного монтажа (функциями и соединениями). При этом функции и соединения, содержащиеся только в проекте, а не в файле импорта, можно удалить из проекта. Если данные проводного монтажа отсутствуют в проекте, они импортируются в проект как неразмещенные функции и соединения.

При импорте также учитываются данные кабельных сборок, содержащиеся в файле импорта.

Условия:

* Вы открыли проект.
* Данные для проводного монтажа и/или кабельных сборок доступны в виде файла `hpdex`.

1. Выберите следующие команды: **Файл** > **Импортировать** > группа команд **Данные проекта** > **Данные проекта** > группа команд **Устройства** > **Данные проводного монтажа**.
2. Выберите в диалоговом окне **Импортировать данные проводного монтажа** нужный для импорта файл с данными проводного монтажа ( `*.hpdex`).
3. Щелкните по кнопке ++"Открыть"++.

![](images/arrow.png) В диалоговом окне **Синхронизировать данные проводного монтажа** отображаются данные проводного монтажа и кабельных сборок, которые необходимо импортировать, а также те, которые уже имеются в проекте.

![](images/arrow.png) В столбце **Статус** отображается, содержатся или не содержатся в проекте функции / соединения, а также имеют ли функции / соединения различные состояния обработки (например, другие значения свойств) в источнике данных и в проекте. Поля с измененными значениями свойств подкрашены темно-серым цветом.
4. В столбце **Операция** определите, что необходимо сделать с соответствующими функциями / соединениями: импортировать, изменить или не импортировать.
5. Щелкните по кнопке ++"OK"++.

![](images/arrow.png) Данные будут импортированы в соответствии с настройками в открытый проект.
