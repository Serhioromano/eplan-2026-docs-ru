# Диалоговое окно Подклассы буквенных обозначений

Вы открыли проект. Файл > Настройки > Проекты > "Имя проекта" > Устройства > Нумерация (online). Рядом с полем Подклассы буквенных обозначений щелкните ++...++.

В этом диалоговом окне для данного проекта можно установить специфические для него буквенные обозначения с подклассами, включая текстовое описание подкласса. Описания при этом задаются как многоязычные тексты. Сохраненные подклассы можно выбрать через всплывающее меню из соответствующего списка выбора в поле Видимое ОУ диалогового окна свойств условных обозначений.

Обзор основных элементов диалогового окна:

### Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать или обработать. Для этого также воспользуйтесь соседней [панелью инструментов](schemeconfig_m_schemaschaltflaechen.md).

### Панель инструментов:

Кнопка |  Значение
---|---
![](images/all_new_as.png){ .ui-icon } (Создать) |  Добавляет новую строку в конец таблицы.
![](images/all_delete_as.png){ .ui-icon } (Удалить) |  Удаляет текущую строку в таблице.

### Таблица:

Укажите в столбце Подкласс соответствующее обозначение подкласса; эта строка символов копируется в поле Видимое ОУ диалогового окна свойств условных обозначений, когда в нем открывается список выбора. Введите поясняющий текст в Цель или задание объекта и Примеры продуктов. При необходимости добавьте указание или примечание в столбце Комментарии. Все тексты в трех последних столбцах могут быть переведены.

Внутри столбца сортировку можно производить как в восходящем, так и в нисходящем порядке, для чего нужно два раза щелкнуть заголовок столбца. После этого направление выводится в заглавии столбца в виде графического символа.

### Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).
