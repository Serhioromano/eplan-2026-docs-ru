# Диалоговое окно Настройки: Внешняя обработка

## Вызов диалогового окна (для данных проекта):

* Вы открыли проект. **Файл** > **Экспортировать** > группа команд **Данные проекта** > **Данные проекта** > группа команд **Внешняя обработка** > **Свойства**. Нажмите в диалоговом окне **Внешняя обработка** рядом с полем **Настройки** кнопку ++"..."++.
* **Файл** > **Настройки** > **Пользователь** > **Интерфейсы** > **Внешняя обработка**.

## Вызов диалогового окна (для данных изделия):

Вкладка **Основные данные** > группа команд **Изделия** > **Управление**. В диалогом окне **База данных изделий** через меню ++"Дополнительно"++ > **Настройки** была открыта база данных изделий. Кнопка ++"Дополнительно"++ > **Внешняя обработка свойств** > **Экспортировать данные**. Нажмите в диалоговом окне **Внешняя обработка** рядом с полем **Настройки** кнопку ++"..."++.

В этом диалоговом окне можно управлять схемами и обрабатывать их для внешней обработки. В схеме указываются настройки для экспорта данных для внешней обработки.

Обзор основных элементов диалогового окна:

### Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать или обработать. Для этого также воспользуйтесь соседней [панелью инструментов](schemeconfig_m_schemaschaltflaechen.md).

### Тип объекта:

Схема для внешней обработки всегда создается для определенного типа объекта. В этом поле отображается тип объекта, выбранный при создании текущей схемы с помощью кнопки ![](images/all_new_as.png) (Создать) в диалоговом окне **Тип объекта**. Тип объекта затем уже нельзя изменить!

В зависимости от того, откуда вызываются настройки, возможны различные типы объектов. В базе данных изделий доступны такие типы объектов, как изделия, адреса, схемы сверления и т. д.; в виде Backstage при экспорте данных проекта доступны такие типы объектов, как устройства, кабели, функциональные тексты зоны и т. д.
