## Указание вариантов макроса в объектах планирования для создания подробного планирования

Если макрос сохранен в объекте планирования, то можно создать подробное планирование, через размещение макроса. Если для сохраненного макроса окна имеется более одного варианта, то на вкладке Макрос этого объекта планирования отображаются объекты-заполнители всех вариантов. В результате такое представление может быстро стать неудобным для просмотра. Кроме того, при перетаскивании объектов планирования с такими макросами в навигатор страниц отображается диалоговое окно выбора для выбора вида представления и варианта макроса.

Теперь, если при перетаскивании должен использоваться конкретный вариант макроса окна, можно указать это в объекте планирования на вкладке Макрос. Для этого рядом с полем Макрос доступен новый раскрывающийся список Вариант. По умолчанию не выбран ни один из вариантов и, соответственно, отображается пустая запись.

Эффект:

Благодаря выбору варианта макроса стал понятнее обзор вкладки Макрос. Можно целенаправленно корректировать значения свойств в объектах-заполнителях.

Благодаря тому, что при перетаскивании объектов планирования в навигатор страниц больше не используется диалоговое окно выбора, размещение происходит быстрее. Это особенно удобно, когда выбрано несколько объектов планирования.

[](../Pictures/Gui/Lang/planninggui_macrovariantselection_ls.png)

Если выбрать в поле Вариант нужный вариант макроса окна, в групповом поле Свойства отображаются только объекты-заполнители, переменные и значения этих вариантов. Если этот вариант макроса имеет только один вид представления, то при генерировании страниц схемы соединений путем перетаскивания объекта планирования в навигатор страниц больше не используется диалоговое окно выбора.

Если макрос берется из присвоенного шаблона сегмента, то имя макроса, отображаемое в поле Макрос, невозможно изменить. Однако в таком случае можно выбрать другой вариант.

Если макрос уже размещен, а на объекте планирования выбран другой вариант макроса, то размещенный макрос можно обновить с помощью пункта всплывающего меню Обновить детальное планирование. Для этого в диалоговом окне [Обновить детальное планирование](eplan/planninggui_d_detailplanungaktualisieren.md) выберите параметр Разместить макросы заново.

Предварительно установленный вариант макроса также учитывается при экспорте и импорте данных предварительного планирования для внешней обработки, а также при импорте данных предварительного планирования. Теперь, чтобы можно было указать вариант макроса для объектов планирования, например, при импорте данных предварительного планирования в формате Excel, доступно новое свойство Вариант макроса (ID 44093).
