## Eplan Fluid: Структура устройства

В Eplan под "структурой устройства" понимается объединение всех структур обозначения для страниц и устройств, используемых в проекте.

Понятие "Устройства Fluid" в Eplan Fluid объединяет следующие типы устройств:

* Устройства Fluid общего назначения (сюда можно отнести, например, клапаны, фильтры, цилиндры и т.д.)
* Распределители и соединители Fluid.

Для каждого из этих двух типов устройств может быть назначена своя независимая структура идентификаторов.

Предшествующие знаки и блоки идентификаторов, при помощи которых в Eplan Fluid можно составить соответствующие стандарту и иерархически структурированные обозначения устройств, перечислены ниже:

Предшествующий знак |  Блок идентификаторов  
---|---  
== |  Функциональное присвоение  
= |  Функциональное назначение  
++ |  Место сборки  
+ |  Место установки  
|  Номер установки  
# |  Определенная пользователем структура  
- |  Устройство (состоит из элементов идентификатора "Предш. цифра", "Буквенное обозначение", "Счетчик", "Разделитель" и "Подсчетчик")  

Благодаря этим блокам идентификаторов Eplan Fluid предоставляет множество различных способов структурирования. Например, можно структурировать ОУ согласно стандарту [EN 81436](projectstructure_k_referenzkennzeichnung.md) или ISO 1219-2.

### Обозначение устройства согласно стандарту Fluid-техники ISO 1219-2

По стандарту ISO 1219-2 предписан следующий ключ обозначения для функциональных элементов Fluid-техники:

* Обозначение установки
* - (разделитель)
* Ключ среды
* Номер логической ячейки
* . (Разделитель)
* Номер функц. элемента

Вместо заданной стандартом составной части идентификатора Обозначение установки программа предоставляет блок идентификаторов Номер установки. Так как в Eplan Fluid отсутствуют специальные блоки идентификаторов для требуемых по стандарту структурных элементов "Ключ среды", "Номер логической ячейки" и "Номер функционального элемента", эти элементы ключа обозначения создаются с помощью настройки проекта Fluid: Использовать обозначение раздела в качестве буквенного обозначения (ключ среды) (командный путь: Файл > Настройки > Проекты > "Имя проекта" > Устройства > ОУ).

Требуемые по стандарту ISO 1219-2 элементы идентификатора "Ключ среды", "Номер логической ячейки" и "Номер функц. элемента" в Eplan Fluid автоматически присваиваются элементам блока идентификаторов "Устройство", т. е. "обычным" элементам ОУ (см. таблицу ниже).

Структурные элементы по стандарту ISO 1219-2 |  Составные части идентификатора в Eplan Fluid  
---|---  
Обозначение установки |  Соответствует блоку идентификаторов Номер установки. Номер установки вводится без предшествующего знака.  
- |  Разделитель (четко определен)  
Ключ среды |  Соответствует Обозначению раздела. Присваивается составной части ОУ Буквенное обозначение.  
Номер логической ячейки |  Присваивается составной части ОУ Счетчик.  
. |  Разделитель (четко определен)  
Номер функц. элемента |  Непрерывный номер. Присваивается составной части ОУ Подсчетчик.  

!!! example "Пример:"

    P = ключ среды для обозначения раздела "Пневматика"

Присвоение структурных элементов отображается в диалоговом окне Полное ОУ в виде таблицы. Для получения доступа к обозначенным по стандарту ISO 1219-2 устройствам Fluid следует обратиться к диалоговому окну Свойства <...> и рядом с полем Полное ОУ нажать на ++...++.

!!! note "Замечание:"

!!! tip "Совет:"

    Eplan Fluid оказывает поддержку при проектировании согласно стандарту ISO 1219-2. С этой целью после установки программы вам будет доступен базовый проектFL_1219-2_bas001.zw9. При использовании этого базового проекта для устройств Fluid, а также для распределителей и соединителей Fluid автоматически предлагаются правильные настройки для соответствующего стандартам обозначения устройства.
