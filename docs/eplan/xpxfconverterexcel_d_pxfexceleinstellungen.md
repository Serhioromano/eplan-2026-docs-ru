## Диалоговое окно Настройки: Экспорт Excel

[Вызов диалогового окна (для данных проекта):](javascript:void\(0\);)

* Вы открыли проект.Файл > Экспортировать > группа команд Данные проекта > Данные проекта > группа команд Внешняя обработка > Свойства. Нажмите в диалоговом окне Внешняя обработка рядом с полем Настройки кнопку [...]. Выберите в следующем диалоговом окне вкладку Общее. Выберите из раскрывающегося списка Тип файла запись "Файл Excel (*.xlsx, *.xlsm)" и нажмите кнопку [Параметры].
* Файл > Настройки > Пользователь > Интерфейсы > Внешняя обработка. Выберите вкладку Общее. Выберите из раскрывающегося списка Тип файла запись "Файл Excel (*.xlsx, *.xlsm)" и нажмите кнопку [Параметры].

[Вызов диалогового окна (для данных маркировки):](javascript:void\(0\);)

* Вы открыли проект.Файл > Экспортировать > группа команд Данные изготовления > Данные изготовления > Маркировки. Нажмите в диалоговом окне Экспортировать данные изготовления / вывести маркировку рядом с полем Настройки кнопку [...]. В диалоговом окне Настройки: Экспорт данных изготовления / маркировка выберите вкладку Файл. Выберите из раскрывающегося списка Тип файла запись "Файл Excel (*.xlsx, *.xlsm)" и нажмите кнопку [Параметры].
* Файл > Настройки > Пользователь > Интерфейсы > Экспорт данных изготовления / маркировка. В диалоговом окне Настройки: Экспорт данных изготовления / маркировка выберите вкладку Файл. Выберите из раскрывающегося списка Тип файла запись "Файл Excel (*.xlsx, *.xlsm)" и нажмите кнопку [Параметры].

[Вызов диалогового окна (для данных изделия):](javascript:void\(0\);)

Вкладка Основные данные > группа команд Изделия > Управление. В диалогом окне База данных изделий через меню [Дополнительно] > Настройки была открыта база данных изделий. Кнопка [Дополнительно] > Внешняя обработка свойств > Экспортировать данные. Нажмите в диалоговом окне Внешняя обработка рядом с полем Настройки кнопку [...]. Выберите вкладку Общее. Выберите из раскрывающегося списка Тип файла запись "Файл Excel (*.xlsx, *.xlsm)" и нажмите кнопку [Параметры].

В этом диалоговом окне указываются настройки для внешней обработки страниц, функций, соединений или данных изделий / для вывода маркировки в программе Excel.

Также вывести обозначение столбца:

В этом раскрывающемся списке определите, какие элементы формата должны выводиться при экспорте как заголовки столбцов. Предусмотрен выбор следующих записей:

* Нет: Элементы формата не выводятся.
* Только имя свойства: Выводится только имя свойства, напр. "ОУ (полное)".
* Полный: Перед именем свойства указывается относящееся к нему определение, например "Кабель / ОУ (полное)".
