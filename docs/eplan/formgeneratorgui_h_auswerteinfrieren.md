## Закрепить страницы отчета

Вы можете закрепить страницы отчета для исключения обновления. Тогда данные проекта в текстах заполнителя на [закрепленных страницах отчета](eplan/formgeneratorgui_k_eingefrorseiten.md) больше не будут обновляться. Обновляемые и необновляемые страницы отчета в навигаторе страниц обозначены разными пиктограммами.

Условия:

* Вы открыли проект.
* Вы сгенерировали страницы отчета.

1. Выберите следующие команды: Вкладка Инструменты > группа команд Отчеты > Генерировать.
2. Выберите вкладку Отчеты.
3. Выделите один блок отчетов.
4. Выберите пункт всплывающего меню Закрепить страницы отчета.  
  
Блок отчетов удаляется. Сохранятся страницы отчета.

!!! tip "Совет:"

    Чтобыгенерироватьновые страницы отчета вам сначала нужно удалить вручную существующие страницы и затемсоздатьновые. Если вы не удалите страницы отчета, то будут созданы дополнительные страницы отчета.
