## Генерировать новые заголовки на страницах формы

При помощи свойства формы Создать заголовки для первых х свойств сортировки (ид. 13060) создайте ссылку на сортировку соответствующих отчетов. Т.е., в форме устанавливается, должны ли использоваться свойства сортировки для генерации новых заголовков.

Для этого свойства доступны следующие значения:

Значение | Значение  
---|---  
0 | Новый заголовок не генерируется.  
1 | Первое свойство сортировки используется для нового заголовка.  
2 | Первое и второе свойства сортировки используются для нового заголовка.  
3 | Первое, второе и третье свойства сортировки используются для нового заголовка.  
x | Первое, второе и т. д. до i-го свойства сортировки используются для нового заголовка. При этом "i" — это любое целое число.  
  
Условия:

  * Вы открыли проект.
  * Вы открыли в редакторе форм ту форму, свойства которой хотите обработать (Вкладка Основные данные > группа команд Рамки / формы > раскрывающаяся кнопка Форма > Открыть > кнопка [Открыть]).
  * Вы выделили форму в навигаторе страниц и открыли с помощью пункта всплывающего меню Свойства диалоговое окно Свойства формы — <Имя формы>.


  1. В диалоговом окне Свойства формы — <Имя формы> щелкните  (Создать) над списком Имя свойства / значение.
  2. В диалоговом окне Выбор свойств выберите свойство Создать заголовки для первых х свойств сортировки.
  3. Щелкните по кнопке [OK].  
  
Свойство копируется в список.
  4. Укажите в столбце Значение количество свойств сортировки, которые надо учитывать.
  5. При необходимости обработайте другие свойства формы.
  6. Щелкните по кнопке [OK].  
  
Установленные свойства копируются для формы, и диалоговое окно Свойства формы — <Имя формы> закрывается.



!!! example "Пример:"

    Для вывода списка обозначений устройств в диалоговом окнеСортировкавыбрана схема "Функциональное назначение +место установки+ ОУ". В форме для списка обозначений устройств определено свойствоСоздать заголовки для первых свойств сортировкисо значением "1".При генерировании страниц отчетов для списка обозначений устройств генерируется новый заголовок для каждого нового функционального назначения. Данные между заголовками затем сортируются по месту установки и ОУ.
