# Экспорт данных для внешней обработки

Вывод данных для внешней обработки зависит от выбранного типа объекта, который можно задать при помощи схем. В зависимости от того, откуда вызывается экспорт, возможны различные типы объектов. В базе данных изделий доступны такие типы объектов, как изделия, адреса, схемы сверления и т. д.; в виде Backstage при экспорте данных проекта доступны такие типы объектов, как устройства, кабели, функциональные тексты зоны и т. д.

Соответственно, при каждом экспорте вам всегда предлагается выбор только из схем с теми типами объекта, которые являются релевантными в данном случае. Возможно, вам придется создать дополнительные схемы для других нужных типов объекта.

###

## Экспорт данных проекта для внешней обработки

Условия:

* Вы открыли проект.
* Вы открыли навигатор и выделили в структуре дерева или списке проект, одну или несколько страниц или одну или несколько записей данных.

1. Выберите следующие команды: **Файл** > **Экспортировать** > группа команд **Данные проекта** > **Данные проекта** > группа команд **Внешняя обработка** > **Свойства**.
2. Выберите схему в диалоговом окне **Внешняя обработка** из раскрывающего списка **Настройки** или нажмите на кнопку ++"..."++, чтобы задать в диалоговом окне **Настройки: Внешняя обработка** настройки для новой определенной пользователем схемы.
3. Из раскрывающего списка **Язык** выберите язык выполнения экспорта.
4. Укажите в поле **Целевой файл** имя целевого файла, включая путь к нему, или нажмите на кнопку ![](images/all_selectfile_as.png), чтобы выбрать каталог и имя файла в интерактивном режиме.
5. Выберите в групповом поле **Вид вывода** одну из доступных опций для вывода.
6. Щелкните по кнопке ++"OK"++.

![](images/arrow.png) Выполняется экспорт данных заданного типа объекта, указатель процесса показывает ход экспорта.
7. В зависимости от специфических для экспорта настроек и настроек вида вывода следует сначала завершить внешнюю обработку, прежде чем продолжить работу в Eplan.

###

## Экспорт данных изделий для внешней обработки

При экспорте данных из базы данных изделий для внешней обработки у вас есть следующие возможности:

* Экспортировать все данные типа объекта (изделие, список принадлежностей и т. д.)
* Экспортировать выбранные данные типа объекта

Какой именно вид данных (данные изделия, данные списка принадлежностей и т. п.) будет экспортирован, задается через тип объекта в схеме для экспорта.

Условие:

В диалогом окне **База данных изделий** через меню ++"Дополнительно"++ > **Настройки** была открыта база данных изделий.

#### Экспортировать все данные типа объекта

1. Выберите следующие команды: Вкладка **Основные данные** > группа команд **Изделия** > **Управление**.
2. Выберите в диалоговом окне **База данных изделий** под кнопкой ++"Дополнительно"++ пункты меню **Внешняя обработка свойств** > **Экспортировать данные**.
3. Выберите схему в диалоговом окне **Внешняя обработка** из раскрывающего списка **Настройки** или нажмите на кнопку ++"..."++, чтобы задать в диалоговом окне **Настройки: Внешняя обработка** настройки для новой определенной пользователем схемы.
4. Из раскрывающего списка **Язык** выберите язык выполнения экспорта.
5. Укажите в поле **Целевой файл** имя целевого файла, включая путь к нему, или нажмите на кнопку ![](images/all_selectfile_as.png), чтобы выбрать каталог и имя файла в интерактивном режиме.
6. Выберите в групповом поле **Вид вывода** одну из доступных опций для вывода.
7. Щелкните по кнопке ++"OK"++.

![](images/arrow.png) Выполняется экспорт данных заданного типа объекта, указатель процесса показывает ход экспорта.
8. В зависимости от специфических для экспорта настроек и настроек вида вывода следует сначала завершить внешнюю обработку, прежде чем продолжить работу в Eplan.

#### Экспортировать выбранные данные типа объекта

1. Выберите следующие команды: Вкладка **Основные данные** > группа команд **Изделия** > **Управление**.
2. Выделите в структуре дерева или в списке одно или несколько изделий или другие записи данных.
3. Выберите пункт всплывающего меню **Экспортировать данные**.
4. Продолжайте в диалоговом окне **Внешняя обработка**, как описано выше.

!!! note "Замечание:"

    Если текущее выделение содержит узлы в представлении в виде дерева, будут учтены все находящиеся под ними записи данных.
