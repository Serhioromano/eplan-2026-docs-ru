## Диалоговое окно Сохранить порядок свойств

Вы открыли проект.

* Вы вставили символ в Графическом редакторе или генерировали новую функцию в Навигаторе.
* Вы выделили функцию в графическом редакторе или навигаторе. Пункт всплывающего меню Свойства.

Выберите в диалоговом окне Свойства <...> вкладку Отображение. В списке Порядок свойств выберите запись "Опред. пользователем", обработайте порядки свойств и щелкните по кнопке  (Сохранить) на панели инструментов, расположенной над раскрывающимся списком.

При помощи этого диалогового окна сохраните связанный с пользователем порядок свойств под независимым от языка именем.

Обзор основных элементов диалогового окна:

Порядок свойств:

Укажите в этом поле описательное название для порядка свойств. Сразу после сохранения пользовательского порядка свойств можно выбрать имеющееся имя из раскрывающегося списка и перезаписать старый порядок свойств.

!!! note "Замечание:"

    В случае перезаписи определенного пользователем порядка свойств измененныенастройкиотображения будут перенесены на все условныеобозначения, использующие данный порядок свойств.

 

Использовать как стандарт:

Этот флажок доступен только для тех символов и функций, которые не являются точками обозначения соединения.

Установите этот флажок, если сохраненный порядок свойств следует применять по умолчанию во всех других случаях использования этого варианта символа. При этом все порядки свойств, сохраненные ранее для данного варианта символа, будут игнорироваться.

Использовать как стандарт для соединений / Использовать как стандарт для кабельных соединений:

Этот флажок доступен только для тех символов/ функций, которые являются точками обозначения соединения!

Установите флажок Использовать как стандарт для соединений, если новый сохраненный порядок свойств должен использоваться по умолчанию во всех других случаях использования этого варианта символа для "обычных" точек обозначения соединения. Порядок свойств используется также для точек определения соединений, возникающих при нумерации соединений. Для этого в настройках нумерации соединений на вкладке Отображение необходимо установить флажок Использовать стандарт.

Установите флажок Использовать как стандарт для кабельных соединений, если новый сохраненный порядок свойств должен использоваться по умолчанию во всех других случаях использования этого варианта символа для точек обозначения соединения для кабельных соединений. Точки определения соединений для кабельных соединений размещаются при чертеже кабелей / экранирований или при перетаскивании мышью из навигатора кабелей или навигатора соединений в графическом редакторе.

Выполненные здесь настройки также отображаются в диалоговом окне Конфигурировать порядки свойств — <Имя проекта>. Там можно обработать все порядки свойств.
