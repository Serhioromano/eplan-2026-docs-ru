## Виды в навигаторе ПЛК

В представлении структуры дерева диалогового окна навигатора ПЛК — <Имя проекта> можно выбирать разные виды для отображения данных ПЛК.

Во всех видах отображаются все существующие в проекте данные ПЛК, т. е. блоки ПЛК, все выводы устройств ПЛК и шаблоны функций. При этом отображаются как пустые блоки ПЛК, так и блоки ПЛК, содержащие только шаблоны функций.

С помощью пункта всплывающего меню Вид доступны следующие виды:

* С ориентацией на ОУ: Данные ПЛК располагаются согласно структуре проекта по их ОУ.
* С ориентацией на адрес: Данные ПЛК располагаются в пределах структуры проекта по адресам. Т. е. ниже адреса ПЛК отображаются выводы устройства В/В ПЛК. Соответствующие источники питания только тогда отражаются ниже адреса ПЛК, когда при источнике питания внесен соответствующий адрес ПЛК. Стоящая впереди пиктограмма  указывает, есть ли под этим адресом неразмещенные соединения ввода/вывода. Дополнительно блоки и выводы устройств ПЛК группируются под соответствующим ЦПУ, если данное свойство внесено в соответствующий блок ПЛК.
* С ориентацией на канал: Данные ПЛК располагаются в пределах структуры проекта по каналам. Т. е. под обозначением канала отображаются выводы устройства В/В и соответствующие источники питания. Пиктограмма  для канала отображает, находится ли под ним релевантный для безопасности вывод устройства. Дополнительно установленная пиктограмма  отображает, содержит ли канал неразмещенные выводы устройства В/В. Выводы устройств ПЛК, у которых нет ни внесенного вручную, ни автоматически определенного обозначения канала, упорядочиваются согласно ОУ.
* Ориентировать по каркасу: Данные ПЛК отображаются в соответствии с присвоением карт ПЛК каркасам. Каркасы отмечаются стоящей впереди пиктограммой ; под ней перечислены карты ПЛК (пиктограмма ) с адресами шины. Последовательность соответствует номерам позиций разъемов. Под картами ПЛК показываются содержащиеся в них функции.  
Карты ПЛК, вставленные или интегрированные в первичную станцию, обозначаются пиктограммой . Карты ПЛК, вставленные рядом с первичной станцией, обозначаются пиктограммой . Первичная станция одновременно является каркасом и поэтому обозначается стоящей впереди пиктограммой . Под каркасом отображаются сначала карты ПЛК, вставленные в первичную станцию, а затем все остальные карты ПЛК.  
Для устройств, находящихся на подразъеме, это отображение возможно за счет того, что за номером разъема, отделенным десятичной точкой, указывается подразъем, напр. 2.1:=EB3+ET1-A99.
* Связано с приводами: данные ПЛК располагаются в пределах структуры проекта по приводам. Приводы обозначается стоящей впереди пиктограммой . Функции отображаются под уровнями иерархии "Проект конфигураций", "Привод" и "Имя станции". Функции, которые не присвоены приводу, также отображаются здесь. Для этого необходимо, чтобы функции были присвоены проекту конфигурации и / или рабочей станции.

С помощью пункта всплывающего меню Конфигурировать представление можно определить, какие свойства отображаются в представлении структуры дерева определенного вида.

!!! tip "Совет:"

    В ориентированном накаркасвиде можно дополнительно отобразить функциональный текст блока ПЛК на каркасе. Для этого в диалоговом окнеКонфигурировать представлениедоступен объект "Функция: Блок ПЛК (вид с ориентацией по каркасу)". Щелкните для этого объекта в полеФормат блокапо[...], чтобы задать требуемый формат и, при необходимости,разделитель. Щелкните дважды в диалоговом окнеФорматв списке доступных элементов формата по элементу "Общая функция" и выберите в следующем диалоговом окнеФормат: Свойство блокаэлемент "Функциональный текст (автоматически)".
