# Создать узлы

Узлом является коллекция изделий, которые относятся к одному устройству (напр., кнопочный переключатель с замыкающим контактом, соответствующим кронштейном и нажимной кнопкой). Узел имеет собственный номер изделия и может и сам содержать узлы. изделия, которые содержатся в узлах, имеют также информацию о вариантах изделия. Именно при выборе устройства или для отчетов в этом случае учитываются и технические данные вариантов.

Условия:

* Вы открыли диалоговое окно **База данных изделий** (вкладка **Основные данные** > группа команд **Изделия** > **Управление**).
* В дереве выделен уровень иерархии "Узел" или изделие в узле.

1. Выберите в дереве пункт всплывающего меню **Создать**.

![](images/arrow.png) При выделении уровня иерархии "Узел" Eplan генерирует новый узел с номером изделия `Создать(<порядковый_номер>)`.

![](images/arrow.png) Когда выделено изделие узла, Eplan генерирует новый узел с номером изделия `исходный_номер_изделия(<порядковый_номер>)`.
2. Перейдите справа в диалоговом окне на вкладку **Свойства**.
3. Измените автоматически назначенную запись для свойства **Номер изделия** на уровне иерархии **Общее**.
4. Измените группировку продуктов для узла, если появились уровни иерархии с обозначением "Не определено". Это происходит, например, когда выделен уровень иерархии "Узел".
5. Для этого нажмите для свойства **Группировка продуктов** в столбец **Значение** и на кнопку ++"..."++. Из раскрывающегося списка группировок продуктов выберите нужную подгруппу продуктов (например, "Общие"), дважды щелкнув по ней.

![](images/arrow.png) Выбранная группировка продуктов отображается в свойстве **Группировка продуктов**. После применения изменений группировка продуктов также отображается для уровней иерархии в дереве.
6. Введите дополнительные данные узла на вкладке **Свойства** (например, производитель).
7. Нажмите на ++"Применить"++, чтобы сохранить введенные данные и изменения, не выходя из базы данных изделий.

!!! note "Замечание:"

    Если для главной группы продуктов (например, Fluid) в дереве отсутствует уровень иерархии "Узел", создайте узел с помощью пунктов всплывающего меню **Создать** > **Узел**.

## Присвоение позиций узла

Условия:

* Вы открыли диалоговое окно **База данных изделий** (вкладка **Основные данные** > группа команд **Изделия** > **Управление**).
* Вы создали узел.

1. Выделите в дереве или списке нужный узел.
2. Перейдите справа в диалоговом окне на вкладку **Узел**.
3. Щелкните по ![](images/all_new_as.png) (Создать), чтобы создать строку в списке позиций узла.
4. Нажмите в столбце **Номер изделия** на кнопку ++"..."++.
5. Выберите в диалоговом окне **Выбор изделия** в представлении в виде дерева или списка нужное изделие. Многократный выбор невозможен.
6. Щелкните по кнопке ++"OK"++.
7. Повторите эти шаги для всех других присвоений.
8. Если вы хотите, чтобы узел был размещен в трехмерном чертеже монтажных поверхностей в распределенном виде, установите флажок **Распределенное размещение узла**.
9. Закройте базу данных изделий и сохраните измененные данные.
10. Нажмите ++"Да"++ в следующем диалоговом окне, чтобы выполнить синхронизацию данных изделий.

!!! note "Замечание:"

    Предварительной настройкой для новой строки является текущая выбранная настройка, т. е. ее данные по числу и номеру изделия будут скопированы. Если ни одна запись не выделена, будет сгенерирована пустая строка (с предварительной настройкой **Количество** = "1").
