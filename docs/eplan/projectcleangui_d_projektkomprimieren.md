## Диалоговое окно Сжать проект

Вы открыли проект. Файл > Дополнительно > группа команд Организовать > Проект > группа команд Оптимизировать > Сжать проект.

В этом диалоговом окне можно указать схему для объема сжатия. Последние настройки сохраняются в связи с проектом.

Обзор основных элементов диалогового окна:

Настройки:

В этом поле выберите схему, содержащую необходимые настройки сжатия. С помощью кнопки [...] откройте диалоговое окно Настройки: Сжатие. Здесь может быть обработана существующая схема или создана новая схема.
