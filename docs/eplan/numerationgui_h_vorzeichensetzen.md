## Установить предшествующий знак в видимом ОУ

Видимое ОУ устройств может выводиться с предшествующим знаком, например -M1, или без предшествующего знака, например M1. Можно раздельно установить эти настройки для всех групп устройств. Группы устройств, например "Общие устройства", "Клеммники", "Штекеры", "Черные ящики".

Условие:

Вы открыли проект.

1. Выберите следующие команды: Файл > Настройки > Проекты > "Имя проекта" > Устройства > ОУ.
2. Установите в диалоговом окне Настройки: ОУ в групповом поле Установить предш. знак флажок тех групп устройств, видимое ОУ которых должно быть отображено без предшествующего знака.
3. Щелкните по кнопке [OK].
