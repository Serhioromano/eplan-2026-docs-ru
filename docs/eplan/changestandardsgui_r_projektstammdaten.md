## Вкладка Основные данные (Изменение стандарта)

[Вызов диалогового окна:](javascript:void\(0\);)

Вы открыли проект. При нескольких открытых проектах: В навигаторе страниц выделен проект. Вкладка Инструменты > группа команд Стандарты > Заменить. Вы определили на вкладке Проект все настройки. Кнопка [Далее]. Вы определили на вкладке Поворот / инверсия все настройки. Кнопка [Далее].

На вкладке перечислены все основные данные, которые используются в проекте и которые можно заменить. К основным данным относятся формы, рамки, библиотеки определений функций и библиотеки символов.

Обзор основных элементов диалогового окна:

Основные данные проекта:

Строка показывает присвоение основных данных исходной библиотеки основным данным целевой библиотеки.

  * Имя: в этом столбце находятся все основные данные, используемые в проекте. Отображается имя файла основных данных.
  * Тип: в этом столбце находится описание типа основных данных. Типами основных данных, которые можно заменить в этом диалоговом окне, являются библиотеки символов и библиотеки определений функций, формы и рамки.
  * Дата изменения: в этом столбце отображается дата последнего изменения основных данных исходного проекта.
  * Новое имя: при помощи этого столбца осуществляется замена основных данных. Щелкните в поле и выберите с помощью кнопки [...] основные данные для целевого проекта. Если поля пустые, основные данные копируются из исходного проекта в целевой проект.
  * Присвоить отдельно: этот флажок доступен только для библиотек символов. Если этот флажок установлен, символы библиотеки исходных и целевых символов можно по отдельности присвоить друг другу. Если флажок снят, присваиваться будет вся библиотека символов.
