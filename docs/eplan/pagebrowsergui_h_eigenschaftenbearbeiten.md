## Обработать свойства страницы

В диалоговом окне навигатора Страницы — <Имя проекта> можно просмотреть или обработать свойства страниц.

Условие:

Вы открыли проект. Открыто диалоговое окно навигатора Страницы — <Имя проекта>.

1. Выделите необходимую страницу в дереве или списке. Возможен многократный выбор.
2. Выберите пункт всплывающего меню Свойства.
3. Измените требуемые свойства в диалоговом окне [Свойства страницы](eplan/pagebrowsergui_d_seiteneigenschaften.md).
4. Щелкните по кнопке [OK].

!!! note "Замечание:"

    В случае изменения идентифицирующих свойств страницы, например свойстваФункциональное назначение, все ОУ на странице также переименовываются с использованием этого же функционального назначения.

 

!!! tip "Совет:"

    В представлении в виде списка навигатора страниц некоторые поля (Описание страниц,Номер чертежаи т. д.) можно обрабатывать прямо в таблице.
