## Диалоговое окно "Экспорт STEP" / диалоговое окно "Экспорт VRML" / диалоговое окно "Экспорт IFC" / диалоговое окно "Экспорт JT"

Вы открыли проект. В навигаторе пространства листа выбрано пространство листа. Файл > Экспортировать > группа команд Данные проекта > Пространство листа > STEP, VRML, IFC или JT.

В этом диалоговом окне устанавливаются настройки для экспорта трехмерных графических данных в формат STEP, VRML, IFC или JT.

Обзор основных элементов диалогового окна:

Источник:

В этом поле выводится на просмотр источник экспорта. Если указан весь проект, то появляется его имя, а для отдельных пространств листа отображаются полные имена пространств листа (включая структурные идентификаторы: Функциональное присвоение, Функциональное назначение и т. д.). Обработка записей в данном поле невозможна.

Схема:

Выберите из раскрывающегося списка схему, которая определяет настройки для экспорта STEP, VRML, IFC или JT.

С помощью кнопки [...] можно открыть диалоговое окно Настройки: Экспорт STEP, диалоговое окно Настройки: Экспорт VRML, диалоговое окно Настройки: Экспорт IFC или диалоговое окно Настройки: Экспорт JT. В этом диалоговом окне указываются настройки для экспорта файлов STEP, VRML, IFC или JT, после чего настройки сохраняются в виде схемы.

Каталог вывода:

Здесь указывается место сохранения. Здесь предварительно выбран каталог, заданный в настройках пользователя для экспорта STEP, VRML, IFC или JT. Кнопка  открывает диалоговое окно Выбрать папку для выбора любого каталога для экспорта.

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](eplan/modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

Имя файла:

При экспорте отдельного пространства листа допустим ввод любого имени файла. С помощью кнопки  можно также свободно задавать имя файла или выбирать имя уже имеющегося файла.

Если специальное имя файла не введено, экспортированному файлу присваивается имя в зависимости от настройки [Генерировать имена файлов](gededit3dgui_d_einstellungenstepexport.htm#Dateinamenerzeugen).

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](eplan/modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

При экспорте нескольких пространств листа невозможен свободный ввод имени файла. Файлы STEP, VRML, IFC или JT будут генерироваться в заданном целевом каталоге с учетом порядкового номера, из имен пространств листа или из свойств в зависимости от настроек выбранной схемы.

Если выбрано пространство листа, содержащее несколько электрошкафов, и при этом в диалоговом окне Настройки: Экспорт STEP активирована настройка Отдельный экспорт для каждого электрошкафа, задать имя файла невозможно. Поле Имя файла в этом случае деактивируется.

Применить ко всему проекту:

При установке данного флажка текущий выбор пространства листа распространяется на все пространства листа проекта.

Если флажок не установлен, экспортируются только выделенные пространства листа.

Если отдельный проект уже выделен (и при этом фильтры не установлены), флажок недоступен. В этом случае настройку больше невозможно изменить.
