## Диалоговое окно Настройки: Экспорт Rittal - Perforex BC / Secarex

[Вызов диалогового окна:](javascript:void\(0\);)

  * Файл > Настройки > Фирма > Механическая обработка > Экспорт Rittal - Perforex BC / Secarex
  * Файл > Экспортировать > группа команд Данные изготовления > Механическая обработка > Rittal - Perforex BC. Нажмите рядом с полем Машина на кнопку [...].



В этом диалоговом окне можно конфигурировать машины ЧУ Perforex BC / Secarex производителя Rittal.

Обзор основных элементов диалогового окна:

Машина:

В комплекте поставки содержится определение машины с названием "Стандарт". Если в качестве схемы сгенерирована другая машина, можно выбрать из раскрывающегося списка другие определения машины и работать с ними.

Через расположенную рядом [панель инструментов](schemeconfig_m_schemaschaltflaechen.htm) можно создавать новые схемы, сохранять изменения в схеме, копировать или удалить схему. Кроме того, схемы можно импортировать и экспортировать.

Описание:

В этом поле дается описание, которое было введено в диалоговом окне Новая схема в поле Описание для машины.

Вкладки:

Для конфигурирования экспорта ЧУ в формате Rittal - Perforex BC / Secarex доступны следующие вкладки:

  * [Вкладка Общ.](ncgui_r_allgemeinexportkiesling.htm)
  * [Вкладка "Обозначение поля"](ncgui_r_feldbezeichner.htm)
  * [Вкладка Инструменты](ncgui_r_werkzeuge.htm)
  * [Вкладка Выбор инструмента](ncgui_r_werkzeugauswahl.htm)
  * [Вкладка Технологические перемычки](ncgui_r_stegparameter.htm)
  * [Вкладка Исключения при сверлении](ncgui_r_bohrausnahmen.htm)
