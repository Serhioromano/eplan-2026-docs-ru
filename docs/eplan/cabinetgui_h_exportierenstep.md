# Экспортировать трехмерные графические данные

Трехмерные графические данные могут быть экспортированы из Eplan Pro Panel для дальнейшего использования в других CAD-программах в форматах STEP, VRML, JT и в открытом стандарте данных IFC.

Условие:

Вы открыли проект. Вы открыли пространство листа.

1. Выделите в навигаторе пространство листа проект или пространства листа, содержания которых нужно экспортировать.
2. Выберите следующие команды: Файл > Экспортировать > группа команд Данные проекта > Пространство листа > группа команд Пространство листа > STEP или VRML или IFC или JT.
3. В поле "Схема" диалогового окна Экспорт STEP, Экспорт VRML, Экспорт IFC или Экспорт JT выберите нужную схему экспорта из выпадающего списка Схема. Или щелкните по ++...++, чтобы создать в следующем окне настройки новой определенной пользователем схемы.
4. Введите в поле Каталог вывода место хранения создаваемого файла экспорта или откройте диалоговое окно Выбрать папку с помощью кнопки ![](images/all_selectdirectory_as.png){ .ui-icon }, чтобы выбрать любой каталог для экспорта.
5. Введите в поле Имя файла имя, под которым будет сохранен файл экспорта. Или выберите имя в интерактивном режиме через ![](images/all_selectfile_as.png){ .ui-icon }.

!!! info "Для сведения:"

    Если вы выбираете уже имеющийся файл, отображается запрос. Выберите, нужно ли перезаписать файл.

6. Щелкните по кнопке ++OK++.

!!! info "Для сведения:"

    Данные будут записан в файл экспорта.
