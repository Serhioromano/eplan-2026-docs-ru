## Вкладка "Общие" (Komax — Zeta)

* Файл > Настройки > Компания > Сборка проводов > Komax — Zeta > вкладка Общие
* Файл > Экспортировать > группа команд Данные изготовления > Сборка проводов > Komax - Zeta. Нажмите рядом с полем Схема на кнопку [...]. Выберите вкладку Общее.

В этой вкладке определяется путь файла и имя файла для экспорта данных провода на машины для сборки проводов Komax — Zeta.

Обзор основных элементов диалогового окна:

Каталог вывода:

Укажите здесь место хранения. В качестве целевых для экспорта данных можно указать любой дисковод и подкаталог. Нажав , откройте диалоговое окно Выбрать папку и перейдите к требуемому каталогу или создайте новый.

С помощью пункта всплывающего меню "Вставить переменную пути" перейдите в диалоговое окно [Выбрать переменную пути](eplan/modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

Генерировать подкаталоги:

В этом раскрывающемся списке определяется стандартный порядок создания подкаталогов при экспорте файлов Komax:

* Нет: Если выбран данный параметр, при экспорте подкаталоги не генерируются.
* Из свойств: Если выбран этот параметр, имя подкаталога составляется из свойств пространства листа и проекта, а также свободно определяемого разделителя. При нажатии кнопки [...] открывается диалоговое окно Формат: Свойство для конфигурации имени каталога. Воспользуйтесь, например, элементом формата "Разделитель каталога", чтобы создать структуру каталога с несколькими подкаталогами, расположенными друг под другом.
