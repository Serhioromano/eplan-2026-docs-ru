## Диалоговое окно Определение атрибута

* Файл > Настройки > Пользователь > Интерфейсы > Экспорт и импорт DXF / DWG. Выберите вкладку Атрибут блока. Выберите запись из списка Доступные свойства и нажмите на  (переместить направо).
* Файл > Экспортировать > группа команд Данные проекта > Данные проекта > группа команд Страница > DXF / DWG. Нажмите рядом с полем Схема на кнопку ++...++. Выберите вкладку Атрибут блока. Выберите запись из списка Доступные свойства и нажмите на  (переместить направо).

В этом диалоговом окне задаются присвоения свойств Eplan атрибутам AutoCAD.

Обзор основных элементов диалогового окна:

Категория:

Выберите из раскрывающегося списка категорию, свойства которой должны быть выведены в списке ниже. Отображаются свойства для элемента, выбранного в Доступные свойства.

Обозначение атрибута:

Укажите обозначение, под которым выбранный элемент будет передан в AutoCAD.

Требование ввода:

Введите здесь требование ввода для выбранного свойства.
