## Операция: import3d

  
**Параметр** |  **Описание**  
---|---  
TYPE |  Вид задачи, которую должна выполнить операция:  
STEP: Импорт трехмерных графических данных в формате STEP  
DESIGNSPACE: Импорт пространств конструкции (в виде файла STEP)  
JT: Импорт трехмерных графических данных в формате JT  
  
PROJECTNAME |  Имя проекта с полным путем к файлу.  
Если не задано, то выбранный проект используется, когда операция вызывается через интерфейс пользователя (например, через сценарий или ленту). При вызове из командной строки Windows следует определить PROJECTNAME или сначала следует использовать ProjectAction. В противном случае отобразится системное сообщение.  
IMPORTFILE |  Путь и имя файла.  
  
SCHEME |  Схема импорта (является опцией). Если данный параметр отсутствует или пуст (""), то используется последняя использованная схема.
