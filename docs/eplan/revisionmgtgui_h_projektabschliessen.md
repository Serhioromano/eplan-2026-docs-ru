# Закрыть проекты / области обработки

Eplan позволяет закрывать проекты в любой момент. Затем проект защищается от записи и не может быть изменен. Закрытый проект сохраняется в каталоге проектов с расширением имени файлов `*.elr`.

Области обработки также можно закрывать в любой момент. В этом случае от записи будут защищены только те страницы или пространства листа, которые относятся к выбранной области обработки.

Условие:

Открыт стандартный проект (Расширение имени файла `*.elk`) или проект ревизии (Расширение имени файла `*.ell`).

1. Выберите следующие команды: **Файл** > **Управление ревизиями** > группа команд **Проект** > **Закрыть** > **Закрыть проект / область**.

![](images/arrow.png) Если закрыть стандартный проект, проект защищается от записи и сохраняется с расширением имени файла `*.elr`.

![](images/arrow.png) При закрытии проекта ревизии открывается диалоговое окно **Закрыть проект**.

![](images/arrow.png) При закрытии области обработки открывается диалоговое окно **Закрыть область обработки**.
2. В диалоговом окне **Закрыть проект** (или **Закрыть область обработки**) введите данные ревизии (индекс ревизии, описание и причину изменения).
3. Установите флажок **Сгенерировать отчет при закрытии проекта**, если необходимо проанализировать проект при его закрытии.
4. Щелкните по кнопке ++"OK"++.

![](images/arrow.png) Сначала закрываются все страницы проекта / области обработки и данные ревизии присваиваются всем измененным страницам проекта ревизии.

![](images/arrow.png) Если закрыть проект, он защищается от записи и сохраняется с расширением имени файла `*.elr`.

![](images/arrow.png) Если закрыть область обработки, страницы области обработки защищаются от записи.
