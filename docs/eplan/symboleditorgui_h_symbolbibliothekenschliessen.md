## Закрыть библиотеки символов

Условие:

Вы открыли проект и как минимум одну библиотеку символов.

  1. Выберите следующие команды: Вкладка Основные данные > группа команд Символы > раскрывающаяся кнопка Библиотека символов > Закрыть.
  2. Если открыто несколько библиотек символов, закройте те, которые нужно закрыть, в диалоговом окне Выбор библиотеки символов и нажмите [OK].  
  
Если открыта только одна библиотека символов, она будет закрыта без дополнительных диалогов.  
  
Если в символ были внесены изменения, которые будут утеряны при закрытии библиотеки, появится запрос, не следует ли сначала сохранить соответствующую страницу.



!!! note "Замечание:"

    В случаепрерываниязапроса при закрытии / сохранении для символа будет прервано и закрытие библиотек символов.
