## Диалоговое окно Конфигурировать представление (список)

[Вызов диалогового окна:](javascript:void\(0\);)

Вы открыли проект и находитесь в представлении навигатора в виде списка, в представлении диалогового окна Выбор символа в виде списка и т. д. Выберите пункт всплывающего меню Конфигурировать представление.

В этом диалоговом окне можно определять отображение и последовательность соответствующих данных таким образом, чтобы выводилась только релевантная информация.

Обзор основных элементов диалогового окна:

Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать или обработать. Для этого также воспользуйтесь соседней [панелью инструментов](schemeconfig_m_schemaschaltflaechen.htm).

Конфигурация:

В этом поле укажите, какие свойства следует отображать. С помощью кнопки  (Создать) можно выбирать другие свойства и вставить их в список. С помощью кнопок со стрелками можно изменять последовательность свойств.

Всплывающее меню:

Пункт меню |  Значение  
---|---  
Выделить все |  Выделяет все записи в списке.  


!!! note "Замечание:"

    Приконфигурациипредставления в виде списка в диалоговом окнеКонфигурировать представлениевсегдаотображаются определенные свойства. Такие свойстваневозможноудалить из списка в полеКонфигурация. Таким образом, например, свойствоИмя проектаотображается в представлении в виде списка навигаторов всегда в виде столбца, если открыто более одного проекта или, наоборот, не открыт ни один проект.
