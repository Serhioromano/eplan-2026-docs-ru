# Вставить новые устройства без ОУ

Новые устройства / функции могут быть размещены на схеме соединений действиями Вставить > Символ без автоматического присвоения ОУ. При этом записи видимого и полного ОУ остаются пустыми.

Условие:

Вы открыли проект.

1. Выберите следующие команды: **Файл** > **Настройки** > **Проекты** > "Имя проекта" > **Устройства** > **Нумерация (online)**.
2. Выберите в групповом поле **При вставке символов** опцию **Пустое поле**.
3. Щелкните по кнопке ++"OK"++.

### Вставить устройство / функцию через символ без ОУ

1. Выберите следующие команды: **Центр вставки** > строка навигации **Главная** > **Символы**. Перейдите через структуру папок к нужному символу и выберите его, щелкнув на плитку предварительного просмотра.

!!! info "Для сведения:"

    Символ появится рядом с курсором.

2. Переместите курсор в нужное место на странице схемы.
3. Для размещения символа щелкните по странице.

!!! info "Для сведения:"

    Откроется диалоговое окно **Свойства (усл. обозначение):** ++"..."++. В поле **Видимое ОУ** ОУ не внесено.

4. Щелкните по кнопке ++"OK"++.

!!! info "Для сведения:"

    Символ размещается без ОУ.

### Создать устройство / функцию без размещения и без ОУ

1. Выберите следующие команды: Вкладка **Устройства** > группа команд **Устройства** > **Навигатор.**
2. Выберите вкладку **Дерево**.
3. Выделите уровень проекта.
4. Выберите пункт всплывающего меню **Создать**.
5. Выделите в диалоговом окне **Определения функций** в поле **Выбор** определение функции и нажмите на кнопку ++"ОК"++.

!!! info "Для сведения:"

    Откроется диалоговое окно **Свойства (усл. обозначение):** ++"..."++. В поле **Видимое ОУ** ОУ не внесено.

6. Щелкните по кнопке ++"OK"++.

!!! info "Для сведения:"

    Устройство / функция сортируется на уровне структуры дерева Без ОУ.
