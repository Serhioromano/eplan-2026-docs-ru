## Разместить подсоединенные функции

Подсоединенными являются любые функции, которые подсоединены к устройству непосредственно через соединения. Когда вы размещаете устройство, вы можете с помощью команды Подсоединенные функции автоматически разместить все соединения и функции, непосредственно подсоединенные к уже размещенной функции.

Условия:

* Вы создали минимум 2 неразмещенных устройства, имеющих выводы.
* Вы создали между устройствами [неразмещенные соединения](planningconnections_h_createconnections.md).
* В Графическом редакторе открыта страница проекта.

1. Выберите следующие команды: Вкладка Устройства > группа команд Устройства > Навигатор.
2. Выделите устройство, обладающее подсоединенными через соединения функциями.
3. Перетащите устройство мышью на страницу проекта.
4. Выделите размещенное устройство.
5. Выберите следующие команды: Вкладка Вставить > группа команд Устройства > Подсоединенные функции.  

Все непосредственно подсоединенные неразмещенные соединения и функции размещаются.
6. Для обновления нажмите [F5].
