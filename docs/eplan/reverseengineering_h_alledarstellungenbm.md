## Обработать свойства во всех представлениях главной функции

Главная функция может быть многократно представлена в проекте в распределенном виде, например, как однополюсная или многополюсная функция, функция обзора, парная перекрестная ссылка и / или функция функциональной схемы автоматизации. С помощью функциональности "Свойства (общие)" можно за одну операцию изменить общие свойства сразу всех представлений функции одной главной функции, например, функциональный текст всех представлений функции одной катушки.

!!! note "Замечание:"

    Данный способ не действует для свойстваПолное ОУ. Если в режиме обработкиСвойства (общие)изменитьПолное ОУглавной функции, ОУ будет изменено на всех представлениях функцииустройства.

 

Условия:

* Вы открыли проект.
* Открыт Навигатор устройств или Графический редактор.

1. Выделите представление функции главной функции в навигаторе устройств или в графическом редакторе и выберите пункт всплывающего меню Свойства (общие).  
Если вы активировали режим Свойства (общие) (командный путь: вкладка Обработать > группа команд Параметры > Общие), дважды щелкните по представлению функции главной функции.  
  
В диалоговом окне Свойства (общие): <...> на вкладке <Категория функции> (Устройство) нанесено обозначение категории функции соответствующего определения функции, например, "Катушка", и дополнение "(Устройство)" для устройства.
2. Измените требуемые свойства главной функции.
3. Щелкните по кнопке [OK].
4. Для обновления нажмите [F5].   
  
Свойства будут изменены на всех других соответствующих представлениях функции выбранной главной функции.

!!! note "Замечание:"

    На вкладкахОтображение,Данные символа / функциииФорматобщие свойства не отображаются. На этих вкладках можно обрабатывать только выбранное представление функции главной функции. Все другие соответствующие представления функции не изменяются.
