# Вкладка Определенные пользователем свойства

## Вызов диалогового окна:

Вкладка **Основные данные** > группа команд **Изделия** > **Управление**. В дереве или списке выделено одно изделие. Выберите вкладку **Определенные пользователем свойства**.

На этой вкладке вы присваиваете определенные пользователем свойства изделию, которое вы ранее создали и настроили в [диалоговом окне конфигурации](eservicesgui_d_konfigeigenschaften.md) для базы данных изделий. Эти свойства присвоены только выбранному варианту изделия.

Обзор основных элементов диалогового окна:

### Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать. Или щелкните по кнопке ++"..."++, чтобы в диалоговом окне **Конфигурировать свойства** обработать или создать схему.

!!! note "Замечание:"

    Управление схемами присвоения определенных пользователем свойств выполняется для каждого конкретного пользователя. Это приводит к тому, что при работе в многопользовательском режиме (когда несколько пользователей имеют доступ к одной базе данных изделий) изменения в такой схеме не синхронизируются автоматически, т. е. не отображаются для другого пользователя. Во время работы в многопользовательском режиме мы рекомендуем управлять этими схемами централизованно и делать их доступными для других пользователей с помощью экспорта и импорта в диалоговом окне **Конфигурировать свойства**. Аналогичное поведение применимо и к схемам присвоения произвольных свойств.

### [Присвоить схему]:

Эта кнопка используется для ввода определенных пользователем свойств, сохраненных в схеме, на вкладке. Если свойства уже назначены, то определенные пользователем свойства прикрепляются из схемы. Если свойство уже выбрано и существует в схеме, его значения во время присвоения не изменяются.

Если ранее присвоенная схема удаляется, то определенные пользователем свойства этой схемы по-прежнему назначаются изделию.

Таблица

В таблице отображаются определенные пользователем свойства, присвоенные изделию.

С помощью кнопки ![](images/all_new_as.png) (Создать) для изделия можно свободно выбирать определенные пользователем свойства или присваивать изделию предварительно заданный набор определенных пользователем свойств с помощью кнопки ++"Присвоить схему"++.

Если впоследствии выбрать изделие или устройство, эти определенные пользователем свойства со значениями будут перенесены в соответствующую главную функцию.

### Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).

Дополнительно здесь представлены следующие пункты всплывающего меню, специфические для данного диалогового окна:

Пункт меню |  Значение
---|---
Конфигурировать свойства |  Доступны только определенные пользователем свойства без определения. Это может произойти, если импортировать изделия из версии 2.9 с присвоенными определенными пользователем свойствами или схемами для определенных пользователем свойств. Этот пункт всплывающего меню дает возможность перейти в диалоговое окно **Конфигурировать свойства** и сконфигурировать это свойство там. В диалоговом окне напрямую задаются целесообразные значения. Затем можно отредактировать определенное пользователем свойство на вкладке **Определенные пользователем свойства**.

!!! tip "Совет:"

    Чтобы в базе данных изделий можно было найти изделия, которым определенные пользователем свойства назначены без определения, в классе сообщений 502 "Основные данные изделия" доступен контрольный прогон 502035.

### [Произвольн. свойства]:

Нажмите на эту кнопку, чтобы открыть диалоговое окно **Произвольн. свойства**.
