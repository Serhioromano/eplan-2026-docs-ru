## Добавить изделие

В отличие от добавления изделий проекта при помощи этого пункта меню присвойте текущему устройству одно (или несколько) другое(ие) изделие(я).

Условие:

Вы открыли проект.

1. Выберите следующие команды: Вкладка Устройства > группа команд Устройства > Спецификация.
2. В диалоговом окне Спецификация — <Имя проекта> выделите устройства, которым необходимо присвоить другие изделия.
3. Выберите пункт всплывающего меню Добавить изделие.
4. В диалоговом окне Выбор изделия выберите добавляемые изделия. Возможен многократный выбор.
5. Щелкните по кнопке [OK].  
  
Новые изделия присваиваются устройствам.

!!! note "Замечание:"

    Могут быть использованы всефункцииВыбор изделия, причем учитываются предварительныенастройки, специфические длябазы данных изделий.
