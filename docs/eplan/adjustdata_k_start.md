## Синхронизация и корректировочный прогон

Синхронизация и корректировочные прогоны позволяют синхронизировать данные проекта для всего проекта, устраняя несоответствия и противоречия. Ниже приведен список случаев, когда могут потребоваться синхронизация и корректировочные прогоны:

* Устройства с двойными / лишними главными функциями: устройство может содержать исключительно одну главную функцию. Чтобы удалить двойные / лишние главные функции из устройства, можно преобразовать все двойные / лишние главные функции во вспомогательные функции в действии для всего проекта.
* Избыточные данные с несколькими и разными видами представления функции: в Eplan можно представить функцию в проекте в распределенном виде, например как однополюсную функцию, многополюсную функцию, функцию обзора, функцию парной перекрестной ссылки или функцию функциональной схемы автоматизации. Кроме того, допускается многократное присутствие функции в одном виде представления, как, например, блок ПЛК, представляемый двумя многополюсными функциями на двух различных страницах. Свойства функции можно обрабатывать в любом виде представления. Для обработки свойств распределения представленных функций с целью унификации можно синхронизировать связанные друг с другом функции.
* Вспомогательная функция должна быть главной функцией: можно преобразовать вспомогательную функцию в главную. Исходная главная функция при этом становится вспомогательной функцией.
