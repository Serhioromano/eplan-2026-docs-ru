## Диалоговое окно Экспортировать настройки

Файл > Настройки. Выделите область настройки "Пользователь" или "Рабочая станция" и щелкните по кнопке  (Экспортировать).

В этом диалоговом окне определяется, в какой целевой файл будут экспортированы настройки выбранной области настройки.

Обзор основных элементов диалогового окна:

<Путь иерархии>:

Текст рядом с флажком указывает на то, какая область настройки выделена в диалоговом окне Настройки в представлении в виде дерева. Если этот флажок установлен, экспортируется выделенная область настройки и все нижестоящие области настройки.

Другие области настройки:

Здесь указывается, какие другие настройки программы и конфигурации также следует экспортировать. Если этот влаг установлен, то выполняется их экспорт. Доступность флажков зависит от того, какая область настройки выделена в диалоговом окне Настройки в представлении в виде дерева.

* Конфигурация свойств: Экспортирует конфигурации свойств устройств, страниц и т. д., заданные соответствующим образом в диалоговом окне Свойства <...> через пункт всплывающего меню Конфигурировать.
* Диалоговая память: Экспортирует из диалоговых окон, например, размер, положение на экране, разрешение экрана, статус "Свернуто" / "Развернуто", а для таблиц в диалоговых окнах настройки ширины столбцов, высоты строк и выделения текста полужирным.

!!! note "Замечание:"

    При импорте / экспорте настроек для диалоговой памяти рекомендуется установить одинаковое разрешение экрана на разных рабочих станциях. В случае разного разрешения экрана диалоговые окна могут выйти за пределы видимой области экрана.

* Текущая рабочая область: экспортирует все определенные пользователем рабочие области.
* Конфигурации дерева и списка: Экспортирует все конфигурации для представлений навигаторов в виде дерева и в виде списка, которые были заданы через пункт всплывающего меню Конфигурировать представление.
* Фильтр: Экспортирует все определенные пользователем настройки фильтра.
* Комбинации клавиш: экспортирует все заданные комбинации клавиш.
* Центр вставки избранного: экспортирует все избранные элементы, заданные в центре вставки. (Эта настройка доступна только в области настройки "Пользователь".)
* Центр вставки тегов: экспортирует все теги, заданные в центре вставки. (Эта настройка доступна только в области настройки "Фирма".)

Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](eplan/userinterface_m_kontextmenu.md).

Целевой файл:

В этом поле выводится предложение пути и имени файла экспорта. По умолчанию файл экспорта получает имя, которое соответствует выделенной области в дереве диалогового окна Настройки. Имя файла состоит из следующих элементов: <Основная категория>+<Подкатегория>+<Область настройки>.xml. С помощью  можно указать другой путь или имя файла экспорта.
