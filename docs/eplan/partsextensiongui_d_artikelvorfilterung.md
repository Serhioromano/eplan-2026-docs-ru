# Диалоговое окно Настройки: Предварительная фильтрация изделий

Файл > Настройки > Пользователь > Управление > Предварительная фильтрация изделий.

В этом диалоговом окне вы можете предварительно отфильтровать базу данных изделий, навигатор основных данных изделий, выбор изделия, выбор устройства и центр вставки на основе определенных свойств.

Обзор основных элементов диалогового окна:

### Фильтр:

В этом раскрывающемся списке содержатся все уже определенные схемы фильтра. С помощью кнопки ++...++ перейдите в диалоговое окно [Фильтр](modaldialogsdb_d_filternnach.md), в котором можно создать новую схему и присвоить новые критерии фильтра. При этом в диалоговом окне Выбор критериев представлены такие свойства изделия, как Деталь, снятая с производства, Номер ERP / PDM и т. д.

!!! note "Замечание:"

    * Если установлена предварительная фильтрация изделий, то пиктограмма Eplan Data Portal не будет отображаться в управлении изделиями, в выборе изделия и в центре вставки. В этом случае поиск в Eplan Data Portal невозможен.
    * Если такой фильтр активирован, то в строке заголовка приведенного выше диалогового окна перед именем базы данных изделий отображается текст "(Предварительная фильтрация)" (например, Управление изделиями - (Предварительная фильтрация) <EPLAN_parts>). Это относится ко всем приведенным выше диалоговым окнам, за исключением центра вставки. В центре вставки текст "(Предварительная фильтрация)" отображается за папкой "Устройства". Эта идентификация используется как на начальной странице, так и при поиске в центре вставки.
    * Предварительная фильтрация изделий влияет на [центр вставки](insertergui_k_start.md). С его помощью можно, например, ограничить предлагаемые для вставки устройства определенным производителем с помощью соответствующей схемы.
