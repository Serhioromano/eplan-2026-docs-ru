# Преобразовать условные обозначения в графику

С помощью команды **Преобразовать** на вкладке **Обработать** у вас есть возможность превратить условное обозначение в графический объект без логической информации. Этой функцией можно пользоваться, например, для графического представления внутренних схем в черных ящиках.

Условное обозначение, преобразованное в графику, не учитывается в отчетах и не может быть преобразовано обратно в работоспособное устройство. (В этом заключается отличие от графического условного обозначения, которое задается с помощью вида представления "Графика").

Условие:

Вы открыли проект. В Графическом редакторе открыта страница проекта. Вы вставили символ.

!!! note "Замечание:"

    При вставке символов в редакторе символов, редакторе форм или редакторе рамок они автоматически преобразуются в графические объекты.

1. Выделите условное обозначение.
2. Выберите следующие команды: Вкладка **Обработать** > группа команд **Упорядочить** > ![](images/ribbon_convertcomponent_as.png) **Преобразовать**.

!!! info "Для сведения:"

    Условное обозначение преобразуется в графический объект. При этом теряется вся логическая информация.

3. Выберите следующие команды: Вкладка **Обработать** > группа команд **Группировать** > **Отменить**, если хотите обработать отдельные графические элементы объекта.
