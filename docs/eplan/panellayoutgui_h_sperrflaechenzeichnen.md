## Начертить заблокированные области

На монтажной плате можно указать области, размещение изделий в которых запрещено. Заблокированные области являются самостоятельными объектами, которые представлены в виде прямоугольника.

Условие:

Вы открыли проект.

1. Выберите следующие команды: Вкладка Устройства > группа команд Компоновка электрошкафа 2D > Навигатор.
2. Выберите в графическом редакторе ту страницу компоновки электрошкафа, на которой следует начертить заблокированную область.
3. Выберите следующие команды: Вкладка Вставить > группа команд Компоновка электрошкафа 2D > раскрывающаяся кнопка Монтажная плата (2D) > Генерировать заблокированную область.
4. Начертите в графическом редакторе прямоугольник, представляющий заблокированную область.  

Выполняется создание заблокированной области.

!!! note "Замечание:"

    Если совершается попытка, установить размещениеизделияв заблокированной области, размещение не выполняется и выводится соответствующее сообщение.
