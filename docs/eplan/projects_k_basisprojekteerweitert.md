## Базовые проекты

Базовые проекты — это шаблоны, из которых можно создавать новые проекты. При этом все данные базового проекта копируются в новый проект.

Тип файла |  Значение  
---|---  
Базовый проект Eplan (*.zw9) |  Базовый проект / файл *.zw9: Из файла *.zw9 можно создавать новые проекты и проекты Eplan сохранять как файл *.zw9.  
  
Базовый проект может содержать, например, следующие настройки проектов, данные проектов и основные данные.

* Все настройки проекта: настройки проекта — это настройки в диалоговом окне Файл > Настройки > Проекты > "Имя проекта". Сюда относятся также и схемы структуры страниц и устройств.
* Все данные проекта: Данные проекта, например неразмещенные и размещенные на страницах устройства.
* Все страницы: копируются все страницы базового проекта.
* Основные данные: Сохраненные в проекте основные данные, например формы и символы.
* Сохраненные внешние документы и графические файлы: Сохраненные внешние документы и графические файлы — это данные, скопированные в проект прямо при соединении или позже с помощью команды Сохранить документы (Сохранить внешние документы). (Для этого вам нужно сначала [Настроить ленту](userinterface_h_menuebandanpassen.md) и присвоить нужную команду определенной пользователем группе команд.)
* Данные, связанные со ссылками: При создании базового проекта в проекте сохраняются все данные, связанные со ссылками. Данные, связанные со ссылками, — это данные, связанные с проектом, например, через гиперссылку, но не содержащиеся в проекте. Сюда относятся внешние документы, присоединенные документы и графические файлы. Чтобы сохранить данные в базовом проекте, они должны находиться на локальном диске или на сетевом диске, к которому у вас имеется доступ. Данные, связанные через протокол http, не сохраняются.

### Примерные шаблоны

После стандартной установки Eplan в каталогах ..\Шаблоны\EPLAN и ..\Шаблоны\<Идентификатор фирмы> находятся, например, следующие базовые проекты.

Имя файла |  Значение  
---|---  
IEC_bas001.zw9 |  Задана структура идентификаторов IEC. Содержит основные данные, например: библиотеки символов, формы, рамку.  
Num_bas001.zw9 |  Задана общая нумерация. Содержит основные данные, например: библиотеки символов, формы, рамку.  
GOST_bas001.zw9 |  Подходит для создания проектов по стандарту ГОСТ. Содержит основные данные, например: библиотеки символов, формы, рамку.  
  
### Операция для преобразования старых шаблонов

Шаблоны проектов из старых версий Eplan (версия 2.9 и более ранняя) преобразуются в базовые проекты с помощью операции XPrjConvertBaseProjectsAction. С помощью этой операции можно выполнить преобразование шаблонов проектов через вызов командной строки, а также через сценарий или Eplan API. Задавая различные параметры, можно выбрать для преобразования отдельные шаблоны проектов, каталоги или определенные типы файлов.
