## Измененные и дополненные свойства изделия

Для свойств изделия в данной версии добавлены следующие возможности:   
\- Количество свойств для номеров ERP / PDM увеличено до десяти  
\- Изменено поведение для свойств изделия с указанием местного времени  
\- Новые свойства для современных требований в области технологий и автоматизации  
\- Новое свойство изделия "Описание варианта изделия"  
\- Новое свойство изделия "Дата импорта Data Portal"  
\- Новые свойства изделия для изделий для замены

### Количество свойств для номеров ERP / PDM увеличено до десяти

Для некоторых изделий могут использоваться разные номера ERP. Поэтому теперь для каждого изделия в управлении изделиями можно сохранять до десяти номеров ERP с соответствующими описаниями. Эти номера назначаются на вкладке Свойства аналогично свойству Внешние документы в последующем диалоговом окне.

Поскольку свойство Номер ERP использовалось не только для номеров ERP, но и для ввода номеров из PDM-системы, то новые свойства были переименованы в Номера ERP / PDM.

Чтобы назначить номера, в столбце Значение нажмите на ++…++, чтобы открыть последующее диалоговое окно Свойство: Номера ERP / PDM. Там в первом столбце введите соответствующие номера, а во втором столбце – соответствующее описание.

Несмотря на то, что теперь для одного изделия можно вводить несколько номеров ERP / PDM, каждый номер ERP / PDM должен быть уникальным. Варианты изделия также должны иметь одинаковый номер ERP / PDM. Как и прежде, введенные номера ERP / PDM синхронизируются с другими вариантами изделия и проверяются Eplan при сохранении изделия или его варианта.

Если при переносе баз данных изделий или импорте данных из версии 2025 (или более ранней) в текущую версию имеются значения для номера ERP, то по соображениям совместимости эти значения всегда указываются в первых номерах.

#### Изменение контрольных прогонов

В рамках этого изменения были переименованы и скорректированы контрольные прогоны 502021 и 502036. Теперь оба контрольных прогона проверяют все номера ERP / PDM (от номера ERP / PDM 1 до номера ERP / PDM 10). Для каждого номера ERP / PDM, содержащего ошибку, выводится отдельное сообщение. Обозначения контрольных прогонов изменены следующим образом:

* P502021: "Свойство изделия 'Номер ERP / PDM <x>' неоднозначно"
* P502036: "Свойство изделия 'Номер ERP / PDM <x>' отличается в разных вариантах изделия"

[Улучшение контрольных прогонов для основных данных изделий](news_p_artikelverwaltung_artikelprueflaeufe_489829.md)

#### Совместное отображение номеров ERP / PDM

На вкладке Обзор можно с помощью свойства Номера ERP / PDM (ид. 22370) совместно отобразить все номера ERP / PDM в одной строке. У вас также есть возможность по отдельности отображать номера ERP / PDM 1-10 (и их описания) в качестве свойств, используя соответствующую конфигурацию вида.

На вкладке Свойства можно также конфигурировать отдельные свойства номеров ERP / PDM (и их описания) для вида. Здесь отдельные свойства доступны только для чтения, редактирование возможно только в диалоговом окне Свойства: Номера ERP / PDM.

### Изменено поведение для свойств изделия с указанием местного времени

Многие свойства с указанием информации о дате / времени в управлении изделиями сохраняют данные по местному времени пользователя. Это приводило к тому, что при использовании данных изделия или базы данных изделия по всему миру пользователи, находящиеся в других часовых поясах, получали неверную информацию о времени. Чтобы иметь сопоставимую информацию о времени по всему миру, поведение этих свойств было изменено. Теперь информация о времени корректируется для каждого пользователя в соответствии с его часовым поясом.

Например, если раньше у пользователя A в дате изменения было указано время "10:00:00", то у пользователя B в другом часовом поясе отображалось это же значение. Теперь у пользователя B в этом же поле отображается время "21:00:00", соответствующее часовому поясу этого пользователя.

Изменение поведения распространяется на следующие свойства:

* Дата изменения (ид. 22981)
* Последний обработчик / дата изменения (ид. 22901)
* Последний обработчик / дата изменения (список принадлежностей) (ид. 22958)
* Последний обработчик / дата изменения (размещение принадлежностей) (ид. 22973)
* Последний обработчик / дата изменения (схема сверления) (ид. 22938)
* Последний обработчик / дата изменения (схема соединений) (ид. 22944)
* Последний обработчик / дата изменения (адрес) (ид. 22937)
* Дата создания (ид. 22983)
* Автор / дата создания (ид. 22902)
* Автор / дата создания (список принадлежностей) (ид. 22936)
* Автор / дата создания (размещение принадлежностей) (ид. 22972)
* Автор / дата создания (схема сверления) (ид. 22939)
* Автор / дата создания (схема соединений)

Кроме того, теперь во время экспорта и импорта эти свойства для внешней обработки защищены от записи и доступны только для чтения. Посредством внешней обработки можно изменить только универсальное глобальное время (UTC).

### Новые свойства для современных требований в области технологий и автоматизации

Теперь в управлении изделиями доступно более 400 новых свойств, с помощью которых можно дополнить данные изделий в соответствии с текущими требованиями в области машиностроения, энергетики, автоматизации зданий и технологии производственных процессов. Здесь можно указывать дополнительные технические данные и информацию от производителя, например, конструктивный тип устройства, значения рабочего напряжения, рабочей температуры, информацию о выбросах CO₂ и т. д. Во многих случаях свойства с тем же названием также доступны в функциях как свойства ссылок изделий.

Эффект:

Расширение перечня свойств изделий делает платформу Eplan еще более привлекательной для пользователей и производителей. Благодаря новым свойствам производители могут еще точнее представлять свою продукцию, а пользователи получают выгоду от более высокого качества данных и увеличения гибкости процесса проектирования. Новые свойства охватывают многочисленные текущие требования, такие как оценки устойчивого развития, подробные эксплуатационные характеристики или особые требования в области машиностроения, энергетики, автоматизации зданий и технологии производственных процессов. Теперь производители могут передавать данные о своих изделиях клиентам Eplan в еще более полной и стандартизированной форме. Это обеспечивает четкий и последовательный обмен техническими данными и упрощает интеграцию в существующие процессы проектирования.

Теперь, благодаря расширению перечня данных изделия и данных ссылок изделия, в вашем распоряжении будет более полная и точная информация для экспорта данных изготовления и вывода маркировки. В результате вы сможете получить подробную документацию и обеспечить информационную базу для производственных и внешних систем, таких как ERP- или PDM-системы.

Ниже приведены некоторые примеры новых свойств, наглядно демонстрирующие их практические преимущества:

* Рабочее напряжение (при переменном токе 50 Гц), макс. (ид. 26087), Рабочее напряжение (при постоянном токе), макс. (ид 26091): Информация о рабочем напряжении упрощает выбор компонентов с подходящими требованиями к напряжению.
* Рабочая температура (ид. 26237), Область измерения: Температура (ид. 26121), Температура окружающей среды (во время эксплуатации), макс. (ид. 26157): Диапазон рабочих температур является важной информацией для проектирования в критических условиях, например: в холодильных камерах, или при проектировании в потенциально взрывоопасных зонах.
* Степень защиты (IP) (ид. 26553), Степень защиты (IP): На передней панели (ид. 26559): Степень защиты полезна в качестве критерия фильтра для эксплуатации в суровых условиях.
* PCF: Эквивалент CO2 (ид. 26526), PCF: Вычисление (ид. 26529): Информация о выбросах CO₂ полезна для поддержки проектов, ориентированных на устойчивое развитие и борьбе с изменением климата.
* Потребление мощности (ид. 26417), Номинальное потребление мощности (ид. 26482): Информация о потреблении мощности важна для оптимизации расчетов энергоэффективности.
* BACnet: Стандарт (ид. 26516), Описание возможностей, стандартизированное: Описание (устройство, услуга, сервис) (ид. 26425): Информация о стандартах и сертификациях облегчает соблюдение нормативных требований.
* Электрический интерфейс (ид. 26036), BACnet: Количество аппаратных интерфейсов (ид. 26214): Интерфейс данных является важной информацией для устройств с поддержкой Интернета вещей.
* Материал (ид. 22081), Материал оболочки кабеля (ид. 26640): Информация о составе материала, из которого изготовлен функциональный элемент, полезна для оценки устойчивого развития или конкретных экологических требований.

Эти свойства можно отображать, как обычно, на страницах проекта и в отчетах, а также экспортировать для экспорта данных изготовления и вывода маркировки. Кроме того, эти свойства также можно использовать для сортировки и фильтрации.

### Новое свойство изделия "Описание варианта изделия"

Теперь можно сохранять описывающий текст для вариантов изделия. Для этого на вкладке Свойства в управлении изделиями доступно новое свойство Описание варианта изделия (ид. 22887). Поскольку размер имени варианта ограничен тремя символами, можно использовать это описание, чтобы лучше различать варианты одного изделия. Это свойство также доступно для конфигурации представления в управлении изделиями (в виде дерева и списка) и в центре вставки (таблица в информационной области для устройств).

### Новое свойство изделия "Дата импорта Data Portal"

Теперь в управлении изделиями есть возможность отфильтровать только те изделия, которые были импортированы из Eplan Data Portal. Для этого на вкладке Свойства в выборе критериев фильтра доступно новое свойство изделия Дата импорта Data Portal (ид. 22391).

Для этого свойства указывается дата при импорте изделия из Eplan Data Portal. Дату импорта нельзя редактировать (например, с помощью внешней обработки), кроме того, она не учитывается при обмене данными (например, при экспорте и импорте в формате EDZ или XML). При копировании и вставке изделия значение этого свойства не переносится в новое изделие. В этом случае свойство остается пустым.

### Новые свойства изделия для изделий для замены

Чтобы упростить идентификацию деталей, снятых с производства, и улучшить понимание того, какое изделие заменило деталь, снятую с производства, теперь доступны следующие четыре новых свойства для изделий для замены:

* Изделие для замены: Оригинальное изделие (ид. 26318)
* Изделие для замены: Дата (ид. 26320)
* Изделие для замены: Номер (ид. 26321)
* Изделие для замены: Описание (ид. 26038)
