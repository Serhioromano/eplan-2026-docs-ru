# Генерировать начальные адреса карт ПЛК

Начальные адреса карт ПЛК могут генерироваться автоматически на основе введенной в них длины данных. Сгенерированные таким образом начальные адреса можно затем использовать для последующей адресации выводов устройств В/В.

Условия:

* На картах ПЛК вводится длина данных для входов и/или выходов (свойства **Устройство ПЛК: Длина данных (входы)**, **Устройство ПЛК: Длина данных (выходы)** или соответствующие свойства для подустройств ПЛК).
* В специфических для ПЛК свойствах для счетчика в формате адреса ПЛК используется значение конфигурации "Начальный адрес карты ПЛК".

1. Выделите одну или несколько карт ПЛК в одном из навигаторов или в графическом редакторе. Либо выделите одну или несколько страниц, содержащих карты ПЛК, или проект в навигаторе страниц.
2. Выберите следующие команды: Вкладка **Устройства** > группа команд **ПЛК** > **Начальные адреса**

![](images/arrow.png) Если выделены карты ПЛК, принадлежащие разным ЦПУ, отобразится диалоговое окно выбора. Выберите требуемый ЦПУ.
3. В диалоговом окне **Генерировать начальные адреса карт ПЛК** в полях **Начальное значение для входов** и **Начальное значение для выходов** введите требуемые начальные значения для первой карты ПЛК.
4. При необходимости установите флажок **Применить ко всему ЦПУ**, чтобы сгенерировать начальные адреса для всех карт ПЛК ЦПУ.
5. При необходимости установите флажок **Предварительный просмотр результата** для отображения предварительного просмотра сгенерированных начальных адресов. В диалоговом окне предварительного просмотра при необходимости можно вручную изменить сгенерированные начальные адреса.

![](images/arrow.png) Если возникают конфликты, то в диалоговом окне предварительного просмотра соответствующие строки выделяются красным цветом. Конфликты могут возникать в результате ручной обработки или обнаруживаться при сравнении с начальными адресами других карт ПЛК того же самого ЦПУ, не включенных в выделение. Вместе с тем, значения могут быть записаны обратно в проект.
6. Щелкните по кнопке ++"OK"++.

![](images/arrow.png) Начальные адреса записываются на карты ПЛК в проекте. При этом уже существующие начальные адреса будут перезаписаны.

![](images/arrow.png) Последовательность генерирования начальных адресов для карт ПЛК соответствует последовательности генерирования карт ПЛК в ориентированном на каркас виде навигатора ПЛК.
