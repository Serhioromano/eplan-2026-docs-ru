## Диалоговое окно Генерировать ревизию

Вы открыли проект. Файл > Управление ревизиями > группа команд Изменения > Отслеживание изменений > Генерировать ревизию.

В этом диалоговом окне введите имя и описание новой ревизии.

Обзор основных элементов диалогового окна:

Имя ревизии:

Здесь указывается имя ревизии. Eplan автоматически предложит имя ревизии на основании имеющихся имен и количества уже созданных ревизий.  
С помощью кнопки [...] откройте диалоговое окно [Выбрать ревизию](eplan/revisionlogmgtgui_d_revauswaehlen.md) Там вы можете выбрать уже имеющиеся имена ревизий и затем изменить их.

Комментарий:

В этом поле можно дополнительно вводить текст комментария.

Пользователь:

В этом поле автоматически вводится пользователь, который создает ревизию. Запись изменить невозможно.

Область обработки:

В этом поле отображается текущая активная область обработки. Запись изменить невозможно.

Дата:

В этом поле автоматически вводится дата генерирования ревизии. Запись изменить невозможно.

Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](eplan/userinterface_m_kontextmenu.md).
