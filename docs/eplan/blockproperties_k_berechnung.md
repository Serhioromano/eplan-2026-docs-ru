# Свойства расчета

В различных местах Eplan у вас есть возможность составить формулу расчета с использованием элементов формата и таким образом определить свойство расчета:

* Тексты-заполнители в редакторе форм и рамок
* Экспорт данных изготовления / маркировка
* Определяемые пользователем свойства блока
* Индексированные свойства блока
* Предварительное определение индексированных форматов для свойств блока на проекте
* Конфигурация определений сегментов для предварительного планирования

В редакторе форм и рамок, а также при экспорте данных изготовления или маркировок можно составлять расчетные формулы как для данных проекта, так и для данных изделий, сохраненных в проекте. Если вы создаете свойства расчета как определяемые пользователем свойства блока предлагаются только данные проекта, поскольку эти свойства сохраняются как специфические для проекта.

Данные, полученные с помощью расчетной формулы, можно отображать в проекте или выводить в отчетах. Формула расчета создается в диалоговом окне Формат: Вычисление. В зависимости от контекста там доступны разные элементы формата.

### Использование определяемых пользователем свойств блока

Свойства расчета могут быть созданы как определяемые пользователем свойства блока. Для этого в диалоговом окне Конфигурировать свойства создайте свойство с типом поля "Одноязычный текст" или "Значение с единицей измерения" и типом отображения "Свойство блока". После нажатия на расположенную рядом кнопку ++"..."++ в диалоговом окне Формат выделите элемент формата Вычисление и подвиньте его вправо. Затем в открывшемся диалоговом окне Формат: Вычисление можно составить расчетную формулу с помощью элементов формата.

Если вы составляете формулу расчета для индексированных свойств блока и вставляете туда свойство, то при выборе свойства отображаются значения, которые введены в соответствующем объекте. Это облегчает поиск нужного свойства и распознавание используемой единицы измерения. При создании определяемого пользователем свойства блока значения также отображаются в окне выборе свойства. В зависимости от контекста, значения будут взяты из объекта, который был выделен до того, как вы открыли диалоговое окно Конфигурировать свойства, или из вышестоящего объекта.

!!! example "Пример:"

    Выделите функцию в графическом редакторе. В диалоговом окне Конфигурировать свойствасоздайте определяемое пользователем свойство блока с назначением "Функция". При выборе свойства отображаются значение выделеннойфункции.Выделите функцию в графическом редакторе. В диалоговом окне Конфигурировать свойствасоздайте определяемое пользователем свойство блока с назначением "Страница". При выборе свойств отображаются значения страницы, на которой размещена функция.

### Указание единиц измерения

Единицы измерения, как правило, не учитываются в формулах расчета. Рассчитываются только числовые значения, и выводится только одно числовое значение без единицы измерения.

Eplan выполняет внутренние расчеты с использованием базовых единиц Международной системы единиц (СИ). Для свойств с типом поля "Значение с единицей измерения" (если действительная единица распознана) числовая часть перед вычислением преобразуется в единицу СИ и вычисляется с ее помощью. Если единицы измерения не распознаются, предполагается, что значение дано в единицах СИ и, следовательно, вычисляется без преобразования.
Для всех остальных свойств числовое значение используется без изменений в том виде, в котором оно было введено.

Вы можете использовать элемент формата Разделитель, чтобы указать связанную единицу измерения для вычисляемого значения. Для этого вставьте после элемента формата Вычисление элемент формата Разделитель. Если в качестве разделителя вы вводите пробел, за которым следует единица измерения, Eplan распознает это как единицу измерения.

!!! tip "Совет:"

    В диалоговом окне Формат: Вычисление в поле Выбранные элементы формата в столбце Предв. просмотр отображаются значения свойств выделенного объекта. Числовые значения, используемые для расчета, указаны в скобках после значения свойства.
