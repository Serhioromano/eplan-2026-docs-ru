## Диалоговое окно Копировать страницы

[Вызов диалогового окна:](javascript:void\(0\);)

Вы открыли навигатор страниц и открыли (как минимум) один проект. Выберите команду Копировать из / в. (Для этого вам нужно сначала [Настроить ленту](userinterface_h_menuebandanpassen.htm) и присвоить нужную команду определенной пользователем группе команд.)

В этом диалоговом окне указывается, какие страницы проекта требуется скопировать в другой или в тот же самый проект.

Обзор основных элементов диалогового окна:

Выбранный проект:

По умолчанию здесь выводится текущий проект. С помощью кнопки [...] откройте диалоговое окно Выбор проекта. В нем выводятся все открытые на данные момент проекты, кроме того, можно открыть и другие проекты. Выберите проект, в который требуется выполнить копирование. После этого он выводится в представлении в виде дерева.

Текущий проект:

В этом поле выводится имя текущего проекта, под ним в виде дерева представлены страницы этого проекта.

Фильтр:

В этом раскрывающемся списке отображаются все доступные фильтры. Выбранный фильтр активируется автоматически. Запись "- Не активировано -" отключает фильтр и приводит к тому, что данные отображаются в неотфильтрованном виде. С помощью кнопки [...] откройте диалоговое окно [Фильтр](modaldialogsdb_d_filternnach.htm). Здесь можно создать, обработать, удалить, скопировать, экспортировать, импортировать фильтр и управлять им.

Во всплывающем меню раскрывающегося списка Фильтр содержатся следующие записи:

  * Выключить: Этот пункт меню доступен, если фильтр установлен: Сбрасывает настройку фильтра до записи "- Не активировано -".
  * Активировать <Имя фильтра>: Этот пункт меню доступен, если для настройки фильтра установлено значение "- Не активировано -": Повторно активирует последний активный фильтр.



Таким образом можно быстро переключаться между неотфильтрованным и отфильтрованным в соответствии с требованиями пользователя представлениями.
