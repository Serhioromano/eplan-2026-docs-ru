# Диалоговое окно Импортировать записи данных

## Вызов диалогового окна:

Вкладка **Основные данные** > группа команд **Изделия** > **Управление**. В диалогом окне **Управление изделиями** через меню ++"Дополнительно"++ > **Настройки** была открыта база данных изделий. Кнопка ++"Дополнительно"++ > **Импортировать**.

В этом диалоговом окне определяется, какие данные требуется импортировать и как следует обрабатывать идентичные записи данных при импорте.

Обзор основных элементов диалогового окна:

### Тип файла:

Выберите требуемый тип файла из раскрывающегося списка. В зависимости от установленного здесь формата импорта кнопка ++"..."++ становится активной, и в последующем диалоговом окне можно задать настройки для импорта.

!!! note "Замечание:"

    Выберите тип файла "VDMA 66413", чтобы импортировать XML-файлы с параметрами, важными с точки зрения безопасности, которые созданы в формате обмена VDMA. (При этом сокращение "VDMA", означающее "Verband Deutscher Maschinen- und Anlagenbau", обозначает объединение по защите интересов машиностроительной отрасли и отрасли производства промышленного оборудования.) Для выполнения импорта необходимо выполнить еще одно простое присвоение. При этом нужно указать, какие идентифицирующие свойства в XML-файле соответствуют определенным свойствам изделий в вашей базе данных изделий. Присвоение выполняется в следующем диалоговом окне, в которое можно перейти из поля **Тип файла**, нажав на кнопку ++"..."++.

### Имя файла:

Введите в это поле имя файла импорта или нажмите на ![](images/all_selectfile_as.png){: .ui-icon }, чтобы выполнить интерактивный выбор. Возможен многократный выбор. При этом расширение имени файла добавляется автоматически в зависимости от выбранного в поле **Тип файла** типа файла.

С помощью пункта всплывающего меню **Вставить переменную пути** перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

### Присвоения полей:

Выберите из этого раскрывающегося списка схему, заданную для структуры и произвольных свойств, в каких полях базы даннных считываются экспортированные данные. Благодаря этому облегчается обмен данными между клиентами, которые используют различные структуры.
Нажмите ++"..."++, чтобы открыть диалоговое окно **Присвоения полей** и там создать новую, определенную пользователем, схему.

### Обработка при импорте:

С помощью опций в нижней части диалогового окна также указываются следующие настройки:

* Добавлять только новые записи данных: Существующие записи данных не изменяются, а добавляются только новые.
* Обновить только имеющиеся записи данных: игнорирует новые записи данных и обновляет только различные данные уже существующих изделий; это необходимо, например, в случае изменения цен.
* Обновить имеющиеся записи данных и добавить новые: комбинирует оба указанных выше параметра.
* Заменить имеющиеся записи данных и добавить новые: Существующие записи данных будут полностью заменены записями данных из файла импорта. Новые записи данных будут добавляться.

!!! note "Замечание:"

    Если при импорте обновляются записи данных, имеющиеся данные в большинстве настроек и шаблонов функции будут перезаписаны. Только в атрибутах, произвольных свойствах и определенных пользователем свойствах при обновлении данные не переписываются, а дополняются.
