# Восстановить проекты

Проекты можно восстанавливать из вида Backstage и из управления проектами. В виде Backstage восстановление происходит при открытии резервированного проекта.

По умолчанию все основные данные считываются в связи с проектом, после чего сравниваются с пулом основных данных. При выявлении различий следует определить используемые данные.

1. Выберите следующие команды: Файл > Открыть > группа команд Открыть > Поиск.
2. Выберите в диалоговом окне Открыть проект тот проект, который хотите восстановить. Возможен многократный выбор. При необходимости выберите в раскрывающемся списке рядом с именем файла запись "Сохраненный проект Eplan (*.zw1)", чтобы отобразить только резервированные проекты.
3. Щелкните по кнопке ++Открыть++.
4. В диалоговом окне Восстановить проект в поле Целевой каталог при помощи кнопки ![](images/all_selectdirectory_as.png) выберите тот целевой каталог, в который необходимо скопировать резервирование данных.
5. Если вы выбрали всего один проект для открытия, в поле Имя проекта можно изменить предварительно установленное имя, чтобы не перезаписывать существующий проект.
6. Подтвердите ввод.

!!! info "Для сведения:"

    Резервированный проект будет восстановлен и скопирован в указанный каталог проекта. При выборе сразу нескольких проектов для открытия они будут восстановлены по очереди.

1. Выберите следующие команды: Файл > Управление проектами > кнопка ++Организовать++ > Восстановить.
2. В диалоговом окне Восстановить проект в поле Каталог для резервирования при помощи кнопки ![](images/all_selectfile_as.png) выберите тот проект, в котором находятся резервированные проекты.

!!! info "Для сведения:"

    В списке Проекты отображаются резервированные проекты, содержащиеся в выбранном каталоге.

!!! info "Для сведения:"

    Если в каталоге содержатся разделенные файлы резервирования, отображается только файл *.000.zw1, остальные файлы резервирования, относящиеся к этому же проекту (*.001.zw1, *.002.zw1 и т. п.), не отображаются.

3. Выделите проект для восстановления. Возможен многократный выбор.
4. Выберите в поле Целевой каталог при помощи кнопки ![](images/all_selectdirectory_as.png) тот целевой каталог, в который необходимо скопировать резервирование данных.
5. Чтобы не перезаписывать уже существующий проект, измените имя, отображаемое в поле Имя проекта при выборе единичного проекта.
6. Подтвердите ввод.

!!! info "Для сведения:"

    Резервированный проект будет восстановлен и скопирован в указанный каталог проекта. При выделении сразу нескольких проектов они будут восстановлены по очереди.

При восстановлении Eplan проверяет, существует ли конкретный проект и можно ли его перезаписать.

При этом следует обратить внимание на следующие различия:

* Проект есть, но не открыт в данный момент. В данном случае при восстановлении появляется сообщение и Вы можете решить, нужно ли перезаписать проект.
* Проект есть, и его открыл сам текущий пользователь. В данном случае при восстановлении появляется сообщение и Вы можете решить, нужно ли перезаписать проект. Если Вы подтвердите восстановление, то проект, открытый в данный момент, закроется, будет перезаписан "старыми" данными и открыт снова. Обратите внимание, что при перезаписи текущие изменения могут быть утеряны.
* Проект есть, и его открыл другой пользователь. В данном случае при восстановлении появится сообщение, а процесс будет прерван.

!!! note "Замечание:"

    * Сообщения, возникающие при резервировании проекта, сохраняются как системные сообщения и доступны для просмотра через Файл > Справка > группа команд Поддержка > Поддержка и обновления > Системные сообщения.
    * При сохранении проектов производится проверка на изменения настроек проекта. При обнаружении различий на экране отображаются сравнительные сообщения, которые сохраняются в управлении сообщениями (вкладка Инструменты > группа команд Проверка > Сообщения).
