# Очистить контуры

Команда **Очистить** убирает все недопустимые элементы из контура. Сюда относятся эллипсы, кривые Безье и трехмерные элементы. Блоки разворачиваются автоматически.

Условия:

* Вы открыли проект.
* Контур, который вы хотите обработать, открыт в редакторе контура (вкладка **Основные данные** > группа команд **Контур / профиль** > раскрывающаяся кнопка **Контур (...)** > **Открыть** > кнопка ++"Открыть"++).

1. Выберите следующие команды: Вкладка **Обработать** > группа команд **Контур** > **Очистить**.
2. Подтвердите сообщение в диалоговом окне **Очистить**, щелкнув по кнопке ++"OK"++.

![](images/arrow.png) Элементы, в сообщении указанные как "недопустимые", удаляются, и блоки развертываются.
