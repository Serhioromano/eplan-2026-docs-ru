## Диалоговое окно Произвольн. свойства

Вкладка Основные данные > группа команд Изделия > Управление. В дереве или списке выделено одно изделие. Вы нажали на вкладке Определенные пользователем свойства на кнопку [Произвольн. свойства].

В этом диалоговом окне можно ввести дополнительную текстовую информацию, которая не зависит от выбранной группы продуктов (кабель, клеммы и т. д.). Эти свойства присвоены только выбранному варианту изделия.

!!! note "Замечание:"

Обзор основных элементов диалогового окна:

Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать. Или нажмите на кнопку [...], чтобы в диалоговом окне Конфигурировать произвольные свойства обработать схему или создать новую.

Схемы присвоения произвольных свойств сохраняются для каждого конкретного пользователя.

[Присвоить схему]:

Щелкните по кнопке, чтобы присвоить выбранную схему в раскрывающемся списке.

!!! note "Замечание:"

    Учтите, что перезаписываются только заполненные ячейки с данными из схемы, пустое содержимое игнорируется.

Таблица:

В ячейках "Отображаемое имя", "Значение" и "Единица измерения" введите дополнительную текстовую информацию, которую хотите использовать для отдельных изделий независимо от типа изделия.

Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).

!!! note "Замечание:"

    Любое поле любого произвольного свойства может использоваться для фильтрации с помощью фильтра.
