# Вывести страницы в PDF-файл

При экспорте в PDF независимо от выполненного выделения (отдельные страницы проекта или весь проект) всегда создается только один файл PDF.

!!! note "Замечание:"

    При экспорте больших страниц учитывайте, что экспорт в оригинальном размере может вызвать проблемы. Поэтому сначала следует разбить импортируемые блоки DXF, чтобы можно было масштабировать размер страницы. (Это делается с помощью следующих команд: вкладка **Обработать** > группа команд **Блок** > **Разбить**.)

Условие:

Вы открыли проект.

1. Выделите в навигаторе страниц те страницы проекта (или весь проект), которые требуется экспортировать.
2. Выберите следующие команды: **Файл** > **Экспортировать** > группа команд **Данные проекта** > **Данные проекта** > группа команд **Страница** > **PDF**.

!!! info "Для сведения:"

    Eplan открывает диалоговое окно **Экспорт PDF**. Выбранные объекты отобразятся в поле **Источник (страница / трехмерная модель)**.

3. Из раскрывающегося списка **Схема** выберите схему или нажмите ++"..."++, чтобы в диалоговом окне **Настройки: Экспорт PDF** создать или изменить схему.
4. Введите в поле **PDF-файл** целевой каталог и имя для генерируемого PDF-файла или выберите с помощью кнопки ![](images/all_selectfile_as.png) в интерактивном режиме. В качестве предварительных настроек здесь используется каталог документации `DOC` и имя выбранного проекта ( `...\<Проект.ebb>\DOC\<Проект>.PDF`).
5. Выберите в поле **Каталог вывода** место хранения, в который должен осуществляться вывод.
6. Укажите в групповом поле **Вывод**, как должен осуществляться вывод.
7. Установите флажок **Применить границы печати**, если установленные в настройках печати поля печати должны учитываться и при экспорте в PDF.
8. С помощью флажка **Вывести трехмерную модель / Вывести страницы с обзорами модели** также укажите, имеются ли в проекте трехмерные модели и/или страницы с обзорами модели, которые должны быть выведены.
9. Если вы хотите расширить этот выбор на весь проект, установите флажок **Применить ко всему проекту**.
10. Нажмите ++"Настройки"++ для обзора настроек языков вывода и полей для печати, если необходимо, измените их.
11. Щелкните по кнопке ++"OK"++.

!!! info "Для сведения:"

    Eplan создаст PDF-файл.

!!! note "Замечание:"

    Для возможности просмотра PDF-файла на вашем компьютере должна быть установлена программа Acrobat Reader компании Adobe (версия не ниже 10.0).
