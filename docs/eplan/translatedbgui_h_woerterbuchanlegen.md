## Создать / выбрать словарь

Вы можете создать и использовать несколько разных словарей. Выберите для своих проектов соответствующий словарь.

### Создать словарь

1. Выберите следующие команды: Вкладка Инструменты > группа команд Перевод > Словарь.
2. Щелкните в диалоговом окне Словарь на вкладке Управление на  (Создать), чтобы создать новый словарь в виде базы данных Eplan или базы данных сервера SQL.  
  
В случае выбора параметра Сервер SQL для этого открывается диалоговое окно Сгенерировать базу данных сервера SQL.
3. Подтвердите ввод.  
  
После этого вновь созданная база данных заносится в настройки в качестве словаря и автоматически выбирается.

### Выбрать словарь

Условие:

Вы создали базу данных для словаря или имеет доступ к такой базе данных.

1. Выберите следующие команды: Вкладка Инструменты > группа команд Перевод > Словарь.
2. Щелкните мышью по вкладке Управление рядом с параметром Eplan на  и выберите при помощи диалогового окна выбора файла нужный файл базы данных *.db.  
Или щелкните мышью на параметр Сервер SQL и выберите одну из 15 последних использованных баз данных SLQ из раскрывающегося списка, при этом последние использованные базы данных находятся в верхней позиции.  
  
База данных вносится в настройки в качестве словаря.

### Добавить язык словаря

1. На вкладке Управление выберите с помощью кнопки [...] словарь, в который необходимо добавить язык словаря.
2. Рядом с полем Языки словаря щелкните  (Создать).  
  
Eplan покажет все языки, которые можно добавить в словарь.
3. Последовательно выберите все языки, которые имеются в словаре.
