## Проверить основные данные изделия

В управлении изделиями у вас есть возможность напрямую проверять основные данные изделий. Для этого можно выполнить контрольные прогоны для основных данных изделия в управлении изделиями, а полученные сообщения будут отображаться не в управлении сообщениями, а непосредственно в управлении изделиями.

Условия:

* Вы открыли диалоговое окно Управление изделиями (вкладка Основные данные > группа команд Изделия > Управление).
* Через меню [Дополнительно] > Настройки была открыта база данных изделий.

1. Выберите в дереве управления изделиями те изделия, которые нужно проверить.
2. Выберите пункт всплывающего меню Выполнить контр. прогон.
3. В диалоговом окне Выполнить контр. прогон выберите схему из раскрывающего списка Настройки или нажмите на кнопку [...], чтобы в диалоговом окне Настройки: Сообщения и контр. прогоны указать настройки новой схемы контрольного прогона для основных данных изделий.  

4. Щелкните по кнопке [OK].  
  
Выделенные изделия проверяются на основании настроек, указанных в схеме. Результаты контрольного прогона записываются в базу данных изделий. При этом убираются результаты предыдущего контрольного прогона.  
  
Отображается сообщение с количеством сгенерированных сообщений тестового прогона. Затем открывается вкладка Сообщения с выданными сообщениями. С помощью пункта всплывающего меню Перейти к можно перейти от сообщения к соответствующему изделию.  
  
Изделия с неверными или неполными данными отмечаются в древовидной структуре управления изделиями красным восклицательным знаком. Для этого необходимо наличие хотя бы одного сообщения контрольного прогона, относящегося к данному изделию. При помощи свойства Имеются сообщения контрольного прогона можно создать фильтр, с помощью которого вы сможете отобразить в управлении изделиями только те изделия, которые отмечены красным восклицательным знаком.
