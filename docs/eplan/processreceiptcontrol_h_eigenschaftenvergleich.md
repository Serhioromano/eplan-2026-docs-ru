# Создать схему сравнения свойств

В схеме сравнения свойств вы определяете, какие свойства сравниваются друг с другом при сравнении проектов нормоконтроля.

Условия:

* Вы выбрали базу данных управления проектами.
* Вы сосчитали каталоги и проекты в управление проектами.

1. Выберите следующие команды: **Файл** > **Управление проектами**.
2. Выделите проект.
3. Выберите ++"Дополнительно"++ > **Проверить проект**.
4. Рядом с флажком **Сравнить свойства** щелкните по ++"..."++.
5. Щелкните рядом с полем **Схема** по кнопке ![](images/all_new_as.png) (Создать).
6. В диалоговом окне **Новая схема** в поле **Имя** введите информативное имя для новой схемы и щелкните по ++"OK"++.

![](images/arrow.png) На вкладках отображаются свойства групп данных проекта "Устройства", "Соединения", "Графика", "Страницы", "Потенциалы" и "Проект".
7. Выберите вкладку группы данных проекта.
8. Чтобы выбрать свойства для сравнения, выделите несколько свойств в поле **Не сравнивать** и щелкните по ![](images/all_arrowright_as.png) (переместить направо).
9. Щелкните по кнопкам ++"Сохранить"++ и ++"OK"++.
