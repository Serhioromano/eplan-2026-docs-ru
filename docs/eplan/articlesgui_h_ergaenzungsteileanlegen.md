# Создать дополнительные части

Дополнительные части позволяют более точно определить узлы или модули. Это может потребоваться в тех случаях, если для создания узла или модуля требуются определенные изделия, которые невозможно приобрести как отдельные изделия и которые не должны указываться в отчетах. Поэтому для изделий с этим типом записи данных невозможно отключить свойство Подавлять в спецификации.

Условия:

* Вы открыли диалоговое окно Управление изделиями (вкладка Основные данные > группа команд Изделия > Управление).
* В структуре дерева выделен уровень иерархии "Дополнительная часть" или изделие-дополнительная часть.

1. Выберите в дереве пункт всплывающего меню Создать.

!!! info "Для сведения:"

    При выделении уровня иерархии "Дополнительная часть" Eplan генерирует новую дополнительную часть с номером изделия `Создать(<порядковый_номер>)`. Это также происходит, если выделен уровень иерархии одной из главных групп продуктов, например, "Fluid-Техника" (если в структуре дерева еще не существует уровня иерархии Дополнительные части).

!!! info "Для сведения:"

    Когда выделено изделие-дополнительная часть, Eplan генерирует новую дополнительную часть с номером изделия `исходный_номер_изделия(<порядковый_номер>)`.

2. Перейдите справа в диалоговом окне на вкладку Свойства.
3. Измените автоматически назначенную запись для свойства Номер изделия на уровне иерархии Общее.
4. Измените группировку продуктов для дополнительной части, если появились уровни иерархии с обозначением "Не определено". Это происходит, например, когда выделен уровень иерархии "Дополнительная часть".
5. Для этого нажмите для свойства Группировка продуктов в столбец Значение и на кнопку ++...++. Из раскрывающегося списка группировок продуктов выберите нужную подгруппу продуктов (например, "Общие"), дважды щелкнув по ней.

!!! info "Для сведения:"

    Выбранная группировка продуктов отображается в свойстве Группировка продуктов. После применения изменений группировка продуктов также отображается для уровней иерархии в дереве.

6. Введите дополнительные данные дополнительной части на вкладке Свойства (например, производитель).
7. Нажмите на ++Применить++, чтобы сохранить введенные данные и изменения, не выходя из базы данных изделий.

!!! note "Замечание:"

    Если для главной группы продуктов (например, Fluid-Техника) в дереве отсутствует уровень иерархии "Дополнительная часть", создайте дополнительную часть с помощью пунктов всплывающего меню Создать > Дополнительная часть.
