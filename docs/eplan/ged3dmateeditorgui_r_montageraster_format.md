# Вкладка Формат (монтажная сетка)

## Вызов диалогового окна:

Вы открыли проект. Вы открыли пространство листа. Пространство листа содержит 3D-объекты. На 3D-объекте определена монтажная сетка. Вы выделили монтажную сетку и выбрали пункт всплывающего меню **Свойства**. Выберите в диалоговом окне **Свойства** ++"..."++ вкладку **Формат**.

На этой вкладке обрабатываются свойства просмотра монтажной сетки.

Обзор основных элементов диалогового окна:

### Свойство / Присвоение:

В таблице доступны уровни иерархии **Монтажная сетка**, которые открываются щелчком по знаку ![](images/all_expand_hierarchy_as.png){ .ui-icon }.

### Направление X / Направление Y:

Здесь вы указываете интервал сетки и количество линий сетки в направлениях X и Y.
