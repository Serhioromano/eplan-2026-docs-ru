## Просмотреть свойства блока

Свойства блока можно просмотреть в схеме соединений и вывести в формы. Это в равной степени относится как к определенным пользователем, так и к индексированным свойствам блока.

### Просмотр свойств блока в схеме соединений

Условия:

* Вы открыли проект.
* Вы открыли диалоговое окно свойств для функции (например, дважды щелкнув условное обозначение в графическом редакторе).

1. Выберите в диалоговом окне Свойства <...> вкладку <Категория функции>.
2. Щелкните на панели инструментов над полем Свойства по  (Создать).
3. Выберите в диалоговом окне Выбор свойств свойство блока и нажмите на кнопку [OK]. Это может быть определенное пользователем или индексированное свойство блока, для которого уже определено свойство формата. 

!!! tip "Совет:"

    Выделить несколько свойств одновременно можно, удерживая нажатой клавишу[Ctrl].

4. Перейдите ко вкладке Отображение и при необходимости измените настройки для просмотра свойства блока.
5. Щелкните по кнопке [OK].  
  
Свойство блока будет отображаться согласно настройкам на схеме соединений и содержать значения свойств, определенных в соответствующем формате или в соответствующем свойстве формата.

!!! note "Замечание:"

    Чтобы свойства блока отображались в проекте макросов на страницах проекта, необходимо установить соответствующий режим отображения в диалоговом окнеНастройки: Представление в проектах макросов.


### Вывод свойств блока в формы

Условия:

* Вы открыли проект.
* В редакторе форм открыта форма.
* Для функций, анализирующихся в форме, уже определены свойства блока (определены соответствующие свойства блока для символа или для проекта).

1. Выберите следующие команды: Вкладка Вставить > группа команд Текст > раскрывающаяся кнопка Формы > Текст-заполнитель
2. В диалоговом окне Свойства - Текст-заполнитель на вкладке Размещение щелкните по [...].
3. В диалоговом окне Тексты-заполнители – <Тип формы> выберите нужное свойство блока и щелкните по кнопке [OK]. Это может быть определенное пользователем или индексированное свойство блока, для которого уже определено свойство формата.
4. Щелкните в диалоговом окне Свойства - Текст-заполнитель по [OK].
5. Разместите свойство в форме.
6. Чтобы при необходимости разместить в форме другие заполнители, повторите приведенные выше шаги.  
  
Если форма используется для отчета, то в заполнители для свойств блока будут подставляться значения свойств, определенные в соответствующих форматах или в соответствующих свойствах формата.
