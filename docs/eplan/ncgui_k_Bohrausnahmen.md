## Исключения при сверлении: принцип

При машинном производстве от используемой машины зависит, удастся ли получить желаемый тип отверстия. Например, при помощи лазера можно получить ровные шестиугольники, а фрезой этого не добиться. Это невозможно точно определить в данных изделий, так как еще не определено, какая машина будет использоваться для производства.

Конкретные исключения при сверлении можно определить в настройках для каждой машины, а также для вывода DXF и шаблонов сверления. При этом происходит замена отверстий, которые невозможно выполнить с помощью одной машины, на другой тип, который может быть выполнен на машине.

При экспорте данных сверления ЧУ вместо оригинальных экспортируются альтернативные варианты. На настоящих машинах после исключения все равно выполняется выбор альтернативных вариантов обработки, вызванных отсутствием инструментов (отсутствующий резьбонарезной инструмент, сверление только отверстия под резьбу и т. д.).
