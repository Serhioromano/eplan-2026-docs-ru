## Диалоговое окно Add-ons

Файл > Дополнительно > группа команд Расширения > Интерфейсы > группа команд Add-ons > Управление

В этом диалоговом окне можно вручную зарегистрировать Add-ons или удалить их регистрацию. Если зарегистрированные Add-ons содержат команды для ленты, эти команды отображаются в группе команд, определенной пользователем. Пункты меню зарегистрированных Add-ons, которые были созданы для более ранних версий Eplan (2.9 или более ранняя), отображаются в ленте как команды на вкладке Расширения. Эта вкладка генерируется автоматически и не может быть отредактирована с помощью команды Настроить ленту.

Обзор основных элементов диалогового окна:

В таблице отображаются все установленные Add-ons. Имеются в виду Add-ons как предоставленные Eplan, так и созданные пользователем самостоятельно. Add-on добавляет в стандартный комплект поставки варианта продукта Eplan дополнительные функции или предоставляет дополнительные данные. Add-ons программы Eplan обычно регистрируются автоматически. Собственные Add-ons вы регистрируете вручную, если они сохранены в локальном каталоге. Для этого установите флажок Зарегистрировано после того, как с помощью кнопки  (Создать) был выбран Add-on.

!!! note "Замечание:"

    Add-ons регистрируются автоматически, если они находятся в каталоге на сервере. Для этого соответствующий файлinstall.xmlдолжен находиться в пути к каталогу, который вы задали в настройках фирмы в диалоговом окнеНастройки: Add-ons.

Панель инструментов:

Кнопка |  Значение  
---|---  
(Создать) |  Открывает диалоговое окно Выбрать Add-on, в котором можно выбрать файл install.xml соответствующего дополнительного модуля.  
(Удалить) |  Удаляет Add-on из таблицы. Удаление возможно при условии, что Add-on не зарегистрирован. Как правило, Add-ons программы Eplan удалять нельзя.
