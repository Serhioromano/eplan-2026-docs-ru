## Определить нумерацию устройств (Изменение стандарта)

Пользовательские и предварительно определенные схемы для нумерации устройств применяются из базового проекта, который был указан при создании целевого проекта.

Условия:

  * Вы открыли проект.
  * При нескольких открытых проектах: В навигаторе страниц выделен проект.
  * Вы настроили целевой проект.
  * Вы задали базовый проект и поворот / инверсию.
  * Вы заменили необходимые рамки, формы, библиотеки символов и символы.
  * Вы определили структуру проекта.


  1. Выберите следующие команды: Вкладка Инструменты > группа команд Стандарты > Заменить > вкладка Проект > кнопка [Далее] > вкладка Поворот / инверсия > кнопка [Далее] > вкладка Основные данные > кнопка [Далее] > вкладка Структура > кнопка [Далее].
  2. На вкладке Нумерация установите флажок Повторно нумеровать устройства.
  3. Выберите из раскрывающегося списка Нумерация устройствo формат нумерации.
  4. Нажмите кнопку [Завершить].  
  
Целевой проект будет отображен в навигаторе страниц.
