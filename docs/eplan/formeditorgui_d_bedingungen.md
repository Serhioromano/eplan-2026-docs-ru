# Диалоговое окно Изменение свойства

Вы открыли проект.

* Вы открыли динамическую форму (например, с помощью следующих команд: вкладка Основные данные > группа команд Рамки / формы > раскрывающаяся кнопка Форма > Открыть > [Открыть]). Вкладка Вставить > группа команд Текст > раскрывающаяся кнопка Формы > Область условий. Область условий вытянута, как прямоугольник. Дважды щелкните по прямоугольнику и выберите в диалоговом окне свойств вкладку Условия. В поле При изменении свойств щелкните ++...++.
* Вкладка Основные данные > группа команд Рамки / формы > раскрывающаяся кнопка Форма > Открыть > кнопка ++Открыть++. Вы выделили форму в навигаторе страниц и открыли с помощью пункта всплывающего меню Свойства диалоговое окно Свойства формы — <Имя формы>. Вы нажали для свойства При изменении заново генерировать заголовок в поле Значение на кнопку ++...++.

В данном диалоговом окне выберите свойства, при которых используется изменение области условий / заголовка.

Обзор основных элементов диалогового окна:

### Свойство:

Щелкните ![](images/all_new_as.png){ .ui-icon } (Создать) на панели инструментов вверху листа, чтобы открыть диалоговое окно Выбор свойств и там выбрать свойства, при которых используется изменение области / заголовка. Для списка обозначений устройств можно, например, задать, что при каждом изменении свойства ОУ (видимое) будет начерчена толстая линия для следующего ОУ или сгенерирован новый основной заголовок.

### Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).
