## Экспорт и импорт трехмерных графических данных

Eplan Pro Panel позволяет экспортировать и импортировать трехмерные графические данные в различные форматы файлов.

### Экспорт трехмерных графических данных

Экспорт трехмерных графических данных возможен в форматах файлов, перечисленных ниже. Специфические для пользователя настройки можно задать для всех видов экспорта в меню Файл > Настройки > Пользователь > Интерфейсы > Экспорт STEP / Экспорт VRML / Экспорт IFC / Экспорт JT [](gededit3dgui_d_einstellungenstepexport.md).

STEP

Экспорт STEP записывает фацетированную геометрию трехмерных тел пространства листа в файл в формате STEP (STandard for the Exchange of Product model data). Данные об аналитических плоскостях или объемах не передаются. Экспортируемые данные можно загружать во внешнюю систему CAD и там визуализировать. При импортировании обрабатываемых трехмерных тел в формате STEP модели используются как трехмерный макрос или функциональный элемент для размещения в проектах Pro Panel.

VRML

Экспорт VRML записывает геометрию трехмерных тел пространства листа в файл в формате VRML (Virtual Reality Modeling Language). Экспортированные файлы в браузерах отображаются как трехмерные модели, которые можно поворачивать во всех направлениях и масштабировать.   
При каждом экспорте VRML параллельно сгенерированному файлу VRML генерируется файл с расширением имени файла *.wri. Ко всем функциональным элементам, имеющим номер изделия или ОУ, прикрепляется номер в форме 'ID000001'. При этом число увеличивается по нарастающей от 1 до n.

IFC

Экспорт IFC записывает геометрические данные трехмерных ограждений монтажного пространства в файл стандарта открытых данных IFC (Industry Foundation Classes). IFC — это глобально используемый стандарт обмена данными в строительной отрасли для планирования с использованием цифровых 3D-моделей зданий. Этот метод цифрового планирования также известен как BIM (Building Information Modeling).

Экспортируемые данные включают в себя следующие свойства электрошкафов:

* Высота, ширина и глубина параллелепипеда, который окружает закрытый электрошкаф, включая цоколь и другие выступающие наружу элементы.
* Максимальное расширение при открытой двери электрошкафа (только на графике)
* Вес (полностью) (ид. 22233)

JT

Экспорт JT записывает геометрические данные трехмерных тел пространства листа в файл в формате JT (Jupiter Tesselation). Экспорт JT позволяет получить трехмерную модель электрошкафа для дальнейшего использования в другой CAD-программе. JT файлы могут содержать детализированные данные, информацию о продукте и производителе, а также метаданные.

!!! note "Замечание:"

    Обратите внимание, что трехмерные графические данные для экспорта JT должны содержать так называемую информацию BREP (BREP = Boundary Representation). Если эта информация отсутствует, при экспорте будет выдано соответствующее предупредительное сообщение, а функциональный элемент, для которого отсутствует информация BREP, будет исключен из экспорта. В этом случае мы рекомендуем либо обновить 3D-макросычерез Eplan Data Portal, либо сгенерировать 3D-макросы с нуля. Затем вам будет необходимо заново вставить все используемые изделия в Eplan Pro Panel.

 

### Импорт трехмерных графических данных

Для создания собственных функциональных элементов и 3D-макросов можно импортировать трехмерные графические данные из внешних CAD-систем. Графические данные должны быть в международном стандартном формате STEP или в формате JT. Для импорта данных доступны специфические для проекта [настройки](xstepgui_d_einstellungen3dimport.md) для обоих форматов.

!!! note "Замечание:"

    Обратите внимание, что при импорте трехмерных графических данных в формате JT в данные должна быть включена так называемая информация BREP (BREP = Boundary Representation), чтобы гарантировать правильное представление 3D-графики в Eplan Pro Panel. Если эта информация отсутствует, при импорте будет выдано соответствующее предупредительное сообщение и импорт будет невозможен.
