## Операция: generatemacros

  
**Параметр** |  **Описание**  
---|---  
PROJECTNAME |  Имя проекта с полным путем файла (является опцией).  
Если не задано, то выбранный проект используется, когда операция вызывается через интерфейс пользователя (например, через сценарий или ленту). При вызове из командной строки Windows следует определить PROJECTNAME или сначала следует использовать ProjectAction. В противном случае отобразится системное сообщение.  
PAGENAMEn |  Имена учитываемых страниц (является опцией). При этом n — это номер (например, /PAGENAME1:=AP+ST1/2 /PAGENAME2:=AP+ST1/4 /PAGENAME3:=AP+ST1/7 и т. д.).  
INSTALLATIONSPACENAMEn |  Имена учитываемых пространств листа (является опцией). При этом n — это номер (например, /INSTALLATIONSPACENAME1:BR1 /INSTALLATIONSPACENAME2:BR2 /INSTALLATIONSPACENAME3:BR3 и т. д.).  
STRUCTUREn |  Структурные идентификаторы учитываемых пространств листа (является опцией). При этом n — это номер (например, /INSTALLATIONSPACENAME1:BR1 /STRUCTURE1:=EB3+ET1 /INSTALLATIONSPACENAME2:BR2 /STRUCTURE2:=EB3+ET2 и т. д.).  
WINDOWMACRODIR |  Каталог для макросов окна (является опцией).  
PAGEMACRODIR |  Каталог для макросов страниц (является опцией).  
FILTERSCHEME |  Схема фильтра (необязательно).  
Значение по умолчанию: последняя использованная схема фильтра. При передаче пустой символьной строки используется последняя использованная схема.  
OVERWRITE |  Режим перезаписывания (является опцией).  

!!! note "Замечание:"

    Учитываются только тепроекты, в которых свойствоВид проектаизменено на "Проект макросов".

 

!!! example "Пример:"

    Генерировать макросы:generatemacros 
/PROJECTNAME:C:\Projects\EPLAN\EPLAN_Sample_Project.elk
