## Вкладка Экспорт (пользователь, Экспорт PDF)

* Файл > Экспортировать > группа команд Данные проекта > Данные проекта > группа команд Страница > PDF. Щелкните в поле Схема диалогового окна Экспорт PDF на ++...++. Выберите вкладку Экспорт.
* Файл > Настройки > Пользователь > Интерфейсы > Экспорт PDF. Выберите вкладку Экспорт.

На этой вкладке устанавливаются предварительные настройки для экспорта. При экспорте отдельных страниц или всего проекта в формат PDF всегда создается только один файл независимо от выполненного выделения.

Обзор основных элементов диалогового окна:

Фильтр страниц:

Из раскрывающегося списка выберите фильтр страниц, сгенерированный как схема в навигаторе страниц. Выбранный таким образом фильтр сохраняется в схеме экспорта файлов PDF. Если сохраненный фильтр больше не существует, экспорт прерывается с соответствующим сообщением.

Выбранный фильтр активируется автоматически. Пункт "-Не активировано-" отключает фильтр и приводит к тому, что данные отображаются в неотфильтрованном виде.

Каталог вывода:

Укажите здесь место хранения. В качестве целевых для экспорта данных можно указать любой дисковод и подкаталог. Нажав , откройте диалоговое окно Выбрать папку и перейдите к требуемому каталогу или создайте новый.

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

Генерировать имена файлов:

В этом раскрывающемся списке определяется стандартный порядок присвоения имен файлам экспорта PDF:

* Из имени страницы: При выборе этого параметра Eplan по умолчанию присваивает файлам PDF имена по образцу <Имя страницы>.PDF.
* Из свойств: Если выбран этот параметр, имя файла составляется из свойств страниц, пространства листа и проекта, а также свободно определяемых разделителей. Используя кнопку ++...++, откройте диалоговое окно Формат: Свойство для конфигурации имени файла.

Генерировать подкаталоги:

В этом раскрывающемся списке определяется стандартный порядок создания подкаталогов при экспорте файлов PDF:

* Нет: Если выбран данный параметр, при экспорте подкаталоги не генерируются.
* Из дерева страниц: Если выбран данный параметр, то при экспорте автоматически генерируются подкаталоги, отражающие структуру проекта. Если, например, в проекте существует функциональное назначение =A1, генерируется подкаталог =A1, в который экспортируются все соответствующие страницы.
* Из свойств: Если выбран этот параметр, имя подкаталога составляется из свойств пространства страниц, пространства листа и проекта, а также свободно определяемых разделителей. При нажатии кнопки ++...++ открывается диалоговое окно Формат: Свойство для конфигурации имени каталога. Воспользуйтесь, например, элементом формата "Разделитель каталога", чтобы создать структуру каталога с несколькими подкаталогами, расположенными друг под другом.

Вывод:

Укажите в этом групповом поле, как должен осуществляться вывод:

* В цвете: Выберите этот параметр, если вывод файла PDF должен осуществляться в цвете. Тогда все элементы выводятся в цветах, которые соответствуют цветовой схеме "Цветное на белом".
* Черно-белый режим: Выберите этот параметр, если вы хотите, чтобы все элементы на страницах проекта (за исключением графических файлов) выводились черным цветом на белом фоне. Графические файлы всегда выводятся в оригинальных цветах.
* Оттенки серого: Выберите этот параметр, если при выводе файла PDF должны использоваться оттенки серого. При этом оттенки серого рассчитываются исходя из цветов для цветовой схемы белого.

Применить границы печати:

Если данный флажок установлен, при экспорте в PDF учитываются установленные в настройках печати границы печати. Если граница печати установлена, на страницах PDF-файла создается соответствующая пустая область. Тем самым при печати страниц в Acrobat Reader образуется поле.

Если этот флажок выключен, границы печати не учитываются. Таким образом, при печати страниц, сгенерированных в Eplan, в Acrobat Reader полей не будет до самой прошивки.
