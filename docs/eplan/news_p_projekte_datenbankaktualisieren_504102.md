## Обновление баз данных проекта

В результате различных дополнений и оптимизаций базы данных проекта обновлены до версии 2026. Эти изменения привели к тому, что **новые проекты** принципиально создаются с новыми базами данных проектов.

Как это повлияет на старые проекты

Чтобы обрабатывать **старые проекты** в новой версии Eplan, а также просто просматривать их, необходимо обязательно выполнить обновление баз данных этих проектов. Обновление старых проектов осуществляется при первом открытии актуальной версии Eplan. Система спрашивает, следует ли копировать проект в текущую версию.

В случае подтверждения клавишей [Да] проект сначала обновляется, а затем открывается. При этом в каталоге проекта дополнительно создается резервная копия вашего проекта с еще не обновленными базами данных проекта. Этот файл резервирования *.zw1 можно без проблем восстановить с помощью команды Файл > Открыть.

Если старый проект не обновить, он не откроется в версии 2026.



!!! warning "Предупреждение:"

    Новые проекты, а также старые обновленные проекты большенельзяоткрывать в старой версии Eplan.


 

!!! tip "Совет:"

    В случае обновления программы вы можете обновить сразу несколько старых проектов вУправлении проектами(командный путь:Файл>Управление проектами). Для этого выберите пункт всплывающего менюАвтоматизированная обработкадля выделенных проектов. Для обновления баз данных проектов в диалоговом окнеВыполнить: автоматизированная обработкадоступна схема "Копирование проекта".
