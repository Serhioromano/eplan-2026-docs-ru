## Функции формы

Возле текста имеется два типа графики в списках отчетов:

* сгенерированная графика
* графика символов.

### Сгенерированная графика

Сгенерированная графика встречается лишь в последующей обработке в форме графики перемычек:

* Спецификация клеммника
* Схема клеммника
* Схема подключения клемм.

Графика на схеме подключений генерируется следующим образом: в форме в тех местах, где должно располагаться основание "ножек перемычки", размещаются определенные тексты-заполнители. В этих текстах-заполнителях для элемента-заполнителя "Клемма" выбраны свойства Графика для мостовых перемычек, Графика для внешних мостовых перемычек и т. д. В ходе оценки в этих местах ставятся специальные свойства клемм, помимо прочего содержащие информацию о перемычке. При последующей обработке эти тексты удаляются, заменяясь соответствующей графикой перемычек. Точный вид графики определяется при этом на основании свойств в текстах-заполнителях, а также некоторых свойств формы.

Для вывода пазов мостовых перемычек в соответствующих формах вам доступны свойства с Графика паза мостовых перемычек 3 по Графика паза мостовых перемычек 5 для элемента-заполнителя "Клемма". Для паза мостовых перемычек 1 используется свойство Графика для внутр. мостовых перемычек, а для паза мостовых перемычек 2 — свойство Графика для внешних мостовых перемычек.

### Графика символов

Символьная графика может использоваться на любой схеме, при этом определенные заполнители в процессе обработки заменяются не текстом, а символьной графикой в форме графических символов или ссылок на функциональные элементы (свойство Графика символа (ид. 13049)). При этом символьная графика всегда берется у косвенно затронутого объекта, то есть используется точно такая же графика, что и для функционального элемента.
