## Диалоговое окно Настройки: Присвоение символов (Изменение стандарта)

Вы открыли проект. При нескольких открытых проектах: В навигаторе страниц выделен проект. Вкладка Инструменты > группа команд Стандарты > Заменить. Вы задали на вкладке Проект все настройки. [Далее]. Вы определили на вкладке Поворот / инверсия все настройки. [Далее]. Вы отметили опцию на вкладке Основные данные в строке библиотеки символов в столбце Присвоить отдельно. [Далее]. Щелкните на вкладке Символы по [Схема].

Это диалоговое окно предназначено для создания схем присвоения символов исходной библиотеки символов символам целевой библиотеки символов и управления ними. В схеме присвоения с помощью варианта задается поворот или инверсия символа. Предварительно подготовленные схемы присвоения доступны в стандартном каталоге схем и могут быть импортированы оттуда.

Обзор основных элементов диалогового окна:

Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать или обработать. Для этого также воспользуйтесь соседней [панелью инструментов](eplan/schemeconfig_m_schemaschaltflaechen.md).

Присвоить символы:

Кнопка |  Значение  
---|---  
(Создать) |  Создает новую строку присвоения. Позволяет индивидуально выбирать и присваивать символы исходной и целевой библиотек символов, заданные через [Дополнительно] > Выбрать исходную и целевую библиотеку символов.  
(Удалить) |  Удаляет выделенную строку присвоения. Строка должна быть выделена в столбце Строка.  
  
Источник:

Отображает символы исходной библиотеки символов.

* Имя символа: отображает имя исходного символа. [...] открывает заданную исходную библиотеку символов в диалоговом окне Выбор символа. Позволяет отобразить свойства выбранного символа или выбрать другой символ.
* Номер символа: отображает номер исходного символа.
* Вариант: отображает используемые варианты исходного символа в исходном проекте.
* Описание: отображает описание исходного символа.

Цель:

Отображает символы целевой библиотеки символов.

* Имя символа: отображает имя целевого символа. [...] открывает заданную целевую библиотеку символов в диалоговом окне Выбор символа. Позволяет отобразить свойства выбранного символа или выбрать другой символ.
* Номер символа: отображает номер целевого символа.
* Вариант: отображает вариант целевого символа. Вариант задает поворот и инверсию целевого символа.
* Описание: отображает описание целевого символа.

Статус:

Проверяется присвоение символов. В данном столбце отображается статус проверки. Статус "OK", когда определения функций символов соответствуют друг другу, а число выводов устройств исходных символов меньше или равно числу выводов устройства целевых символов.

[Дополнительно]:

Пункт меню |  Значение  
---|---  
Выбрать исходную и целевую библиотеку символов |  Сначала открывает диалоговое окно Выбрать исходную библиотеку символов. Позволяет задать исходную библиотеку символов для схемы присвоения символов. Затем открывает диалоговое окно Выбрать целевую библиотеку символов. Позволяет задать целевую библиотеку символов для схемы присвоения символов.  
Автоматически добавить исходные символы |  Записывает в строки все символы исходной библиотеки символов, заданные через [Дополнительно] > Выбрать исходную и целевую библиотеку символов.  
Предложить подходящие целевые символы |  Автоматически присваивает символы целевой библиотеки символов, заданные через [Дополнительно] > Выбрать исходную и целевую библиотеку символов, символам исходной библиотеки символов.
