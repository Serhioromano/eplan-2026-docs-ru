# Шаблоны отчета

Шаблоны отчетов позволяют сохранять и повторно использовать настройки отчетов. Вы можете генерировать отчеты на основе шаблонов отчетов. Все настройки, которые уже были установлены в шаблонах отчетов, применяются для отчетов. Шаблоны отчетов можно импортировать и экспортировать в виде файлов *.xml.

Если вы заново создаете существующий отчет на основе шаблона отчета, существующий отчет удаляется и создается новый.

!!! tip "Совет:"

    Можно создать несколько шаблонов для одного и того же типа отчета. Если существующий шаблон отчета (с именем 0001) уже существует, то при создании другого шаблона этого типа отображается запрос, спрашивающий, следует ли перезаписать старый шаблон. Если выбрать [Нет], будут созданы два шаблона с одинаковыми именами, названия которых необходимо изменить.

### Условные отчеты

С помощью шаблонов отчета можно генерировать отчеты в зависимости от свойств проекта. Для этого определите фильтр проекта и назначьте его для шаблона отчета. При составлении отчета, отчет генерируется из шаблона отчета только в том случае, если текущий проект удовлетворяет условиям фильтра проекта.

!!! example "Пример:"

    Эта функция полезна, например, если вы создаете два проекта для разных задач планирования проекта из базового проекта (в качестве общего стандарта):Настроить базовый проект Для первого проектаEPLAN_Demoсоздайте шаблон отчета для титульного листа с формой A в базовом проекте. Этому шаблону отчета присваивается имяTitle_EPLAN_Demo.Для второго проектаEPLAN_Testсоздайте шаблон отчета для титульного листа с формой B в базовом проекте. Этому шаблону отчета присваивается имяTitle_EPLAN_Test.Вы определяете свойство проекта как условие фильтрации в фильтре проекта и назначаете его шаблону отчетаTitle_EPLAN_Demo.Создать проекты Вы создаете проектEPLAN_Demoи проектEPLAN_Testиз базового проекта.Чтобы иметь возможность различать два проекта во время генерации отчета, назначьте свойство проекта, которое вы определили как условие фильтрации в фильтре проектов, первому проектуEPLAN_Demo.Генерация отчета по проектам Если вы генерируете отчет проектаEPLAN_Demoна основе шаблонов отчета, Eplan использует шаблон отчетаTitle_EPLAN_Demoи генерирует титульный лист изформыA.Если вы генерируете отчет проектаEPLAN_Test, Eplan использует шаблон отчетаTitle_EPLAN_Testи генерирует титульный лист из формы B.
