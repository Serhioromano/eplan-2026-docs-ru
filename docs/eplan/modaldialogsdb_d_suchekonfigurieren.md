## Диалоговое окно "Конфигурировать поиск"

Вы находитесь в управлении изделиями, в выборе изделия, в навигаторе основных данных изделий или в центре вставки. Щелкните кнопку […] рядом с полем Поиск.

В этом диалоговом окне можно указать свойства, среди которых следует осуществлять поиск по поисковому запросу.

При этом свойства сохраняются в виде схем, поэтому их можно повторно использовать в любое время. Для поиска в управлении изделиями и для поиска в центре вставки применяются разные схемы.

Обзор основных элементов диалогового окна:

Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать или обработать. Для этого также воспользуйтесь соседней [панелью инструментов](schemeconfig_m_schemaschaltflaechen.md).

Конфигурация:

В этом поле укажите, по каким свойствам будет осуществляться поиск. С помощью кнопки  (Создать) можно выбирать другие свойства и вставить их в список. С помощью кнопок со стрелками можно изменять последовательность свойств.

Всплывающее меню:

Пункт меню |  Значение  
---|---  
Выделить все |  Выделяет все записи в списке.  

!!! note "Замечание:"

    Если вы хотите выполнить поиск по всем свойствам, необходимо использовать "пустую" схему, т. е. схему без выбранных свойств. В качестве альтернативы можно создать схему со всеми свойствами.
