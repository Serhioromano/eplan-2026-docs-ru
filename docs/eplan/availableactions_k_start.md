## Операции Eplan

В Eplan функциональности программы, вызывающие видимые результаты для пользователя, осуществляются посредством так называемых "Операций" (actions). Так, например, все команды ленты связаны с той или иной операцией.

Некоторую часть этих операций можно четко распознать и таким образом, к примеру, задать автоматическое осуществление функциональностей программы. В этой справке мы привели перечень всех доступных вам операций, а также их возможных параметров.

Операции Eplan предлагают вам следующие возможности:

* Вы можете вставить некоторые операции в виде команд при настройке ленты.
* Некоторые из этих операций можно использовать для запуска Eplan посредством вызова командной строки.
* Кроме того, операции можно использовать при создании и выполнении сценариев.
* В автоматически генерируемых сценариях функции Автоматизированная обработка также используются операции Eplan.

!!! note "Замечание:"

    При использовании Операций Eplan всценарииили вызове командной строки следует учитывать регистр. Написание имени операции и параметров должно соответствовать приведенному здесь написанию.
