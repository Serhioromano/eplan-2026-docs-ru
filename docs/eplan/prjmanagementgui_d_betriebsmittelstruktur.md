## Диалоговое окно Структура устройства

* Вы открыли проект. Вкладка Главная > группа команд Страница > Навигатор. Выделите проект. Выберите команды Файл > Сведения > группа команд Свойства проекта > Структура. Щелкните по [...] рядом с полем для устройств.
* Вы открыли проект. Вкладка Главная > группа команд Страница > Навигатор. Выделите проект. Выберите пункт всплывающего меню Свойства. Выберите вкладку Структура. Щелкните по [...] рядом с полем для устройств.
* Вы выбрали базу данных управления проектами. Вы считали каталоги и проекты. Файл > Управление проектами. Выделите проект. Выберите вкладку Структура. Щелкните по [...] рядом с полем для устройств.

В этом диалоговом окне вы можете создавать, обрабатывать схемы для маркировки и нумерации устройств и управлять схемами.

Обзор основных элементов диалогового окна:

Схема:

В этом поле находится имя текущей схемы идентификаторов. При помощи расположенной рядом [панели инструментов](eplan/schemeconfig_m_schemaschaltflaechen.md) можно создавать схемы, сохранять изменения в схеме, копировать или удалить схему. Кроме того, схемы можно импортировать и экспортировать.

Описание:

В этом поле находится описание схемы идентификаторов. Описание введите в диалоговом окне Новая схема в поле Описание.

Таблица:

В таблице укажите, какие блоки идентификаторов являются идентифицирующими, описывающими или недоступными для структуры устройства.

* Структура: Здесь перечислены блоки идентификаторов, соответствующие структуре устройства. В соседнем столбце отображаются соответствующие предшествующие знаки.
* Значение: В этом столбце определите в раскрывающемся списке, является ли блок идентификаторов идентифицирующим, описывающим или он не должен быть доступен.
