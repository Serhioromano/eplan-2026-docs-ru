## Диалоговое окно Выбор изделия: Выбрать источник данных

Вы открыли проект. Вкладка Основные данные > группа команд Изделия > раскрывающаяся кнопка Управление > Настройки. Установите флажок Выбор изделия с выбором схемы и нажмите кнопку [ОК].

* Вы выделили главную функцию в графическом редакторе или навигаторе. Пункт всплывающего меню Свойства. Выберите вкладку Изделие и щелкните в поле Номер изделия по кнопке [...].
* Вкладка Устройства > группа команд Устройства > Навигатор. Выделите одну запись. Всплывающее меню Новое устройство.
* Вкладка Устройства > группа команд Устройства > Спецификация. Выделите одну запись. Пункт всплывающего меню Добавить изделие или Заменить изделие.
* Вкладка Устройства > группа команд Устройства > раскрывающаяся кнопка Навигатор > Список устройств. Выделите одну запись. Пункт всплывающего меню Добавить изделие.

В этом диалоговом окне выберите схему выбора изделия из источника данных. С ее помощью вы определите, какие источники данных должны использоваться при выборе изделия.

Обзор основных элементов диалогового окна:

Источник данных:

Выберите из раскрывающегося списка схему, которая определяет пользовательские предварительные настройки для выбора изделия. С помощью кнопки [...] откройте диалоговое окно [Настройки: Изделие (пользователь)](partselectiongui_d_datenauswahlbenutzer.md), в котором можно изменить эти предварительные настройки.

Всегда использовать этот источник данных:

Если этот флажок установлен, то выбранный источник данных будет использоваться для всех дальнейших операций, при которых открыт выбор изделия. При этом диалоговое окно Выбор изделия: Выбрать источник данных больше не выводится. Вы можете снова активировать диалоговое окно Выбор изделия: Выбрать источник данных, заново включив настройку Выбор изделия с выбором схемы (командный путь: вкладка Основные данные > группа команд Изделия > раскрывающаяся кнопка Управление > Настройки).
