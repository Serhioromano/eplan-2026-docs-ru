# Поиск объектов в центре вставки

Чтобы найти один или несколько конкретных объектов в центре вставки, можно воспользоваться полнотекстовым поиском в поле **Поиск**. Информацию о различных параметрах поиска можно найти в разделе ["Поиск в центре вставки и управлении изделиями"](insertergui_k_suchen.md).

Условия:

* Вы открыли проект.
* В Графическом редакторе открыта страница проекта. Или в графическом редакторе открыто пространство листа.
* Вы открыли центр вставки.

### Поиск во всех типах объекта

Для поиска в поле **Поиск** по умолчанию активирована кнопка ![](images/insertergui_search_in_all_as.png) (Поиск во всех разделах). В этом случае поиск выполняется во всех типах объекта. При этом поиск — если это возможно — также выполняется в Eplan Data Portal. Если поиск должен выполняться без учета Eplan Data Portal, необходимо использовать кнопку ![](images/insertergui_search_in_all_except_DP_as.png) (Поиск во всех разделах (кроме Data Portal)).

1. Введите в поле **Поиск** (![](images/insertergui_start_searching_as.png)) нужное искомое слово.
2. Нажмите кнопку ++"Enter"++.

!!! info "Для сведения:"

    В строке навигации отобразится запись **Главная** > **Результаты поиска**.

!!! info "Для сведения:"

    Результат поиска (разделенный по типам объектов) появится под строкой навигации в форме раскрывающихся папок, в которых указано количество найденных совпадений. Для Eplan Data Portal также отображается количество найденных совпадений.

!!! info "Для сведения:"

    Если при поиске изделие не найдено в центре вставки, но найдено в Eplan Data Portal, то оно также будет отображаться там. Для этого, при необходимости, открывается Eplan Data Portal.

3. Чтобы отобразить конкретный результат поиска, нажмите на кнопку с направленной вниз стрелкой рядом с папкой нужного типа объекта. Чтобы отобразить результаты поиска в Eplan Data Portal, нажмите на пиктограмму ![](images/userinterface_edpIcon_as.png) "Data Portal".

!!! info "Для сведения:"

    Под типом объекта отобразятся плитки предварительного просмотра найденных объектов. Объекты можно разместить напрямую.

!!! info "Для сведения:"

    Если к этому моменту Eplan Data Portal еще не отображается, то он откроется. Текст поиска, введенный в поле **Поиск**, также используется для поиска в Eplan Data Portal. В Eplan Data Portal можно выбирать и скачать изделия.

4. При необходимости перейдите к результату поиска другого типа объекта, открыв соответствующую папку.
5. Чтобы вернуться к стандартному виду, нажмите в строке навигации на **Главная**.

!!! info "Для сведения:"

    Термин, введенный в поле **Поиск**, и папка **Результаты поиска** сохраняются.

### Поиск в определенном типе объекта

1. Щелкните по кнопке ![](images/insertergui_search_in_all_as_21x20.png) (Поиск во всех разделах).
2. В открывшемся меню выберите нужную опцию (например, ![](images/insertergui_search_only_device_as.png) **Поиск в устройствах**).
3. Введите в поле **Поиск** (![](images/insertergui_start_searching_as.png)) нужное искомое слово.
4. Нажмите кнопку ++"Enter"++.

!!! info "Для сведения:"

    В строке навигации отобразится запись **Главная** > **Результаты поиска**.

!!! info "Для сведения:"

    Папка данного типа объекта в результатах поиска раскрывается напрямую, и отображаются плитки предварительного просмотра найденных объектов. Объекты можно разместить напрямую.

5. Чтобы вернуться к стандартному виду, нажмите в строке навигации на **Главная**.

!!! info "Для сведения:"

    Термин, введенный в поле **Поиск**, и папка **Результаты поиска** сохраняются.

!!! note "Замечание:"

    В результате поиска в плитке предварительного просмотра всегда отображается только стандартный вариант объекта.

!!! tip "Совет:"

    По умолчанию поиск осуществляется по определенным свойствам типа объекта. С помощью кнопки ++"…"++ можно перейти в последующее диалоговое окно **Конфигурировать поиск**. Здесь с помощью схемы вы можете указать, по каким свойствам типа объекта должен осуществляться поиск и в какой последовательности.

### Удаление результата поиска

Условия:

Вы ввели искомое понятие в поле **Поиск**, запустили поиск и получили результат поиска.

1. Нажмите на пиктограмму ![](images/all_delete_input_as.png) рядом с введенным искомым понятием.

!!! info "Для сведения:"

    Поле **Поиск** очистится, а результат поиска удалится.

!!! info "Для сведения:"

    Вы вернетесь к стандартному виду центра вставки.
