# Переместить тексты свойств

C помощью команды **Переместить** на вкладке **Главная** активируются точки вставки текстов свойств условных обозначений, которые могут сделаны видимыми, нажав на отдельное условное обозначение. Их можно переместить с помощью перетаскивания мышью.

Кроме того, таким же образом можно вручную переместить Образ контакта.

Условия:

* Вы открыли проект. Вы открыли редактор, например графический редактор, редактор рамок и т. д.
* Не разрешается присоединять тексты свойств. При необходимости отсоедините тексты (с помощью настройки ![](images/all_undock_as.png) (Отсоединить) на вкладке **Отображение** диалогового окна 'Свойства').

1. Выберите следующие команды: Вкладка **Главная** > группа команд **Текст** > **Переместить**.
2. Выделите условные обозначения, тексты свойств которых Вы хотели бы переместить.

![](images/arrow.png) Точки элементов текстов свойств отображаются как небольшие незаполненные квадраты.
3. Выделите текст свойства и переместите его. Обратите внимание на то, что при этом перемещается случайно установленная указательная линия. (Указательные линии задаются на вкладке **Отображение** в меню **Рамки**.)

![](images/arrow.png) Выделение остается активным до тех пор, пока не будет выделен другой текст свойства или прервана операция.

!!! note "Замечание:"

    Если удерживать нажатой клавишу ++"Shift"++ при перемещении, текущая сетка будет разделена на "четверти". При этом точку вставки можно перемещать в шагах, которые имеют значение четверти шага сетки.

### Сбросить перемещенные тексты свойств

С помощью команды **Сбросить** удаляются все перемещенные тексты свойств выделенных символов. и снова выводятся тексты свойств, сохраненные для символа. (Каждый символ содержит информацию о том, какие тексты свойств по умолчанию отображаются при вставке этого символа.)

1. Выделите нужные условные обозначения.
2. Выберите следующие команды: Вкладка **Главная** > группа команд **Текст** > раскрывающаяся кнопка **Переместить** > **Сбросить**.

![](images/arrow.png) У всех выделенных условных обозначений будут удалены скопированные тексты свойств и выведены тексты свойств символа, которые отображаются по умолчанию.
