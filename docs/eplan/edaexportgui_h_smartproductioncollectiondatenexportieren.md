# Экспорт данных изготовления для Eplan Smart Production

Данные изготовления для Eplan Smart Production экспортируются в файл EPDZ через отдельный интерфейс.

Условия:

* Вы открыли проект.
* Открыты навигатор пространства листа и пространство листа.
* Размещены несущие шины, кабельные каналы и функциональные элементы.
* Сгенерированы маршрутизируемые соединения.

1. Выберите следующие команды: **Файл** > **Экспортировать** > группа команд **Данные изготовления** > **Данные изготовления** > **Smart Production**.
2. В диалоговом окне **Экспорт Eplan Smart Production** выберите имя файла и каталог для вывода файла EPDZ.
3. Щелкните по кнопке ++"OK"++.

!!! info "Для сведения:"

    В настроенном каталоге вывода файл EPDZ сгенерируется с заранее выбранным именем. Затем вы можете считать этот файл в Eplan Smart Production.
