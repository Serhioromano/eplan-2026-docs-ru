## Создать схему контрольных прогонов для проверки проекта

В схеме контрольных прогонов для нормоконтроля вы определяете, какие контрольные прогоны выполняет Eplan.

Условия:

* Вы выбрали базу данных управления проектами.
* Вы сосчитали каталоги и проекты в управление проектами.

1. Выберите следующие команды: Файл > Управление проектами.
2. Выделите проект.
3. Выберите [Дополнительно] > Проверить проект.
4. Рядом с флажком Выполнить контрольные прогоны щелкните по [...].
5. Щелкните рядом с полем Схема по кнопке  (Создать).
6. В диалоговом окне Новая схема в поле Имя введите информативное имя для новой схемы и щелкните по [OK].
7. В столбце Класс выделите класс сообщения.  
  
В таблице справа от диалогового окна отображаются доступные сообщения выделенного класса.
8. Для каждого сообщения в столбце Категория используйте раскрывающийся список, чтобы определить, выводится ли сообщение как ошибка, предупреждение или замечание.
9. В столбце Вид проверки используйте раскрывающийся список, чтобы определить, будет ли проверка выполняться как в режиме онлайн, так и в автономном режиме (настройка "Online / Offline"), либо только в автономном режиме (настройка "Offline"), или же соответствующая проверка не будет выполняться (настройка "Нет").
10. Щелкните по кнопкам [Сохранить] и [OK].
