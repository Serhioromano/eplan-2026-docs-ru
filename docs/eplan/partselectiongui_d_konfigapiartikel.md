## Диалоговое окно Настройки: Выбор изделия API

Вы открыли проект.

* Файл > Настройки > Пользователь > Управление > Изделия. В диалоговом окне Настройки: Изделие выберите определенную пользователем Схему из раскрывающегося списка. Выберите опцию API и нажмите на кнопку ++...++.
* Вы выделили главную функцию в графическом редакторе или навигаторе. Пункт всплывающего меню Свойства. Вы щелкнули на вкладке Изделие рядом с полем Источн. данных по кнопке ++...++. В диалоговом окне Настройки: Изделие (пользователь) выберите определенную пользователем Схему из раскрывающегося списка. Выберите опцию API и нажмите на кнопку ++...++.

В этом диалоговом окне укажите, какие свойства изделия будут загружаться через интерфейс API.

Выбор изделия через API — это чисто функциональный интерфейс. Как спроектирована возможность выбора и как выглядит диалоговое окно выбора зависит от реализации соответствующей программы API.

Обзор основных элементов диалогового окна:

Имя операции:

В данном поле указывается операция, которая будет запускаться при выборе изделия через интерфейс API. Эта операция осуществляется через программу API.
