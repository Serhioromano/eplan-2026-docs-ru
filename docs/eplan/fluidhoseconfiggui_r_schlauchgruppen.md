## Вкладка "Группы шлангов"

* Файл > Настройки > Пользователь > Add-ons > Конфигуратор шлангопроводов. Нажмите на вкладку Группы шлангов.
* Вы открыли проект. Вы открыли диалоговое окно [Конфигурировать шлангопроводы](eplan/fluidhoseconfiggui_d_schlauchleitungen.md). Выберите пункты меню Дополнительно > Настройки. В последующем диалоговом окне нажмите на вкладку Группы шлангов.

На этой вкладке определяются данные по умолчанию для групп шлангов. При этом вы объединяете разные типы шлангов в группы и сохраняете для выбранных типов шлангов соответствующую информацию по стандартам для шлангов и изделиям. Сохраненные в таблице указания на стандарты для типов шлангов предлагаются на выбор во время конфигурации шлангопроводов в диалоговом окне Обработать <...>.

Обзор основных элементов диалогового окна:

Номер группы (список):

Задайте группы шлангов, присваивая номер каждой группе шлангов.

Используйте кнопки панели инструментов над списком, чтобы создавать новые записи, обрабатывать имеющиеся и/или удалять более ненужные записи.

!!! note "Замечание:"

    

 

Таблица:

В этой таблице соответствующей группе шлангов присваиваются требуемые типы шланга, стандарты и номера изделий.

С помощью кнопки [...] в ячейках таблицы столбца Изделия можно получить доступ к базе данных изделий и выбрать в ней нужное изделие.

Используйте кнопки панели инструментов над таблицей для создания новых записей и/или удаления ненужных записей.

Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](eplan/userinterface_m_kontextmenu.md).
