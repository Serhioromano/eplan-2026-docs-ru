# Создать модули

Модули на платформе Eplan предоставляют одну из опций, которая позволяет отображать сложные устройства. Модули обладают теми же свойствами, что и изделия, однако дополнительно содержат списки подизделий (т. н. позиций модулей). Эти подизделия идентифицируются с помощью нижестоящего ОУ или "идентификатора ОУ".

Условия:

* Вы открыли диалоговое окно **Управление изделиями** (вкладка **Основные данные** > группа команд **Изделия** > **Управление**).
* В структуре дерева выделен уровень иерархии "Модуль" или изделие модуля.
* Создан подходящий макрос для модуля.

1. Выберите в дереве пункт всплывающего меню **Создать**.

![](images/arrow.png) При выделении уровня иерархии "Модуль" Eplan генерирует новый модуль с номером изделия `Создать(<порядковый_номер>)`. Это также происходит, если выделен уровень иерархии одной из главных групп продуктов, например, "Fluid" (если в структуре дерева еще не существует уровня иерархии Модули).

![](images/arrow.png) Когда выделено изделие модуля, Eplan генерирует новый модуль с номером изделия `исходный_номер_изделия(<порядковый_номер>)`.
2. Перейдите справа в диалоговом окне на вкладку **Свойства**.
3. Измените автоматически назначенную запись для свойства **Номер изделия** на уровне иерархии **Общее**.
4. Измените группировку продуктов для модуля, если появились уровни иерархии с обозначением "Не определено". Это происходит, например, когда выделен уровень иерархии "Модуль".
5. Для этого нажмите для свойства **Группировка продуктов** в столбец **Значение** и на кнопку ++"..."++. Из раскрывающегося списка группировок продуктов выберите нужную подгруппу продуктов (например, "Общие"), дважды щелкнув по ней.

![](images/arrow.png) Выбранная группировка продуктов отображается в свойстве **Группировка продуктов**. После применения изменений группировка продуктов также отображается для уровней иерархии в дереве.
6. Введите дополнительные данные модуля на вкладке **Свойства** (например, производитель).
7. Выберите в той же вкладке уровень иерархии **Данные**. Для модулей из главной группы продуктов "Механика" выберите уровень иерархии **Монтажные данные**.
8. Для свойства **Макрос схемы соединений** / **Графический макрос** нажмите на столбец **Значение** и выберите с помощью ![](images/all_selectfile_as.png) ранее созданный макрос для модуля.

![](images/arrow.png) Если окно **Предв. просмотр графики** активировано, здесь при выборе отображается его предварительный просмотр макроса.
9. Нажмите на ++"Применить"++, чтобы сохранить введенные данные и изменения, не выходя из базы данных изделий.

!!! note "Замечание:"

    Если для главной группы продуктов (например, Fluid) в дереве отсутствует уровень иерархии "Модуль", создайте модуль с помощью пунктов всплывающего меню **Создать** > **Модуль**.

## Присвоение позиций модуля

Условия:

* Вы открыли диалоговое окно **Управление изделиями** (вкладка **Основные данные** > группа команд **Изделия** > **Управление**).
* Вы создали модуль.

1. Выделите в дереве или списке нужный модуль.
2. Перейдите справа в диалоговом окне на вкладку **Модуль**.
3. Щелкните по ![](images/all_new_as.png) (Создать), чтобы создать строку в списке позиций модуля.

!!! note "Замечание:"

    Предварительной настройкой для новой строки является текущая выбранная настройка, т. е. ее данные по числу и номеру изделия будут скопированы. Если ни одна запись не выделена, будет сгенерирована пустая строка (с предварительной настройкой **Количество** = "1").

4. Нажмите в столбце **Номер изделия** на кнопку ++"..."++.
5. Выберите в диалоговом окне **Выбор изделия** в представлении в виде дерева или списка нужное изделие. Многократный выбор невозможен.
6. Щелкните по кнопке ++"OK"++.
7. Введите в столбце **ОУ** нижестоящее обозначение устройства, которое относится к этому модулю.

!!! note "Замечание:"

* Устройство должно быть частью макроса, присвоенного модулю. Указанное в строке изделие присваивается этому устройству при вставке модуля.
* Для идентификации устройства, находящегося в присвоенном макросе, используется либо нижестоящее ОУ устройства, либо указанный на устройстве идентификатор ОУ. Соответственно, на строку (т. е. для каждой позиции модуля) возможен ввод либо в столбец **ОУ**, либо в столбец **Идентификатор ОУ**.

8. Повторите эти шаги для всех других присвоений.
9. Нажмите на ++"Применить"++, чтобы сохранить введенные данные и изменения, не выходя из базы данных изделий.

![](images/arrow.png) Если активирована настройка пользователя **Автоматически объединить шаблоны функций**, то шаблоны функций, находящиеся в подизделиях модулей, автоматически объединяются и вводятся для всех модулей на вкладке **Шаблоны функций**. При этом модули на самой верхней позиции дополняются шаблоном функции для черного ящика. Для модулей из подгруппы продуктов "Предварительно собранный" вместо этого добавляется шаблон функции для определения кабеля (если еще отсутствует).
10. Если настройка пользователя **Автоматически объединить шаблоны функций** отключена, то нужно объединять шаблоны функций вручную. Для этого выберите под кнопкой ++"Дополнительно"++ пункт меню **Объединить шаблоны функций**.
11. Закройте базу данных изделий и сохраните измененные данные.
12. Нажмите ++"Да"++ в следующем диалоговом окне, чтобы выполнить синхронизацию данных изделий.

## Вставка модулей в графике

Условие:

В Графическом редакторе открыта страница проекта.

1. Выберите следующие команды: **Центр вставки** > строка навигации **Главная** > **Устройства**.
2. Перейдите в центре вставки к ранее созданному модулю через структуру папок или строку навигации и выберите его в качестве устройства, нажав на плитку предварительного просмотра.
3. Разместите модуль на странице схемы соединений с помощью перетаскивания.

![](images/arrow.png) Изделие модуля заносится в черный ящик, и устройства модуля содержат перечисленные в модуле подизделия.

Модули из главной группы продуктов "Механика" также вставляются через центр вставки в открытом пространстве листа. При размещении на трехмерном чертеже монтажных поверхностей отображаются точки захвата, чтобы модуль можно было присоединить многократно.
