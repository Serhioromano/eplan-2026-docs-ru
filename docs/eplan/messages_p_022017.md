## P022017: В проекте имеются превышения длины поля в базе данных: <x>

### Причина

Управление многочисленными идентификаторами, номерами и обозначениями в проектах Eplan, например обозначениями устройств, осуществляется в различных базах данных. В отдельных случаях ввод очень длинных последовательностей букв и / или цифр в одной из баз данных может привести к усечению информации и, как следствие, к неверным результатам.

### Решение

Реорганизуйте проект.

1. Выберите следующие команды: Файл > Дополнительно > группа команд Организовать > Проект > группа команд Оптимизировать > Сжать проект.
2. Щелкните в диалоговом окне Сжать проект рядом с полем Настройки по [...].
3. В диалоговом окне Настройки: Сжатие выберите существующую схему для обработки или создайте новую.
4. Установите в поле Сжимаемые данные под флажком Реорганизовать проект флажок Расширенный режим.
5. Щелкните по кнопке  (Сохранить).
6. Щелкните по кнопке [OK].
7. Дождитесь завершения процесса реорганизации, а затем запустите новый контрольный прогон для всего проекта.

!!! note "Замечание:"

    Нам часто задают вопросы о стандартной длине поля идентифицирующих элементовобозначенияустройства.
