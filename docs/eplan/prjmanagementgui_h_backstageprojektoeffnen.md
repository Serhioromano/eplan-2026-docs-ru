# Открыть проект (вид Backstage)

Внутри вида Backstage можно легко открывать проекты. Уже открытые проекты можно опознать по тому, что имена проектов отображаются в строке заголовка главного окна.

Количество проектов, отображаемых в виде Backstage Открыть, и должен ли Eplan автоматически запускаться с последними открытыми проектами при следующем запуске программы, можно задать в специфических для пользователя настройках для интерфейса пользователя.

1. Выберите следующие команды: Файл > Открыть.

!!! info "Для сведения:"

    В области Последние использованные отображается список недавно открытых проектов.

!!! info "Для сведения:"

    По каждому проекту отображается соответствующий каталог, а также дата и время последнего открытия или закрытия проекта. Если проект был открыт в эксклюзивном режиме или с защитой от записи, дополнительно отображается режим обработки, в котором проект находился прошлый раз.

!!! info "Для сведения:"

    В окне предварительного просмотра свойств отображаются значения некоторых свойств проекта, таких как Описание проекта, Название фирмы, Последний обработчик и т. п. для выделенного в списке проекта. Здесь отображается та же информация, что и в окне предварительного просмотра Проводника Windows.

2. Дважды щелкните на нужный проект в виде Backstage Открыть в списке последних открытых проектов.
3. Если нужного проекта нет в списке, выберите команду Поиск.
4. Перейдите в диалоговом окне Открыть проект в каталог,в котором находится нужный проект, и выделите проект.
5. Щелкните по кнопке ++Открыть++.

!!! info "Для сведения:"

    Вид Backstage закрывается и проект открывается в навигаторе страниц.

!!! info "Для сведения:"

    Имя проекта выделяется на панели быстрого доступа полужирным шрифтом.

!!! tip "Совет:"

    Через раскрывающийся список в диалоговом окне Открыть проект для проекта можно настроить определенный режим обработки (стандартный, эксклюзивный, с защитой от записи). Это важно, например, при работе в многопользовательском режиме.

### Закрепить проекты

Для закрепления часто используемых проектов можно использовать пиктограмму ![](images/userinterface_unpin_as.png) (Закрепить). Эти проекты будут отображаться во втором списке над последними открытыми проектами. Если вам больше не нужна запись, закрепленная вверху, вы можете удалить ее из списка закрепленных проектов, нажав на пиктограмму ![](images/userinterface_pin_as.png).

Если в списке закрепленных проектов имеется заданное максимальное количество проектов, то дальнейшее их закрепление невозможно. Максимальное количество задается в настройках пользователях для интерфейса.
