## Вид Backstage: Справка

[Вызов диалогового окна:](javascript:void\(0\);)

Файл > Справка

В виде Backstage Справка доступны следующие команды:

Команда |  Значение  
---|---  
Содержимое |  Здесь можно найти сведения о продуктах Eplan.

  * Информационный портал: запускает интернет-страницу Eplan со сведениями о продуктах Eplan (справочные системы, технические советы, примечания к выпуску и т. д.). С помощью полнотекстового поиска по всем сохраненным техническим публикациям здесь можно найти требуемые понятия.
  * Справочная система: вызывает справку о вашей версии Eplan.

  
Поддержка и обновления | 

  * Поддержка: запускает интернет-страницу Eplan с формой для запроса о поддержке.
  * Download Manager: запускает Eplan Download Manager и предоставляет возможность установить компоненты программы для Eplan.

  
Группа команд Сведения |  Здесь можно найти сведения о вашей версии Eplan:

  * Продукт
  * Объем лицензии
  * Авторское право / Торговая марка
  * Информация о системе
