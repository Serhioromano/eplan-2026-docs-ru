# Вкладка Общее (Настройки: Внешняя обработка)

## Вызов диалогового окна (для данных проекта):

* Вы открыли проект. **Файл** > **Экспортировать** > группа команд **Данные проекта** > **Данные проекта** > группа команд **Внешняя обработка** > **Свойства**. Нажмите в диалоговом окне **Внешняя обработка** рядом с полем **Настройки** кнопку ++"..."++. Выберите вкладку **Общее**.
* **Файл** > **Настройки** > **Пользователь** > **Интерфейсы** > **Внешняя обработка**. Выберите вкладку **Общее**.

## Вызов диалогового окна (для данных изделия):

Вкладка **Основные данные** > группа команд **Изделия** > **Управление**. В диалогом окне **База данных изделий** через меню ++"Дополнительно"++ > **Настройки** была открыта база данных изделий. Кнопка ++"Дополнительно"++ > **Внешняя обработка свойств** > **Экспортировать данные**. Нажмите в диалоговом окне **Внешняя обработка** рядом с полем **Настройки** кнопку ++"..."++. Выберите вкладку **Общее**.

На этой вкладке задайте общие настройки для внешней обработки.

Обзор основных элементов диалогового окна:

### Тип файла:

Выберите из этого раскрывающегося списка требуемый тип файла, который необходимо сгенерировать при экспорте. В зависимости от выбора вы можете открыть диалоговое окно для соответствующих настроек с помощью пункта ++"Параметры"++.

### Целевой файл:

В этом поле укажите дисковод, каталог и имя генерируемого целевого файла или нажмите на кнопку ![](images/all_selectfile_as.png), чтобы выбрать дисковод и каталог в интерактивном режиме.

С помощью пункта всплывающего меню **Вставить переменную пути** перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

### Шаблон:

Если из раскрывающегося списка **Тип файла** выбрана запись "Файл Excel (*.xlsx, *.xlsm)", в этом поле можно ввести путь файла и имя файла шаблона или выбрать файл с помощью кнопки ![](images/all_selectfile_as.png); этот шаблон затем будет определять формат данных при экспорте.

С помощью пункта всплывающего меню **Вставить переменную пути** перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.
