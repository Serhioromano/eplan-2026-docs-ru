## Определить предварительный выбор изделия

Предварительный список изделий представляет собой список изделий, который Вы составляете и сохраняете под определенным именем . Его можно использовать в качестве фильтра при выборе изделия или устройства. Предварительный выбор изделий сохраняется для конкретного проекта.

Условие:

Вы дважды щелкнули по условному обозначению и выбрали в диалоговом окне Свойства <...> вкладку Изделие.

1. Выберите под кнопкой [Настройки] пункт всплывающего меню Выбор устройства.
2. В диалоговом окне Настройки: выбор устройства нажмите рядом с полем Список выбора на [...].
3. Выберите из раскрывающегося списка определенную пользователем схему, которую вы хотели бы изменить, или создайте с помощью  (Создать) новую [схему](schemeconfig_h_schematabearbeiten.md).  
  
Если предварительный выбор изделий уже содержит изделия, они будут отображены в списке.
4. При помощи  (Создать) над списком изделий откройте диалоговое окно Выбор изделия.
5. Просмотрите структуру дерева и выделите изделия, которые хотите внести в предварительный выбор изделий.
6. Щелкните по кнопке [OK].  
  
Изделия будут внесены в список.
7. Нажмите в диалоговом окне Предварительный выбор изделий на [OK].  
  
Схема предварительного выбора изделий будет сохранена и отображена в диалоговом окне Настройки: выбор устройства в раскрывающемся списке Список выбора.
8. Закройте диалоговое окно Настройки: Выбор устройства нажатием кнопки [OK].
