## Диалоговое окно Настройки: Общие (проекты, управление)

[Вызов диалогового окна:](javascript:void\(0\);)

Вы открыли проект. Файл > Настройки > Проекты > "Имя проекта" > Управление > Общее.

В этом диалоговом окне задаются общие, специфические для проекта, специфические для основных данных предварительные настройки.

Обзор основных элементов диалогового окна:

Синхронизировать основные данные проекта при открытии:

Если установлен этот флажок, используемые в проекте основные данные синхронизируются с пулом основных данных, как только соответствующий проект будет открыт или восстановлен.

Библиотеки символов и формы могут синхронизироваться только тогда, когда акивирован флажок для отдельных библиотек символов и форм Синхронизировать. Те библиотеки символов и формы, которые синхронизируются, устновите в следующих местах:

  * Библиотеки символов: диалоговое окно Настройки: Библиотеки символов (Файл > Настройки > Проекты > "Имя проекта" > Управление > Библиотеки символов)
  * Формы: диалоговое окно Настройки: Вывод в страницах (Файл > Настройки > Проекты > "Имя проекта" > Отчеты > Вывод в страницах)



Если флажок снят, основные данные не синхронизируются при открытии проекта, даже если для отдельных библиотек символов или форм установлен флажок Синхронизировать.

Синхронизировать рамки:

Если этот флажок установлен, используемые в проекте рамки синхронизируются с пулом основных данных, как только соответствующий проект будет открыт или восстановлен. Необходимо только, чтобы был активирован флажок Синхронизировать основные данные проекта при открытии.

Обновить сохраненные изделия при открытии:

Если установлен этот флажок, то имеющиеся в проекте изделия синхронизируются с изделиями базы данных изделий при открытии проекта. Если изделия проекта устарели, открывается запрос.

Предпочтительные стандарты для вставки макросов схем соединений:

В этом групповом поле вы задаете, какой фирменный или другой стандарт необходимо использовать для вставки макросов. Если на вкладке Свойства базы данных изделий на изделии для соответствующего фирменного или другого стандарта сохранен макрос схемы соединений, будет использован этот макрос. Это действительно для почти всех операций, в которых выполняется вставка макроса или вставка либо размещение устройств. Дополнительную информацию см. в разделе "[Макрос схемы соединений: Учет фирменных и других стандартов](macrosgui_k_standards.htm)".

Фирменный стандарт:

Сюда можно ввести имя фирменного стандарта. Если это имя также внесено в базу данных изделий в диалоговом окне Свойство: Макросы схемы соединений фирменного стандарта и для этого имени там сохранен макрос схемы соединений, при вставке макросов будет использован этот макрос схемы соединений.

Стандарт:

При помощи раскрывающегося списка вы определяете, какой стандарт должен использоваться при вставке макросов. Если здесь выбрать, например, запись "IEC", будет вставлен макрос, сохраненный на изделии в свойстве Макрос схемы соединений: IEC.



!!! note "Замечание:"

    


 

Стандарт для генерирования макросов схемы соединений:

Эти настройки можно обрабатывать только в Проекте макросов! В этом групповом поле вы задаете, какой фирменный или другой стандарт следует сохранить при автоматическом генерировании макросов на соответствующем макросе схемы соединений.

Для этого либо введите нужное обозначение в поле Стандарт компании, либо выберите нужный стандарт в поле Стандарт. Два поля одновременно не могут быть заполнены.

Настройка для стандарта компании или другого стандарта сохраняется в рамках макросов всех сгенерированных макросов схемы соединений при генерировании макросов схемы соединений. Соответствующее значение переносится в свойства Макрос: Стандарт компании или Макрос: Стандарт.

На основании заданной настройки сгенерированные автоматически макросы схемы соединений при вставке можно отфильтровывать посредством центра вставки в другом проекте.
