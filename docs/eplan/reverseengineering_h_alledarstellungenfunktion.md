## Обработать свойства во всех представлениях вспомогательной функции

Вспомогательная функция может быть многократно представлена в проекте в распределенном виде, например, как однополюсная или многополюсная функция, функция обзора, парная перекрестная ссылка и / или функция функциональной схемы автоматизации. С помощью функциональности "Свойства (общие)" можно за одну операцию изменить общие свойства сразу всех представлений функции одной вспомогательной функции, например, функциональный текст всех представлений функции замыкающего контакта.

Условия:

* Вы открыли проект.
* Открыт Навигатор устройств или Графический редактор.

1. Выделите представление функции вспомогательной функции в навигаторе устройств или в графическом редакторе и выберите пункт всплывающего меню Свойства (общие).  
Если режим Свойства (общие) активирован (командный путь: вкладка Обработать > группа команд Параметры > Общие), дважды щелкните по представлению функции вспомогательной функции.  
  
В диалоговом окне Свойства (общие): <...> на вкладке <Категория функции> (Устройство) нанесено обозначение категории функции соответствующего определения функции, например, "Замыкающий контакт" или "Плавкий предохранитель".
2. Измените требуемые свойства вспомогательной функции.
3. Щелкните по кнопке ++OK++.
4. Для обновления нажмите ++F5++.   
  
Свойства будут изменены на всех других соответствующих представлениях функции выбранной вспомогательной функции.

!!! note "Замечание:"

    В режиме обработки Свойства (общие)вы не сможете изменять Видимое ОУ, так каквидимое ОУотдельных функцийустройстваможет отличаться. Поле в этом случае будет недоступно. Если же вы измените Полное ОУ, отсюда будет автоматически установлено видимое ОУ. На вкладке<Категория функции>можно изменить поле Полное ОУдля всех представлений функции вспомогательной функции. После этого такие представления функции уже не будут принадлежать устройству. Также на вкладке<Категория функции> (Устройство)можно изменить Полное ОУдля всего устройства.
