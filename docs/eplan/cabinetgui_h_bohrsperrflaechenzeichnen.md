## Начертить и изменить заблокированные для монтажных отверстий области

Заблокированные для монтажных отверстий области исключают затронутую область из определения координат сверления. При этом различают два случая:

* Размещение монтажных отверстий или функциональных элементов со схемами сверления по заранее определенной заблокированной для монтажных отверстий области: Размещение монтажных отверстий невозможно. Размещение функциональных элементов со схемами сверления хотя и возможно, однако схемы сверления не будут видны в отображении отверстий и не экспортируются как данные ЧУ.
* Размещение заблокированной для монтажных отверстий области поверх уже имеющихся монтажных отверстий или функциональных элементов со схемами сверления: Имеющиеся отверстия со схем сверления, лежащие на этой поверхности, не будут видны в отображении отверстий и не экспортируются. Имеющиеся монтажные отверстия будут отображаться по-прежнему и будут экспортироваться как данные ЧУ, несмотря на размещенную поверх заблокированную для монтажных отверстий область.

Заблокированные для монтажных отверстий области размещаются таким же образом, как и запретные зоны для размещения. В отличие от запретных зон для размещения, заблокированные для монтажных отверстий области проникают сквозь весь функциональный элемент и становятся видны и активны с противоположной стороны.

Заблокированные для монтажных отверстий области отображаются в навигаторе пространства листа для каждой монтажной поверхности на уровне иерархии Заблокированные области.

Условие:

Вы открыли проект. Вы открыли пространство листа. Вы разместили один электрошкаф или монтажную плату.

1. Выберите следующие команды: Вкладка Вставить > группа команд Заблокированные области > Монтажное отверстие.
2. Переместите курсор на область, которую требуется заблокировать, чтобы автоматически ее активировать; либо активируйте монтажную поверхность непосредственно в навигаторе пространства листов.  
  
Автоматически или напрямую активированная монтажная область выделяется цветом. Ввод теперь возможен только на этой поверхности.
3. Начертите прямоугольник, представляющий заблокированную для монтажных отверстий область.

!!! tip "Совет:"

    При вставке используйте пункт всплывающего менюОпции размещения. В одноименном следующем диалоговом окне в поляхСмещение XиСмещение Yможно напрямую определить расстояние между курсором и точкой установки для начальной и конечной точки заблокированной для монтажных отверстий области.

 

### Изменить размер заблокированной для монтажных отверстий области

Размер заблокированной для монтажных отверстий области можно изменить двумя способами:

* Изменение свойств формата в диалоговом окне 'Свойства': на вкладке Формат в диалоговом окне 'Свойства' введите измененные значения в поля Ширина и Высота. Изменение производится относительно нижней левой угловой точки.
* Графическое изменение: выделите объект. На угловых точках и в центре боковых линий отображаются указатели в виде стрелок в направлении, в котором можно растянуть или сжать объект. При перемещении вдоль указателя на соседних объектах 3D отображаются точки захвата, которые можно использовать для точного позиционирования.
