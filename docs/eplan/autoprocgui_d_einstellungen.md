# Диалоговое окно Настройки: Автоматизированная обработка

* Вы открыли проект. Вкладка Инструменты > группа команд Отчеты > Автоматизированная обработка. В диалоговом окне Выполнить: Автоматизированная обработка щелкните по кнопке ++...++ рядом с полем Схема.
* Вы открыли проект. Файл > Дополнительно > группа команд Расширения > Интерфейсы > группа команд Автоматизированная обработка > Автоматизированная обработка. В диалоговом окне Выполнить: Автоматизированная обработка щелкните по кнопке ++...++ рядом с полем Схема.
* Файл > Управление проектами. Вы считали в диалоговом окне Управление проектами каталоги и выделили, как минимум, один проект. [Организовать] > Автоматизированная обработка. В диалоговом окне Выполнить: Автоматизированная обработка щелкните по кнопке ++...++ рядом с полем Схема.

В этом диалоговом окне определяется последовательность действий, которые выполняются автоматически. Эта последовательность сохраняется в виде схемы для каждого пользователя, которую можно копировать, экспортировать и импортировать.

Обзор основных элементов диалогового окна:

### Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать или обработать. Для этого также воспользуйтесь соседней [панелью инструментов](schemeconfig_m_schemaschaltflaechen.md).

### Доступные операции:

Это поле содержит все [операции](autoprocgui_k_automprojektaktionen.md), которые можно выбрать для автоматизированной обработки. Чтобы скопировать операцию в схему, при помощи кнопки ![](images/all_arrowright_as.png){ .ui-icon } (переместить направо) переместите ее в поле Выбранные операции.

Таблица:

Таблица содержит следующие столбцы:

* Строка: показывает порядковый номер строки.
* Выбранные операции: отображает все [операции](autoprocgui_k_automprojektaktionen.md), которые содержатся в выбранной схеме.
* Описание: введите здесь информативный текст, чтобы, например, различать одноименные операции.
