## Экспортировать списки присвоений

Экспорт списков присвоений всегда связан с ЦПУ. Принадлежность карты ПЛК к ЦПУ задается через [Имя ЦПУ](devicetaggui_r_spsstruktur.htm#CPU). ЦПУ однозначно идентифицируется путем ввода имени ЦПУ в формате [Проект конфигураций].[Имя станции].[Идентификатор ЦПУ].



!!! note "Замечание:"

    Вы можете экспортировать всякий раз только отдельный список для каждого процессора (ЦПУ). Поэтому в диалоговом окнеАдреса / Списки присвоенийнастройтефильтртак, чтобы отображались толькоадреса ПЛКодногоЦПУ. Схема, задающая формат адресов ПЛК, находится на основе ЦПУ, содержащихся в выборе, и здесь ее нельзя изменить. Если ЦПУ не присвоена схема, используется схема, заданная в настройках проекта.


 

  1. Выберите следующие команды: Вкладка Устройства > группа команд ПЛК > Список присвоений > кнопка [Дополнительно] > Экспортировать список присвоений (весь ЦПУ).  
  
В диалоговом окне [Экспортировать список присвоений (весь ЦПУ)](plcgui_d_exportzuli.htm) в поле Специфические для ПЛК настройки отображается схема, задающая формат адресов ПЛК. Над полем дополнительно отображаются проект конфигураций и имя станции, которым присвоено ЦПУ.
  2. В поле Язык выберите соответствующий списку присвоений язык.  

  3. В поле Имя файла укажите имя, под которым сохраняется экспортированный файл.
  4. Щелкните по кнопке [OK].  
  
Адреса из списка присвоений записываются в файл экспорта. При этом все карты ПЛК учитываются с одинаковым именем ЦПУ.
