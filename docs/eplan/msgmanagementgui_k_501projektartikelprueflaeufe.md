# Зависимые от проекта сообщения контрольного прогона для основных данных изделий

Для проверки основных данных изделий в управлении изделиями доступны контрольные прогоны класса сообщений 502 "Основные данные изделий". Зависимые от проекта контрольные прогоны устаревшего класса сообщений 501 "Основные данные изделий" больше не будут выполняться.

В проектах прежних версий (2025 и старше) все еще могут сохраняться зависимые от проекта сообщения контрольного прогона старого класса сообщений 501 "Основные данные изделий". При открытии такого проекта можно убрать эти сообщения с помощью запроса из проекта. В противном случае эти сообщения будут и дальше отображаться в управлении сообщениями.

Для сообщения контрольного прогона класса сообщений 501, отображаемого в управлении сообщениями, можно с помощью пункта всплывающего меню ++"Свойства"++ перейти в управление изделиями и там устранить ошибку в изделии. Для обработанных сообщений можно установить флаг **Выполнено** и скрыть их, используя фильтр по этому свойству.

Чтобы получить информацию о методах устранения соответствующей проблемы для старого сообщения контрольного прогона из класса сообщений 501, см. справку по контрольным прогонам класса сообщений 502 "[Основные данные изделий](msg/messages_o_502Partmasterdata.md)" с такими же тремя последними цифрами (например, для сообщения контрольного прогоне 501002 обратитесь к справке по сообщению контрольного прогона 502002).
