# Определение тегов в центре вставки

Такие объекты, как символы, устройства, а также макросы окна и символа могут быть связаны в центре вставки с любым ключевым словом с помощью так называемого "тега". Задавая теги, можно присваивать объекты, например, производителю, имени клиента или части установки. Кроме того, теги упрощают нахождение объектов, которые возможно понадобятся вам для вставки в будущем.

Условия:

* Вы открыли проект.
* В Графическом редакторе открыта страница проекта. Либо вы открыли пространство листа.
* Вы открыли центр вставки.

1. Перейдите по папкам типов объектов **Символ**, **Устройство** или **Макрос окна / символа** и их подпапкам к объекту, который вы хотите присвоить тегу.
2. Нажмите в плитке предварительного просмотра объекта на пиктограмму ![](images/insertergui_no_tag_tile as.png) (тег).

![](images/arrow.png) Пиктограмма теперь будет иметь заполненный вид (![](images/insertergui_tag_tile_as.png)).

3. Введите в диалоговом окне **Управление тегами: <Имя объекта>** нужное ключевое слово в поле **Новый тег**. Или выберите тег в открывшемся списке.

![](images/arrow.png) После щелчка по этому полю отобразится список имеющихся тегов, которым еще не назначен объект.
4. Щелкните по кнопке ++"OK"++.

![](images/arrow.png) Тег отобразится в списке **Теги**.
5. При необходимости введите остальные теги или удалите ненужные теги с помощью кнопки ![](images/all_delete_as.png) (Удалить).
6. Щелкните по кнопке ++"OK"++.

![](images/arrow.png) Объект будет связан с тегами, содержащимися в списке **Теги**.
7. Выберите в строке навигации **Главная** > **Теги**.

![](images/arrow.png) Созданный тег отображается как новая папка под строкой навигации.

![](images/arrow.png) Рядом с папкой отобразится "1", как количество объектов, присвоенных тегу. Если вы присвоите тегу другие объекты, количество увеличится соответствующим образом.

8. Нажмите на папку тега.

![](images/arrow.png) Объект или объекты, связанные с тегом, теперь будут доступны вам в виде плиток предварительного просмотра, их можно сразу же вставлять.

!!! tip "Совет:"

    В качестве альтернативы нажатию на пиктограмму ![](images/insertergui_tag_tile_as.png), объект, выделенный в плитке предварительного просмотра, может быть связан с тегом с помощью клавиши ++"T"++.

!!! note "Замечание:"

* Невозможно определить многоязычные теги.
* Ключевые слова, определенные в качестве тегов, могут состоять из любых символьных строк, включая специальные символы.
* Eplan запоминает все ключевые слова, назначенные в качестве тегов. Если вы хотите присвоить объекту уже существующее ключевое слово, просто введите в диалоговом окне обработки тегов первые символы ключевого слова в поле **Новый тэг** (при этом верхний / нижний регистры не учитываются). Все назначенные теги, которые начинаются с введенных символов, будут предложены под полем для выбора. Щелкнув мышью по нужному тегу и нажав на кнопку ++"OK"++, присвойте объект выбранному ключевому слову.
* Один и тот же объект может быть присвоен разным тегам.

### Удаление присвоения тега

1. Выберите в строке навигации **Главная** > **Теги** > "Имя", и переключитесь отсюда в режим предварительного просмотра отображаемых под именем тега объектов.
2. Выделите в плитке предварительного просмотра пиктограмму (![](images/insertergui_tag_tile_as.png)) на том объекте, присвоение тега которого вы хотите удалить.

![](images/arrow_11x11.png) Откроется диалоговое окно **Управление тегами: <Имя объекта>**, в котором отобразятся имена тегов, которым присвоен объект.

3. Выделите в списке тот тег, которому больше не должен быть присвоен объект.
4. Нажмите кнопку ![](images/all_delete_as.png).
5. Щелкните по кнопке ++"OK"++.

![](images/arrow_11x11.png) Плитка предварительного просмотра объекта будет удалена.

![](images/arrow_11x11.png) Отображение количества объектов, присвоенных тегу, уменьшится на значение "1" рядом с соответствующей папкой. Если тегу был присвоен всего один объект, тег удалится полностью.
