## Расширения для индивидуального разъединения узлов и модулей

Для индивидуального разъединения узлов и модулей в данной версии реализованы следующие возможности:   
\- Индивидуальное разъединение узлов при выборе изделия  
\- Индивидуальное разъединение узлов и модулей при экспорте данных изготовления

### Индивидуальное разъединение узлов при выборе изделия

Изначально возможность разъединения узлов с помощью специфической для пользователя настройки Развернуть узел при выборе изделия была единственным способом разъединения узла на составные части в спецификациях. Однако при этом терялась взаимосвязь между изделием узла и отдельными составными частями.

Уже некоторое время существуют различные варианты разъединения в спецификациях, например, настройка Развернуть узлы в специфических для проекта настройках для значений изделия.

Чтобы предотвратить случайное разъединение узлов во время выбора изделия, специфическая для пользователя настройка Развернуть узел перенесена из диалогового окна Настройки: Изделие (пользователь) на вкладку Узел в управлении изделиями. Благодаря этому теперь вы можете индивидуально указывать для каждого изделия узла, следует ли его разъединять при выборе изделия или нет.

Если для какого-либо изделия узла в групповом поле Выбор изделия установлен флажок Развернуть узел, то тогда этот узел будет разъединен при выборе изделия. Это также относится к вставке узла из центра вставки. Флажок До степени, который также был перемещен, можно позволяет задать уровень, до которого будет разъединен узел при выборе изделия.

### Индивидуальное разъединение узлов и модулей при экспорте данных изготовления

Теперь в управлении изделиями можно индивидуально для каждого узла и для каждого модуля указывать, следует ли разъединять данное изделие при экспорте данных изготовления / при выводе данных маркировки или нет. Для этого на вкладках Узел и Модуль в управлении изделиями добавлена таблица Значения изделия с новым столбцом Данные изготовления (экспорт). Используя настройки для этого столбца, можно указать, будет ли соответствующий узел или модуль разъединяться при экспорте данных изготовления для отчета "Групповая спецификация изделий" и / или "Спецификация изделий" или нет.

Значение по умолчанию — параметр "Из настроек". В этом случае используются настройки, заданные в диалоговом окне "Настройки". Если вы выберете другой параметр, то он заменит настройку, заданную в диалоговом окне "Настройки".

Как и при экспорте данных изделия, вы также можете указывать при экспорте данных изготовления, следует ли учитывать при разъединении дополнительные части, содержащиеся в узле или модуле.

В рамках этого расширения настройки, уже имевшиеся ранее на этих вкладках для индивидуального разъединения узла или модуля в отчетах "Групповая спецификация изделий" и "Спецификация изделий", также были перенесены в таблицу Значения изделия, где их можно задать с помощью столбца Отчеты.
