## Диалоговое окно "Присвоение поля (импорт устройств / маршрутизируемых соединений)" / диалоговое окно "Настройки: Импорт"

Вызов диалогового окна "Присвоения полей":

Вы открыли проект.

* Файл > Импортировать > группа команд Данные проекта > Данные проекта > группа команд Устройства > Устройства. В диалоговом окне Импортировать данные устройств щелкните мышкой рядом с полем Присвоение полей по кнопке [...].
* Файл > Импортировать > группа команд Данные проекта > Данные проекта > группа команд Маршрутизируемые соединения > Маршрутизируемые соединения. В диалоговом окне Импортировать данные соединений щелкните мышкой рядом с полем Присвоение полей по кнопке [...].

Вызов диалогового окна Настройки: Импорт:

Вы открыли проект.

* Файл > Настройки > Проекты > "Имя проекта" > Устройства > Импорт
* Файл > Настройки > Проекты > "Имя проекта" > Маршрутизируемые соединения > Импорт

В диалоговом окне Настройки: Импорт можно создавать и обрабатывать схемы с настройками для присвоения полей при импорте устройств и маршрутизируемых соединений. Эти настройки выбираются и применяются в диалоговом окне Присвоение полей.

Диалоговое окно Присвоение полей делает возможным присвоение внешнего поля данных из источника данных свойству Eplan. Присвоения можно выбирать в качестве схемы, сохранять и обрабатывать.

Обзор основных элементов диалогового окна:

Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать или обработать. Для этого также воспользуйтесь соседней [панелью инструментов](schemeconfig_m_schemaschaltflaechen.md).

Панель инструментов Таблица:

Кнопка |  Значение  
---|---  
(Создать) |  Создает новую строку. Только в диалоговом окне Присвоения полей в строках со статусом : разблокирует еще не присвоенное обозначение поля данных для обработки.  
(Удалить) |  Удаляет выделенные строки.  

Таблица:

В таблице имеются следующие столбцы:

* Статус: Пиктограмма  показывает, что поле данных есть только в схеме. Эти строки не учитываются при импорте и могут быть удалены при помощи кнопки  (Удалить).   
Только в диалоговом окне Присвоение полей: пиктограмма  показывает, что поле данных есть в источнике данных и его удалось идентифицировать.
* Номер столбца: Возможность ввода для номера столбца, на основании которого выбираются поля данных во внешнем источнике данных, из которого должны импортироваться данные.
* Внешнее обозначение поля данных: В этом столбце отображаются обозначения поля данных внешнего источника данных. Если в источнике данных отсутствует строка с обозначениями поля данных, здесь ничего не отображается.
* Свойство: В этом столбце отображается свойство Eplan, присвоенное внешнему полю данных. Для присвоения свойства щелкните в столбце Свойство по одной из ячеек. Щелкнув кнопку [...], можно открыть диалоговое окно Выбор свойства и выбрать другое свойство.

!!! tip "Совет:"

    В диалоговом окнеПрисвоение полейвсе ячейки строки выделены серым цветом, если обозначению поля данных, обнаруженному во внешнем источнике данных, еще не присвоено свойство Eplan. В этом случае поле данных имеет статус(Поле данных в схеме отсутствует).
