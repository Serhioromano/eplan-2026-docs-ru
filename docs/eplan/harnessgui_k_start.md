## Проводной монтаж

Eplan оказывает поддержку при проектировании проводного монтажа, кабельных сборок и их компонентов, а также при управлении ими. С помощью функции импорта можно импортировать в проекты Eplan проводной монтаж, кабельные сборки и связанные с ними компоненты, созданные в Eplan Harness proD, и там обрабатывать и анализировать их. Затем можно снова экспортировать проводной монтаж, кабельные сборки и их компоненты для дальнейшей обработки в Eplan Harness proD.

Возможно следующее:

* Созданные с помощью Eplan Harness proD проводной монтаж и кабельные сборки можно импортировать в проект на платформе Eplan.
* Проводной монтаж и кабельные сборки можно генерировать с предварительно заданными свойствами или вставлять в качестве символа в схему соединений.
* Можно назначить проводному монтажу или кабельной сборке дополнительные функции, соединения или изделия либо удалить существующие присвоения.
* Изделия, внесенные на определения проводного монтажа, определения кабельных сборок и их компоненты, можно выводить в отчетах либо использовать для экспорта данных изготовления или для маркировки.
* Проводной монтаж и кабельные сборки можно экспортировать для дальнейшей обработки в Eplan Harness proD.
