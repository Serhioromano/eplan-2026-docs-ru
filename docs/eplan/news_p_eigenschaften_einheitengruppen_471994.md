## Группы единиц измерения для свойств типа поля "Значение с единицей измерения"

Теперь все определения свойств типа поля "Значение с единицей измерения" содержат дополнительную информацию для определения конкретной группы единиц измерения (например, "Длина" или "Давление"). Если для свойства типа поля "Значение с единицей измерения" определена группа единиц измерения и для этого свойства указывается значение без единицы измерения, то для такого значения используется соответствующая стандартная единица СИ (например, при пересчете).

Группу единиц измерения теперь можно указать при настройке определенных пользователем свойств в диалоговом окне Конфигурировать свойства. Для этого диалоговое окно было дополнено новым раскрывающимся списком Группа единиц измерения. Кроме того, из-за ограничений по размеру была изменена компоновка диалогового окна и теперь оно разделено на две вкладки: Общее и Представление. Это относится как к определенным пользователем свойствам проекта, так и к определенным пользователем свойствам в управлении изделиями.

Вкладка Общее в основном содержит настройки, которые нельзя изменить после создания определенного пользователем свойства. Также на этой вкладке находится новый раскрывающийся список Группа единиц измерения. Однако в этом поле настройку можно изменить.

Чтобы можно было проверять свойства типа поля "Значение с единицей измерения" в проекте и в основных данных изделия, в классах сообщений 022 "Прочее" и 502 "Основные данные изделий" добавлены два новых контрольных прогона:

* Контрольные прогоны 022063 и 502040 проверяют, отсутствует ли единица измерения в значении свойства, если это определено в конфигурации.
* Контрольные прогоны 022064 и 502041 позволяют выявить неверную единицу измерения в значении свойства, если в конфигурации определена группа единиц измерения.
