## Указания по ознакомлению с руководством

Перед началом чтения обратите внимание на следующие указания:

!!! warning "Предупреждение:"

    Фрагменты текста, сопровождаемые этим знаком, являются предупреждениями. Прочтите их, прежде чем продолжить обработку!

 

Данным изображением предваряются примеры, которые можно развернуть. Чтобы отобразить текст примера, нажмите на символ "плюс".

!!! example "Пример:"

    Текст примера выводится на отображение. Чтобы снова скрыть текст примера, нажмите на символ "минус".

 

!!! note "Замечание:"

    Рядом с таким изображением находятся указания, которые должны облегчить работу с программой.

 

!!! tip "Совет:"

    Рядом с этим изображением находятся полезные советы, например, по альтернативным методам работы.

 

* Элементы пользовательского интерфейса выделены шрифтом синего цвета, что позволяет быстро найти их в тексте.
* Полужирный шрифтом выделен текст, имеющий особую важность, на который следует обязательно обратить внимание.
* Примеры кодов, имена каталогов, команды прямого ввода и т.п. выделяются непропорциональным шрифтом.
* Для облегчения поиска определенных параметров программы в некоторых темах справки имеется предшествующий "командный путь". Выберите выделенные синим цветом команды и параметры, чтобы перейти из ленты к соответствующему параметру. С помощью указанного ниже пути к команде можно вызвать справочную систему Eplan: Файл > Справка > группа команд Поддержка > Содержимое > Справочная система.
* В указаниях по действиям, ведущих шаг за шагом к определенной цели, во многих местах после показывающего вправо символа стрелки  описывается реакция программы на ваши действия.
* Под строкой См. также находятся гиперссылки на страницы, также относящиеся к данной теме. Например, с помощью нижеследующей гиперссылки можно перейти к разделу "Использование справочной системы", где представлена подробная информация о работе со справочной системой.
