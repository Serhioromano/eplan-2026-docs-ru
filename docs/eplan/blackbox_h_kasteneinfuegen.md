## Вставить черные ящики

Черный ящик представляет собой физический функциональный элемент, состоящий из нескольких графических элементов; все они расположены внутри прямоугольника черного ящика (напр., изображение блока питания). При создании черного ящика программа присваивает ему собственное ОУ.

Условие:

Вы открыли проект. В Графическом редакторе открыта страница проекта.

1. Выберите следующие команды: Вкладка Вставить > группа команд Устройства > Черный ящик.
2. Нарисуйте прямоугольник, который будет представлять блок.
3. В диалоговом окне черного ящика Свойства введите данные устройства.
4. Щелкните по кнопке [OK].  

Черный ящик будет сохранен в проекте со всеми свойствами.

!!! note "Замечание:"

    При включенномзахвате сетки(кнопка(вкл. / выкл. захват сетки) в строке состояния) вновь начерченный черный ящик расположен точно на сетке, на которой он был размещен; если захват сетки отключен, блок можно нарисовать произвольно рядом с сеткой.

!!! tip "Совет:"

    Черный ящик можно отобразить при помощи символовDC2илиDCF2, известных также при черчении ломаных линий. Для этого в диалоговом окнеВыбор символавыберите символ и задайте начальную точку блока, щелкнув левой клавишей мыши в схеме соединений. После задания всех остальных пунктов завершите действие через Всплывающее менюЗакрыть ломаную линию.
