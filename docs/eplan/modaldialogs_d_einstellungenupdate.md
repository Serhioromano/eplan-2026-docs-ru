# Диалоговое окно Настройки: Проверить версию Eplan

## Вызов диалогового окна:

**Файл** > **Настройки** > **Фирма** > **Управление** > **Проверить версию Eplan**

В этом диалоговом окне определяется, необходимо ли выполнять проверку наличия обновлений программного обеспечения при запуске Eplan.

Обзор основных элементов диалогового окна:

### Проверить наличие новой версии Eplan:

Если этот флажок установлен, при запуске Eplan выполняется проверка наличия последней версии программного обеспечения. В этом случае появится системное сообщение, а в строке состояния отобразится пиктограмма ![](images/modaldialogsgui_update_available.png){ .ui-icon }. Нажав на эту пиктограмму, вы откроете Eplan Download Manager и сможете установить последнюю версию Eplan.
