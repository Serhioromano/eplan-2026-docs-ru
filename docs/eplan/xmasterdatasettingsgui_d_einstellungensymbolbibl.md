## Диалоговое окно Настройки: Библиотеки символов

Вы открыли проект.

* Файл > Настройки > Проекты > "Имя проекта" > Управление > Библиотеки символов
* Вы открыли символ или библиотеку символов (командный путь: вкладка Основные данные > группа команд Символы > раскрывающаяся кнопка Символ > Открыть или раскрывающаяся кнопка Библиотека символов > Открыть). Для библиотек символов необходимо еще в диалоговом окне Открыть библиотеку символов выбрать библиотеку символов и щелкнуть на [Открыть]. Пункт всплывающего меню Настройки.

В этом диалоговом окне возможно добавить библиотеки символов к текущему проекту, т.е. сохранить их в проекте или снова удалить сохраненные библиотеки. При выборе символа через центр вставки всегда отображаются только символы сохраненных библиотек символов, при чем они идентифицируются в проекте через их имена (без пути).

На библиотеки символов идет ссылка следующим образом:

* Все библиотеки символов, задаваемые в настройках проекта (командный путь: Файл > Настройки > Проекты > "имя проекта" > Управление > Библиотеки символов)
* Все открываемые или генерируемые библиотеки символов (командный путь: вкладка Основные данные > группа команд Символы > раскрывающаяся кнопка Библиотека символов > Открыть или Создать)
* Библиотеки символов, содержащиеся в свойствах формы Присвоение свойства / значения графике, Присвоение определения функции графике и Присвоение индекса графике.

!!! note "Замечание:"

    Если в диалоговом окнеСинхронизация основных данных <Имя проекта>(командный путь: вкладкаОсновные данные> группа командСинхронизация>Синхронизировать проект) запускается обновление библиотеки символов, выполняется точная проверка отдельных символов перед заменой библиотеки. Если находятся несовместимые данные, процесс прерывается с выводом соответствующего сообщения.

Обзор основных элементов диалогового окна:

Синхронизировать:

Если этот флажок установлен, при открытии проекта соответствующая библиотека символов автоматически синхронизируется с пулом основных данных, если в диалоговом окне Настройки: Общее (проекты, управление) установлен флажок Синхронизировать основные данные проекта при открытии (Файл > Настройки > Проекты > "Имя проекта" > Управление > Общее).

Предшествующий знак:

Задайте здесь предшествующий знак, который должен использоваться для различения библиотек символов. Eplan автоматически предлагает первую букву библиотеки символов.

В представлении в виде списка диалогового окна Выбор символа с помощью пункта всплывающего меню Имя с предш. знаком можно задать, чтобы отображался дополнительный столбец, содержащий определенный здесь предшествующий знак для библиотеки символов и собственное имя символа, отделенное двоеточием.

!!! example "Пример:"

    если у вас есть для библиотеки символовIEC_Symbolпредшествующий знакIто, напр. замыкающий силовой контакт этой библиотеки отображается какI:SL.

Библиотеки символов:

Щелкните в этом столбце и потом на [...] чтобы выбрать новую библиотеку символов, которая заменит текущую (если первоначальная библиотека символов и новая выбранная совместимы), или если вы нажали на [...] в пустом столбце, чтобы сохранить новую дополнительную библиотеку символов.

Стандартный вариант:

Щелкните по этому столбцу, чтобы открыть раскрывающийся список и выбрать пункт. Выбранный здесь пункт будет скопирован как заданное по умолчанию значение для стандартного варианта символов соответствующей библиотеки символов. Для отдельных символов этот стандартный вариант можно изменить в диалоговом окне Свойства символа — < Имя символа>.

(Удалить):

Щелкните на эту иконку в панели инструментов выше таблицы, чтобы удалить неиспользуемую библиотеку символов из проекта. Eplan проверяет, используются ли символы этой библиотеки символов в проекте и вставляет в этом случае соответствующее примечание.
