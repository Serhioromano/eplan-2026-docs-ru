## Генерировать данные изготовления для машин по сборке проводов

Eplan Pro Panel позволяет выводить данные изготовления для машин по сборке проводов от различных производителей для дальнейшей передачи производителю услуг:

* Rittal — Wire Terminal WT
* Steinhauer (Personal Wiring Assistant)
* CadCabel
* Metzner (Triathlon Kabelcenter)
* Schleuniger (Easy ProductionServer)
* Komax — Zeta

Каждый из этих форматов должен быть лицензирован как отдельный интерфейс.

Кроме того, можно сконфигурировать и вывести 'Общую спецификацию проводов'. Экспортированный файл может использоваться сборочными машинами, интерпретирующими данный формат, для автоматического обмера в длину, маркировки и сборки концов жил кабелей. В спецификации проводов содержится вся информация о соединениях между устройствами изделия, их трассе маршрутизации и их длине:

* Непрерывный номер
* Цвет / номер соединения
* Поперечное сечение / диаметр соединения
* Полное ОУ и обозначение вывода устройства, подключенного к источнику соединения
* Полное ОУ и обозначение вывода устройства, подключенного к цели соединения
* Длина соединения (без единицы измерения)
* Обработка концов проводов, источник
* Обработка концов проводов, цель
* Направление подсоединения, источник
* Направление подсоединения, цель
* Номер объединенных проводов
* Номер соединения
* Трасса маршрутизации (номера позиций пройденных кабельных каналов / ОУ кабельных каналов или областей маршрутизации)

Во всех случаях экспорта машин из Eplan Pro Panel в качестве заключительного сообщения отображается диалоговое окно, в котором перечисляются конкретные данные об экспортируемых компонентах или указываются причины, почему компоненты не могут быть экспортированы. В диалоговом окне отображается следующая информация:

* Имя экспортированного формата
* Имя использованной схемы и настроенного пути вывода
* Количество экспортированных компонентов
* Альтернативные варианты экспорта
* Перечень неэкспортированных компонентов с указанием причины, по которой они не были экспортированы.
* Указание на возможно выводившиеся системные сообщения.

!!! note "Замечание:"

    Для подготовки экспортированных с помощью Eplan данных изготовления для машины по сборке проводовRittal Wire Terminal WTтребуется шаблон импорта, который можносоздатьс помощью программного обеспеченияWire Cockpit.
