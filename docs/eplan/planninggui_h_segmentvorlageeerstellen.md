# Создать шаблоны сегментов

Создавать шаблоны сегментов и управлять ими можно в навигаторе шаблонов сегментов.

### Создать шаблоны сегментов

1. Выберите следующие команды: Вкладка Предварительное планирование > группа команд Общее > Шаблоны сегментов.
2. Выделите в дереве определение сегмента (например, измерительный контур) и выберите пункт всплывающего меню Новый шаблон сегмента.
3. Введите в диалоговом окне Свойства ++...++ на вкладке Шаблоны сегментов идентифицирующее имя и, при желании, описание для нового шаблона сегмента.
4. При необходимости присвойте шаблону сегмента нижестоящие шаблоны сегментов, используя таблицу Нижестоящие шаблоны сегментов. Для этого нажмите кнопку ![](images/all_new_as.png){ .ui-icon } (Создать) и выберите в последующем диалоговом окне Выбрать шаблон сегмента нужный шаблон сегмента. Возможен многократный выбор. При необходимости введите в поле Поиск текст, по которому должна выполняться фильтрация шаблонов сегментов.
5. При необходимости присвойте шаблону сегмента дополнительные свойства на других вкладках. То, какие вкладки отображаются, зависит от определения сегмента.
6. При необходимости запишите на вкладке Изделие изделие. Шаблоны функции изделия позднее можно будет использовать для создания подробного планирования.
7. При необходимости запишите на вкладке Макрос макрос. Позднее этот макрос можно будет использовать для [создания детального планирования](planninggui_h_makrosdragdrop.md).
8. Щелкните по кнопке ++OK++.

!!! info "Для сведения:"

    Будет создан шаблон сегмента с соответствующими свойствами.

!!! tip "Совет:"

    * В представлении структуры дерева навигатора шаблонов сегментов можно переместить шаблоны сегментов с помощью перетаскивания в другое место внутри определения основного сегмента, если эти шаблоны еще не использованы в проекте. При этом шаблону сегмента автоматически присваивается определение сегмента, под которое он был перемещен. При перетаскивании удерживайте нажатой кнопку ++Ctrl++, так происходит копирование выделенных шаблонов сегментов.
    * В навигаторе шаблонов сегментов можно выбрать несколько шаблонов сегментов одновременно. Если при этом вы выбрали шаблоны сегментов с одинаковыми нижестоящими шаблонами сегментов, то с помощью функции Групповая обработка можно, например, одновременно выбрать нижестоящие шаблоны сегментов для всех выбранных шаблонов сегментов или удалить выбранные нижестоящие шаблоны сегментов. Для этого выделите эти шаблоны сегментов в навигаторе шаблонов сегментов и выберите пункт всплывающего меню Свойства.

### Создать шаблон сегмента из имеющегося сегмента

Условия:

* Вы открыли проект, который уже содержит сегменты.
* Вы открыли навигатор предварительного планирования и навигатор шаблонов сегментов.

1. Выделите сегмент в навигаторе предварительного планирования.
2. Перетащите сегмент в навигатор шаблонов сегментов.

!!! info "Для сведения:"

    Будет создан шаблон сегмента со свойствами выделенного сегмента.

!!! note "Замечание:"

    * Шаблон сегмента не присваивается сегменту, из которого он был генерирован. При необходимости это присвоение нужно выполнить вручную.
    * Шаблоны сегментов с нижестоящими шаблонами сегментов таким образом создать невозможно.
