## Диалоговое окно Предварительный выбор изделий

[Вызов диалогового окна:](javascript:void\(0\);)

Вы открыли проект.

  * Файл > Настройки > Проекты > "Имя проекта" > Управление > Выбор изделия. Рядом с полем Предварительный выбор изделий нажмите [...].
  * Вы выделили главную функцию в графическом редакторе или навигаторе. Пункт всплывающего меню Свойства. Выберите вкладку Изделие. Кнопка [Настройки] > Выбор изделия (проект). В диалоговом окне Настройки: Выбор изделия (проект) рядом с полем Предварительный выбор изделий нажмите [...].



В этом диалоговом окне можно обрабатывать списки для предварительного выбора изделий или создавать новые.

Обзор основных элементов диалогового окна:

Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать или обработать. Для этого также воспользуйтесь соседней [панелью инструментов](schemeconfig_m_schemaschaltflaechen.htm).

Описание:

Данное поле отображает текст описания, который вы ввели при создании схемы в диалоговом окне Новая схема в поле Описание.

Панель инструментов:

На панели инструментов доступны такие кнопки:

Кнопка |  Значение  
---|---  
(Создать) |  С помощью этой кнопки можно открыть диалоговое окно Выбор изделия и выбрать там другие изделия, которые переносятся в список предварительного выбора изделия.  
(Удалить) |  С помощью этой кнопки можно удалить выделенные изделия из текущего списка.
