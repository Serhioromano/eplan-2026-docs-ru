## Создание диаграмм GRAFCET

Диаграммы GRAFCET можно создавать на уже существующей или новой странице. Ниже описано создание диаграммы GRAFCET на новой странице. Порядок действий при создании диаграмм GRAFCET на уже существующих страницах аналогичен.

Условия:

* Вы открыли проект.
* Вы добавили в проект библиотеку символов OS_SYM_ESS.slk. (Необходимые настройки можно выполнить при помощи следующих команд: Файл > Настройки > Проекты > "Имя проекта" > Управление > Библиотеки символов).
* Вы задали в настройках проекта специальный символ, который должен использоваться при размещении текстов свойств в блок-схемах рабочего процесса (например, OS3 для диаграмм GRAFCET).
* Вы вставили функции или устройства в проект и указали необходимые значения для свойств Функциональный текст, Статус [1] по Статус [10] и т. д.

!!! note "Замечание:"

### Создание страницы проекта для диаграммы GRAFCET

1. Создайте новую страницу проекта. Выберите следующие команды: Вкладка Главная > группа команд Страница > Создать.
2. Выберите в диалоговом окне Новая страница в поле Тип страницы запись "Обзор (I)" и наберите в поле Описание страниц текст описания для страницы проекта.
3. Введите в таблице в поле Сетка значение "3 мм".
4. Щелкните по кнопке ++OK++.  
  
Генерируется новая страница проекта. Если настройки сетки и используемая форма подходят друг к другу, то точки сетки попадут ровно в середину определенных в форме ячеек таблицы. Это облегчает процесс размещения устройств и стадий рабочего процесса.

### Создание таблицы переменных

Заголовок таблицы переменных создается с помощью макроса. Отдельную строку таблицы можно вставить с помощью размещения текстов свойств из навигатора устройств.

1. Откройте страницу проекта для блок-схемы рабочего процесса, например, с помощью двойного щелчка мыши на странице проекта в навигаторе страниц.
2. Выберите следующие команды: Центр вставки > строка навигации Главная > Макросы окна / символа.
3. Перейдите через структуру папок к каталогу макросов OS_ESS и выберите там макрос Table_GRAFCET.ema, нажав на плитку предварительного просмотра.
4. Затем разместите макрос с заголовком таблицы на нужном месте на диаграмме.
5. Выберите следующие команды: Вкладка Устройства > группа команд Устройства > Навигатор.
6. Выделите одну из функций в навигаторе устройств и выберите пункты всплывающего меню Функциональное размещение > С графикой символов.  
  
Специальный символ, заданный в настройках проекта, появится рядом с курсором. Если вы используете специальный символ OS3, то отобразится строка таблицы с текстами свойств функции (т. е. значение свойства Статус [10]).
7. Разместите графику (строку таблицы) на нужном месте в диаграмме.
8. Повторите описанные выше шаги для других устройств, которые должны быть представлены в таблице переменных.

### Чертить порядок рабочего процесса

Порядок рабочего процесса чертится с помощью графических элементов (например, ломаных линий). Eplan поддерживает ускоренную вставку специальных элементов блок-схем рабочего процесса. Стрелки, сигнальные точки, условия 'И' и 'ИЛИ', шаги GRAFCET, действия GRAFCET и прохождения GRAFCET можно внести в блок-схему рабочего процесса с помощью соответствующих команд. (Для этого вам нужно сначала [Настроить ленту](userinterface_h_menuebandanpassen.md) и присвоить нужную команду определенной пользователем группе команд.)

1. Если вам нужно начертить ломаную линию, выберите следующие команды: вкладка Вставить > группа команд Графика > кнопка  (Ломаная линия). (С помощью других кнопок можно начертить также прямоугольники, круги и т. д.).
2. Укажите по очереди точки ломаной линии и щелкните левой клавишей мыши, чтобы разместить каждую из этих точек.
3. Завершите операцию через [Пробел] или пункт всплывающего меню Закрыть ломаную линию.
4. Если вам нужно вставить шаг, выберите команду Шаг. (Для этого вам нужно сначала [Настроить ленту](userinterface_h_menuebandanpassen.md) и присвоить нужную команду определенной пользователем группе команд.) Аналогичным образом, воспользовавшись командами Шаг с прохождением, Действие, Действие с привязкой и Прохождение, можно вставлять другие элементы GRAFCET.  
  
Шаг появится рядом с курсором.
5. Нажимая клавишу ++Tab++ несколько раз, выберите нужный вариант шага, например начальный шаг.
6. Разметите шаг в блок-схеме рабочего процесса.  
  
После этого символ снова появится рядом с курсором, и вы сможете разместить следующий шаг.
7. Завершите операцию, выбрав пункт всплывающего меню Прервать операцию или нажав клавишу ++Esc++.
8. Повторите описанные выше шаги для других элементов GRAFCET, которые следует разместить в блок-схеме рабочего процесса.
