# Диалоговое окно Управление изделиями

Вкладка Основные данные > группа команд Изделия > Управление. Через меню ++Дополнительно++ > Настройки была открыта база данных изделий.

В этом диалоговом окне можно управлять основными данными баз данных изделий. При этом управление изделиями содержит как технические и коммерческие данные изделий, так и персональные данные (для клиентов и производителей / поставщиков), а также другие типы записей данных, такие как список принадлежностей, схема сверления и т. д.

Обзор основных элементов диалогового окна:

В левой области диалогового окна в виде дерева, списка или комбинированного представления отображаются управляемые данные. В представлении в виде дерева можно сконфигурировать отображаемые иерархии для изделий с помощью раздела [Конфигурация дерева](partsmanagementgui_d_baumkonfiguration.md).

### Панель инструментов:

Вы можете настроить отображение данных с помощью следующих кнопок:

Кнопка |  Значение
---|---
![](images/all_treeview_as.png) (представление в виде дерева) |  Отображает данные в виде иерархической структуры дерева. В качестве последнего уровня иерархии для изделий отображаются индивидуальные номера изделий или (при наличии) обозначение вариантов изделий.
![](images/all_listview_as.png) (представление в виде списка) |  Отображает изделия, расположенные друг под другом, в виде списка. Представление в виде списка невозможно для таких типов записи данных, как список принадлежностей, схема сверления и т. д.
![](images/all_combinationview_as.png) (Комбинация) |  Отображает изделия в комбинированном представлении дерева и списка. При этом в списке отображаются изделия выбранного в дереве узла. Комбинированное представление невозможно для таких типов записи данных, как список принадлежностей, схема сверления и т. д.
![](images/articlesgui_filterview_as.png) |  Переключает в оба направления между последней выбранной схемой фильтра и нефильтрованным видом.

Вы можете настроить, какие узлы / уровни иерархии будут отображаться для определенного типа записи данных в дереве с помощью [Дополнительно] > Настройки в Конфигурации дерева.

Отображать Eplan Data Portal в управление изделиями

Если вы зарегистрировались в Eplan Cloud, то в древовидной структуре и в комбинированном представлении над главным узлом для изделий будет отображаться пиктограмма ![](images/userinterface_edpIcon_as.png) "Data Portal".

Если щелкнуть по пиктограмме, в правой части управление изделиями в окне браузера в виде вкладки отобразится Eplan Data Portal. Здесь можно выбрать и скачать основные данные изделий.

Эта пиктограмма предназначена только для отображения Eplan Data Portal; ее нельзя настроить через пункт всплывающего меню Конфигурировать представление или через конфигурацию дерева. Пиктограмма отсутствует в представлении в виде списка и в комбинированном представлении.

Если установлена предварительная фильтрация изделий, то поиск в Eplan Data Portal невозможен и пиктограмма ![](images/userinterface_edpIcon_as.png) "Data Portal" не отображается.

Дополнительную информацию по Eplan Data Portal см. [здесь]https://www.eplan.help/ru-ru/Infoportal/Content/EDP_Cloud/Content/htm/DataPortalCS_k_home.htm.

### Фильтр:

В этом раскрывающемся списке отображаются все доступные фильтры. Выбранный фильтр активируется автоматически и применяется как к дереву, так и к списку. Запись "- Не активировано -" отключает фильтр и приводит к тому, что данные отображаются в неотфильтрованном виде. С помощью кнопки ++...++ откройте диалоговое окно [Фильтр](modaldialogsdb_d_filternnach.md). Здесь можно создать, обработать, удалить, скопировать, экспортировать, импортировать фильтр и управлять им.

Во всплывающем меню раскрывающегося списка Фильтр содержатся следующие записи:

* Выключить: Этот пункт меню доступен, если фильтр установлен: Сбрасывает настройку фильтра до записи "- Не активировано -".
* Активировать <Имя фильтра>: Этот пункт меню доступен, если для настройки фильтра установлено значение "- Не активировано -": Повторно активирует последний активный фильтр.

Таким образом можно быстро переключаться между неотфильтрованным и отфильтрованным в соответствии с требованиями пользователя представлениями.

С помощью критериев фильтра Шаблон функции в изделии можно фильтровать изделия в соответствии с определениями функций и другими данными шаблонов функций (например, техническими параметрами). В результате применения такого фильтра отображаются только те изделия, у которых значения свойств или определения функций сохраненных в них шаблонов функций соответствуют заданным критериям.

### Пoиск:

Введите в это поле текст для поиска и подтвердите клавишей [Enter].

По умолчанию при поиске учитываются только самые важные свойства (например, Номер изделия, Номер типа, Производитель и т. д.). Если поиск должен осуществляться с использованием других свойств, используйте кнопку ++...++ для перехода к диалоговому окну [Конфигурировать поиск](modaldialogsdb_d_suchekonfigurieren.md). Здесь с помощью схемы вы можете указать, по каким свойствам должен осуществляться поиск и в какой последовательности.

В остальном поиск ведет себя точно так же, как и [поиск](insertergui_k_suchen.md) в центре вставки: вы можете использовать те же операторы и символы-заполнители.

Если поиск не дал результатов, то он будет продолжен – если это возможно – в Eplan Data Portal. Если изделие было там найдено, то оно будет отображаться в Eplan Data Portal. Для этого, при необходимости, открывается Eplan Data Portal.
При поиске в Eplan Data Portal не учитываются операторы, символы-заполнители и свойства, указанные в конфигурации поиска.

### Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).

Дополнительно здесь представлены следующие пункты всплывающего меню, специфические для данного диалогового окна:

Пункт меню |  Значение
---|---
Создать |  Создает новое изделие / запись данных под выделенным изделием / узлом.
Создать вариант |  Доступно только для изделий. Открывает диалоговое окно Создать вариант для создания варианта изделия.
Вставить данные |  Открывает диалоговое окно [Вставить данные](articlesgui_d_dateneinfuegen.md), с помощью которого можно задать, какие данные скопированного изделия будут переданы выбранным изделиям / вариантам.
Список с предварительным выбором (только дерево) |  Уменьшает число отображаемых элементов, чтобы ускорить ориентирование в представлении в виде списка. Если этот параметр включен, представление в виде списка вызывается с автоматическим фильтром (выбор), причем этот фильтр содержит только что выбранные элементы.
Выбрать в дереве (только список) |  Показывает выделенный объект в представлении в виде дерева.
Конфигурировать представление |  Открывает диалоговое окно Конфигурировать представление, в котором можно задать, какие свойства должны отображаться в представлении в виде списка и в представлении структуры дерева.
Загрузить в eStock |  Загружает выбранные записи данных в центральную базу данных [eStock](partselectiongui_d_datenauswahlbenutzer.md) Eplan Cloud. Сначала для изделия открывается диалоговое окно Загрузить данные изделия. Здесь можно указать, будут ли выбранные изделия добавлены в коллекцию eStock. Данные других типов записей данных (список принадлежностей, схема сверления и т. п.) будут загружены автоматически.
Открыть в eStock |  Доступно, только если [коллекция eStock настроена в качестве источника данных](partselectiongui_d_datenauswahlbenutzer.md). Открывает выделенное изделие в eStock. Там данные можно обработать и после обработки обновить здесь, в управлении изделиями, перейдя в меню ++Дополнительно++ > Обновить данными из eStock.
Экспортировать |  Открывает для выделенных записей данных диалоговое окно "Экспортировать записи данных", в котором следует указать имя и тип файла экспорта. Если текущее выделение содержит узлы в представлении в виде дерева, будут учтены все находящиеся под ними записи данных.
Экспортировать данные |  Дает с помощью диалогового окна Внешняя обработка возможность экспортировать данные выделенных записей данных (изделия, адреса, схемы сверления и т. д.) для внешней обработки. Если текущее выделение содержит узлы в представлении в виде дерева, будут учтены все находящиеся под ними записи данных.
Объединить шаблоны функций |  Доступно только для узлов и модулей с подизделиями. Объединяет шаблоны функций подизделий для выделенных узлов и/или модулей и заносит их во вкладку Шаблоны функций узлов или модулей. Ручное объединение шаблонов функций имеет смысл только в том случае, если отключена настройка пользователя [Автоматически объединить шаблоны функций](partselectiongui_d_datenauswahlbenutzer.md) и поэтому автоматическое объединение не выполняется. Выбранные модули на самой верхней позиции дополняются шаблоном функции для черного ящика. Для модулей из подгруппы продуктов "Предварительно собранный" вместо этого добавляется шаблон функции для определения кабеля. Черный ящик или определение кабеля требуются в качестве группирующего элемента и получают при вставке модуля номер изделия модуля.
Присвоить шаблоны функций |  Позволяет автоматически создавать отсутствующие шаблоны функций из записанных макросов для выделенных записей данных. Обратите внимание, что для данной функциональности команда Отменить недоступна! Поэтому перед крупными изменениями желательно сохранить данные изделия.
Выполнить контр. прогон (только в дереве, только главный узел "Изделие") |  Открывает диалоговое окно [Выполнить контр. прогон](xesinspectiongui_d_prueflauf.md), в котором можно выполнить контрольный прогон на базе текущих или других настроек. После выполнения контрольного прогона сначала отображается окно сообщений с количеством сгенерированных сообщений контрольного прогона, а затем автоматически отображается вкладка [Сообщения](articlesgui_r_meldungen.md). Для отображения этой вкладки необходимо выбрать в древовидной структуре главный узел, например "Изделие".

В правой части этого диалогового окна отображается соответствующая информация о записях данных (например, изделиях, списках принадлежностей, клиентах), которые выделены в левой части. Если выбран главный узел (изделие, список принадлежностей и т. д.), в правой части будет отображаться вкладка Информация. Какие еще вкладки будут здесь отображаться помимо вкладки Свойства при выборе подузла, зависит от соответствующего типа записи данных.

### [Дополнительно]:

Пункт меню |  Значение
---|---
Импортировать |  Открывает диалоговое окно Импортировать записи данных, в котором указывается имя и тип файла и выбирается, каким образом должны быть обработаны импортируемые записи данных.
Экспортировать |  Открывает диалоговое окно Экспортировать записи данных, в котором задается имя и тип файла, а также объем экспорта.
Внешняя обработка свойств |  Дает возможность экспортировать данные изделий, адресов, схем сверления и т. д. через подменю и снова импортировать их после внешней обработки.
Перевод |  Открывает подменю с параметрами для автоматического перевода.
Объединить шаблоны функций |  Объединяет шаблоны функций подизделий для всех узлов и модулей и заносит их во вкладку Шаблоны функций узлов и модулей. Ручное объединение шаблонов функций имеет смысл только в том случае, если отключена настройка пользователя [Автоматически объединить шаблоны функций](partselectiongui_d_datenauswahlbenutzer.md) и поэтому автоматическое объединение не выполняется. Модули на самой верхней позиции дополняются шаблоном функции для черного ящика. Для модулей из подгруппы продуктов "Предварительно собранный" вместо этого добавляется шаблон функции для определения кабеля. Черный ящик или определение кабеля требуются в качестве группирующего элемента и получают при вставке модуля номер изделия модуля.
Присвоить шаблоны функций |  Позволяет автоматически создавать отсутствующие шаблоны функций из записанных макросов для всех записей данных. Обратите внимание, что для данной функциональности нет операции Отменить! Поэтому перед крупными изменениями желательно сохранить данные изделия.
Оптимизировать базу данных |  Оптимизирует базу данных изделий для свойств, которые используются в ранее определенных фильтрах и в конфигурациях дерева. Какие свойства оптимизируются, а какие нет, будет показано в нижеследующем запросе.

!!! note "Замечание:"

    Если вы используете только фильтры и представления структуры дерева, поставляемые компанией Eplan, то в оптимизации базы данных изделий нет необходимости. Мы рекомендуем выполнять оптимизацию базы данных изделий, если часто используемые фильтры и конфигурации дерева были централизованно определены, стандартизированы и распределены в вашей организации. Оптимизация также ускоряет работу определенных позже фильтров и конфигураций дерева, если для них используются ранее оптимизированные свойства.

Конфигурировать свойства |  Открывает диалоговое окно Конфигурировать свойства, в котором вы можете создать и настроить определенные пользователем свойства для изделий.
Перенести произвольные свойства |  Открывается диалоговое окно [Перенести произвольные свойства](articlesgui_d_migrationfreieeigenschaften.md), в котором можно преобразовать устаревшие произвольные свойства в определенные пользователем свойства изделий.
Настройки |  Открывает диалоговое окно Настройки: Изделие (пользователь), в котором можно выбрать уже существующую базу данных изделий или создать новую базу данных изделий. Кроме того, в этом диалоговом окне задаются общие настройки для работы с базой данных изделий.
Удалить сообщения контрольного прогона |  Удаляются сообщения контрольного прогона для основных данных изделий из базы данных изделий.
Загрузить в eStock все изделия |  Загружает все изделия в центральную базу данных eStock Eplan Cloud. Будут также загружены данные, которые используются в изделиях, а именно производитель, макросы и т. п.
Обновить данными из eStock |  Доступно, только если [коллекция eStock настроена в качестве источника данных](partselectiongui_d_datenauswahlbenutzer.md). Обновляет данные в управлении изделиями на измененные данные из eStock.
Проверить на наличие изменений в eStock |  Доступно, только если коллекция eStock настроена в качестве источника данных. Проверяет данные в eStock на наличие изменений. Чтобы обновить данные в управлении изделиями, подтвердите запрос ниже, нажав кнопку ++Да++.
Удалить локальные данные eStock |  Доступно, только если коллекция eStock настроена в качестве источника данных. Удаляются загруженные данные изделий из eStock и прерывается соединение с коллекцией eStock. Это может потребоваться, например, если коллекция eStock больше не существует в сети и нужно убрать локальные данные. Или, например, если вы создали отдельные каталоги для основных данных коллекции eStock и хотели бы их изменить. Эта невозможно сделать, пока вы подключены к коллекции eStock. При удалении локальных данных eStock файлы, связанные с элементами eStock (макросы, изображения и т. д.), не удаляются. Прерывание соединения с коллекцией eStock приведет к сбросу настроек для каталогов и источника базы данных. При этом в настройках для источника базы данных устанавливается подходящая схема (например, схема для другой коллекции eStock). Если подходящая схема не найдена, то эти настройки сбрасываются на стандартные настройки, указанные при установке ($(MD_PARTS)\EPLAN_parts.alk).
