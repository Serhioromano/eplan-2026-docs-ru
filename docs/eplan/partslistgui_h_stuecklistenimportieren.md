# Импортировать спецификации

Данные изделия спецификации можно импортировать в текущий проект. Обратите внимание на то, что экспорт и импорт можно осуществлять только в проекте!

Условие:

Вы открыли проект.

1. Выберите следующие команды: Вкладка **Устройства** > группа команд **Устройства** > **Спецификация**.
2. В диалоговом окне **Спецификация — <Имя проекта>** выберите пункт всплывающего меню **Импортировать**.
3. Установите в диалоговом окне **Импортировать спецификацию** дисковод и каталог, в котором находится импортируемый файл. (Чтобы вернуться к стандартно настроенному каталогу, щелкните на пиктограмму Eplan в левой части области навигации и выведенному под ней каталогу.)
4. Выберите из раскрывающегося списка типов файла одну из записей для формата импортируемого файла.
5. Выберите требуемый файл импорта из списка.
6. Щелкните по кнопке ++"Открыть"++.

![](images/arrow.png) Записи данных импортируются. В случае возникновения ошибок при импорте отображается соответствующее замечание, подробную информацию можно просмотреть в управлении сообщениями (вкладка **Инструменты** > группа команд **Проверка** > **Сообщения**).

Если данные экспортированы и затем обработаны, то при импорте записываются только определенные поля файла экспорта. Обзор полей приведен в разделе "[Спецификации: Поля в файле экспорта](partslistgui_k_felderexportdatei.md)".

!!! note "Замечание:"

    При импорте уже присвоенной ОУ ссылки изделия обозначение устройства должно уже быть доступным. Если этого не происходит, то создается ссылка изделия для изделия проекта.
