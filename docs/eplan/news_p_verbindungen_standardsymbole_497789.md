## Задать стандартные символы для точек определения соединения как специфические для проекта

Теперь в свойствах проекта можно предварительно задать для всего проекта символы для точек определения соединения, точек определения потенциала и точек определения сети. Для этого в настройках проекта для соединений доступно новое диалоговое окно Настройки: Стандартные символы. Командный путь к этому диалоговому окну: Файл > Настройки > Проекты > "Имя проекта" > Соединения > Стандартные символы.

Эффект:

Теперь вы можете задавать стандартные символы для точек определения соединения, точек определения потенциала и точек определения сети независимо от пользователя. Это обеспечивает единообразное и последовательное использование этих символов в рамках проекта.

[](../Pictures/Gui/Lang/connections_defaultsymbol_ls.png)

Стандартные символы, указанные в этом диалоговом окне, используются при ручном размещении точек определения соединения, точек определения потенциала и точек определения сети. Эти символы также используются в том случае, когда изменяются свойства соединения (например, в Навигаторе соединений) и в результате этого точка определения соединения размещается автоматически. Однако эта настройка не применяется к точкам определения соединения, размещаемым из нумерации соединений. Для таких точек определения соединения вы указываете символ в настройках нумерации соединений.

Диалоговое окно содержит такие вкладки:

  * Многополюсный: здесь вы указываете стандартные символы для точек определения соединения, размещаемых на многополюсных страницах.
  * Однополюсный: здесь вы указываете стандартные символы для точек определения соединения, размещаемых на однополюсных страницах.
  * Общие: здесь вы указываете стандартные символы для точек определения потенциала и точек определения сети. Указанные здесь символы размещаются независимо от вида представления.



Чтобы указать стандартные символы, доступно поле Номер / Имя на каждой вкладке; эти поля изначально пустые. Нажав на [...], вы откроете диалоговое окно Выбор символа и можете выбрать там нужный символ. При наличии нескольких вариантов символа можно выбрать другой вариант символа в поле Вариант с помощью раскрывающегося списка.

С помощью кнопки  (Удалить) можно удалить выбранный стандартный символ. Если стандартный символ не задан, то при размещении точки определения соединения, точки определения потенциала или точки определения сети вставляется последний использованный символ из диалоговой памяти.
