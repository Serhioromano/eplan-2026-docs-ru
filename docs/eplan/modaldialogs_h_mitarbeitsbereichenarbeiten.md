## Работать с рабочими областями

Рабочая область Eplan охватывает размеры и позиции главного окна Eplan, редакторов (графический редактор, редактор символов, редактор форм и т. д.), центра вставки и "присоединяемых" диалоговых окон (навигаторы, управление сообщениями и т. д.). Для присоединяемых диалоговых окон и центра вставки настройки позиции окна (например, присоединение, всплывающее окно и т. д.) также относятся к рабочей области. В рабочую область сохраняются также настройки ленты, например, с определенными пользователем вкладками и группами команд.

Это может быть полезным в том случае, если требуется настроить Eplan для выполнения разных задач по проектированию. Так, например, нажатием кнопки можно переключиться на обработку ПЛК и автоматически открыть все требуемые для этого диалоговые окна, причем позиции и настройки уже будут заданы. Все непредусмотренные в данном случае диалоговые окна автоматически закрываются.

Рабочие области можно в любой момент сохранить в виде схем, вновь выбрать их позже или даже удалить. Помимо этого, в диалоговом окне Рабочая область Eplan имеется несколько предварительно определенных рабочих областей, которые, например, можно использовать в качестве шаблонов для других рабочих областей. Так же, как и для схем, здесь с помощью [панели инструментов](eplan/schemeconfig_m_schemaschaltflaechen.md) можно создавать, копировать, удалять, импортировать и экспортировать схемы для рабочей области.

!!! note "Замечание:"

    

 

### [Определить рабочие области](javascript:void\(0\);)

Условие:

Интерфейс пользователя Eplan настроен для определенной задачи проектирования.

1. Нажмите справа вверху в ленте на кнопку  (рабочая область) и выберите в раскрывшемся списке команду Обработать раб. область.
2. В диалоговом окне Рабочая область щелкните  (Создать) на панели инструментов рядом с раскрывающимся списком Схема.
3. В диалоговом окне Новая схема в поле Имя введите имя схемы.
4. В поле Описание введите краткое описание для новой схемы.
5. Щелкните по кнопке [OK].  
  
Диалоговое окно Новая схема закрывается, а новая схема становится в диалоговом окне текущей.
6. Щелкните по кнопке [OK].  
  
Новая рабочая область создается под введенным именем. Текущие настройки интерфейса пользователя, относящиеся к открытым "присоединяемым" диалоговым окнам, позициям диалоговых окон и т. д., сохраняются.

Конфигурацию интерфейса пользователя этой рабочей области при необходимости можно изменить (например, изменить размер и позиция "присоединяемых" диалоговых окон и т. д. и сохранить заново (см. "Обработка рабочих областей").

### [Выбрать рабочие области](javascript:void\(0\);)

1. Нажмите справа вверху в ленте на кнопку  (рабочая область) и выберите в раскрывшемся списке имя нужной рабочей области.  
  
Текущая выбранная рабочая область обозначается в раскрывающемся списке стоящей впереди галочкой.  
  
Настройки выбранной рабочей области, относящиеся к открытым "присоединяемым" диалоговым окнам, позициям диалоговых окон и т. д. применяются, а интерфейс пользователя программы соответствующим образом обновляется.

### [Обработать рабочие области](javascript:void\(0\);)

Чтобы сохранить измененную конфигурацию интерфейса текущей выбранной рабочей области, нажмите в диалоговом окне Рабочая область на кнопку .

Кроме того, при обработке рабочей области существует возможность перезаписи выбранной рабочей области с помощью содержимого другой рабочей области. Это имеет значение, например, в том случае, если уже существующая схема должна послужить образцом для новой рабочей области.

1. Нажмите справа вверху в ленте на кнопку  (рабочая область) и выберите в раскрывшемся списке команду Обработать раб. область.
2. В диалоговом окне Рабочая область щелкните  (Обработать).
3. Выберите в диалоговом окне Обработать раб. область ту рабочую область, которая должна использоваться в качестве шаблона для текущей рабочей области.
4. Щелкните по кнопке [OK].
5. В диалоговом окне Рабочая область при необходимости откорректируйте описание для текущей рабочей области.
6. Щелкните по кнопке [OK].  
  
Измененные настройки сохраняются в текущей рабочей области.
