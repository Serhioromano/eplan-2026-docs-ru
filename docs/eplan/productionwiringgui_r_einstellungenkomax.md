# Вкладка "Настройки" (Komax — Zeta)

## Вызов диалогового окна:

* **Файл** > **Настройки** > **Компания** > **Сборка проводов** > **Komax — Zeta** > вкладка **Настройки**
* **Файл** > **Экспортировать** > группа команд **Данные изготовления** > **Сборка проводов** > **Komax - Zeta**. Нажмите рядом с полем **Схема** на кнопку ++"..."++. Выберите вкладку **Настройки**.

В этой вкладке хранится информация о технических возможностях используемой машины. Отдельные настройки задаются заранее индивидуально для машины при помощи подходящих значений, которые можно здесь изменить.

!!! note "Замечание:"

    Если вы не вводите единицы измерения, для указания длины принимается значение "мм", а поперечного сечения — "мм²". Если вы хотите указать длину соединения в дюймах или поперечное сечение соединения в AWG, укажите соответствующую единицу измерения непосредственно. Преобразование из дюймов в мм, необходимое для машины, выполняется при экспорте, но AWG не преобразуется.

Обзор основных элементов диалогового окна:

### Мин. длина соединения:

Минимальная длина, необходимая для заданной обработки провода машиной (стандартное значение: 240 мм). Более короткие провода передаются в машину с данной минимальной длиной.

### Макс. длина соединения:

Провода, длина которых превышает указанную здесь величину, машина изготовить не может (стандартное значение: 3000 мм).

### Мин. поперечное сечение соединения:

Минимальное поперечное сечение провода, которое машина может обрабатывать.

### Макс. поперечное сечение соединения:

Максимальное поперечное сечение провода, которое машина может обработать (стандартное значение: 6 мм²).
