## Резервировать проекты

Проекты можно резервировать из вида Backstage и из управления проектами.

### [Резервирование проектов из вида Backstage](javascript:void\(0\);)

Условие:

Вы выделили проект в Навигаторе страниц.

  1. Выберите следующие команды: Файл > Резервировать.
  2. В диалоговом окне [Резервировать проекты](bakbackupdlggui_d_projektesichern.htm) задайте настройки резервирования данных.
  3. Щелкните по кнопке [OK].  
  
Проект будет резервирован в соответствии с настройками в заданном каталоге.



!!! note "Замечание:"

    Eplan запоминает настройки для соответствующего проекта и снова предлагает их при повторном процессе резервирования.


 

### [Резервирование проектов из Управления проектами](javascript:void\(0\);)

Условия:

  * Вы настроили управление проектами.
  * В представлении структуры дерева управления проектами находится считанный каталог, как минимум, с одним проектом.


  1. Выберите следующие команды: Файл > Управление проектами.
  2. Выделите в представлении структуры дерева диалогового окна Управление проектами требуемые проекты.
  3. Выберите пункт всплывающего меню Резервировать.
  4. В диалоговом окне [Резервировать проекты](bakbackupdlggui_d_projektesichern.htm) задайте настройки резервирования данных.
  5. Подтвердите ввод.  
  
Проекты будут последовательно сжаты и сохранены в заданном каталоге.
