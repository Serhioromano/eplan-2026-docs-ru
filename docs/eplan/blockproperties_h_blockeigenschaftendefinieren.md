# Определение индексированных свойств блока

Индексированные свойства блока можно заранее определить как в функции, так и в символах или в проекте. Далее описывается определение свойств блока в функции; предварительное определение свойств блока в символе или проекте выполняется аналогичным образом. Для проектов разница состоит лишь в том, что для разных категорий функций существует одно (индексированное) свойство формата **Свойство блока: Формат (<Категория функции>) [n]**.

Условия:

* Вы открыли проект.
* Вы открыли диалоговое окно свойств для функции (например, дважды щелкнув условное обозначение в графическом редакторе).

1. Выберите в диалоговом окне **Свойства** ++"..."++ вкладку **<Категория функции>**.
2. Щелкните на панели инструментов над полем **Свойства** по ![](images/all_new_as.png) (Создать).
3. Выберите в диалоговом окне **Выбор свойств** свойство формата и нажмите на кнопку ++"OK"++.

!!! tip "Совет:"

    Одновременно можно выбрать и соответствующее свойство блока для просмотра в графическом редакторе. Выделите одновременно несколько свойств, удерживая нажатой клавишу ++"Ctrl"++ и нажав на свойства.

4. Выберите на вкладке **<Категория функции>** диалогового окна "Свойства" свойство **Свойство блока: Формат [n]** и нажмите в столбце **Значение** на кнопку ++"..."++.
5. Выберите в диалоговом окне **Формат** в списке **Доступные элементы формата** группу свойств и нажмите на символ ![](images/all_expand_hierarchy_as.png), чтобы открыть группы свойств более низкого уровня.

![](images/arrow.png) Если вы из объекта хотите выбрать косвенные свойства других объектов, то кнопка ![](images/all_stairup_as.png) (Следующая степень) активна.
6. Если вы хотите выбрать косвенные свойства, нажмите ![](images/all_stairup_as.png) (Следующая степень).

![](images/arrow.png) В поле **Доступные элементы формата** снова отобразится первоначальное группирование свойств — теперь это (косвенные) свойства дополнительного объекта!
7. Выделите нужную группу форматов и нажмите на ![](images/all_arrowright_as.png) (Переместить направо).

![](images/arrow.png) Кнопка ![](images/all_arrowright_as.png) (Переместить направо) активна, только если можно выбрать и группу форматов.
8. Выберите в диалоговом окне **Формат: Свойство блока** определенное свойство и задайте для него форматирование.
9. Нажмите на кнопку ++"ОК"++.

![](images/arrow.png) В диалоговом окне **Формат** в поле **Выбранные элементы формата** в табличной форме выводятся выбранные элементы формата с их обозначением, символическим представлением (для предварительного просмотра) и заданным значением. Последовательность, в которой свойства находятся в списке, определяет их последовательности отображения при выводе свойств блока.

![](images/arrow.png) Если вы выбрали косвенные свойства, будет активна кнопка ![](images/all_stairdown_as.png) (Предыдущая ступень). При помощи этой кнопки можно снова перейти назад до выходного объекта.
10. Для определения других элементов формата повторите шаги 5 - 7.
11. При необходимости при помощи клавиш управления курсором на панели инструментов измените последовательность элементов формата.
12. Щелкните по кнопке ++"OK"++.

![](images/arrow.png) Таким образом, свойство блока определено. В диалоговом окне "Свойства" для соответствующего свойства формата заполняется поле **Значение** с предварительным просмотром установленного формата.

!!! tip "Совет:"

    при помощи функций Копировать и Вставить установленный формат можно перенести и на другие свойства формата.
