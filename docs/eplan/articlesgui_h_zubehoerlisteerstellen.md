## Создать список принадлежностей и присвоить его главному изделию

Чтобы обеспечить простое управление частями принадлежностей, в базе данных изделий имеются так называемые "Списки принадлежностей". Они позволяют выбрать изделие из списка возможных альтернативных вариантов. При этом списки принадлежностей в базе данных изделий представляют собой отдельный тип записи данных и отображаются в представлении в виде дерева под своим именем под отдельным уровнем иерархии "Список принадлежностей".

После создания списков принадлежностей их можно присвоить главному изделию какого-либо типа изделий в базе данных изделий.

Условие:

Вы открыли диалоговое окно База данных изделий (вкладка Основные данные > группа команд Изделия > Управление).

### [Создание списка принадлежностей](javascript:void\(0\);)

1. В дереве выделите уровень иерархии Список принадлежностей.
2. Выберите пункт всплывающего меню Создать.  
  
Eplan автоматически генерирует новый список принадлежностей с именем Создать(<порядковый_номер>). Если выделен существующий список принадлежностей, используется имя этого списка принадлежностей, которое расширено порядковым номером.
3. Перейдите справа в диалоговом окне на вкладку Свойства.
4. Измените автоматически назначенную запись для свойства Имя (список принадлежностей) на уровне иерархии Данные.   
  
Eplan автоматически заполняет свойства Дата создания и Дата изменения (на уровне иерархии Ревизия) соответствующими данными, которые не могут быть изменены.
5. Переместите вкладку Изделие на передний план.
6. Щелкните по  (Создать), чтобы создать строку в списке принадлежностей.
7. Нажмите в столбце Номер изделия на кнопку [...].  
  
Откроется диалоговое окно Выбор изделия. Здесь отображаются только определенные ранее части принадлежностей.
8. Выделите нужный предмет оборудования в дереве и щелкните по кнопке [ОК].
9. Повторите выбор, если необходимо добавить другой предмет оборудования.
10. Закройте базу данных изделий и сохраните измененные данные.
11. Нажмите [Да] в следующем диалоговом окне, чтобы выполнить синхронизацию данных изделий.

### [Присвоить список принадлежностей главному изделию](javascript:void\(0\);)

1. Выделите в дереве или списке нужное главное изделие.
2. Перейдите справа в диалоговом окне на вкладку Принадлежности.
3. Щелкните по  (Создать), чтобы создать строку в списке предметов оборудования.
4. Нажмите в столбце Номер изделия / имя на кнопку [...].
5. Выделите в диалоговом окне Выбор изделия в структуре дерева уровня иерархии Список принадлежностей вновь созданный список принадлежностей.
6. Щелкните по кнопке [OK].
7. Закройте базу данных изделий и сохраните измененные данные.
8. Нажмите [Да] в следующем диалоговом окне, чтобы выполнить синхронизацию данных изделий.
