## Диалоговое окно "Конфигурировать свойства" (определенные пользователем свойства)

* Вы открыли проект. Вкладка Инструменты > группа команд Управление > Свойства.
* Вкладка Основные данные > группа команд Изделия > Управление. Вы открыли базу данных изделий (кнопка [Дополнительно] > Настройки). Кнопка [Дополнительно] > Конфигурировать свойства.

Создайте в этом диалоговом окне определенные пользователем свойства для проекта или изделия. Специфические для проекта свойства сохраняются в проекте и могут использоваться на различных объектах в проекте. Определенные пользователем свойства изделия сохраняются в каждой базе данных изделий и могут использоваться на изделиях. Эти определенные пользователем свойства можно присвоить изделию в базе данных изделий, используя вкладку Определенные пользователем свойства.

Обзор основных элементов диалогового окна:

В левой части диалогового окна определенные пользователем свойства в текущем проекте / в текущей базе данных изделий отображаются в представлении в виде дерева и представлении в виде списка.

!!! note "Замечание:"

    После присвоения определенных пользователем свойств одному или нескольким изделиям и выполнения синхронизации данных изделий свойства изделий также отображаются вконфигурациипроекта. Такие определенные пользователем свойства можно распознать по невозможности их обработки в проекте и по записи "Изделие" в полеПрисвоение.

Отображать только "Больше не использовать":

Если этот флажок установлен, в представлении в виде дерева и представлении в виде списка отображаются только свойства, обозначенные как более не используемые. Для этих свойств установлен флажок Больше не использовать.

Кнопка |  Значение  
---|---  
(Создать) |  Открывает диалоговое окно Новое свойство, в котором можно создать свойство.  
(Импортировать) |  Позволяет импортировать определенные пользователем свойства из файла формата XML.  
(Экспортировать) |  Дает возможность экспортировать выделенные определенные пользователем свойства в файл формата XML. Свойства, обозначенные как более не используемые, не экспортируются.  

Нажмите над полем на кнопку  (Создать), чтобы создать свойство. Затем в диалоговом окне Новое свойство введите однозначное идентифицирующее имя свойства. Рекомендуем начинать имя с идентификатора вашей фирмы. Идентифицирующее имя может содержать прописные и строчные буквы, цифры и специальные символы "., -, _, &". В имени должна быть как минимум одна точка, однако она не должна стоять в начале или конце имени. Нельзя использовать строку символов "Eplan" в начале имени. Точки в имени расцениваются как подструктура и генерируют подслой в дереве.

!!! note "Замечание:"

Пoиск:

Введите в это поле текст, по которому должна выполняться фильтрация свойств. При этом поиск свойств выполняется как по идентифицирующему, так и по отображаемому имени.

Если необходимо вернуться к прежнему виду свойств, удалите текст из поля ввода. Для этого нажмите кнопку  (Удалить).

Всплывающее меню:

Дополнительно здесь представлены следующие пункты всплывающего меню, специфические для данного диалогового окна:

Пункт меню |  Значение  
---|---  
Вставить в список результатов поиска |  Это возможно только при конфигурации проекта. Проверяет использование выделенных свойств в проекте и вносит найденные объекты в список результатов поиска. Благодаря этому с помощью пункта всплывающего меню Перейти к (графика) можно найти используемые свойства объектов, например условные обозначения, размещения изделий и т. д., в графике.

Вкладка Общее

Идентифицирующее имя:

Здесь отображается однозначное имя, установленное при создании свойства. Свойством под этим именем можно управлять в Eplan.

Отображаемое имя:

Здесь вводится имя, под которым будет отображаться свойство. Возможен многоязычный ввод.

!!! example "Пример:"

    Вы создаете свойство с идентифицирующим именемИдентификаторфирмы.МоиСвойства.Свойство1и отображаемым именемСвойство 1. В структуре дерева в качестве верхнего узла отображаетсяИдентификатор фирмы. Под ним находится узелМоиСвойства, а под ним — узелСвойство1. В проекте это свойство отображается под именемСвойство 1.

Описание

Здесь вы можете ввести описание, которое будет отображаться для свойства в диалоговых окнах выбора. Возможен многоязычный ввод.

Присвоение:

Через раскрывающийся список можно задать, для каких объектов должно быть доступно это свойство. Присвоение можно задать только при создании свойства, позднее изменить его уже невозможно.

* Точка разрыва: Свойство доступно в точках разрыва.
* Ссылка изделия: Свойство доступно для ссылок изделий и таким образом отображается в диалоговом окне свойств главных функций во вкладке Изделие. Дополнительно автоматически на всех объектах, которые могут нести изделие, генерируется соответствующее индексированное свойство.
* Функция: Свойство доступно на любых функциях во всех разделах.
* Проект: Свойство доступно в свойствах проекта.
* Страница: Свойство доступно на страницах.
* Соединение: Свойство доступно на соединениях, в точках определения соединения, точках определения потенциала и точках определения сети.
* Предварительное планирование: Свойство можно использовать на сегментах в предварительном планировании, а также при создании определений сегмента.
* Изделие: свойство доступно на изделиях. Это присвоение возможно только при конфигурации в базе данных изделий.

Также активировать для ссылок изделий:

Установите этот флажок, если свойство должно быть доступно также как свойство ссылки изделия. Это возможно только при конфигурации в базе данных изделий.

Тип поля:

С помощью раскрывающегося списка задайте символы и формат, допустимые для определенных пользователем свойств. Например, возможны следующие типы полей: "Bool" (истинно / ложно), "Десятичное число", "Дата", "Многоязычный текст". Настройку можно задать только при создании свойства, позднее изменить ее уже невозможно.

!!! note "Замечание:"

    Если для определенного пользователем свойства необходимо ввести значения с единицами измерения, выберите тип поля "Значение с единицей измерения". Этот тип поля имеет свойство "одноязычного текста", за исключением изложенных ниже ситуаций.

Группа единиц измерения:

Эта настройка доступна только для типа поля "Значение с единицей измерения". Выберите из раскрывающегося списка требуемую группу единиц измерения. Это свойство еще можно изменить позднее.

Если для свойства типа "Значение с единицей измерения" определена группа единиц измерения и для этого свойства указывается значение без единицы измерения, то для такого значения, например, при пересчете, используется соответствующая стандартная единица СИ.

Если в конфигурации определена группа единиц измерения, то с помощью контрольных прогонов можно проверять наличие определенных пользователем свойств, у которых в значении свойства отсутствует единица измерения (022063, 502040) или указана неверная единица измерения (022064, 502041).

Перевести значение свойства:

Эта настройка доступна только для типа поля "Многоязычный текст". Установите этот флажок, если значение определенного пользователем свойства следует учитывать при автоматическом переводе проекта или автоматическом переводе в базе данных изделий.

Больше не использовать:

Если этот флажок установлен, свойство больше не отображается в проекте / на вкладке Определенные пользователем свойства базы данных изделий. С помощью пунктов меню [Дополнительно] > Убрать больше не используемые свойства эти свойства можно удалить.

!!! note "Замечание:"

    В проекте определенные пользователем свойства, которые используются в изделиях или других основных данных, невозможно удалить, пока в столбцеКоличество использованийне отобразится значение "0", даже если параметр "Больше не использовать" включен. Для этого сначала необходимо отменить использование (убрать выбранные изделия,формыи т. д.) и удалить неиспользуемые изделия, формы и т. д. путем сжатия проекта. Только после этого соответствующие свойства можно удалить с помощью пункта менюУбрать больше не используемые свойстваили повторного сжатия.

Вкладка Представления

На этой вкладке задается представление определенного пользователем свойства.

Отображаемый тип:

Выберите из раскрывающегося списка, какой вид ввода возможен для данного свойства. Записи в этом списке зависят от выбранного типа поля. Например, для типа поля "Bool" можно указать, должны ли значения отображаться как "Да / Нет", "Вкл. / Выкл." и т. д.

Для типов полей "Одноязычный текст", "Многоязычный текст" и "Значение с единицей измерения" возможны следующие отображаемые типы:

* Свободный ввод: Можно вручную вводить любые значения, например текст, числа или числа с единицами измерения.
* Список выбора: Значения можно выбирать только из раскрывающегося списка. Возможные записи задаются в раскрывающемся списке в поле Список выбора значений по умолчанию.
* Свободный ввод со списком вариантов выбора: любые значения можно ввести вручную или выбрать из раскрывающегося списка. Возможные записи задаются в раскрывающемся списке в поле Список выбора значений по умолчанию.
* Саморасширяющийся список выбора: Значения можно выбрать из раскрывающегося списка или ввести вручную. Возможные записи задаются в раскрывающемся списке в поле Список выбора значений по умолчанию. Введенные вручную значения расширяют значения по умолчанию в раскрывающемся списке.
* Свойство блока: Эта запись доступна только для типов полей "Одноязычный текст" и "Значение с единицей измерения". В поле Формат блока задается формат связанного блока.

Категория:

Для просмотра в программе свойства подразделены на различные категории, т.е. на группы свойств, которые могут отображаться независимо друг от друга. Из раскрывающегося списка выберите категорию, которой вы хотите присвоить свойство.

Защищена от записи в интерфейсе пользователя:

Если этот флажок активирован, значение соответствующего определенного пользователем свойства только отображается в интерфейсе пользователя и не может быть изменено в нем. Тем не менее остается возможность вносить изменения через Eplan API, через импорт (например после внешней обработки) или через автоматизированные интерфейсы (например ERP/PDM, EEC).

Формат блока:

Если в поле Отображаемый тип вы выбрали запись "Свойство блока", откройте диалоговое окно Формат, используя кнопку [...]. В нем вы указываете свойства, которые должны быть объединены в свойстве блока.

После того как вы установите формат для свойства блока, здесь будет доступна опция предварительного просмотра формата. При этом выбранные элементы формата отображаются со своим символическим представлением. В этом поле можно отредактировать непосредственно сам формат. Введенный здесь формат можно удалить, отредактировать вручную или скопировать и перенести в поле Формат блока другого определяемого пользователем свойства отображаемого типа "Свойство блока".

Перезаписываемый формат блока на объекте:

Эта настройка доступна только для типа отображения поля "Свойство блока". Если этот флажок установлен, то в дополнение к определенному пользователем свойству блока генерируется еще одно свойство блока с тем же идентифицирующим именем. Это второе свойство отличается от фактического определенного пользователем свойства блока дополнением "(локальный формат)" в отображаемом имени и возможностью редактирования. Это свойство блока предназначено для определения локального формата блока и может также выбираться для объекта, которому назначено определенное пользователем свойство (например, функция).

Локальный формат блока можно использовать для следующих объектов: Точки разрыва, функции, страницы, соединения и сегменты предварительного планирования.

Чтобы указать локальный формат блока для объекта, выберите свойство блока для локального формата в таблице свойств. С помощью кнопки […] в столбце Значение можно перейти в диалоговое окно Формат и определить там локальный формат. Затем указанное здесь значение будет также отображаться для соответствующего определенного пользователем свойства блока с тем же идентифицирующим именем.

Список выбора значений по умолчанию:

Если в поле Отображаемый тип выбран один из параметров "Список выбора", "Свободный ввод со списком вариантов выбора" или "Саморасширяющийся список выбора", определите здесь возможные записи в раскрывающемся списке.

Нажмите на кнопку  (Создать) для создания новой строки в списке, после чего введите нужное значение. Возможен многоязычный ввод.  
С помощью кнопки  (Удалить) можно удалить ненужное значение.

С помощью кнопок со стрелками над полем можно установить порядок возможных записей в раскрывающемся списке.
