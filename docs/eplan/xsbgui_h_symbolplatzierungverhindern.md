# Предотвратить новое размещение символа

Если вы хотите обработать символ, вы можете помешать его использованию. При этом символ не сможет вставить заново в проект или обработать другой пользователь во время обработки. Уже введенные в проект символы могут тем не менее использоваться далее.
После обработки символа его можно снова разблокировать. Только разблокированный символ может быть обработан или введен другим пользователем.

Условие:

Вы открыли проект. Открыто диалоговое окно навигатора **Страницы — <Имя проекта>**.

1. Выберите следующие команды: Вкладка **Основные данные** > группа команд **Символы** > раскрывающаяся кнопка **Символ** > **Открыть**.
2. Если вы еще не открыли ни одной библиотеки символов, выберите в диалоговом окне **Открыть библиотеку символов** сначала библиотеку символов, в которой находится символ, который вы хотите обработать.
3. В диалоговом окне **Выбор символа** выберите символ, который вы хотите обработать, и щелкните по кнопке ++"ОК"++.

![](images/arrow.png) Обрабатываемый символ откроется в редакторе символов.
4. Выделите в диалоговом окне **Страницы — <Имя проекта>** открытый символ и выберите пункт всплывающего меню **Свойства**.
5. В диалоговом окне **Свойства символа — <Имя библиотеки>** в таблице свойств установите флажок **Предотвратить новое размещение**. Если этот флажок у вас не отображается, добавьте этого свойство в таблицу через диалоговое окно **Выбор свойств**.
6. После того как вы закроете символ и подтвердите последующее диалоговое окно **Синхронизация основных данных**, нажатием на кнопку ++"Да"++, выбранный символ будет заблокирован для размещения.

![](images/arrow.png) Заблокированный символ недоступен для выбора ни в диалоговом окне **Центр вставки** для размещения, ни в диалоговом окне **Выбор символа** для замены символа.

![](images/arrow.png) Заблокированный символ может обрабатываться в редакторе символов. После завершения обработки снова снимите в диалоговом окне **Свойства символа — <Имя библиотеки>** флажок **Предотвратить новое размещение**.
