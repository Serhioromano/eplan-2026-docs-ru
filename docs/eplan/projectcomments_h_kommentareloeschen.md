# Удалить комментарии

Вы можете удалить комментарии, импортированные или созданные в Eplan. Можно удалить либо выделенные комментарии, либо все комментарии из всего проекта.

Условия:

* Вы открыли проект. Этот проект содержит комментарии.
* В Графическом редакторе открыта страница проекта.
* Открыт навигатор комментариев.

1. Выделите один или несколько комментариев на странице проекта или в навигаторе комментариев, или выделите проект в навигаторе комментариев.
2. Выберите пункт всплывающего меню Удалить и подтвердите появившееся диалоговое окно нажатием кнопки Да.

!!! info "Для сведения:"

    Все выделенные комментарии удаляются со страницы проекта и из навигатора комментариев или — если вы выделили проект — из всего проекта.

!!! tip "Совет:"

    Вы также можете удалить все комментарии из всего проекта, сжав его. Для этого выберите команды Файл > Дополнительно > группа команд Организовать > Проект > Сжать проект и установите флажок Комментарии в диалоговом окне Настройки: Сжатие.
