# Вкладка Шаблоны сегментов

## Вызов диалогового окна:

Вы открыли проект.

* В навигаторе шаблонов сегментов был сгенерирован шаблон. Выберите в диалоговом окне **Свойства** ++"..."++ вкладку **Шаблон сегмента**.
* В навигаторе шаблонов сегментов выделен шаблон. Пункт всплывающего меню **Свойства**. Выберите вкладку **Шаблон сегмента**.

На этой вкладке установите идентифицирующее имя и описание шаблона сегмента.

Обзор основных элементов диалогового окна:

### Идентифицирующее имя:

Введите однозначное имя для шаблона сегмента. Под этим именем можно управлять шаблоном сегмента в Eplan.

### Описание:

Здесь вводится имя, под которым будет отображаться шаблон сегмента в проекте. Возможен многоязычный ввод.

### Нижестоящие шаблоны сегментов:

В этой таблице можно указывать шаблоны сегментов, которые подчинены текущему шаблону сегмента. Для этого необходимо с помощью кнопки ![](images/all_new_as.png){ .ui-icon } (Создать) перейти в диалоговое окно **Выбрать шаблон сегмента**. В левой части этого диалогового окна отображаются имеющиеся подходящие шаблоны сегментов. Вы можете использовать поле **Поиск**, чтобы ограничить количество отображаемых здесь шаблонов сегментов. При этом поиск выполняется как по названиям отображаемых шаблонов, так и по их описанию. Выберите нужные шаблоны сегментов. Возможен многократный выбор. С помощью кнопки ![](images/all_arrowright_as.png){ .ui-icon } (Переместить направо) перенесите выбранные шаблоны сегментов в поле **Нижестоящие шаблоны сегментов**.

Перечень шаблонов сегментов, доступных вам в диалоговом окне **Выбрать шаблон сегмента**, зависит от конфигурации определений сегментов. Для шаблонов измерительных контуров, например, по умолчанию на выбор предлагаются шаблоны для функций измерения.

Последовательность нижестоящего шаблона сегмента определяет последовательность нижестоящих сегментов, которые возникают при создании нового сегмента по текущему шаблону сегмента. Вы можете изменить последовательность с помощью кнопок со стрелками на панели инструментов.

### Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](userinterface_m_kontextmenu.md).
