## Вкладка Символы (Изменение стандарта)

Вы открыли проект. При нескольких открытых проектах: В навигаторе страниц выделен проект. Вкладка Инструменты > группа команд Стандарты > Заменить. Вы задали на вкладке Проект все настройки. Кнопка [Далее]. Вы определили на вкладке Поворот / инверсия все настройки. Кнопка [Далее]. Вы отметили опцию на вкладке Основные данные в строке библиотеки символов в столбце Присвоить отдельно. Кнопка [Далее].

На этой вкладке можно выбирать схемы присвоения символов исходной библиотеки символов символам целевой библиотеки символов.

Обзор основных элементов диалогового окна:

Присвоить символы:

Строка содержит присвоение символов исходной библиотеки символов символам целевой библиотеки символов. Отображаются пары присвоения библиотек символов, для которых на вкладке Основные данные установлен флажок Присвоить отдельно.

* Библиотека символов, источник: отображает имя файла библиотеки символов исходного проекта без расширения имени файла.
* Библиотека символов, цель: отображает имя файла библиотеки символов целевого проекта без расширения имени файла.
* Схема: в этом столбце можно выбрать схему. В этой схеме сохранено, какие символы присвоены друг другу. С помощью кнопки [Схема] можно создавать и обрабатывать схему.
* Статус: если в столбце Схема выбрана какая-либо схема, проверяется присвоение символов. В данном столбце отображается статус проверки. Статус "OK", когда определения функций символов соответствуют друг другу, а число выводов устройств исходных символов меньше или равно числу выводов устройства целевых символов.
