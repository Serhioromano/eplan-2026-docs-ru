## Вкладка Проект (Изменение стандарта)

[Вызов диалогового окна:](javascript:void\(0\);)

Вы открыли проект. При нескольких открытых проектах: В навигаторе страниц выделен проект. Вкладка Инструменты > группа команд Стандарты > Заменить.

На вкладке настраивается целевой проект. Для адаптации проекта к другому стандарту создается целевой проект.

Обзор основных элементов диалогового окна:

Имя исходного проекта:

В этом поле указан проект для адаптации к другому стандарту. Этот исходный проект при изменении стандарта не изменяется.

Имя целевого проекта:

Укажите в этом поле имя для целевого проекта без расширения имени файла.

Место хранения:

В этом поле расположен каталог для сохранения нового проекта. Eplan предлагает в качестве места хранения тот каталог, который настроен в диалоговом окне Настройки: Каталоги в поле Проекты (Файл > Настройки > Пользователь > Управление > Каталоги).

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.htm), из которого можно будет скопировать одну из доступных переменных пути.

Скопировать свойства проекта из исходного проекта:

Если этот флажок установлен, свойства копируются из свойств исходного проекта; если флажок снят, свойства применяются из шаблона. Определенные пользователем свойства всегда копируются из исходного проекта.
