## Размещение монтажной платы (2D)

При размещении монтажных плат на странице типа "Компоновка электрошкафа" различают размещение в качестве устройства с помощью центра вставки и "свободное" размещение с помощью диалогового окна "Свойства".

### Разместить монтажные платы как устройства с помощью центра вставки

Условия:

* Вы открыли проект.
* Вы находитесь в графическом редакторе на странице типа "компоновка электрошкафа".

1. Выберите следующие команды: Центр вставки > строка навигации Главная > Устройства.
2. Перейдите через папки Механика > Отдельная часть > Корпус > Монтажные платы к нужному производителю монтажных плат.
3. Выделите требуемую монтажную плату в плитке предварительного просмотра.
4. Переместите курсор на страницу проекта и кратко щелкните левой кнопкой мыши по позиции, на которой вы хотите разместить монтажную плату.  
  
Откроется диалоговое окно "Свойства".
5. Введите на вкладке Монтажная плата обозначение устройства в поле Видимое ОУ.
6. При необходимости присвойте монтажной плате другие свойства.
7. Щелкните по кнопке ++OK++.

### Размещение произвольных монтажных плат

Условия:

* Вы открыли проект.
* Вы находитесь в графическом редакторе на странице типа "компоновка электрошкафа".

1. Выберите следующие команды: Вкладка Вставить > группа команд Компоновка электрошкафа 2D > Монтажная плата (2D).  
  
Символ рамки, представляющий монтажную плату, прикреплен к курсору.
2. С помощью мыши растяните на требуемой позиции прямоугольник, представляющий монтажную плату.  
  
Откроется диалоговое окно Свойства <...>: Монтажная плата.
3. Кратко щелкните левой кнопкой мыши.
4. Введите на вкладке Монтажная плата обозначение устройства в поле Видимое ОУ.
5. При необходимости присвойте монтажной плате другие свойства.
6. Щелкните по кнопке ++OK++.  
  
Идет создание монтажной платы.
