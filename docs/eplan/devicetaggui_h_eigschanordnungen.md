## Использовать определенный пользователем порядок свойств

Порядок свойств присваивает функции порядок размещенных текстов свойств и их настройки отображения. Настройки для образа контакта также сохраняются в порядке свойств.

Определенный пользователем порядок свойств сохраняется как специфический для проекта и присваивается варианту символа, для которого он был создан. Поэтому такой порядок свойств доступен только для функций с одинаковым вариантом символа. Для 3D-размещения изделия в пространстве листа порядки свойств присваиваются определению функции и, соответственно, доступны для 3D-размещения изделия с одинаковым определением функции.

Определенные пользователем порядки свойств можно создавать на условных обозначениях или непосредственно на 3D-размещении изделия либо при конфигурации в диалоговом окне конфигурации.

С помощью диалогового окна конфигурации [Конфигурировать порядки свойств](eplan/eservicesgui_d_konfigeigenschaftsanordnungen.md) выводится обзор всех порядков свойств, имеющихся в проекте. Это диалоговое окно позволяет экспортировать порядки свойств нескольких выбранных 3D-размещений изделий или условных обозначений и импортировать их в другой проект. Кроме того, можно проверять использование определенных пользователем порядков свойств и удалять неиспользованные порядки свойств.

### [Создать порядки свойств на условных обозначениях](javascript:void\(0\);)

Условие:

Вы открыли проект.

1. Выделите условное обозначение в графическом редакторе или функцию в навигаторе данных проекта. Или выделите 3D-размещение изделия в пространстве листа.
2. Выберите пункт всплывающего меню Свойства.
3. Выберите в диалоговом окне Свойства <...> вкладку Отображение.
4. Выберите из списка Порядок свойств запись "Опред. пользователем" и обработайте порядок свойств.
5. Используйте кнопки  (Создать) и  (Удалить) для выбора дополнительных свойств или удаления выделенных свойств из списка.
6. Используйте кнопки  (Вырезать) или  (Копировать), чтобы вырезать или скопировать выделенные в списке свойства с их заданными свойствами отображения. В другом условном обозначении эти свойства вставляются с помощью кнопки  (Вставить) под выделенным свойством в списке другого порядка свойств. Свойства, которые невозможно использовать на условном обозначении, не учитываются при вставке. (После этой операции порядок свойств на целевом условном обозначении устанавливается на "Определено пользователем".) 
7. В списке свойств выделите свойство, настройки отображения которого вы желаете определить. При этом заданное значение в отдельных полях копируется из графы "Стандартное значение по умолчанию".
8. Обработайте свойства отображения в таблице [Свойство / Присвоение](eplan/devicetaggui_r_anzeigeeigenschaften.md).
9. Щелкните по кнопке  (Сохранить).
10. В диалоговом окне [Сохранить порядок свойств](eplan/devicetaggui_d_eigschanordnungspeichern.md) введите имя для порядка свойств или выберите имеющееся имя из раскрывающегося списка.
11. Установите флажок Использовать как стандарт, чтобы задать порядок свойств в качестве стандартного для всех дальнейших применений этого варианта символа (для функций) / этого определения функции (для 3D-размещений изделий).
12. Подтвердите ввод.  
  
Порядок свойств сохраняется и присваивается варианту символа. При 3D-размещении изделий порядок свойств присваивается определению функции.  
  
Если порядок свойств задан как стандартный, то он используется для соответствующего варианта символа по умолчанию, например при вставке символа. При 3D-размещении изделий порядок свойств используется по умолчанию для соответствующего определения функции.

!!! tip "Совет:"

    С помощью кнопок(Экспортировать) и(Импортировать) можно экспортировать сохраненный определенный пользователем порядок свойств варианта символа и импортировать его в другой проект.

 

### [Создать порядки свойств в диалоговом окне конфигурации](javascript:void\(0\);)

Условие:

Вы открыли проект.

1. Выберите следующие команды: Вкладка Инструменты > группа команд Управление > Порядок свойств.
2. Выделите в дереве уровень иерархии или уже имеющийся порядок свойств. 
3. Нажмите в диалоговом окне Конфигурировать порядки свойств — <Имя проекта> кнопку  (Создать).  
  
Если выбрано 3D-размещение изделия, вариант символа либо порядок свойств 3D-размещения изделия или варианта символа, открывается диалоговое окно Новый порядок свойств.  
  
Если в дереве выбран более высокий уровень иерархии, выделенный контур используется как фильтр для диалогового окна Определения функций или Выбор символа, которое открывается далее. После выбора 3D-размещения изделия или символа также открывается диалоговое окно Новый порядок свойств.
4. В диалоговом окне Новый порядок свойств введите однозначное идентифицирующее имя.  
  
Идентифицирующее имя затем уже нельзя изменить.
5. В поле Отображаемое имя введите имя, под которым порядок свойств будет отображаться в проекте. Возможен многоязычный ввод.
6. Установите флажок Стандарт, если порядок свойств следует применять по умолчанию во всех других случаях использования 3D-размещения изделия / варианта символа.
7. Чтобы выбрать свойства, на соответствующей вкладке Трехмерные функции, Условное обозначение и т. д. нажмите кнопку  (Создать).
8. В таблице Свойство / присвоение задайте настройки отображения для выбранных свойств.
9. Щелкните по кнопке [OK].  
  
Порядок свойств сохраняется и присваивается варианту символа. При 3D-размещении изделий порядок свойств присваивается определению функции.  
  
Если порядок свойств задан как стандартный, то он используется для соответствующего варианта символа по умолчанию, например при вставке символа. При 3D-размещении изделий порядок свойств используется по умолчанию для соответствующего определения функции.

!!! tip "Совет:"

    С помощью пунктов всплывающего менюКопировать/ВырезатьиВставитьможно переносить порядки свойств с одного варианта символа или 3D-размещения изделия на другой вариант символа или 3D-размещения изделия. Свойства, которые невозможно использовать на условном обозначении или 3D-размещении изделия, не учитываются при вставке.Кроме того, можно вставить скопированные порядки свойств в вариант символа или 3D-размещение элемента. Для этого идентифицирующее имя копии нумеруется счетчиком по нарастающей, начиная с 1. Вы можете редактировать это идентифицирующее имя, пока не примените новые данные.Переносить порядки свойств между областями "Размещение изделия (3D)" и "Условное обозначение" невозможно.

 

### [Альтернативные возможности присвоения порядков свойств](javascript:void\(0\);)

Порядок свойств для условного обозначения или 3D-размещения изделия можно задать на вкладке Отображение в диалоговом окне "Свойства" с помощью раскрывающегося списка Порядок свойств. В качестве альтернативы имеются следующие возможности:

* При табличной форме обработки функций можно отобразить столбец Порядок свойств и выбрать нужный вариант из раскрывающегося списка. Список содержит любой порядок свойств, доступный для соответствующего варианта символа.
* При создании схем для внешней обработки можно выбрать порядок свойств в диалоговом окне Настройки: Внешняя обработка как элемент формата, тем самым учитывая соответствующие данные при экспорте и импорте.
* В диалоговом окне Свойства объектов-заполнителей можно использовать свойство Порядок свойств (Ид. 19307) и с помощью переменной присваивать определенный пользователем порядок свойств в качестве наборов значений. Для этого проект должен содержать соответствующий порядок свойств.
* Уже имеющийся порядок свойств также можно присваивать с помощью определенной пользователем кнопки на панели инструментов. Для этого в диалоговом окне Настроить выберите XEsSetPropertyAction и используйте в качестве значения параметра PropertyId Ид. 19307 свойства Порядок свойств.

### [Сбросить порядок свойств](javascript:void\(0\);)

Условия:

* В Графическом редакторе открыта страница проекта.
* Вы создали минимум один определенный пользователем порядок свойств.

1. Выделите в графическом редакторе или в навигаторе данных проекта одну или несколько функций, которые используют определенный пользователем порядок свойств. Или выделите 3D-размещение изделия в пространстве листа.
2. Выберите следующие команды: Вкладка Главная > группа команд Текст > раскрывающаяся кнопка Переместить > Сбросить порядок свойств.  
  
Порядок свойств для выделенных функций / 3D-размещений изделий сбрасывается до стандартной настройки. Этой настройкой может быть либо настройка "Станд. указание", либо порядок свойств, заданный как стандартный.

!!! tip "Совет:"

    Стандартные значения по умолчанию также можно восстановить непосредственно в диалоговом окне "Свойства". На вкладкеОтображениевыберите из раскрывающегося спискаПорядок свойствзапись "Стандартное значение по умолчанию"; при этом все настройки будут заменены стандартными значениями.
