# Дополнения для нижестоящих шаблонов сегментов

В навигаторе шаблонов сегментов отображаются определенные в проекте шаблоны сегментов, их можно обрабатывать. Для создания вложенных шаблонов сегментов — т. е. шаблонов сегментов с нижестоящими шаблонами сегментов — на вкладке **Шаблоны сегментов** диалогового окна "Свойства" шаблонов сегментов доступна таблица **Нижестоящие шаблоны сегментов**. Для нижестоящих шаблонов сегментов добавлены следующие возможности:

Для автоматизированной обработки проектов в данной версии реализованы следующие возможности:
\- Выбрать многократный выбор в диалоговом окне "Выбрать шаблоны сегментов"
\- Поле поиска при выборе нижестоящих шаблонов сегментов
\- Конфигурировать представление таблиц для нижестоящих шаблонов сегментов
\- Назначить нижестоящие шаблоны сегментов нескольким шаблонам сегментов одновременно

### Выбрать многократный выбор в диалоговом окне "Выбрать шаблоны сегментов"

Если нижестоящие шаблоны сегментов назначаются какому-либо шаблону сегмента на вкладке **Шаблоны сегментов**, то теперь в последующем диалоговом окне **Выбрать шаблон сегмента** возможен многократный выбор при выборе этих нижестоящих шаблонов сегментов.

### Поле поиска при выборе нижестоящих шаблонов сегментов

В левой части диалогового окна **Выбрать шаблон сегмента** отображаются имеющиеся подходящие шаблоны сегментов. Теперь для удобства просмотра обширных списков выбора (например, в автоматизации зданий) можно ограничить количество отображаемых здесь шаблонов сегментов с помощью недавно добавленного поля **Поиск**. При этом поиск выполняется как по названиям отображаемых шаблонов, так и по их описанию.

### Конфигурировать представление таблиц для нижестоящих шаблонов сегментов

Теперь в диалоговых окнах для шаблонов сегментов в таблицах для нижестоящих шаблонов сегментов имеется пункт всплывающего меню **Конфигурировать представление**. Это относится как к таблице в диалоговом окне "Свойства» шаблона сегмента на вкладке **Шаблоны сегментов**, так и к таблице в диалоговом окне **Выбрать шаблоны сегментов**. Это позволит вам добавлять в таблицы новые столбцы для соответствующих свойств и изменять последовательность столбцов любым образом. При этом можно выбрать разные конфигурации для обоих диалоговых окон.

### Назначить нижестоящие шаблоны сегментов нескольким шаблонам сегментов одновременно

В навигаторе шаблонов сегментов можно выбрать несколько шаблонов сегментов одновременно. Ранее, при открытии диалогового окна "Свойства" (например, для технологических контуров), при многократном выборе невозможно было вносить изменения в таблицу **Нижестоящие шаблоны сегментов**. Теперь, если вы выбрали шаблоны сегментов с одинаковыми нижестоящими шаблонами сегментов, то с помощью функции Групповая обработка можно, например, одновременно выбрать нижестоящие шаблоны сегментов для всех выбранных шаблонов сегментов или удалить выбранные нижестоящие шаблоны сегментов.
