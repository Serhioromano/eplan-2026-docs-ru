## Создать проект (Управление проектами)

Проекты можно создавать с помощью управления проектами или непосредственно. При этом проект создается на основе базового проекта. В качестве альтернативы базовым проектам (*.zw9) вы можете выбрать сохраненные проекты Eplan (*.zw1) в качестве шаблонов проектов при их создании. Если вы сами еще не создали базовый проект, можно использовать [Примерные шаблоны](eplan/projects_k_basisprojekteerweitert.md#Beispielvorlagen) Eplan. Ниже описывается, как создать проект с помощью управления проектами.

Условия:

* Вы имеете доступ к [Базовые проекты](eplan/projects_k_basisprojekteerweitert.md).
* Вы создали базу данных управления проектами.

1. Выберите следующие команды: Файл > Управление проектами > кнопка [Организовать] > Создать.
2. Введите имя проекта и место хранения в диалоговом окне [Создать проект](eplan/prjmanagementgui_d_projekterstellen.md).
3. Выберите нужный базовый проект или нужный сохраненный проект Eplan для проекта.
4. Щелкните по кнопке [OK].  
  
В целевом каталоге создается новый проект *.elk.  
  
Новый проект автоматически считывается в управление проектами.
5. Проверьте все записи в диалоговом окне Свойства проекта: <Имя проекта> и скорректируйте их при необходимости.
