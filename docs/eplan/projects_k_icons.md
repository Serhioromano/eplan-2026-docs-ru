## Расширения имен файлов и пиктограммы для проектов

В дереве Навигатор страниц и Управление проектами следующие пиктограммы и расширения имен файлов наглядно демонстрируют типе проекта:

Пиктограмма |  Тип файла |  Значение |  Расширение имени файлов  
---|---|---|---  
|  Проект Eplan |  Стандартный проект Eplan, который можно открыть и обработать. Если вы работаете в многопользовательском режиме, открытый таким образом проект могут обрабатывать сразу несколько пользователей. |  *.elk  
|  Эксклюзивно открытый проект Eplan |  Проект Eplan, который был открыт эксклюзивно. Проект можете обрабатывать только вы. Если вы работаете в многопользовательском режиме, другие пользователи не имеют доступа к открытому таким образом проекту. |  *.elk  
|  Проект Eplan с защитой от записи |  Проект Eplan, открытый с защитой от записи. Вы можете просматривать проект, но не можете его обрабатывать. Когда вы работаете в многопользовательском режиме, другие пользователи не могут обрабатывать данный проект. |  *.elk  
|  Запакованный проект Eplan |  Запакованный проект. Пиктограмма отображается только в Управление проектами. |  *.elp  
|  Выгруженный проект Eplan |  Для внешней обработки выгруженного проекта. Проект можно открыть в Eplan с защитой от записи, не вносить изменений и не удалять. Создается через: Файл > Резервировать методом "Выгрузить для внешней обработки". Из проекта *.elk в том же каталоге получается проект *.els. Дополнительно в выбранном каталоге резервирования генерируется файл резервирования *.zw1. |  *.els  
\--- |  Сохранение данных Eplan: Проект |  1) Файл резервирования выгруженного проекта Eplan или 2) Файл резервирования выгруженного проекта Eplan или 3) Файл резервирования дополнительно сохраненного проекта. Создается через: Файл > Резервировать методом "Дополнительно сохранить". Проект *.elk сохраняется в том же каталоге. Дополнительно в выбранном каталоге резервирования генерируется файл резервирования *.zw1. |  *.zw1  
|  Выгруженный запакованный проект Eplan |  Такой проект можно было создать в предыдущих версиях Eplan путем запаковки выгруженных проектов. Сначала проект нужно распаковать, прежде чем его можно будет открыть в режиме с защитой от записи. Пиктограмма отображается только в Управление проектами. |  *.elx  
|  Архивированный проект Eplan |  Проект открыть невозможно. Пиктограмма отображается только в Управление проектами.  
Создается через: Файл > Резервировать методом "Архивировать". Из проекта *.elk в том же каталоге получается проект *.ela. Дополнительно в выбранном каталоге резервирования генерируется файл резервирования *.zw1. |  *.ela  
|  Закрытый проект Eplan |  Закрытый проект. Проект можно открыть в Eplan с защитой от записи, не вносить изменений и не удалять. Создается через: Файл > Управление ревизиями > группа команд Проект > Закрыть > Закрыть проект / область. Из проекта *.elk получается проект *.elr. |  *.elr  
|  Исходный проект Eplan |  Исходный проект. Проект можно открыть в Eplan с защитой от записи, не вносить изменений и не удалять. Создается через: Файл > Управление ревизиями > группа команд Проект > Сравнение свойств > Сгенерировать исходный проект. Проект *.elk сохраняется. Дополнительно создается копия проекта в качестве закрытого проекта с расширением *.elr. |  REV*.elr  
|  Проект ревизии Eplan |  Проект с отслеживанием изменений. Проект можно открыть и обработать. Создается через: Файл > Управление ревизиями > группа команд Изменения > Отслеживание изменений > Генерировать ревизию. Из проекта *.elk получается проект *.ell. |  *.ell  


!!! note "Замечание:"

    Учтите, пожалуйста, что в диалоговом окнеОткрыть проектиспользуется другая пиктограмма. ЗдесьпроектыEplan обозначены с помощью символа приложения Eplan.
