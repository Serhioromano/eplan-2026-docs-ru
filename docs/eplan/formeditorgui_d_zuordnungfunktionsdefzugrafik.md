## Диалоговое окно Присвоение "определения функции к графике"

Вы открыли проект. Вкладка Основные данные > группа команд Рамки / формы > раскрывающаяся кнопка Форма > Открыть > кнопка [Открыть]. Вы выделили форму в навигаторе страниц и открыли с помощью пункта всплывающего меню Свойства диалоговое окно Свойства формы — <Имя формы>. Вы нажали для свойства Присвоение определения функции графике в поле Значение на кнопку [...].

В этом диалоговом окне укажите, для какого определения функции должна быть выведена определенная графика в области данных. Это свойство необходимо, чтобы в спецификации клеммника могла быть выведена (фиксированная) графика для клемм определенного типа клемм (конкретного определения функции).

Если после определения присвоения в данном диалоговом окне в форме разместить свойство Присвоение определения функции графике [n], то символ будет размещен в зависимости от определения выводимой функции.

Обзор основных элементов диалогового окна:

Категория / Группа / Описание:

Как только было выбрано определение функции, в этих полях выводятся соответствующие значения.

!!! example "Пример:"

    В качестве определения функции была выбрана 'проходная клемма, 4 цели, с мостовой перемычкой'; поля заполняются следующим образом:Категория:КлеммыГруппа:Клеммы (2 вывода устройства)Описание:Проходная клемма с четырьмя целями и с возможностью установки мостовых перемычек.

 

Определение функции:

Щелкните по [...], чтобы в этом поле открыть диалоговое окно Определение функции и выбрать определение функции. Многократный выбор здесь невозможен.

!!! note "Замечание:"

    Как вкладкаАтрибуты, так и вкладкаДанные соединениявыбранного определения функции здесьнеобрабатываются!

 

Библиотека символов:

При выборе символа в этом поле выводится библиотека символов.

Имя символа:

В это поле вводится символ, графика которого должна быть присвоена определению функции: Щелкните кнопку [...], чтобы открыть диалоговое окно Выбор символа и выбрать символ. Многократный выбор здесь невозможен.

!!! note "Замечание:"

    Обратите внимание на то, что на просмотр выводятся толькосимволысохраненныхбиблиотек символов. Если эта форма будет использоваться в проекте, в котором отсутствует или не сохранена соответствующая библиотека символов, то в отчете эти условныеобозначениябудут отсутствовать!

 

Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](eplan/userinterface_m_kontextmenu.md).
