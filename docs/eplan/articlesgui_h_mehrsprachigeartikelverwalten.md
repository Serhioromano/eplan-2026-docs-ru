# Управление многоязычными данными изделий

Если, напр., при зарубежных поставках следует применять иностранные обозначения, можно создать и обработать основные данные изделия на различных языках. Многоязычные записи для изделий возможны на вкладке Свойства, например, для свойств Изделие: Обозначение [1–3] и Описание. По умолчанию многоязычные редактируемые поля ввода также обозначаются стоящей впереди пиктограммой в базе данных изделий. Перечень возможных многоязычных свойств для базы данных изделий вы найдете в настройках перевода, определенных пользователем (диалоговое окно Настройки: Управление изделиями / вкладка Управление изделиями).

### Определение настроек перевода

1. Выберите следующие команды: Вкладка Основные данные > группа команд Изделия > Управление.
2. Выберите в диалоговом окне Управление изделиями под кнопкой [Дополнительно] пункты меню Перевод > Настройки.
3. Перейдите в диалоговом окне Настройки: Перевод на вкладку Вне зависимости от проекта.
4. В списке Языки выберите языки перевода, на которые должны переводиться тексты изделий: Используйте кнопки над полем для добавления или удаления языков.
5. В поле Исходный язык определите исходный язык для перевода текстов, независимо от проекта. Из раскрывающегося списка можно выбрать или язык диалогового окна, или язык, уже заданный как язык перевода.

!!! info "Для сведения:"

    Для данного языка Eplan при переводе ищет подходящие ключевые слова в словаре и переводит их на все выбранные языки перевода. Если выбран параметр ##_## (Язык диалогового окна), исходный язык автоматически адаптируется под язык диалогового окна, в настоящий момент установленного в Eplan.

6. Щелкните по кнопке ++OK++.

Условия:

* Вы открыли диалоговое окно Управление изделиями (вкладка Основные данные > группа команд Изделия > Управление).
* Вы ввели текст на исходном языке для многоязычного свойства изделия и установили курсор в соответствующее поле.

1. Выберите пункт всплывающего меню Перевести.

!!! info "Для сведения:"

    Если в словаре уже есть переводы для введенного понятия, открывается диалоговое окно Найденные слова; в нем перечисляются все тексты, начинающиеся на исходном языке с введенных букв.

2. Выберите подходящий текст перевода в диалоговом окне Найденные слова, выполнив двойной щелчок.

!!! info "Для сведения:"

    Если в словаре нет переводов, открывается диалоговое окно Перевести, после чего можно ввести новый текст перевода.

3. При необходимости отредактируйте текст перевода в диалоговом окне Перевод или введите новый текст перевода.

4. Щелкните по кнопке ++OK++.

!!! info "Для сведения:"

    Текст переводится. Стоящая впереди пиктограмма ![](images/navigatorgui_globecolor_as.png) помечает текст как зависимый от языка.

!!! example "Пример:"

    Введите текст "Tacho" для свойства Изделие: Обозначение 2в столбце Значение. Выберите пункт всплывающего меню Перевести. В диалоговом окне Найденные словавыводятся следующие записи:DE: Tacho EN: TachometerDE: Tachogenerator EN: Tachometer generatorДважды щелкните по требуемой записи. Открывается диалоговое окно Многоязычный ввод, в котором можно доработать перевод.

Условия:

* Вы открыли диалоговое окно Управление изделиями (вкладка Основные данные > группа команд Изделия > Управление).
* Вы ввели текст на исходном языке для многоязычного свойства изделия и установили курсор в соответствующее поле.

1. Выберите пункт всплывающего меню Многоязычный ввод.
2. Введите текст перевода в диалоговом окне Многоязычный ввод.
3. Щелкните по кнопке ++OK++.

Условия:

* Вы открыли диалоговое окно Управление изделиями (вкладка Основные данные > группа команд Изделия > Управление).
* Вы перевели текст или сохранили текст перевода для многоязычного свойства изделия.

1. Установите курсор в соответствующее поле.
2. Выберите пункт всплывающего меню Убрать переводы.

!!! info "Для сведения:"

    Тексты перевода текущего выбранного свойства будут удалены. Стоящая впереди пиктограмма ![](images/navigatorgui_globegrey_as.png) помечает текст как не зависимый от языка.

1. Выберите следующие команды: Вкладка Основные данные > группа команд Изделия > Управление.
2. Выберите в диалоговом окне Управление изделиями под кнопкой [Дополнительно] пункты меню Перевод > Импортировать тексты изделий.
3. Выберите в диалоговом окне Выбрать языки языки, тексты которых необходимо импортировать в словарь, и нажмите ++OK++.

!!! info "Для сведения:"

    Тексты изделий импортируются.
