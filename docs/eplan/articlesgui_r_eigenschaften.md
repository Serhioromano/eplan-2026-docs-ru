## Вкладка Свойства

Вкладка Основные данные > группа команд Изделия > Управление. Через меню [Дополнительно] > Настройки была открыта база данных изделий. В дереве или списке выделено одно изделие, или в дереве выделен список принадлежностей, размещение принадлежностей и т. д. Выберите вкладку Свойства.

На этой вкладке для изделий отображаются свойства изделий в виде таблицы, и их можно редактировать. Если выбрать другой тип записи данных, такой как список принадлежностей, схема сверления и т. д., на вкладке в виде таблицы отобразятся свойства, типичные для той или иной записи данных.

Обзор основных элементов диалогового окна:

Панель инструментов:

Вы можете настроить отображение свойств с помощью следующих кнопок:

Кнопка |  Значение  
---|---  
(представление в виде дерева) |  Отображает свойства в виде дерева.  
(представление в виде списка) |  Отображает свойства, расположенные друг под другом, в виде списка.  
(Все свойства) |  Отображает все свойства.  
(Заполненные свойства) |  Отображает только те свойства, для которых существует значение.  
(Из схемы) |  Отображает настроенные свойства из схемы.  
  
Если активирована кнопка  (Из схемы), вы можете выбрать из раскрывающегося списка схему для отображения и обработки свойств. Откройте с помощью кнопки [...] диалоговое окно Конфигурировать свойства. Здесь вы можете указать для схемы, какие свойства должны отображаться на вкладке Свойства и в какой последовательности.

Если активирована кнопка  (Все свойства),  (Заполненные свойства) или  (Из схемы), вы можете перейти в представление в виде дерева или списка с помощью кнопок  (Представление в виде дерева) и  (Представление в виде списка).

!!! note "Замечание:"

    

 

Пoиск:

Введите в это поле текст, по которому должна выполняться фильтрация свойств. При этом выполняется поиск имен отображаемых свойств и их значений.

Если необходимо вернуться к прежнему виду свойств, удалите текст из поля ввода. Для этого нажмите кнопку  (Удалить).

Свойство / Значение:

Отображает значения определенных свойств для выделенного или выделенных изделий / типов записи данных. Какие именно свойства и значения можно здесь обработать, зависит от выбранной схемы / кнопки для свойств.

Всплывающее меню:

Всплывающее меню дает доступ, в зависимости от типа поля (например, дата, целое число, многоязычный), к пунктам меню, при помощи которых вы можете по необходимости, например, влиять на представление таблиц или обрабатывать значения в полях. Обзор пунктов этого всплывающего меню вы можете найти в разделе [Пункты всплывающего меню](eplan/userinterface_m_kontextmenu.md).

Дополнительно здесь представлены следующие пункты всплывающего меню, специфические для данного диалогового окна:

Пункт меню |  Значение  
---|---  
Перейти к |  Доступно только для свойств, которые ссылаются на другое изделие (например, для изделий группировки продуктов "Механика > Сборные шины > Система" свойство Кронштейн сборной шины: Номер изделия). Переход к изделию, введенному в текущей выделенной строке.  
  
Обзор основных свойств:

[Уровень иерархии "Общее"](javascript:void\(0\);)

Здесь задается важная информация для изделия, например, номер изделия или группировка продуктов. Номер изделия и номера ERP / PDM изделия должны быть уникальными. Другие данные можно задать один раз для каждого варианта изделия.

Изделие: Обозначение 1:   
Изделие: Обозначение 2:   
Изделие: Обозначение 3:

В этих свойствах можно ввести дополнительную информацию об изделии, например, в соответствии с данными в каталоге производителя. Они не анализируются по отдельности, но могут быть выведены в спецификации.

Номер изделия:

Номер изделия является идентифицирующим — он объединяет разные варианты одного изделия. Если речь идет о вариантах изделий, идентифицирующей является комбинация номера изделия и обозначение варианта.

Вы можете ввести любое количество символов для номера изделия, но идентифицирующими являются только первые 96 символов в формате UTF-8. При сохранении изделия или варианта система автоматически проверяет, существует ли уже такой номер изделия или обозначение варианта.

!!! note "Замечание:"

    Мы рекомендуем всегда использовать одну и ту же структуру при присвоении номеров изделия.

 

!!! example "Пример:"

    Номер_группы.Производитель.Прочая_информация.Порядковый_номер; обозначение ввода:KM22.KLM.0750.0001Производитель.Номер_группы.Порядковый_номер; обозначение ввода:SIE.3TB.000

 

Деталь, снятая с производства:

Установите этот флажок, если изделие должно быть помечено как "больше не используется". Затем можно отобразить или отфильтровывать такие изделия с помощью конфигурации представления в виде списка в навигаторах изделий и спецификаций, а также с помощью фильтра.

Номера ERP / PDM:

В этом свойстве можно сохранять для одного изделия до десяти номеров ERP / PDM с соответствующими описаниями. В столбце Значение нажмите на […], чтобы открыть последующее диалоговое окно Свойство: Номера ERP / PDM.

Укажите в первом столбце номер существующей ERP-системы или PDM-системы. Номера ERP / PDM для разных изделий должны быть уникальными. В одном изделии допускается также использовать одни и те же значение для свойств от Номер ERP / PDM 1 до Номер ERP / PDM 10. Варианты изделия также должны иметь одинаковый номер ERP / PDM. Вы можете ввести любое количество символов, но идентифицирующими являются только первые 64 символа в формате UTF-8.

Во втором столбце введите к номеру ERP / PDM соответствующее описание.

Если вы ввели несколько номеров ERP / PDM и их описаний, то эти записи отображаются вместе на вкладке Свойства в одной ячейке столбца Значение и будут разделены разрывом строки. Вы можете также отобразить отдельные свойства для номеров ERP / PDM 1-10 (и их описания) на вкладке Свойства. Для этого необходимо настроить соответствующую конфигурацию свойств или же активировать вид "Все свойства". Здесь отдельные свойства доступны только для чтения, редактирование возможно только в диалоговом окне Свойства: Номера ERP / PDM.

Введенные номера ERP / PDM проверяются при сохранении изделия или варианта. Если такой номер уже существует, на экране появится сообщение. Если номер ERP / PDM вводится для варианта изделия, то этот номер синхронизируется с другими вариантами изделия. При копировании изделия номера ERP / PDM не копируются вместе с ним. При импорте многократно используемые номера ERP / PDM перечисляются в системных сообщениях и не переносятся в базу данных изделий.

Несмотря на то что номера ERP / PDM проверяются на уникальность при вводе и импорте данных изделий, все же возможно наличие одинаковых номеров ERP / PDM на разных изделиях или вариантах изделий вследствие обработки через API Eplan. Чтобы можно было найти нужные изделия, в классе сообщения 502 "Основные данные изделия" доступен контрольный прогон 502021. Кроме того, возможно существование различных номеров ERP / PDM для вариантов изделия. Чтобы найти эти различия между вариантами изделия, дополнительно доступен контрольный прогон 502036.

Производитель:  
Поставщик:

В этих свойствах можно выбрать соответствующее краткое и полное имя в столбце Значение, нажав на кнопку [...]. Ввод краткого имени напрямую также возможен, но свойство для полного имени не может быть обработано.

Группировка продуктов:

Чтобы изменить отнесение изделия к группировке продуктов, нажмите в столбце Значение для этого свойства на кнопку [...]. Из раскрывающегося списка группировок продуктов выберите нужную подгруппу продуктов (например, "Общие"), дважды щелкнув по ней.

После сохранения или применения изменений изделие будет соответствующим образом пересортировано в представлении в виде дерева.

Номер типа:

В отличие от номера изделия, номер типа, в частности, для кабелей, не является уникальным. Введенные здесь данные должны по возможности соответствовать данным в каталоге производителя.

Вариант:

Введите здесь нужное обозначение варианта (не более трех символов). Для изделия всегда существует минимум один вариант. Первому варианту изделия по умолчанию присваивается обозначение варианта "1".

[Уровень иерархии "Данные" (для изделий)](javascript:void\(0\);)

Здесь задаются "общие" данные для изделия.

Схема соединений:

Чтобы сохранить в изделии схему соединений, созданную на уровне иерархии "Схема соединений", нажмите на кнопку [...] в столбце Значение и выберите в диалоговом окне Выбор схемы соединений нужную схему соединений.

Схема соединений: Смещение в направлении X:  
Схема соединений: Смещение в направлении Y:

Задайте в этих свойствах для соответствующей схемы соединений смещение в направлениях X и Y. Таким образом, можно использовать идентичные схемы соединений для изделий разной величины.

Атрибуты:

Свойства, доступные под этим уровнем иерархии, служат вводу дополнительных атрибутов. Атрибуты не зависят от типа изделия. В отличие от определенных пользователем свойств атрибуты не являются многоязычными!

!!! note "Замечание:"

    Каждый атрибут может использоваться для фильтрации. Можно указать, например, классы изделий и признаки классификации согласноETIMи отобразить данные изделия, отфильтрованные согласно этой модели.

 

Тип записи данных:

Это свойство отображает тип данных изделий или смежных данных (например, отдельная часть, узел, список принадлежностей, схема сверления, клиент). При работе с данными изделий и адресами можно изменить тип записи данных с помощью раскрывающегося списка. Это применимо к таким данным изделий: отдельная часть, узел, модуль; а также к таким адресам: клиент, производитель / поставщик.

Группа функций:

Это свойство служит в информативных целях и может, например, использоваться для фильтрации при выборе изделий.

!!! example "Пример:"

    В схему соединений вставлен аварийный нажимной выключатель. Для его выбора можно разделить следующим образом:Группа функций: ПереключательВид изделия: Кнопочный переключатель

 

Номер группы:

Номер группы служит для различия отдельных групп изделий.

Макрос схемы соединений:

Нажмите в столбце Значение на , чтобы выбрать нужный 2D-макрос для проектирования схемы соединений с помощью диалогового окна выбора файла.

В частности для модуля важно связывание с каким-нибудь макросом; если при сохранении модуля макрос не присвоен, будет выведено сообщение об этом.

В этом свойстве можно также задать контуры типа "Выдавить контур". Эти контурные чертежи можно использовать для размещения определенных пользователем шин в пространстве листа.

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](eplan/modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

!!! note "Замечание:"

    Соблюдайте наширекомендации по работе с 2D- и 3D-макросами.

 

!!! tip "Совет:"

    Если какое-либо изделие с указанным таким образом макросом или чертежом контура вставить в список устройств, то данное изделие можно будет разместить в схеме соединений при помощи перетаскивания.

 

Макрос схемы соединений: GB/CCC... Макрос схемы соединений: NFPA мм:

В этих свойствах вы можете сохранить для одного изделия несколько специфических для стандарта макросов схемы соединений. Нажмите в столбце Значение на , чтобы выбрать нужный макрос с помощью диалогового окна выбора файла.

Макросы схемы соединений фирменного стандарта:

В этом свойстве вы можете сохранить для одного изделия до десяти фирменных стандартов с соответствующими макросами схемы соединений. Щелкните в столбце Значение по [...], чтобы открыть следующее диалоговое окно Свойство: Макросы схемы соединений фирменного стандарта. Там в первом столбце внесите названия фирменных стандартов, а во втором столбце выберите соответствующие макросы при помощи .

Название фирменного стандарта не переводится. Если название уже существует, его можно выбрать в столбце Макрос схемы соединений: Название фирменного стандарта, нажав на […].

Чтобы макрос для стандарта компании использовался при вставке, имя стандарта компании также должно быть внесено в настройку проекта Фирменный стандарт группового поля Предпочтительные стандарты для вставки макросов схем соединений.

!!! note "Замечание:"

    

 

Вид изделия:

Виды изделий служат для группирования одинаковых изделий; так, напр., можно использовать группирование по силовым и вспомогательным контакторам с различными многими размыкающими и замыкающими контактами. Или, например, можно выделить в одну группу функциональные элементы, чувствительные к нагреву или вибрации. Просто выделите группируемые изделия и введите нужное обозначение в свойство.

!!! example "Пример:"

    Создайте для чувствительных к нагреву функциональных элементов вид изделия "WE", для чувствительных к вибрации элементов вид изделия "VIB".

 

[Уровень иерархии "Данные" (для списков принадлежностей)](javascript:void\(0\);)

Здесь определяются списки принадлежностей. Список принадлежностей позволяет выбрать изделие принадлежностей из списка возможных альтернативных вариантов.

Имя (список принадлежностей):

Введите здесь имя списка принадлежностей. На основании имени можно выбрать список принадлежностей на изделии на вкладке Принадлежности.

[Уровень иерархии "Настройки" (для списков принадлежностей)](javascript:void\(0\);)

Вставить полностью список принадлежностей:

Установите этот флажок, чтобы автоматически добавлять все изделия списка принадлежностей при выборе устройства либо при вставке или размещении устройства.

Дополнительную информацию см. в разделе "[Вставить полностью список](eplan/articlesgui_k_zubehoerlisten.md#ZubehoerlistenVollstaendig)".

[Уровень иерархии "Данные" (для размещения принадлежностей)](javascript:void\(0\);)

Здесь определяется размещение принадлежностей. При размещении принадлежностей можно задать позицию (исходную точку), на которой будет размещен компонент принадлежностей. Если такое размещение принадлежностей определено на элементе принадлежностей в базе данных изделий, размещение принадлежностей происходит автоматически при вставке в пространстве листа.

Описание (размещение принадлежностей):

Введите здесь описание для размещения принадлежностей.

Имя (размещение принадлежностей):

Введите здесь имя размещения принадлежностей. На основании имени можно выбрать размещение принадлежностей на изделии для принадлежностей или на списке принадлежностей.

[Уровень иерархии "Данные" (для схем сверления)](javascript:void\(0\);)

Здесь определяются схемы сверления. Схема сверления содержит данные о виде и расположении монтажных отверстий и отверстий в функциональных элементах электрошкафов.

Имя:

Введите здесь имя схемы сверления. На основании имени можно выбрать схему сверления на изделии на вкладке Изготовление.

[Уровень иерархии "Данные" (для схем соединений)](javascript:void\(0\);)

Здесь определяются стандартные значения для выводов устройств на схеме соединений. Чаще всего размещения изделий в пространстве листа получают информацию о существующих выводах устройства из определения схемы соединений изделия. Чтобы присвоить изделию схему соединений, определенную в типе записи данных "Схема соединений", на вкладке Свойства изделий в свойстве Схема соединений можно выбрать заданную здесь схему соединений.

Категория соединения (стандарт):

Выберите из раскрывающегося списка в столбце Значение значение по умолчанию, которое точнее задает тип вывода устройства соединений.

Нажмите на кнопку [...], чтобы в следующем диалоговом окне задать собственные значения и сохранить их в базе данных. При создании новых схем соединений мы рекомендуем использовать только [категории соединений в соответствии с классификацией ECLASS](eplan/partsmanagementgui_d_einstanschlussausf.md#Tabelle).

Размер присоединения (стандарт):

Здесь можно ввести размер присоединения для болтовых соединений, соединений с помощью плоского штекера, ленточных выводов, шинных соединений, внутренней и наружной резьбы. Задайте для клеммы с категорией соединения "Болтовое соединение", например, диаметр болта "3 мм". Или введите для резьбового разъема с категорией соединения "Наружная резьба" присоединительную резьбу, например "M3" или "G1/8".

Имя (схема соединений):

Введите здесь имя схемы соединений. На основании имени можно выбрать схему соединений на изделии.

Направление подсоединения (стандарт):

Выберите из этого раскрывающегося списка значение по умолчанию для направления вывода устройства.

Дополнительная длина (стандарт):

Введите здесь значение по умолчанию дополнительной длины расположения вывода устройства.

[Уровень иерархии "Монтажные данные"](javascript:void\(0\);)

Здесь задаются монтажные данные для изделия. Эти данные используются при размещении изделия на трехмерном чертеже монтажных поверхностей и частично на компоновке электрошкафа 2D.

Размеры:

Свойства Ширина, Высота и Глубина, доступные под этим уровнем иерархии, предназначены для ввода размеров конкретного устройства в мм. В случае использования систем разводки данные о размерах следует вводить в соответствии с монтажной шиной, кабельной развилкой или перфорированной планкой.

Устройства и функциональные элементы можно визуализировать не только с помощью свойств Ширина, Высота и Глубина, но и с помощью квалифицированных графических 3D-макросов.

Высота крепления зажимом:

Относится только к трехмерному чертежу монтажных поверхностей. Высота крепления зажимом описывает позицию в виде сбоку или сверху/снизу. При размещении на несущей шине функциональный элемент автоматически размещается на шине на нужной глубине установки. При замене шины функциональный элемент соответствующим образом перемещается по высоте. Таким образом, выравнивание функционального элемента осуществляется не по нижнему краю шины, а по верхней кромке с учетом введенного здесь значения.

!!! example "Пример:"

    (1) высота крепления зажимом

 

Графический файл:

Нажмите в столбце Значение на , чтобы с помощью диалогового окна выбора файла выбрать нужный графический файл (*.bmp, *.jpg и т. д.). Сохраненный здесь графический файл отображается для изделия в предварительном просмотре графики, при вставке в качестве устройства в центре вставки и т. д.

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](eplan/modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

Интервалы установки:

Эти свойства используются для ввода интервала установки в мм. В случае использования систем разводки данные о размерах следует вводить в соответствии с монтажной шиной, кабельной развилкой или перфорированной планкой.

Если в этих свойствах сохранены значения, можно вычислить значение свойства Занимаемая площадь по следующей формуле:  
((b+ab) * (h+ah)), где b = ширина, ab = интервал установки по ширине, h = высота и ah = интервал установки по высоте.

Глубина установки:

Введите глубину установки в мм. Это свойство изделия учитывается при размещении изделия 3D только в том случае, если для размещения изделия не используется графический макрос 3D. Значение автоматически указывает, насколько функциональный элемент после размещения изделия входит в другой функциональный элемент по оси Z и относительно монтажной поверхности.

!!! example "Пример:"

    (1) Функциональный элемент (дверь), (2) монтажная поверхность, (3) размещение изделия, (4) глубина установки

 

Внешнее размещение:

Установите этот флажок, если изделие обозначается как "внешне размещенный" и тем самым должен подсоединяться от вида использования в компоновке элетрошкафа (напр., двигатели или генераторы).

Графический макрос:

Нажмите в столбце Значение на , чтобы выбрать нужный макрос с помощью диалогового окна выбора файла.

Содержание сохраненного здесь 3D-макроса определяет графику для трехмерного чертежа монтажных поверхностей. Если у изделия нет графического макроса, то графика будет представлена в виде параллелепипеда с указанными высотой, шириной и глубиной.

!!! note "Замечание:"

    Соблюдайте наширекомендации по работе с 2D- и 3D-макросами.

 

В этом свойстве можно также задать контуры типа "Выдавить контур". Эти контурные чертежи можно использовать для размещения определенных пользователем шин в пространстве листа.

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](eplan/modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

Несовпадение центров:

Относится только к трехмерному чертежу монтажных поверхностей. Если в виде спереди изделие размещается не по центру, здесь следует ввести расстояние для смещения относительно середины несущей шины. Функциональный элемент будет автоматически перемещен на заданное расстояние.

!!! example "Пример:"

    (1) несовпадение центров = 0; (2) положительное значение для смещения центра; (3) отрицательное значение для смещения центра

 

Занимаемая площадь:

Введите здесь занимаемую площадь изделия. Если для свойств Ширина и Высота внесены значения, то занимаемая площадь определяется автоматически по следующей формуле:  
(b*h) где b = ширина и h = высота.

Текстура:

Нажмите в столбце Значение на , чтобы выбрать нужный графический файл для текстуры с помощью диалогового окна выбора файла. Графический файл, сохраненный в этом свойстве, отображается при размещении изделия в пространстве листа (при наличии размеров изделия) на передней странице размещенного 3D-объекта. При использования графического файла в качестве текстуры поверхность 3D-модели будет детализирована и представлена более реалистично, либо будет отображена фотография оригинального функционального элемента.

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](eplan/modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

Номера штрихкодов:  

Штрихкоды служат для однозначного определения товаров. В мире используются различные стандартные кодировки, например GTIN (Global Trade Item Number). Поэтому на предприятиях используются или специфические для предприятия, или отраслевые кодировки. В этом свойстве можно сохранить для одного изделия нужный номер штрихкода.

Тип штрихкода:

Значение этого свойства указывает, какой тип кодировки используется, например, кодировка 2D, EAN / GTIN, ISBN и т. д.

Содержание свойств Номера штрихкодов и Тип штрихкода может анализироваться в значениях изделия (спецификации изделий, списки производителей / поставщиков и т. д.) и учитываться при экспорте / импорте изделий.

[Уровень иерархии "Технические данные" (для сборных шин)](javascript:void\(0\);)

Здесь задается информация для Расчет мощности потерь сборных шин для изделий группировки продуктов "Механика > Сборные шины > Шина".

Проводимость (при +20 °C):

Удельная электрическая проводимость указывается в единицах МСм/м (= Мегасименс на метр). Значения для материалов шин "Медь, Cu-ETP CW004A" и "Алюминий, EN AW-1350A" вводятся автоматически. Значения для других материалов можно узнать из технического паспорта.

Поперечное сечение шины:

Поперечное сечение шины рассчитывается из значений высоты и ширины или берется из технического паспорта производителя.

Материал шины:

Можно выбрать следующие материалы:

* Медь, Cu-ETP – CW004A: Cu-ETP — обозначение материала согласно стандарту; CW004A — номер материала согласно стандарту EN 13601 для материала с содержанием меди не менее 99,9 %.
* Алюминий, EN AW-1350A
* Другой материал

При выборе материала "Медь, Cu-ETP — CW004A" или "Алюминий, EN AW-1350A" свойства Проводимость (при +20 °C) и Температурный коэффициент заполняются автоматически. После этого свойства становятся защищены от записи.

Температурный коэффициент:

Температурный коэффициент описывает относительное изменение электрического сопротивления сборной шины в зависимости от Материал шины и температуры по отношению к эталонной температуре 20 °C. Значения для материалов шины "Медь" и "Алюминий" записываются автоматически. Значения для других материалов можно узнать из технического паспорта.
