## Диалоговое окно "Настройки экспорта: Rittal - RiPanel Processing Center"

Файл > Экспортировать > группа команд Данные изготовления > Механическая обработка > Rittal - RiPanel Processing Center. Нажмите рядом с полем Схема на кнопку [...].

В этом диалоговом окне задаются общие настройки экспорта данных для интерфейса Rittal - RiPanel Processing Center.

Обзор основных элементов диалогового окна:

Схема:

Выберите из раскрывающегося списка схему, которую требуется использовать или обработать. Для этого также воспользуйтесь соседней [панелью инструментов](schemeconfig_m_schemaschaltflaechen.md).

* * *

Вкладка Общее

Каталог вывода:

Файл экспорта будет создан в виде AML-файла. В этом поле укажите место хранения. В качестве целевых для экспорта данных можно указать любой дисковод и подкаталог. Предварительно установлен каталог $(EPLAN_DATA)\Export.  

С помощью пункта всплывающего меню Вставить переменную пути перейдите в диалоговое окно [Выбрать переменную пути](modaldialogsdb_d_pfadvariablen.md), из которого можно будет скопировать одну из доступных переменных пути.

Генерировать имена файлов:

В этом раскрывающемся списке определяется стандартный порядок присвоения имен файлам экспорта:

* Из свойств: если выбран этот параметр, имя файла составляется из свойств проекта, а также свободно определяемого разделителя. Используя кнопку [...], откройте диалоговое окно Формат: Свойство для конфигурации имени файла.

Генерировать подкаталоги:

В этом раскрывающемся списке определяется стандартный порядок создания подкаталогов при экспорте файлов AML:

* Нет: Если выбран данный параметр, при экспорте подкаталоги не генерируются.

* Из свойств: Если выбран этот параметр, имя подкаталога составляется из свойств проекта, а также свободно определяемых разделителей / разделителей каталога. При нажатии кнопки [...] открывается диалоговое окно Формат: Свойство для конфигурации имени каталога. Воспользуйтесь, например, элементом формата "Разделитель каталога", чтобы создать структуру каталога с несколькими подкаталогами, расположенными друг под другом.
