## Диалоговое окно Настройки: База данных изделий

[Вызов диалогового окна:](javascript:void\(0\);)

  * Вы открыли базу данных изделий. Вкладка Основные данные > группа команд Изделия > Управление. Кнопка [Дополнительно] > Настройки. Кнопка [Другие].
  * Вы открыли проект и выделили главную функцию в графическом редакторе или навигаторе. Пункт всплывающего меню Свойства. Выберите вкладку Изделия и нажмите рядом с полем Источн. данных на [...].
  * Файл > Настройки > Пользователь > Управление > Изделия. Кнопка [Другие].



В диалоговом окне Настройки: Изделие (пользователь) щелкните по кнопке [Другие].

В этом диалоговом окне устанавливаются определенные предварительные настройки для работы с базой данных изделий.

Обзор основных элементов диалогового окна:

Импорт / экспорт единицы измерения:

В базе данных изделий единицы измерения всегда сохраняются в "мм / кг". При импорте или экспорте данных Eplan с помощью этих опций можно установить, какая система единиц измерения должна использоваться.

Валюта 1 / валюта 2:

В этих двух полях задайте две валютные единицы, которые будут использоваться для выбранной базы данных изделий.
