## Просмотреть и обработать свойства соединения

  1. Выберите следующие команды: Вкладка Соединения > группа команд Соединения > Навигатор.
  2. Выделите в диалоговом окне Соединения — <Имя проекта> нужные соединения и выберите пункт всплывающего меню Свойства.
  3. В диалоговом окне Свойства <...> во вкладке [Соединение](devicetaggui_r_verbindung.htm) измените свойства соединений, а во вкладке [Графика соединения](devicetaggui_r_verbindungsgrafik.htm) — графические свойства линий соединений.
  4. Щелкните по кнопке [OK].



Свойства соединения можно просмотреть и обработать в диалоговом окне Соединения — <Имя проекта>.



!!! note "Замечание:"

    ПосредствомТочки обозначения соединениясоединениям могут быть присвоены дополнительные свойства. Эти свойства обрабатываются на точке определения соединения.


 

!!! tip "Совет:"

    Во вкладкеСоединениев полеОбозначение соединенияможно автоматически определить ближайшее свободное обозначение соединения. Для этого воспользуйтесь пунктом всплывающего менюОпределить новое обозначениеили комбинацией клавиш[Ctrl]+[N].
