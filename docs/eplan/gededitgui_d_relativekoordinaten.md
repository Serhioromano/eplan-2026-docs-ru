## Диалоговое окно Относительный ввод координат

[Вызов диалогового окна:](javascript:void\(0\);)

Вы открыли проект. В Графическом редакторе открыта страница проекта. Вкладка Обработать > группа команд Параметры > Относительный ввод координат.

В этом диалоговом окне вводятся целевые координаты для установки курсора. Ввод выполняется относительно текущей позиции курсора. При этом у вас есть две возможности: либо укажите в поле Интервал целевые координаты относительно текущей позиции курсора. Или целевые координаты указываются с помощью угла и длины линии перемещения.



!!! note "Замечание:"

    Обратите внимание, что результаты перехода к целевым координатам не точные, а ориентированы на сетку, если вводится длина, исеткавключена.


 

Обзор основных элементов диалогового окна:

Интервал (<Система координат>):

При вызове диалогового окна здесь выводятся установленная система координат и текущая позиция курсора. Введите в полях X и Y значения, на которые должна переместиться конечная точка от координат исходной точки в направлении X и Y. Возможен ввод положительных и отрицательных значений. При этом значения в полях Угол и Длина изменяются автоматически.

Угол:

Введите значение угла, чтобы определить направление перемещения курсора.

Длина:

Укажите длину, на которую должен быть перемещен курсор в направлении введенного угла. При этом значения для полей X и Y в поле Интервал изменяются автоматически.
