## Расширение функциями Fluid

Все модули расширения из Eplan Electric P8 для версии 2026 расширены в функциями Eplan Fluid. Благодаря этому теперь все функции Eplan Fluid являются неотъемлемой составной частью Eplan Electric P8.

Это означает, что установка Eplan Fluid как отдельной программы больше не требуется. По-прежнему возможна установка оригинальных основные данных Eplan Fluid в качестве Add-on. По умолчанию обширные основные данные для Eplan Fluid при установке Eplan Electric P8 не устанавливаются. Однако при выборе компонентов программы в Eplan Setup Manager у вас есть возможность активировать установку этих данных.
